05 QUESTIONS & ANSWERS

Frequently Asked Questions

Answers on running .js files without HTML, ES modules, infinite loops, and Node.js modules.

Can I run a .js file directly on Android without creating an HTML page?+
Yes! Tapping Run on any .js, .mjs, or .cjs file launches SuperCode's standalone JavaScript console immediately — completely offline.
Can I split my JavaScript code across multiple files with import/export or require()?+
Yes. Both ES Modules (import / export) and CommonJS (require / module.exports), as well as .json imports, work across local project files and unsaved tabs.
Will an accidental while(true) loop freeze my editor or lose unsaved code?+
Never. Scripts execute in an isolated background worker guarded by a 15-second watchdog and output-flood breaker, terminating runaway loops in under 1 millisecond without touching the UI thread.
What if I want to build a visual DOM website with HTML, CSS, and WebAssembly?+
SuperCode includes both! Use the standalone JavaScript IDE for pure JS/Node modules and algorithms, and the Full-Stack Web & PHP Studio whenever you want live HTTP DOM rendering, Responsive Viewports, and Web DevTools.
