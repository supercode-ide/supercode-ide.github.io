03 ADIM ADIM İŞ AKIŞI

Mobil Kazıyıcı veya Bot Prototipinden VPS Dağıtımına

Tek bir birleşik Android IDE'den üretim düzeyinde Python betikleri oluşturun, test edin, çıktıları inceleyin ve yayınlayın.

STEP 01 PIP -> requests, bs4, rich

Görsel PIP Yöneticisinde Hızlı Yongalara Dokunun

Yerleşik hızlı kurulum yongalarını kullanarak `requests`, `beautifulsoup4`, `rich`, `pyyaml`, `flask` veya `telebot` paketlerini saniyeler içinde kurun.

STEP 02 .env + scraper.py

API Anahtarlarını .env İçinde Güvenle Saklayın & Betiğinizi Çalıştırın

API belirteçlerini yerel bir `.env` dosyasında tutun (çalışma alanınıza otomatik bağlanır) ve konsolda biçimlendirilmiş Rich/ANSI günlüklerini inceleyin.

STEP 03 output.json / cache.db

Dışa Aktarılan JSON, CSV veya SQLite Verilerini Doğrulayın

Oluşturulan `.json` veya `.csv` dosyalarını tek dokunuşlu düzenli biçimlendirmeyle açın ya da `.db` tablolarını SuperCode'un SQL Gezgini'nde inceleyin.

STEP 04 Git Push / SFTP Sync

GitHub'a Commit Edin veya Uzak Sunucunuza Yansıtın

05 SORULAR VE CEVAPLAR

Sıkça Sorulan Sorular

Android'den web kazıma, `.env` dosyaları, Telegram botları ve Python betiği dağıtımı hakkında yanıtlar.

`lxml` ve `pydantic`, `requests` ve `beautifulsoup4` ile birlikte çalışıyor mu?+
Evet. Hem saf Python kütüphaneleri (`requests`, `beautifulsoup4`, `telebot`, `rich`) hem de derlenmiş ayrıştırıcılar (`lxml`, `pydantic`, `orjson`, `cryptography`) desteklenir.
Python betiğim bir `.env` veya `config.yaml` dosyasından değişken yükleyebilir mi?+
Evet. SuperCode'un çalışma alanı çözümleyicisi `.env`, `.yaml`, `.yml`, `.toml`, `.ini` ve `.json` dosyalarını `.py` modüllerinizle birlikte otomatik olarak bağlar.
Etkileşimli konsolda bir web kazıyıcı veya bot yoklaması ne kadar süre çalışabilir?+
Etkileşimli betikler yerel çalıştırma başına 120 saniyeye kadar yürütme penceresinde çalışır (istediğiniz an Durdur/Kes denetimiyle); böylece arka planda kontrolsüz pil tüketimi olmadan API çağrılarını, kazıyıcıları ve bot webhook işleyicilerini güvenle test edebilirsiniz.
SuperCode'da test ettikten sonra bir Telegram botunu 7/24 nasıl çalıştırırım?+
Bot işleyicilerinizi SuperCode'da yerelde geliştirip hata ayıklayın, ardından 7/24 kesintisiz çalışma için projeyi SuperCode'un yerleşik SFTP istemcisi veya Görsel Git istemcisiyle doğrudan Linux VPS'inize ya da bulut sunucunuza gönderin.
