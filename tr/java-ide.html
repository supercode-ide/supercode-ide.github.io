05 SORULAR VE CEVAPLAR

Sıkça Sorulan Sorular

Java 17 özellikleri, çok dosyalı OOP, özel .jar dosyaları ve çevrimdışı Scanner girişi hakkında sık sorulan sorular.

SuperCode, Android'de hangi Java sürümünü çevrimdışı derler?+
SuperCode; record'lar, sealed sınıflar, switch ifadeleri, instanceof kalıp eşleştirme, metin blokları ve Stream'ler dahil Java 17'yi çevrimdışı derler ve çalıştırır; Java 21+ özellikleri içinse otomatik Bulut Java yönlendirmesi sunar.
Birden fazla sınıf ve paket içeren bir Java projesini çalıştırabilir miyim?+
Evet. SuperCode proje klasörlerinizdeki ve açık düzenleyici sekmelerindeki tüm .java dosyalarını çözümler, main() içeren sınıfı otomatik belirler ve yazılan tüm dosyaları çalışma alanınıza geri eşitler.
Java'yı yerel bir SQLite veritabanına bağlayabilir veya harici .jar dosyaları ekleyebilir miyim?+
Evet! Çevrimdışı jdbc:sqlite:... JDBC sürücüsü dahili olarak gelir ve projenizin libs/ dizinine koyduğunuz tüm uyumlu .jar kütüphaneleri classpath'e otomatik eklenir.
Scanner(System.in) etkileşimli olarak çalışır mı?+
Evet. Scanner veya BufferedReader girdi beklediğinde programınız sorunsuzca duraklar ve bölünmüş ekran terminalinde birden çok satır yazmanıza olanak tanır.
