05 QUESTIONS & ANSWERS

Frequently Asked Questions

Common questions on Java 17 features, multi-file OOP, custom .jar files, and offline Scanner input.

What version of Java does SuperCode compile offline on Android?+
SuperCode compiles and runs Java 17 offline — including records, sealed classes, switch expressions, pattern matching for instanceof, text blocks, and Streams — with automatic Cloud Java routing for Java 21+ features.
Can I run a Java project with multiple classes and packages?+
Yes. SuperCode resolves all .java files across your project folders and open editor tabs, arbitrates the class containing main() automatically, and syncs any written files back to your workspace.
Can I connect Java to a local SQLite database or add external .jar files?+
Yes! An offline jdbc:sqlite:... JDBC driver is built right in, and any compatible .jar libraries placed in your project's libs/ directory are added to the classpath automatically.
Does Scanner(System.in) work interactively?+
Yes. Your program pauses cleanly whenever Scanner or BufferedReader waits for input, letting you type multiple lines in the split-screen terminal.
