02 মূল সক্ষমতা

SRE, সিসঅ্যাডমিন ও সেলফ-হোস্টেড হোমল্যাব নির্মাতাদের জন্য তৈরি

দুর্বল মোবাইল নেটওয়ার্ক, বিশাল লগ ডাম্প এবং রিমোট Linux হোস্টে অনাকাঙ্ক্ষিত পারমিশন নষ্ট হওয়া থেকে সুরক্ষায় প্রতিটি অংশ হার্ডেন করা।

02.1

POSIX 0755 বজায় রেখে ৩-ধাপের অ্যাটমিক SFTP সেভ

অস্থির সেলুলার ডেটায় লাইভ /usr/local/bin/backup.sh সেভ করলে স্ক্রিপ্ট কেটে যাবে না বা +x বিট হারাবে না। SuperCode আগে স্টেজিং ফাইলে লেখে, ইন্টিগ্রিটি যাচাই করে, অ্যাটমিক রিনেম করে এবং সঠিক 0755/0644 মোড অক্ষুণ্ণ রাখে।

শূন্য অর্ধ-লিখিত কনফিগ · POSIX 0755 সুরক্ষিত
02.2

হার্ডওয়্যার-ব্যাকড AES-256 SSH কী ও হোস্ট ভল্ট

কনকারেন্ট ট্রান্সফার ও রিজিউমসহ Android Keystore AES-256 দিয়ে এনক্রিপ্ট করা Ed25519/RSA SSH প্রাইভেট কী ব্যবহার করে SFTP, FTPS ও FTP-র মাধ্যমে Ubuntu, Debian, Rocky বা Alpine সার্ভারে যুক্ত হন।

Ed25519 / RSA কী · Keystore AES-256 · রিজিউম
02.3

03 ধাপে ধাপে ওয়ার্কফ্লো

Android-এ অন-কল ইনসিডেন্ট ও কনফিগ আপডেট ওয়ার্কফ্লো

চারটি আলাদা অ্যাপ না খুলেই ডায়াগনসিস, ড্রাই-রান, অ্যাটমিক ডিপ্লয় ও Git-এ কমিট করুন।

STEP 01 SFTP -> Download Log

SSH কী দিয়ে যুক্ত হন ও প্রোডাকশন লগ দেখুন

SFTP এক্সপ্লোরারে আপনার Linux সার্ভার খুলুন এবং ডিস্ক-পেজড GB ভিউয়ারে বিশাল `.log` ফাইল দেখুন বা `grep`/`awk` দিয়ে ফিল্টার করুন।

STEP 02 Editor -> Format YAML/.sh

Shell হুক, Docker Compose বা Nginx কনফিগ এডিট করুন

অফলাইন ফরম্যাটিংসহ `.sh`, `.yml` বা `.conf` ফাইল এডিট করুন এবং আপলোডের আগে লোকালি shell পাইপলাইন লজিক টেস্ট করুন।

STEP 03 Save -> 3-Phase Atomic

0755 অক্ষুণ্ণ রেখে SFTP দিয়ে নিরাপদে পাবলিশ করুন

সরাসরি রিমোট হোস্টে সেভ করুন — অ্যাটমিক স্টেজিং আংশিক রাইট ঠেকায় এবং `0755` এক্সিকিউটেবল পারমিশন অক্ষুণ্ণ রাখে।

STEP 04 Visual Git -> Push

ইনফ্রাস্ট্রাকচার পরিবর্তন আপনার Git রিপোতে কমিট করুন

Visual Git-এ সঠিক ইউনিফাইড ডিফ রিভিউ করে হটফিক্স কমিট পুশ করুন, যাতে প্রোডাকশন ও ভার্সন কন্ট্রোল সিঙ্কে থাকে।

05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

Android-এ SuperCode ব্যবহারকারী Linux সিসঅ্যাডমিন, SRE ও হোমল্যাব ইঞ্জিনিয়ারদের প্রশ্নোত্তর।

SFTP দিয়ে রিমোট `.sh` স্ক্রিপ্ট এডিট করলে কি তার `chmod 0755` এক্সিকিউটেবল বিট মুছে যাবে?+
কখনোই না। সেভ করার আগে SuperCode রিমোট ফাইলের বর্তমান POSIX মোড দেখে নেয় এবং ৩-ধাপের অ্যাটমিক স্টেজিং রিনেমের সময় `0755` (বা কাস্টম পারমিশন) অক্ষুণ্ণ রাখে।
SuperCode কীভাবে আমার SSH প্রাইভেট কী ও SFTP পাসওয়ার্ড সুরক্ষিত রাখে?+
সকল SFTP/FTPS ক্রেডেনশিয়াল, হোস্ট প্রোফাইল ও ইমপোর্ট করা SSH প্রাইভেট কী (`Ed25519`, `RSA`, `ECDSA`) ডিভাইসেই হার্ডওয়্যার-ব্যাকড Android Keystore AES-256 সুরক্ষায় এনক্রিপ্ট থাকে।
`nginx.conf` সেভ করার মাঝপথে মোবাইল নেটওয়ার্ক চলে গেলে কী হবে?+
যেহেতু SuperCode প্রথমে একটি অস্থায়ী স্টেজিং ফাইলে আপলোড করে এবং ট্রান্সফার যাচাই সফল হওয়ার পরেই অ্যাটমিক সার্ভার-সাইড রিনেম করে, তাই আপনার লাইভ `nginx.conf` কখনোই অর্ধ-লিখিত বা ফাঁকা হয় না।
SFTP থেকে ডাউনলোড করা ১.৫ GB সার্ভার লগ কি ফোন ক্র্যাশ না করেই দেখা যাবে?+
হ্যাঁ! SuperCode-এর Large File Editor পুরো ফাইল RAM-এ লোড না করে ডিস্ক-ব্যাকড পেজে মাল্টি-গিগাবাইট ফাইল মাউন্ট করে, সাথে রয়েছে Global Stream Regex Replace।
