02 মূল সক্ষমতা

শুধু রিড-অনলি টেবিল গ্রিড নয় — এটি একটি পূর্ণাঙ্গ অফলাইন SQLite ওয়ার্কস্টেশন

অভ্যন্তরীণ মেটাডেটা ইনস্পেক্ট করুন, প্যারামিটারাইজড এডিট চালান, ফ্ল্যাট ফাইলকে SQL টেবিলে রূপান্তর করুন এবং কয়েক সেকেন্ডেই পরিচ্ছন্ন রিপোর্ট এক্সপোর্ট করুন।

02.1

.db, .sqlite, .sqlite3, .db3 ও .s3db-এর জন্য ১-ট্যাপ ইনস্পেক্টর

SuperCode-এর Explorer থেকে যেকোনো বাইনারি SQLite ডেটাবেসে ট্যাপ করুন বা Android স্টোরেজ থেকে খুলুন। SuperCode স্বয়ংক্রিয়ভাবে বাইনারি হেডার যাচাই করে .dbinfo পেজ স্ট্যাটাস, .tables সংখ্যা ও পূর্ণাঙ্গ .schema DDL দেখায়।

.db · .sqlite · .sqlite3 · .db3 · .s3db
02.2

পরিবর্তনযোগ্য ৯টি .mode ফরম্যাট (Box, Markdown, JSON, CSV+)

যেকোনো কাজের উপযোগী ফরম্যাটে ফলাফল সাজান: মোবাইলে পড়ার জন্য ঝকঝকে Unicode box গ্রিড ও ASCII টেবিল, GitHub ডকের জন্য markdown টেবিল, API-এর জন্য json অ্যারে, শিটের জন্য csv/tabs, insert SQL ডাম্প বা ভার্টিক্যাল line কার্ড।

box · table · markdown · json · csv · tabs · insert · line · list
02.3

ঝামেলাহীন .import --csv, --tsv ও --json

বিরক্তিকর CREATE TABLE লেখার ঝামেলা এড়ান। .import --csv sales.csv sales বা .import --json users.json users (৮ MB পর্যন্ত) চালান—SuperCode স্বয়ংক্রিয়ভাবে কলামের নাম বুঝে নেয়, যাতে সাথে সাথে JOIN ও অ্যাগ্রিগেট করতে পারেন।

অটো টেবিল তৈরি · CSV / TSV / JSON ৮ MB পর্যন্ত
02.4

.sql স্ক্রিপ্টের জন্য অটো-মাউন্টেড ওয়ার্কস্পেস ডেটাবেস

আপনার প্রোজেক্টের app.db ফাইলের পাশেই queries.sql রাখুন। SuperCode নিজে থেকেই ওয়ার্কস্পেস ডেটাবেস শনাক্ত ও মাউন্ট করে (অথবা .open কমান্ড অনুসরণ করে), ফলে স্কিমা মাইগ্রেশন ও এডিট সরাসরি ডিস্কে সেভ থাকে।

ডিস্কে স্থায়ী এডিট · .open মাল্টি-DB সাপোর্ট
02.5

প্রোজেক্ট ফোল্ডারে সরাসরি .once ফাইল এক্সপোর্ট

যেকোনো আউটপুট মোডের সাথে .once <filename> ব্যবহার করুন — যেমন .mode markdown + .once report.md বা .mode csv + .once clean_leads.csv — আর কুয়েরির ফলাফল সরাসরি শেয়ার করার উপযোগী ওয়ার্কস্পেস ফাইলে সেভ করুন।

03 ধাপে ধাপে ওয়ার্কফ্লো

Android-এ কীভাবে `.db` ফাইল ইনস্পেক্ট বা CSV/JSON ডেটাসেট কুয়েরি করবেন

চারটি দ্রুত ধাপে বিদ্যমান বাইনারি ডেটাবেস খুলুন বা সাধারণ ফাইল থেকে নতুন ডেটাবেস তৈরি করুন।

STEP 01 Explorer -> Tap .db

এক ট্যাপে যেকোনো .db, .sqlite বা .sqlite3 ফাইল খুলুন

তাৎক্ষণিকভাবে .dbinfo সারাংশ, .tables তালিকা এবং CREATE TABLE / INDEX স্কিমা দেখতে ওয়ার্কস্পেসে একটি ডেটাবেস ফাইল বেছে নিন।

STEP 02 .import --csv / --json

অথবা সাধারণ CSV, TSV ও JSON ফাইল টেবিলে ইমপোর্ট করুন

৮ MB পর্যন্ত ফ্ল্যাট ফাইল থেকে স্বয়ংক্রিয়ভাবে রিলেশনাল কলাম তৈরি ও ডেটা ভরতে .sql স্ক্রিপ্টে .import --csv data.csv my_table চালান।

STEP 03 .mode box / markdown

SQL কুয়েরি চালান ও ৯টি আউটপুট ফরম্যাটে দেখুন

AST SQL অটো-কমপ্লিশনসহ SELECT, JOIN, UPDATE বা ALTER স্টেটমেন্ট লিখুন এবং পরিচ্ছন্ন Unicode box বা Markdown গ্রিড প্রিভিউ করুন।

STEP 04 .once export.csv

পরিচ্ছন্ন ফলাফল সরাসরি ওয়ার্কস্পেসে এক্সপোর্ট করুন

আপনার প্রোজেক্ট ফোল্ডারে অ্যানালিটিক্যাল আউটপুট সেভ করতে csv, json, markdown বা insert মোডের সাথে .once ব্যবহার করুন।

SuperCode এক ট্যাপেই `.db`, `.sqlite`, `.sqlite3`, `.db3` এবং `.s3db` ফাইল শনাক্ত করে এবং স্বয়ংক্রিয়ভাবে অফলাইনে `.dbinfo`, `.tables` ও `.schema` ইনস্পেক্ট করে।
সাধারণ Android SQLite ভিউয়ারের তুলনায় এমবেডেড SQLite 3.54.1 কেন গুরুত্বপূর্ণ?+
বেশিরভাগ Android DB ভিউয়ার ফোনের পুরনো সিস্টেম SQLite বিল্ড ব্যবহার করে, যাতে `STRICT` টেবিল, `RETURNING`, `JSONB`, আধুনিক Window frame ক্লজ এবং আপডেটেড কুয়েরি প্ল্যানার থাকে না। SuperCode সব Android 8.0+ ডিভাইসে ধারাবাহিকভাবে SQLite 3.54.1 দেয়।
আগে `CREATE TABLE` না লিখেই কি `.csv` বা `.json` ফাইল ইমপোর্ট করা যায়?+
হ্যাঁ! ৮ MB পর্যন্ত ফাইলের জন্য `.import --csv filename.csv tablename` (অথবা `--tsv` / `--json`) চালান — `tablename` আগে থেকে না থাকলে SuperCode আপনার CSV হেডার বা JSON অবজেক্ট কী থেকে স্বয়ংক্রিয়ভাবে টেবিল স্কিমা তৈরি করে দেয়।
SQL কুয়েরির ফলাফল কীভাবে Markdown টেবিল বা CSV ফাইলে এক্সপোর্ট করবো?+
আপনার `SELECT` স্টেটমেন্টের ঠিক আগে `.mode markdown` (বা `.mode csv` / `.mode json` / `.mode insert`) এবং তারপরে `.once output.md` লিখে Run চাপুন — ফাইলটি সাথে সাথে আপনার প্রোজেক্ট এক্সপ্লোরারে দেখা যাবে।
