05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

Android-এ HTML5/CSS3/JS এডিটিং, ES Modules এবং রেসপন্সিভ ভিউপোর্ট প্রিভিউ সম্পর্কে সাধারণ প্রশ্নোত্তর।

অন্যান্য HTML এডিটর অ্যাপে আমার `<script type="module">` বা `fetch('./data.json')` কেন ব্যর্থ হয়?+
কঠোর CORS নিরাপত্তা নিয়মের কারণে ব্রাউজার `file://` URL-এ ES Modules এবং `fetch()` ব্লক করে। SuperCode স্বয়ংক্রিয়ভাবে আপনার প্রজেক্টকে সঠিক MIME হেডারসহ একটি আসল `localhost` HTTP/1.1 অরিজিন থেকে সার্ভ করে, যাতে আধুনিক JS মডিউল ও JSON ফেচ অফলাইনেই নেটিভভাবে কাজ করে।
স্মার্টফোন স্ক্রিনে কীভাবে ট্যাবলেট ও ডেস্কটপ CSS মিডিয়া কুয়েরি প্রিভিউ করব?+
SuperCode-এর লাইভ ওয়েব প্রিভিউয়ের ভেতরে ফ্লোটিং Dynamic Island-এর ভিউপোর্ট আইকনে ট্যাপ করে সাথে সাথেই মোবাইল, ট্যাবলেট (`768dp`) এবং প্রশস্ত ডেস্কটপ ভিউপোর্টের মধ্যে সুইচ করুন — যা আপনার `@media` নিয়মগুলোকে নির্ভুলভাবে ট্রিগার করে।
১-ট্যাপ ফরম্যাটার কি `<style>`-এর ভেতরের CSS এবং `<script>`-এর ভেতরের JS-ও ফরম্যাট করে?+
হ্যাঁ। SuperCode-এর রিকার্সিভ HTML ফরম্যাটার `.html` ফাইলের ভেতরে এমবেড করা `<style>` ও `<script>` ব্লকগুলো পার্স করে এবং এক ট্যাপেই তিনটি ভাষাকেই পরিচ্ছন্নভাবে ইন্ডেন্ট করে।
আমি কি অফলাইনে লোকাল `.mp4` ভিডিও, `.woff2` ফন্ট এবং `.glb` 3D মডেল ব্যবহার করতে পারব?+
হ্যাঁ। `font/woff2`, `model/gltf-binary`, `image/svg+xml`-সহ ৬৫টিরও বেশি MIME টাইপ লোকালি প্রি-কনফিগার করা আছে, সাথে মসৃণ `<video>` ও `<audio>` টাইমলাইন সিকিংয়ের জন্য HTTP `206 Partial Content` বাইট-রেঞ্জ স্ট্রিমিং রয়েছে।
