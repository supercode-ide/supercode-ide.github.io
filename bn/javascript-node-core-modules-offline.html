02 মূল সক্ষমতা

টার্মিনালের ঝামেলা ছাড়াই ব্যাকএন্ড JavaScript স্ক্রিপ্টিং ও ফাইল টুলিং

কয়েক মিলিসেকেন্ডে অফলাইনে JSON/CSV রূপান্তর অটোমেট করুন, বিল্ড আর্টিফ্যাক্ট কমপ্রেস করুন, মডিউলার লাইব্রেরি টেস্ট করুন এবং CLI ইউটিলিটি চালান।

02.1

অফলাইনে প্রস্তুত ২৯+ বিল্ট-ইন Node.js কোর মডিউল

কোনো সেটআপ ছাড়াই `node:` প্রিফিক্স বা সরাসরি কোর মডিউল ইম্পোর্ট করুন: fs, fs/promises, path, path/posix, buffer, events, stream, stream/promises, stream/web, zlib, crypto, util, assert, url, querystring, readline, string_decoder, timers, timers/promises, perf_hooks, os, process এবং diagnostics_channel।

node:fs · path · buffer · events · stream · zlib · util
02.2

আসল node:fs ও fs/promises ওয়ার্কস্পেস সিঙ্ক্রোনাইজেশন

আপনার আসল প্রজেক্ট ফাইলের ওপর readFileSync, writeFile, appendFile, mkdir({ recursive: true }), readdir, stat এবং copyFile চালান। তৈরি হওয়া JSON বান্ডেল, Markdown ডক, CSV ও `.gz` আর্কাইভ সরাসরি আপনার Android ফোল্ডারেই দেখা যাবে।

fs.readFileSync · fs/promises · স্থায়ী ফোল্ডার I/O
02.3

সহজ ES Modules (.mjs) ও CommonJS (.cjs) ইন্টারঅপ

`import` / `export` ও টপ-লেভেল `await` সহ আধুনিক ES Modules লিখুন, `require()` ও `module.exports` দিয়ে CommonJS ইউটিলিটি চালান এবং নেস্টেড ডিরেক্টরি থেকে নেটিভভাবে `.json` কনফিগ ফাইল ইম্পোর্ট করুন।

import / export · require() · .mjs / .cjs / .json
02.4

package.json Exports, সাবপাথ ও #imports সাপোর্ট

`package.json` দিয়ে পরিচ্ছন্ন মাল্টি-ফাইল প্যাকেজ সাজান: SuperCode `\"type\": \"module\"`, `\"main\"`, কন্ডিশনাল `\"exports\"` ম্যাপ এবং প্রাইভেট `#internal/*` সাবপাথ ইম্পোর্ট রিজলভ করে — এমনকি আনসেভ করা খোলা এডিটর ট্যাব থেকেও।

package.json · কন্ডিশনাল exports · #subpath ইম্পোর্ট
02.5

বাইনারি Buffer, EventEmitter, Stream ও Zlib

মোবাইলে `Buffer.alloc`/`concat` (UTF-8, hex, base64, base64url), `EventEmitter`, `Readable`/`Writable`/`Transform` `pipeline()` এবং `zlib.gzipSync`/`gunzipSync` দিয়ে বাইনারি প্রোটোকল ও বড় টেক্সট স্ট্রিম দক্ষতার সাথে প্রসেস করুন।

Buffer · EventEmitter · stream.pipeline · gzipSync
02.6

সকেট ও ওয়ার্কারের জন্য স্বয়ংক্রিয় Cloud Node.js ফলব্যাক

আপনার স্ক্রিপ্টে যখন OS-লেভেল TCP/HTTP লিসেনার বা মাল্টি-প্রসেস স্পনিং (`node:http`, `https`, `net`, `tls`, `dns`, `dgram`, `child_process`, `worker_threads`) দরকার হয়, তখন SuperCode স্বয়ংক্রিয়ভাবে লোকাল মডিউল ট্রি Cloud Node.js-এ বান্ডেল করে চালায়।

03 ধাপে ধাপে ওয়ার্কফ্লো

Android-এ মাল্টি-মডিউল Node.js স্ক্রিপ্ট যেভাবে তৈরি করবেন

কয়েক গিগাবাইট টার্মিনাল প্যাকেজ ইনস্টল না করেই আসল ফাইল-সিস্টেম, স্ট্রিম ও CLI টুলিং স্ক্রিপ্ট চালান।

STEP 01 package.json + src/

ওয়ার্কস্পেসে .js, .mjs বা .cjs ফাইল তৈরি করুন

একটি স্বতন্ত্র স্ক্রিপ্ট শুরু করুন অথবা `.js` ফাইলে ES Module সিনট্যাক্স চালু করতে `\"type\": \"module\"` সহ `package.json` যোগ করুন।

STEP 02 import fs from 'node:fs'

২৯+ অফলাইন Node কোর API-এর যেকোনোটি ইম্পোর্ট করুন

লোকাল `.json`/`.csv` ফাইল পড়ুন, `node:path` দিয়ে পাথ ম্যানিপুলেট করুন, স্ট্রিম ট্রান্সফর্ম করুন অথবা `node:zlib` দিয়ে আউটপুট কমপ্রেস করুন।

STEP 03 Toolbar -> Run ▶

অফলাইনে রান করুন ও node:readline দিয়ে ইন্টারঅ্যাক্ট করুন

লাইভ ইন্টারঅ্যাক্টিভ stdin, `process.env` এবং `assert` টেস্ট ফিডব্যাক সহ আইসোলেটেড ওয়ার্কার কনসোলে কয়েক মিলিসেকেন্ডেই চালান।

STEP 04 Explorer Sync + Git

তৈরি ফাইল যাচাই করুন ও Visual Git দিয়ে কমিট করুন

তৈরি হওয়া ফাইল সরাসরি SuperCode-এর এডিটরে খুলুন বা Visual Git দিয়ে আপনার মডিউলার JavaScript প্যাকেজ GitHub-এ কমিট করুন।

হ্যাঁ। আধুনিক `import fs from 'node:fs/promises'` ES Module সিনট্যাক্স এবং ক্লাসিক `const fs = require('fs')` CommonJS কল—উভয়ই ঠিক একই বিল্ট-ইন অফলাইন ইমপ্লিমেন্টেশনে রিজলভ হয়।
আমার স্ক্রিপ্ট `node:http`, `net` বা `worker_threads` ইম্পোর্ট করলে কী হবে?+
যেসব মডিউলে OS সার্ভার সকেট বা সাবপ্রসেস (`http`, `https`, `net`, `tls`, `dns`, `child_process`, `worker_threads`) প্রয়োজন হয়, সেগুলো স্বয়ংক্রিয়ভাবে শনাক্ত হয়ে SuperCode-এর মাল্টি-ফাইল Cloud Node.js বান্ডলারের মাধ্যমে চলে — পাশাপাশি SuperCode-এর Web IDE-তেও ফুল-স্ট্যাক লোকাল HTTP প্রিভিউ রয়েছে।
