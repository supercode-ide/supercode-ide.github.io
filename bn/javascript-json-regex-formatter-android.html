02 মূল সক্ষমতা

প্রাইভেসি-ফার্স্ট JSON, Regex ও JavaScript ইউটিলিটি ওয়ার্কবেঞ্চ

আপনার API কী, প্রোডাকশন JSON ডাম্প এবং রেজেক্স টেস্ট ১০০% লোকাল রাখুন আপনার Android ডিভাইসে—ডেস্কটপ মানের গতি ও এডিটরে শূন্য বিজ্ঞাপনসহ।

02.1

লেক্সার-সচেতন JSON, JSONC ও JS অটো-ফরম্যাটার

এক ট্যাপেই মিনিফাইড এক-লাইনের JSON বা JSONC কনফিগ (// ও /* */ কমেন্ট অক্ষুণ্ণ রেখে) এক্সপ্যান্ড করুন এবং Error Radar-এ ট্রেইলিং কমা বা ভাঙা ব্র্যাকেট শনাক্ত করুন।

JSON · JSONC · ES2024 ফরম্যাটার · 1-Undo
02.2

ES2024 RegExp টেস্টিং (/d Indices, /v Sets, Lookbehind)

নেমড ক্যাপচার গ্রুপ, matchAll() ইটারেটর, ইউনিকোড প্রোপার্টি এসকেপ \\p{...} এবং /d ম্যাচ ইনডেক্স লোকালি মিলিসেকেন্ডে টেস্ট করুন—ক্যাটাস্ট্রফিক-ব্যাকট্র্যাকিং ফ্রিজ ছাড়াই।

02.3

লাইভ টপ-লেভেল Await fetch() ও URLSearchParams

fetch() · AbortController · node:fs সেভ
02.4

STEP 03 matchAll() /d

Worker-এ ES2024 Regex ও ডেটা ট্রান্সফর্ম চালান

STEP 04 fs.writeFile()
