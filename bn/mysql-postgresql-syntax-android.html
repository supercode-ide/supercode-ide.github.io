05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

অফলাইনে MySQL ও PostgreSQL সিনট্যাক্স চালানো বনাম Cloud MySQL 8.0-এ স্টোরড প্রসিডিউর সংক্রান্ত প্রশ্নাবলি।

আমি কি ইন্টারনেট ছাড়াই MySQL-এর `CREATE TABLE ... AUTO_INCREMENT ENGINE=InnoDB` স্ক্রিপ্ট চালাতে পারবো?+
হ্যাঁ! SuperCode-এর অফলাইন SQL কমপ্যাটিবিলিটি লেয়ার স্বচ্ছভাবে প্রচলিত MySQL এবং PostgreSQL DDL ক্লজ (`AUTO_INCREMENT`, `SERIAL`, `BIGSERIAL`, `UNSIGNED`, `ENUM`, `ENGINE=InnoDB`, `CHARSET`) অনুবাদ করে, যাতে আপনার স্কিমা ও কুয়েরি অফলাইনেই রান হয়।
`SHOW TABLES`, `DESCRIBE table_name` এবং `TRUNCATE TABLE` কি অফলাইনে কাজ করে?+
হ্যাঁ। কোনো MySQL কোর্স অনুসরণ করার সময় আপনাকে `.schema` বা `PRAGMA table_info(...)` মুখস্থ করতে হবে না — `SHOW TABLES`, `DESCRIBE` / `DESC`, `SHOW CREATE TABLE` এবং `TRUNCATE TABLE` সরাসরি অফলাইনেই কাজ করে।
Android-এ MySQL স্টোরড প্রসিডিউর (`CREATE PROCEDURE` ও `DELIMITER //`) কীভাবে চলে?+
যেহেতু প্রসিডিউরাল `BEGIN ... END` রুটিন এবং `DELIMITER`-এর জন্য সার্ভার-গ্রেডের প্রসিডিউরাল ইঞ্জিন প্রয়োজন, তাই SuperCode সেই স্ক্রিপ্টগুলোকে নির্বিঘ্নে Cloud MySQL 8.0-এ পাঠায় এবং আপনার `CALL` রেজাল্ট সেট সরাসরি কনসোলে ফিরিয়ে আনে।
অফলাইনে অতিরিক্ত কোন কোন MySQL ও PostgreSQL ফাংশন পাওয়া যায়?+
অফলাইনে ৫০টিরও বেশি স্কেলার ফাংশন বিল্ট-ইন রয়েছে, যার মধ্যে আছে `DATE_FORMAT`, `DATEDIFF`, `NOW`, `CURDATE`, `CONCAT_WS`, `LPAD`, `RPAD`, `SUBSTRING_INDEX`, `ILIKE`, `REGEXP_REPLACE`, `UUID`, `MD5`, `SHA256`, `MEDIAN` এবং `STDDEV`।
