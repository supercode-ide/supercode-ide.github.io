SQL শিক্ষার্থী, ডেটা সায়েন্সের ছাত্রছাত্রী এবং ব্যাকএন্ড ইন্টারভিউ পরীক্ষার্থীদের সাধারণ প্রশ্নাবলি।

আমি কি অফলাইনে LeetCode-ধরনের SQL Window Function সমস্যা (`DENSE_RANK`, `LAG`, রোলিং সাম) অনুশীলন করতে পারবো?+
হ্যাঁ! প্রতিটি স্ট্যান্ডার্ড SQL উইন্ডো ফাংশন (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) এবং `ROWS`/`RANGE`/`GROUPS` ফ্রেম স্পেসিফিকেশন ১০০% অফলাইনে কাজ করে।
SuperCode কি সরাসরি SQL-এ `MEDIAN()`, `PERCENTILE()` এবং `STDDEV()` সাপোর্ট করে?+
হ্যাঁ। সাধারণ SQLite-এ পরিসংখ্যানগত অ্যাগ্রিগেট না থাকলেও, SuperCode-এ আগে থেকেই নেটিভ `MEDIAN(col)`, `PERCENTILE(col, 95)` এবং `STDDEV(col)` ফাংশন যুক্ত রয়েছে, যাতে ডেটা অ্যানালিস্টরা এক `SELECT`-এই ডিস্ট্রিবিউশন হিসাব করতে পারেন।
একটি `.sql` কুয়েরির ভেতরে `READ_STDIN()` কীভাবে কাজ করে?+
আপনার `.sql` ফাইলের ভেতরে `WHERE department = READ_STDIN('Department name: ')` লিখে Run ট্যাপ করুন — SuperCode ডক করা কনসোলে ইন্টারেক্টিভভাবে ইনপুট চাইবে, যাতে কোড এডিট না করেই প্যারামিটারাইজড কুয়েরি বারবার চালাতে পারেন।
FTS5 ফুল-টেক্সট সার্চ এবং R*Tree / Geopoly স্পেশাল মডিউল কি চালু আছে?+
হ্যাঁ। `USING fts5(...)` (`bm25()`, `highlight()` এবং `snippet()` সহ) এবং `USING rtree(...)` / Geopoly স্পেশাল এক্সটেনশন—উভয়ই সরাসরি SuperCode-এর অফলাইন SQLite 3.54.1 ইঞ্জিনে কম্পাইল করা আছে।
