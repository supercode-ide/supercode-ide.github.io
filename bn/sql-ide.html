03 ধাপে ধাপে ওয়ার্কফ্লো

SuperCode-এ ডেটাবেস কোয়েরি ও ডেটাসেট ইমপোর্ট করার পদ্ধতি

পরিচ্ছন্ন, স্ক্রিপ্ট-চালিত ডেটাবেস ওয়ার্কফ্লো যা সরাসরি আপনার Android ওয়ার্কস্পেসে সংরক্ষিত থাকে।

STEP 01 query.sql or app.db

একটি .db ডেটাবেস খুলুন বা .sql স্ক্রিপ্ট তৈরি করুন

যেকোনো লোকাল .db/.sqlite ফাইলে ট্যাপ করে এর স্কিমা দেখুন, অথবা অফলাইন AST SQL কীওয়ার্ড/ফাংশন কমপ্লিশন ও ফরম্যাটিংসহ একটি .sql স্ক্রিপ্ট তৈরি করুন।

STEP 02 .import --csv / --json

টেবিল সিড করুন বা CSV ও JSON ফাইল ইমপোর্ট করুন

একটি কমান্ডেই আপনার প্রজেক্ট ফোল্ডার থেকে CSV, TSV বা JSON ডেটাসেট টাইপড রিলেশনাল টেবিলে লোড করুন।

STEP 03 Run ▶ (.mode box)

অফলাইনে মাল্টি-স্টেটমেন্ট কোয়েরি চালান

স্প্লিট-স্ক্রিন কনসোলে Unicode Box Grids, Markdown টেবিল বা JSON আউটপুট দেখুন, এবং প্রয়োজনে লাইভ READ_STDIN() প্যারামিটার প্রম্পট ব্যবহার করুন।

STEP 04 .save / .once report.csv

পরিচ্ছন্ন রিপোর্ট এক্সপোর্ট ও PHP/Java-তে .db সিঙ্ক করুন

আপডেট করা .db ফাইল বা .csv/.json রিপোর্ট সরাসরি আপনার প্রজেক্ট ফোল্ডারে সেভ করুন — SuperCode-এর PHP PDO বা Java JDBC ওয়ার্কস্পেস থেকে কোয়েরি করার জন্য প্রস্তুত!

৬টি বিল্ট-ইন SQL উদাহরণ · PHP PDO ও Java 17 JDBC-এর সাথে সরাসরি ইন্টারঅপ অ্যাপ গাইড

05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

অফলাইন SQL প্র্যাকটিস, .db/.sqlite ফাইল খোলা, CSV/JSON ইমপোর্ট ও MySQL সিনট্যাক্স নিয়ে প্রশ্নোত্তর।

আমি কি কোনো ডেটাবেস সার্ভার সেটআপ না করেই অফলাইনে SQL কোয়েরি প্র্যাকটিস করতে পারব?+
হ্যাঁ! যেকোনো .sql ফাইল তৈরি করে Run ট্যাপ করুন এবং ফরম্যাটেড Unicode Box Grid টেবিলসহ ১০০% অফলাইনে মাল্টি-স্টেটমেন্ট CREATE, INSERT, JOIN, CTE ও Window Function কোয়েরি চালান।
SuperCode কি আমার ফোনে থাকা .db এবং .sqlite ফাইল খুলতে পারে?+
হ্যাঁ। কোনো .db, .sqlite, .sqlite3 বা .db3 ফাইল ট্যাপ বা রান করলে সব টেবিল, ভিউ, ইনডেক্স ও স্কিমা দেখা যায় এবং একই প্রজেক্ট ফোল্ডারের যেকোনো .sql স্ক্রিপ্ট সরাসরি সেই ডেটাবেসে কোয়েরি চালাতে পারে।
এতে কি AUTO_INCREMENT, SHOW TABLES, DESCRIBE বা Stored Procedures-এর মতো MySQL সিনট্যাক্স কাজ করে?+
দৈনন্দিন MySQL/PostgreSQL DDL এবং কমান্ড (AUTO_INCREMENT, ENUM, SHOW TABLES, DESCRIBE, ILIKE) লোকালি অফলাইনে চলে, আর সার্ভার-নির্দিষ্ট MySQL 8.0 Stored Procedures ও Triggers স্বয়ংক্রিয়ভাবে Cloud MySQL 8.0-এ রাউট হয়।
SQL কোয়েরির ফলাফল CSV, Markdown বা JSON-এ কীভাবে এক্সপোর্ট করব?+
আপনার SELECT কোয়েরির আগে `.mode csv` (অথবা `.mode markdown` / `.mode json`) ও `.once output.csv` যোগ করুন — SuperCode সরাসরি আপনার প্রজেক্ট ফোল্ডারে এক্সপোর্ট করা ফাইলটি লিখে দেবে।
