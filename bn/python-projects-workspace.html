02 মূল সক্ষমতা

টাচ স্ক্রিনের জন্য নতুনভাবে গড়া ডেস্কটপ-মানের Python প্রজেক্ট অভিজ্ঞতা

মোবাইলে ফাইল ম্যানেজমেন্টের ঝামেলা দূর করতেই SuperCode-এর Python ওয়ার্কস্পেস রিজলভারের প্রতিটি অংশ তৈরি করা হয়েছে।

02.1

যেকোনো খোলা ট্যাব থেকে স্মার্ট এন্ট্রি-পয়েন্ট আর্বিট্রেশন

টপ-লেভেল রানার ছাড়া `services/ledger.py` বা `models/user.py` এডিট করছেন? Run ট্যাপ করলেই স্বয়ংক্রিয়ভাবে প্রজেক্ট রুট (`pyproject.toml`, `requirements.txt`, `.git`) খুঁজে `main.py`, `app.py`, `run.py` বা `src/main.py` রান করে।

হেল্পার মডিউল এডিট -> Run চাপুন -> main.py রান হয়
02.2

লাইভ আনসেভড ট্যাব মেমোরি ওভারলে ও PEP 420 নেমস্পেস

তিনটি খোলা `.py` ট্যাব এডিট করেই সাথে সাথে Run চাপুন — `src/` ফোল্ডারে অপ্রয়োজনীয় খালি `__init__.py` ফাইল না ভরেই SuperCode আপনার সেভ না করা এডিটর বাফারগুলো মেমোরিতে ওভারলে করে চালায়।

জিরো-ওয়েট রান · PEP 420 ইমপ্লিসিট নেমস্পেস প্যাকেজ
02.3

প্রকৃত ইন্টারঅ্যাক্টিভ input() ও [EOF] ডুয়াল-পেন কনসোল

ধারাবাহিক `input()` ও `sys.stdin.readline()` কলসহ CLI অ্যাপ টেস্ট করুন। ফোনে কনসোল কোডের নিচে ডক হয় বা ট্যাবলেটে ৫৫%/৪৫% পাশাপাশি স্প্লিট হয়, সাথে থাকে তাৎক্ষণিক Stop/Interrupt কন্ট্রোল।

নন-ব্লকিং Stdin কিউ · [EOF] সিগন্যাল · ৫৫:৪৫ স্প্লিট
02.4

অফলাইন AST কমপ্লিশন, PEP 8 ফরম্যাটার ও Error Radar

ক্লাস ও মডিউলে `.` টাইপ করলেই সাব-মিলিসেকেন্ড অফলাইন AST সাজেশন পান, এক ট্যাপে অগোছালো ইন্ডেন্টেশন PEP 8-এ ফরম্যাট করুন এবং রানের আগেই Error Radar-এ মিক্সড ট্যাব/স্পেস (`TabError`) বা বাদ পড়া কোলন ধরুন।

AST স্কোপ ইঞ্জিন · ১-ট্যাপ PEP 8 · TabError Radar
02.5

স্বয়ংসম্পূর্ণ ভিজ্যুয়াল Git ও ১২০-কমিট টাইম মেশিন

HTTPS PAT দিয়ে প্রাইভেট GitHub/GitLab Python রিপো ক্লোন করুন, ফিচার ব্রাঞ্চ তৈরি করুন, সিনট্যাক্স-কালারড ডিফ দেখুন, ভিজ্যুয়ালি মার্জ কনফ্লিক্ট সমাধান করুন এবং এডিটর না ছেড়েই কমিট পুশ করুন।

ক্লোন · ব্রাঞ্চ · ভিজ্যুয়াল মার্জ · কমিট ও পুশ
02.6

৫০,০০০-নোড ফাজি ফাইল ফাইন্ডার ও গ্লোবাল Regex সার্চ

ফাজি ফাইল ফাইন্ডার দিয়ে বিশাল মনোরিপো থেকে মিলিসেকেন্ডেই যেকোনো `.py` মডিউলে যান, অথবা স্ট্রিমিং regex সার্চ ও রিপ্লেস দিয়ে পুরো প্রজেক্টে ফাংশনের নাম রিফ্যাক্টর করুন।

ফাজি ফাইল জাম্প · প্রজেক্ট-ব্যাপী Regex রিফ্যাক্টরিং
ফোন, ফোল্ডেবল ও ট্যাবলেটের জন্য নির্মিত · হালকা 40.2 MB Python কোডিং অ্যাপ হাব
03 ধাপে ধাপে ওয়ার্কফ্লো

Android-এ Python রিপো ক্লোন, রিফ্যাক্টর, টেস্ট ও পুশ করার ধাপ

আপনার ফোন বা Android ট্যাবলেটেই একটি পূর্ণাঙ্গ সফটওয়্যার ইঞ্জিনিয়ারিং লাইফসাইকেল।

STEP 01 Git Clone / Open Folder

GitHub রিপো ক্লোন করুন বা লোকাল প্রজেক্ট ট্রি খুলুন

HTTPS পার্সোনাল অ্যাক্সেস টোকেন দিয়ে ক্লোন করুন বা ডিভাইস স্টোরেজের যেকোনো ফোল্ডার খুলুন — স্ক্যানের সময় `.git`, `venv` ও `__pycache__` জঞ্জাল স্বয়ংক্রিয়ভাবে বাদ যায়।

STEP 02 Multi-Tab Edit + PEP 8

AST কমপ্লিশন ও ২১-কী সিম্বল বার দিয়ে মডিউল এডিট করুন

`:`, `->`, `_`, `()`, `[]` ও `INDENT`-এর জন্য ২১-কী সিম্বল বার ব্যবহার করুন এবং পরিচ্ছন্ন ৪-স্পেস PEP 8 অ্যালাইনমেন্টের জন্য Format ট্যাপ করুন।

STEP 03 Run ▶ / unittest

অফলাইনে এন্ট্রি স্ক্রিপ্ট বা ইউনিট টেস্ট স্যুইট রান করুন

তাৎক্ষণিক মিলিসেকেন্ড টাইমিং ও ক্লিকেবল স্ট্যাক-ট্রেস নেভিগেশনসহ অফলাইনে `main.py` বা `unittest` স্যুইট চালান।

STEP 04 Git Time Machine -> Push

ইউনিফাইড ডিফ রিভিউ করে কমিট ও আপস্ট্রিমে পুশ করুন

Git টাইম মেশিনে লাইন-বাই-লাইন পরিবর্তন দেখে ফাইল স্টেজ করুন এবং নির্বিঘ্নে GitHub, GitLab বা Bitbucket-এ পুশ করুন।

প্রতি রানে সর্বোচ্চ ২৫০টি ওয়ার্কস্পেস ফাইল সমর্থিত · স্বয়ংক্রিয় ২.৫ সেকেন্ড বাইটকোড ক্যাশ রিফ্রেশ অ্যাপ গাইড
04 সক্ষমতার ম্যাট্রিক্স

SuperCode মাল্টি-ফাইল Python ওয়ার্কস্পেস বনাম মোবাইল স্ক্র্যাচপ্যাড

SuperCode IDE Android-এ ডেস্কটপ-মানের মাল্টি-ফাইল Python প্রজেক্ট সাপোর্ট দেয়; যেখানে স্বয়ংক্রিয় `pyproject.toml`/`src/` রুট রিজলিউশন, স্মার্ট `main.py` এন্ট্রি আর্বিট্রেশন, আনসেভড ট্যাব মেমোরি ওভারলে, PEP 8 ফরম্যাটিং, AST অটোকমপ্লিট ও বিল্ট-ইন ভিজ্যুয়াল Git রয়েছে।

ANDROID-এ মাল্টি-ফাইল PYTHON প্রজেক্ট IDE তুলনা
ইঞ্জিনিয়ারিং ফিচার SuperCode Python স্টুডিও সিঙ্গেল-ফাইল Python অ্যাপ ব্রাউজার ক্লাউড IDE CLI টার্মিনাল এডিটর
প্রজেক্ট রুট ও src/ pyproject.toml, src/ ও PEP 420 অটো-রিজলভ করে শুধু ফ্ল্যাট সিঙ্গেল স্ক্রিপ্ট সমর্থিত (শুধু অনলাইনে) ম্যানুয়াল PYTHONPATH
সাবমডিউল থেকে রান স্মার্ট এন্ট্রি আর্বিট্রেশন -> main.py/app.py রান করে ভুল হেল্পার ফাইল রান করে ম্যানুয়াল launch.json ম্যানুয়াল CLI কমান্ড

`utils/helpers.py`-এর মতো হেল্পার মডিউল এডিট করার সময় Run চাপলে কী হয়?+
`helpers.py`-এ যদি টপ-লেভেল এক্সিকিউশন কোড ছাড়া শুধু ফাংশন বা ক্লাস থাকে, তবে SuperCode স্বয়ংক্রিয়ভাবে প্রজেক্টের এন্ট্রি স্ক্রিপ্ট (`main.py`, `app.py`, `run.py`, `__main__.py` বা `src/main.py`) খুঁজে নিয়ে পুরো অ্যাপ্লিকেশন রান করে।
SuperCode কি Python 3.12-এর `match/case` ও `type` অ্যালাইয়াস সিনট্যাক্স সাপোর্ট করে?+
স্ট্রাকচারাল `match/case` ও `tomllib` Python 3.11+-এ অফলাইনে কাজ করে, এবং PEP 695 জেনেরিক `type` অ্যালাইয়াস সিনট্যাক্স ব্যবহার করা ফাইলে স্বয়ংক্রিয়ভাবে Python 3.12 সাপোর্ট সক্রিয় হয়।
মাল্টি-ফোল্ডার ইমপোর্টের জন্য কি প্রতিটি ফোল্ডারে `__init__.py` থাকা জরুরি?+
না। SuperCode PEP 420 ইমপ্লিসিট নেমস্পেস প্যাকেজ মেনে চলে এবং রিপোজিটরিতে অযাচিত `__init__.py` ফাইল যোগ না করেই পরিচ্ছন্নভাবে প্রজেক্ট রুট মাউন্ট করে।
আমি কি প্রাইভেট GitHub রিপোজিটরি ক্লোন করে সেগুলোর Python টেস্ট অফলাইনে চালাতে পারব?+
হ্যাঁ। ভিজ্যুয়াল Git-এ HTTPS + পার্সোনাল অ্যাক্সেস টোকেন দিয়ে ক্লোন করুন, একবার `requirements.txt` ব্যাচ-ইনস্টল করে নিন, আর তারপর যেকোনো জায়গায় সম্পূর্ণ অফলাইনে `unittest` স্যুইট এডিট ও রান করুন।
