02 মূল সক্ষমতা

02.1

নেটিভ 64-Bit পূর্ণসংখ্যা, // ডিভিশন ও Bitwise অপারেটর

ফ্লোট অ্যাপ্রক্সিমেশনের বদলে নির্ভুল 64-bit signed integer দিয়ে &, |, ~ (XOR/NOT), <<, >> এবং // integer floor division ব্যবহার করে সরাসরি bitmask, flag, hash ও tile coordinates ম্যানিপুলেট করুন।

02.2

05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

Android-এ Lua 5.4 bitwise অপারেটর, `<close>` ভ্যারিয়েবল এবং মাল্টি-ফোল্ডার `require()` সম্পর্কে প্রশ্নোত্তর।

অন্যান্য Android Lua অ্যাপে `//` আর `&` দিলে সিনট্যাক্স এরর দেখায় কেন?+
পুরোনো অনেক মোবাইল Lua অ্যাপ LuaJ ব্যবহার করে, যা Lua 5.2-এর সময়ের একটি Java পোর্ট—তখনও Lua 5.3/5.4-এর নেটিভ 64-bit পূর্ণসংখ্যা, `//` floor division ও bitwise অপারেটর আসেনি। SuperCode আসল নেটিভ Lua 5.4.7 চালায়।
`LUA_PATH` সেট না করেই মাল্টি-ফাইল `require()` কীভাবে কাজ করে?+
SuperCode আপনার প্রজেক্ট রুটসহ `src/`, `lib/`, `modules/`, `core/` ও `utils/` ফোল্ডারে `?.lua` এবং `?/init.lua` খোঁজার জন্য অটোমেটিক `package.path` কনফিগার করে — এমনকি রানের আগে আনসেভড ওপেন ট্যাবও সিঙ্ক করে।
`main.lua`-এর বদলে `lib/math_ext.lua` এডিট করার সময় Run চাপলে কী হবে?+
অ্যাক্টিভ ফাইলটি যদি একটি মডিউল টেবিল (`return M`) রিটার্ন করে এবং প্রজেক্ট রুটে `main.lua` বা `init.lua` থাকে, তবে SuperCode অটোমেটিক এন্ট্রি স্ক্রিপ্টটি রান করে যাতে বারবার ট্যাব বদলাতে না হয়।
কোনো ব্লকের ভেতর এরর হলেও কি Lua 5.4 `<close>` কাজ করে?+
হ্যাঁ। স্ট্যান্ডার্ড ডেস্কটপ Lua 5.4.7-এর মতোই, ব্লক স্বাভাবিকভাবে শেষ হোক বা `error()` দিয়ে আনওয়াইন্ড হোক, `<close>` চিহ্নিত প্রতিটি লোকাল ভ্যারিয়েবল নির্ভুলভাবে তার মেটাটেবিলের `__close(self, err)` মেটামেথড কল করে।
