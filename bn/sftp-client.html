02 মূল সক্ষমতা

এন্টারপ্রাইজ-মানের রিমোট নিরাপত্তা ও দুর্নীতিমুক্ত ফাইল ইঞ্জিনিয়ারিং

বিশেষভাবে অস্থিতিশীল মোবাইল নেটওয়ার্কের জন্য ডিজাইন করা — যেখানে 5G বা Wi-Fi ড্রপ করলে সাধারণ FTP এডিটর প্রোডাকশন কনফিগকে ০ বাইটে নামিয়ে নষ্ট করে দেয়।

02.1

৪টি প্রোটোকলই সাপোর্টেড: SFTP, FTPS Explicit, FTPS Implicit ও FTP

SSH SFTP (পোর্ট ২২), এনক্রিপ্টেড প্যাসিভ ডেটা চ্যানেল (PBSZ 0 + PROT P) সহ TLS 1.2/1.3-এর ওপর Explicit FTPS, Implicit FTPS (পোর্ট ৯৯০) এবং UTF-8 প্যাসিভ FTP (পোর্ট ২১) সাপোর্ট করে।

SFTP (22) · FTPS TLS 1.3 (21) · FTPS (990) · FTP
02.2

SSH প্রাইভেট কী পিকার, AES-256 ভল্ট ও TOFU গার্ড

OpenSSH, PEM, RSA, Ed25519 বা ECDSA কী (.pem, .key, id_rsa, id_ed25519) ও পাসফ্রেজ ইম্পোর্ট করুন। সমস্ত গোপন তথ্য Android KeyStore AES-256-GCM দিয়ে এনক্রিপ্ট থাকে এবং SHA256 হোস্ট-কী অমিল সতর্কতায় সুরক্ষিত।

Ed25519 / RSA / PEM · AES-256-GCM · MITM হোস্ট গার্ড
02.3

৩-ধাপের অ্যাটমিক রিমোট সেভ (০-বাইট ফাইল নষ্ট হওয়ার শূন্য ঝুঁকি)

রিমোট ফাইল খুললে একটি স্থায়ী লোকাল মিরর ট্যাব (☁️) তৈরি হয়। Save চাপলে টেম্প ফাইলে আপলোড হয়, STAT/SIZE দিয়ে রিমোট বাইট সাইজ যাচাই হয় এবং POSIX পারমিশন অটুট রেখে মূল ফাইলে অ্যাটমিক রিনেম হয়!

টেম্প আপলোড -> সাইজ যাচাই -> অ্যাটমিক রিনেম + chmod
02.4

লাইভ টেস্ট হ্যান্ডশেক কনসোল ও সেল্ফ-হিলিং পুল

সার্ভার সেভ করার আগেই বিল্ট-ইন ডায়াগনস্টিক কনসোলে TCP, TLS/SSH নেগোসিয়েশন এবং কী অথেনটিকেশন যাচাই করুন। Wi-Fi/5G বদলালে ৩-চ্যানেলের কানেকশন পুল অচল সকেট স্বয়ংক্রিয়ভাবে পুনরুদ্ধার করে।

⚡ টেস্ট হ্যান্ডশেক · ৩-চ্যানেল সেল্ফ-হিলিং পুল

৪-স্ট্রিম ট্রান্সফার কিউ ও বাইট-অফসেট রিজিউম

20fps MB/s প্রগ্রেস প্যানেল সহ ৪টি প্যারালাল স্ট্রিমে পুরো ডিরেক্টরি ট্রি আপলোড বা ডাউনলোড করুন। বড় ট্রান্সফার বিচ্ছিন্ন হলে SFTP RESUME বা FTP REST দিয়ে ঠিক আগের বাইট অফসেট থেকে রিজিউম হয়!

03 ধাপে ধাপে ওয়ার্কফ্লো

Android থেকে লাইভ সার্ভারে কানেক্ট ও নিরাপদে এডিট করার পদ্ধতি

হার্ডওয়্যার-এনক্রিপ্টেড ভল্টে একবার কনফিগার করুন আর যেকোনো জায়গা থেকে কয়েক সেকেন্ডেই হটফিক্স ডিপ্লয় করুন।

STEP 01 Explorer -> Remote Servers -> +

প্রোটোকল বেছে নিন ও পাসওয়ার্ড বা SSH কী ইম্পোর্ট করুন

SFTP, FTPS (TLS), FTPS (990) বা FTP নির্বাচন করুন, host/user দিন এবং পাসওয়ার্ড লিখুন অথবা আপনার .pem / id_ed25519 প্রাইভেট কী ফাইল বেছে নিন।

STEP 02 ⚡ Test Handshake -> Save

হ্যান্ডশেক ডায়াগনস্টিকস যাচাই করুন ও হোস্ট ফিঙ্গারপ্রিন্ট ট্রাস্ট করুন

রিয়েল টাইমে TCP/TLS/SSH অথেনটিকেশন নিশ্চিত করতে Test Handshake ট্যাপ করুন, সার্ভারের SHA256 হোস্ট ফিঙ্গারপ্রিন্ট যাচাই করুন এবং AES-256 ভল্টে সেভ করুন।

STEP 03 Mount -> Tap Remote File

রিমোট ট্রি ব্রাউজ করুন ও পূর্ণ AST + ফরম্যাট সহ এডিট করুন

AST অটো-কমপ্লিশন, Error Radar এবং এক-ট্যাপ ফরম্যাটিং সহ সরাসরি এডিটর ট্যাবে Nginx কনফিগ, Python/PHP ব্যাকএন্ড ফাইল বা শেল স্ক্রিপ্ট খুলুন।

STEP 04 Save / Batch Upload

অ্যাটমিকভাবে সেভ করুন বা কনফ্লিক্ট নিয়ন্ত্রণ সহ ফোল্ডার সিঙ্ক করুন

৩-ধাপের অ্যাটমিক ডিপ্লয়মেন্টের জন্য Save ট্যাপ করুন, অথবা Overwrite, Byte-Offset Resume, Keep Both বা Skip নীতিমালা সহ আপলোড/ডাউনলোডের জন্য একাধিক ফোল্ডার সিলেক্ট করুন।

রিমোট Linux POSIX ফাইল পারমিশন অক্ষুণ্ণ রাখে · অফলাইনে অ্যাপ রিস্টার্টেও টিকে থাকে অ্যাপ গাইড
04 সক্ষমতার ম্যাট্রিক্স

ANDROID SFTP / FTPS রিমোট কোড এডিটিং তুলনা
রিমোট সক্ষমতা SuperCode SFTP/FTPS স্টুডিও সাধারণ FTP ফাইল অ্যাপ সাধারণ এডিটর প্লাগইন
সাপোর্টেড প্রোটোকল SFTP (22) + FTPS Explicit TLS 1.3 + FTPS 990 + FTP শুধু ফাইল ট্রান্সফার (IDE নেই) শুধু বেসিক FTP/SFTP

সচরাচর জিজ্ঞাসিত প্রশ্ন

SSH প্রাইভেট কী (.pem / Ed25519), FTPS TLS 1.3, রিমোট সেভ নষ্ট হওয়া রোধ এবং বড় ডাউনলোড রিজিউম করার উত্তর।

AWS EC2, DigitalOcean বা Linux VPS সার্ভারের জন্য কোন কোন SSH প্রাইভেট কী ফরম্যাট কাজ করে?+
SuperCode পাসফ্রেজ সহ বা ছাড়াই OpenSSH, PEM (.pem), RSA (id_rsa), Ed25519 (id_ed25519) এবং ECDSA প্রাইভেট কী সাপোর্ট করে — পাশাপাশি Downloads ও .ssh ফোল্ডারে দ্রুত যাওয়ার পিকার রয়েছে।
সেভ করার সময় মোবাইল নেটওয়ার্ক চলে গেলে SuperCode কীভাবে সার্ভারে ০-বাইটের নষ্ট ফাইল হওয়া রোধ করে?+
প্রতিটি রিমোট ট্যাব সেভে ৩-ধাপের অ্যাটমিক ট্রানজ্যাকশন ব্যবহার হয়: প্রথমে এটি একটি টেম্প ফাইলে আপলোড করে, STAT/SIZE দিয়ে সার্ভারে সঠিক বাইট সংখ্যা পৌঁছেছে কি না যাচাই করে, আর তবেই Linux পারমিশন অক্ষুণ্ণ রেখে মূল ফাইলে অ্যাটমিক রিনেম করে।
SSH SFTP-এর পাশাপাশি SuperCode কি FTPS (FTP over SSL/TLS) সাপোর্ট করে?+
হ্যাঁ! Explicit FTPS (পোর্ট ২১-এ এনক্রিপ্টেড PROT P প্যাসিভ ডেটা চ্যানেল সহ AUTH TLS 1.2/1.3) ও Implicit FTPS (পোর্ট ৯৯০) এবং স্ট্যান্ডার্ড UTF-8 প্যাসিভ FTP—সবই নেটিভভাবে সাপোর্ট করে।
সংযোগ বিচ্ছিন্ন হলে কি বড় ব্যাকআপ ডাউনলোড বা আপলোড রিজিউম করা যাবে?+
হ্যাঁ। বিদ্যমান আংশিক ফাইলের বিপরীতে ট্রান্সফার করার সময় SuperCode আংশিক সাইজ শনাক্ত করে এবং সম্পন্ন হওয়া বাইট পুনরায় না পাঠিয়েই সঠিক বাইট অফসেট থেকে ১-ট্যাপে Resume Partial Transfer অপশন দেয়।
