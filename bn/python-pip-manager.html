02 মূল সক্ষমতা

আপনার ফোনে Python লাইব্রেরি যুক্ত করার ৪টি সহজ উপায়

হাই-স্পিড Wi-Fi থাকুক বা ক্লাসরুমে একদমই ইন্টারনেট না থাকুক—SuperCode আপনার Python ডিপেন্ডেন্সিগুলো গুছিয়ে ও স্থায়ীভাবে সংরক্ষণ করে রাখে।

02.1

Auto-PIP মিসিং ইমপোর্ট ডিটেক্টর ও ৩৫+ অ্যালায়াস ম্যাপ

import bs4, import yaml, import dotenv, import jwt বা import telebot লিখে Run চাপুন। SuperCode স্বয়ংক্রিয়ভাবে ইমপোর্ট নামটিকে তার মূল PyPI প্যাকেজের (beautifulsoup4, pyyaml, python-dotenv, PyJWT, pyTelegramBotAPI) সাথে ম্যাপ করে ইনস্টল করে নেয় এবং স্ক্রিপ্ট পুনরায় চালায়।

bs4 -> beautifulsoup4 · yaml -> pyyaml · ৩৫+ অ্যালায়াস
02.2

জিরো-কনফিগ requirements.txt ওয়ার্কস্পেস ডিটেকশন

Git রিপোজিটরি ক্লোন করুন বা requirements.txt আছে এমন প্রজেক্ট ফোল্ডার খুলুন। Visual PIP Manager ওপরের ৬টি প্যারেন্ট ডিরেক্টরি পর্যন্ত স্ক্যান করে, লাইন কন্টিনিউয়েশন (\) ও প্ল্যাটফর্ম মার্কার পার্স করে এবং ১-ট্যাপ ব্যাচ ইনস্টল ব্যানার দেখায়।

আপওয়ার্ড রুট স্ক্যান · প্ল্যাটফর্ম মার্কার · ব্যাচ কিউ
02.3

১০০% অফলাইন .whl, .tar.gz ও .zip লোকাল ইমপোর্টার

যাতায়াতের পথে, ফ্লাইটে বা সীমাবদ্ধ ক্যাম্পাস Wi-Fi-তে পড়াশোনা করছেন? আগে থেকেই Android Downloads-এ pure-Python .whl, .tar.gz বা .zip ডিস্ট্রিবিউশন ডাউনলোড করে রাখুন এবং পূর্ণ PEP 440 ভার্সন যাচাইকরণসহ সম্পূর্ণ অফলাইনে ইনস্টল করুন।

এয়ারপ্লেন-মোড ইনস্টল · .whl / .tar.gz / .zip
02.4

PEP 440 ভার্সন কনস্ট্রেইন্ট ও কমান্ড পার্সার

ইনপুট বক্সে সরাসরি পুরো pip install কমান্ড (যেমন pip install requests>=2.31.0 flask~=3.0) পেস্ট করুন। SuperCode CLI-এর বাড়তি অংশ বাদ দিয়ে Python 3.11-এর বিপরীতে ==, >=, <=, != এবং ~= শর্ত যাচাই করে উপযুক্ত রিলিজ বেছে নেয়।

PEP 440 সমর্থিত · সম্পূর্ণ pip কমান্ড পেস্ট করুন

03 ধাপে ধাপে ওয়ার্কফ্লো

ধাপে ধাপে: SuperCode-এ PIP ও অফলাইন হুইল ব্যবহারের নিয়ম

৩০ সেকেন্ডেরও কম সময়ে অনলাইনে PyPI প্যাকেজ ইনস্টল করুন অথবা অফলাইনে .whl ফাইল সাইডলোড করুন।

STEP 01 Python Console -> PIP Icon

Visual PIP Package Manager খুলুন

যেকোনো .py ফাইল খুলে Python কনসোল হেডারের PIP আইকনে ট্যাপ করুন — অথবা আনইনস্টল করা ইমপোর্টসহ একটি স্ক্রিপ্ট রান করেই Auto-PIP চালু করুন।

STEP 02 Quick Chips / Input Box

জনপ্রিয় চিপে ট্যাপ করুন, pip install পেস্ট করুন বা requirements.txt বেছে নিন

ওয়ান-ক্লিক চিপে (requests, rich, beautifulsoup4, pyyaml, flask, telebot, colorama) ট্যাপ করুন, ভার্সনসহ স্পেক লিখুন অথবা স্বয়ংক্রিয়ভাবে শনাক্ত হওয়া requirements.txt ব্যানারে ট্যাপ করুন।

STEP 03 Import Local Archive (.whl)

অথবা অফলাইন .whl / .zip প্যাকেজের জন্য Downloads ব্রাউজ করুন

অফলাইন পরিবেশের জন্য PIP ডায়ালগে Local Archive-এ ট্যাপ করে আপনার Downloads বা প্রজেক্ট ফোল্ডার থেকে .whl, .tar.gz এবং .zip প্যাকেজ স্ক্যান করুন।

STEP 04 Manage Tab -> Verify

মাল্টি-ফাইল স্ক্রিপ্টে তাৎক্ষণিকভাবে ইমপোর্ট করুন

অ্যাপ রিস্টার্ট করলেও ইনস্টল করা লাইব্রেরিগুলো আপনার আইসোলেটেড site-packages ডিরেক্টরিতে স্থায়ীভাবে থেকে যায় এবং AST অটোকমপ্লিটের সাথে সাথেই কাজ করে।

ডিভাইসে স্থায়ী site-packages · ৫০ms নন-ব্লকিং ইনস্টল লগ স্ট্রিম অ্যাপ গাইড
04 সক্ষমতার ম্যাট্রিক্স

SuperCode Visual PIP বনাম প্রচলিত মোবাইল প্যাকেজ ইনস্টলার

SuperCode-এর Visual PIP Package Manager Android ডেভেলপারদের টার্মিনালের ঝামেলা ছাড়াই থার্ড-পার্টি Python লাইব্রেরি ইনস্টল করার সুবিধা দেয়। এতে একসাথে রয়েছে PyPI প্যাকেজ রেজোলিউশন, ৩৫+ স্বয়ংক্রিয় ইমপোর্ট অ্যালায়াস ম্যাপিং, ওয়ার্কস্পেস requirements.txt ব্যাচ ইনস্টলেশন এবং অফলাইন .whl/.tar.gz/.zip আর্কাইভ ইমপোর্টিং।

ANDROID PYTHON প্যাকেজ ম্যানেজমেন্ট তুলনা
PIP সক্ষমতা SuperCode Python Studio সাধারণ মোবাইল Python অ্যাপ টার্মিনাল CLI pip অনলাইন নোটবুক
ইমপোর্ট অ্যালায়াস ম্যাপিং ৩৫+ অটো ম্যাপ (bs4, yaml, pil, dotenv, jwt) ম্যানুয়ালি খুঁজতে হয় ম্যানুয়ালি খুঁজতে হয় ম্যানুয়াল `!pip install`
অফলাইন .whl / .zip বিল্ট-ইন লোকাল স্টোরেজ স্ক্যানার (০ ইন্টারনেট) খুব কম ক্ষেত্রেই সমর্থিত ম্যানুয়াল ফাইল পাথ ফ্ল্যাগ সক্রিয় ইন্টারনেট প্রয়োজন
requirements.txt ওপরের ৬টি প্যারেন্ট ফোল্ডার পর্যন্ত অটো-ডিটেক্ট + ১-ট্যাপ রান সমর্থিত নয় ম্যানুয়াল `cd` + `pip -r` প্রতি সেশনে রিসেট হয়
সায়েন্টিফিক C-এক্সটেনশন প্রি-বিল্ট ক্যাশড হুইলে অটো-রাউটেড পেইড প্লাগইন ছাড়া ব্যর্থ হয় C/Fortran কম্পাইল করতে গিয়ে ব্যর্থ হয় শুধুমাত্র ক্লাউড-ভিত্তিক
ডিস্ক ও ভার্সন অডিট সাইজ ও তাৎক্ষণিক ফিল্টারসহ ভিজ্যুয়াল Manage ট্যাব হিডেন ডিরেক্টরি শুধুমাত্র `pip list` টেক্সট অস্থায়ী কন্টেইনার

05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

Android-এ PyPI প্যাকেজ, অফলাইন .whl হুইল এবং requirements.txt ইনস্টল সংক্রান্ত সাধারণ প্রশ্নোত্তর।

আমি কি SuperCode-এ পুরো `pip install requests beautifulsoup4` কমান্ড পেস্ট করতে পারব?+
হ্যাঁ। PIP ইনপুট পার্সার স্বয়ংক্রিয়ভাবে শুরুর `pip install`, `pip3 install` বা `python -m pip install` প্রিফিক্স বাদ দেয়, অপ্রয়োজনীয় CLI ফ্ল্যাগ নিরাপদভাবে এড়িয়ে যায় এবং তালিকাভুক্ত সব প্যাকেজকে তাদের PEP 440 ভার্সন কনস্ট্রেইন্টসহ কিউতে যুক্ত করে।
ইন্টারনেট না থাকলে Android-এ Python প্যাকেজ কীভাবে ইনস্টল করব?+
আগে থেকেই ফোনে pure-Python `.whl` (যেমন `*-py3-none-any.whl`), `.tar.gz` বা `.zip` আর্কাইভ ডাউনলোড করে রাখুন, এরপর SuperCode-এর PIP Package Manager খুলে Local Archive বাটনে ট্যাপ করে সরাসরি আপনার Downloads ফোল্ডার থেকে ইনস্টল করুন।
আমাকে কেন ম্যানুয়ালি `pip install numpy` বা `matplotlib` করতে হয় না?+
NumPy, Pandas, SciPy, Matplotlib এবং Scikit-Learn-এর মতো ভারী নেটিভ C/Fortran এক্সটেনশনযুক্ত লাইব্রেরিগুলো SuperCode-এর সায়েন্টিফিক রানটাইমে আগে থেকেই অ্যাডাপ্ট করা আছে। আপনার স্ক্রিপ্টে শুধু `import numpy as np` লিখে Run চাপুন।
অ্যাপ বন্ধ করার পরও কি ইনস্টল করা PIP প্যাকেজগুলো ফোনে থেকে যায়?+
হ্যাঁ। প্রতিটি ইনস্টল করা প্যাকেজ SuperCode-এর লোকাল `python_site_packages` স্টোরেজে স্থায়ীভাবে সংরক্ষিত থাকে, তাই পুনরায় ইনস্টল না করেই যেকোনো সময় অফলাইনে আপনার স্ক্রিপ্ট রান করতে পারবেন।
