02 মূল সক্ষমতা

সাধারণ স্ক্রিপ্ট থেকে ডেটা সায়েন্স পর্যন্ত তিন-স্তরের Python এক্সিকিউশন

প্রাথমিক CS হোমওয়ার্ক থেকে শুরু করে সায়েন্টিফিক প্লটিং ও ওয়েব স্ক্র্যাপিং — প্রতিটি ওয়ার্কফ্লো টার্মিনাল ঝামেলা ছাড়াই মসৃণভাবে চলে।

02.1

অফলাইন মাল্টি-ফাইল Python 3.11 & স্মার্ট এন্ট্রি রাউটিং

.py, .json, .csv, .yaml এবং .toml ফাইল জুড়ে মাল্টি-মডিউল প্রোজেক্ট ১০০% অফলাইনে রান করুন। কোনো হেল্পার মডিউলের ভেতর থেকে Run চাপলে তা স্বয়ংক্রিয়ভাবে প্রোজেক্টের মূল এন্ট্রি স্ক্রিপ্ট খুঁজে নিয়ে রান করে।

মাল্টি-ফাইল ইমপোর্ট · আনসেভড ট্যাব ওভারলে · ফাইল সিঙ্ক
02.2

অন-ডিভাইস ক্যাশড NumPy, Pandas & Matplotlib

numpy, scipy, pandas, matplotlib বা scikit-learn ইমপোর্ট করলে অন-ডিভাইস সায়েন্টিফিক রানটাইম চালু হয় — লোকালি হুইল ক্যাশ করে রাখায় ডেটা অ্যানালাইসিস ও plt.savefig() চার্ট জেনারেশন অফলাইনেই চলে।

NumPy · Pandas · Matplotlib · অটো-সেভ PNG/SVG/PDF
02.3

ভিজ্যুয়াল PIP ম্যানেজার, Auto-PIP & অফলাইন .whl ইমপোর্ট

bs4 বা yaml-এর মতো কোনো লাইব্রেরি না থাকলে Auto-PIP অ্যালিয়াস ম্যাপ করে (bs4 -> beautifulsoup4), PyPI থেকে ইনস্টল করে এবং স্বয়ংক্রিয়ভাবে স্ক্রিপ্ট রিস্টার্ট করে — অথবা অফলাইনে requirements.txt ও লোকাল .whl/.zip ফাইল ব্যাচ-ইনস্টল করুন।

03 ধাপে ধাপে ওয়ার্কফ্লো

SuperCode-এ কীভাবে Python কোডিং ও প্যাকেজ ম্যানেজ করবেন

চার ট্যাপেই খালি ফোল্ডার থেকে শুরু করে তৈরি করুন মাল্টি-ফাইল Python ও Matplotlib প্রোজেক্ট।

STEP 01 New File -> main.py

স্ক্রিপ্ট তৈরি করুন বা বিল্ট-ইন Python উদাহরণ লোড করুন

Python ২১-কী সিম্বল বার দিয়ে শূন্য থেকে শুরু করুন অথবা কোড উদাহরণ লাইব্রেরি থেকে ৮টি বিল্ট-ইন Python টেমপ্লেটের একটি বেছে নিন।

STEP 02 PIP Package Manager

PyPI লাইব্রেরি বা অফলাইন .whl আর্কাইভ ইনস্টল করুন

এক ট্যাপে ব্যাচ ইনস্টলেশনের জন্য requirements.txt-এ ট্যাপ করুন, কিউরেটেড চিপ (requests, rich, bs4, flask) বেছে নিন বা অফলাইন ক্লাসরুমের জন্য Downloads থেকে .whl প্যাকেজ ইমপোর্ট করুন।

STEP 03 Toolbar -> Run ▶

অফলাইনে চালান ও লাইভ input()-এর মাধ্যমে ইন্টারঅ্যাক্ট করুন

input() প্রম্পটে লাইভ উত্তর টাইপ করার পাশাপাশি স্প্লিট-স্ক্রিন কনসোলে তাৎক্ষণিক আউটপুট, এক্সিট কোড, মিলিসেকেন্ড টাইমিং ও মেমোরি ডেল্টা দেখুন।

STEP 04 Explorer Refresh

তৈরি হওয়া চার্ট, CSV & JSON আউটপুট পরীক্ষা করুন

open() বা plt.savefig('plot.png') দিয়ে লেখা যেকোনো ফাইল সরাসরি আপনার প্রোজেক্ট ফোল্ডারে সিঙ্ক হয় এবং SuperCode-এর বিল্ট-ইন হাই-রেজ ইমেজ বা PDF ভিউয়ারে খুলে যায়।

হ্যাঁ। মাল্টি-ফাইল Python 3.11 স্ক্রিপ্ট, স্ট্যান্ডার্ড লাইব্রেরি মডিউল, লোকালি ইনস্টল করা PIP/.whl প্যাকেজ এবং ক্যাশড সায়েন্টিফিক Python 3.12 লাইব্রেরি (NumPy, Pandas, Matplotlib, SciPy, scikit-learn) ১০০% অফলাইনে চলে।
requests, bs4 বা অফলাইন .whl ফাইলের মতো থার্ড-পার্টি লাইব্রেরি কীভাবে ইনস্টল করব?+
ভিজ্যুয়াল PIP প্যাকেজ ম্যানেজার খুলুন (অথবা সরাসরি স্ক্রিপ্ট রান করে Auto-PIP-কে অনুপস্থিত ইমপোর্ট শনাক্ত করতে দিন)। আপনি PyPI থেকে ইনস্টল করতে, শনাক্তকৃত requirements.txt চিপে ট্যাপ করতে বা লোকাল স্টোরেজ থেকে .whl, .tar.gz ও .zip প্যাকেজ ইমপোর্ট করতে পারবেন।
Matplotlib প্লট বা open('data.csv', 'w') দিয়ে তৈরি ফাইলগুলো কোথায় যায়?+
আপনার স্ক্রিপ্টের তৈরি প্রতিটি ইমেজ, PDF, CSV বা JSON ফাইল স্বয়ংক্রিয়ভাবে সক্রিয় প্রোজেক্ট ফোল্ডারে সিঙ্ক হয়ে যায় এবং SuperCode-এর বিল্ট-ইন ইমেজ গ্যালারি বা ফাইল এডিটরে তাৎক্ষণিকভাবে দেখা যায়।
SuperCode কি ইন্টারঅ্যাক্টিভ Python input() লুপ সাপোর্ট করে?+
হ্যাঁ। যখনই আপনার স্ক্রিপ্ট input() কল করে, স্প্লিট-স্ক্রিন কনসোল ইনপুট বারটিকে হাইলাইট করে যাতে আপনি রিয়েল টাইমে ইন্টারঅ্যাক্টিভভাবে উত্তর দিতে পারেন।
