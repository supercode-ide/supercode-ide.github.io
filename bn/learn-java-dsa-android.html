02.4

লাইভ স্ট্রিমিং Scanner(System.in) এবং নিরাপদ System.exit()

স্প্লিট-স্ক্রিন টার্মিনালে প্রতিটি `Scanner.nextLine()` বা `nextInt()` প্রম্পটে ইন্টারঅ্যাক্টিভ CLI অ্যাসাইনমেন্ট স্বাভাবিকভাবে বিরতি নেয় (সাথে ডেডিকেটেড `[EOF]` বাটন), আর `System.exit(0)` কল করলে অ্যাপ বন্ধ না হয়ে প্রোগ্রাম নিরাপদে থামে।

02.5

03 ধাপে ধাপে ওয়ার্কফ্লো

ফোনে অফলাইনে Java শেখা যেভাবে শুরু করবেন

কোনো রেজিস্ট্রেশন নেই, টাইপিংয়ে বিজ্ঞাপনের ঝামেলা নেই এবং ডেস্কটপ কম্পিউটারেরও প্রয়োজন নেই।

STEP 01 Examples -> Java

বিল্ট-ইন Java টেমপ্লেট বাছুন বা Hello.java তৈরি করুন

৮টি রেডি-টু-রান Java উদাহরণের (লুপ, OOP ক্লাস, কালেকশন, রিকার্সন) যেকোনোটি খুলুন অথবা কমপ্যাক্ট `void main()` স্ক্রিপ্ট লিখুন।

STEP 02 21-Key Bar + AST

স্মার্ট ব্র্যাকেট ও অটোকমপ্লিট দিয়ে সাবলীলভাবে টাইপ করুন

`;`, `{}` ও `[]`-এর জন্য সোয়াইপ-আপ সিম্বল কী ব্যবহার করুন, আর অফলাইন AST অটোকমপ্লিট `String`, `ArrayList` ও `Math` মেথড সাজেস্ট করবে।

STEP 03 Toolbar -> Run ▶

অফলাইনে কম্পাইল করুন ও লাইভ Scanner ইনপুট দিন

তাৎক্ষণিক আউটপুট দেখতে Run ▶ ট্যাপ করুন, ইন্টারঅ্যাক্টিভ `Scanner(System.in)` ইনপুট টেস্ট করুন এবং `^~~~` ক্যারেট হিন্ট দেখে টাইপো ঠিক করুন।

STEP 04 Menu -> Save As .pdf

কোড ফরম্যাট করুন ও A4 PDF হোমওয়ার্ক এক্সপোর্ট করুন

সুন্দর ইন্ডেন্টেশনের জন্য Format ট্যাপ করুন, তারপর A4 PDF হ্যান্ডআউট এক্সপোর্ট করুন বা Visual Git দিয়ে GitHub-এ পুশ করুন।

অনেক অনলাইন কম্পাইলারে Run চাপার আগেই অন্ধভাবে সব ইনপুট দিতে হয়। SuperCode রিয়েল টাইমে ইন্টারঅ্যাক্টিভভাবে `System.in` স্ট্রিম করে — আগে আপনার প্রম্পট প্রিন্ট করে, প্রতিটি লাইন টাইপ করার জন্য অপেক্ষা করে এবং `while (sc.hasNext())` লুপের জন্য `[EOF]` বাটন দেয়।
Java কোড লেখার আগে কি আমাকে অ্যাকাউন্ট খুলতে বা লগইন করতে হবে?+

পরে কি আমি কমপ্যাক্ট `void main()` থেকে সাধারণ মাল্টি-ক্লাস Java প্যাকেজে যেতে পারব?+
হ্যাঁ। ছোট অনুশীলনের সুবিধার জন্য কমপ্যাক্ট `void main()` একটি ঐচ্ছিক সুবিধা — যখনই আপনি সাধারণ `public class Main` ফাইল, একাধিক `.java` ক্লাস, ইন্টারফেস বা `jdbc:sqlite` ডেটাবেস প্রজেক্ট লিখবেন, SuperCode কোনো মোড বদলানো ছাড়াই তা কম্পাইল করে।
