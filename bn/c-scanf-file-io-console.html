02 মূল সক্ষমতা

প্রতিটি C ইনপুট ও আউটপুট চ্যানেল কাজ করে নেটিভ টার্মিনালের মতো

মেনু-ভিত্তিক কনসোল অ্যাপ, কমান্ড-লাইন পার্সার এবং বাইনারি রেকর্ড অ্যাসাইনমেন্ট একদম ডেস্কটপ টার্মিনালের মতোই আচরণ করে।

02.1

scanf ও fgets-এর আগে স্বয়ংক্রিয় আনবাফার্ড stdout

অনেক মোবাইল ও অনলাইন রানারে শেষে নিউলাইন না থাকলে printf("Enter age: ");-এর আউটপুট scanf() শেষ না হওয়া পর্যন্ত দেখা যায় না! SuperCode স্বয়ংক্রিয়ভাবে stdout আনবাফার করে, যাতে টাইপ করার আগেই প্রম্পট দেখা যায়।

fflush(stdout)-এর প্রয়োজন নেই · স্বাভাবিক মেনু লুপ
02.2

মাল্টি-স্টেপ লাইভ Stdin ও এক-ট্যাপে [EOF] সিগন্যাল

প্রোগ্রাম চলাকালীন ধাপে ধাপে ইন্টারঅ্যাক্টিভ ইনপুট দিন। while (scanf("%d", &x) != EOF) বা while (fgets(buf, sizeof buf, stdin)) টেস্ট করছেন? একটি খালি ইনপুট লাইন সাবমিট করলেই পরিচ্ছন্ন EOF সিগন্যাল চলে যাবে।

scanf · fgets · getchar · পরিচ্ছন্ন [EOF] টার্মিনেশন
02.3

argc / argv CLI প্রোগ্রামের জন্য // @args ডিরেক্টিভ

আপনার .c ফাইলের শুরুতে // @args -i "input data.csv" --verbose যোগ করে উদ্ধৃত স্পেস অক্ষুণ্ণ রেখে সর্বোচ্চ ৩২টি পার্স করা কমান্ড-লাইন টোকেন সরাসরি main(int argc, char *argv[])-এ পাঠান।

// @args · কোটেড স্ট্রিং · সর্বোচ্চ ৩২টি argv টোকেন
02.4

স্বয়ংক্রিয় .txt / .csv / .dat / .in ডেটাসেট মাউন্টিং

আপনার প্রজেক্ট ডিরেক্টরিতে input.in, students.csv বা records.dat রাখুন এবং fopen("students.csv", "r")-এর মতো স্ট্যান্ডার্ড রিলেটিভ পাথে খুলুন—Android-এর /storage/emulated/0 হার্ডকোড করার দরকার নেই।

রিলেটিভ পাথ fopen() · .txt / .csv / .dat / .in
02.5

দ্বিমুখী fopen, fprintf ও fwrite ওয়ার্কস্পেস সিঙ্ক

fopen(..., "w" / "wb"), fprintf() এবং fwrite()-এর মাধ্যমে লেখা টেক্সট রিপোর্ট ও বাইনারি স্ট্রাক্ট স্বয়ংক্রিয়ভাবে আপনার Android ওয়ার্কস্পেস ট্রি-তে সিঙ্ক হয় এবং ফাইল এক্সপ্লোরার সঙ্গে সঙ্গে রিফ্রেশ হয়।

টেক্সট ও বাইনারি ফাইল সিঙ্ক · তাৎক্ষণিক এক্সপ্লোরার রিফ্রেশ
02.6

২০-সেকেন্ডের আইডল-পজড CPU লুপ ওয়াচডগ

ভেবেচিন্তে কনসোল ইনপুট টাইপ করতে যত সময় লাগে নিন—stdin-এর অপেক্ষায় থাকলে ২০-সেকেন্ডের ওয়াচডগ বিরতি নেয়, কিন্তু ইনপুটের পর কোনো ত্রুটিপূর্ণ লুপ অনন্তকাল CPU ঘোরাতে থাকলে সঙ্গে সঙ্গে থামিয়ে দেয়।

03 ধাপে ধাপে ওয়ার্কফ্লো

SuperCode-এ Stdin, CLI আর্গুমেন্ট ও ফাইল I/O টেস্ট করার পদ্ধতি

মোবাইলে নির্বিঘ্নে মেনু-ভিত্তিক কোর্সওয়ার্ক, Unix CLI টুল এবং ফাইল-প্রসেসিং ল্যাব চালান।

STEP 01 // @args (Optional)

ফাইলের শুরুতে ঐচ্ছিক CLI ফ্ল্যাগ ডিক্লেয়ার করুন

আপনার অ্যাসাইনমেন্ট argc এবং argv[] পড়লে ১ম লাইনে // @args input.txt output.csv-এর মতো কমেন্ট যোগ করুন।

STEP 02 Drop .in / .csv

প্রজেক্ট ফোল্ডারের ভেতরে ইনপুট ডেটাসেট রাখুন

একই ফোল্ডারে .txt, .csv, .in বা .dat ফাইল তৈরি বা ইমপোর্ট করুন, যাতে রিলেটিভ fopen() কল সেগুলো স্বয়ংক্রিয়ভাবে খুঁজে পায়।

STEP 03 Run ▶ -> Live Stdin

লাইভ প্রম্পটে ইনপুট দিন এবং শেষে [EOF] পাঠান

রিয়েল টাইমে আনবাফার্ড printf প্রম্পট দেখুন, কনসোল বারে মান দিন, অথবা [EOF] পাঠাতে খালি বক্সে সেন্ড ট্যাপ করুন।

STEP 04 Explorer -> Inspect

তৈরি হওয়া আউটপুট ফাইল সরাসরি এডিটরে খুলুন

আপনার প্রোগ্রামের ডিস্ক আউটপুট যাচাই করতে প্রজেক্ট ট্রি-তে নতুন তৈরি .txt, .csv বা লগ ফাইলে ট্যাপ করুন।

04 সক্ষমতার ম্যাট্রিক্স

SuperCode লাইভ Stdin ও ফাইল I/O বনাম ব্যাচ মোবাইল রানার

SuperCode-এর ইন্টারঅ্যাক্টিভ C কনসোল Android-এ ডেস্কটপ মানের স্ট্যান্ডার্ড ইনপুট, কমান্ড-লাইন আর্গুমেন্ট এবং ফাইল হ্যান্ডলিং সুবিধা দেয়। এটি scanf ও fgets-এর আগে স্বয়ংক্রিয়ভাবে আনবাফার্ড প্রম্পট দেখায়, এক-ট্যাপে EOF টার্মিনেশন সাপোর্ট করে, // @args-এর মাধ্যমে সর্বোচ্চ ৩২টি argc/argv ফ্ল্যাগ পাঠায় এবং fopen আউটপুট ফোল্ডারে সিঙ্ক করে।

ইন্টারঅ্যাক্টিভ মেনু লুপ আসল লাইভ মাল্টি-টার্ন Stdin + [EOF] আগেই সব ইনপুট অনুমান করে দিতে হয় ব্যাচ stdin টেক্সটএরিয়া সমর্থিত
argc / argv আর্গুমেন্ট বিল্ট-ইন `// @args` ডিরেক্টিভ (৩২টি আর্গ) সমর্থিত নয় লুকানো সেটিংস ড্রয়ার ম্যানুয়াল CLI ফ্ল্যাগ

Android-এ `scanf` প্রম্পট, `fgets` নিউলাইন সমস্যা, `EOF` এবং `fopen` পাথ সংক্রান্ত ট্রাবলশুটিং।

`fflush(stdout)` ছাড়াই SuperCode-এ `printf("Enter number: ");` সঙ্গে সঙ্গে কেন দেখা যায়?+
পাইপ করা হলে স্ট্যান্ডার্ড C স্ট্রিম সাধারণত ব্লক-বাফার্ড থাকে, ফলে শেষে `\n` না থাকলে প্রম্পট আড়ালে থেকে যায়। SuperCode স্বয়ংক্রিয়ভাবে আনবাফার্ড স্ট্যান্ডার্ড স্ট্রিম কনফিগার করে, যাতে `scanf`, `fgets` বা `getchar` অপেক্ষা করার আগেই ইন্টারঅ্যাক্টিভ প্রম্পট দেখা যায়।
Android টাচস্ক্রিন কিবোর্ডে `Ctrl+D` (`EOF`) পাঠাব কীভাবে?+
কনসোল ইনপুট বার সক্রিয় ও খালি থাকা অবস্থায় সেন্ড বাটনে ট্যাপ করলে চলমান C প্রসেসে পরিচ্ছন্নভাবে `EOF` (`[EOF]`) পাঠানো হয়—যা `while (scanf(...) != EOF)` ও `getchar() != EOF` লুপ শেষ করে।
স্পেসযুক্ত কমান্ড-লাইন আর্গুমেন্ট `char *argv[]`-তে কীভাবে পাঠাব?+
আপনার `.c` ফাইলের শুরুর দিকে `// @args "My Report.txt" -n 10` লিখুন। SuperCode-এর আর্গুমেন্ট টোকেনাইজার কোটেড স্ট্রিংকে একক `argv[i]` এন্ট্রি হিসেবে অক্ষুণ্ণ রাখে এবং সর্বোচ্চ ৩২টি আর্গুমেন্ট সাপোর্ট করে।
`fopen("output.txt", "w")` দিয়ে তৈরি ফাইল কোথায় সংরক্ষিত হয়?+
এগুলো সরাসরি আপনার `.c` সোর্স ফাইলের একই Android প্রজেক্ট ফোল্ডারে সিঙ্ক হয়, তাই স্থায়ীভাবে সংরক্ষিত থাকে এবং SuperCode-এর এডিটরের ভেতরেই খোলা যায়।
