02 মূল সক্ষমতা

C প্রোগ্রামারদের জন্য নিবেদিত C17 আর্কিটেকচার কেন গুরুত্বপূর্ণ

বিশ্ববিদ্যালয়ের ল্যাব, এমবেডেড প্রোটোটাইপিং ও অ্যালগরিদমের জন্য পরিচ্ছন্ন C17 সিম্যান্টিকস, কঠোর হেডার হাইজিন এবং ঝামেলাহীন Makefile-মুক্ত অভিজ্ঞতা।

02.1

শুরু থেকেই বিশুদ্ধ GNU C17 স্ট্যান্ডার্ড ও <math.h>

C++ নেম-ম্যাংলিং বা রানটাইম বাড়তি চাপ ছাড়াই বিশুদ্ধ C স্ট্যান্ডার্ড লাইব্রেরি ও ম্যাথ লাইব্রেরি (-lm)-সহ -std=gnu17-এ কম্পাইল হয় — ANSI/ISO C কোর্সওয়ার্ক ও সিস্টেমস ফান্ডামেন্টালসের জন্য আদর্শ।

-std=gnu17 · <stdio.h> · <stdlib.h> · <math.h>
02.2

জিরো-কনফিগ মাল্টি-ফাইল .c / .h লিংকার ও হ্যাশ ক্যাশ

আপনার ফোল্ডার ও খোলা ট্যাব থেকে #include "..." হেডার ও সহায়ক .c ফাইল স্বয়ংক্রিয়ভাবে খুঁজে নেয় — কোনো Makefile লাগে না। ইনক্রিমেন্টাল হ্যাশ ক্যাশিং অপরিবর্তিত .c ফাইল পুনরায় কম্পাইল করা এড়িয়ে যায়।

অটো .c/.h ডিসকভারি · হেডার -> main.c আরবিট্রেশন
02.3

প্রকৃত ইন্টার‍্যাক্টিভ scanf / fgets / getchar কনসোল

স্বাভাবিকভাবে ইন্টার‍্যাক্টিভ C প্রোগ্রাম টেস্ট করুন: scanf বা fgets ইনপুটের অপেক্ষায় থাকলেই টার্মিনাল হাইলাইট করে, আর খালি লাইন সাবমিট করলে [EOF] পাঠিয়ে while(scanf(...) != EOF) লুপ পরিচ্ছন্নভাবে শেষ করে।

লাইভ Stdin · [EOF] সিগন্যাল · মাইক্রোসেকেন্ড + KB পরিসংখ্যান
02.4

fopen / fwrite ওয়ার্কস্পেস ফাইল I/O সিঙ্ক্রোনাইজেশন

fopen(), fprintf() ও fwrite()-এর মাধ্যমে তৈরি বাইনারি ও টেক্সট ফাইল স্বয়ংক্রিয় এক্সপ্লোরার রিফ্রেশসহ সরাসরি আপনার প্রজেক্ট ফোল্ডারে সিঙ্ক হয়, যাতে আউটপুট ফাইল সঙ্গে সঙ্গে দেখতে পারেন।

রিয়েল ফাইল I/O · অটো ওয়ার্কস্পেস ট্রি সিঙ্ক
02.5

ইনফিনিট-লুপ সার্কিট ব্রেকার ও পয়েন্টার ডায়াগনস্টিকস

02.6

৬টি বিল্ট-ইন C টেমপ্লেট ও POSIX ক্লাউড ফলব্যাক

৬টি বাছাই করা C উদাহরণ (পয়েন্টার ও মেমোরি, স্ট্রাক্ট, বিটওয়াইজ অপস, সাইন ওয়েভ, ইকো Stdin) দিয়ে দ্রুত শেখা শুরু করুন, সাথে প্রয়োজনে স্বয়ংক্রিয় POSIX (<pthread.h>, <sys/socket.h>, fork) ক্লাউড C কম্পাইলেশন।

03 ধাপে ধাপে ওয়ার্কফ্লো

Android-এ মাল্টি-ফাইল C প্রোগ্রাম বিল্ড ও ডিবাগ করবেন যেভাবে

কোনো বিল্ড-স্ক্রিপ্ট কনফিগারেশন ছাড়াই সিঙ্গেল-ফাইল অনুশীলন বা মাল্টি-মডিউল C প্রজেক্ট লিখুন।

STEP 01 main.c + utils.h

.c সোর্স ও .h হেডার ফাইল তৈরি করুন

মডুলার C17 কোড লিখতে C/C++ ২১-কী সিম্বল বার (->, *, &, {}, ;, #include) এবং AST স্ট্রাক্ট-মেম্বার কমপ্লিশন ব্যবহার করুন।

STEP 02 Format & Error Radar

অফলাইনে ডিরেক্টিভ চেক ও ইন্ডেন্টেশন ফরম্যাট করুন

Error Radar ত্রুটিপূর্ণ #include ডিরেক্টিভ ও অমিল ব্র্যাকেট মুহূর্তেই ধরে ফেলে; K&R/Allman ব্লক ও কলাম-০ ম্যাক্রো সাজাতে Format-এ ট্যাপ করুন।

STEP 03 Toolbar -> Run ▶

যেকোনো প্রজেক্ট ট্যাব থেকে অফলাইনে কম্পাইল ও লিংক করুন

আপনার কার্সর utils.h-এর ভেতরে থাকলেও Run ট্যাপ করলে স্বয়ংক্রিয়ভাবে main.c খুঁজে নেয়, পরিবর্তিত ইউনিট কম্পাইল করে, -lm লিংক করে এবং বাইনারি চালু করে।

STEP 04 Stdin / Workspace

লাইভ scanf ইনপুট দিন ও আউটপুট ফাইল যাচাই করুন

ডক করা বা পাশাপাশি টার্মিনালে ইন্টার‍্যাক্টিভভাবে টেস্ট মান লিখুন এবং এক্সিট স্ট্যাটাস, ms-এ রানটাইম, মেমোরি ব্যবহার ও তৈরি হওয়া ফাইল দেখুন।

একবার অফলাইন টুলচেইন ডাউনলোড · প্রতি ফাইলে ইনক্রিমেন্টাল বিল্ড ক্যাশ অ্যাপ গাইড
04 সক্ষমতার ম্যাট্রিক্স

SuperCode C17 কম্পাইলার বনাম প্রচলিত মোবাইল কম্পাইলার

SuperCode C কম্পাইলার হলো Android-এর জন্য একটি নিবেদিত অফলাইন GNU C17 ডেভেলপমেন্ট এনভায়রনমেন্ট। এতে রয়েছে বিশুদ্ধ C17 কম্পাইলেশন ও ম্যাথ লাইব্রেরি লিংকিং, Makefile ছাড়াই স্বয়ংক্রিয় মাল্টি-ফাইল .c ও .h প্রজেক্ট বিল্ডিং, লাইভ scanf/fgets কনসোল ইনপুট, ওয়ার্কস্পেস ফাইল I/O সিঙ্ক এবং AST স্ট্রাক্ট অটোকমপ্লিশন।

ANDROID C প্রোগ্রামিং কম্পাইলার তুলনা
C ফিচার SuperCode C17 স্টুডিও মিশ্রিত C/C++ সাধারণ অ্যাপ অনলাইন C কম্পাইলার CLI টার্মিনাল সেটআপ
C স্ট্যান্ডার্ড ও লিংকেজ নিবেদিত GNU C17 (-std=gnu17) + -lm .c ফাইলে জোরপূর্বক C++ কম্পাইলার চালায় সার্ভার-নির্ভর ম্যানুয়াল gcc ফ্ল্যাগ

একাধিক .c এবং .h ফাইল কম্পাইল করতে কি আমাকে Makefile লিখতে হবে?+
না। SuperCode আপনার ওয়ার্কস্পেস ও খোলা এডিটর ট্যাব থেকে #include "..." হেডার ও সহায়ক .c ফাইলগুলো স্বয়ংক্রিয়ভাবে স্ক্যান করে, পরিবর্তিত ফাইলগুলো ইনক্রিমেন্টালি কম্পাইল করে এবং স্বয়ংক্রিয়ভাবে <math.h> (-lm) লিংক করে।

হ্যাঁ। আপনার C প্রোগ্রাম যখনই stdin থেকে ইনপুট পড়ে, স্প্লিট-স্ক্রিন টার্মিনাল এক্সিকিউশন থামিয়ে দেয়, আপনাকে লাইভ একাধিক লাইনের ইনপুট টাইপ করতে দেয় এবং খালি প্রম্পট সাবমিট করলে EOF পাঠায়।
