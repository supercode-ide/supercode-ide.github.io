05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

ES2024 সিনট্যাক্স, টপ-লেভেল `await`, `fetch()` এবং ইনফিনিট-লুপ সুরক্ষা নিয়ে সাধারণ প্রশ্ন।

HTML ফাইল তৈরি না করেই কি আমি SuperCode-এ সরাসরি JavaScript ফাইল চালাতে পারি?+
হ্যাঁ! HTML5 Web IDE-এর পাশাপাশি SuperCode-এর আলাদা স্বতন্ত্র JavaScript কনসোল ইঞ্জিন রয়েছে। যেকোনো `.js`, `.mjs` বা `.cjs` ফাইল খুলে শুধু Run ▶ ট্যাপ করুন।
`async function main()`-এর ভেতর কোড না মুড়ে আমি কীভাবে টপ-লেভেল `await` ব্যবহার করব?+
আপনার ফাইলটি `.mjs` হিসেবে সেভ করুন (অথবা `package.json`-এ `\"type\": \"module\"` সেট করুন, কিংবা ES Module স্ক্রিপ্টে সরাসরি টপ-লেভেল `await` লিখুন) — SuperCode নেটিভভাবেই টপ-লেভেল `await` চালায় এবং সব Promise সেটল হওয়া পর্যন্ত অপেক্ষা করে।
ফোনে ভুল করে ইনফিনিট `while (true)` লুপ লিখে ফেললে কী হবে?+
স্ক্রিপ্টগুলো একটি আইসোলেটেড ব্যাকগ্রাউন্ড ওয়ার্কার থ্রেডে চলে বলে আপনার এডিটর ও আনসেভ করা ফাইল ১০০% রেসপন্সিভ থাকে। ১ মিলিসেকেন্ডেরও কম সময়ে ওয়ার্কার থামাতে Stop ■ বাটন ট্যাপ করুন (অথবা ১৫-সেকেন্ডের CPU ওয়াচডগ ট্রিগার হতে দিন)।
স্বতন্ত্র JavaScript স্ক্রিপ্টের ভেতর কি `fetch()` কাজ করে?+
হ্যাঁ। আপনার ডিভাইসে ইন্টারনেট সংযোগ থাকলেই লাইভ HTTPS API টেস্ট করার জন্য স্ট্যান্ডার্ড `fetch()`, `Headers`, `Request`, `Response` এবং `AbortController` সরাসরি ওয়ার্কার রানটাইমে বিল্ট-ইন রয়েছে।
