02 মূল সক্ষমতা

সাধারণ টার্মিনাল অ্যাপ কেন `/sdcard`-এ ব্যর্থ হয় — আর SuperCode কীভাবে তা সমাধান করে

সুবিধাজনক শেয়ার্ড প্রজেক্ট ফোল্ডারে স্ক্রিপ্ট লিখুন, সহজেই CLI ফ্ল্যাগ পাস করুন এবং ডিভাইস রুট না করেই নিরাপদে চালান।

02.1

শেয়ার্ড স্টোরেজের noexec বাধা নিরাপদে এড়িয়ে যান (রুট ছাড়া)

Android /storage/emulated/0 ও Downloads ফোল্ডার noexec দিয়ে মাউন্ট করে, ফলে chmod +x ও ./script.sh ব্লক হয়। SuperCode ওয়ার্কস্পেস ফাইল নিখুঁতভাবে মিরর রেখে একটি ক্লিন নন-রুট স্যান্ডবক্সে স্ক্রিপ্ট চালায়।

03 ধাপে ধাপে ওয়ার্কফ্লো

রুট ছাড়া Android-এ `.sh` স্ক্রিপ্ট এডিট ও রান করার পদ্ধতি

ডাউনলোড করা `.sh` ফাইল থেকে চার ট্যাপেই নিখুঁত এক্সিকিউশনে যান।

STEP 01 Open Folder / .sh

শেয়ার্ড স্টোরেজ বা ওয়ার্কস্পেসে যেকোনো `.sh` স্ক্রিপ্ট খুলুন

Downloads বা Documents-এর ফোল্ডার খুলুন — স্ক্রিপ্টকে গোপন অ্যাপ-প্রাইভেট ডিরেক্টরিতে সরানো বা chmod চালানোর দরকার নেই।

STEP 02 # @args + Format

ব্লক ফরম্যাট করুন ও ঐচ্ছিক CLI আর্গুমেন্ট সেট করুন

ইন্ডেন্টেশন ঠিক করতে Format ট্যাপ করুন এবং প্রয়োজনে `$1` / `getopts` ফ্ল্যাগ পাঠাতে `# @args` কমেন্ট লাইন যোগ করুন।

STEP 03 Toolbar -> Run ▶

লাইভ read Stdin ও ফাইল সিঙ্কসহ অফলাইনে রান করুন

তাৎক্ষণিক রানের জন্য Run ▶ ট্যাপ করুন, ইন্টারঅ্যাক্টিভ `read` প্রম্পটে উত্তর দিন এবং আউটপুট ফাইল Explorer-এ সিঙ্ক হতে দেখুন।

STEP 04 SFTP / Visual Git

যাচাইকৃত স্ক্রিপ্ট Linux সার্ভার বা Git-এ পুশ করুন

লোকালি টেস্ট শেষে SFTP-তে আপলোড করুন (0755 এক্সিকিউটেবল পারমিশন বজায় রেখে) অথবা Visual Git দিয়ে রিপোজিটরিতে কমিট করুন।

.sh · .bash · .zsh · .ksh সাপোর্টেড · ৬টি বিল্ট-ইন শেল স্টার্টার টেমপ্লেট অ্যাপ গাইড
04 সক্ষমতার ম্যাট্রিক্স

SuperCode নন-রুট `.sh` রানার বনাম সাধারণ টার্মিনাল ওয়ার্কঅ্যারাউন্ড

SuperCode Shell Script Runner রুট অ্যাক্সেস বা শেয়ার্ড-স্টোরেজের Permission denied এরর ছাড়াই Android-এ Linux .sh, .bash, .zsh ও .ksh স্ক্রিপ্ট চালায়। এতে আসল প্রজেক্ট-ফোল্ডার $PWD সিঙ্ক, set -euo pipefail, getopts, লাইভ read -p stdin, মাল্টি-স্ক্রিপ্ট সোর্সিং ও অফলাইন ফরম্যাটিং রয়েছে।

শেয়ার্ড ফোল্ডার $PWD সরাসরি প্রজেক্ট ফোল্ডারে চলে ও সিঙ্ক হয় noexec মাউন্টে ব্লকড ঝুঁকিপূর্ণ সিস্টেম-ওয়াইড রাইট শুধু এডিট করা যায়

05 প্রশ্ন ও উত্তর

সচরাচর জিজ্ঞাসিত প্রশ্ন

রুট ছাড়া `.sh` স্ক্রিপ্ট চালানো এবং Android-এ `Permission denied` সমাধান নিয়ে সাধারণ প্রশ্নোত্তর।

Android Downloads থেকে `.sh` ফাইল চালাতে গেলে `Permission denied` দেখায় কেন?+
নিরাপত্তার কারণে Android শেয়ার্ড ইউজার স্টোরেজ (`/sdcard`, `Downloads`, `Documents`) `noexec` ফাইলসিস্টেম ফ্ল্যাগ দিয়ে মাউন্ট করে, তাই `chmod +x` দিলেও সেখানে ফাইল এক্সিকিউটেবল হয় না। SuperCode তার নেটিভ রানটাইমে নিরাপদে স্ক্রিপ্ট চালায় এবং অটোমেটিক আপনার প্রজেক্ট ফোল্ডার সিঙ্ক করে।
শেল স্ক্রিপ্ট চালাতে কি SuperCode-এর জন্য রুটেড Android ফোন লাগে?+
না। SuperCode সাধারণ, আনরুটেড Android 8.0+ ফোন, ফোল্ডেবল ও ট্যাবলেটে ইনস্টলের পর থেকেই কাজ করে।
`./deploy.sh --env staging`-এর মতো কমান্ড-লাইন আর্গুমেন্ট কীভাবে পাস করব?+
আপনার স্ক্রিপ্টের শুরুর দিকে `# @args --env staging` যোগ করুন (অথবা `read -p` দিয়ে ইন্টারঅ্যাক্টিভ ইনপুট দিন), আর SuperCode Run করার সাথে সাথেই ওই পজিশনাল প্যারামিটারগুলো (`$1`, `$2`, `$@`) সরাসরি স্ক্রিপ্টে পাঠিয়ে দেবে।
কোনো `.sh` স্ক্রিপ্ট কি আমার ওয়ার্কস্পেসের ভেতর নতুন ফাইল বা ফোল্ডার তৈরি করতে পারবে?+
হ্যাঁ। রান করার সময় `$PWD`-এর সাপেক্ষে তৈরি হওয়া যেকোনো ফাইল, লগ বা আর্কাইভ অটোমেটিক আপনার অ্যাক্টিভ Android প্রজেক্ট ডিরেক্টরিতে সিঙ্ক হয়ে যায়।
