05 QUESTIONS & ANSWERS

Frequently Asked Questions

Answers on running Scikit-Learn, OpenCV, PyTorch, and remote GPU workflows from Android.

Can I run Scikit-Learn, XGBoost, and OpenCV (`cv2`) without internet?+
Yes. Once cached on your device by SuperCode's scientific runtime, `scikit-learn`, `xgboost`, `lightgbm`, `opencv-python` (`cv2`), `Pillow`, and `scikit-image` run completely offline.
How do I run PyTorch or TensorFlow code without filling up my phone's storage?+
Simply `import torch` or `import tensorflow as tf` (or place `# @cloud` on line 1). SuperCode bundles your local `.py` modules, executes them on the cloud Python cluster, and maps any traceback directly to your local editor lines.
Can I edit and trigger scripts on my own Linux GPU workstation?+
Yes. Connect your workstation via SuperCode's SFTP workspace (supporting Ed25519/RSA SSH keys encrypted with AES-256) to edit remote `.py` and `.yaml` configs with full AST autocomplete and 3-phase atomic saves.
Does `cv2.imwrite()` save processed images to my folder?+
Yes — every image written via `cv2.imwrite()` or `Image.save()` syncs straight into your project directory and opens cleanly in SuperCode's built-in Image Viewer.
