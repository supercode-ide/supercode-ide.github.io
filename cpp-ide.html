05 QUESTIONS & ANSWERS

Frequently Asked Questions

Answers about C++20 support, STL competitive programming, multi-file headers, and offline usage.

Does SuperCode compile C++20 and STL containers offline without internet?+
Yes. Once the offline C++ toolchain pack is initialized on first use, GNU C++20 (-std=gnu++2a) and the full STL (vectors, maps, priority queues, ranges, smart pointers, lambdas) compile and run 100% offline.
Is SuperCode suitable for competitive programming (Codeforces, LeetCode, Olympiad) on a phone or tablet?+
Yes. Fast compilation with incremental caching, live multi-line std::cin input, millisecond and KB execution telemetry, and 55%/45% landscape split-screen make it ideal for algorithm practice anywhere.
How do multi-file .cpp and .hpp projects work?+
Simply place your .hpp and .cpp files in the same project folder (or open tabs). SuperCode discovers local includes automatically, links all implementation files, and even finds main() when you press Run from a header tab.
Can I use C++ <thread> or networking APIs?+
Yes. When OS-level threading or socket headers are detected, SuperCode automatically compiles your multi-file project via the cloud C++ cluster with -pthread support.
