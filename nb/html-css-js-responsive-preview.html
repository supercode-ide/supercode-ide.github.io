05 SPØRSMÅL OG SVAR

Ofte stilte spørsmål

Ofte stilte spørsmål om HTML5/CSS3/JS-redigering, ES Modules og responsive visningsfelt på Android.

Hvorfor feilet `<script type="module">` eller `fetch('./data.json')` i andre HTML-apper?+
Nettlesere blokkerer ES Modules og `fetch()` på `file://`-adresser på grunn av strenge CORS-regler. SuperCode serverer automatisk prosjektet ditt over en ekte `localhost` HTTP/1.1-origin med riktige MIME-headere, slik at moderne JS-moduler og JSON-henting fungerer direkte frakoblet.
Hvordan kan jeg forhåndsvise CSS-mediespørringer for nettbrett og skrivebord på en mobilskjerm?+
I SuperCodes direkte nettforhåndsvisning trykker du på visningsfelt-ikonet på den flytende Dynamic Island for å bytte umiddelbart mellom Mobil, Nettbrett (`768dp`) og bredt Skrivebord — og utløse `@media`-reglene dine nøyaktig.
Formaterer 1-trykks-formatereren også CSS inni `<style>` og JS inni `<script>`?+
Ja. SuperCodes rekursive HTML-formaterer analyserer innebygde `<style>`- og `<script>`-blokker i `.html`-filer og rykker inn alle tre språkene pent med ett trykk.
Kan jeg bruke lokale `.mp4`-videoer, `.woff2`-fonter og `.glb` 3D-modeller frakoblet?+
Ja. Over 65 MIME-typer er forhåndskonfigurert lokalt, inkludert `font/woff2`, `model/gltf-binary`, `image/svg+xml` og HTTP `206 Partial Content` byte-range-strømming for jevn spoling i `<video>` og `<audio>`.
