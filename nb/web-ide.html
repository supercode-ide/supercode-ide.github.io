05 SPØRSMÅL OG SVAR

Ofte stilte spørsmål

Svar om frakoblet PHP + SQLite, ES Modules / fetch() / WASM, Web DevTools og FTP/SFTP-utrulling.

Kan jeg kjøre dynamiske PHP-nettsteder og koble til SQL-databaser frakoblet på Android?+
Ja! SuperCode kjører .php-sider, REST JSON-endepunkter, økter, skjemaopplastinger og flerfils-includes helt frakoblet, med innebygd støtte for PDO('sqlite:...') og SQLite3-databaser.
Fungerer ES6-moduler (<script type="module">), fetch() og WebAssembly (.wasm)?+
Ja. Fordi SuperCode serverer prosjektet ditt over en ekte lokal HTTP-server med over 65 MIME-typer (inkludert application/wasm), fungerer fetch(), ES-moduler, WebGL 3D-modeller og WebAssembly.instantiateStreaming() rett ut av boksen.
Hvordan feilsøker jeg JavaScript-feil, nettverksforespørsler og skrivebordslayouter på telefonen?+
Trykk på den flyttbare Dynamic Island-pillen i forhåndsvisning for å veksle mellom Mobil, Nettbrett (768dp) og Skrivebord, eller åpne den justerbare Web DevTools-skuffen for å filtrere Error/Warn/Net-logger og kjøre JavaScript direkte i REPL.
Kan jeg forhåndsvise og oppdatere nettsteder som ligger på en ekstern FTP- eller SFTP-server?+
Ja. Monter serveren i SFTP/FTPS/FTP-arbeidsområdet, rediger eksterne HTML/CSS/JS/PHP-faner direkte med 3-fase atomisk lagring, og trykk Kjør for å forhåndsvise eksterne sider med hurtigbufring av ressurser ved behov.
