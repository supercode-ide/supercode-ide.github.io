05 SPØRSMÅL OG SVAR

Ofte stilte spørsmål

Svar på vanlige spørsmål om kjøring av PHP 8.2, PDO SQLite, økter og filopplastinger frakoblet på Android.

Kjører SuperCode PHP 8.2 helt frakoblet uten internett?+
Ja. SuperCodes PHP 8.2-motor og PDO SQLite-databasedriver kjører 100 % lokalt på Android-enheten din — du kan bygge og teste flersiders PHP-nettsteder, innloggingsskjemaer og JSON-API-er i flymodus.
Hvorfor velge SuperCode fremfor KSWEB eller å kjøre `php -S` i en terminalapp?+
Separate server-daemons krever manuelle virtuelle vertsbaner, holder bakgrunnstjenester kjørende og tvinger deg til å bytte mellom tre apper (editor, server, nettleser). SuperCode forener AST PHP-redigering, automatisk HTTP-ruting fra prosjektrot, Web DevTools, SQL Studio og SFTP-publisering i én lettvekts IDE.
Kan frontend JavaScript kalle mine lokale `.php`-filer ved hjelp av `fetch()`?+
Ja! Fordi arbeidsområdet ditt serveres over et ekte `localhost` HTTP/1.1-opphav, fungerer `await fetch('/api/tasks.php', { method: 'POST', ... })` sømløst med JSON-headere, informasjonskapsler og DevTools nettverkstiming.
Kan jeg inspisere SQLite `.db`-filen som opprettes av PHP `new PDO('sqlite:app.db')`?+
Umiddelbart. Trykk på `app.db` i SuperCodes filutforsker for å inspisere tabeller, skjema og rader i Unicode-boks- eller Markdown-format inne i SQL Studio.
