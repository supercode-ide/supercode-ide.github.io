Bygget fra verktøylinjen og opp for ekte programvareprosjekter

Hver mikrointeraksjon — fra hopp over parenteser til markeringsforankret formatering — er verifisert for tommelhastighet og visuell klarhet.

02.1

Hybrid AST-kontekstbevisst kodefullføring

Utløses automatisk på ., ->, :: og : på tvers av C/C++, Python, Java, Kotlin, JS/TS, HTML, CSS, PHP, Lua, Shell og SQL — og løser opp lokale typer, struct-/klassemedlemmer, STL/DOM-API-er og kodesnutter offline.

Operatorer: . · -> · :: · : | 10 språkfamilier
02.2

Dobbel utheving & smart gjenkjenning av navnløse filer

Uthever synlige linjer i visningsfeltet øyeblikkelig i 120Hz samtidig som indre formattokens (\n, %d, {0}) og @param/TODO-tagger bevares. Gjenkjenner språk automatisk i filer uten filendelse via #! Shebang og leksikalsk poengberegning.

40+ filendelser · Shebang-detektor · 0 tapte bilder
02.3

30+ offline kodeformaterere & smart kommentering

Formater C/C++, Java, Kotlin, JS/TS, Python (PEP 8), JSON, CSS, PHP, SQL, Lua, Shell og HTML/Vue (med rekursiv formatering av <script> og <style>!) mens grunninnrykket for markeringen bevares i ett enkelt angre-trinn.

Ett-trinns atomisk angre · Rekursiv HTML/JS/CSS
02.4

Error Radar V2.0 & holografisk dokumentstatistikk

Fanger opp uparede parenteser, ulukkede strenger/tagger, Python TabError/manglende kolon og ugyldige JSON-kommaer med ett-trykks hopp til Ln X, Col Y — side om side med globalt og markert antall linjer, ord, tegn og nøyaktige UTF-8-bytes.

03 STEG-FOR-STEG-ARBEIDSFLYT

Slik tilpasser og mestrer du editorarbeidsområdet

Sett opp en personlig mobil kodeflyt på skrivebordsnivå på under to minutter.

STEP 01 Explorer / Smart Save

Opprett eller åpne hvilken som helst kildefil

Åpne flere faner fra intern lagring, SD/USB OTG, Git eller SFTP. Selv navnløse kladder gjenkjenner språksyntaks automatisk og foreslår riktig filendelse ved Smart lagring.

STEP 02 21-Key Symbol Bar

Skriv raskere med dobbeltfunksjonstaster & AST

Trykk for å sette inn parede skilletegn eller pakke inn markeringer; sveip opp på enhver tast for sekundære operatorer (===, /**/, reduser innrykk) og utløs 0ms AST-medlemsfullføring.

STEP 03 Format · Lint · Count

Formater kode & inspiser Error Radar

Trykk Formater for å justere innrykk pent, og trykk deretter Tell for å inspisere sanntids Error Radar-koordinater sammen med UTF-8-statistikk for markering og hele dokumentet.

STEP 04 Right-Edge Swipe

Sveip fra høyre kant for 5 hurtighandlinger

Dra innover fra høyre skjermkant med én hånd for å trykke Angre/Gjenta/Tema/Linjebryting gjentatte ganger uten å lukke menyen, slå på Zen-modus eller eksportere en A4-PDF.

05 SPØRSMÅL OG SVAR

Ofte stilte spørsmål

Svar om offline formatering, språk for autofullføring, tilpasning av verktøylinjen og PDF-/bildeverktøy.

Fungerer smart kodefullføring og formatering 100 % offline?+
Ja. AST-bevisst kodefullføring, dobbel syntaksutheving, sanntids Error Radar-linting og alle 30+ språkformaterere kjører helt offline på Android-enheten din uten nettverksavhengighet.
Hvordan øker 21-tasters symboltastaturet kodehastigheten på telefon?+
Det laster automatisk én av 6 språkprofiler (C/C++, Python, Java/Kotlin, JS/TS, Web, Shell/SQL), pakker markert tekst inn i parenteser eller anførselstegn, støtter sveip-opp for sekundære symboler med forstørrelseslupe og har en markørlås-modus som skjuler systemtastaturet mens du navigerer.
Kan jeg endre rekkefølgen på bunnlinjen og knappene i hurtigmenyen?+
Ja. Åpne Innstillinger -> Tilpass verktøylinjer & meny for å dra og endre rekkefølgen på både hovedlinjen (bunn/side) og alle 5 gylne hurtighandlingsplasser, eller tilbakestill til standard med ett trykk.
Kan jeg eksportere kildekode til PDF eller vise PDF-er og bilder inne i IDE-en?+
Ja. Bruk Skriv ut eller Lagre som .pdf for å generere skarpe A4 monospace-PDF-er, og inspiser prosjekt-PDF-er (1x–5x zoom, sidehopp) samt 10 bildeformater (inkludert WEBP, HEIC, AVIF, ICO) direkte inne i SuperCode.
