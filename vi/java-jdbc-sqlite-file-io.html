02 NĂNG LỰC CỐT LÕI

Ngăn xếp lưu trữ bền vững, File I/O & Mạng hoàn chỉnh cho Java 17

02.1

Driver SQLite JDBC Offline tích hợp sẵn không cần cài đặt

Viết DriverManager.getConnection(\"jdbc:sqlite:campus.db\") hoặc \"jdbc:sqlite::memory:\" rồi nhấn Chạy. SuperCode đăng ký sẵn org.sqlite.JDBC offline — không cần săn tìm tệp .jar driver, mẹo Class.forName() hay cấu hình pom.xml rườm rà.

jdbc:sqlite:app.db · :memory: · Không cần cài Driver
02.2

PreparedStatement, Giao dịch ACID & Bài lab DAO theo lô

Làm chủ phòng chống SQL injection bằng tham số hóa PreparedStatement, chạy giao dịch nhiều bảng nguyên tử với setAutoCommit(false) và rollback(), bật PRAGMA foreign_keys và kiểm tra cột qua ResultSetMetaData.

PreparedStatement · ACID Rollback · executeBatch()
02.3

Chuyển 1 chạm sang SQL Studio trực quan của SuperCode

Mọi tệp .db hoặc .sqlite3 được tạo từ mã Java JDBC của bạn sẽ hiện ngay trong cây dự án. Chạm vào tệp để xem schema, index và bảng dữ liệu trong SQL Studio theo chế độ Box, Markdown, CSV và JSON.

Workspace .db dùng chung · Xem Schema & Bảng trực quan
02.4

Đầy đủ Java NIO.2 & Stream File I/O truyền thống

Đọc tập dữ liệu CSV, cập nhật cấu hình .properties và xuất báo cáo có cấu trúc bằng java.nio.file.Files (readString, writeString, readAllLines, createDirectories), FileChannel, BufferedReader và ObjectOutputStream — đồng bộ trực tiếp ra thư mục.

java.nio.file.Files · Path.of() · Đồng bộ đĩa bền vững

03 QUY TRÌNH TỪNG BƯỚC

Cách xây dựng dự án Java + SQLite JDBC trên Android

Đi từ thư mục trống đến vòng lặp CSDL JDBC bền vững + kiểm tra SQL trực quan chỉ trong vài giây.

STEP 01 import java.sql.*;

Kết nối qua DriverManager.getConnection(\"jdbc:sqlite:...\")

Mở bất kỳ tệp .java nào và kết nối tới tên tệp CSDL tương đối (ví dụ: jdbc:sqlite:store.db) — driver tự động nạp offline.

STEP 02 PreparedStatement

Chạy DDL, Insert tham số hóa & truy vấn Join

Thực thi CREATE TABLE, INSERT theo lô và SELECT join offline, hoặc đọc tệp dữ liệu mẫu .csv đi kèm bằng Files.readAllLines().

STEP 03 Explorer -> store.db

Kiểm tra tệp .db vừa tạo trong SQL Studio

Chạm vào tệp store.db đã đồng bộ trong Trình duyệt tệp để xem bảng, chạy truy vấn SQL tùy ý hoặc xuất kết quả dạng Markdown/CSV.

STEP 04 Visual Git / Export

Xuất báo cáo hoặc Commit dự án DAO của bạn

Kiểm tra tệp CSV/JSON xuất ra ngay trong trình soạn thảo, in mã nguồn sang PDF A4 hoặc commit repo DAO đa class bằng Visual Git.

Đóng gói sẵn org.sqlite.JDBC Offline · Đồng bộ tệp thật · Kèm SQL IDE trực quan Hướng dẫn

05 HỎI & ĐÁP

Câu hỏi thường gặp

Giải đáp về chuỗi kết nối JDBC, tệp `.db` bền vững, đường dẫn NIO.2 và `HttpClient` trên Android.

Tôi có cần gọi `Class.forName(\"org.sqlite.JDBC\")` hay thêm Maven dependency để dùng SQLite trong Java không?+
Không! SuperCode tích hợp và tự động đăng ký sẵn `org.sqlite.JDBC`. Chỉ cần import `java.sql.*` và gọi `DriverManager.getConnection(\"jdbc:sqlite:mydb.db\")` — chạy ngay 100% offline.
Các tệp `.db`, `.csv` và `.txt` được lưu ở đâu khi chương trình Java của tôi ghi dữ liệu?+
Đường dẫn tương đối như `jdbc:sqlite:inventory.db` hay `Path.of(\"report.csv\")` được phân giải thẳng vào thư mục dự án đang mở và tự động đồng bộ lại vào không gian làm việc Android ngay khi chạy xong.
Tôi có thể tạo sẵn dữ liệu SQLite trong SQL Studio của SuperCode rồi dùng Java truy vấn lại không?+
Hoàn toàn được! Đây là một trong những quy trình phổ biến nhất trên SuperCode: thiết kế bảng và nạp dữ liệu mẫu trong SQL Studio (`schema.sql` -> `app.db`), sau đó mở lớp `.java` DAO trong cùng thư mục và truy vấn `jdbc:sqlite:app.db` mượt mà.
`java.net.http.HttpClient` có dùng để test REST API được không?+
Có. `HttpClient`, `HttpRequest` và `HttpResponse` chuẩn Java 11/17 hoạt động ngay cho các yêu cầu HTTPS REST khi thiết bị có mạng, trong khi mọi thao tác JDBC và tệp NIO.2 hoạt động hoàn toàn offline.
