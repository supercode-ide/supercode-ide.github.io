02 NĂNG LỰC CỐT LÕI

Hơn cả bảng dữ liệu chỉ đọc — Trạm làm việc SQLite ngoại tuyến thực thụ

Kiểm tra metadata nội bộ, chỉnh sửa bằng truy vấn tham số hóa, chuyển tệp phẳng thành bảng SQL và xuất báo cáo gọn gàng trong vài giây.

02.1

Trình kiểm tra 1 chạm cho .db, .sqlite, .sqlite3, .db3 & .s3db

Chạm vào bất kỳ cơ sở dữ liệu SQLite nhị phân nào trong Trình duyệt tệp của SuperCode hoặc mở từ bộ nhớ Android. SuperCode xác minh header nhị phân và tự động in thông số trang .dbinfo, số lượng .tables cùng toàn bộ .schema DDL.

.db · .sqlite · .sqlite3 · .db3 · .s3db
02.2

9 định dạng .mode chuyển đổi linh hoạt (Box, Markdown, JSON, CSV+)

Định dạng kết quả cho mọi nhu cầu: lưới box Unicode sắc nét và bảng ASCII dễ đọc trên di động, bảng markdown cho tài liệu GitHub, mảng json cho API, csv/tabs cho trang tính, bản dump insert SQL hoặc thẻ line dọc.

box · table · markdown · json · csv · tabs · insert · line · list
02.3

Lệnh .import --csv, --tsv & --json không cần code mẫu

Bỏ qua việc gõ CREATE TABLE rườm rà. Chạy .import --csv sales.csv sales hoặc .import --json users.json users (tối đa 8 MB) và SuperCode tự động suy luận tên cột để bạn JOIN và tổng hợp dữ liệu ngay lập tức.

Tự tạo bảng · CSV / TSV / JSON tối đa 8 MB
02.4

Tự động gắn cơ sở dữ liệu Workspace cho script .sql

Đặt queries.sql cạnh tệp app.db trong dự án của bạn. SuperCode tự động nhận diện và gắn kết cơ sở dữ liệu workspace (hoặc theo lệnh .open tường minh) để các thay đổi schema và chỉnh sửa được lưu trực tiếp trên ổ đĩa.

Lưu chỉnh sửa trên ổ đĩa · Hỗ trợ đa DB với .open
02.5

Xuất tệp trực tiếp bằng .once vào thư mục dự án

Kết hợp mọi chế độ xuất với .once <filename> — như .mode markdown + .once report.md hoặc .mode csv + .once clean_leads.csv — để ghi kết quả truy vấn thẳng vào tệp workspace sẵn sàng chia sẻ.

Xuất với .once · Tạo báo cáo & bản dump tức thì

03 QUY TRÌNH TỪNG BƯỚC

Cách kiểm tra tệp `.db` hoặc truy vấn tập dữ liệu CSV/JSON trên Android

Mở cơ sở dữ liệu nhị phân có sẵn hoặc tạo mới từ tệp thô chỉ trong 4 bước nhanh chóng.

STEP 01 Explorer -> Tap .db

Mở mọi tệp .db, .sqlite hoặc .sqlite3 chỉ với 1 chạm

Chọn tệp cơ sở dữ liệu trong workspace để xem ngay tóm tắt .dbinfo, danh sách .tables và schema CREATE TABLE / INDEX.

STEP 02 .import --csv / --json

Hoặc nhập tệp CSV, TSV & JSON thô thành bảng

Chạy .import --csv data.csv my_table trong script .sql để tự động tạo và nạp cột quan hệ từ tệp phẳng tối đa 8 MB.

STEP 03 .mode box / markdown

Chạy truy vấn SQL & chuyển đổi giữa 9 định dạng xuất

Viết lệnh SELECT, JOIN, UPDATE hoặc ALTER với gợi ý mã SQL từ AST và xem trước lưới Unicode box hoặc Markdown sắc nét.

STEP 04 .once export.csv

Xuất kết quả sạch trở lại Workspace của bạn

Dùng .once với chế độ csv, json, markdown hoặc insert để lưu kết quả phân tích gọn gàng trực tiếp vào thư mục dự án.

05 HỎI & ĐÁP

Câu hỏi thường gặp

Giải đáp về việc mở tệp `.db`/`.sqlite3`, nhập tập dữ liệu CSV/JSON và xuất kết quả đã định dạng ngoại tuyến.

SuperCode có thể mở trực tiếp những phần mở rộng tệp cơ sở dữ liệu SQLite nào?+
SuperCode nhận diện tệp `.db`, `.sqlite`, `.sqlite3`, `.db3` và `.s3db` chỉ với một chạm, tự động chạy kiểm tra ngoại tuyến `.dbinfo`, `.tables` và `.schema`.
Tại sao SQLite 3.54.1 nhúng lại quan trọng hơn so với các trình xem SQLite Android thông thường?+
Phần lớn trình xem DB Android phụ thuộc vào bản SQLite hệ thống cũ của điện thoại, vốn thiếu bảng `STRICT`, `RETURNING`, `JSONB`, mệnh đề Window frame hiện đại và trình tối ưu truy vấn mới. SuperCode cung cấp SQLite 3.54.1 đồng nhất trên mọi thiết bị Android 8.0+.
Tôi có thể nhập tệp `.csv` hoặc `.json` mà không cần viết `CREATE TABLE` trước không?+
Có! Chạy `.import --csv filename.csv tablename` (hoặc `--tsv` / `--json`) tối đa 8 MB — nếu `tablename` chưa tồn tại, SuperCode tự động tạo schema bảng từ tiêu đề CSV hoặc các khóa đối tượng JSON của bạn.
Làm thế nào để xuất kết quả truy vấn SQL ra bảng Markdown hoặc tệp CSV?+
Thêm `.mode markdown` (hoặc `.mode csv` / `.mode json` / `.mode insert`) theo sau bởi `.once output.md` ngay phía trên lệnh `SELECT` của bạn và chạm Chạy — tệp sẽ xuất hiện ngay lập tức trong trình duyệt dự án.
