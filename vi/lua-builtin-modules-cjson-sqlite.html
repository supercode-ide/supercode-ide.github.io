02 NĂNG LỰC CỐT LÕI

Viết script Lua thực chiến vượt xa thư viện chuẩn cơ bản

Xây dựng REST client, trình sửa tệp lưu SQLite cục bộ, công cụ xử lý thư mục hàng loạt và script JSON kiểu OpenResty/Redis mà không cần đụng trình biên dịch C.

02.1

Tuần tự hóa cjson & dkjson dùng ngay lập tức

Phân tích và xuất payload JSON tức thì khi ngoại tuyến bằng require('cjson') hoặc require('dkjson') — kèm cjson.encode_pretty() cho tệp cấu hình dễ đọc và gỡ lỗi API.

cjson.encode · encode_pretty · cjson.decode
02.2

Bộ máy cơ sở dữ liệu nhúng lsqlite3 / sqlite3

Mở :memory: hoặc tệp .db bền vững trong workspace qua require('lsqlite3') hoặc require('sqlite3'). Hỗ trợ prepared statement, liên kết tham số :named, trình lặp db:nrows() và giao dịch ACID.

lsqlite3 · Đồng bộ .db bền vững · Dùng chung SQL IDE
02.3

Tự động hóa thư mục & tệp với LuaFileSystem (lfs)

Tự động đổi tên hàng loạt và kiểm tra tài nguyên trong thư mục dự án bằng require('lfs') — gồm lfs.dir(), lfs.mkdir(), lfs.currentdir() và kiểm tra kích thước/thời gian với lfs.attributes().

lfs.dir · lfs.mkdir · lfs.attributes
02.4

Bộ bảo mật crypto, sha2, md5 & base64

Ký payload webhook, kiểm tra checksum tệp và tạo ID duy nhất ngoại tuyến với SHA-256, SHA-512, MD5, mã băm HMAC có khóa, crypto.uuid() cùng mã hóa/giải mã Base64 chuẩn RFC.

SHA-256/512 · HMAC · crypto.uuid() · base64
02.5

socket.http, Regex đầy đủ & Table inspect

Kiểm thử REST API thực tế qua require('socket.http'), chạy biểu thức chính quy PCRE/POSIX đầy đủ khi pattern của Lua chưa đủ qua require('regex') và in gọn table lồng nhau với require('inspect').

socket.http · Regex đầy đủ · inspect(table)
02.6

Định tuyến Cloud Lua cho C-Rock lpeg & luv

Đang dùng bộ phân tích PEG trong lpeg hay vòng lặp bất đồng bộ libuv trong luv? SuperCode tự động đóng gói các mô-đun dự án lên runtime Cloud Lua và ánh xạ traceback 1:1 về trình soạn thảo.

05 HỎI & ĐÁP

Câu hỏi thường gặp

Câu hỏi thường gặp về sử dụng cjson, lsqlite3, LuaFileSystem và các mô-đun luarocks trên Android.

Tôi có cần cài luarocks hay trình biên dịch C để dùng `cjson`, `lsqlite3` hoặc `lfs` không?+
Không. Toàn bộ 11+ bí danh mở rộng cốt lõi (`cjson`, `dkjson`, `lsqlite3`, `sqlite3`, `lfs`, `crypto`, `sha2`, `md5`, `base64`, `regex`, `socket.http` và `inspect`) đều được tích hợp trực tiếp vào SuperCode và chạy ngay qua `require()`.
`lsqlite3` có thể dùng chung cùng tệp `.db` với Python, PHP hoặc SQL IDE của SuperCode không?+
Có! Cơ sở dữ liệu `.db` do `lsqlite3` tạo trong thư mục dự án là tệp nhị phân SQLite 3 chuẩn, có thể truy vấn trực tiếp trong SQL Studio của SuperCode, Python `sqlite3`, PHP `PDO` hoặc Java JDBC.
`cjson` có hỗ trợ in định dạng đẹp cho tệp cấu hình không?+
Có. Ngoài `cjson.encode()` và `cjson.decode()` chuẩn, SuperCode còn cung cấp `cjson.encode_pretty()` giúp bạn kiểm tra hoặc lưu JSON thụt lề gọn gàng khi ngoại tuyến.
Điều gì xảy ra nếu script của tôi yêu cầu `lpeg` hoặc `luv`?+
Khi có kết nối internet, SuperCode nhận diện các lệnh nhập C-rock gốc chuyên dụng như `lpeg` hoặc `luv` và tự động định tuyến dự án đa tệp của bạn sang môi trường Cloud Lua.
