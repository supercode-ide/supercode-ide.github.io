05 ПИТАННЯ ТА ВІДПОВІДІ

Часті запитання

Часті запитання про багатопакетну структуру, додавання зовнішніх бібліотек .jar та визначення main().

Як додати зовнішню бібліотеку `.jar`, як-от Gson чи Commons Lang, у SuperCode?+
Створіть теку `libs` (або `lib`) у корені вашого Java-проєкту та скопіюйте туди файл `.jar`. SuperCode автоматично додає всі архіви `.jar` із `libs/` (до 30 МБ) до classpath компіляції та виконання — жодних скриптів збірки не потрібно.
Що станеться, якщо натиснути «Запустити» під час редагування класу Java без методу `main()`?+
Арбітратор точок входу SuperCode сканує скомпільовані класи проєкту, автоматично обирає основний клас із методом `main()` і запускає його — вам не доведеться постійно перемикатися між вкладками.
Обов'язково використовувати `src/main/java`, чи працюють і прості теки з кількома файлами?+
Обидва варіанти працюють бездоганно! Ви можете розмістити два файли `.java` поруч у простій теці без директиви `package`, організувати підтеки `com.example.*` напряму або застосувати повну структуру `src/main/java` + `resources/` + `libs/`.
Які файли `.jar` працюють офлайн на Android?+
Будь-яка стандартна pure-Java бібліотека `.jar` під Java 8, 11 або 17 (наприклад, `gson`, `org.json`, `commons-lang3`, `commons-csv` або університетські тестові бібліотеки) працює на 100% офлайн. Десктопні GUI-архіви з вікнами AWT/Swing не призначені для мобільних консолей.
