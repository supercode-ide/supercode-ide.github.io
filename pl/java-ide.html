05 PYTANIA I ODPOWIEDZI

Często zadawane pytania

Najczęstsze pytania o funkcje Java 17, wieloplikowe OOP, własne pliki .jar oraz wejście Scanner offline.

Jaką wersję Javy SuperCode kompiluje offline na Androidzie?+
SuperCode kompiluje i uruchamia Java 17 offline — w tym records, klasy sealed, wyrażenia switch, dopasowanie wzorców w instanceof, bloki tekstowe i Streams — z automatycznym kierowaniem funkcji Java 21+ do chmury.
Czy mogę uruchomić projekt Java z wieloma klasami i pakietami?+
Tak. SuperCode rozwiązuje wszystkie pliki .java w folderach projektu i otwartych kartach, automatycznie wyznacza klasę zawierającą main() i synchronizuje zapisane pliki z obszarem roboczym.
Czy mogę połączyć Javę z lokalną bazą SQLite lub dodać zewnętrzne pliki .jar?+
Tak! Sterownik JDBC jdbc:sqlite:... działa wbudowany offline, a wszystkie kompatybilne biblioteki .jar umieszczone w katalogu libs/ projektu są automatycznie dodawane do classpath.
Czy Scanner(System.in) działa interaktywnie?+
Tak. Program płynnie wstrzymuje działanie, gdy Scanner lub BufferedReader oczekuje na dane, pozwalając wpisywać wiele wierszy w dzielonym terminalu.
