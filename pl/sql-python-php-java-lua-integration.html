05 PYTANIA I ODPOWIEDZI

Często zadawane pytania

Najczęstsze pytania o współdzielenie plików `.db` między językami oraz edycję dużych zrzutów `.sql` na Androidzie.

Czy muszę pobierać plik `.jar`, aby użyć `jdbc:sqlite:app.db` w Java 17?+
Nie! SuperCode ma fabrycznie wbudowany sterownik SQLite JDBC w ścieżce classpath Java 17 offline — wystarczy napisać `DriverManager.getConnection("jdbc:sqlite:app.db")` i nacisnąć Uruchom.
Czy Python, PHP, Java i Lua naprawdę mogą odczytywać i zapisywać ten sam plik `app.db`?+
Tak. Dopóki pliki `.sql`, `.py`, `.php`, `.java` i `.lua` znajdują się w tym samym folderze roboczym (lub wskazują tę samą ścieżkę względną), wszystkie wykonują i zatwierdzają transakcje ACID na identycznym pliku `app.db` na dysku.
Jak korzystać z SQLite w skryptach Lua 5.4 w SuperCode?+
Wywołaj `local sqlite3 = require('lsqlite3')` oraz `local db = sqlite3.open('app.db')`. Wbudowany moduł `lsqlite3` jest zintegrowany z natywnym runtime Lua 5.4 offline i uruchamia się w ułamku milisekundy.
Czy SuperCode otworzy zrzut bazy `.sql` o rozmiarze ponad 1 GB bez zawieszenia telefonu?+
Tak. Edytor dużych plików GB w SuperCode strumieniuje ogromne pliki `.sql`, `.csv` i `.log` bezpośrednio ze stron dysku zamiast ładować cały plik do RAM — z wyszukiwaniem/zamianą regex i wykrywaniem kodowania.
