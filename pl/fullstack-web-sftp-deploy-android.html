03 PRZEPŁYW KROK PO KROKU

Jak podglądać, bezpiecznie edytować i publikować stronę na żywo z Androida

Dwa przejrzyste potoki wdrożeń — bezpośredni SFTP/FTPS dla serwerów PHP/VPS albo wizualny Git dla Pages.

STEP 01 SFTP / Git -> Connect

Zamontuj serwer WWW lub sklonuj repozytorium Git

Dodaj swój serwer VPS/cPanel w menedżerze SFTP/FTPS (z zaszyfrowanym kluczem SSH lub hasłem) albo sklonuj repozytorium GitHub Pages.

STEP 02 Edit + Run ▶ Preview

Sprawdź zdalne lub lokalne strony w 3 viewportach

Edytuj HTML, CSS, JS lub PHP z podpowiedziami AST i dotknij Uruchom ▶, aby przed publikacją sprawdzić układ Telefon/Tablet/Desktop oraz logi DevTools.

STEP 03 Save (Atomic) / Diff

Zweryfikuj zmiany w Unified Diff lub zapisz atomowo

Zapisuj zdalne karty SFTP/FTPS przez 3-fazową atomową zmianę nazwy, aby odwiedzający nigdy nie trafili na niepełny plik, lub przejrzyj kolorowy diff Git.

STEP 04 Verify Live / Push

Wypchnij na produkcję i potwierdź status sieciowy

Wypchnij commity, aby uruchomić GitHub/Cloudflare Pages, lub zsynchronizuj równolegle foldery zasobów ze swoim serwerem produkcyjnym.

05 PYTANIA I ODPOWIEDZI

Często zadawane pytania

Częste pytania o edycję zdalnych stron przez SFTP/FTPS, zapobieganie uszkodzonym wysyłkom i wypychanie na GitHub Pages.

Jak działa podgląd zdalnej strony SFTP lub FTP bez pobierania całego serwera?+
Gdy dotkniesz Uruchom na otwartej zdalnej karcie `.html` lub `.php`, SuperCode renderuje ją na lokalnym serwerze podglądu i automatycznie pobiera ze zdalnego hosta wyłącznie wskazane względne pliki CSS, JS, fonty oraz obrazy na żądanie.
Co się stanie, jeśli telefon straci zasięg dokładnie w trakcie zapisu zdalnego pliku `index.php`?+
Twój działający plik produkcyjny pozostaje nienaruszony! 3-fazowy zapis atomowy w SuperCode najpierw wysyła dane do pliku tymczasowego, potwierdza w 100% zgodność rozmiaru w bajtach i dopiero wtedy wykonuje atomową zmianę nazwy po stronie serwera.
Czy SuperCode obsługuje zarówno hosting współdzielony cPanel/Plesk, jak i serwery Linux SSH VPS?+
Tak. Użyj SFTP (z hasłem lub prywatnymi kluczami Ed25519/RSA) dla chmurowych instancji VPS takich jak DigitalOcean, AWS Lightsail, Hetzner czy Linode, a dla cPanel i hostingu współdzielonego wybierz FTPS (TLS 1.3) lub FTP.
Czy mogę za darmo zbudować i opublikować statyczną stronę HTML/CSS/JS lub WASM na GitHub Pages?+
Tak. Stwórz i przetestuj stronę offline na lokalnym serwerze HTTP w SuperCode, a następnie zacommituj i wypchnij ją prosto do swojego repozytorium GitHub Pages za pomocą wbudowanego wizualnego klienta Git.
