05 PYTANIA I ODPOWIEDZI

Często zadawane pytania

Konkretne odpowiedzi o kompilatorach offline, obsłudze dużych plików, wspieranych językach oraz pracy z Git i SFTP.

Które języki programowania działają offline w SuperCode IDE na Android?+
SuperCode uruchamia lokalnie na Android: Python (3.11 & naukowy 3.12), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, PHP, HTML5/CSS3/WebAssembly, Lua 5.4 oraz skrypty Linux Shell, z opcjonalnym wsparciem chmury dla Kotlin, MySQL 8.0 i ciężkich frameworków serwerowych.
Czy SuperCode otwiera gigabajtowe pliki logów i zrzuty SQL bez zawieszania?+
Tak. Pliki większe niż 30 MB automatycznie włączają strumieniowy Pager GB, dzieląc pliki setek MB i GB na dyskowe bloki po 10 mln znaków z natychmiastowym skokiem do strony, wykrywaniem 34 zestawów znaków i globalną zamianą strumieniową Regex.
Czy C i C++ oraz SQL i Web/PHP to osobne, dedykowane środowiska?+
Tak. C17 i C++20 mają własne standardy, nagłówki i szablony; SQL posiada 9-trybową konsolę i binarny inspektor .db; a Web Studio uruchamia prawdziwy lokalny serwer podglądu HTTP + PHP + PDO SQLite + WebAssembly z wbudowanymi DevTools.
Czy SuperCode zawiera wbudowanego klienta Git i zdalny edytor SFTP/FTPS?+
Tak. Zawiera kompletny wizualny klient Git (klonowanie z PAT, gałęzie, zunifikowane diffy w Commit Time Machine i narzędzie rozwiązywania konfliktów scalania) oraz szyfrowaną AES-256 przestrzeń SFTP, FTPS (TLS 1.3) i FTP z 3-fazowym atomowym zapisem zdalnym.
Czy SuperCode jest zoptymalizowany pod kątem telefonów i tabletów Android?+
Tak. Na telefonach paski narzędzi są w zasięgu kciuka z menu wysuwanym z prawej krawędzi i automatycznie zwijaną konsolą dzieloną; na urządzeniach składanych i tabletach pasek dokuje pionowo, a terminal otwiera się w układzie stanowiska roboczego 55% / 45% obok siebie.
