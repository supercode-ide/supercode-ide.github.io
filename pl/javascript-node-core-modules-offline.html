05 PYTANIA I ODPOWIEDZI

Często zadawane pytania

Pytania dotyczące obsługiwanych modułów `node:*`, ścieżek plików `fs`, `package.json` i pakietów npm na Androidzie.

Które moduły rdzeniowe Node.js działają w 100% offline w SuperCode?+
Ponad 29 standardowych modułów działa całkowicie offline, w tym `fs`, `fs/promises`, `path`, `path/posix`, `buffer`, `events`, `stream`, `stream/promises`, `stream/web`, `zlib`, `crypto`, `readline`, `util`, `assert`, `url`, `querystring`, `string_decoder`, `timers`, `timers/promises`, `perf_hooks`, `os`, `process` oraz `console`.
Czy `fs.writeFileSync('out.json', data)` zapisuje prawdziwy plik w moim folderze na Androidzie?+
Tak! Operacje systemu plików czytają bezpośrednio z otwartego folderu projektu (wliczając niezapisane karty edytora) i synchronizują każdy utworzony lub zmodyfikowany plik z powrotem do katalogu na Androidzie.
Czy mogę używać zarówno prefiksów `node:fs`, jak i zwykłego `require('fs')`?+
Tak. Zarówno nowoczesna składnia ES Module `import fs from 'node:fs/promises'`, jak i klasyczne wywołania CommonJS `const fs = require('fs')` wskazują na dokładnie te same wbudowane implementacje offline.
Co się stanie, jeśli mój skrypt zaimportuje `node:http`, `net` lub `worker_threads`?+
Moduły wymagające systemowych gniazd serwera lub podprocesów (`http`, `https`, `net`, `tls`, `dns`, `child_process`, `worker_threads`) są wykrywane automatycznie i wykonywane przez wieloplikowy bundler Node.js w chmurze SuperCode — a lokalne podglądy HTTP full-stack są też dostępne w Web IDE SuperCode.
