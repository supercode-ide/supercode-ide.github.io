03 PRZEPŁYW KROK PO KROKU

Jak klonować, refaktoryzować, testować i wypychać repo Pythona na Androidzie

Pełny cykl życia inżynierii oprogramowania bezpośrednio na telefonie lub tablecie z Androidem.

STEP 01 Git Clone / Open Folder

Sklonuj repo GitHub lub otwórz lokalne drzewo projektu

Sklonuj przez HTTPS z Personal Access Tokenem lub otwórz dowolny folder w pamięci urządzenia — zbędne `.git`, `venv` i `__pycache__` są automatycznie pomijane przy skanowaniu.

STEP 02 Multi-Tab Edit + PEP 8

Edytuj moduły z podpowiedziami AST i 21-klawiszowym paskiem symboli

Przesuń w górę 21-klawiszowy pasek symboli, by wpisać `:`, `->`, `_`, `()`, `[]` i `INDENT`, a potem stuknij Formatuj, aby uzyskać czyste 4-spacjowe wcięcia PEP 8.

STEP 03 Run ▶ / unittest

Uruchamiaj skrypty startowe lub testy unittest offline

Wykonuj `main.py` lub zestawy testów `unittest` offline z pomiarem czasu co do milisekundy i klikalnymi śladami stosu.

STEP 04 Git Time Machine -> Push

Przejrzyj zunifikowane diffy, zatwierdź i wypchnij zmiany

Sprawdź zmiany linia po linii w Git Time Machine, przygotuj pliki do commita i wypchnij je czysto na GitHub, GitLab lub Bitbucket.

05 PYTANIA I ODPOWIEDZI

Często zadawane pytania

Pytania o układ `src/`, importy względne, `unittest` i integrację Git dla Pythona na Androidzie.

Co się stanie, gdy kliknę Uruchom podczas edycji modułu pomocniczego, np. `utils/helpers.py`?+
Jeśli `helpers.py` definiuje wyłącznie funkcje lub klasy bez kodu wykonywalnego na najwyższym poziomie, SuperCode automatycznie znajduje skrypt startowy projektu (`main.py`, `app.py`, `run.py`, `__main__.py` lub `src/main.py`) i uruchamia całą aplikację.
Czy SuperCode obsługuje składnię Pythona 3.12, taką jak `match/case` i aliasy `type`?+
Strukturalne `match/case` i `tomllib` działają offline w Pythonie 3.11+, a pliki używające składni generycznych aliasów `type` (PEP 695) automatycznie włączają obsługę Pythona 3.12.
Czy potrzebuję pliku `__init__.py` w każdym folderze, aby działały importy między folderami?+
Nie. SuperCode obsługuje niejawne pakiety przestrzeni nazw PEP 420 i czysto montuje katalog główny projektu bez wstrzykiwania niechcianych plików `__init__.py` do repozytorium.
Czy mogę sklonować prywatne repozytoria GitHub i uruchamiać ich testy Pythona offline?+
Tak. Sklonuj repo przez HTTPS + Personal Access Token w Visual Git, zainstaluj jednorazowo pakiety z `requirements.txt`, a następnie edytuj i uruchamiaj zestawy testów `unittest` całkowicie offline w dowolnym miejscu.
