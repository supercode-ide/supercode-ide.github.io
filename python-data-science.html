05 QUESTIONS & ANSWERS

Frequently Asked Questions

Questions about running NumPy, Pandas, Polars, and Matplotlib offline on Android phones and tablets.

Does NumPy and Pandas really run offline on my Android phone?+
Yes. Once the scientific runtime initializes and caches a package wheel (such as `numpy`, `pandas`, or `matplotlib`) on your device, all future runs execute 100% offline with zero internet required.
How do I view `matplotlib.pyplot` charts on Android?+
Save your chart with `plt.savefig('plot.png', dpi=180)` (or `.svg` / `.pdf`). SuperCode syncs the file directly into your active project directory and lets you open it immediately in the built-in high-resolution Image or PDF viewer.
Can my Pandas script read a `.csv` or `.sqlite` file stored in the same folder?+
Yes. Relative paths like `pd.read_csv('sales.csv')` or `sqlite3.connect('app.db')` resolve directly against your project workspace, and any modified or newly created files sync back when execution finishes.
Is Polars and DuckDB supported in addition to Pandas?+
Yes — both `polars` and `duckdb` (along with `pyarrow` and `fastparquet`) are supported for high-speed analytical queries on mobile.
