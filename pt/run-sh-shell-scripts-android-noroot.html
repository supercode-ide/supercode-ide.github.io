05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Dúvidas comuns sobre rodar scripts `.sh` sem root e corrigir `Permission denied` no Android.

Por que recebo `Permission denied` ao rodar um arquivo `.sh` da pasta Downloads do Android?+
Por segurança, o Android monta o armazenamento compartilhado do usuário (`/sdcard`, `Downloads`, `Documents`) com a flag `noexec` no sistema de arquivos, então nem `chmod +x` consegue tornar arquivos executáveis ali. O SuperCode executa os scripts de forma limpa no runtime nativo enquanto sincroniza sua pasta do projeto automaticamente.
O SuperCode exige um celular Android com root para executar shell scripts?+
Não. O SuperCode funciona de fábrica em celulares, dobráveis e tablets com Android 8.0+ padrão, sem root.
Como passo argumentos de linha de comando como `./deploy.sh --env staging`?+
Adicione `# @args --env staging` perto do topo do script (ou forneça entradas interativamente via `read -p`), e o SuperCode repassa esses parâmetros posicionais (`$1`, `$2`, `$@`) direto ao script ao executar.
Um script `.sh` pode criar novos arquivos ou pastas dentro do meu workspace?+
Sim. Quaisquer arquivos, logs ou pacotes criados em relação a `$PWD` durante a execução são sincronizados automaticamente de volta para o diretório ativo do projeto no Android.
