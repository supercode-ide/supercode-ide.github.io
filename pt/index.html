05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Respostas diretas sobre compiladores offline, abertura de arquivos gigantes, linguagens suportadas e fluxos Git/SFTP.

Quais linguagens de programação rodam offline no SuperCode IDE para Android?+
O SuperCode executa localmente no Android Python (3.11 e científico 3.12), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, PHP, HTML5/CSS3/WebAssembly, Lua 5.4 e scripts Shell Linux, com suporte opcional na nuvem para Kotlin, MySQL 8.0 e frameworks pesados de servidor.
O SuperCode consegue abrir arquivos de texto gigantes GB e dumps SQL sem travar?+
Sim. Arquivos maiores que 30 MB ativam automaticamente o Paginador via Streaming em Escala GB, fatiando arquivos de centenas de MB ou gigabytes em páginas no disco de 10 milhões de caracteres com salto imediato, detecção de 34 codificações e Substituição Global via Stream com Regex.
C e C++, ou SQL e Web/PHP, funcionam em ambientes dedicados e separados?+
Sim. C17 e C++20 possuem padrões, cabeçalhos e modelos próprios; o SQL tem seu próprio console de 9 modos e inspetor binário .db; e o Estúdio Web executa um servidor HTTP local real + PHP + PDO SQLite + WebAssembly com DevTools integradas.
O SuperCode inclui um cliente Git visual e editor remoto SFTP/FTPS embutido?+
Sim. Ele traz um Cliente Git Visual completo (clone via PAT, branches, diffs unificados na Máquina do Tempo e resolvedor visual de conflitos) mais um espaço remoto SFTP, FTPS (TLS 1.3) e FTP criptografado com AES-256 e salvamento atômico em 3 fases.
O SuperCode é otimizado tanto para celulares quanto para tablets Android?+
Sim. Em celulares, as barras ficam ao alcance do polegar com menu deslizante na borda direita e console dividido retrátil; em dobráveis e tablets, a barra acopla na vertical e o terminal abre lado a lado na proporção 55% / 45%.
