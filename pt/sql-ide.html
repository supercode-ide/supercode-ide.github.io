05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Dúvidas sobre prática de SQL offline, abertura de arquivos .db/.sqlite, importação CSV/JSON e sintaxe MySQL.

Consigo treinar consultas SQL offline sem configurar um servidor de banco de dados?+
Sim! Basta criar qualquer arquivo .sql e tocar em Executar para rodar múltiplas instruções CREATE, INSERT, JOIN, CTE e Window Functions 100% offline com tabelas Unicode alinhadas.
O SuperCode abre arquivos .db e .sqlite que já estão no meu celular?+
Sim. Tocar ou executar um arquivo .db, .sqlite, .sqlite3 ou .db3 exibe todas as tabelas, views, índices e esquemas, e qualquer script .sql na mesma pasta pode consultar esse banco diretamente.
Ele aceita sintaxe MySQL como AUTO_INCREMENT, SHOW TABLES, DESCRIBE ou Stored Procedures?+
Comandos e DDL comuns de MySQL/PostgreSQL (AUTO_INCREMENT, ENUM, SHOW TABLES, DESCRIBE, ILIKE) rodam localmente offline, enquanto Stored Procedures e Triggers exclusivos do MySQL 8.0 são roteados automaticamente para o Cloud MySQL 8.0.
Como exporto o resultado de uma consulta SQL para CSV, Markdown ou JSON?+
Adicione `.mode csv` (ou `.mode markdown` / `.mode json`) e `.once saida.csv` antes do seu SELECT — o SuperCode grava o arquivo exportado diretamente na pasta do seu projeto.
