05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Perguntas frequentes sobre recursos do Java 17, POO multiarquivo, bibliotecas .jar externas e leitura offline com Scanner.

Qual versão do Java o SuperCode compila offline no Android?+
O SuperCode compila e roda Java 17 offline — incluindo records, sealed classes, expressões switch, pattern matching para instanceof, text blocks e Streams — com roteamento automático para o Cloud Java em recursos do Java 21+.
Consigo rodar um projeto Java com várias classes e pacotes?+
Sim. O SuperCode resolve todos os arquivos .java nas pastas do projeto e abas abertas, identifica automaticamente a classe com main() e sincroniza qualquer arquivo gravado de volta na sua pasta.
Posso conectar o Java a um banco SQLite local ou incluir arquivos .jar externos?+
Sim! Um driver JDBC offline jdbc:sqlite:... já vem integrado, e qualquer biblioteca .jar compatível colocada na pasta libs/ do projeto entra automaticamente no classpath.
O Scanner(System.in) funciona de modo interativo?+
Sim. Seu programa aguarda normalmente sempre que Scanner ou BufferedReader pedem dados, permitindo digitar múltiplas linhas no terminal dividido.
