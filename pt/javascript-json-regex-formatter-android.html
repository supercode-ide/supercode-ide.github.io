05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Respostas sobre validação JSON/JSONC offline, testes de regex ES2024, logs JSON grandes e scripts de API.

É seguro formatar JSON de produção confidencial ou configs de API no SuperCode?+
Sim. Tanto o formatador JSON/JSONC quanto o worker JavaScript ES2024 do SuperCode rodam 100% localmente no seu dispositivo Android — seus payloads JSON nunca tocam um servidor externo de formatação.
O formatador suporta arquivos JSONC com comentários // como tsconfig.json ou settings.json?+
Sim. O CodeFormatEngine reconhece comentários JSONC junto ao JSON padrão, formatando objetos e arrays aninhados de forma limpa sem remover seus comentários.
E se uma regex complexa causar backtracking catastrófico durante o teste?+
Todos os scripts de regex JavaScript rodam dentro de uma thread worker isolada fora da UI, permitindo interromper uma regex lenta ou descontrolada imediatamente sem congelar o editor.
O SuperCode consegue abrir e pesquisar um arquivo de log JSON ou NDJSON de 500 MB no celular?+
Sim. Arquivos acima de 30 MB ativam perfeitamente o Paginador GB Streaming em disco do SuperCode, com rolagem a 120Hz e Substituição Regex em Stream Global.
