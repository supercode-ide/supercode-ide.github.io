05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Dúvidas comuns sobre instalação de pacotes PyPI, wheels .whl offline e requirements.txt no Android.

Posso colar um comando `pip install requests beautifulsoup4` completo no SuperCode?+
Sim. O parser do PIP remove automaticamente prefixos `pip install`, `pip3 install` ou `python -m pip install`, ignora flags de CLI não suportadas com segurança e enfileira todos os pacotes com suas restrições PEP 440.
Como instalo pacotes Python no Android sem conexão à internet?+
Baixe antes o arquivo `.whl` em Python puro (como `*-py3-none-any.whl`), `.tar.gz` ou `.zip` no celular, abra o Gerenciador de Pacotes PIP do SuperCode e toque em Arquivo Local para instalar direto da pasta Downloads.
Por que não preciso rodar `pip install numpy` ou `matplotlib` manualmente?+
Bibliotecas com extensões nativas pesadas em C/Fortran como NumPy, Pandas, SciPy, Matplotlib e Scikit-Learn já vêm pré-adaptadas no runtime científico do SuperCode. Basta escrever `import numpy as np` no script e tocar em Executar.
Os pacotes PIP instalados continuam no celular após fechar o app?+
Sim. Cada pacote instalado fica salvo de forma persistente no armazenamento local `python_site_packages` do SuperCode, permitindo rodar seus scripts offline a qualquer momento sem reinstalar.
