05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Respostas sobre suporte offline ao Java 17, migração do Jvdroid e recursos do Java 21+ no Android.

O SuperCode realmente compila records e sealed classes do Java 17 sem internet?+
Sim. Após o SDK leve Java 17 offline inicializar na primeira execução, `record`, `sealed` / `permits`, expressões `switch ->`, pattern matching `instanceof`, text blocks (`\"\"\"`) e `Stream.toList()` compilam e executam 100% offline em modo avião.
Como o SuperCode se compara como alternativa moderna a apps de Java 8 ou Java 11?+
Apps antigos de Java para Android costumam falhar em trabalhos acadêmicos modernos e soluções do LeetCode que usam tuplas `record`, `Stream.toList()` ou switch expressions. O SuperCode suporta Java 17 LTS completo offline, além de fallback automático para Cloud Java 21+, Git Visual e SQLite JDBC integrado.
Posso usar `CompletableFuture`, `Optional` e `java.time` offline?+
Sim. Toda a biblioteca padrão principal — incluindo `java.util.stream`, `java.util.concurrent.CompletableFuture`, `java.time.*`, `java.math.BigDecimal` e `java.nio.file` — roda nativamente offline.
Como executo virtual threads do Java 21 no meu celular Android?+
Basta escrever `Thread.ofVirtual()` ou `Executors.newVirtualThreadPerTaskExecutor()` (ou adicionar `// @cloud` no topo do arquivo) e tocar em Executar. O SuperCode empacota automaticamente as classes do seu projeto para o Cloud Java 21+ e transmite a saída para o console.
