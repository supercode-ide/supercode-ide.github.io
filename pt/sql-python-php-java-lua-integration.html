05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Perguntas frequentes sobre compartilhamento de arquivos `.db` entre linguagens e edição de dumps `.sql` gigantes no Android.

Preciso baixar algum arquivo `.jar` para usar `jdbc:sqlite:app.db` em Java 17?+
Não! O SuperCode já inclui o driver SQLite JDBC diretamente no classpath offline do Java 17 — basta escrever `DriverManager.getConnection("jdbc:sqlite:app.db")` e tocar em Executar.
Python, PHP, Java e Lua conseguem mesmo ler e gravar exatamente no mesmo arquivo `app.db`?+
Sim. Desde que seus arquivos `.sql`, `.py`, `.php`, `.java` e `.lua` estejam na mesma pasta do workspace (ou apontem para o mesmo caminho relativo), todos leem e executam transações ACID no mesmo arquivo `app.db` em disco.
Como usar o SQLite dentro de scripts Lua 5.4 no SuperCode?+
Chame `local sqlite3 = require('lsqlite3')` e `local db = sqlite3.open('app.db')`. O módulo `lsqlite3` já vem embutido no runtime offline Lua 5.4 do SuperCode com inicialização em sub-milissegundo.
O SuperCode consegue abrir um dump de banco `.sql` de 1 GB+ sem travar o celular?+
Sim. O Editor de Arquivos Grandes do SuperCode faz streaming de arquivos `.sql`, `.csv` e `.log` direto de páginas em disco em vez de carregar tudo na RAM — com busca/substituição por regex e detecção de codificação.
