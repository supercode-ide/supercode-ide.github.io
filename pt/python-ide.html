05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Respostas sobre execução offline de Python, instalação de bibliotecas pip/.whl, NumPy/Matplotlib e imports multiarquivo.

Posso escrever e rodar código Python no Android totalmente sem internet?+
Sim. Scripts Python 3.11 multiarquivo, módulos da biblioteca padrão, pacotes PIP/.whl instalados localmente e bibliotecas científicas do Python 3.12 em cache (NumPy, Pandas, Matplotlib, SciPy, scikit-learn) rodam 100% offline.
Como instalo bibliotecas externas como requests, bs4 ou arquivos .whl offline?+
Abra o Gerenciador Visual de Pacotes PIP (ou apenas rode seu script e deixe o Auto-PIP detectar os imports ausentes). Você pode instalar direto do PyPI, tocar no chip requirements.txt detectado ou importar pacotes .whl, .tar.gz e .zip do armazenamento local.
Para onde vão os gráficos do Matplotlib ou arquivos criados com open('dados.csv', 'w')?+
Toda imagem, PDF, CSV ou JSON gravado pelo seu script é sincronizado automaticamente na pasta ativa do projeto e pode ser aberto na hora no visualizador de imagens ou editor do SuperCode.
O SuperCode suporta laços interativos com input() no Python?+
Sim. Sempre que seu script chama input(), o console em tela dividida destaca a barra de entrada para você digitar e enviar respostas interativamente em tempo real.
