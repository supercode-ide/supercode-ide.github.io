05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Dúvidas comuns sobre layouts multipacotes, adição de bibliotecas .jar externas e resolução de main().

Como adiciono uma biblioteca `.jar` externa como Gson ou Commons Lang no SuperCode?+
Crie uma pasta chamada `libs` (ou `lib`) na raiz do seu projeto Java e copie o arquivo `.jar` para dentro dela. O SuperCode adiciona automaticamente todos os arquivos `.jar` em `libs/` (até 30 MB) ao classpath de compilação e execução — sem precisar de scripts de build.
O que acontece se eu pressionar Executar enquanto edito uma classe Java que não tem `main()`?+
O árbitro de ponto de entrada do SuperCode analisa as classes compiladas do projeto, seleciona automaticamente a classe principal que contém `main()` e a executa — evitando que você fique alternando entre abas o tempo todo.
Preciso usar `src/main/java` ou pastas simples com vários arquivos também funcionam?+
Ambos funcionam perfeitamente! Você pode colocar dois arquivos `.java` lado a lado em uma pasta simples sem declaração `package`, organizar subpastas `com.example.*` diretamente ou usar uma estrutura completa `src/main/java` + `resources/` + `libs/`.
Quais arquivos `.jar` funcionam offline no Android?+
Qualquer biblioteca `.jar` Java pura padrão direcionada ao Java 8, 11 ou 17 (como `gson`, `org.json`, `commons-lang3`, `commons-csv` ou bibliotecas de correção da faculdade) funciona 100% offline. Jars de GUI desktop que exigem janelas AWT/Swing não se destinam a consoles móveis.
