05 PERGUNTAS E RESPOSTAS

Perguntas Frequentes (FAQ)

Dúvidas sobre layouts `src/`, imports relativos, `unittest` e integração Git para Python no Android.

O que acontece se eu tocar em Executar enquanto edito um módulo auxiliar como `utils/helpers.py`?+
Se `helpers.py` só define funções ou classes sem código de execução no topo, o SuperCode localiza automaticamente o script de entrada do projeto (`main.py`, `app.py`, `run.py`, `__main__.py` ou `src/main.py`) e roda a aplicação inteira.
O SuperCode suporta sintaxe do Python 3.12 como `match/case` e aliases `type`?+
`match/case` estrutural e `tomllib` funcionam offline no Python 3.11+, e arquivos que usam sintaxe genérica de alias `type` da PEP 695 ativam automaticamente o suporte ao Python 3.12.
Preciso de `__init__.py` em toda pasta para imports multipasta funcionarem?+
Não. O SuperCode respeita pacotes de namespace implícitos da PEP 420 e monta a raiz do projeto de forma limpa sem injetar arquivos `__init__.py` indesejados no repositório.
Posso clonar repositórios privados do GitHub e rodar os testes Python deles offline?+
Sim. Clone via HTTPS + Personal Access Token no Git Visual, instale `requirements.txt` em lote uma única vez e edite/execute suítes `unittest` totalmente offline em qualquer lugar.
