05 FRÅGOR & SVAR

Vanliga frågor

Vanliga frågor om att använda cjson, lsqlite3, LuaFileSystem och luarocks-moduler på Android.

Behöver jag installera luarocks eller en C-kompilator för att använda `cjson`, `lsqlite3` eller `lfs`?+
Nej. Alla 11+ kärntilläggsalias (`cjson`, `dkjson`, `lsqlite3`, `sqlite3`, `lfs`, `crypto`, `sha2`, `md5`, `base64`, `regex`, `socket.http` och `inspect`) är förintegrerade direkt i SuperCode och fungerar omedelbart via `require()`.
Kan `lsqlite3` dela samma `.db`-fil med Python, PHP eller SuperCodes SQL-IDE?+
Ja! En `.db`-databas som skapats av `lsqlite3` i din projektmapp är en vanlig binär SQLite 3-fil som kan frågas direkt i SuperCodes SQL Studio, Python `sqlite3`, PHP `PDO` eller Java JDBC.
Stöder `cjson` formaterad utskrift (pretty-printing) för konfigurationsfiler?+
Ja. Utöver standardfunktionerna `cjson.encode()` och `cjson.decode()` erbjuder SuperCode `cjson.encode_pretty()` så att du kan granska eller spara snyggt indenterad JSON offline.
Vad händer om mitt skript kräver `lpeg` eller `luv`?+
När du är ansluten till internet upptäcker SuperCode specialiserade nativa C-rock-importer som `lpeg` eller `luv` och dirigerar automatiskt ditt flerfilsprojekt till sin molnbaserade Lua-miljö.
