05 FRÅGOR & SVAR

Vanliga frågor

Svar om offline-stöd för Java 17, Jvdroid-migrering och Java 21+-funktioner på Android.

Kompilerar SuperCode verkligen Java 17 records och sealed classes utan internet?+
Ja. När det lätta offline-SDK:et för Java 17 har initierats vid första starten kompileras och körs `record`, `sealed` / `permits`, `switch ->`-uttryck, `instanceof`-mönstermatchning, textblock (`"""`) och `Stream.toList()` 100 % offline i flygplansläge.
Hur står sig SuperCode som modernt alternativ till Java 8- eller Java 11-mobilappar?+
Äldre Java-appar för Android misslyckas ofta med moderna universitetsuppgifter och LeetCode-lösningar som använder `record`-tupler, `Stream.toList()` eller switch-uttryck. SuperCode stöder fullständig LTS Java 17 offline plus automatisk Cloud Java 21+-fallback, Visual Git och inbyggd SQLite JDBC.
Kan jag använda `CompletableFuture`, `Optional` och `java.time` offline?+
Ja. Hela standardbiblioteket — inklusive `java.util.stream`, `java.util.concurrent.CompletableFuture`, `java.time.*`, `java.math.BigDecimal` och `java.nio.file` — körs nativt offline.
Hur kör jag Java 21 virtuella trådar på min Android-telefon?+
Skriv helt enkelt `Thread.ofVirtual()` eller `Executors.newVirtualThreadPerTaskExecutor()` (eller lägg till `// @cloud` överst i filen) och tryck på Kör. SuperCode paketerar automatiskt dina projektklasser till Cloud Java 21+ och strömmar utdata tillbaka till din konsol.
