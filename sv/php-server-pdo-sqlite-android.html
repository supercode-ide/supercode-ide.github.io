05 FRÅGOR & SVAR

Vanliga frågor

Svar på vanliga frågor om att köra PHP 8.2, PDO SQLite, sessioner och filuppladdningar offline på Android.

Kör SuperCode PHP 8.2 helt offline utan internet?+
Ja. SuperCodes PHP 8.2-motor och PDO SQLite-databasdrivrutin körs 100 % lokalt på din Android-enhet — du kan bygga och testa flersidiga PHP-webbplatser, inloggningsformulär och JSON-API:er i flygplansläge.
Varför välja SuperCode framför KSWEB eller att köra `php -S` i en terminalapp?+
Separata server-daemons kräver manuella virtual-host-sökvägar, håller bakgrundstjänster igång och tvingar dig att växla mellan tre appar (editor, server, webbläsare). SuperCode förenar AST PHP-redigering, automatisk HTTP-routing från projektroten, Web DevTools, SQL Studio och SFTP-publicering i en enda lättviktig IDE.
Kan frontend JavaScript anropa mina lokala `.php`-filer med `fetch()`?+
Ja! Eftersom din arbetsyta serveras över ett riktigt `localhost` HTTP/1.1-ursprung fungerar `await fetch('/api/tasks.php', { method: 'POST', ... })` sömlöst med JSON-headers, cookies och DevTools Network-tidtagning.
Kan jag inspektera `.db`-filen för SQLite som skapats av PHP `new PDO('sqlite:app.db')`?+
Omedelbart. Tryck på `app.db` i SuperCodes filutforskare för att granska tabeller, schema och rader i Unicode-ram eller Markdown-format inuti SQL Studio.
