05 FRÅGOR & SVAR

Vanliga frågor

Frågor om att köra MySQL- och PostgreSQL-syntax offline jämfört med lagrade procedurer i Cloud MySQL 8.0.

Kan jag köra MySQL-skript med `CREATE TABLE ... AUTO_INCREMENT ENGINE=InnoDB` utan internet?+
Ja! SuperCodes offline-kompatibilitetslager för SQL översätter transparent vanliga MySQL- och PostgreSQL-DDL-satser (`AUTO_INCREMENT`, `SERIAL`, `BIGSERIAL`, `UNSIGNED`, `ENUM`, `ENGINE=InnoDB`, `CHARSET`) så att ditt schema och dina frågor körs offline.
Fungerar `SHOW TABLES`, `DESCRIBE table_name` och `TRUNCATE TABLE` offline?+
Ja. Du behöver inte memorera `.schema` eller `PRAGMA table_info(...)` när du följer en MySQL-kurs — `SHOW TABLES`, `DESCRIBE` / `DESC`, `SHOW CREATE TABLE` och `TRUNCATE TABLE` fungerar direkt offline.
Hur körs lagrade MySQL-procedurer (`CREATE PROCEDURE` och `DELIMITER //`) på Android?+
Eftersom procedurella `BEGIN ... END`-rutiner och `DELIMITER` kräver en procedurell motor på servernivå dirigerar SuperCode dessa skript sömlöst till Cloud MySQL 8.0 och strömmar dina `CALL`-resultatuppsättningar direkt tillbaka till konsolen.
Vilka extra MySQL- och PostgreSQL-funktioner finns tillgängliga offline?+
Över 50 skalärfunktioner är inbyggda offline, inklusive `DATE_FORMAT`, `DATEDIFF`, `NOW`, `CURDATE`, `CONCAT_WS`, `LPAD`, `RPAD`, `SUBSTRING_INDEX`, `ILIKE`, `REGEXP_REPLACE`, `UUID`, `MD5`, `SHA256`, `MEDIAN` och `STDDEV`.
