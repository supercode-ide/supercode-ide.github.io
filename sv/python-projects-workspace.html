05 FRÅGOR & SVAR

Vanliga frågor

Frågor om `src/`-strukturer, relativa importer, `unittest` och Git-integration för Python på Android.

Vad händer om jag trycker Kör medan jag redigerar en hjälpmodul som `utils/helpers.py`?+
Om `helpers.py` bara definierar funktioner eller klasser utan körbar toppnivåkod letar SuperCode automatiskt upp projektets startskript (`main.py`, `app.py`, `run.py`, `__main__.py` eller `src/main.py`) och kör hela applikationen.
Stöder SuperCode Python 3.12-syntax som `match/case` och `type`-alias?+
Strukturell `match/case` och `tomllib` fungerar offline i Python 3.11+, och filer som använder PEP 695 generisk `type`-aliassyntax aktiverar automatiskt stöd för Python 3.12.
Behöver jag `__init__.py` i varje mapp för att importer mellan mappar ska fungera?+
Nej. SuperCode respekterar PEP 420 implicita namnrymdspaket och monterar din projektrot rent utan att injicera oönskade `__init__.py`-filer i ditt repo.
Kan jag klona privata GitHub-repon och köra deras Python-tester offline?+
Ja. Klona via HTTPS + Personal Access Token i Visuell Git, batchinstallera `requirements.txt` en gång och redigera/kör `unittest`-sviter helt offline var som helst.
