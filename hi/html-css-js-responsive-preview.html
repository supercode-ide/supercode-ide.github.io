02.1

असली लोकल HTTP/1.1 सर्वर (65+ MIME टाइप्स)

CORS 'origin null' एरर को अलविदा कहें। असली localhost HTTP/1.1 ऑरिजिन पर सर्व करने से नेटिव <script type="module"> इम्पोर्ट्स, fetch('./data.json'), localStorage, IndexedDB, SVG स्प्राइट्स और .woff2 वेब फ़ॉन्ट्स बिना रुकावट चलते हैं।

असली Localhost ऑरिजिन · 65+ MIME टाइप्स · ज़ीरो CORS ब्लॉक
02.2

डायनामिक-आइलैंड 3-व्यू पोर्ट रिस्पॉन्सिव स्विचर

तीन अलग डिवाइस रखे बिना जाँचें कि आपकी CSS Grid, Flexbox और @media क्वेरीज़ हर स्क्रीन पर कैसी दिखती हैं। ड्रैगेबल डायनामिक आइलैंड पिल पर टैप करें और Mobile, Tablet (768dp) व चौड़े Desktop लेआउट में लाइव स्विच करें।

Mobile · Tablet (768dp) · Desktop ब्रेकपॉइंट्स
02.3

05 सवाल और जवाब

अक्सर पूछे जाने वाले सवाल (FAQ)

Android पर HTML5/CSS3/JS एडिटिंग, ES Modules और रिस्पॉन्सिव व्यू पोर्ट प्रीव्यू से जुड़े अक्सर पूछे जाने वाले सवाल।

अन्य HTML एडिटर ऐप्स में मेरा `<script type="module">` या `fetch('./data.json')` क्यों फेल हो जाता था?+
कड़े CORS सुरक्षा नियमों के कारण ब्राउज़र `file://` URL पर ES Modules और `fetch()` को ब्लॉक कर देते हैं। SuperCode आपके प्रोजेक्ट को सही MIME हेडर्स के साथ असली `localhost` HTTP/1.1 ऑरिजिन पर सर्व करता है, जिससे मॉडर्न JS मॉड्यूल्स और JSON फ़ेच ऑफ़लाइन भी नेटिवली काम करते हैं।
मैं स्मार्टफोन स्क्रीन पर Tablet और Desktop CSS मीडिया क्वेरीज़ का प्रीव्यू कैसे देख सकता हूँ?+
SuperCode के लाइव Web Preview में, फ्लोटिंग डायनामिक आइलैंड पर व्यू पोर्ट आइकन टैप करें और तुरंत Mobile, Tablet (`768dp`) और चौड़े Desktop व्यू पोर्ट्स में स्विच करें — जिससे आपके `@media` नियम बिल्कुल सटीक ट्रिगर होते हैं।
क्या 1-टैप फ़ॉर्मेटर `<style>` के अंदर CSS और `<script>` के अंदर JS को भी फ़ॉर्मेट करता है?+
हाँ। SuperCode का रिकर्सिव HTML फ़ॉर्मेटर `.html` फ़ाइलों के अंदर मौजूद `<style>` और `<script>` ब्लॉक्स को पार्स करता है और एक ही टैप में तीनों भाषाओं को साफ़-सुथरा इंडेंट कर देता है।
क्या मैं लोकल `.mp4` वीडियो, `.woff2` फ़ॉन्ट्स और `.glb` 3D मॉडल ऑफ़लाइन उपयोग कर सकता हूँ?+
हाँ। लोकली 65 से ज़्यादा MIME टाइप्स प्री-कॉन्फ़िगर हैं, जिनमें `font/woff2`, `model/gltf-binary`, `image/svg+xml` और स्मूथ `<video>` व `<audio>` टाइमलाइन सीकिंग के लिए HTTP `206 Partial Content` बाइट-रेंज स्ट्रीमिंग शामिल हैं।
