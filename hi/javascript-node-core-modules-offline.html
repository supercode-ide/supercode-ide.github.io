05 सवाल और जवाब

अक्सर पूछे जाने वाले सवाल (FAQ)

Android पर सपोर्टेड `node:*` मॉड्यूल्स, `fs` फ़ाइल पाथ्स, `package.json` और npm पैकेजेज़ से जुड़े सवाल।

SuperCode में कौन से Node.js कोर मॉड्यूल्स 100% ऑफ़लाइन काम करते हैं?+
29 से अधिक स्टैंडर्ड मॉड्यूल्स पूरी तरह ऑफ़लाइन चलते हैं, जिनमें `fs`, `fs/promises`, `path`, `path/posix`, `buffer`, `events`, `stream`, `stream/promises`, `stream/web`, `zlib`, `crypto`, `readline`, `util`, `assert`, `url`, `querystring`, `string_decoder`, `timers`, `timers/promises`, `perf_hooks`, `os`, `process` और `console` शामिल हैं।
क्या `fs.writeFileSync('out.json', data)` मेरे Android फ़ोल्डर में असली फ़ाइल सेव करता है?+
हाँ! फ़ाइल सिस्टम ऑपरेशंस सीधे आपके खुले प्रोजेक्ट फ़ोल्डर (अनसेव्ड एडिटर टैब्स सहित) से पढ़ते हैं और हर बनाई या बदली गई फ़ाइल को सीधे आपकी Android डायरेक्टरी में सिंक्रोनाइज़ करते हैं।
क्या मैं `node:fs` प्रीफ़िक्स और बेयर `require('fs')` इम्पोर्ट्स दोनों का उपयोग कर सकता हूँ?+
हाँ। आधुनिक `import fs from 'node:fs/promises'` ES Module सिंटैक्स और क्लासिक `const fs = require('fs')` CommonJS कॉल्स दोनों बिल्कुल एक ही बिल्ट-इन ऑफ़लाइन इम्प्लीमेंटेशन पर रिज़ॉल्व होते हैं।
अगर मेरी स्क्रिप्ट `node:http`, `net` या `worker_threads` इम्पोर्ट करती है तो क्या होता है?+
OS सर्वर सॉकेट्स या सबप्रोसेस (`http`, `https`, `net`, `tls`, `dns`, `child_process`, `worker_threads`) वाले मॉड्यूल्स को ऑटोमैटिकली पहचान कर SuperCode के मल्टी-फ़ाइल क्लाउड Node.js बंडलर के ज़रिए चलाया जाता है — जबकि SuperCode के Web IDE में फ़ुल-स्टैक लोकल HTTP प्रीव्यू भी उपलब्ध हैं।
