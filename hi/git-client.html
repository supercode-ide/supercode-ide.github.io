02 प्रमुख विशेषताएं

हर ज़रूरी Git ऑपरेशन — ख़ास मोबाइल टच के लिए इंजीनियर किया गया

रिपॉजिटरी लॉक सुरक्षा, खुले टैब्स के ऑटो-सेव और Detached HEAD रेस्क्यू बैनर से सुरक्षित ताकि मोबाइल पर वर्ज़न कंट्रोल पूरी तरह तनाव-मुक्त रहे।

02.1

स्मार्ट Git डैशबोर्ड और मल्टी-रेपो स्विचर

अपनी माउंट की गई रिपॉजिटरी, सक्रिय ब्रांच, शॉर्ट कमिट हैश, लाइव ↑ Ahead / ↓ Behind काउंटर और Modified / Added / Deleted / Conflicting फ़ाइल संख्या एक नज़र में देखें — और एक टैप में रेपो बदलें।

मल्टी-रेपो स्विचर · ↑Ahead ↓Behind · मौजूदा रेपो माउंट
02.2

HTTPS + PAT क्लोन और एन्क्रिप्टेड टोकन स्टोरेज

Personal Access Tokens (PAT) की मदद से GitHub, GitLab, Gitee, Bitbucket या सेल्फ़-होस्टेड Git सर्वर से पब्लिक व प्राइवेट रिपॉजिटरी क्लोन करें। टारगेट फ़ोल्डर नाम अपने-आप भरता है और टोकन भविष्य के Push के लिए सुरक्षित सेव रहता है।

GitHub / GitLab / Gitee PAT · लाइव क्लोन प्रोग्रेस
02.3

अनसेव्ड-टैब ऑटो-फ़्लश, बदलाव प्रीव्यू और ऑथर कॉन्फ़िग

कमिट करने से पहले SuperCode किसी भी बदले हुए खुले टैब को स्वतः डिस्क पर सेव करता है ताकि कोई बदलाव न छूटे, 80 फ़ाइलों तक [M]/[A]/[U]/[D] बैज दिखाता है और कस्टम Author Name व Email सेट करने देता है।

शून्य छूटे बदलाव · कस्टम Author · ऑटो Upstream बाइंड
02.4

ऑटो-स्टैश और कर्सर-सुरक्षित रीलोड वाला स्मार्ट Pull

Pull करते समय लोकल अनकमिटेड बदलाव मौजूद हैं? SuperCode बिना नकली कमिट बनाए उन्हें स्वतः स्टैश करता है, रिमोट अपडेट लाता है, आपके बदलाव दोबारा लागू करता है और खुले टैब्स को सटीक उसी कर्सर लाइन व कॉलम पर रीलोड करता है!

ज़ीरो-नॉइज़ ऑटो-स्टैश · इन-प्लेस टैब हॉट-रीलोड

03 स्टेप-बाय-स्टेप उपयोग गाइड

संपूर्ण 6-स्टेप गाइड: SuperCode IDE में Git कैसे चलाएं

अपने फ़ोन या टैबलेट से रिपॉजिटरी क्लोन, ब्रांच, Diff, मर्ज और GitHub पुश करने का सटीक तरीका।

STEP 01 Menu -> Git Controls -> Clone

रिमोट रिपॉजिटरी क्लोन करें या लोकल प्रोजेक्ट माउंट करें

अपना HTTPS URL (जैसे https://github.com/user/repo.git) और वैकल्पिक PAT टोकन पेस्ट कर CLONE दबाएं — या पहले से .git वाले फ़ोल्डर के लिए Mount Existing Repo चुनें।

STEP 02 Time Machine -> Branch ▾

ब्रांच बदलें या नई फ़ीचर ब्रांच बनाएं

Git Time Machine खोलें और ऊपरी ब्रांच सेलेक्टर पर टैप करके ब्रांच स्विच करें या ऑटो नेम-वैलिडेशन के साथ + Create New Branch… (जैसे feature/mobile-ui) बनाएं।

STEP 03 Editor Tabs -> Save / Edit

पूर्ण IDE इंटेलिजेंस के साथ मल्टी-फ़ाइल कोड लिखें

ऑफ़लाइन कोड एडिट, फ़ॉर्मेट और टेस्ट करें। यदि आप किसी खुले टैब को सेव करना भूल भी जाएं, तो Git ऑपरेशन चलने से पहले उसे अपने-आप डिस्क पर सेव कर देता है।

STEP 04 Git Dashboard -> Pull

टीम के रिमोट अपडेट्स सुरक्षित रूप से Pull करें

पुश करने से पहले Pull दबाएं। अनकमिटेड लोकल बदलाव अपने-आप स्टैश होकर वापस जुड़ जाते हैं और खुले टैब्स बिना कर्सर की जगह खोए रिफ़्रेश हो जाते हैं।

STEP 05 Open Conflict Resolver

मर्ज टकराव को विज़ुअल कार्ड्स से सुलझाएं

यदि एक ही लाइन पर बदलाव टकराते हैं, तो Open Conflict Resolver टैप करें, Local बनाम Remote ब्लॉक्स की तुलना करें, Keep Current / Incoming / Both चुनें और Apply Resolutions दबाएं।

STEP 06 Commit & Push

बदली फ़ाइलें जांचें, कमिट मैसेज लिखें और Push करें

Pending Changes सूची में [M]/[A]/[D] बैज जांचें, अपना Author नाम व कमिट मैसेज कन्फ़र्म करें, और स्टेज, कमिट व origin पर पुश करने के लिए COMMIT दबाएं।

05 सवाल और जवाब

अक्सर पूछे जाने वाले सवाल (FAQ)

GitHub Personal Access Tokens, प्राइवेट रिपॉजिटरी, मर्ज कॉन्फ़्लिक्ट और कमिट इतिहास से जुड़े व्यावहारिक जवाब।

प्राइवेट GitHub, GitLab या Gitee रिपॉजिटरी से कैसे लॉगिन करें?+
GitHub/GitLab/Gitee पर repo परमिशन वाला HTTPS Personal Access Token (PAT) बनाएं और Clone, Commit & Push या Pull के समय Token फ़ील्ड में पेस्ट करें। SuperCode इसे सुरक्षित सेव रखता है ताकि हर बार दोबारा न डालना पड़े।
अगर खुले अनसेव्ड टैब या अनकमिटेड बदलाव रहते हुए मैं Pull दबा दूं तो क्या होगा?+
SuperCode पहले अनसेव्ड टैब्स को डिस्क पर सेव करता है, आपके ट्रैक किए गए अनकमिटेड बदलावों को स्वतः स्टैश करता है, नवीनतम रिमोट कमिट्स Pull करता है, आपके काम को वापस जोड़ता है और खुले टैब्स को सटीक उसी लाइन पर रीलोड कर देता है।
पुराने कमिट में हुए बदलाव कैसे देखें या पुरानी स्थिति पर वापस कैसे जाएं?+
Git Dashboard से Git Time Machine खोलें और किसी भी कमिट पर टैप करें। कलर-कोडेड बदलाव देखने के लिए View Code Changes (Commit Diff) चुनें, स्नैपशॉट जांचने के लिए Checkout (View Only) चुनें, या ब्रांच पीछे ले जाने के लिए Hard Reset चुनें।
क्या इंटरनेट न होने पर भी मैं ऑफ़लाइन कमिट कर सकता हूं?+
जी हां! फ़ाइल स्टेजिंग, लोकल कमिट्स, नई ब्रांच बनाना, कमिट इतिहास देखना, यूनिफ़ाइड Diff और मर्ज कॉन्फ़्लिक्ट समाधान सब कुछ ऑफ़लाइन काम करता है; इंटरनेट आने पर बस Push कर दें।
