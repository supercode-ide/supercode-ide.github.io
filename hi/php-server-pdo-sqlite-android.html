02 प्रमुख विशेषताएं

फ़ोन पर असली डायनेमिक PHP बैकएंड्स बनाने के लिए ज़रूरी हर चीज़

यूनिवर्सिटी वेब कोर्सवर्क और REST API प्रोटोटाइपिंग से लेकर पूरे CRUD एडमिन पैनल तक — एयरप्लेन मोड में भी काम करने के लिए डिज़ाइन किया गया।

02.1

आधुनिक PHP 8.2 सिंटैक्स और 32-लेवल मल्टी-फ़ाइल इनक्लूड्स

PHP 8.2 match एक्सप्रेशंस, ऐरो फ़ंक्शंस (fn() =>), कंस्ट्रक्टर प्रॉपर्टी प्रमोशन, नेमस्पेस और 32 लेवल गहरे नेस्टेड include, require व require_once हायरार्कीज़ के साथ क्लीन बैकएंड आर्किटेक्चर लिखें।

PHP 8.2 · match · fn() => · डेप्थ-32 require_once
02.2

बिल्ट-इन PDO('sqlite:app.db') और ACID ट्रांज़ैक्शंस

new PDO('sqlite:app.db') के साथ PHP स्क्रिप्ट्स को सीधे लोकल SQLite डेटाबेस से जोड़ें — SQL इंजेक्शन से बचाव के लिए ? और :named प्रिपेयर्ड स्टेटमेंट्स, PDO::FETCH_ASSOC और beginTransaction() / commit() / rollBack() के पूरे सपोर्ट के साथ।

ज़ीरो php.ini एडिट्स · प्रिपेयर्ड स्टेटमेंट्स · ACID
02.3

पर्सिस्टेंट $_SESSION, $_COOKIE और Bcrypt ऑथेंटिकेशन

ऑफ़लाइन असली लॉगिन, शॉपिंग कार्ट और CSRF-प्रोटेक्टेड फ़्लो बनाएं। SuperCode पेज रीडायरेक्ट्स (header('Location: ...')) के बीच $_SESSION और $_COOKIE स्टेट सेव रखता है और इसमें नेटिव password_hash() व password_verify() शामिल हैं।

session_start() · password_hash() · HTTP रीडायरेक्ट्स
02.4

$_GET, $_POST, JSON REST APIs और कस्टम हेडर्स

फ्रंटएंड fetch() क्लाइंट्स के लिए कस्टम HTTP स्टेटस कोड्स और header('Content-Type: application/json') रिस्पॉन्स भेजते हुए URL क्वेरी पैरामीटर्स, urlencoded HTML फ़ॉर्म्स और रॉ php://input JSON पेलोड्स हैंडल करें।

$_GET / $_POST · php://input · JSON REST एंडपॉइंट्स
02.5

24 MB तक के मल्टीपार्ट $_FILES अपलोड्स

अपने Android कैमरा या फ़ाइल पिकर से <input type="file"> फ़ॉर्म्स टेस्ट करें। $_FILES के अंदर MIME मेटाडेटा वैलिडेट करें और move_uploaded_file() के ज़रिए 24 MB तक की इमेज या डॉक्यूमेंट्स सीधे अपने वर्कस्पेस में सेव करें।

multipart/form-data · कैमरा/स्टोरेज · 24 MB लिमिट
02.6

समृद्ध कोर एक्सटेंशंस: mbstring, PCRE और JSON

mb_strlen() और mb_substr() से इंटरनेशनल UTF-8 स्ट्रिंग्स प्रोसेस करें, preg_match() व preg_replace() से इनपुट वैलिडेट करें, टाइमस्टैम्प फ़ॉर्मेट करें और बिना बैकग्राउंड डीमन बैटरी ड्रेन के मल्टी-फ़ाइल ऐप्स चलाएं।

mbstring · preg_* · json_encode · तुरंत स्टार्टअप

अक्सर पूछे जाने वाले सवाल (FAQ)

Android पर ऑफ़लाइन PHP 8.2, PDO SQLite, सेशंस और फ़ाइल अपलोड्स चलाने से जुड़े आम सवालों के जवाब।

क्या SuperCode बिना इंटरनेट के PHP 8.2 पूरी तरह ऑफ़लाइन चलाता है?+
हाँ। SuperCode का PHP 8.2 इंजन और PDO SQLite डेटाबेस ड्राइवर 100% लोकली आपके Android डिवाइस पर चलते हैं — आप एयरप्लेन मोड में भी मल्टी-पेज PHP साइट्स, लॉगिन फ़ॉर्म्स और JSON APIs बना व टेस्ट कर सकते हैं।
KSWEB या टर्मिनल ऐप में `php -S` चलाने के बजाय SuperCode क्यों चुनें?+
अलग सर्वर डीमन्स में मैन्युअल वर्चुअल-होस्ट पाथ सेट करने पड़ते हैं, बैकग्राउंड सर्विसेज़ चलती रहती हैं और आपको तीन ऐप्स (एडिटर, सर्वर, ब्राउज़र) के बीच स्विच करना पड़ता है। SuperCode एक ही हल्के IDE में AST PHP एडिटिंग, ऑटोमैटिक प्रोजेक्ट-रूट HTTP राउटिंग, Web DevTools, SQL Studio और SFTP पब्लिशिंग को जोड़ता है।
क्या फ्रंटएंड JavaScript `fetch()` का उपयोग करके मेरी लोकल `.php` फ़ाइलों को कॉल कर सकता है?+
हाँ! चूँकि आपका वर्कस्पेस असली `localhost` HTTP/1.1 ओरिजिन पर सर्व होता है, इसलिए `await fetch('/api/tasks.php', { method: 'POST', ... })` JSON हेडर्स, कुकीज़ और DevTools Network टाइमिंग के साथ आसानी से काम करता है।
क्या मैं PHP `new PDO('sqlite:app.db')` से बनी SQLite `.db` फ़ाइल को इंस्पेक्ट कर सकता हूँ?+
तुरंत। SQL Studio के अंदर Unicode बॉक्स या Markdown फ़ॉर्मेट में इसकी टेबल्स, स्कीमा और रोज़ देखने के लिए SuperCode के फ़ाइल एक्सप्लोरर में `app.db` पर टैप करें।
