अक्सर पूछे जाने वाले सवाल (FAQ)

JavaScript बिगिनर्स, बूटकैंप स्टूडेंट्स और इंटरव्यू लर्नर्स के आम सवाल।

क्या ऑफ़लाइन JavaScript सीखना शुरू करने के लिए SuperCode पूरी तरह मुफ़्त है?+
हाँ! आप बिना किसी लॉगिन के मुफ़्त में अनलिमिटेड `.js`, `.mjs`, `.json` और `.html` फ़ाइलें बना सकते हैं, सभी 6 बिल्ट-इन JavaScript टेम्पलेट्स चला सकते हैं, 21-की सिंबल बार इस्तेमाल कर सकते हैं, कोड फ़ॉर्मेट कर सकते हैं और ऑफ़लाइन ES2024 + Node Core स्क्रिप्ट्स चला सकते हैं।
क्या मैं Android पर SuperCode को ऑफ़लाइन JSON फ़ॉर्मेटर और वैलिडेटर के रूप में इस्तेमाल कर सकता हूँ?+
हाँ। कोई भी `.json` फ़ाइल (भले ही मल्टी-मेगाबाइट पेलोड हो) खोलें या पेस्ट करें, सटीक लाइन/कॉलम सिंटैक्स एरर के लिए Error Radar देखें और एक स्टेप में इंडेंट या क्लीन करने के लिए Format दबाएं।
जब मुझे वेबसाइट बनानी हो, तो क्या SuperCode HTML, CSS और DOM JavaScript भी चलाता है?+
बिल्कुल। जब भी आप स्टैंडअलोन कंसोल JS से आगे बढ़कर विज़ुअल वेब पेजेज़ बनाना चाहें, तो SuperCode का बिल्ट-इन Web IDE असली लोकल HTTP सर्वर पर मल्टी-फ़ाइल HTML5, CSS3, DOM JavaScript और यहाँ तक कि ऑफ़लाइन PHP + SQLite का भी लाइव प्रीव्यू दिखाता है।
क्या मैं TypeScript सिंटैक्स की प्रैक्टिस भी कर सकता हूँ?+
SuperCode पूरा TypeScript (`.ts` / `.tsx`) सिंटैक्स हाइलाइटिंग, AST सिंबल अवेयरनेस, 21-की JS/TS सिंबल बार और वन-टैप फ़ॉर्मेटिंग के साथ ही ऑफ़लाइन स्टैंडअलोन ES2024 `.js`/`.mjs` एग्ज़ीक्यूशन भी देता है।
