02 प्रमुख विशेषताएं

Android पर आधुनिक वेब इंजीनियरिंग की छह जुड़ी हुई परतें

फ़्रंटएंड ES मॉड्यूल्स, बाइनरी WebAssembly, बैकएंड PHP सेशन्स, रिलेशनल SQL डेटाबेस, DevTools इंस्पेक्शन और रिमोट SFTP डिप्लॉयमेंट — सब एक जगह।

02.1

HTML5, CSS3, JS और WASM के लिए असली लोकल HTTP ओरिजिन

टूटे हुए file:// URL के बजाय प्रोजेक्ट को असली लोकल HTTP/1.1 ओरिजिन पर सर्व करता है — जिससे fetch(), <script type="module">, WebAssembly.instantiateStreaming() (.wasm), WebGL .glb/.gltf एसेट्स, IndexedDB और HTTP 206 वीडियो स्ट्रीमिंग तुरंत काम करते हैं।

65+ MIME टाइप्स · ES Modules · application/wasm · HTTP 206
02.2

100% ऑफ़लाइन डायनेमिक PHP बैकएंड इंजन

$_GET, $_POST, परसिस्टेंट $_SESSION, $_FILES अपलोड, JSON REST हेडर्स और password_hash() के साथ मल्टी-पेज .php टेम्पलेट्स, OOP क्लासेस, closures, match और include/require पूरी तरह ऑफ़लाइन चलाएं।

$_GET / $_POST / $_SESSION · JSON APIs · ऑफ़लाइन PHP
02.3

PDO और SQLite3 के ज़रिए एकीकृत SQL डेटाबेस

प्रिपेयर्ड स्टेटमेंट्स (? और :named बाइंडिंग्स), ACID ट्रांज़ैक्शन और SQL IDE में तुरंत टेबल निरीक्षण के साथ new PDO('sqlite:app.db') या SQLite3 द्वारा ऑफ़लाइन डेटा-संचालित PHP ऐप्स बनाएं।

PDO('sqlite:...') · प्रिपेयर्ड स्टेटमेंट्स · ACID ट्रांज़ैक्शन
02.4

फ़्लोटिंग DevTools कंसोल, नेटवर्क लॉग और JS REPL

लाइव HTTP रिक्वेस्ट्स (GET /api.php -> 200 · 3ms · 1.2 KB) जांचें, All / Error / Warn / Net लॉग फ़िल्टर करें, स्ट्रक्चर्ड DOM/Object ट्री देखें और > Run JavaScript... REPL में लाइव एक्सप्रेशन्स चलाएं।

नेट टाइमिंग · एरर बैज · इंटरैक्टिव JS REPL
02.5

3-मोड व्यूपोर्ट स्विचर और 2560px पेज स्क्रीनशॉट

ड्रैगेबल डायनेमिक आइलैंड से Mobile, Tablet (768dp) और Desktop लेआउट के बीच तुरंत स्विच करें, कैमरा/गैलरी <input type="file"> अपलोड टेस्ट करें और शार्प 2560px PNG स्क्रीनशॉट एक्सपोर्ट करें।

Mobile / Tablet / Desktop · 2560px PNG एक्सपोर्ट
02.6

लाइव रिमोट FTP / FTPS / SFTP वेब प्रीव्यू और डिप्लॉय

SFTP या FTPS पर लाइव वेबसाइट एडिट कर रहे हैं? रिमोट पेजों का लोकल प्रीव्यू देखने के लिए Run दबाएं (सापेक्ष CSS, JS व इमेजेज़ ऑन-डिमांड लोड होती हैं) और बदलावों को एटॉमिक सेव से सुरक्षित होस्ट पर सेव करें।

03 स्टेप-बाय-स्टेप उपयोग गाइड

Android पर फ़ुल-स्टैक वेबसाइट कैसे बनाएं, डीबग और डिप्लॉय करें

लोकल HTML/CSS/WASM और PHP+SQL प्रोटोटाइपिंग से लेकर लाइव सर्वर होस्टिंग तक।

STEP 01 index.html / index.php

HTML5, CSS3, JS, WASM और PHP फ़ाइलें लिखें

AST HTML/CSS/JS/PHP ऑटो-कंप्लीट और एक साथ <script> व <style> ब्लॉक्स इंडेंट करने वाले रिकर्सिव वन-टैप फ़ॉर्मेटर के साथ मल्टी-फ़ाइल वेब प्रोजेक्ट एडिट करें।

STEP 02 PDO + app.db

ऑफ़लाइन PHP फ़ॉर्म्स और API को SQL से जोड़ें

PDO प्रिपेयर्ड स्टेटमेंट्स से लोकल .db SQLite डेटाबेस क्वेरी करें, या सीधे SuperCode के SQL स्टूडियो में टेबल्स तैयार करें।

STEP 03 Run ▶ -> Dynamic Island

मोबाइल, टैबलेट और डेस्कटॉप + DevTools में प्रीव्यू देखें

तुरंत व्यूपोर्ट बदलें, रीसाइज़ेबल DevTools ड्रॉअर में नेटवर्क स्टेटस और JS एरर जांचें, या JS REPL में लाइव DOM बदलाव परखें।

STEP 04 SFTP / Visual Git

वेब होस्ट या GitHub Pages पर सीधे पब्लिश करें

विज़ुअल Git के ज़रिए स्टैटिक/WASM बिल्ड GitHub Pages पर पुश करें, या SFTP/FTPS से सीधे अपने VPS पर PHP व वेब फ़ाइलें डिप्लॉय करें।

बाएं किनारे से स्वाइप करने पर सीधे Explorer पर लौटें · वन-टैप कैश और सेशन रीसेट ऐप गाइड

05 सवाल और जवाब

अक्सर पूछे जाने वाले सवाल (FAQ)

ऑफ़लाइन PHP + SQLite, ES Modules / fetch() / WASM, Web DevTools और FTP/SFTP डिप्लॉयमेंट से जुड़े सवाल।

क्या मैं Android पर बिना इंटरनेट डायनेमिक PHP वेबसाइट चला सकता हूं और SQL डेटाबेस से जोड़ सकता हूं?+
जी हां! SuperCode इन-बिल्ट PDO('sqlite:...') और SQLite3 डेटाबेस सपोर्ट के साथ .php पेज, REST JSON API, सेशन्स, फ़ॉर्म अपलोड और मल्टी-फ़ाइल includes को 100% ऑफ़लाइन चलाता है।
क्या ES6 मॉड्यूल्स (<script type="module">), fetch() और WebAssembly (.wasm) काम करते हैं?+
बिल्कुल। क्योंकि SuperCode आपके प्रोजेक्ट को 65+ MIME टाइप्स (application/wasm सहित) वाले असली लोकल HTTP सर्वर पर चलाता है, इसलिए fetch(), ES मॉड्यूल्स, WebGL 3D मॉडल्स और WebAssembly.instantiateStreaming() बिना किसी रुकावट काम करते हैं।
मोबाइल पर JavaScript एरर, नेटवर्क रिक्वेस्ट और डेस्कटॉप लेआउट कैसे डीबग करें?+
प्रीव्यू मोड में ड्रैगेबल डायनेमिक आइलैंड पिल टैप करके Mobile, Tablet (768dp) और Desktop व्यूपोर्ट बदलें, या रीसाइज़ेबल Web DevTools ड्रॉअर खोलकर Error/Warn/Net लॉग फ़िल्टर करें और REPL में लाइव JavaScript चलाएं।
क्या मैं रिमोट FTP या SFTP सर्वर पर होस्ट की गई वेबसाइट का प्रीव्यू और अपडेट कर सकता हूं?+
हां। SFTP/FTPS/FTP वर्कस्पेस में अपना सर्वर माउंट करें, 3-चरणीय एटॉमिक सेव के साथ सीधे रिमोट HTML/CSS/JS/PHP टैब एडिट करें और ऑन-डिमांड एसेट कैशिंग के साथ रिमोट पेज प्रीव्यू करने के लिए Run दबाएं।
