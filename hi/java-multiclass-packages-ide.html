02 प्रमुख विशेषताएं

भारी Gradle इंतज़ार के बिना डेस्कटॉप-ग्रेड Java पैकेज आर्किटेक्चर

4-मिनट के Gradle सिंक या मैनुअल `javac -cp` फ़्लैग्स से जूझे बिना Android पर साफ़ domain, service और repository पैकेज स्ट्रक्चर करें।

02.1

नेस्टेड पैकेजेस में 500 तक .java फ़ाइलें स्कैन करता है

स्टैंडर्ड Maven/Gradle फ़ोल्डर कन्वेंशन (src/main/java/com/company/...) या हल्के फ़्लैट सबफ़ोल्डर्स से प्रोजेक्ट्स ऑर्गनाइज़ करें। SuperCode 500 तक .java फ़ाइलें (12 MB सोर्स बजट) स्कैन करता है और एक पास में क्रॉस-पैकेज इम्पोर्ट्स कंपाइल करता है।

src/main/java · नेस्टेड पैकेज · 500 फ़ाइलें / 12 MB
02.2

ज़ीरो-कॉन्फ़िग libs/*.jar और lib/*.jar क्लासपाथ लोडर

Gson, Apache Commons, org.json या प्रोफ़ेसर की कस्टम कोर्स लाइब्रेरी चाहिए? प्योर-Java .jar फ़ाइलें (कुल 30 MB तक) अपने प्रोजेक्ट के libs/ या lib/ फ़ोल्डर में डालें और उनके पैकेज तुरंत ऑफ़लाइन इम्पोर्ट करें।

libs/*.jar · lib/*.jar · 30 MB तक क्लासपाथ
02.3

लगभग 0ms इंस्टेंट री-रन के लिए SHA-256 क्लोज़र कैश

SuperCode सभी शामिल .java सोर्सेज़, खुले टैब बफ़र्स और .jar फ़ाइलों पर एक क्रिप्टोग्राफ़िक SHA-256 डाइजेस्ट कैलकुलेट करता है। अलग कंसोल इनपुट्स के साथ री-टेस्ट करने पर बिना रीकंपाइल किए ~0ms में ⚡ Cache हिट होता है।

SHA-256 क्लोज़र हैश · ⚡ कैश बैज · इंस्टेंट लॉन्च
02.4

किसी भी खुले टैब से स्मार्ट main() एंट्री आर्बिट्रेशन

कोई InvoiceRepository इंटरफ़ेस या TaxCalculator हेल्पर क्लास एडिट कर रहे हैं? वहीं से Run ▶ दबाएँ — SuperCode पैकेज ग्राफ़ जाँचकर आपके प्रोजेक्ट की main() एंट्री क्लास ढूँढता है और बिना सेव किए गए टैब एडिट्स ऑटोमैटिक मर्ज करता है।

किसी भी टैब से रन · अनसेव्ड बफ़र ओवरले
02.5

ऑटोमैटिक resources/ क्लासपाथ एसेट बंडलिंग

.properties, .json, .csv, .xml या .txt टेम्पलेट्स को resources/ या src/main/resources/ में रखें। आपकी क्लासेस उन्हें डेस्कटॉप की तरह ही Class.getResourceAsStream() या ClassLoader.getResource() से साफ़ लोड कर सकती हैं।

05 सवाल और जवाब

अक्सर पूछे जाने वाले सवाल (FAQ)

मल्टी-पैकेज लेआउट्स, बाहरी .jar लाइब्रेरीज़ जोड़ने और main() रिज़ॉल्यूशन से जुड़े आम सवाल।

SuperCode में Gson या Commons Lang जैसी बाहरी `.jar` लाइब्रेरी कैसे जोड़ें?+
अपने Java प्रोजेक्ट रूट के अंदर `libs` (या `lib`) नाम का फ़ोल्डर बनाएँ और अपनी `.jar` फ़ाइल उसमें कॉपी करें। SuperCode ऑटोमैटिक `libs/` में मौजूद सभी `.jar` आर्काइव्स (30 MB तक) को कंपाइल-टाइम और रनटाइम दोनों क्लासपाथ में जोड़ देता है — किसी बिल्ड स्क्रिप्ट की ज़रूरत नहीं।
अगर मैं ऐसी Java क्लास एडिट करते समय Run दबाऊँ जिसमें `main()` नहीं है, तो क्या होगा?+
SuperCode का एंट्री-पॉइंट आर्बिट्रेटर आपके प्रोजेक्ट की कंपाइल्ड क्लासेस को स्कैन करता है, ऑटोमैटिक `main()` वाली मुख्य एंट्री क्लास चुनता है और उसे रन करता है — इससे आपको बार-बार टैब्स बदलने की ज़रूरत नहीं पड़ती।
क्या मुझे `src/main/java` का उपयोग करना ज़रूरी है, या साधारण मल्टी-फ़ाइल फ़ोल्डर्स भी चलते हैं?+
दोनों बिना किसी झंझट के चलते हैं! आप बिना `package` स्टेटमेंट के एक सिंपल फ़ोल्डर में दो `.java` फ़ाइलें साथ रख सकते हैं, सीधे `com.example.*` सबफ़ोल्डर्स ऑर्गनाइज़ कर सकते हैं, या पूरा `src/main/java` + `resources/` + `libs/` डायरेक्टरी लेआउट उपयोग कर सकते हैं।
Android पर कौन-सी `.jar` फ़ाइलें ऑफ़लाइन चलती हैं?+
Java 8, 11 या 17 को टार्गेट करने वाली कोई भी स्टैंडर्ड प्योर-Java `.jar` लाइब्रेरी (जैसे `gson`, `org.json`, `commons-lang3`, `commons-csv`, या यूनिवर्सिटी ग्रेडिंग लाइब्रेरीज़) 100% ऑफ़लाइन काम करती है। AWT/Swing विंडोज़ वाले डेस्कटॉप GUI jars मोबाइल कंसोल के लिए नहीं हैं।
