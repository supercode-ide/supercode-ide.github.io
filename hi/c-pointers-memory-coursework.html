05 सवाल और जवाब

अक्सर पूछे जाने वाले सवाल (FAQ)

Turbo C से स्विच करने वाले, malloc/free प्रैक्टिस करने वाले या यूनिवर्सिटी C लैब्स सबमिट करने वाले छात्रों के लिए जवाब।

C सीखते समय मुझे `<conio.h>`, `clrscr()`, या `getch()` क्यों नहीं इस्तेमाल करना चाहिए?+
`<conio.h>` 1980 के दशक का एक नॉन-स्टैंडर्ड MS-DOS हेडर था जिसे हर आधुनिक Linux, macOS और यूनिवर्सिटी ग्रेडिंग सर्वर अस्वीकार कर देता है। SuperCode स्टैंडर्ड ISO/GNU C17 (`<stdio.h>`, `<stdlib.h>`, `getchar()`, `fgets()`) कंपाइल करता है ताकि आप जो भी सीखें वह सीधे कॉलेज परीक्षाओं और सिस्टम्स जॉब्स में काम आए।
क्या SuperCode `.c` फ़ाइलों को C++ की जगह असली C कंपाइलर से कंपाइल करता है?+
हाँ। C में `malloc()` एक `void *` लौटाता है जो बिना कास्ट के टाइप्ड पॉइंटर्स में इम्प्लिसिटली बदल जाता है, जबकि C++ इसे रिजेक्ट करता है। SuperCode `.c` फ़ाइलों को समर्पित GNU C17 (`-std=gnu17`) के तहत कंपाइल करता है ताकि वैध C17 इडियम्स साफ़ काम करें।
क्या `sqrt()`, `pow()`, या `sin()` इस्तेमाल करते समय मुझे मैनुअल रूप से `-lm` पास करना होगा?+
नहीं। SuperCode हर C17 बिल्ड पर स्टैंडर्ड math लाइब्रेरी (`-lm`) ऑटोमैटिक लिंक कर देता है, इसलिए `<math.h>` फ़ंक्शन तुरंत काम करते हैं।
अगर मैं गलती से कोई बैड पॉइंटर डीरेफ़रेंस कर दूँ या अनंत `while(1)` लूप लिख दूँ तो क्या होगा?+
आपका एडिटर सेशन पूरी तरह सुरक्षित रहता है: आइसोलेटेड सबप्रोसेस एग्ज़ीक्यूशन क्रैश एग्ज़िट कोड साफ़ रिपोर्ट करता है, और 20-सेकंड का CPU वॉचडॉग आपके फ़ोन को फ़्रीज़ किए बिना बेकाबू अनंत लूप को रोक देता है।
