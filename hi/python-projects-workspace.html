03 स्टेप-बाय-स्टेप उपयोग गाइड

Android पर Python रेपो को क्लोन, रीफ़ैक्टर, टेस्ट & पुश कैसे करें

सीधे आपके फ़ोन या Android टैबलेट पर पूरा सॉफ़्टवेयर इंजीनियरिंग लाइफ़साइकिल।

STEP 01 Git Clone / Open Folder

GitHub रेपो क्लोन करें या लोकल प्रोजेक्ट ट्री खोलें

HTTPS Personal Access Token से क्लोन करें या डिवाइस स्टोरेज पर कोई भी फ़ोल्डर खोलें — स्कैन के दौरान `.git`, `venv` और `__pycache__` की भीड़ अपने-आप इग्नोर हो जाती है।

STEP 02 Multi-Tab Edit + PEP 8

AST कम्प्लीशन & 21-की सिंबल बार से मॉड्यूल एडिट करें

`:`, `->`, `_`, `()`, `[]` और `INDENT` के लिए 21-की सिंबल बार पर ऊपर स्वाइप करें, और साफ़ 4-स्पेस PEP 8 अलाइनमेंट के लिए Format टैप करें।

STEP 03 Run ▶ / unittest

एंट्री स्क्रिप्ट या यूनिट टेस्ट सूट्स ऑफ़लाइन चलाएँ

तुरंत मिलीसेकंड टाइमिंग और क्लिकेबल स्टैक-ट्रेस नेविगेशन के साथ `main.py` या `unittest` सूट्स ऑफ़लाइन एक्सीक्यूट करें।

STEP 04 Git Time Machine -> Push

यूनिफ़ाइड डिफ़ रिव्यू करें, कमिट करें & अपस्ट्रीम पुश करें

Git टाइम मशीन में लाइन-बाय-लाइन बदलाव देखें, फ़ाइलें स्टेज करें और साफ़-सुथरे तरीके से GitHub, GitLab या Bitbucket पर पुश करें।

05 सवाल और जवाब

अक्सर पूछे जाने वाले सवाल (FAQ)

Android पर Python के लिए `src/` लेआउट, रिलेटिव इम्पोर्ट, `unittest` और Git इंटीग्रेशन से जुड़े सवाल।

अगर मैं `utils/helpers.py` जैसे हेल्पर मॉड्यूल को एडिट करते समय Run दबाऊँ तो क्या होगा?+
यदि `helpers.py` में केवल फ़ंक्शन या क्लास डिफ़ाइन हैं और कोई टॉप-लेवल एक्सीक्यूशन कोड नहीं है, तो SuperCode अपने-आप आपके प्रोजेक्ट की एंट्री स्क्रिप्ट (`main.py`, `app.py`, `run.py`, `__main__.py` या `src/main.py`) ढूँढता है और पूरा एप्लिकेशन चलाता है।
क्या SuperCode `match/case` और `type` एलियास जैसे Python 3.12 सिंटैक्स को सपोर्ट करता है?+
स्ट्रक्चरल `match/case` और `tomllib` Python 3.11+ में ऑफ़लाइन काम करते हैं, और PEP 695 जेनेरिक `type` एलियास सिंटैक्स इस्तेमाल करने वाली फ़ाइलें अपने-आप Python 3.12 सपोर्ट चालू कर लेती हैं।
क्या मल्टी-फ़ोल्डर इम्पोर्ट काम करने के लिए मुझे हर फ़ोल्डर में `__init__.py` चाहिए?+
नहीं। SuperCode PEP 420 इम्प्लिसिट नेमस्पेस पैकेज को सपोर्ट करता है और आपकी रिपॉज़िटरी में बेकार `__init__.py` फ़ाइलें डाले बिना प्रोजेक्ट रूट को साफ़-सुथरे तरीके से माउंट करता है।
क्या मैं प्राइवेट GitHub रिपॉज़िटरी क्लोन करके उनके Python टेस्ट ऑफ़लाइन चला सकता हूँ?+
हाँ। Visual Git में HTTPS + Personal Access Token से क्लोन करें, एक बार `requirements.txt` बैच-इंस्टॉल करें और कहीं भी पूरी तरह ऑफ़लाइन `unittest` सूट्स एडिट व रन करें।
