05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Pertanyaan umum seputar kompilasi file `.kt` / `.kts`, pengeditan offline, dan pembuatan APK.

Apakah kompilasi Kotlin di SuperCode memerlukan koneksi internet?+
Pengeditan, syntax highlighting, autolengkap AST, pemformatan `.kt`/`.gradle.kts`, Visual Git, dan ekspor PDF A4 semuanya bekerja 100% offline. Kompilasi dan eksekusi kode `.kt` dan `.kts` memakai kompiler Kotlin cloud cepat SuperCode (sedangkan Java 17 dikompilasi 100% offline di perangkat).
Bisakah saya memasukkan input uji multi-baris ke `readln()` atau `Scanner` di Kotlin?+
Ya! Ketik atau tempel kasus uji multi-baris ke bar input `stdin` persisten di konsol sebelum mengetuk Run, sehingga latihan pemrograman kompetitif dan wawancara jadi praktis.
Apakah SuperCode membangun bundel `.apk` Android Gradle multi-modul secara penuh?+
SuperCode dirancang untuk pemrograman Kotlin mandiri (`.kt`/`.kts`), pemodelan OOP, pipeline fungsional, latihan DSA, dan pengeditan file `.gradle.kts` via Git — bukan pengemasan `.apk` Android SDK berukuran multi-gigabyte.
Bisakah saya memformat file `build.gradle.kts` secara offline?+
Ya. Baik file sumber `.kt`/`.kts` maupun skrip Gradle Kotlin DSL `.gradle.kts` didukung oleh syntax highlighter dan formatter kode satu ketukan offline di SuperCode.
