03 ALUR KERJA LANGKAH DEMI LANGKAH

Langkah demi Langkah: Cara Menggunakan PIP & Wheel Offline di SuperCode

Instal paket PyPI secara online atau sideload file .whl offline dalam waktu kurang dari 30 detik.

STEP 01 Python Console -> PIP Icon

Buka Manajer Paket PIP Visual

Buka file .py apa saja dan ketuk ikon PIP di header konsol Python — atau cukup jalankan skrip dengan impor yang belum terinstal untuk memicu Auto-PIP.

STEP 02 Quick Chips / Input Box

Ketuk Chip Populer, Tempel pip install, atau Pilih requirements.txt

Ketuk chip sekali klik (requests, rich, beautifulsoup4, pyyaml, flask, telebot, colorama), ketik spesifikasi versi, atau ketuk banner requirements.txt yang terdeteksi otomatis.

STEP 03 Import Local Archive (.whl)

Atau Telusuri Unduhan untuk Paket .whl / .zip Offline

Untuk lingkungan offline, ketuk Arsip Lokal di dialog PIP untuk memindai folder Unduhan atau folder proyek Anda guna mencari paket .whl, .tar.gz, dan .zip.

STEP 04 Manage Tab -> Verify

Impor Langsung di Berbagai Skrip Multi-File

Library terinstal tersimpan persisten di direktori site-packages terisolasi meski aplikasi dimulai ulang dan langsung mendukung pelengkapan otomatis AST.

05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Pertanyaan umum seputar instalasi paket PyPI, wheel .whl offline, dan requirements.txt di Android.

Bisakah saya menempel perintah lengkap `pip install requests beautifulsoup4` ke SuperCode?+
Ya. Parser input PIP otomatis menghapus awalan `pip install`, `pip3 install`, atau `python -m pip install`, mengabaikan flag CLI yang tidak didukung secara aman, dan mengantrekan semua paket beserta batasan versi PEP 440-nya.
Bagaimana cara menginstal paket Python di Android saat tidak ada internet?+
Unduh lebih dulu arsip pure-Python `.whl` (seperti `*-py3-none-any.whl`), `.tar.gz`, atau `.zip` ke ponsel Anda, buka Manajer Paket PIP SuperCode, lalu ketuk tombol Arsip Lokal untuk menginstal langsung dari folder Unduhan.
Mengapa saya tidak perlu menjalankan `pip install numpy` atau `matplotlib` secara manual?+
Library dengan ekstensi C/Fortran native yang berat seperti NumPy, Pandas, SciPy, Matplotlib, dan Scikit-Learn sudah diadaptasi sebelumnya di runtime ilmiah SuperCode. Cukup tulis `import numpy as np` di skrip Anda dan tekan Jalankan.
Apakah paket PIP yang terinstal tetap tersimpan di ponsel setelah aplikasi ditutup?+
Ya. Setiap paket yang terinstal disimpan secara persisten di penyimpanan lokal `python_site_packages` SuperCode, sehingga skrip Anda dapat berjalan offline kapan saja tanpa instal ulang.
