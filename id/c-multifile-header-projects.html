05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Pertanyaan umum seputar error `undefined reference`, path `#include`, Makefile, dan CMake di Android.

Mengapa aplikasi C Android lain memunculkan `undefined reference` saat saya menulis `#include "helper.h"`?+
Aplikasi mobile satu file hanya meneruskan file yang aktif ke compiler dan tidak pernah menautkan `helper.c`. SuperCode memindai folder Anda (termasuk subdirektori `src/` atau `include/`), mengompilasi `helper.c` bersama `main.c`, lalu menautkan semua file objek secara otomatis.
Apakah saya wajib menulis `CMakeLists.txt` atau `Makefile` untuk proyek C kecil?+
Tidak sama sekali. Jika tidak ada `CMakeLists.txt` atau `Makefile`, perayap dependensi `#include "..."` tanpa konfigurasi milik SuperCode otomatis menemukan dan menautkan file `.c` dan `.h` Anda. Jika `CMakeLists.txt` atau `Makefile` tersedia, SuperCode mengikuti graf targetnya.
Bagaimana jika proyek saya memiliki perubahan yang belum disimpan di tab `.h` yang terbuka saat menekan Run?+
SuperCode otomatis melapiskan buffer editor yang belum disimpan ke snapshot build workspace, sehingga perubahan di seluruh tab `.h` dan `.c` yang terbuka selalu langsung tercermin.
Bagaimana SuperCode menangani workspace yang berisi dua program uji `main()` terpisah?+
Jika Anda menjalankan file yang mendefinisikan `main()` sendiri, `main()` tersebut yang dipilih. Jika dijalankan dari header `.h` bersama, SuperCode memeriksa target `CMakeLists.txt`/`Makefile` serta jalur `#include` lokal untuk memilih executable yang cocok tanpa bentrok duplikat simbol.
