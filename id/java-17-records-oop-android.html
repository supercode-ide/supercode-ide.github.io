05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Jawaban seputar dukungan bahasa Java 17 offline, migrasi Jvdroid, dan fitur Java 21+ di Android.

Apakah SuperCode benar-benar mengompilasi Java 17 records dan sealed classes tanpa internet?+
Ya. Setelah SDK Java 17 offline yang ringan diinisialisasi saat peluncuran pertama, `record`, `sealed` / `permits`, ekspresi `switch ->`, pattern matching `instanceof`, text blocks (`\"\"\"`), dan `Stream.toList()` dikompilasi dan berjalan 100% offline bahkan dalam mode pesawat.
Bagaimana perbandingan SuperCode sebagai alternatif modern bagi aplikasi mobile Java 8 atau Java 11?+
Aplikasi Java Android lama sering gagal pada tugas kuliah modern dan solusi LeetCode yang memakai tuple `record`, `Stream.toList()`, atau ekspresi switch. SuperCode mendukung LTS Java 17 penuh secara offline plus fallback Cloud Java 21+ otomatis, Visual Git, dan SQLite JDBC bawaan.
Bisakah saya memakai `CompletableFuture`, `Optional`, dan `java.time` secara offline?+
Ya. Pustaka standar inti lengkap — termasuk `java.util.stream`, `java.util.concurrent.CompletableFuture`, `java.time.*`, `java.math.BigDecimal`, dan `java.nio.file` — berjalan secara native offline.
Bagaimana cara menjalankan virtual threads Java 21 di ponsel Android saya?+
Cukup tulis `Thread.ofVirtual()` atau `Executors.newVirtualThreadPerTaskExecutor()` (atau tambahkan `// @cloud` di baris teratas file Anda) lalu ketuk Jalankan. SuperCode otomatis mengemas kelas proyek Anda ke Cloud Java 21+ dan mengalirkan outputnya kembali ke konsol.
