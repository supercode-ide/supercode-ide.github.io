05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Jawaban langsung seputar compiler offline, penanganan file besar, bahasa yang didukung, dan alur kerja Git/SFTP.

Bahasa pemrograman apa saja yang berjalan offline di SuperCode IDE di Android?+
SuperCode menjalankan Python (3.11 & 3.12 ilmiah), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, PHP, HTML5/CSS3/WebAssembly, Lua 5.4, dan skrip Linux Shell secara lokal di Android, dengan dukungan cloud opsional untuk Kotlin, MySQL 8.0, dan framework server berat.
Bisakah SuperCode membuka file log dan SQL dump berukuran gigabyte tanpa macet?+
Ya. File lebih besar dari 30 MB otomatis mengaktifkan Streaming Pager Skala GB, memotong file ratusan MB hingga GB menjadi chunk disk 10 juta karakter dengan lompat halaman instan, deteksi 34 charset, dan Ganti Regex Stream Global.
Apakah C dan C++, atau SQL dan Web/PHP, memiliki lingkungan khusus yang terpisah?+
Ya. C17 dan C++20 masing-masing memiliki standar, header, dan template khusus; SQL memiliki konsol 9 mode dan inspektor biner .db sendiri; dan Web Studio menjalankan server pratinjau lokal asli HTTP + PHP + PDO SQLite + WebAssembly dengan DevTools bawaan.
Apakah SuperCode menyertakan klien Git bawaan dan editor jarak jauh SFTP/FTPS?+
Ya. Tersedia Klien Git Visual mandiri (Clone dengan PAT, Branching, diff terpadu Commit Time Machine, dan Penyelesai Konflik Merge) plus ruang kerja SFTP, FTPS (TLS 1.3), dan FTP terenkripsi AES-256 dengan simpan jarak jauh atomik 3 fase.
Apakah SuperCode dioptimalkan untuk ponsel dan tablet Android?+
Ya. Di ponsel, toolbar berada dalam jangkauan ibu jari dengan menu geser tepi kanan dan konsol terpisah yang melipat otomatis; di perangkat lipat dan tablet, toolbar menempel vertikal dan terminal terbuka dalam workstation berdampingan 55% / 45%.
