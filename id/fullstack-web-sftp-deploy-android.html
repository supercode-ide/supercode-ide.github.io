03 ALUR KERJA LANGKAH DEMI LANGKAH

Cara Pratinjau, Edit Aman & Terbitkan Situs Live dari Android

Dua jalur deployment bersih — SFTP/FTPS langsung untuk host PHP/VPS, atau Git Visual untuk Pages.

STEP 01 SFTP / Git -> Connect

Mount Host Web Anda atau Kloning Repo Git Anda

Tambahkan host VPS/cPanel Anda di pengelola SFTP/FTPS (dengan kunci SSH atau kata sandi terenkripsi) atau kloning repositori GitHub Pages Anda.

STEP 02 Edit + Run ▶ Preview

Pratinjau Halaman Jarak Jauh atau Staging di 3 Viewport

Edit HTML, CSS, JS, atau PHP dengan pelengkapan AST lalu ketuk Run ▶ untuk memeriksa rendering Ponsel/Tablet/Desktop dan log DevTools sebelum terbit.

STEP 03 Save (Atomic) / Diff

Verifikasi Perubahan dengan Unified Diff atau Unggah Atomik

Simpan tab SFTP/FTPS jarak jauh melalui ganti nama atomik 3-fase agar pengunjung live tak pernah membuka file setengah jadi, atau periksa diff Git berwarna.

STEP 04 Verify Live / Push

Push ke Produksi & Konfirmasi Status Jaringan

Push commit untuk memicu GitHub/Cloudflare Pages atau sinkronkan folder aset secara bersamaan ke server produksi Anda.

Enkripsi Kredensial Berbasis Hardware · Mendukung SFTP, FTPS Eksplisit/Implisit (TLS 1.3), FTP & Git HTTPS Panduan Aplikasi

05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Pertanyaan umum seputar pengeditan situs web jarak jauh via SFTP/FTPS, pencegahan unggahan rusak, dan push ke GitHub Pages.

Bagaimana cara kerja pratinjau halaman web SFTP atau FTP jarak jauh tanpa mengunduh seluruh server?+
Saat Anda mengetuk Run pada tab `.html` atau `.php` jarak jauh yang terbuka, SuperCode merendernya di server pratinjau lokal dan otomatis hanya mengambil file CSS, JS, font, serta gambar relatif yang direferensikan sesuai permintaan dari host jarak jauh Anda.
Apa yang terjadi jika ponsel saya kehilangan sinyal seluler tepat saat menyimpan file `index.php` jarak jauh?+
File produksi live Anda tetap utuh! Simpan atomik 3-fase SuperCode menulis ke file sementara terlebih dahulu, memastikan jumlah byte yang diunggah cocok 100%, dan baru setelah itu menjalankan ganti nama atomik di sisi server.
Apakah SuperCode mendukung shared web hosting cPanel/Plesk maupun server VPS SSH Linux?+
Ya. Gunakan SFTP (dengan kata sandi atau kunci privat Ed25519/RSA) untuk instance VPS cloud seperti DigitalOcean, AWS Lightsail, Hetzner, atau Linode, serta gunakan FTPS (TLS 1.3) atau FTP untuk cPanel dan shared hosting.
Bisakah saya membangun dan menerbitkan situs HTML/CSS/JS statis atau WASM ke GitHub Pages secara gratis?+
Ya. Buat dan uji situs Anda secara offline melalui server HTTP lokal SuperCode, lalu commit dan push langsung ke repositori GitHub Pages Anda memakai klien Git Visual bawaan.
