Ya. SuperCode menyertakan lingkungan offline khusus untuk C17, C++20, Python 3.11/3.12, Java 17, JavaScript, Lua 5.4, PHP/Web, dan SQLite di dalam satu studio Android ringan berukuran 40.2 MB.
