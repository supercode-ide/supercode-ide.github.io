05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Pertanyaan seputar menjalankan sintaks MySQL dan PostgreSQL secara offline vs. stored procedure di Cloud MySQL 8.0.

Bisakah saya menjalankan skrip MySQL `CREATE TABLE ... AUTO_INCREMENT ENGINE=InnoDB` tanpa internet?+
Ya! Lapisan kompatibilitas SQL offline SuperCode menerjemahkan klausa DDL MySQL dan PostgreSQL umum (`AUTO_INCREMENT`, `SERIAL`, `BIGSERIAL`, `UNSIGNED`, `ENUM`, `ENGINE=InnoDB`, `CHARSET`) secara transparan agar skema dan kueri Anda berjalan offline.
Apakah `SHOW TABLES`, `DESCRIBE table_name`, dan `TRUNCATE TABLE` berfungsi offline?+
Ya. Anda tidak perlu menghafal `.schema` atau `PRAGMA table_info(...)` saat mengikuti mata kuliah MySQL — `SHOW TABLES`, `DESCRIBE` / `DESC`, `SHOW CREATE TABLE`, dan `TRUNCATE TABLE` langsung berfungsi secara offline.
Bagaimana cara Stored Procedure MySQL (`CREATE PROCEDURE` dan `DELIMITER //`) berjalan di Android?+
Karena rutin prosedural `BEGIN ... END` dan `DELIMITER` membutuhkan mesin prosedural kelas server, SuperCode merutekan skrip tersebut secara mulus ke Cloud MySQL 8.0 dan mengalirkan set hasil `CALL` Anda langsung kembali ke konsol.
Fungsi MySQL dan PostgreSQL tambahan apa saja yang tersedia secara offline?+
Lebih dari 50 fungsi skalar terpasang secara offline, termasuk `DATE_FORMAT`, `DATEDIFF`, `NOW`, `CURDATE`, `CONCAT_WS`, `LPAD`, `RPAD`, `SUBSTRING_INDEX`, `ILIKE`, `REGEXP_REPLACE`, `UUID`, `MD5`, `SHA256`, `MEDIAN`, dan `STDDEV`.
