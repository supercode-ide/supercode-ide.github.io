05 TANYA & JAWAB

Pertanyaan yang Sering Diajukan

Pertanyaan tentang menjalankan NumPy, Pandas, Polars, dan Matplotlib secara offline di ponsel dan tablet Android.

Apakah NumPy dan Pandas benar-benar berjalan offline di ponsel Android saya?+
Ya. Setelah runtime ilmiah melakukan inisialisasi dan meng-cache wheel paket (seperti `numpy`, `pandas`, atau `matplotlib`) di perangkat Anda, semua eksekusi berikutnya berjalan 100% offline tanpa perlu internet.
Bagaimana cara melihat grafik `matplotlib.pyplot` di Android?+
Simpan grafik Anda dengan `plt.savefig('plot.png', dpi=180)` (atau `.svg` / `.pdf`). SuperCode menyinkronkan file langsung ke direktori proyek aktif dan memungkinkannya dibuka seketika di penampil Gambar atau PDF resolusi tinggi bawaan.
Bisakah skrip Pandas saya membaca file `.csv` atau `.sqlite` yang tersimpan di folder yang sama?+
Ya. Path relatif seperti `pd.read_csv('sales.csv')` atau `sqlite3.connect('app.db')` langsung mengarah ke workspace proyek Anda, dan setiap file yang diubah atau baru dibuat tersinkron kembali saat eksekusi selesai.
Apakah Polars dan DuckDB juga didukung selain Pandas?+
Ya — baik `polars` maupun `duckdb` (bersama `pyarrow` dan `fastparquet`) didukung untuk kueri analitik berkecepatan tinggi di mobile.
