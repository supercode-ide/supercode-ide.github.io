## &#128640; What is Code Editor: SuperCode IDE?

**Code Editor: SuperCode IDE** (`com.phoenixglobal.supercodeeditor`), engineered by **Phoenix Global Studios**, is a next-generation hybrid mobile **Integrated Development Environment (IDE)** and **Code Editor** for Android 8.0 to Android 15.

Within a compact **40.2 MB** package rated **4.92 / 5.00 &#9733;** on Google Play, SuperCode breaks mobile sandbox limits by combining a sub-millisecond **WebAssembly Tree-Sitter AST** syntax engine, a strict **30.0 MB Anti-OOM memory shield** (streaming **150,000-line** files at **120Hz O(1)**), and **six industrial offline &amp; hybrid compilation runtimes**:

1. **[Code Editor for Android (`code-editor.html`)](https://supercode-ide.github.io/code-editor.html)**: WebAssembly Tree-Sitter AST engine running in parallel with TextMate lexical grammars (`< 1ms` leaf-node completion), **34 auto-detected character encodings** (`UTF-8`, `GB18030`, `Big5`, `Shift_JIS`, `EUC-KR`, `Windows-1251`), native PDF export, and **51 offline AI project templates**.
2. **[Python Coding App &amp; Python 3.11 IDE (`python-ide.html`)](https://supercode-ide.github.io/python-ide.html)**: Standalone offline Python 3.11 runtime with a visual Pip package manager for local `.whl` and `.tar.gz` wheels (`requests`, `flask`, `telebot`), paired with a **Smart AST Router** that offloads heavy `NumPy`, `Pandas`, and `Scikit-Learn` scripts to a Serverless Edge WASM cluster with zero phone RAM overhead.
3. **[Offline C11 / C++20 Compiler (`cpp-ide.html`)](https://supercode-ide.github.io/cpp-ide.html)**: Driven by an embedded native **LLVM / Clang 17** toolchain supporting multi-file `#include "..."` dependency linking, interactive `std::cin` console input, and a hardware-grade **150,000-character stdout buffer lock** that safely intercepts infinite loops in 14ms.
4. **[Native Java 8+ Dex IDE (`java-ide.html`)](https://supercode-ide.github.io/java-ide.html)**: Powered by local Eclipse Compiler for Java (`ECJ`) and `D8` desugaring engines. Compiles multi-file OOP `package` hierarchies and Lambda expressions offline into native `.dex` bytecode loaded via `DexClassLoader` with zero-latency `java.util.Scanner` input.
5. **[HTML/JS Web Editor &amp; Local HTTP Server (`web-ide.html`)](https://supercode-ide.github.io/web-ide.html)**: Built-in Virtual Local HTTP Server (`http://127.0.0.1`) that eliminates `file://` CORS blocks for ES6 modules (`import/export`) and WebAssembly binaries, complete with desktop-grade `Canvas.toBlob` gallery export and a 60fps throttled JS DevTools console.
6. **[Visual Git Client &amp; SFTP DevOps Studio (`git-client.html`)](https://supercode-ide.github.io/git-client.html)**: Side-by-side **Visual Merge Conflict Resolver**, gesture-driven **Git Time Machine** (`Hard Reset` &amp; branch switching), one-click `Clone / Commit / Push / Pull`, direct **SFTP / FTP** remote server editing, and native **Linux Bash/Sh** + **Lua 5.4** terminals.
