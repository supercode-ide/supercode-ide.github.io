02 القدرات الأساسية

لماذا يرتقي مطورو الواجهات الأمامية عن عارضات HTML الأساسية للهاتف

دلالات أصل متصفح حقيقية، واختبار تخطيط فعلي متعدد نقاط التوقف، وتنسيق سلس على الهواتف والأجهزة القابلة للطي والأجهزة اللوحية.

02.1

خادم HTTP/1.1 محلي حقيقي (أكثر من 65 نوع MIME)

ودّع أخطاء CORS 'origin null'. يتيح التقديم عبر أصل localhost HTTP/1.1 حقيقي استيرادات <script type="module"> الأصلية، و fetch('./data.json')، و localStorage، و IndexedDB، ورسوم SVG، وخطوط الويب .woff2.

أصل Localhost حقيقي · +65 نوع MIME · بلا حظر CORS
02.2

مبدّل Dynamic-Island لـ 3 منافذ عرض متجاوبة

تحقق من تكيّف CSS Grid و Flexbox واستعلامات @media عبر الشاشات دون امتلاك ثلاثة أجهزة. انقر على كبسولة Dynamic Island القابلة للسحب للتبديل فورياً بين تخطيطات الهاتف والجهاز اللوحي (768dp) وسطح المكتب الواسع.

نقاط توقف الهاتف · الجهاز اللوحي (768dp) · سطح المكتب
02.3

منسّق عودي لـ HTML + <style> + <script> بنقرة واحدة

تبقى نماذج الملف الواحد نظيفة تماماً: نقرة واحدة على Format تضبط المسافات البادئة لعناصر HTML5 المتداخلة مع تنسيق قواعد CSS المضمنة داخل <style> وكود JavaScript داخل كتل <script> بشكل عودي.

منسق موحّد لـ Markup + CSS + JS
02.4

بث وسائط HTTP 206 ومظللات WebGL ثلاثية الأبعاد

اختبر مشغلات <video> و <audio> التفاعلية مع تمرير الخط الزمني عبر نطاقات البايت لـ HTTP 206 Partial Content الحقيقي، أو اعرض Three.js ونماذج .glb/.gltf ثلاثية الأبعاد و HTML5 Canvas ومظللات WebGL GLSL المخصصة بمعدلات إطارات سلسة.

بحث النطاق HTTP 206 · WebGL GLSL · .glb / .gltf

05 أسئلة وأجوبة

الأسئلة الشائعة

الأسئلة الشائعة حول تحرير HTML5/CSS3/JS و ES Modules ومعاينات منافذ العرض المتجاوبة على Android.

لماذا فشل `<script type="module">` أو `fetch('./data.json')` في تطبيقات تحرير HTML الأخرى؟+
تحظر المتصفحات ES Modules و `fetch()` على روابط `file://` بسبب قواعد أمان CORS الصارمة. يقدّم SuperCode مشروعك تلقائياً عبر أصل `localhost` HTTP/1.1 حقيقي مع ترويسات MIME الصحيحة لتعمل وحدات JS الحديثة وجلب JSON محلياً دون اتصال.
كيف يمكنني معاينة استعلامات وسائط CSS للجهاز اللوحي وسطح المكتب على شاشة هاتف ذكي؟+
داخل المعاينة الحية للويب في SuperCode، انقر على أيقونة منفذ العرض في Dynamic Island العائمة للتبديل فوراً بين منافذ عرض الهاتف والجهاز اللوحي (`768dp`) وسطح المكتب الواسع — مما يفعّل قواعد `@media` لديك بدقة.
هل ينسق المنسق ذو النقرة الواحدة أيضاً CSS داخل `<style>` و JS داخل `<script>`؟+
نعم. يحلل منسق HTML العودي في SuperCode كتل `<style>` و `<script>` المضمنة داخل ملفات `.html` ويضبط المسافات البادئة للغات الثلاث بشكل منظم بنقرة واحدة.
هل يمكنني استخدام مقاطع فيديو `.mp4` محلية وخطوط `.woff2` ونماذج `.glb` ثلاثية الأبعاد دون اتصال؟+
نعم. تم تهيئة أكثر من 65 نوع MIME مسبقاً محلياً، بما في ذلك `font/woff2` و `model/gltf-binary` و `image/svg+xml` وبث نطاقات البايت HTTP `206 Partial Content` لتمرير سلس للخط الزمني في `<video>` و `<audio>`.
