02 القدرات الأساسية

تجربة مشاريع Python بمستوى سطح المكتب أُعيد تصميمها للمس

صُمّم كل تفصيل في محلّل مساحة عمل Python في SuperCode لإزالة عوائق إدارة الملفات على الهاتف.

02.1

تحكيم ذكي لنقطة الدخول من أي تبويب مفتوح

تحرّر ملف `services/ledger.py` أو `models/user.py` دون مشغّل أعلى؟ عند النقر على تشغيل يصعد تلقائياً إلى جذر مشروعك (`pyproject.toml` و`requirements.txt` و`.git`) ويشغّل `main.py` أو `app.py` أو `run.py` أو `src/main.py`.

حرّر وحدة مساعدة -> اضغط تشغيل -> يشغّل main.py
02.2

تراكب ذاكرة فوري للتبويبات غير المحفوظة وحزم PEP 420

عدّل ثلاثة تبويبات `.py` مفتوحة واضغط تشغيل فوراً — يدمج SuperCode مخازن المحرّر غير المحفوظة في الذاكرة دون إغراق مجلدات `src/` بملفات `__init__.py` فارغة غير مرغوب فيها.

تشغيل فوري دون انتظار · حزم أسماء ضمنية PEP 420
02.3

وحدة تحكم مزدوجة حقيقية لـ input() التفاعلي وإشارة [EOF]

اختبر تطبيقات سطر الأوامر باستدعاءات `input()` و`sys.stdin.readline()` المتسلسلة. ترسو وحدة التحكم تلقائياً أسفل الكود على الهواتف أو تنقسم جنباً إلى جنب بنسبة 55%/45% على الأجهزة اللوحية مع تحكم فوري بالإيقاف والمقاطعة.

رتل Stdin غير حاجب · إشارة [EOF] · تقسيم 55:45
02.4

إكمال AST دون إنترنت ومنسّق PEP 8 ورادار الأخطاء

اكتب `.` على الأصناف والوحدات لإكمال AST فوري دون إنترنت، ونسّق المسافات البادئة الفوضوية وفق PEP 8 بنقرة واحدة، والتقط خلط المسافات وعلامات الجدولة (`TabError`) أو النقطتين المفقودتين عبر رادار الأخطاء قبل التشغيل.

محرك نطاقات AST · PEP 8 بنقرة واحدة · رادار TabError
02.5

Visual Git متكامل وآلة زمن لـ 120 اعتماداً

استنسخ مستودعات Python الخاصة على GitHub/GitLab عبر HTTPS PAT، وأنشئ فروع المزايا، وافحص الفروقات الملوّنة نحوياً، وحلّ تعارضات الدمج بصرياً، وادفع الاعتمادات دون مغادرة المحرّر.

استنساخ · تفريع · دمج مرئي · اعتماد ودفع

03 سير العمل خطوة بخطوة

كيفية استنساخ مستودع Python وإعادة هيكلته واختباره ودفعه على Android

دورة حياة هندسة برمجيات كاملة مباشرة على هاتفك أو جهازك اللوحي بنظام Android.

STEP 01 Git Clone / Open Folder

استنسخ مستودع GitHub أو افتح شجرة مشروع محلي

استنسخ عبر رمز الوصول الشخصي HTTPS أو افتح أي مجلد على وحدة تخزين الجهاز — يتم تجاهل فوضى `.git` و`venv` و`__pycache__` تلقائياً أثناء الفحص.

STEP 02 Multi-Tab Edit + PEP 8

حرّر الوحدات بإكمال AST وشريط الرموز ذي 21 مفتاحاً

اسحب للأعلى على شريط الرموز ذي 21 مفتاحاً لرموز `:` و`->` و`_` و`()` و`[]` و`INDENT`، وانقر تنسيق لمحاذاة PEP 8 نظيفة من 4 مسافات.

STEP 03 Run ▶ / unittest

شغّل سكربتات الدخول أو حزم اختبارات الوحدات دون إنترنت

نفّذ `main.py` أو حزم `unittest` دون إنترنت مع توقيت فوري بالمللي ثانية وتنقل قابل للنقر عبر تتبّع المكدس.

STEP 04 Git Time Machine -> Push

راجع الفروقات الموحدة واعتمد وادفع للمستودع البعيد

افحص التغييرات سطراً بسطر في آلة زمن Git، وجهّز الملفات، وادفعها بنظافة إلى GitHub أو GitLab أو Bitbucket.

يدعم حتى 250 ملف مساحة عمل لكل تشغيل · تحديث تلقائي لذاكرة البايت كود كل 2.5 ثانية دليل التطبيق

05 أسئلة وأجوبة

الأسئلة الشائعة

أسئلة حول تخطيطات `src/` والاستيرادات النسبية و`unittest` وتكامل Git لـ Python على Android.

ماذا يحدث إذا ضغطت تشغيل أثناء تحرير وحدة مساعدة مثل `utils/helpers.py`؟+
إذا كان `helpers.py` يعرّف دوال أو أصنافاً فقط دون كود تنفيذ في المستوى الأعلى، يحدد SuperCode تلقائياً سكربت دخول مشروعك (`main.py` أو `app.py` أو `run.py` أو `__main__.py` أو `src/main.py`) ويشغّل التطبيق بالكامل.
هل يدعم SuperCode صيغ Python 3.12 مثل `match/case` والأسماء المستعارة `type`؟+
تعمل بنية `match/case` و`tomllib` دون إنترنت في Python 3.11+، كما تفعّل الملفات التي تستخدم صيغة الأسماء المستعارة المعممة `type` في PEP 695 دعم Python 3.12 تلقائياً.
هل أحتاج إلى `__init__.py` في كل مجلد لتعمل الاستيرادات متعددة المجلدات؟+
لا. يلتزم SuperCode بحزم الأسماء الضمنية PEP 420 ويربط جذر مشروعك بنظافة دون حقن ملفات `__init__.py` غير مرغوب فيها داخل مستودعك.
هل يمكنني استنساخ مستودعات GitHub الخاصة وتشغيل اختبارات Python فيها دون إنترنت؟+
نعم. استنسخ عبر HTTPS + رمز الوصول الشخصي في Visual Git، وثبّت `requirements.txt` دفعة واحدة، ثم حرّر وشغّل حزم `unittest` بالكامل دون إنترنت في أي مكان.
