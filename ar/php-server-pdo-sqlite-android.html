02 القدرات الأساسية

كل ما تحتاجه لبناء واجهات PHP خلفية ديناميكية حقيقية على الهاتف

من مشاريع الويب الجامعية ونمذجة REST API إلى لوحات تحكم CRUD كاملة — مصمّم ليعمل في وضع الطيران.

02.1

صياغة PHP 8.2 الحديثة وتضمين متعدد الملفات حتى 32 مستوى

صمّم هياكل خلفية نظيفة باستخدام تعبيرات match في PHP 8.2 والدوال السهمية (fn() =>) وترقية خصائص الباني (constructor property promotion) ونطاقات الأسماء وهياكل include و require و require_once المتداخلة حتى عمق 32 مستوى.

PHP 8.2 · match · fn() => · require_once بعمق 32
02.2

PDO('sqlite:app.db') مدمج ومعاملات ACID

اربط سكربتات PHP مباشرة بقواعد بيانات SQLite المحلية عبر new PDO('sqlite:app.db') — مع دعم كامل للاستعلامات المحضّرة بـ ? و :named للحماية من حقن SQL، و PDO::FETCH_ASSOC، و beginTransaction() / commit() / rollBack().

دون تعديل php.ini · استعلامات محضّرة · ACID
02.3

$_SESSION و $_COOKIE مستمرة ومصادقة Bcrypt

ابنِ تدفقات تسجيل دخول وسلال تسوّق وحماية CSRF حقيقية دون اتصال. يحفظ SuperCode حالة $_SESSION و $_COOKIE عبر إعادة توجيه الصفحات (header('Location: ...')) ويتضمن password_hash() و password_verify() أصلياً.

session_start() · password_hash() · إعادة توجيه HTTP
02.4

$_GET و $_POST وواجهات JSON REST APIs وترويسات مخصصة

عالج معاملات استعلام URL ونماذج HTML المشفرة بـ urlencoded وحمولات JSON الخام عبر php://input مع إرسال رموز حالة HTTP مخصصة واستجابات header('Content-Type: application/json') لعملاء fetch() في الواجهة الأمامية.

$_GET / $_POST · php://input · نقاط نهاية JSON REST
02.5

رفع ملفات Multipart $_FILES حتى 24 MB

اختبر نماذج <input type="file"> باستخدام كاميرا Android أو منتقي الملفات. تحقّق من بيانات MIME الوصفية داخل $_FILES واحفظ الصور أو المستندات المرفوعة مباشرة في مساحة عملك عبر move_uploaded_file() حتى 24 MB.

multipart/form-data · الكاميرا/التخزين · حد 24 MB
02.6

إضافات أساسية غنية: mbstring و PCRE و JSON

عالج نصوص UTF-8 الدولية عبر mb_strlen() و mb_substr()، وتحقق من المدخلات عبر preg_match() و preg_replace()، ونسّق الطوابع الزمنية، وشغّل تطبيقات متعددة الملفات دون استنزاف البطارية بخدمات خلفية.

mbstring · preg_* · json_encode · تشغيل فوري

03 سير العمل خطوة بخطوة

كيفية تشغيل مشروع PHP 8.2 + SQLite دون اتصال على Android

دون صلاحيات root، ودون قوائم توجيه المنافذ، ودون تشغيل خادم قاعدة بيانات منفصل.

STEP 01 New Folder -> index.php

أنشئ أو استنسخ مساحة عمل PHP متعددة الملفات

أنشئ مجلد مشروع يضم index.php و includes/db.php و assets/ — يتعامل SuperCode تلقائياً مع جذر مشروعك كجذر لخادم الويب المحلي.

STEP 02 new PDO('sqlite:app.db')

اتصل بقاعدة بيانات SQLite محلية

أنشئ الجداول مباشرة من PHP PDO أو أنشئ app.db وافحصه بصرياً داخل SQL Studio المدمج في SuperCode.

STEP 03 Toolbar -> Run ▶

اختبر النماذج والجلسات وواجهات Fetch عبر Localhost

اضغط تشغيل ▶ لفتح معاينة المتصفح الحية عبر مصدر HTTP محلي حقيقي، وأرسل نماذج POST/الملفات، وراقب توقيت طلبات PHP في تبويب Net.

STEP 04 Session Reset / SFTP

أعد ضبط ملفات الارتباط بنقرة أو انشر عبر SFTP

امسح ملفات تعريف ارتباط $_SESSION النشطة في أي وقت من شريط المعاينة لإعادة اختبار تدفقات تسجيل الدخول، ثم انشر ملفات PHP المتحقّق منها مباشرة إلى مضيف Linux عبر SFTP/FTPS.

05 أسئلة وأجوبة

الأسئلة الشائعة

إجابات عن الأسئلة الشائعة حول تشغيل PHP 8.2 و PDO SQLite والجلسات ورفع الملفات دون اتصال على Android.

هل يشغّل SuperCode إصدار PHP 8.2 دون اتصال بالكامل ودون إنترنت؟+
نعم. يعمل محرك PHP 8.2 ومشغّل قاعدة بيانات PDO SQLite في SuperCode محلياً بنسبة 100% على جهاز Android الخاص بك — يمكنك بناء واختبار مواقع PHP متعددة الصفحات ونماذج تسجيل الدخول وواجهات JSON API في وضع الطيران.
لماذا أختار SuperCode بدلاً من KSWEB أو تشغيل `php -S` في تطبيق طرفية؟+
تتطلب خدمات الخادم المنفصلة مسارات مضيف افتراضي يدوية، وتُبقي خدمات خلفية قيد التشغيل، وتجبرك على التنقل بين ثلاثة تطبيقات (محرر وخادم ومتصفح). يوحّد SuperCode تحرير PHP المعتمد على AST والتوجيه التلقائي لجذر المشروع عبر HTTP و Web DevTools و SQL Studio والنشر عبر SFTP في بيئة IDE واحدة خفيفة الوزن.
هل تستطيع JavaScript في الواجهة الأمامية استدعاء ملفات `.php` المحلية باستخدام `fetch()`؟+
نعم! لأن مساحة عملك تُقدَّم عبر مصدر HTTP/1.1 `localhost` حقيقي، يعمل `await fetch('/api/tasks.php', { method: 'POST', ... })` بسلاسة مع ترويسات JSON وملفات تعريف الارتباط وتوقيت الشبكة في DevTools.
هل يمكنني فحص ملف `.db` لـ SQLite الذي أنشأه PHP عبر `new PDO('sqlite:app.db')`؟+
فوراً. اضغط على `app.db` في مستكشف ملفات SuperCode لمعاينة جداوله ومخططه وصفوفه بتنسيق جداول Unicode أو Markdown داخل SQL Studio.
