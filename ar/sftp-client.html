02 القدرات الأساسية

أمان بعيد بمستوى المؤسسات وهندسة ملفات خالية من التلف

مصمم خصيصًا لشبكات الهاتف المتقلبة — حيث يؤدي محرر FTP عادي إلى بتر إعدادات الإنتاج إلى 0 بايت عند سقوط 5G أو Wi-Fi.

02.1

جميع البروتوكولات الأربعة: SFTP وFTPS الصريح والضمني وFTP

يدعم SSH SFTP (منفذ 22)، وFTPS الصريح عبر TLS 1.2/1.3 مع قنوات بيانات سلبية مشفّرة (PBSZ 0 + PROT P)، وFTPS الضمني (منفذ 990)، وFTP السلبي بترميز UTF-8 (منفذ 21).

SFTP (22) · FTPS TLS 1.3 (21) · FTPS (990) · FTP
02.2

منتقي مفاتيح SSH الخاصة وخزنة AES-256 وحارس TOFU

استورد مفاتيح OpenSSH أو PEM أو RSA أو Ed25519 أو ECDSA (.pem و.key وid_rsa وid_ed25519) مع عبارات المرور. تُشفّر جميع الأسرار عبر Android KeyStore AES-256-GCM وتحميها تنبيهات تغيّر بصمة الخادم SHA256.

Ed25519 / RSA / PEM · AES-256-GCM · حارس MITM للخادم
02.3

حفظ بعيد ذري ثلاثي المراحل (بلا تلف إلى 0 بايت)

فتح ملف بعيد ينشئ تبويب مرآة محلي مستمر (☁️). عند الضغط على حفظ، يُرفع إلى ملف مؤقت، ويُتحقق من حجم البايتات الدقيق عبر STAT/SIZE، ثم يُعاد تسميته ذريًا فوق الهدف مع إبقاء صلاحيات POSIX!

رفع مؤقت -> تحقق الحجم -> إعادة تسمية ذرية + chmod
02.4

وحدة فحص المصافحة الفورية ومجمع اتصالات ذاتي التعافي

تحقق من TCP وتفاوض TLS/SSH وتوثيق المفتاح في وحدة تشخيص مدمجة قبل حفظ الخادم. ويستعيد مجمع اتصالات ثلاثي القنوات المقابس المتوقفة تلقائيًا بعد التنقل بين Wi-Fi و5G.

⚡ فحص المصافحة · مجمع 3 قنوات ذاتي التعافي
02.5

طابور نقل بـ 4 قنوات واستئناف دقيق بالبايت

ارفع أو نزّل أشجار مجلدات كاملة عبر 4 قنوات متوازية مع لوحة تقدم بسرعة MB/s بمعدل 20 إطارًا/ث. تستأنف عمليات النقل الكبيرة المنقطعة من نفس البايت عبر SFTP RESUME أو FTP REST!

4 قنوات متوازية · سرعة MB/s حية · استئناف بالبايت

03 سير العمل خطوة بخطوة

كيف تتصل بخوادم الإنتاج وتعدّلها بأمان من Android

أعِدّ الخادم مرة واحدة في الخزنة المشفّرة عتاديًا وانشر الإصلاحات العاجلة من أي مكان في ثوانٍ.

STEP 01 Explorer -> Remote Servers -> +

اختر البروتوكول واستورد كلمة المرور أو مفتاح SSH

اختر SFTP أو FTPS (TLS) أو FTPS (990) أو FTP، وأدخل المضيف والمستخدم، ثم أدخل كلمة المرور أو اختر ملف المفتاح الخاص .pem / id_ed25519.

STEP 02 ⚡ Test Handshake -> Save

افحص تشخيص المصافحة وثِق ببصمة الخادم

اضغط فحص المصافحة لتأكيد توثيق TCP/TLS/SSH لحظيًا، وتحقق من بصمة SHA256 للخادم، واحفظ الإعدادات في خزنة AES-256.

STEP 03 Mount -> Tap Remote File

تصفّح الشجرة البعيدة وعدّل مع AST والتنسيق الكامل

افتح إعدادات Nginx أو ملفات خوادم Python/PHP أو نصوص Shell مباشرة في تبويبات المحرر مع إكمال AST ورادار الأخطاء والتنسيق بنقرة واحدة.

STEP 04 Save / Batch Upload

احفظ ذريًا أو زامن المجلدات مع التحكم بالتعارضات

اضغط حفظ للنشر الذري ثلاثي المراحل، أو حدد مجلدات متعددة للرفع/التنزيل بسياسات الكتابة فوق الملف، أو الاستئناف بالبايت، أو إبقاء كليهما، أو التخطي.

يحفظ صلاحيات ملفات POSIX البعيدة على Linux · يصمد عند إعادة تشغيل التطبيق دون اتصال دليل التطبيق

05 أسئلة وأجوبة

الأسئلة الشائعة

إجابات حول مفاتيح SSH الخاصة (.pem / Ed25519)، وبروتوكول FTPS TLS 1.3، ومنع تلف الملفات البعيدة، واستئناف التنزيلات الكبيرة.

ما صيغ مفاتيح SSH الخاصة التي تعمل مع خوادم AWS EC2 أو DigitalOcean أو Linux VPS؟+
يدعم SuperCode مفاتيح OpenSSH وPEM (.pem) وRSA (id_rsa) وEd25519 (id_ed25519) وECDSA — بعبارة مرور أو بدونها — مع منتقٍ سريع للوصول لمجلدي التنزيلات و.ssh.
كيف يمنع SuperCode تلف الملفات إلى 0 بايت على الخادم إذا انقطعت شبكة الهاتف أثناء الحفظ؟+
كل حفظ لتبويب بعيد يستخدم معاملة ذرية ثلاثية المراحل: يرفع إلى ملف مؤقت أولًا، ثم يستعلم الخادم عبر STAT/SIZE للتحقق من وصول عدد البايتات كاملًا، وعندها فقط يعيد التسمية ذريًا فوق الملف الهدف مع الحفاظ على صلاحيات Linux.
هل يدعم SuperCode بروتوكول FTPS (FTP عبر SSL/TLS) بجانب SSH SFTP؟+
نعم! يدعم أصليًا كلًا من FTPS الصريح (AUTH TLS 1.2/1.3 على المنفذ 21 مع قنوات بيانات سلبية مشفّرة PROT P) وFTPS الضمني (المنفذ 990)، إضافة إلى FTP السلبي القياسي بترميز UTF-8.
هل يمكنني استئناف تنزيل أو رفع نسخة احتياطية كبيرة إذا انقطع الاتصال؟+
نعم. عند النقل فوق ملف جزئي موجود، يكتشف SuperCode الحجم الجزئي ويعرض استئناف النقل الجزئي بنقرة واحدة من نفس موضع البايت دون إعادة إرسال البايتات المكتملة.
