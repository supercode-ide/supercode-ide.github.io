05 أسئلة وأجوبة

الأسئلة الشائعة

أسئلة شائعة من متعلمي SQL وطلاب علم البيانات والمرشحين لمقابلات الخلفية.

هل يمكنني التدرب على مسائل Window Function بمستوى LeetCode (`DENSE_RANK` و `LAG` والمجاميع المتحركة) دون إنترنت؟+
نعم! جميع دوال النوافذ القياسية (`ROW_NUMBER` و `RANK` و `DENSE_RANK` و `NTILE` و `LAG` و `LEAD` و `FIRST_VALUE` و `LAST_VALUE` و `NTH_VALUE`) ومواصفات الإطار `ROWS`/`RANGE`/`GROUPS` تعمل دون إنترنت 100%.
هل يدعم SuperCode دوال `MEDIAN()` و `PERCENTILE()` و `STDDEV()` مباشرةً في SQL؟+
نعم. بينما يفتقر SQLite التقليدي إلى التجميعات الإحصائية، يسجّل SuperCode مسبقاً دوال `MEDIAN(col)` و `PERCENTILE(col, 95)` و `STDDEV(col)` الأصلية ليتمكن محللو البيانات من حساب التوزيعات في `SELECT` واحد.
كيف تعمل دالة `READ_STDIN()` داخل استعلام `.sql`؟+
اكتب `WHERE department = READ_STDIN('Department name: ')` داخل ملف `.sql` وانقر Run — وسيطالبك SuperCode تفاعلياً في وحدة التحكم المدمجة لإعادة تشغيل الاستعلامات ذات المعاملات دون تعديل الكود.
هل البحث النصي الكامل FTS5 ووحدات R*Tree / Geopoly المكانية مفعّلة؟+
نعم. تم تجميع كل من `USING fts5(...)` (بما يشمل `bm25()` و `highlight()` و `snippet()`) وإضافات `USING rtree(...)` / Geopoly المكانية مباشرةً داخل محرك SQLite 3.54.1 دون إنترنت في SuperCode.
