03 سير العمل خطوة بخطوة

خطوة بخطوة: كيفية استخدام PIP وحزم Wheel دون إنترنت في SuperCode

ثبّت حزم PyPI عبر الإنترنت أو حمّل ملفات .whl محلياً دون إنترنت في أقل من 30 ثانية.

STEP 01 Python Console -> PIP Icon

افتح مدير حزم PIP المرئي

افتح أي ملف .py وانقر أيقونة PIP في ترويسة وحدة تحكم Python — أو شغّل سكربتاً يحتوي على استيراد غير مثبت لتفعيل Auto-PIP تلقائياً.

STEP 02 Quick Chips / Input Box

اختر شريحة شائعة، أو الصق pip install، أو حدد requirements.txt

انقر الشرائح السريعة (requests, rich, beautifulsoup4, pyyaml, flask, telebot, colorama)، أو اكتب مواصفات الإصدار، أو انقر شريط requirements.txt المكتشف تلقائياً.

STEP 03 Import Local Archive (.whl)

أو استعرض التنزيلات لحزم .whl / .zip دون إنترنت

للبيئات غير المتصلة، انقر «أرشيف محلي» في نافذة PIP لفحص مجلد التنزيلات أو المشروع بحثاً عن حزم .whl و.tar.gz و.zip.

STEP 04 Manage Tab -> Verify

استورد فوراً عبر سكربتات متعددة الملفات

تبقى المكتبات المثبتة محفوظة في مجلد site-packages المعزول بعد إعادة تشغيل التطبيق وتعمل فوراً مع الإكمال التلقائي عبر AST.

05 أسئلة وأجوبة

الأسئلة الشائعة

أسئلة شائعة حول تثبيت حزم PyPI وحزم .whl دون إنترنت وrequirements.txt على Android.

هل يمكنني لصق أمر `pip install requests beautifulsoup4` كامل في SuperCode؟+
نعم. يزيل محلل الإدخال في PIP تلقائياً بادئات `pip install` أو `pip3 install` أو `python -m pip install`، ويتجاهل أعلام CLI غير المدعومة بأمان، ويجدول جميع الحزم المذكورة مع قيود إصداراتها وفق PEP 440.
كيف أثبّت حزم Python على Android عندما لا يتوفر لدي إنترنت؟+
حمّل أرشيف Python الخالص `.whl` (مثل `*-py3-none-any.whl`) أو `.tar.gz` أو `.zip` إلى هاتفك مسبقاً، وافتح مدير حزم PIP في SuperCode، ثم انقر زر «أرشيف محلي» للتثبيت مباشرة من مجلد التنزيلات.
لماذا لا أحتاج إلى تنفيذ `pip install numpy` أو `matplotlib` يدوياً؟+
المكتبات ذات امتدادات C/Fortran الثقيلة مثل NumPy وPandas وSciPy وMatplotlib وScikit-Learn مكيّفة مسبقاً في بيئة التشغيل العلمية لـ SuperCode. فقط اكتب `import numpy as np` في السكربت واضغط تشغيل.
هل تبقى حزم PIP المثبتة على هاتفي بعد إغلاق التطبيق؟+
نعم. تُحفظ كل حزمة مثبتة بشكل دائم داخل مخزن `python_site_packages` المحلي في SuperCode، لذا تعمل سكربتاتك دون إنترنت في أي وقت دون إعادة تثبيت.
