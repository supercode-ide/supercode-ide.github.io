02 KEUPAYAAN TERAS

Ergonomik Projek Python Kelas Desktop Direka Semula untuk Sentuhan

Setiap perincian penyelesai ruang kerja Python SuperCode dibina untuk menghapuskan geseran pengurusan fail mudah alih.

02.1

Timbang Tara Titik Masuk Pintar Dari Mana-Mana Tab Terbuka

Menyunting `services/ledger.py` atau `models/user.py` tanpa pelari peringkat atas? Mengetik Jalankan secara automatik naik ke akar projek anda (`pyproject.toml`, `requirements.txt`, `.git`) dan melaksanakan `main.py`, `app.py`, `run.py`, atau `src/main.py`.

Sunting Modul Pembantu -> Tekan Jalankan -> Laksanakan main.py
02.2

Tindanan Memori Tab Belum Disimpan Secara Langsung & Ruang Nama PEP 420

Ubah suai tiga tab `.py` yang terbuka dan tekan Jalankan serta-merta — SuperCode menindih penimbal editor anda yang belum disimpan dalam memori tanpa menyemakkan folder `src/` dengan fail `__init__.py` kosong yang tidak diingini.

Larian Tanpa Menunggu · Pakej Ruang Nama Tersirat PEP 420
02.3

input() Interaktif Sebenar & Konsol Dwi-Anak Tetingkap [EOF]

Uji aplikasi CLI dengan panggilan `input()` dan `sys.stdin.readline()` berjujukan. Konsol berlabuh secara automatik di bawah kod anda pada telefon atau terbelah 55%/45% bersebelahan pada tablet, dengan kawalan Henti/Ganggu segera.

05 SOALAN & JAWAPAN

Soalan Lazim

Soalan tentang reka letak `src/`, import relatif, `unittest`, dan integrasi Git untuk Python di Android.

Apakah yang berlaku jika saya menekan Jalankan semasa menyunting modul pembantu seperti `utils/helpers.py`?+
Jika `helpers.py` hanya mentakrifkan fungsi atau kelas tanpa kod pelaksanaan peringkat atas, SuperCode secara automatik mencari skrip entri projek anda (`main.py`, `app.py`, `run.py`, `__main__.py`, atau `src/main.py`) dan menjalankan aplikasi penuh.
Adakah SuperCode menyokong sintaks Python 3.12 seperti `match/case` dan alias `type`?+
`match/case` berstruktur dan `tomllib` berfungsi secara luar talian dalam Python 3.11+, manakala fail yang menggunakan sintaks alias `type` generik PEP 695 mengaktifkan sokongan Python 3.12 secara automatik.
Adakah saya memerlukan `__init__.py` dalam setiap folder agar import berbilang folder berfungsi?+
Tidak. SuperCode mematuhi pakej ruang nama tersirat PEP 420 dan memasang akar projek anda dengan kemas tanpa menyuntik fail `__init__.py` yang tidak diingini ke dalam repositori anda.
Bolehkah saya mengklon repositori GitHub peribadi dan menjalankan ujian Python mereka secara luar talian?+
Ya. Klon melalui HTTPS + Token Akses Peribadi dalam Git Visual, pasang secara berkelompok `requirements.txt` sekali, dan sunting/jalankan suit `unittest` sepenuhnya secara luar talian di mana-mana sahaja.
