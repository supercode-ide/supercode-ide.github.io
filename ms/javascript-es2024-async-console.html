05 SOALAN & JAWAPAN

Soalan Lazim

Soalan lazim tentang sintaks ES2024, `await` peringkat atas, `fetch()` dan perlindungan gelung tak terhingga.

Bolehkah saya menjalankan fail JavaScript terus dalam SuperCode tanpa mencipta fail HTML?+
Ya! SuperCode mempunyai enjin konsol JavaScript kendiri khusus yang berasingan daripada Web IDE HTML5. Hanya buka mana-mana fail `.js`, `.mjs` atau `.cjs` dan ketik Jalankan ▶.
Bagaimanakah cara menggunakan `await` peringkat atas tanpa membalut kod dalam `async function main()`?+
Simpan fail anda sebagai `.mjs` (atau tetapkan `\"type\": \"module\"` dalam `package.json`, atau hanya tulis `await` peringkat atas dalam skrip ES Module) — SuperCode menjalankan `await` peringkat atas secara natif dan menunggu semua Promise selesai.
Apakah yang berlaku jika saya tidak sengaja menulis gelung `while (true)` tak terhingga pada telefon saya?+
Editor dan fail anda yang belum disimpan kekal 100% responsif kerana skrip berjalan pada benang worker latar belakang terasing. Ketik butang Berhenti ■ (atau biarkan pengawal CPU 15 saat bertindak) untuk menamatkan worker di bawah 1 milisaat.
Adakah `fetch()` berfungsi di dalam skrip JavaScript kendiri?+
Ya. `fetch()`, `Headers`, `Request`, `Response` dan `AbortController` standard terbina terus ke dalam masa jalan worker untuk menguji API HTTPS langsung setiap kali peranti anda mempunyai sambungan.
