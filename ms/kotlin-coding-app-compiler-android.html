05 SOALAN & JAWAPAN

Soalan Lazim

Soalan lazim tentang pengkompilan fail `.kt` / `.kts`, suntingan luar talian dan binaan APK.

Adakah pengkompilan Kotlin memerlukan sambungan internet dalam SuperCode?+
Penyuntingan, penyerlahan sintaks, autolengkap AST, pemformatan `.kt`/`.gradle.kts`, Visual Git dan eksport PDF A4 semuanya berfungsi 100% luar talian. Pengkompilan dan pelaksanaan kod `.kt` dan `.kts` menggunakan pengkompil Kotlin awan pantas SuperCode (manakala Java 17 dikompil 100% luar talian pada peranti).
Bolehkah saya menghantar input ujian berbilang baris kepada `readln()` atau `Scanner` dalam Kotlin?+
Ya! Taip atau tampal kes ujian berbilang baris ke dalam bar input `stdin` berterusan konsol sebelum mengetik Jalankan, menjadikan latihan pengaturcaraan kompetitif dan temu duga amat mudah.
Adakah SuperCode membina himpunan `.apk` Android Gradle berbilang modul penuh?+
SuperCode direka untuk pengaturcaraan Kotlin (`.kt`/`.kts`) kendiri, pemodelan OOP, saluran paip fungsian, latihan DSA dan penyuntingan fail `.gradle.kts` melalui Git — bukan pembungkusan `.apk` Android SDK berbilang gigabait.
Bolehkah saya memformat fail `build.gradle.kts` secara luar talian?+
Ya. Kedua-dua fail sumber `.kt`/`.kts` dan skrip Gradle Kotlin DSL `.gradle.kts` disokong oleh penyerlah sintaks luar talian dan pemformat kod satu ketikan SuperCode.
