05 SOALAN & JAWAPAN

Soalan Lazim

Jawapan mengenai pembukaan fail `.db`/`.sqlite3`, mengimport set data CSV/JSON dan mengeksport hasil berformat secara luar talian.

Sambungan fail pangkalan data SQLite manakah yang boleh dibuka terus oleh SuperCode?+
SuperCode mengecam fail `.db`, `.sqlite`, `.sqlite3`, `.db3` dan `.s3db` dalam satu ketik, serta menjalankan pemeriksaan luar talian untuk `.dbinfo`, `.tables` dan `.schema` secara automatik.
Mengapakah SQLite 3.54.1 terbenam penting berbanding pemapar SQLite Android biasa?+
Kebanyakan pemapar DB Android bergantung pada binaan SQLite sistem telefon yang lebih lama, yang kekurangan jadual `STRICT`, `RETURNING`, `JSONB`, klausa bingkai Window moden dan perancang kueri terkini. SuperCode menyertakan SQLite 3.54.1 secara konsisten merentas peranti Android 8.0+.
Bolehkah saya mengimport fail `.csv` atau `.json` tanpa menulis `CREATE TABLE` terlebih dahulu?+
Ya! Jalankan `.import --csv filename.csv tablename` (atau `--tsv` / `--json`) hingga 8 MB — jika `tablename` belum wujud, SuperCode mencipta skema jadual secara automatik daripada pengepala CSV atau kunci objek JSON anda.
Bagaimanakah cara mengeksport hasil kueri SQL ke jadual Markdown atau fail CSV?+
Tambahkan `.mode markdown` (atau `.mode csv` / `.mode json` / `.mode insert`) diikuti `.once output.md` tepat di atas pernyataan `SELECT` anda dan ketik Jalankan — fail tersebut muncul serta-merta dalam penjelajah projek anda.
