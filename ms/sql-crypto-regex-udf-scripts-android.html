05 SOALAN & JAWAPAN

Soalan Lazim

Jawapan tentang SQLite REGEXP_REPLACE, UDF pencincangan SHA-256, skrip .read berbilang fail, dan ATTACH DATABASE.

Adakah REGEXP dan REGEXP_REPLACE berfungsi luar talian dalam SuperCode tanpa memuatkan sambungan?+
Ya. SuperCode mengikat enjin regex Unicode ICU natif Android (dengan cache LRU 64 entri) terus ke dalam SQLite 3.54.1, membolehkan REGEXP, REGEXP_LIKE, REGEXP_REPLACE, dan REGEXP_EXTRACT serta-merta.
Fungsi cincangan kriptografi manakah yang boleh saya panggil terus di dalam pertanyaan SQL?+
SuperCode mendedahkan UDF MD5, SHA1, SHA224, SHA256, SHA384, SHA512, dan HMAC_SHA256 disokong BoringSSL secara natif untuk pencincangan luar talian, hasil tambah semak, dan pengawananama.
Bolehkah satu skrip SQL melaksanakan fail .sql anak dan mencantum merentasi berbilang pangkalan data .db?+
Ya. Gunakan .read relative/file.sql untuk menyumber skrip skema/benih modular dan ATTACH DATABASE 'other.db' AS alias untuk mencantum atau menyandarkan berbilang fail SQLite dalam folder projek anda.
Apakah yang berlaku jika cantuman silang secara tidak sengaja berjalan terlalu lama pada fail .db yang besar?+
Ketik Henti bila-bila masa—SuperCode mencetuskan sampukan SQLite segera / henti paksa CancellationSignal supaya pertanyaan panjang batal dengan bersih tanpa mengunci pangkalan data anda atau membekukan UI.
