05 SOALAN & JAWAPAN

Soalan Lazim

Soalan tentang modul `node:*` yang disokong, laluan fail `fs`, `package.json` dan pakej npm di Android.

Modul teras Node.js manakah yang berfungsi 100% secara luar talian dalam SuperCode?+
Lebih 29 modul standard berjalan sepenuhnya secara luar talian, termasuk `fs`, `fs/promises`, `path`, `path/posix`, `buffer`, `events`, `stream`, `stream/promises`, `stream/web`, `zlib`, `crypto`, `readline`, `util`, `assert`, `url`, `querystring`, `string_decoder`, `timers`, `timers/promises`, `perf_hooks`, `os`, `process` dan `console`.
Adakah `fs.writeFileSync('out.json', data)` menyimpan fail sebenar ke dalam folder Android saya?+
Ya! Operasi sistem fail membaca terus daripada folder projek terbuka anda (termasuk tab editor yang belum disimpan) dan menyegerakkan setiap fail yang dicipta atau diubah suai terus kembali ke direktori Android anda.
Bolehkah saya menggunakan kedua-dua awalan `node:fs` dan import `require('fs')` terus?+
Ya. Kedua-dua sintaks ES Module moden `import fs from 'node:fs/promises'` dan panggilan CommonJS klasik `const fs = require('fs')` diselesaikan kepada pelaksanaan luar talian terbina dalam yang sama.
Apakah yang berlaku jika skrip saya mengimport `node:http`, `net` atau `worker_threads`?+
Modul yang memerlukan soket pelayan OS atau subproses (`http`, `https`, `net`, `tls`, `dns`, `child_process`, `worker_threads`) dikesan secara automatik dan dijalankan melalui penghimpun Node.js Awan berbilang fail SuperCode — manakala pratonton HTTP tempatan tindanan penuh turut tersedia dalam Web IDE SuperCode.
