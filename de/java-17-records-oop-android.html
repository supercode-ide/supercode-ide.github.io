05 FRAGEN & ANTWORTEN

Häufig gestellte Fragen (FAQ)

Antworten zu Offline-Java 17-Sprachfeatures, Jvdroid-Migration und Java 21+ auf Android.

Kompiliert SuperCode Java 17 Records und Sealed Classes wirklich ohne Internet?+
Ja. Sobald das schlanke Offline-Java 17 SDK beim ersten Start initialisiert ist, kompilieren und laufen `record`, `sealed` / `permits`, `switch ->`-Ausdrücke, `instanceof` Pattern Matching, Textblöcke (`"""`) und `Stream.toList()` zu 100 % offline im Flugmodus.
Wie schlägt sich SuperCode als moderne Alternative zu Java 8- oder Java 11-Apps?+
Ältere Android-Java-Apps scheitern oft an modernen Uni-Aufgaben und LeetCode-Lösungen mit `record`-Tupeln, `Stream.toList()` oder Switch-Ausdrücken. SuperCode unterstützt volles LTS Java 17 offline plus automatisches Cloud Java 21+-Fallback, Visual Git und integriertes SQLite JDBC.
Kann ich `CompletableFuture`, `Optional` und `java.time` offline nutzen?+
Ja. Die gesamte Kern-Standardbibliothek — inklusive `java.util.stream`, `java.util.concurrent.CompletableFuture`, `java.time.*`, `java.math.BigDecimal` und `java.nio.file` — läuft nativ offline.
Wie starte ich Java 21 Virtual Threads auf meinem Android-Smartphone?+
Schreibe einfach `Thread.ofVirtual()` oder `Executors.newVirtualThreadPerTaskExecutor()` (oder setze `// @cloud` an den Dateianfang) und tippe auf Run. SuperCode bündelt deine Projektklassen automatisch für Cloud Java 21+ und streamt die Ausgabe zurück in deine Konsole.
