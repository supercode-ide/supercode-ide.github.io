05 FRAGEN & ANTWORTEN

Häufig gestellte Fragen (FAQ)

Antworten zu konkreten Python-Paketen, GUI-Toolkits und C-Erweiterungs-Kompatibilität auf Android.

Funktionieren Polars, DuckDB, Pydantic v2 und Cryptography auf Android in SuperCode?+
Ja. Anders als herkömmliche mobile pip-Installer, die beim Kompilieren von Rust- oder C-Erweiterungen auf dem Smartphone scheitern, bietet SuperCode vorkompilierte Binärunterstützung für polars, duckdb, pydantic, orjson, lxml und cryptography.
Kann ich SQLite-Datenbanken mit Python auf Android nutzen?+
Ja — `sqlite3` ist direkt in der Offline-Standardbibliothek von Python 3.11 enthalten, zudem werden `sqlalchemy` und `apsw` unterstützt. Praktischerweise kannst du dieselbe `.db`-Datei direkt visuell in der SQL IDE von SuperCode inspizieren.
Was ist mit Paketen, die Desktop-X11-Fenster wie Tkinter benötigen?+
Headless-Diagrammerzeugung (`matplotlib`, `seaborn`, `Pillow`, `opencv-python`) funktioniert nahtlos und speichert Bilder direkt im Projektordner für den integrierten HD-Bildbetrachter, während Web-UIs mit `flask` oder der Web IDE von SuperCode entstehen können.
Wie erkenne ich, ob ein PyPI-Paket Pure Python für die Offline-`.whl`-Installation ist?+
Auf PyPI.org -> Download files ist jedes Wheel mit der Endung `-py3-none-any.whl` ein universelles Pure-Python-Wheel, das sich über den Lokales-Archiv-Importer von SuperCode 100 % offline installieren lässt.
