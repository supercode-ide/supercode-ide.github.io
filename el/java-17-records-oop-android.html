02.1

Αμετάβλητα Java 17 Records & Compact Constructors

Αντικαταστήστε 70 γραμμές boilerplate από getters, equals(), hashCode() και toString() με μία μόνο δήλωση record. Υποστηρίζει compact canonical constructors για επικύρωση, generic records, τοπικά records μέσα σε μεθόδους και υλοποίηση διεπαφών.

record Order(...) · Compact επικύρωση · Τοπικά Records
02.2

Sealed Classes & Αλγεβρικές Ιεραρχίες Πεδίου

Μοντελοποιήστε καθαρά κλειστές μηχανές καταστάσεων, κόμβους AST και αποτελέσματα πληρωμών με δηλώσεις sealed class και sealed interface σε συνδυασμό με permits, final και non-sealed υποτύπους — με έλεγχο κατά τη μεταγλώττιση πλήρως εκτός σύνδεσης.

sealed interface · permits · Πληρότητα στον έλεγχο μεταγλώττισης
02.3

Εκφράσεις Switch Arrow, Pattern Matching & Text Blocks

Εξαλείψτε τα σφάλματα fall-through με εκφράσεις switch (->) και yield, περιορίστε τύπους inline με pattern matching if (obj instanceof Card c), συνάγετε εκτενή generics με var και ενσωματώστε καθαρά πολυγραμμικά \"\"\" text blocks για JSON/SQL.

switch -> · instanceof Pattern · \"\"\" Text Blocks · var
02.4

Σύγχρονα Streams (.toList()), java.time & CompletableFuture

Αλυσιδώστε συναρτησιακούς μετασχηματισμούς με τα συνοπτικά Stream.toList(), Stream.mapMulti(), Optional.ifPresentOrElse() της Java 17, αμετάβλητα factories Map.of(), αριθμητική java.time LocalDate/Instant και ασύγχρονες ροές CompletableFuture.

Stream.toList() · java.time · CompletableFuture
02.5

Σχεδιασμένο για να αντικαταστήσει ξεπερασμένες εφαρμογές Java 8 & Java 11

Πολλές παλαιότερες εφαρμογές Java στο Android απορρίπτουν λέξεις-κλειδιά record, text blocks ή .toList() με σφάλματα σύνταξης. Το SuperCode μεταγλωττίζει πλήρεις στόχους release Java 17 τοπικά στη συσκευή και αποθηκεύει στην cache το αμετάβλητο bytecode για άμεση επανεκτέλεση.
