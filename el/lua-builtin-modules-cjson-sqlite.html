02 ΒΑΣΙΚΕΣ ΔΥΝΑΤΟΤΗΤΕΣ

Πραγματικό Lua scripting πέρα από τη βασική τυπική βιβλιοθήκη

Χτίστε REST clients, τοπικούς επεξεργαστές αρχείων αποθήκευσης SQLite, μαζικά εργαλεία καταλόγων και scripts JSON τύπου OpenResty/Redis χωρίς να αγγίξετε μεταγλωττιστή C.

02.1

Σειριοποίηση cjson & dkjson άμεσα διαθέσιμη

Αναλύστε και παράγετε JSON payloads ακαριαία εκτός σύνδεσης με require('cjson') ή require('dkjson') — μαζί με cjson.encode_pretty() για ευανάγνωστα αρχεία ρυθμίσεων και αποσφαλμάτωση API.

cjson.encode · encode_pretty · cjson.decode
02.2

Ενσωματωμένη μηχανή βάσης δεδομένων lsqlite3 / sqlite3

Ανοίξτε :memory: ή μόνιμα αρχεία .db στον χώρο εργασίας μέσω require('lsqlite3') ή require('sqlite3'). Υποστηρίζει prepared statements, δεσμεύσεις παραμέτρων :named, επαναλήπτες db:nrows() και συναλλαγές ACID.

lsqlite3 · Μόνιμος συγχρονισμός .db · Κοινό με το SQL IDE
02.3

Αυτοματισμός καταλόγων & αρχείων LuaFileSystem (lfs)

Αυτοματοποιήστε μαζικές μετονομασίες και ελέγχους πόρων στον φάκελο του έργου σας με require('lfs') — συμπεριλαμβανομένων των lfs.dir(), lfs.mkdir(), lfs.currentdir() και ελέγχων μεγέθους/χρονοσήμανσης lfs.attributes().

lfs.dir · lfs.mkdir · lfs.attributes
02.4

Σουίτα ασφαλείας crypto, sha2, md5 & base64

Υπογράψτε webhook payloads, επαληθεύστε checksums αρχείων και παράγετε μοναδικά IDs εκτός σύνδεσης με SHA-256, SHA-512, MD5, συνόψεις HMAC με κλειδί, crypto.uuid() και κωδικοποίηση/αποκωδικοποίηση Base64 συμβατή με RFC.

SHA-256/512 · HMAC · crypto.uuid() · base64
02.5

socket.http, πλήρες regex & table inspect

Δοκιμάστε ζωντανά REST APIs μέσω require('socket.http'), εκτελέστε πλήρεις κανονικές εκφράσεις PCRE/POSIX όταν δεν αρκούν τα μοτίβα Lua με require('regex') και εκτυπώστε καθαρά ένθετα tables με require('inspect').

socket.http · Πλήρες regex · inspect(table)
02.6

Δρομολόγηση Cloud Lua για C-Rocks lpeg & luv

Δουλεύετε με PEG parsers στο lpeg ή ασύγχρονους βρόχους libuv στο luv; Το SuperCode πακετάρει αυτόματα τα modules του έργου σας στο περιβάλλον Cloud Lua και αντιστοιχίζει τα tracebacks 1:1 στον επεξεργαστή σας.

Cloud lpeg & luv · Αυτόματο πακετάρισμα πολλαπλών αρχείων

STEP 02 Toolbar -> Run ▶

Επιθεωρήστε οπτικά βάσεις δεδομένων lsqlite3

Πατήστε το παραγόμενο αρχείο .db στον Εξερευνητή για να περιηγηθείτε σε σχήματα και να εκτελέσετε αναλυτικά ερωτήματα στο SQL Studio 9 λειτουργιών του SuperCode.

STEP 04 require('lpeg')

Εκτελέστε απρόσκοπτα εξειδικευμένα C-Rocks στο cloud όταν χρειάζεται

05 ΕΡΩΤΗΣΕΙΣ & ΑΠΑΝΤΗΣΕΙΣ

Συχνές Ερωτήσεις

Συχνές ερωτήσεις για τη χρήση των cjson, lsqlite3, LuaFileSystem και modules luarocks στο Android.

Χρειάζεται να εγκαταστήσω luarocks ή μεταγλωττιστή C για να χρησιμοποιήσω τα `cjson`, `lsqlite3` ή `lfs`;+
Όχι. Και τα 11+ βασικά aliases επεκτάσεων (`cjson`, `dkjson`, `lsqlite3`, `sqlite3`, `lfs`, `crypto`, `sha2`, `md5`, `base64`, `regex`, `socket.http` και `inspect`) είναι προενσωματωμένα απευθείας στο SuperCode και λειτουργούν αμέσως μέσω `require()`.
Μπορεί το `lsqlite3` να μοιράζεται το ίδιο αρχείο `.db` με την Python, την PHP ή το SQL IDE του SuperCode;+
Ναι! Μια βάση δεδομένων `.db` που δημιουργείται από το `lsqlite3` στον φάκελο του έργου σας είναι ένα τυπικό δυαδικό αρχείο SQLite 3 που μπορεί να δεχθεί ερωτήματα απευθείας στο SQL Studio του SuperCode, στην Python `sqlite3`, στην PHP `PDO` ή στη Java JDBC.
Υποστηρίζει το `cjson` μορφοποιημένη εκτύπωση (pretty-printing) για αρχεία ρυθμίσεων;+
Ναι. Εκτός από τα τυπικά `cjson.encode()` και `cjson.decode()`, το SuperCode παρέχει το `cjson.encode_pretty()` ώστε να επιθεωρείτε ή να αποθηκεύετε καθαρά στοιχισμένο JSON εκτός σύνδεσης.
Τι συμβαίνει αν το script μου απαιτεί `lpeg` ή `luv`;+
Όταν είστε συνδεδεμένοι στο διαδίκτυο, το SuperCode εντοπίζει εξειδικευμένες εισαγωγές εγγενών C-rock όπως `lpeg` ή `luv` και δρομολογεί αυτόματα το έργο πολλαπλών αρχείων σας στο περιβάλλον Cloud Lua.
