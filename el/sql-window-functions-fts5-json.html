05 ΕΡΩΤΗΣΕΙΣ & ΑΠΑΝΤΗΣΕΙΣ

Συχνές Ερωτήσεις

Συχνές ερωτήσεις από σπουδαστές SQL, φοιτητές επιστήμης δεδομένων και υποψήφιους συνεντεύξεων backend.

Μπορώ να εξασκηθώ σε προβλήματα Window Function SQL τύπου LeetCode (`DENSE_RANK`, `LAG`, κυλιόμενα αθροίσματα) εκτός σύνδεσης;+
Ναι! Κάθε τυπική συνάρτηση παραθύρου SQL (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) και προδιαγραφή πλαισίου `ROWS`/`RANGE`/`GROUPS` λειτουργεί 100% εκτός σύνδεσης.
Υποστηρίζει το SuperCode τις συναρτήσεις `MEDIAN()`, `PERCENTILE()` και `STDDEV()` απευθείας στην SQL;+
Ναι. Ενώ η απλή SQLite δεν διαθέτει στατιστικές συναρτήσεις, το SuperCode προεγγράφει εγγενείς συναρτήσεις `MEDIAN(col)`, `PERCENTILE(col, 95)` και `STDDEV(col)` ώστε οι αναλυτές να υπολογίζουν κατανομές σε ένα μόνο `SELECT`.
Πώς λειτουργεί η `READ_STDIN()` μέσα σε ένα ερώτημα `.sql`;+
Γράψτε `WHERE department = READ_STDIN('Department name: ')` στο αρχείο `.sql` και πατήστε Εκτέλεση — το SuperCode σάς ζητά διαδραστικά είσοδο στην ενσωματωμένη κονσόλα για να επανεκτελείτε παραμετρικά ερωτήματα χωρίς αλλαγή κώδικα.
Είναι ενεργοποιημένες η αναζήτηση πλήρους κειμένου FTS5 και οι χωρικές επεκτάσεις R*Tree / Geopoly;+
Ναι. Τόσο η `USING fts5(...)` (συμπεριλαμβανομένων των `bm25()`, `highlight()` και `snippet()`) όσο και οι χωρικές επεκτάσεις `USING rtree(...)` / Geopoly είναι μεταγλωττισμένες απευθείας στη μηχανή SQLite 3.54.1 εκτός σύνδεσης του SuperCode.
