02 ΒΑΣΙΚΕΣ ΔΥΝΑΤΟΤΗΤΕΣ

Κάθε ροή εργασίας — από εισαγωγικές ασκήσεις πληροφορικής έως επιστημονικά γραφήματα και web scraping — λειτουργεί ομαλά χωρίς περιττή ρύθμιση τερματικού.

02.1

Offline Python 3.11 πολλών αρχείων & Έξυπνη δρομολόγηση εισόδου

Εκτελέστε έργα πολλών ενοτήτων σε αρχεία .py, .json, .csv, .yaml και .toml 100% offline. Πατώντας Εκτέλεση μέσα σε μια βοηθητική ενότητα, εντοπίζεται και εκτελείται αυτόματα το κύριο script εισόδου του έργου σας.

Η εισαγωγή των numpy, scipy, pandas, matplotlib ή scikit-learn ενεργοποιεί το τοπικό επιστημονικό runtime — αποθηκεύοντας τοπικά τα wheels ώστε η ανάλυση δεδομένων και η δημιουργία γραφημάτων plt.savefig() να εκτελούνται offline.

NumPy · Pandas · Matplotlib · Αυτόματη αποθήκευση PNG/SVG/PDF

03 ΒΗΜΑ ΠΡΟΣ ΒΗΜΑ ΡΟΗ

Πώς να γράψετε κώδικα & να διαχειριστείτε πακέτα Python στο SuperCode

Μεταβείτε από έναν κενό φάκελο σε ένα έργο Python & Matplotlib πολλών αρχείων με τέσσερα πατήματα.

STEP 01 New File -> main.py

Δημιουργήστε ένα script ή φορτώστε ένα ενσωματωμένο παράδειγμα Python

Ξεκινήστε από το μηδέν με τη γραμμή συμβόλων 21 πλήκτρων Python ή επιλέξτε ένα από τα 8 ενσωματωμένα πρότυπα Python από τη βιβλιοθήκη Παραδειγμάτων Κώδικα.

STEP 02 PIP Package Manager

Εγκαταστήστε βιβλιοθήκες PyPI ή offline αρχεία .whl

Πατήστε requirements.txt για μαζική εγκατάσταση με ένα άγγιγμα, επιλέξτε έτοιμα chips (requests, rich, bs4, flask) ή εισαγάγετε πακέτα .whl από τις Λήψεις για offline αίθουσες διδασκαλίας.

STEP 03 Toolbar -> Run ▶

Εκτελέστε offline & αλληλεπιδράστε μέσω ζωντανού input()

Παρακολουθήστε άμεση έξοδο, κωδικούς εξόδου, χρονισμό σε millisecond και μεταβολή μνήμης στη διαχωρισμένη κονσόλα ενώ πληκτρολογείτε ζωντανές απαντήσεις σε προτροπές input().

STEP 04 Explorer Refresh

Επιθεωρήστε παραγόμενα γραφήματα, CSV & εξόδους JSON

Κάθε αρχείο που γράφεται μέσω open() ή plt.savefig('plot.png') συγχρονίζεται απευθείας στον φάκελο του έργου σας και ανοίγει στον ενσωματωμένο προβολέα εικόνων ή PDF υψηλής ανάλυσης του SuperCode.

Μπορώ να γράφω και να εκτελώ κώδικα Python στο Android εντελώς offline;+

Πώς εγκαθιστώ βιβλιοθήκες τρίτων όπως requests, bs4 ή offline αρχεία .whl;+
Ανοίξτε τον οπτικό διαχειριστή πακέτων PIP (ή απλώς εκτελέστε το script σας και αφήστε το Auto-PIP να εντοπίσει τα ελλιπή imports). Μπορείτε να εγκαταστήσετε από το PyPI, να πατήσετε ένα εντοπισμένο chip requirements.txt ή να εισαγάγετε πακέτα .whl, .tar.gz και .zip από τον τοπικό χώρο αποθήκευσης.
Πού αποθηκεύονται τα γραφήματα Matplotlib ή τα αρχεία που δημιουργούνται με open('data.csv', 'w');+
Κάθε εικόνα, PDF, CSV ή JSON που γράφεται από το script σας συγχρονίζεται αυτόματα στον ενεργό φάκελο του έργου σας και προβάλλεται άμεσα στην ενσωματωμένη συλλογή εικόνων ή τον επεξεργαστή αρχείων του SuperCode.
Υποστηρίζει το SuperCode διαδραστικούς βρόχους Python input();+
