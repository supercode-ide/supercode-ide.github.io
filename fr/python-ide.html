05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Réponses sur l’exécution Python hors ligne, l’installation de bibliothèques pip/.whl, NumPy/Matplotlib et les imports multi-fichiers.

Puis-je écrire et exécuter du code Python sur Android totalement hors ligne ?+
Oui. Les scripts Python 3.11 multi-fichiers, la bibliothèque standard, les paquets PIP/.whl installés localement ainsi que les bibliothèques scientifiques Python 3.12 mises en cache (NumPy, Pandas, Matplotlib, SciPy, scikit-learn) fonctionnent à 100 % hors ligne.
Comment installer des bibliothèques tierces comme requests, bs4 ou des fichiers .whl hors ligne ?+
Ouvrez le gestionnaire visuel PIP (ou lancez simplement votre script pour laisser Auto-PIP détecter les imports manquants). Vous pouvez installer depuis PyPI, toucher une puce requirements.txt détectée ou importer des archives .whl, .tar.gz et .zip depuis le stockage local.
Où vont les graphiques Matplotlib ou les fichiers créés par open('data.csv', 'w') ?+
Chaque image, PDF, CSV ou JSON écrit par votre script est automatiquement synchronisé dans votre dossier projet actif et peut être ouvert immédiatement dans la galerie d’images ou l’éditeur intégré.
SuperCode prend-il en charge les boucles Python interactives avec input() ?+
Oui. Dès que votre script appelle input(), la console en écran partagé met en évidence le champ de saisie afin de vous permettre d’envoyer vos réponses en temps réel.
