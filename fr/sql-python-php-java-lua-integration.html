05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Questions fréquentes sur le partage de fichiers `.db` entre langages et l'édition de gros dumps `.sql` sur Android.

Dois-je télécharger un `.jar` pour utiliser `jdbc:sqlite:app.db` en Java 17 ?+
Non ! SuperCode préintègre le pilote SQLite JDBC directement dans le classpath Java 17 hors ligne — écrivez simplement `DriverManager.getConnection("jdbc:sqlite:app.db")` et appuyez sur Exécuter.
Python, PHP, Java et Lua peuvent-ils vraiment lire et écrire dans le même fichier `app.db` ?+
Oui. Tant que vos fichiers `.sql`, `.py`, `.php`, `.java` et `.lua` résident dans le même dossier d'espace de travail (ou pointent vers le même chemin relatif), tous lisent et valident des transactions ACID sur l'unique fichier `app.db` sur disque.
Comment utiliser SQLite dans des scripts Lua 5.4 sous SuperCode ?+
Appelez `local sqlite3 = require('lsqlite3')` puis `local db = sqlite3.open('app.db')`. Le module `lsqlite3` embarqué est intégré au runtime Lua 5.4 hors ligne de SuperCode avec démarrage sous la milliseconde.
SuperCode peut-il ouvrir un dump `.sql` de plus de 1 Go sans faire planter mon téléphone ?+
Oui. L'éditeur de gros fichiers de SuperCode lit les fichiers `.sql`, `.csv` et `.log` volumineux par pages disque au lieu de tout charger en RAM — avec recherche/remplacement regex et détection d'encodage.
