05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Questions sur les structures `src/`, imports relatifs, `unittest` et l'intégration Git pour Python sur Android.

Que se passe-t-il si j'appuie sur Exécuter en éditant un module utilitaire comme `utils/helpers.py` ?+
Si `helpers.py` ne définit que des fonctions ou classes sans code d'exécution de haut niveau, SuperCode repère automatiquement le script d'entrée de votre projet (`main.py`, `app.py`, `run.py`, `__main__.py` ou `src/main.py`) et lance toute l'application.
SuperCode prend-il en charge la syntaxe Python 3.12 comme `match/case` et les alias `type` ?+
Le filtrage structurel `match/case` et `tomllib` fonctionnent hors ligne sous Python 3.11+, et les fichiers utilisant la syntaxe générique d'alias `type` PEP 695 activent automatiquement le support Python 3.12.
Faut-il un `__init__.py` dans chaque dossier pour que les imports multi-dossiers fonctionnent ?+
Non. SuperCode respecte les paquets namespace implicites PEP 420 et monte proprement la racine de votre projet sans injecter de fichiers `__init__.py` indésirables dans votre dépôt.
Puis-je cloner des dépôts GitHub privés et exécuter leurs tests Python hors ligne ?+
Oui. Clonez via HTTPS + jeton d'accès personnel dans Visual Git, installez `requirements.txt` en lot une seule fois, puis éditez et lancez vos suites `unittest` entièrement hors ligne partout.
