05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Questions fréquentes sur l'arborescence multi-packages, l'ajout de .jar externes et la résolution de main().

Comment ajouter une bibliothèque `.jar` externe comme Gson ou Commons Lang dans SuperCode ?+
Créez un dossier nommé `libs` (ou `lib`) à la racine de votre projet Java et copiez-y votre fichier `.jar`. SuperCode ajoute automatiquement toutes les archives `.jar` de `libs/` (jusqu'à 30 Mo) au classpath de compilation et d'exécution — sans aucun script de build.
Que se passe-t-il si j'appuie sur Exécuter depuis une classe Java sans méthode `main()` ?+
L'arbitre de point d'entrée de SuperCode analyse les classes compilées du projet, sélectionne automatiquement la classe principale contenant `main()` et l'exécute — vous évitant des allers-retours incessants entre onglets.
Dois-je utiliser `src/main/java`, ou de simples dossiers multi-fichiers fonctionnent-ils aussi ?+
Les deux fonctionnent sans couture ! Placez deux fichiers `.java` côte à côte sans instruction `package`, organisez directement des sous-dossiers `com.example.*`, ou adoptez une arborescence complète `src/main/java` + `resources/` + `libs/`.
Quels fichiers `.jar` fonctionnent hors ligne sur Android ?+
Toute bibliothèque `.jar` Java pure ciblant Java 8, 11 ou 17 (comme `gson`, `org.json`, `commons-lang3`, `commons-csv` ou les bibliothèques de notation universitaire) fonctionne 100% hors ligne. Les `.jar` graphiques desktop exigeant des fenêtres AWT/Swing ne sont pas destinés aux consoles mobiles.
