02 FONCTIONNALITÉS CLÉS

Quatre façons simples d'ajouter des bibliothèques Python sur téléphone

Avec du Wi-Fi haut débit ou sans aucune connexion en cours, SuperCode garde vos dépendances Python organisées et persistantes.

02.1

Détecteur Auto-PIP d'imports manquants & 35+ alias

Écrivez import bs4, import yaml, import dotenv, import jwt ou import telebot et appuyez sur Exécuter. SuperCode associe automatiquement l'import à son paquet PyPI officiel (beautifulsoup4, pyyaml, python-dotenv, PyJWT, pyTelegramBotAPI), l'installe et relance votre script.

bs4 -> beautifulsoup4 · yaml -> pyyaml · 35+ alias
02.2

Détection zéro-config de requirements.txt dans l'espace de travail

Clonez un dépôt Git ou ouvrez un dossier contenant requirements.txt. Le gestionnaire PIP visuel explore jusqu'à 6 répertoires parents, analyse les sauts de ligne (\) et marqueurs de plateforme, et affiche une bannière d'installation en lot en un geste.

Scan ascendant · Marqueurs plateforme · File par lots
02.3

Importateur local .whl, .tar.gz & .zip 100 % hors ligne

Vous codez dans les transports, en vol ou sur un campus restreint ? Téléchargez à l'avance des distributions pur Python .whl, .tar.gz ou .zip dans Téléchargements et installez-les totalement hors ligne avec validation PEP 440 complète.

Installation mode avion · .whl / .tar.gz / .zip
02.4

Contraintes de version PEP 440 & analyseur de commandes

Collez des commandes pip install complètes (comme pip install requests>=2.31.0 flask~=3.0) directement dans le champ. SuperCode nettoie les préfixes CLI, évalue ==, >=, <=, != et ~= pour Python 3.11 et résout les versions compatibles.

Conforme PEP 440 · Collage direct pip install
02.5

Inspecteur disque des paquets installés & nettoyage en 1 geste

Passez à l'onglet Gérer pour filtrer les bibliothèques installées en temps réel, vérifier les numéros de version exacts et l'empreinte disque en Ko/Mo, puis supprimer proprement les paquets inutilisés en un geste.

Filtre en direct · Taille exacte · Désinstallation propre

Saisir numpy, pandas, matplotlib, scipy ou scikit-learn dans PIP ne provoquera aucune erreur de compilation C/Fortran sur votre téléphone — SuperCode les redirige automatiquement vers des wheels scientifiques précompilés en cache local.

05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Questions fréquentes sur l'installation de paquets PyPI, wheels .whl hors ligne et requirements.txt sur Android.

Puis-je coller une commande complète `pip install requests beautifulsoup4` dans SuperCode ?+
Oui. L'analyseur PIP supprime automatiquement les préfixes `pip install`, `pip3 install` ou `python -m pip install`, ignore sans risque les options CLI non prises en charge et met en file d'attente tous les paquets listés avec leurs contraintes PEP 440.
Comment installer des paquets Python sur Android sans connexion Internet ?+
Téléchargez au préalable l'archive pur Python `.whl` (comme `*-py3-none-any.whl`), `.tar.gz` ou `.zip` sur votre téléphone, ouvrez le gestionnaire PIP de SuperCode et touchez Archive locale pour installer directement depuis Téléchargements.
Pourquoi n'ai-je pas besoin d'exécuter `pip install numpy` ou `matplotlib` manuellement ?+
Les bibliothèques dotées de lourdes extensions natives C/Fortran comme NumPy, Pandas, SciPy, Matplotlib et Scikit-Learn sont préadaptées dans le runtime scientifique de SuperCode. Écrivez simplement `import numpy as np` et appuyez sur Exécuter.
Les paquets PIP installés restent-ils sur mon téléphone après fermeture de l'app ?+
Oui. Chaque paquet installé est stocké de façon persistante dans le dossier local `python_site_packages` de SuperCode : vos scripts tournent hors ligne à tout moment sans réinstallation.
