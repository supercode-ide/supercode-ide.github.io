05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Réponses sur l’exécution directe de fichiers .js sans HTML, les modules ES, les boucles infinies et Node.js.

Puis-je exécuter un fichier .js directement sur Android sans créer de page HTML ?+
Oui ! Appuyer sur Exécuter dans n’importe quel fichier .js, .mjs ou .cjs ouvre immédiatement la console autonome JavaScript de SuperCode — entièrement hors ligne.
Puis-je répartir mon code JavaScript sur plusieurs fichiers avec import/export ou require() ?+
Oui. Les modules ES (import / export), CommonJS (require / module.exports) ainsi que les imports .json fonctionnent directement entre vos fichiers locaux et vos onglets ouverts.
Une boucle while(true) accidentelle risque-t-elle de figer l’éditeur ou de faire perdre mon code ?+
Jamais. Les scripts tournent dans un worker d’arrière-plan isolé, surveillé par un watchdog de 15 secondes et un coupe-circuit d’affichage, stoppant toute boucle infinie en moins d’une milliseconde sans toucher à l’interface.
Et si je souhaite créer un site visuel complet avec DOM HTML, CSS et WebAssembly ?+
SuperCode intègre les deux ! Utilisez l’IDE JavaScript autonome pour vos modules JS/Node purs et algorithmes, et passez au Studio Web & PHP Full-Stack dès que vous avez besoin du rendu HTTP DOM en direct, des vues responsives et des DevTools.
