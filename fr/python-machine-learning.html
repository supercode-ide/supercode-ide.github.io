05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Réponses sur l'exécution de Scikit-Learn, OpenCV, PyTorch et les workflows GPU distants depuis Android.

Puis-je exécuter Scikit-Learn, XGBoost et OpenCV (`cv2`) sans connexion Internet ?+
Oui. Une fois mis en cache sur votre appareil par le runtime scientifique de SuperCode, `scikit-learn`, `xgboost`, `lightgbm`, `opencv-python` (`cv2`), `Pillow` et `scikit-image` tournent entièrement hors ligne.
Comment exécuter du code PyTorch ou TensorFlow sans saturer le stockage de mon téléphone ?+
Faites simplement `import torch` ou `import tensorflow as tf` (ou placez `# @cloud` à la ligne 1). SuperCode empaquette vos modules `.py` locaux, les exécute sur le cluster Python cloud et mappe chaque traceback directement sur vos lignes d'éditeur locales.
Puis-je éditer et lancer des scripts sur ma propre station GPU Linux ?+
Oui. Connectez votre station via l'espace SFTP de SuperCode (compatible clés SSH Ed25519/RSA chiffrées en AES-256) pour éditer vos `.py` et `.yaml` distants avec complétion AST complète et sauvegardes atomiques en 3 phases.
`cv2.imwrite()` enregistre-t-il bien les images traitées dans mon dossier ?+
Oui — chaque image écrite via `cv2.imwrite()` ou `Image.save()` se synchronise directement dans votre répertoire projet et s'ouvre proprement dans la visionneuse d'images intégrée de SuperCode.
