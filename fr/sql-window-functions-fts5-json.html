05 QUESTIONS & RÉPONSES

Questions Fréquentes (FAQ)

Questions fréquentes des apprenants SQL, étudiants en data science et candidats backend.

Puis-je m'entraîner hors ligne aux exercices SQL type LeetCode (`DENSE_RANK`, `LAG`, sommes glissantes) ?+
Oui ! Toutes les fonctions de fenêtrage SQL standard (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) et les cadres `ROWS`/`RANGE`/`GROUPS` fonctionnent 100 % hors ligne.
SuperCode prend-il en charge `MEDIAN()`, `PERCENTILE()` et `STDDEV()` directement en SQL ?+
Oui. Alors que SQLite standard manque d'agrégats statistiques, SuperCode pré-enregistre nativement `MEDIAN(col)`, `PERCENTILE(col, 95)` et `STDDEV(col)` pour calculer vos distributions en un seul `SELECT`.
Comment fonctionne `READ_STDIN()` dans une requête `.sql` ?+
Écrivez `WHERE department = READ_STDIN('Nom du service : ')` dans votre fichier `.sql` et touchez Exécuter — SuperCode vous invite à saisir la valeur dans la console ancrée pour relancer la requête sans modifier le code.
La recherche plein texte FTS5 et les modules spatiaux R*Tree / Geopoly sont-ils activés ?+
Oui. `USING fts5(...)` (avec `bm25()`, `highlight()` et `snippet()`) ainsi que les extensions spatiales `USING rtree(...)` / Geopoly sont compilés directement dans le moteur SQLite 3.54.1 hors ligne de SuperCode.
