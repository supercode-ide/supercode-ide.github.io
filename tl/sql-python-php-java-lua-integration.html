05 MGA TANONG AT SAGOT

Mga Madalas Itanong

Mga madalas itanong tungkol sa pag-share ng `.db` files sa iba't ibang wika at pag-edit ng malalaking `.sql` dumps sa Android.

Kailangan ko bang mag-download ng `.jar` file para magamit ang `jdbc:sqlite:app.db` sa Java 17?+
Hindi! Naka-pre-bundle na sa SuperCode ang SQLite JDBC driver direkta sa offline Java 17 classpath — isulat lang ang `DriverManager.getConnection("jdbc:sqlite:app.db")` at pindutin ang Run.
Nakakapagbasa at nakakapagsulat ba talaga ang Python, PHP, Java, at Lua sa mismong `app.db` file?+
Oo. Basta nasa parehong workspace folder ang mga `.sql`, `.py`, `.php`, `.java`, at `.lua` files mo (o naka-point sa parehong relative path), lahat sila ay magbabasa at magko-commit ng ACID transactions sa iisang `app.db` file sa disk.
Paano gamitin ang SQLite sa loob ng Lua 5.4 scripts sa SuperCode?+
I-call lang ang `local sqlite3 = require('lsqlite3')` at `local db = sqlite3.open('app.db')`. Naka-build in ang embedded `lsqlite3` sa offline Lua 5.4 runtime ng SuperCode na may sub-millisecond startup.
Kaya bang buksan ng SuperCode ang 1 GB+ `.sql` database dump nang hindi nagka-crash ang phone ko?+
Oo. Direktang nag-i-stream mula sa disk pages ang GB Large File Editor ng SuperCode para sa malalaking `.sql`, `.csv`, at `.log` files sa halip na i-load ang buong file sa RAM — kumpleto sa regex search/replace at encoding detection.
