05 MGA TANONG AT SAGOT

Mga Madalas Itanong

Mga karaniwang tanong tungkol sa pagpapatakbo ng `.sh` scripts nang walang root at pag-ayos ng `Permission denied` sa Android.

Bakit lumalabas ang `Permission denied` kapag pinapatakbo ang `.sh` file mula sa Android Downloads?+
Para sa seguridad, naka-mount ang shared user storage ng Android (`/sdcard`, `Downloads`, `Documents`) gamit ang `noexec` filesystem flag, kaya kahit `chmod +x` ay hindi kayang gawing executable ang files doon. Maayos na pinapatakbo ng SuperCode ang script sa native runtime nito habang awtomatikong sini-sync ang iyong project folder.
Kailangan ba ng rooted na Android phone para magpatakbo ng shell scripts sa SuperCode?+
Hindi. Gumagana agad ang SuperCode sa standard, hindi rooted na Android 8.0+ phones, foldables, at tablets.
Paano magpasa ng command-line arguments tulad ng `./deploy.sh --env staging`?+
Idagdag ang `# @args --env staging` malapit sa itaas ng script mo (o magbigay ng input gamit ang `read -p`), at ipapasa ng SuperCode ang mga positional parameters na iyon (`$1`, `$2`, `$@`) diretso sa script pagka-Run.
Pwedeng gumawa ng bagong files o folders sa loob ng workspace ko ang isang `.sh` script?+
Oo. Lahat ng files, logs, o archives na ginawa relative sa `$PWD` habang tumatakbo ay awtomatikong sini-sync pabalik sa active Android project directory mo.
