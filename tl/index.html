05 MGA TANONG AT SAGOT

Mga Madalas Itanong

Direktang sagot tungkol sa mga offline compiler, paghawak ng malalaking file, suportadong wika, at Git/SFTP workflows.

Aling mga programming language ang tumatakbo offline sa SuperCode IDE sa Android?+
Lokal na pinapatakbo ng SuperCode sa Android ang Python (3.11 & scientific 3.12), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, PHP, HTML5/CSS3/WebAssembly, Lua 5.4, at Linux Shell scripts, na may opsyonal na cloud support para sa Kotlin, MySQL 8.0, at mabibigat na server framework.
Nakakapagbukas ba ang SuperCode ng gigabyte-sized log files at SQL dumps nang hindi nagfi-freeze?+
Oo. Awtomatikong bumubukas ang GB-Scale Streaming Pager para sa mga file na higit sa 30 MB, hinahati ang daan-daang MB at GB files sa 10M-character disk chunks na may instant page jump, 34-charset detection, at Global Stream Regex Replace.
Hiwalay at nakalaan ba ang mga environment para sa C at C++, o SQL at Web/PHP?+
Oo. May kanya-kanyang standard, header, at template ang C17 at C++20; ang SQL ay may sariling 9-mode console at .db binary inspector; at ang Web Studio ay nagpapatakbo ng totoong lokal na HTTP + PHP + PDO SQLite + WebAssembly preview server na may built-in DevTools.
May built-in Git client at SFTP/FTPS remote editor ba ang SuperCode?+
Oo. May kasama itong sariling Visual Git Client (Clone gamit ang PAT, Branching, Commit Time Machine unified diffs, at Merge Conflict Resolver) plus AES-256 encrypted na SFTP, FTPS (TLS 1.3), at FTP workspace na may 3-phase atomic remote save.
Optimized ba ang SuperCode para sa parehong Android phone at tablet?+
Oo. Sa mga phone, abot-kamay ng hinlalaki ang mga toolbar na may right-edge swipe menu at auto-collapsing split console; sa mga foldable at tablet, nakadikit nang patayo ang toolbar at nagbubukas ang terminal sa 55% / 45% side-by-side workstation.
