05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Preguntas frecuentes sobre edición HTML5/CSS3/JS, ES Modules y vistas previas responsivas en Android.

¿Por qué fallan `<script type="module">` o `fetch('./data.json')` en otras apps editoras de HTML?+
Los navegadores bloquean los ES Modules y `fetch()` en URLs `file://` por reglas estrictas de seguridad CORS. SuperCode sirve tu proyecto automáticamente desde un origen HTTP/1.1 `localhost` real con cabeceras MIME adecuadas, para que los módulos JS modernos y cargas JSON funcionen de forma nativa y sin conexión.
¿Cómo puedo previsualizar media queries CSS de Tablet y Escritorio en la pantalla de un smartphone?+
Dentro de la vista previa web en vivo de SuperCode, toca el ícono de viewport en la Dynamic Island flotante para cambiar al instante entre Móvil, Tablet (`768dp`) y Escritorio ancho — activando tus reglas `@media` con total precisión.
¿El formateador de 1 toque también formatea el CSS dentro de `<style>` y el JS dentro de `<script>`?+
Sí. El formateador HTML recursivo de SuperCode analiza los bloques `<style>` y `<script>` integrados dentro de archivos `.html` e indenta limpiamente los tres lenguajes en un solo toque.
¿Puedo usar videos `.mp4`, fuentes `.woff2` y modelos 3D `.glb` locales sin conexión?+
Sí. Hay más de 65 tipos MIME preconfigurados localmente, incluidos `font/woff2`, `model/gltf-binary`, `image/svg+xml` y streaming por rango de bytes HTTP `206 Partial Content` para adelantar o retroceder `<video>` y `<audio>` sin cortes.
