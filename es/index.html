05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Respuestas directas sobre compiladores offline, manejo de archivos pesados, lenguajes soportados y flujos con Git/SFTP.

¿Qué lenguajes de programación funcionan sin internet en SuperCode IDE para Android?+
SuperCode ejecuta localmente en Android Python (3.11 y científico 3.12), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, PHP, HTML5/CSS3/WebAssembly, Lua 5.4 y scripts de Shell Linux, con soporte opcional en la nube para Kotlin, MySQL 8.0 y frameworks pesados de servidor.
¿Puede SuperCode abrir archivos de texto grandes GB y volcados SQL sin congelarse?+
Sí. Al abrir archivos mayores de 30 MB se activa automáticamente el Paginador por Streaming a Escala GB, que divide archivos de cientos de MB o gigabytes en páginas en disco de 10 millones de caracteres con salto instantáneo, detección de 34 codificaciones y Reemplazo Global por Stream con Regex.
¿Son C y C++, o SQL y Web/PHP, entornos dedicados e independientes?+
Sí. C17 y C++20 cuentan con estándares, cabeceras y plantillas propios; SQL dispone de su consola de 9 modos e inspector binario .db; y el Estudio Web ejecuta un servidor HTTP local real + PHP + PDO SQLite + WebAssembly con DevTools integradas.
¿Incluye SuperCode un cliente Git visual y editor remoto SFTP/FTPS integrado?+
Sí. Incorpora un Cliente Git Visual autónomo (clonado con PAT, ramas, diffs unificados en Máquina del Tiempo y resolución visual de conflictos) junto con un espacio remoto SFTP, FTPS (TLS 1.3) y FTP cifrado con AES-256 y guardado atómico en 3 fases.
¿Está optimizado SuperCode tanto para teléfonos como para tablets Android?+
Sí. En móviles, las barras quedan al alcance del pulgar con un menú deslizable en el borde derecho y consola dividida auto-plegable; en plegables y tablets, la barra se acopla verticalmente y la terminal se abre lado a lado en proporción 55% / 45%.
