03 GUÍA PASO A PASO

Guía Completa en 6 Pasos: Cómo Usar Git en SuperCode IDE

Sigue este flujo paso a paso dentro de SuperCode para clonar, crear ramas, revisar diffs, fusionar y hacer push desde tu teléfono o tablet.

STEP 01 Menu -> Git Controls -> Clone

Clona un Repositorio Remoto o Monta uno Local

Pega tu URL HTTPS (ej. https://github.com/usuario/repo.git) y tu token PAT opcional, y toca CLONAR — o pulsa Montar Repositorio Existente si la carpeta ya tiene .git.

STEP 02 Time Machine -> Branch ▾

Cambia de Rama o Crea una Rama de Función

Abre la Máquina del Tiempo Git y toca el selector superior para cambiar de rama o pulsa + Crear Nueva Rama… (ej. feature/login-movil) con validación automática de nombres.

STEP 03 Editor Tabs -> Save / Edit

Edita Código Multiarchivo con Inteligencia Completa

Modifica, formatea y prueba tu código offline. Aunque olvides guardar alguna pestaña abierta, las operaciones Git vuelcan los cambios pendientes a disco automáticamente.

STEP 04 Git Dashboard -> Pull

Descarga Cambios de tu Equipo de Forma Segura

Toca Pull antes de subir tus cambios. Las ediciones locales no confirmadas se protegen con auto-stash y las pestañas abiertas se actualizan sin mover tu cursor.

STEP 05 Open Conflict Resolver

Resuelve Colisiones de Fusión Visualmente

Si hay ediciones superpuestas, toca Abrir Resolutor de Conflictos, compara bloques Local vs Remoto lado a lado, elige Actual / Entrante / Ambos y aplica las soluciones.

STEP 06 Commit & Push

Revisa Archivos Pendientes, Escribe el Mensaje y Sube

Verifica las etiquetas [M]/[A]/[D] en Cambios Pendientes, confirma tu identidad de Autor y mensaje de commit, y toca COMMIT para confirmar y subir a origin.

Recuperación Automática de index.lock Huérfanos · Admite Commits Locales Sin Internet Guía App

05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Respuestas prácticas sobre Personal Access Tokens de GitHub, repositorios privados, conflictos de fusión e historial de commits.

¿Cómo me autentico en repositorios privados de GitHub, GitLab o Gitee?+
Genera un Personal Access Token (PAT) HTTPS con permisos de repositorio (repo) en GitHub/GitLab/Gitee y pégalo en el campo Token al hacer Clone, Commit y Push o Pull. SuperCode lo guarda de forma cifrada para que no tengas que escribirlo cada vez.
¿Qué pasa si toco Pull teniendo pestañas sin guardar o cambios sin confirmar?+
SuperCode guarda primero las pestañas modificadas en disco, aplica auto-stash sobre tus cambios locales en seguimiento, descarga los últimos commits remotos, reaplica tu trabajo y recarga las pestañas abiertas en tu línea exacta.
¿Cómo veo qué cambió en un commit anterior o vuelvo atrás en el historial?+
Abre la Máquina del Tiempo Git desde el Panel Git y toca cualquier commit de la línea temporal. Elige Ver Cambios de Código (Diff) para ver el diff en color, Checkout (Solo Vista) para inspeccionarlo sin riesgo o Hard Reset para rebobinar la rama.
¿Puedo hacer commits sin conexión cuando no tengo internet?+
¡Sí! Preparar cambios, hacer commits locales, crear ramas, consultar el historial, revisar diffs unificados y resolver conflictos funciona todo sin internet; podrás hacer push a origin en cuanto recuperes la conexión.
