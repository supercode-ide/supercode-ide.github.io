05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Respuestas a dudas comunes sobre ejecutar PHP 8.2, PDO SQLite, sesiones y subida de archivos sin conexión en Android.

¿SuperCode ejecuta PHP 8.2 completamente sin conexión a internet?+
Sí. El motor PHP 8.2 y el controlador de base de datos PDO SQLite de SuperCode corren 100% en tu dispositivo Android — puedes crear y probar sitios PHP multipágina, formularios de login y APIs JSON en modo avión.
¿Por qué elegir SuperCode sobre KSWEB o correr `php -S` en una app de terminal?+
Los daemons de servidor independientes exigen rutas manuales de virtual-host, dejan servicios corriendo en segundo plano y te obligan a saltar entre tres apps (editor, servidor, navegador). SuperCode unifica edición AST de PHP, enrutamiento HTTP automático en la raíz del proyecto, Web DevTools, SQL Studio y publicación SFTP en un solo IDE ligero.
¿El JavaScript del frontend puede llamar a mis archivos `.php` locales con `fetch()`?+
¡Sí! Como tu espacio de trabajo se sirve sobre un origen HTTP/1.1 `localhost` real, `await fetch('/api/tasks.php', { method: 'POST', ... })` funciona sin problemas con encabezados JSON, cookies y tiempos de red en DevTools.
¿Puedo inspeccionar el archivo `.db` de SQLite creado por PHP `new PDO('sqlite:app.db')`?+
De inmediato. Toca `app.db` en el explorador de archivos de SuperCode para inspeccionar sus tablas, esquema y filas en formato de cajas Unicode o Markdown dentro de SQL Studio.
