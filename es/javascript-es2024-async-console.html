05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Preguntas frecuentes sobre sintaxis ES2024, `await` de nivel superior, `fetch()` y protección contra bucles infinitos.

¿Puedo ejecutar archivos JavaScript directo en SuperCode sin crear un archivo HTML?+
¡Sí! SuperCode cuenta con un motor de consola JavaScript independiente aparte de su Web IDE HTML5. Solo abre cualquier archivo `.js`, `.mjs` o `.cjs` y toca Ejecutar ▶.
¿Cómo uso `await` de nivel superior sin envolver el código en una `async function main()`?+
Guarda tu archivo como `.mjs` (o configura `\"type\": \"module\"` en `package.json`, o escribe directamente `await` en el nivel superior dentro de un script ES Module) — SuperCode ejecuta `await` de nivel superior de forma nativa y espera a que todas las Promises finalicen.
¿Qué pasa si escribo por accidente un bucle infinito `while (true)` en mi teléfono?+
Tu editor y tus archivos sin guardar permanecen 100% fluidos porque los scripts corren en un hilo worker aislado en segundo plano. Toca el botón Detener ■ (o deja que actúe el guardián de CPU de 15 segundos) para terminar el worker en menos de 1 milisegundo.
¿Funciona `fetch()` dentro de scripts JavaScript independientes?+
Sí. `fetch()`, `Headers`, `Request`, `Response` y `AbortController` estándar vienen integrados en el runtime del worker para probar APIs HTTPS en vivo siempre que tu dispositivo tenga conexión.
