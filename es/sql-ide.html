05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Respuestas sobre cómo practicar SQL sin conexión, abrir archivos .db/.sqlite, importar CSV/JSON y usar sintaxis MySQL.

¿Puedo practicar consultas SQL sin internet y sin instalar un servidor de bases de datos?+
¡Sí! Crea cualquier archivo .sql y pulsa Ejecutar para correr sentencias múltiples CREATE, INSERT, JOIN, CTE y Funciones de Ventana 100% offline con tablas Unicode perfectamente alineadas.
¿Puede SuperCode abrir archivos .db y .sqlite que ya tenga en mi teléfono?+
Sí. Al tocar o ejecutar un archivo .db, .sqlite, .sqlite3 o .db3 se inspeccionan todas sus tablas, vistas, índices y esquemas, y cualquier script .sql en esa misma carpeta puede consultar la base directamente.
¿Admite sintaxis de MySQL como AUTO_INCREMENT, SHOW TABLES, DESCRIBE o Procedimientos Almacenados?+
Los comandos y DDL habituales de MySQL/PostgreSQL (AUTO_INCREMENT, ENUM, SHOW TABLES, DESCRIBE, ILIKE) corren localmente offline, mientras que los Procedimientos Almacenados y Triggers propios de MySQL 8.0 se enrutan automáticamente a Cloud MySQL 8.0.
¿Cómo exporto los resultados de una consulta SQL a CSV, Markdown o JSON?+
Añade `.mode csv` (o `.mode markdown` / `.mode json`) y `.once salida.csv` antes de tu consulta SELECT — SuperCode guardará el archivo exportado directamente en la carpeta de tu proyecto.
