05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Respuestas para quienes inician en Java, estudiantes de AP Computer Science A, docentes y candidatos a entrevistas.

¿Puedo usar SuperCode para estudiar para el examen AP Computer Science A sin Wi-Fi?+
¡Sí! Cada clase de Java, arreglo, `ArrayList`, método de `String`, jerarquía de herencia y patrón de recursión evaluado en el examen AP Computer Science A compila y se ejecuta 100% sin conexión en tu teléfono o tablet.
¿Por qué falla mi `Scanner(System.in)` en compiladores web al leer varias líneas y cómo lo maneja SuperCode?+
Muchos compiladores en línea te obligan a escribir todas las entradas a ciegas antes de presionar Ejecutar. SuperCode transmite `System.in` de forma interactiva en tiempo real — muestra primero tu mensaje, espera a que escribas cada línea e incluye un botón `[EOF]` para bucles `while (sc.hasNext())`.
¿Necesito crear una cuenta o iniciar sesión antes de escribir código Java?+
Nunca. SuperCode abre directamente en el espacio de trabajo sin pantallas de registro, para que estudiantes y clases puedan empezar a programar de inmediato.
¿Puedo pasar después de `void main()` compacto a paquetes Java multiclase estándar?+
Sí. `void main()` compacto es una comodidad opcional para ejercicios rápidos — cuando escribes archivos estándar `public class Main`, múltiples clases `.java`, interfaces o proyectos de base de datos `jdbc:sqlite`, SuperCode los compila sin cambiar de modo.
