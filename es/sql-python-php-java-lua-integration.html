05 PREGUNTAS Y RESPUESTAS

Preguntas Frecuentes

Preguntas frecuentes sobre compartir archivos `.db` entre lenguajes y editar volcados `.sql` enormes en Android.

¿Necesito descargar un archivo `.jar` para usar `jdbc:sqlite:app.db` en Java 17?+
¡No! SuperCode ya incluye el driver SQLite JDBC directamente en el classpath de Java 17 sin conexión — solo escribe `DriverManager.getConnection("jdbc:sqlite:app.db")` y presiona Ejecutar.
¿Pueden Python, PHP, Java y Lua leer y escribir realmente el mismo archivo `app.db`?+
Sí. Mientras tus archivos `.sql`, `.py`, `.php`, `.java` y `.lua` estén en la misma carpeta del workspace (o apunten a la misma ruta relativa), todos leen y confirman transacciones ACID sobre el idéntico archivo `app.db` en disco.
¿Cómo uso SQLite dentro de scripts Lua 5.4 en SuperCode?+
Llama a `local sqlite3 = require('lsqlite3')` y `local db = sqlite3.open('app.db')`. El módulo `lsqlite3` integrado viene compilado en el runtime Lua 5.4 sin conexión de SuperCode con arranque en menos de un milisegundo.
¿SuperCode puede abrir un volcado de base de datos `.sql` de 1 GB+ sin colgar mi teléfono?+
Sí. El editor de archivos grandes GB de SuperCode transmite archivos `.sql`, `.csv` y `.log` enormes directamente desde páginas en disco sin cargar todo el archivo en RAM — completo con búsqueda/reemplazo regex y detección de codificación.
