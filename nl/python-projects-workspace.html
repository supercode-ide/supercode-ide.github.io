05 VRAGEN & ANTWOORDEN

Veelgestelde vragen

Vragen over `src/`-indelingen, relatieve imports, `unittest` en Git-integratie voor Python op Android.

Wat gebeurt er als ik op Run druk terwijl ik een hulpmodule zoals `utils/helpers.py` bewerk?+
Als `helpers.py` alleen functies of klassen definieert zonder hoofduitvoercode, zoekt SuperCode automatisch het startscript van je project (`main.py`, `app.py`, `run.py`, `__main__.py` of `src/main.py`) en voert de volledige applicatie uit.
Ondersteunt SuperCode Python 3.12-syntaxis zoals `match/case` en `type`-aliassen?+
Structurele `match/case` en `tomllib` werken offline in Python 3.11+, en bestanden die PEP 695 generieke `type`-aliassyntaxis gebruiken activeren automatisch Python 3.12-ondersteuning.
Heb ik `__init__.py` nodig in elke map om imports tussen mappen te laten werken?+
Nee. SuperCode respecteert PEP 420 impliciete namespace-packages en koppelt je projectroot netjes zonder ongewenste `__init__.py`-bestanden aan je repository toe te voegen.
Kan ik privé GitHub-repositories klonen en hun Python-tests offline uitvoeren?+
Ja. Kloon via HTTPS + Personal Access Token in Visual Git, installeer `requirements.txt` één keer in batch en bewerk/draai `unittest`-suites overal volledig offline.
