05 VRAGEN & ANTWOORDEN

Veelgestelde vragen

Veelgestelde vragen van JavaScript-beginners, bootcamp-studenten en sollicitanten.

Is SuperCode helemaal gratis om offline te beginnen met JavaScript leren?+
Ja! Je kunt onbeperkt `.js`-, `.mjs`-, `.json`- en `.html`-bestanden aanmaken, alle 6 ingebouwde JavaScript-templates draaien, de 21-toetsen symboolbalk gebruiken, code formatteren en gratis offline ES2024 + Node Core-scripts uitvoeren zonder in te loggen.
Kan ik SuperCode gebruiken als offline JSON-formatter en -validator op Android?+
Ja. Open of plak elk `.json`-bestand (zelfs payloads van meerdere megabytes), bekijk de exacte regel-/kolomfouten in de Foutenradar en tik op Formatteren om alles in één stap netjes in te springen of op te schonen.
Draait SuperCode ook HTML, CSS en DOM JavaScript als ik websites wil bouwen?+
Zeker. Zodra je vanuit losse console-JS wilt overstappen naar visuele webpagina's, toont SuperCode's ingebouwde Web IDE direct een preview van multi-file HTML5, CSS3, DOM JavaScript en zelfs offline PHP + SQLite via een echte lokale HTTP-server.
Kan ik ook TypeScript-syntax oefenen?+
SuperCode biedt volledige TypeScript (`.ts` / `.tsx`) syntax highlighting, AST-symboolherkenning, de 21-toetsen JS/TS-symboolbalk en 1-tik formattering, plus standalone offline ES2024 `.js`/`.mjs`-uitvoering.
