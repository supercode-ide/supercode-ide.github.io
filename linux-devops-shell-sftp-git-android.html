05 QUESTIONS & ANSWERS

Frequently Asked Questions

Questions from Linux sysadmins, SREs, and homelab engineers using SuperCode on Android.

Will editing a remote `.sh` script over SFTP strip its `chmod 0755` executable bit?+
Never. SuperCode inspects the remote file's existing POSIX mode before saving and preserves `0755` (or custom permissions) across its 3-phase atomic staging rename.
How does SuperCode protect my SSH private keys and SFTP passwords?+
All SFTP/FTPS credentials, host profiles, and imported SSH private keys (`Ed25519`, `RSA`, `ECDSA`) are encrypted on device using hardware-backed Android Keystore AES-256 protection.
What happens if my mobile signal drops halfway through saving `nginx.conf`?+
Because SuperCode uploads to a temporary staging file first and performs an atomic server-side rename only after transfer verification succeeds, your live `nginx.conf` is never left half-written or empty.
Can I inspect a 1.5 GB server log downloaded from SFTP without crashing my phone?+
Yes! SuperCode's Large File Editor mounts multi-gigabyte files in disk-backed pages rather than loading the entire file into RAM, complete with Global Stream Regex Replace.
