05 ВОПРОСЫ И ОТВЕТЫ

Часто задаваемые вопросы (FAQ)

Прямые ответы об офлайн-компиляторах, открытии гигабайтных файлов, поддерживаемых языках и работе с Git/SFTP.

Какие языки программирования работают в SuperCode IDE на Android без интернета?+
Локально на устройстве запускаются Python (3.11 и научный 3.12), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, динамический PHP, HTML5/CSS3/WebAssembly, Lua 5.4 и скрипты Linux Shell, а для Kotlin, MySQL 8.0 и тяжёлых серверных фреймворков предусмотрена опциональная облачная поддержка.
Может ли SuperCode открывать гигабайтные лог-файлы и дампы SQL без зависаний?+
Да. Для файлов крупнее 30 МБ автоматически включается потоковый ГБ-пейджер, разбивающий файлы в сотни МБ и гигабайты на дисковые страницы по 10 млн символов с мгновенным переходом по страницам, автоопределением 34 кодировок (включая Windows-1251 и KOI8-R) и глобальной потоковой Regex-заменой.
Разделены ли C и C++, а также SQL и Web/PHP на самостоятельные рабочие среды?+
Да. У C17 и C++20 раздельные стандарты, заголовки и шаблоны; для SQL создана собственная консоль с 9 режимами вывода и бинарным инспектором .db; а Веб-студия поднимает настоящий локальный HTTP-сервер с PHP, PDO SQLite, WebAssembly и встроенными DevTools.
Есть ли в SuperCode встроенный клиент Git и редактор удалённых серверов SFTP/FTPS?+
Да. В IDE встроены автономный визуальный Git-клиент (клонирование по PAT, ветки, цветной Unified Diff в Машине времени и разрешение конфликтов слияния) и защищённое шифрованием AES-256 пространство SFTP, FTPS (TLS 1.3) и FTP с 3-фазным атомарным сохранением.
Оптимизирован ли интерфейс SuperCode и для смартфонов, и для планшетов на Android?+
Да. На смартфонах панели расположены под большим пальцем с меню бокового свайпа и автосворачиванием консоли при печати, а на складных экранах и планшетах панель закрепляется вертикально, открывая терминал рядом с кодом в пропорции 55% / 45%.
