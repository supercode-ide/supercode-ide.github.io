02 КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ

Полный стек персистентности, файлового I/O и сети для Java 17

Выполняйте лабораторные по базам данных, отрабатывайте паттерн DAO, парсите CSV/JSON и пишите REST-клиенты в едином рабочем пространстве Android.

02.1

Встроенный офлайн-драйвер SQLite JDBC без настройки

Напишите DriverManager.getConnection(\"jdbc:sqlite:campus.db\") или \"jdbc:sqlite::memory:\" и нажмите Запуск. SuperCode заранее регистрирует org.sqlite.JDBC офлайн — без поиска .jar-драйвера, хаков с Class.forName() или шаблонного pom.xml.

jdbc:sqlite:app.db · :memory: · Нулевая настройка драйвера
02.2

PreparedStatement, ACID-транзакции и пакетные DAO-запросы

Защищайтесь от SQL-инъекций с помощью параметризованных PreparedStatement, выполняйте атомарные переводы между таблицами через setAutoCommit(false) и rollback(), включайте PRAGMA foreign_keys и инспектируйте ResultSetMetaData.

PreparedStatement · ACID Rollback · executeBatch()
02.3

Переход в визуальный SQL Studio в один тап

Любой файл .db или .sqlite3, созданный вашим Java JDBC-кодом, сразу появляется в дереве проекта. Нажмите на него, чтобы открыть схемы, индексы и таблицы в SQL Studio от SuperCode в режимах Box, Markdown, CSV или JSON.

Общая папка .db · Визуальная схема и просмотр таблиц

Полноценный файловый ввод-вывод Java NIO.2 и классических потоков

java.nio.file.Files · Path.of() · Сохранение на диск

Стандартный java.net.http.HttpClient и локальный HttpServer

Обращайтесь к REST JSON API через современный HttpClient (синхронный send() или неблокирующий sendAsync() с CompletableFuture, таймаутами и заголовками) или поднимайте лёгкие маршруты на com.sun.net.httpserver.HttpServer.

03 ПОШАГОВОЕ РУКОВОДСТВО

Как создать проект Java + SQLite JDBC на Android

Пройдите путь от пустой папки до постоянной БД JDBC и визуальной проверки SQL за пару секунд.

STEP 01 import java.sql.*;

Подключитесь через DriverManager.getConnection(\"jdbc:sqlite:...\")

Откройте любой .java файл и подключитесь по относительному имени БД (например, jdbc:sqlite:store.db) — драйвер загрузится автоматически офлайн.

STEP 02 PreparedStatement

Выполните DDL, параметризованные INSERT и JOIN-запросы

Выполняйте CREATE TABLE, пакетные INSERT и выборки SELECT JOIN офлайн либо подгружайте исходные .csv через Files.readAllLines().

STEP 03 Explorer -> store.db

Откройте созданный .db файл в SQL Studio

Нажмите на синхронизированный файл store.db в Проводнике, чтобы просмотреть таблицы, выполнить произвольный SQL или экспортировать выборку в Markdown/CSV.

STEP 04 Visual Git / Export

Экспортируйте отчёты или закоммитьте проект DAO

Проверьте выгруженные CSV/JSON в редакторе, распечатайте исходный код в A4 PDF или зафиксируйте многоклассовый репозиторий DAO через Visual Git.

05 ВОПРОСЫ И ОТВЕТЫ

Часто задаваемые вопросы (FAQ)

Вопросы о строках подключения JDBC, сохранении файлов `.db`, путях NIO.2 и `HttpClient` на Android.

Нужно ли вызывать `Class.forName("org.sqlite.JDBC")` или добавлять зависимость Maven для работы с SQLite в Java?+
Нет! SuperCode уже включает и автоматически регистрирует `org.sqlite.JDBC` из коробки. Просто импортируйте `java.sql.*` и вызовите `DriverManager.getConnection("jdbc:sqlite:mydb.db")` — всё сразу работает на 100% офлайн.
Куда сохраняются файлы `.db`, `.csv` и `.txt`, когда их записывает моя Java-программа?+
Относительные пути вроде `jdbc:sqlite:inventory.db` или `Path.of("report.csv")` разрешаются относительно папки вашего активного проекта и синхронизируются с рабочим пространством Android сразу после завершения выполнения.
Можно ли заранее наполнить базу SQLite в SQL Studio от SuperCode, а затем обращаться к ней из Java?+
Да! Это один из самых популярных сценариев в SuperCode: спроектируйте таблицы и заполните их тестовыми данными в SQL Studio (`schema.sql` -> `app.db`), затем откройте `.java` класс DAO в той же папке и свободно делайте запросы к `jdbc:sqlite:app.db`.
Работает ли `java.net.http.HttpClient` для тестирования REST API?+
Да. Стандартные классы Java 11/17 `HttpClient`, `HttpRequest` и `HttpResponse` работают из коробки для HTTPS REST-запросов при подключении к сети, а операции JDBC и NIO.2 с файлами полностью работают офлайн.
