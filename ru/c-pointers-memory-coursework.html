05 ВОПРОСЫ И ОТВЕТЫ

Часто задаваемые вопросы (FAQ)

Ответы для студентов, переходящих с Turbo C, изучающих malloc/free и сдающих лабораторные по C в вузе.

Почему при изучении C не стоит использовать `<conio.h>`, `clrscr()` и `getch()`?+
`<conio.h>` — нестандартный заголовок MS-DOS из 1980-х годов, который отклоняет любой современный сервер проверки на Linux, macOS и в вузах. SuperCode компилирует стандартный ISO/GNU C17 (`<stdio.h>`, `<stdlib.h>`, `getchar()`, `fgets()`), поэтому ваши знания напрямую пригодятся на экзаменах и в системной разработке.
Компилирует ли SuperCode файлы `.c` настоящим компилятором C, а не C++?+
Да. В C функция `malloc()` возвращает `void *`, который неявно приводится к типизированному указателю без каста, тогда как C++ это запрещает. SuperCode компилирует файлы `.c` в строгом режиме GNU C17 (`-std=gnu17`), поэтому стандартные идиомы C17 работают корректно.
Нужно ли вручную передавать флаг `-lm` при использовании `sqrt()`, `pow()` или `sin()`?+
Нет. SuperCode автоматически линкует стандартную математическую библиотеку (`-lm`) при каждой сборке C17, поэтому функции из `<math.h>` работают сразу.
Что произойдет, если случайно разыменовать битый указатель или написать бесконечный цикл `while(1)`?+
Сеанс редактора останется в полной безопасности: изолированный дочерний процесс аккуратно выведет код аварийного завершения, а 20-секундный watchdog по CPU остановит бесконечный цикл без зависания телефона.
