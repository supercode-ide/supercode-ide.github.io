05 ВОПРОСЫ И ОТВЕТЫ

Часто задаваемые вопросы (FAQ)

Частые вопросы о синтаксисе ES2024, top-level `await`, `fetch()` и защите от бесконечных циклов.

Можно ли запускать файлы JavaScript прямо в SuperCode без создания HTML-файла?+
Да! В SuperCode есть отдельный консольный движок JavaScript, независимый от HTML5 Web IDE. Просто откройте любой файл `.js`, `.mjs` или `.cjs` и нажмите Запуск ▶.
Как использовать top-level `await`, не оборачивая код в `async function main()`?+
Сохраните файл с расширением `.mjs` (или укажите `\"type\": \"module\"` в `package.json`, либо просто используйте top-level `await` в скрипте ES-модуля) — SuperCode выполняет top-level `await` нативно и дожидается завершения всех Promise.
Что будет, если я случайно напишу бесконечный цикл `while (true)` на телефоне?+
Редактор и несохранённые файлы останутся на 100% отзывчивыми, так как скрипты выполняются в изолированном фоновом потоке воркера. Нажмите Стоп ■ (или дождитесь срабатывания 15-секундного сторожевого таймера CPU), чтобы остановить воркер быстрее чем за 1 миллисекунду.
Работает ли `fetch()` внутри автономных скриптов JavaScript?+
Да. Стандартные `fetch()`, `Headers`, `Request`, `Response` и `AbortController` встроены прямо в среду выполнения воркера для тестирования живых HTTPS API при наличии подключения к сети.
