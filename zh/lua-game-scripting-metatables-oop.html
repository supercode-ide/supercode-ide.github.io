在 SuperCode 中练习 Lua 5.4 能直接迁移到 Roblox (Luau) 和 Love2D 吗？+
完全可以！核心的 Lua 表、闭包、词法作用域、元表（`__index`、`__add`）、协程、数学库以及模块化 `return M` 写法，正是 Roblox Luau、Love2D、Defold、Solar2D 以及魔兽世界 / Garry's Mod 插件共同的技术基石。
SuperCode 能直接渲染 3D Roblox 场景或 Love2D OpenGL 窗口吗？+
SuperCode 专注于在原生终端中高效打磨解耦后的游戏玩法逻辑、数据驱动 RPG 系统、基于 SQLite/JSON 的背包存档以及算法原型 — 让你随时随地完善核心模块脚本，并通过 Git 同步到桌面端渲染器。
SuperCode 如何避免 Lua OOP 中的 `.` 与 `:` 调用错误？+
当你输入 `entity:` 或 `Entity.` 时，SuperCode 的离线 AST 自动补全会根据上下文过滤候选项，将冒号定义的实例方法与静态模块函数明确区分开来。
应用内是否自带可供离线学习的入门游戏脚本？+
是的。内置 8 个可直接运行的 Lua 模板 — 包括 `adventure.lua`、`guess.lua`、`metatables.lua` 和 `tables.lua` — 100% 支持离线学习与运行。
