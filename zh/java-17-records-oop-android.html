05 常见问答

常见问题解答 (FAQ)

关于 Android 端离线 Java 17 语法支持、旧版工具迁移及 Java 21+ 特性的常见解答。

SuperCode 真的能在断网状态下编译 Java 17 Record 和密封类吗？+
是的。首次启动初始化轻量级离线 Java 17 SDK 后，`record`、`sealed` / `permits`、`switch ->` 表达式、`instanceof` 模式匹配、文本块（`"""`）以及 `Stream.toList()` 均可在飞行模式下 100% 离线编译运行。
作为 Java 8 或 Java 11 手机应用的现代替代品，SuperCode 有何优势？+
老旧 Android Java 应用在运行使用 `record` 元组、`Stream.toList()` 或 switch 表达式的现代高校作业和算法题解时经常报错。SuperCode 离线支持完整 LTS Java 17，并提供自动云端 Java 21+ 回退、可视化 Git 及内置 SQLite JDBC。
我可以在离线状态下使用 `CompletableFuture`、`Optional` 和 `java.time` 吗？+
可以。完整核心标准库 — 包括 `java.util.stream`、`java.util.concurrent.CompletableFuture`、`java.time.*`、`java.math.BigDecimal` 及 `java.nio.file` — 均可原生离线运行。
如何在 Android 手机上运行 Java 21 虚拟线程？+
只需在代码中编写 `Thread.ofVirtual()` 或 `Executors.newVirtualThreadPerTaskExecutor()`（或在文件顶部添加 `// @cloud`）并点击运行。SuperCode 会自动将项目类打包至云端 Java 21+ 执行，并将输出流式回传到终端。
