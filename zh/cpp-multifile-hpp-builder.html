05 常见问答

常见问题解答 (FAQ)

关于 21 套 C++ 工程模板、`.hpp`/`.inl` 文件、`#pragma once` 以及在 Android 上使用 CMake 的常见问题。

SuperCode 的 21 套多文件 C++ 入门工程具体包含哪些内容？+
这 21 套工程模板都会生成一个结构清晰的目录，内含模块化的 `.h`/`.hpp` 头文件、`.cpp` 实现文件、`main.cpp` 驱动入口以及标准的 `CMakeLists.txt`—让你能够立刻运行、研读并定制一套完整的多类架构工程。
在 SuperCode 中创建的 CMake 工程，能拿去电脑上的 CLion 或 VS Code 打开吗？+
完全可以！由于生成的项目采用标准 `CMakeLists.txt` 文件以及可移植的 ISO/GNU C++20 目录结构，你可以通过 Git 无缝在桌面端 IDE 中打开，没有任何专有工程格式绑定。
SuperCode 支持纯头文件库（Header-Only）以及 `.inl` / `.ipp` 模板实现文件吗？+
支持。无论是使用 `#pragma once` 的头文件，还是位于 `include/` 及嵌套子目录中的 `.inl` / `.ipp` 模板文件，都会被依赖扫描器与内容哈希缓存准确追踪。
如果我在离线开发时重命名或拆分了 `.cpp` 文件怎么办？+
无论是 `CMakeLists.txt` 解析器还是零配置 `#include` 爬虫，都会在你下次点击运行时自动重新索引工作区，立即识别新增或重命名的 `.cpp` 与 `.hpp` 文件。
