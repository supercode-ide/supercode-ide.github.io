03 分步实操使用方法

从手机端爬虫或机器人原型到 VPS 上线部署

在一个统一的 Android IDE 中完成构建、调试、结果检查与生产级 Python 脚本交付。

STEP 01 PIP -> requests, bs4, rich

在可视化 PIP 管理器中点击快捷安装标签

使用内置快捷安装标签，几秒内完成 `requests`、`beautifulsoup4`、`rich`、`pyyaml`、`flask` 或 `telebot` 的安装。

STEP 02 .env + scraper.py

将 API 密钥安全存入 .env 并运行脚本

将 API 令牌保存在本地 `.env` 文件中（自动挂载至工作区），并在终端控制台中查看格式化的 Rich/ANSI 日志。

STEP 03 output.json / cache.db

检查导出的 JSON、CSV 或 SQLite 数据

一键美化格式化生成的 `.json` 或 `.csv` 文件，或在 SuperCode 的 SQL 浏览器中直接浏览 `.db` 数据表。

提交至 GitHub 或同步至远程服务器

05 常见问答

常见问题解答 (FAQ)

关于在 Android 上进行网页爬虫、`.env` 配置、Telegram 机器人开发及部署 Python 脚本的常见解答。

`lxml` 和 `pydantic` 可以与 `requests`、`beautifulsoup4` 配合使用吗？+
可以。纯 Python 库（`requests`、`beautifulsoup4`、`telebot`、`rich`）以及带原生编译的解析器（`lxml`、`pydantic`、`orjson`、`cryptography`）均已提供支持。
我的 Python 脚本可以从 `.env` 或 `config.yaml` 文件加载环境变量和配置吗？+
可以。SuperCode 的工作区解析器会自动将 `.env`、`.yaml`、`.yml`、`.toml`、`.ini` 和 `.json` 文件与你的 `.py` 模块一同挂载。
爬虫或机器人轮询任务在交互式控制台中单次最长可以运行多久？+
本地交互式脚本单次最长支持 120 秒执行窗口（且随时支持一键停止/中断），让你在调试 API 请求、爬虫和机器人 Webhook 处理器时无需担心后台失控耗电。
在 SuperCode 中测试好 Telegram 机器人后，如何实现 7×24 小时全天候运行？+
先在 SuperCode 本地构建并调试好机器人处理逻辑，随后通过内置的 SFTP 客户端或可视化 Git 客户端将项目直接推送至你的 Linux VPS 或云主机，即可实现 7×24 小时在线托管。
