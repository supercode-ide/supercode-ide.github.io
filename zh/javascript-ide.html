05 常见问答

常见问题解答 (FAQ)

关于无需 HTML 直接运行 .js 文件、ES 模块多文件导入、防死循环卡死及 Node.js 支持的解答。

在安卓手机上不写 HTML 页面，能直接单独运行 .js 文件吗？+
当然可以！在任意 .js、.mjs 或 .cjs 文件标签页直接点击「运行」，即可在完全离线状态下瞬间启动 SuperCode 独立的 JavaScript 控制台输出结果。
可以把 JavaScript 代码拆分到多个文件并用 import/export 或 require() 互相引用吗？+
完全支持。无论是现代 ES Modules（import / export）、经典 CommonJS（require / module.exports）还是直接导入本地 .json 配置文件，均可在本地工程目录与未保存标签页之间无缝解析。
写算法时不小心触发了 while(true) 死循环，会导致编辑器卡死丢代码吗？+
绝不会。所有 JS 代码均运行在脱离 UI 主线程的隔离后台工作线程中，并受 15 秒看门狗与防刷屏断路器双重保护，遇到死循环可在 1 毫秒内瞬间终止，编辑器与未保存代码毫发无损。
如果我既想单独跑纯 JS 算法，又想做带 HTML、CSS 和 WebAssembly 的可视化网页呢？+
SuperCode 同时内置了这两大专精工作台！平时练算法和写模块用独立的 JavaScript IDE；需要真实 HTTP DOM 渲染、多端响应式视口切换与网页 DevTools 调试时，一键打开全栈 Web & PHP 工作室即可。
