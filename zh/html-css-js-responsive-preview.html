05 常见问答

常见问题解答 (FAQ)

关于在 Android 上编辑 HTML5/CSS3/JS、使用 ES Modules 及响应式视口预览的常见问题。

为什么我的 `<script type="module">` 或 `fetch('./data.json')` 在其他 HTML 编辑器里会报错？+
出于严格的 CORS 安全策略，浏览器会拦截 `file://` 地址下的 ES Modules 与 `fetch()` 请求。SuperCode 自动通过带有规范 MIME 响应头的真实 `localhost` HTTP/1.1 同源服务加载项目，让现代 JS 模块与 JSON 请求在离线状态下也能原生运行。
如何在智能手机屏幕上预览平板和桌面端的 CSS 媒体查询效果？+
在 SuperCode 实时 Web 预览界面中，点击悬浮灵动岛上的视口图标，即可在手机、平板（`768dp`）和宽屏桌面视口间瞬间切换 — 精准触发对应的 `@media` 样式规则。
一键格式化功能是否也能同时格式化 `<style>` 中的 CSS 和 `<script>` 中的 JS？+
是的。SuperCode 的递归 HTML 格式化引擎会深度解析 `.html` 文件内嵌的 `<style>` 和 `<script>` 代码块，只需一次点击即可将三种语言统一缩进整理。
离线状态下能否使用本地 `.mp4` 视频、`.woff2` 字体和 `.glb` 3D 模型？+
完全支持。本地服务器已预置 65 种以上 MIME 类型，涵盖 `font/woff2`、`model/gltf-binary`、`image/svg+xml`，以及面向 `<video>` 和 `<audio>` 流畅进度条拖拽的 HTTP `206 Partial Content` 字节范围流式传输。
