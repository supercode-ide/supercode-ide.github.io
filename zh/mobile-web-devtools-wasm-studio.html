05 常见问答

常见问题解答 (FAQ)

关于离线排查控制台报错、监控 HTTP 请求、执行 DOM JS 命令以及运行 `.wasm` 模块的常见问题。

使用 DevTools 需要手动粘贴 `<script src="eruda.js">` 或连接互联网吗？+
完全不需要！SuperCode 的 Web DevTools 控制台、网络监控器与交互式 JavaScript REPL 原生内置于离线预览引擎中 — 无需注入任何外部 CDN 脚本标签，飞行模式下也能 100% 正常运行。
能否离线运行由 Rust 或 C/C++ 编译生成的二进制 `.wasm` WebAssembly 文件？+
可以。只需将 `.wasm` 二进制文件放入项目目录，即可通过 `WebAssembly.instantiateStreaming(fetch('./module.wasm'))` 直接加载 — SuperCode 会以完全规范的 `application/wasm` MIME 类型提供服务。
如果打印 DOM 元素或包含循环引用的对象会发生什么？+
DOM 元素会自动渲染为清晰的 `<tag#id.class>` 摘要标签，存在循环引用的对象则会被安全识别并标注为 `[Circular]`，彻底避免抛出 `JSON.stringify` 异常。
Net 网络标签页除了静态文件和 `fetch()` 之外，还能捕获 PHP 后端接口请求吗？+
是的。无论是静态资源、ES 模块、`.wasm` 二进制文件、`fetch()` / `XMLHttpRequest` 请求，还是本地 `.php` 接口执行，都会完整记录在 Net 标签页中，清晰展示 HTTP 状态码、毫秒级延迟与字节载荷大小。
