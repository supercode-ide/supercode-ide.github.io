02.1

scanf 与 fgets 前自动无缓冲 stdout 输出

在许多移动端或在线运行器中，不带换行符的 printf("Enter age: "); 会一直隐身，直到 scanf() 执行完毕才显示！SuperCode 自动解除 stdout 缓冲，确保输入前就能实时看到提示。

无需 fflush(stdout) · 流畅菜单循环
02.2

分步实时标准输入与一键 [EOF] 信号

程序运行期间可随时分步输入数据。需要测试 while (scanf("%d", &x) != EOF) 或 while (fgets(buf, sizeof buf, stdin))？在空输入栏直接点击发送，即可干净利落地传递 EOF 信号。

scanf · fgets · getchar · 干净的 [EOF] 终止
02.3

面向 argc / argv 命令行程序的 // @args 指令

在 .c 文件顶部添加 // @args -i "input data.csv" --verbose，即可将最多 32 个解析后的命令行参数直接传入 main(int argc, char *argv[])，并完整保留引号内的空格。

// @args · 引号字符串 · 最多 32 个 argv 参数

05 常见问答

常见问题解答 (FAQ)

解答 Android 上 `scanf` 提示不显示、`fgets` 换行异常、`EOF` 发送与 `fopen` 路径问题。

为什么在 SuperCode 中无需 `fflush(stdout)`，`printf("Enter number: ");` 也能立刻显示？+
标准 C 流在重定向管道中常采用块缓冲，导致不带 `\\n` 结尾的提示语被隐藏。SuperCode 会自动将标准流设为无缓冲模式，确保交互提示在 `scanf`、`fgets` 或 `getchar` 等待输入前就实时显示。
在 Android 触屏键盘上如何发送 `Ctrl+D`（`EOF`）？+
当控制台输入栏处于激活且内容为空时，点击“发送”按钮即可向正在运行的 C 进程干净地发送 `EOF`（`[EOF]`）信号，从而正常结束 `while (scanf(...) != EOF)` 与 `getchar() != EOF` 循环。
如何向 `char *argv[]` 传入包含空格的命令行参数？+
在 `.c` 文件顶部附近写入 `// @args "My Report.txt" -n 10`。SuperCode 的参数分词器会将引号包裹的字符串完整保留为单个 `argv[i]` 参数项，最多支持 32 个参数。
使用 `fopen("output.txt", "w")` 创建的文件保存在哪里？+
文件会直接同步到你 `.c` 源文件所在的 Android 项目文件夹中，永久保留并可直接在 SuperCode 编辑器中打开查看。
