05 常见问答

常见问题解答 (FAQ)

关于离线 Web Crypto、`node:crypto` 加密套件、JWT 验签及密钥安全性的常见问题解答。

为什么 `crypto.subtle` 在普通 Android WebView 应用中经常失败，而在 SuperCode 中却能离线运行？+
浏览器会在不安全的 `file://` 页面下禁用 `window.crypto.subtle`。SuperCode 独立的 JavaScript 工作线程原生离线暴露 `globalThis.crypto.subtle`（`crypto.webcrypto`）与 `node:crypto`，彻底摆脱安全上下文限制。
离线支持哪些 AES 分组模式与摘要算法？+
支持 `aes-128`、`aes-192` 和 `aes-256` 的 `GCM`（带 16 字节认证标签）、`CBC` 与 `CTR` 模式，同时支持 `SHA-1`、`SHA-256`、`SHA-384`、`SHA-512` 和 `MD5` 哈希与 HMAC 计算。
`Buffer.toString('base64url')` 是否可用于构建和校验 JWT？+
完全支持。SuperCode 的 `Buffer` 实现开箱即支持 `utf8`、`hex`、`base64` 以及 RFC 4648 `base64url` 编解码，轻松编写零依赖的 JWT 与 OAuth PKCE `S256` 脚本。
运行 `node:crypto` 时是否会通过网络传输任何密钥或明密文数据？+
绝不会。所有 `node:crypto` 与 `crypto.subtle` 运算均 100% 在你的 Android 设备本地执行，即使完全关闭 Wi-Fi 与移动数据也能正常工作。
