05 常见问答

常见问题解答 (FAQ)

关于离线编译器、GB 级大文件处理、多语言独立工作区以及 Git/SFTP 实战流程的权威解答。

SuperCode IDE 在手机上支持哪些编程语言离线运行？+
SuperCode 支持在 Android 设备本地离线运行 Python（3.11 与科学计算 3.12）、C 语言（GNU C17）、C++（GNU C++20）、Java 17、JavaScript（ES2024）、SQL、动态 PHP、HTML5/CSS3/WebAssembly、Lua 5.4 以及 Linux Shell 脚本；同时可选支持 Kotlin、MySQL 8.0 及重型服务端框架的云端扩展执行。
手机打开 GB 大文件日志或 SQL 数据库备份真的不会卡死闪退吗？+
完全不会。超过 30 MB 的文件会自动启用 GB 级流式磁盘分页引擎，将数百 MB 乃至数 GB 的巨型文件按每页 1000 万字符在磁盘上切片加载，支持任意页码瞬时跳转、34 种编码自动识别与跨分页全局流式正则替换。
C 与 C++、SQL 与 Web/PHP 在内部是各自独立的专业环境吗？+
是的。C17 与 C++20 拥有各自独立的标准编译参数、头文件体系与模板；SQL 拥有专属的 9 模式分析控制台与 .db 二进制透视器；而 Web 工作室内置真实本地 HTTP + 离线 PHP + PDO SQLite + WebAssembly 预览服务器及网页开发者工具。
SuperCode 是否内置了可视化 Git 客户端和 SFTP/FTPS 远程编辑器？+
是的。应用内置零外部依赖的安卓可视化 Git 客户端（支持 PAT 令牌克隆、分支管理、提交时光机彩色统一 Diff 与可视化冲突合并），以及支持 AES-256 硬件加密保险箱与三阶段原子保存的 SFTP、FTPS (TLS 1.3) 与 FTP 远程服务器工作区。
SuperCode 是否同时针对安卓手机、折叠屏与平板做了交互优化？+
是的。在手机竖屏下，工具栏位于大拇指黄金触控区，配有右边缘滑出菜单与打字自动收起的分屏控制台；在折叠屏与横屏平板下，工具栏自动垂直停靠，终端以 55% / 45% 黄金比例并排展开。
