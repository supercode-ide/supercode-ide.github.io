05 常见问答

常见问题解答 (FAQ)

来自 SQL 学习者、数据科学专业学生与后端面试候选人的常见问题。

我可以离线练习 LeetCode 风格的 SQL 窗口函数题（`DENSE_RANK`、`LAG`、滚动求和）吗？+
可以！所有标准 SQL 窗口函数（`ROW_NUMBER`、`RANK`、`DENSE_RANK`、`NTILE`、`LAG`、`LEAD`、`FIRST_VALUE`、`LAST_VALUE`、`NTH_VALUE`）以及 `ROWS`/`RANGE`/`GROUPS` 窗口帧语法均支持 100% 离线运行。
SuperCode 支持直接在 SQL 中使用 `MEDIAN()`、`PERCENTILE()` 和 `STDDEV()` 吗？+
支持。原版 SQLite 缺少统计聚合函数，而 SuperCode 预先注册了原生 `MEDIAN(col)`、`PERCENTILE(col, 95)` 和 `STDDEV(col)` 函数，让数据分析师在单条 `SELECT` 中即可完成分布统计。
`READ_STDIN()` 在 `.sql` 查询中是如何工作的？+
只需在 `.sql` 文件中编写 `WHERE department = READ_STDIN('Department name: ')` 并点击运行 — SuperCode 会在底部停靠终端中交互提示输入，无需修改代码即可反复测试不同参数查询。
FTS5 全文检索和 R*Tree / Geopoly 空间模块是否已启用？+
已启用。`USING fts5(...)`（含 `bm25()`、`highlight()` 与 `snippet()`）以及 `USING rtree(...)` / Geopoly 空间扩展均已直接编译进 SuperCode 的离线 SQLite 3.54.1 引擎中。
