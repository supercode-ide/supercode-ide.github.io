05 常见问答

常见问题解答 (FAQ)

关于在 Android 上运行 Scikit-Learn、OpenCV、PyTorch 及远程 GPU 工作流的常见解答。

Scikit-Learn、XGBoost 和 OpenCV (`cv2`) 可以在无网络环境下运行吗？+
可以。经由 SuperCode 科学计算运行时缓存到本地设备后，`scikit-learn`、`xgboost`、`lightgbm`、`opencv-python` (`cv2`)、`Pillow` 和 `scikit-image` 均可完全离线运行。
如何在不塞满手机存储的情况下运行 PyTorch 或 TensorFlow 代码？+
只需编写 `import torch` 或 `import tensorflow as tf`（或在第一行加上 `# @cloud`）。SuperCode 会自动打包本地 `.py` 模块并在云端 Python 集群上执行，同时将报错堆栈精准映射回本地编辑器的对应代码行。
我可以在自己的 Linux GPU 工作站上编辑并触发脚本吗？+
可以。通过 SuperCode 的 SFTP 工作区（支持 AES-256 加密的 Ed25519/RSA SSH 密钥）连接工作站，即可使用完整 AST 自动补全和三阶段原子保存功能编辑远程 `.py` 与 `.yaml` 配置文件。
`cv2.imwrite()` 处理后的图片会保存到我的文件夹吗？+
会的 — 所有通过 `cv2.imwrite()` 或 `Image.save()` 写入的图像都会直接同步至你的项目目录，并可在 SuperCode 内置图像查看器中流畅打开。
