05 常见问答

常见问题解答 (FAQ)

关于 SuperCode 25 套 Java 17 项目模板、离线 ECJ + D8 构建与自定义扩展的常见解答。

全部 25 套多文件 Java 项目模板都能在 Android 上完全离线运行吗？+
是的。全部 25 套模板均为纯正零 AWT 依赖的 Java 17 项目，专为 SuperCode 离线 ECJ + D8 + DexClassLoader 运行时逐一验证，飞行模式下即可直接编译运行。
我可以在这些模板中添加自己的 .java 包或外部 .jar 库吗？+
可以。你可以在项目文件树任意位置新增文件夹与 .java 文件（最多支持 500 个文件），或将自定义 JAR 放入 libs/*.jar 目录——SuperCode 会自动完成编译与链接。
为什么这些交互式模板从不会抛出 NoSuchElementException 崩溃？+
每套使用 Scanner(System.in) 的模板都内置了完善的 EOF 防护与合理的默认演示回退逻辑，无论你在终端实时键入输入还是直接自动化运行演示都能顺畅执行。
修改其中某个类之后，多文件 Java 模板的重新构建速度有多快？+
SuperCode 会对你的源码树计算 SHA-256 哈希——未改动的运行直接从 DEX 缓存约 0ms 秒开，增量修改也能在不到一秒内干净完成重编译。
