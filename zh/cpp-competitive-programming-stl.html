05 常见问答

常见问题解答 (FAQ)

解答 Codeforces、LeetCode、AtCoder、ICPC 与 USACO 选手在 Android 上刷题的常见疑问。

结构化绑定 `auto [u, w]`、`std::popcount` 和 `std::ranges::sort` 等 C++20 特性可以离线使用吗？+
可以。SuperCode 的本地 C++ 编译器基于 GNU C++20（`-std=gnu++2a`）运行，因此结构化绑定、`constexpr if`、泛型 Lambda、`<bit>`、`<ranges>` 以及 `std::gcd` / `std::lcm` 均可 100% 离线编译。
在 SuperCode 中可以使用 `ios::sync_with_stdio(false); cin.tie(nullptr);` 吗？+
完全可以！竞赛常用的快读快写写法无论是搭配多行粘贴测试样例，还是配合 `freopen()` 文件重定向，都能稳定流畅运行。
如何测试需要一直读取到文件末尾（`while (cin >> x)`）的题目？+
先将测试数据行粘贴到实时控制台输入栏并发送，随后保持输入栏为空再点击一次发送按钮，即可传递 `[EOF]` 并打印最终答案。
SuperCode 会显示我 C++ 题解的运行速度和内存占用吗？+
会的。每次运行结束后都会显示执行摘要徽章，精确展示进程退出码、执行耗时（`µs` 或 `ms`）以及峰值内存（`KB` 或 `MB`）。
