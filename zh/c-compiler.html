05 常见问答

常见问题解答 (FAQ)

关于手机离线 C17 编译、多文件头文件管理、math.h 链接以及 scanf 交互输入的常见解答。

SuperCode 中的 C 语言编译器与 C++ 是彻底分开的吗？+
是的！打开 .c 文件会自动激活专属的 GNU C17 (-std=gnu17) 编译管线与纯 C 标准库链接，绝不会把您的 C 代码当成 C++ 编译，从而保证 void* 指针转换、restrict 关键字与纯 C 语法行为 100% 符合教学与工程标准。
编译包含多个 .c 和 .h 文件的课程设计项目需要手写 Makefile 吗？+
完全不需要。SuperCode 会自动递归解析您工程文件夹及已打开标签页中的本地 #include 头文件与对应 .c 实现文件，仅对修改过的文件执行增量编译，并自动为您加上 -lm 数学库参数。
在手机上使用 scanf() 和 fgets() 可以像在电脑上一样边运行边输入吗？+
可以。每当 C 程序读取标准输入时，分屏终端都会实时暂停等待您键入一行或多行数据；在刷算法题需要测试多组数据直至文件末尾时，直接提交空输入即可发送 EOF 信号。
如果我的 C 代码用到了 pthread.h 多线程或 sys/socket.h 网络编程怎么办？+
SuperCode 会自动识别系统级 POSIX 头文件，并将您的多文件工程无缝路由至云端 POSIX Linux C 工具链完成编译执行，同时在控制台保留精准的本地文件名与行号报错提示。
