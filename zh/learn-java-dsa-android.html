完全不需要。SuperCode 打开即进入工作区，没有任何注册门槛，学生和课堂教学都能立刻开始编写代码。

可以。精简 `void main()` 只是方便快速练习的可选语法糖 — 只要你编写标准的 `public class Main` 文件、多个 `.java` 类、接口或 `jdbc:sqlite` 数据库项目，SuperCode 无需切换任何模式即可直接编译运行。
