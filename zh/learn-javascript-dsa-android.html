JavaScript 初学者、编程训练营学员与面试备考者最关心的问题。

SuperCode 离线学 JavaScript 是否完全免费起步？+
是的！无需登录即可免费创建无限个 `.js`、`.mjs`、`.json` 与 `.html` 文件，运行全部 6 套内置 JavaScript 模板，使用 21 键符号栏、一键格式化并离线执行 ES2024 与 Node 核心脚本。
可以把 SuperCode 当作 Android 上的离线 JSON 格式化与校验工具吗？+
当然可以。打开或粘贴任意 `.json` 文件（包括数 MB 的大报文），即可通过错误雷达精确定位语法错误的行列号，并一键缩进排版或清理格式。

完全没问题。当你准备从纯控制台 JS 迈向可视化网页开发时，SuperCode 内置的 Web IDE 可通过真实本地 HTTP 服务器实时预览多文件 HTML5、CSS3、DOM JavaScript 乃至离线 PHP + SQLite 项目。
我还能练习 TypeScript 语法吗？+
SuperCode 提供完整的 TypeScript（`.ts` / `.tsx`）语法高亮、AST 符号感知、21 键 JS/TS 符号栏与一键格式化，并支持 `.js`/`.mjs` 独立 ES2024 脚本离线执行。
