05 常见问答

常见问题解答 (FAQ)

关于在 Android 手机和平板上离线运行 NumPy、Pandas、Polars 与 Matplotlib 的常见问题。

NumPy 和 Pandas 真的能在我的 Android 手机上离线运行吗？+
是的。只要科学计算运行时完成初始化并将包 wheel（如 `numpy`、`pandas` 或 `matplotlib`）缓存到设备后，后续所有运行均可 100% 离线执行，完全无需联网。
在 Android 上如何查看 `matplotlib.pyplot` 生成的图表？+
使用 `plt.savefig('plot.png', dpi=180)`（或保存为 `.svg` / `.pdf`）保存图表。SuperCode 会将文件直接同步到当前项目目录，并让你立即在内置高分辨率图片或 PDF 查看器中打开。
Pandas 脚本能读取同一文件夹下的 `.csv` 或 `.sqlite` 文件吗？+
可以。`pd.read_csv('sales.csv')` 或 `sqlite3.connect('app.db')` 等相对路径会直接基于你的项目工作区解析，执行完成后所有修改或新生成的文件都会自动同步回去。
除了 Pandas，还支持 Polars 和 DuckDB 吗？+
支持 — 同时支持 `polars` 与 `duckdb`（以及 `pyarrow` 和 `fastparquet`），可在移动端实现高速分析查询。
