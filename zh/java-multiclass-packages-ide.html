05 常见问答

常见问题解答 (FAQ)

关于多包目录结构、引入外部 .jar 依赖库以及 main() 入口解析的常见问题。

如何在 SuperCode 中添加 Gson 或 Commons Lang 等外部 `.jar` 库？+
在 Java 项目根目录下创建名为 `libs`（或 `lib`）的文件夹，并将 `.jar` 文件复制进去。SuperCode 会自动将 `libs/` 中的全部 `.jar` 归档包（最高 30 MB）加入编译期和运行期类路径 — 无需编写任何构建脚本。
在没有 `main()` 方法的 Java 类标签页点击运行会发生什么？+
SuperCode 的入口仲裁器会扫描项目中已编译的类，自动识别并选中包含 `main()` 的主入口类执行 — 省去您在多个标签页之间频繁来回切换的麻烦。
必须使用 `src/main/java` 结构吗？简单的多文件目录也能用吗？+
两种方式都能无缝支持！您可以把两个不带 `package` 声明的 `.java` 文件直接并排放在普通文件夹里，也可以直接组织 `com.example.*` 子目录，或者采用完整的 `src/main/java` + `resources/` + `libs/` 标准结构。
哪些 `.jar` 文件可以在 Android 上离线运行？+
任何面向 Java 8、11 或 17 编译的标准纯 Java `.jar` 库（例如 `gson`、`org.json`、`commons-lang3`、`commons-csv` 或高校评测库）均可 100% 离线运行。需要 AWT/Swing 桌面窗口的 GUI 类库不适用于移动端控制台环境。
