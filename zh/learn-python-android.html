05 常见问答

常见问题解答 (FAQ)

初学者、计算机专业学生与一线教师最关心的问题解答。

纯零基础在手机上学 Python，SuperCode 好上手吗？+
非常好上手。无需配置编译器、环境变量或注册账号—只要新建一个 `.py` 文件（或选用内置 8 个 Python 示例之一），点一下运行即可。错误雷达和一键 PEP 8 格式化还能帮新手第一时间纠正拼写和缩进错误。
可以离线刷 LeetCode 和数据结构算法题吗？+
可以。`collections`、`heapq`、`bisect`、`itertools`、`functools`、`math`、`typing` 等标准算法模块全部 100% 离线运行，并实时显示毫秒级耗时与内存占用数据。
教室里学生没有 Wi-Fi，老师能用 SuperCode 开展课堂教学吗？+
完全可以。核心 Python 3.11 运行时开箱即离线，离线 `.whl` 安装包也可在无网环境下本地分发，学生完成后还能直接将作业导出为带语法高亮的 A4 PDF 上交。
白天光线强时，SuperCode 除了深色模式还支持浅色模式吗？+
支持—SuperCode 内置 8 套光学护眼主题（涵盖清爽浅色主题与低眩光深色主题），并支持自由缩放编辑器和控制台字号。
