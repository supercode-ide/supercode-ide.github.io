05 常见问答

常见问题解答 (FAQ)

关于 C17 数据结构、指针成环防护、嵌入式 stdint.h 头文件及作业导出的常见解答。

可以在完全离线的情况下用 C 语言编译递归结构体、链表和二叉树吗？+
可以。SuperCode 内置的离线 GNU C17 工具链完整支持递归结构体、malloc/calloc/realloc/free 堆内存管理、函数指针以及多文件 .c/.h 头文件，全程无需联网。
如果链表或 while 循环在手机上陷入死循环怎么办？+
离线 C 程序运行在独立隔离的非 UI Web Worker 中。编辑器始终保持 120Hz 流畅响应，点击“停止”即可立即终止 Worker，绝不会引发 ANR 或应用闪退。
SuperCode 是否支持在同一文件夹下用 #if 0 保留多个测试 main() 代码块？+
支持。SuperCode 的 O(N) C/C++ 预处理器词法器会在链接前自动识别并跳过 #if 0 和 #if false 死分支，归档的测试代码块绝不会触发重复 main() 报错。
可以在 Android 上直接格式化凌乱的 C 语言作业并导出为 PDF 吗？+
可以。点击“格式化”即可运行具备词法感知能力的 C 格式化器（支持一键撤销），随后一键导出带行号、语法高亮的整洁 A4 PDF 用于课程提交。
