03 分步实操使用方法

如何在 SuperCode 中管理数据库并导入分析数据集

清爽、可复现的脚本化数据库工作流，所有数据文件直接持久化保存在您的本地工程目录中。

STEP 01 query.sql 或 app.db

直开已有 .db 数据库或新建 .sql 查询脚本

轻点本地任意 .db/.sqlite 文件一键检视全库表结构，或新建带离线 AST SQL 关键字/函数补全与一键格式化的 .sql 脚本。

STEP 02 .import --csv / --json

初始化业务数据表或批量导入 CSV 与 JSON

仅需一条指令，即可将工程文件夹内的 CSV、TSV 或 JSON 原始数据极速加载为带类型的结构化数据表。

STEP 03 运行 ▶ (.mode box)

离线极速执行多条复杂联表分析查询

在分屏控制台中直观审阅对齐工整的 Unicode 线框表格、Markdown 表格或 JSON 结果，按需响应 READ_STDIN() 动态参数输入。

STEP 04 .save / .once report.csv

导出干净分析报表并与 PHP / Java 无缝共享数据库

将持久化更新后的 .db 库文件或 .csv/.json 报表直接保存至工程目录——瞬间即可被 SuperCode 的 PHP PDO 或 Java JDBC 项目直接读取调用！

05 常见问答

常见问题解答 (FAQ)

关于离线练习 SQL、手机打开 .db/.sqlite 数据库文件、导入 CSV/JSON 以及兼容 MySQL 语法的常见问题。

不用配置任何数据库服务器，可以直接在手机上离线练习 SQL 语句吗？+
完全可以！只需新建任意 .sql 文件并点击「运行」，即可 100% 离线连续执行建表 CREATE、插入 INSERT、多表 JOIN、递归 CTE 与窗口分析查询，并在控制台直接查看排版整齐的 Unicode 线框表格。
SuperCode 能直接打开并查询手机里已有的 .db 和 .sqlite 数据库文件吗？+
可以。点击或运行任意 .db、.sqlite、.sqlite3 或 .db3 文件即可一键列出全部数据表、视图、索引与建表 Schema；同时在该文件夹下编写任何 .sql 脚本都会自动连接该数据库进行读写操作。
支持 MySQL 常用的 AUTO_INCREMENT、SHOW TABLES、DESCRIBE 或存储过程吗？+
日常高频使用的 MySQL/PostgreSQL 语法（如 AUTO_INCREMENT、ENUM、SHOW TABLES、DESCRIBE、ILIKE）可直接在本地离线兼容运行；而针对服务端专属的 MySQL 8.0 存储过程与触发器，系统会自动路由至云端 MySQL 8.0 集群执行。
如何把 SQL 查询结果一键导出成 CSV 表格、Markdown 文档或 JSON 文件？+
只需在 SELECT 查询语句上方加上一行 `.mode csv`（或 `.mode markdown` / `.mode json`）以及 `.once output.csv`，点击运行后 SuperCode 就会将导出文件直接生成到您当前的工程文件夹中。
