从高校 Web 课程作业、REST API 原型验证到完整 CRUD 管理后台 —— 全程支持飞行模式离线开发。

02.1

现代 PHP 8.2 语法与 32 层多文件引用

采用 PHP 8.2 match 表达式、箭头函数（fn() =>）、构造器属性提升与命名空间构建清晰后端架构，完整支持最深 32 层的 include、require 与 require_once 嵌套引用。

PHP 8.2 · match · fn() => · 32 层 require_once
02.2

通过 new PDO('sqlite:app.db') 将 PHP 脚本直连本地 SQLite 数据库 —— 完整支持防 SQL 注入的 ? 与 :named 预处理语句、PDO::FETCH_ASSOC 以及 beginTransaction() / commit() / rollBack()。

免改 php.ini · 预处理防注入 · ACID 事务
02.3

持久化 $_SESSION、$_COOKIE 与 Bcrypt 身份认证

离线构建真实登录、购物车与 CSRF 防护流程。SuperCode 可在页面重定向（header('Location: ...')）间持久化保存 $_SESSION 与 $_COOKIE 状态，并原生支持 password_hash() 与 password_verify()。

session_start() · password_hash() · HTTP 重定向
02.4

$_GET、$_POST、JSON REST 接口与自定义响应头

轻松处理 URL 查询参数、urlencoded 表单及原始 php://input JSON 请求体，同时返回自定义 HTTP 状态码与 header('Content-Type: application/json') 响应，无缝对接前端 fetch() 请求。

$_GET / $_POST · php://input · JSON REST 接口

结合 Android 相机或系统文件选择器测试 <input type="file"> 表单。在 $_FILES 中校验 MIME 元数据，并通过 move_uploaded_file() 将最高 24 MB 的图片或文档直接保存至工作区。

03 分步实操使用方法

如何在 Android 上离线运行 PHP 8.2 + SQLite 项目

无需 Root 权限、无需配置端口转发，也无需单独启动数据库守护进程。

STEP 01 New Folder -> index.php

创建或克隆多文件 PHP 工作区

建立包含 index.php、includes/db.php 与 assets/ 的项目文件夹 —— SuperCode 会自动将项目根目录映射为本地 Web 服务器根目录。

STEP 02 new PDO('sqlite:app.db')

连接本地 SQLite 数据库

直接在 PHP PDO 中初始化数据表，或提前在 SuperCode 集成的 SQL 工作室中可视化建表并检视 app.db。

STEP 03 Toolbar -> Run ▶

在 Localhost 下调试表单、会话与 Fetch 接口

点击运行 ▶ 即可在真实本地 HTTP 源下打开实时浏览器预览，提交 POST 与文件上传表单，并在 Net 面板查看 PHP 请求耗时。

STEP 04 Session Reset / SFTP

一键重置 Cookie 或通过 SFTP 发布上线

随时从预览工具栏一键清除当前 $_SESSION Cookie 以复测登录流程，验证无误后通过 SFTP/FTPS 将 PHP 文件直接部署至 Linux 主机。

05 常见问答

常见问题解答 (FAQ)

关于在 Android 上离线运行 PHP 8.2、PDO SQLite、会话及文件上传的常见疑问解答。

SuperCode 能否在完全断网的情况下运行 PHP 8.2？+
可以。SuperCode 的 PHP 8.2 引擎与 PDO SQLite 数据库驱动 100% 在 Android 设备本地运行 —— 即使开启飞行模式也能开发并测试多页面 PHP 网站、登录表单与 JSON 接口。
为什么选择 SuperCode，而不是 KSWEB 或在终端里运行 `php -S`？+
独立的服务器守护进程需要手动设置虚拟主机路径、后台常驻保活，还迫使你在编辑器、服务端和浏览器三个应用间来回切换。SuperCode 在一个轻量 IDE 内统一了 AST PHP 编辑、自动项目根目录 HTTP 路由、Web DevTools、SQL 工作室与 SFTP 发布。
前端 JavaScript 可以通过 `fetch()` 调用本地 `.php` 接口吗？+
完全可以！由于工作区运行在真实的 `localhost` HTTP/1.1 源下，`await fetch('/api/tasks.php', { method: 'POST', ... })` 可与 JSON 请求头、Cookie 以及 DevTools 网络耗时面板无缝协同。
可以查看 PHP `new PDO('sqlite:app.db')` 创建的 SQLite `.db` 文件吗？+
即点即看。在 SuperCode 文件树中轻点 `app.db`，即可直接在 SQL 工作室中以 Unicode 表格或 Markdown 格式检视数据表、表结构与行数据。
