02 核心工程能力

企业级远程密钥防护与专为移动弱网打造的零损坏文件工程

当手机处于电梯、高铁或 5G/Wi-Fi 切换的波动网络中，普通 FTP 编辑器一旦断流就会把线上核心配置文件截断成 0 字节瘫痪状态——SuperCode 从底层协议彻底根除了这一噩梦。

02.1

四大远程协议全满贯：SFTP、显式 FTPS、隐式 FTPS 与 FTP

原生支持 SSH SFTP（默认 22 端口）、基于 TLS 1.2/1.3 并开启被动数据通道全加密（PBSZ 0 + PROT P）的显式 FTPS、隐式 FTPS（990 端口）以及标准 UTF-8 被动模式 FTP（21 端口）。

SFTP (22) · FTPS TLS 1.3 (21) · FTPS (990) · FTP
02.2

SSH 私钥快捷选择器、AES-256 硬件保险箱与主机指纹防中间人守卫

一键导入 OpenSSH、PEM、RSA、Ed25519 或 ECDSA 私钥文件（.pem、.key、id_rsa、id_ed25519）及密钥口令。全部凭据均由 Android KeyStore AES-256-GCM 硬件级加密存储，并配备 TOFU SHA256 主机指纹突变告警，严防中间人劫持。

Ed25519 / RSA / PEM · AES-256-GCM 硬件加密 · SHA256 指纹防劫持
02.3

三阶段远程原子保存（100% 杜绝断网产生 0 字节空文件）

点击远程文件会自动建立持久化本地镜像标签页（☁️）。按下保存时严格执行三阶段事务：先上传至远程临时文件 -> 通过 STAT/SIZE 校验远端落盘字节数分毫不差 -> 原子重命名覆盖目标文件并完整继承原有 Linux POSIX 权限！

临时上传 -> 精确字节核验 -> 原子重命名覆盖 + 保留 chmod 权限
02.4

实时连接握手诊断控制台与三通道自愈连接池

保存主机配置前，可在内嵌诊断终端实时核验 TCP 连通性、TLS/SSH 协议协商与密钥认证全过程。底层配备 3 通道多路复用连接池，在手机切换 Wi-Fi 与 5G 网络后自动静默重连自愈。

03 分步实操使用方法

如何在 Android 上安全连接并热修复线上生产服务器

在硬件级加密保险箱中一次配妥，随时随地数秒内安全完成紧急配置排障与热更新。

STEP 01 Explorer -> Remote Servers -> +

选择传输协议并导入密码或 SSH 私钥文件

按需选择 SFTP、FTPS (TLS)、FTPS (990) 或 FTP，填入主机地址与用户名，输入密码或直接通过内置快捷选择器导入 .pem / id_ed25519 私钥。

STEP 02 ⚡ Test Handshake -> Save

实时查验握手日志并信任服务器 SHA256 指纹

轻点「测试握手」实时确认 TCP/TLS/SSH 鉴权通过，核对服务器首次返回的 SHA256 主机公钥指纹后安全存入 AES-256 保险箱。

STEP 03 Mount -> Tap Remote File

浏览远程目录树并享受完整 AST 补全与一键格式化

在多标签页中直接打开线上 Nginx 配置、Python/PHP 后端源码或运维脚本，畅享离线 AST 智能补全、错误雷达诊断与一键代码美化。

STEP 04 Save / Batch Upload

三阶段原子级发布文件或带冲突策略同步整套目录

轻点保存即刻完成零风险三阶段原子部署；亦可多选文件夹执行批量上传/下载，自由选择覆盖、字节断点续传、保留双方或跳过策略。

严格保留远程 Linux 服务器文件原有 POSIX 读写执行权限 · 离线重启应用亦不丢失镜像草稿 新手引导

05 常见问答

常见问题解答 (FAQ)

关于阿里云/腾讯云/AWS 私钥格式（.pem / Ed25519）、FTPS TLS 1.3、防止断网写坏线上文件与断点续传的解答。

连接阿里云、腾讯云、AWS EC2 或自建 Linux VPS 支持哪些格式的 SSH 私钥？+
SuperCode 全面支持 OpenSSH 新格式、传统 PEM（.pem）、RSA（id_rsa）、高安全性 Ed25519（id_ed25519）以及 ECDSA 私钥——无论是否带有私钥保护口令（Passphrase）均可解析，并内置直达下载目录与 .ssh 文件夹的快捷选钥匙面板。
在地铁或信号不稳的地方点保存，SuperCode 是如何保证不会把服务器上的代码截断成 0 字节的？+
每一次远程标签页保存都严格遵循「三阶段原子事务」：第一步先将数据上传为远程临时文件；第二步通过协议级 STAT/SIZE 指令向服务器核实落盘字节大小与本地完全一致；只有校验 100% 通过后，第三步才会执行原子重命名替换目标文件并还原原有的 Linux 文件权限。
除了 SSH 端口的 SFTP，还支持加密的 FTPS（FTP over SSL/TLS）虚拟主机吗？+
完全支持！无论是 21 端口通过 AUTH TLS 1.2/1.3 升级并开启 PROT P 被动数据流加密的「显式 FTPS」，还是 990 端口的「隐式 FTPS」，乃至标准 UTF-8 被动模式 FTP，均已原生内置。
下载或上传几百兆的服务器备份包时如果中途断网了，支持断点续传吗？+
支持。当检测到远端或本地已存在未传完的同名部分文件时，SuperCode 会自动比对已传输字节数并提供一键「断点续传（Resume）」，直接从中断的精确字节偏移处继续传输，无需重头再来。
