05 常见问答

常见问题解答 (FAQ)

关于 Android 上 `awk`、`sed`、`grep`、`bc -l`、`curl` 与 GNU Bash 5.2 兼容性的常见解答。

`awk`、`sed`、`grep`、`sort` 和 `sha256sum` 能否完全离线运行？+
可以！标准 POSIX 文本、归档与校验管道（`awk`、`sed`、`grep`、`egrep`、`sort`、`uniq`、`wc`、`cut`、`tr`、`find`、`xargs`、`tar`、`gzip`、`base64`、`md5sum`、`sha256sum`、`bc -l`）全部在您的设备上本地离线运行。
为什么 `declare -A` 关联数组在 Android 默认 Shell 中会报错？SuperCode 是如何运行的？+
Android 内置的系统 Shell 基于 POSIX/`mksh`，而非 GNU Bash 5。当 SuperCode 检测到 Bash 专属语法（带有 `declare -A`、`[[ =~ ]]`、`mapfile` 或 `jq` 的 `#!/usr/bin/env bash`）或 `# @cloud` 标记时，会自动在 Ubuntu GNU Bash 5.2 环境中执行您的脚本。
我的 `awk` 或 `sed` 脚本能读取本地 `.csv` 并保存新文件吗？+
可以。相对输入路径与输出重定向（`> cleaned.csv` 或 `| tee out.txt`）均直接作用于当前工作区，新生成的文件会自动同步回您的 Android 文件夹。
如果原始服务器日志超过 1 GB 怎么办？+
直接使用 SuperCode 基于磁盘分页的大文件编辑器打开数 GB 日志，即可实现零卡顿秒级浏览与全局流式正则替换！
