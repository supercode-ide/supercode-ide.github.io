02 核心工程能力

在 Android 上打通现代全栈 Web 工程的六大核心链路

前端模块化 ES 脚本、高性能二进制 WebAssembly、后端动态 PHP 会话、关系型 SQL 数据库、DevTools 网络审查与远程 SFTP 发布——浑然一体。

02.1

真实的本地 HTTP/1.1 源服务器：彻底解锁现代前端与 WASM

通过标准本地 HTTP/1.1 协议而非受限的 file:// 路径承载工程——彻底解锁 fetch() 异步请求、type="module" ES 模块、WebAssembly.instantiateStreaming() (.wasm)、WebGL .glb/.gltf 3D 模型、IndexedDB 以及 HTTP 206 音视频拖动播放。

支持 65+ 种 MIME 类型 · ES Modules · application/wasm · HTTP 206
02.2

100% 离线动态 PHP 后端执行引擎

无需联网即可在手机本地运行多页面 .php 动态模板、OOP 类、闭包、match 表达式与 include/require，完整支持 $_GET、$_POST、持久化 $_SESSION 会话、$_FILES 表单文件上传、JSON REST 接口头与 password_hash()。

$_GET / $_POST / $_SESSION · JSON 接口开发 · 纯离线动态 PHP
02.3

通过 PDO 与 SQLite3 无缝读写本地关系型数据库

在离线 PHP 中直接调用 new PDO('sqlite:app.db') 或 SQLite3 扩展构建数据驱动应用，支持预处理防注入参数绑定（? 与 :named）、ACID 事务，并可随时切回 SQL 工作室直开查看数据表。

PDO('sqlite:...') · 预处理防注入语句 · ACID 事务保障
02.4

悬浮网页 DevTools 控制台、网络耗时监控与实时 JS REPL

实时追踪每一笔 HTTP 请求状态（如 GET /api.php -> 200 · 3ms · 1.2 KB），按全部/错误/警告/网络分级过滤日志，展开检视 DOM 与嵌套对象树，并在底部 REPL 输入框中实时注入执行 JavaScript 表达式。

请求耗时追踪 · 错误角标提醒 · 交互式 JS REPL
02.5

三端响应式视口切换灵动岛与 2560px 超清长截图导出

轻点可自由拖拽的悬浮灵动岛，瞬间在手机、平板（768dp）与桌面电脑三种视口宽度间切换调试，原生打通相机/相册文件上传控件，并支持一键导出 2560px 超清 PNG 网页预览图。

手机 / 平板 / 桌面三视口 · 2560px 超清 PNG 导出

03 分步实操使用方法

如何在 Android 上开发、调试并部署全栈动态网站

从本地 HTML/CSS/WASM 与 PHP+SQL 全栈原型设计，一路直达线上服务器安全发布。

STEP 01 index.html / index.php

高效编写 HTML5、CSS3、JS、WASM 与 PHP 源码

借助离线 AST 前端/PHP 补全与一键递归格式化（同时自动对齐 HTML 内嵌的 script 与 style 代码块！）高效构建多文件站点。

STEP 02 PDO + app.db

将离线 PHP 表单与接口接入本地 SQL 数据库

在 PHP 中通过 PDO 预处理语句安全读写本地 .db SQLite 数据库，或直接在内置 SQL 工作室中初始化建表与导入测试数据。

STEP 03 运行 ▶ -> 悬浮灵动岛

跨手机/平板/桌面视口预览并用 DevTools 排错

一键切换响应式屏幕尺寸，拉开可调节高度的 DevTools 抽屉排查网络请求与 JS 报错，或在 REPL 中实时调试 DOM 样式。

STEP 04 SFTP / 可视化 Git

直接发布至线上云主机或 GitHub Pages

通过可视化 Git 将静态与 WASM 站点一键推送至 GitHub Pages，或通过 SFTP/FTPS 将 PHP 全栈应用直接同步至云服务器。

左边缘内滑手势瞬返工程树 · 支持一键清空浏览器缓存与重置 PHP Session 新手引导

05 常见问答

常见问题解答 (FAQ)

关于离线运行动态 PHP + SQLite、ES 模块与 fetch()/WASM 跨域、手机端网页 DevTools 及远程 SFTP 发布的解答。

不联网的情况下，真的可以在安卓手机上运行动态 PHP 网页并连接 SQL 数据库吗？+
完全可以！SuperCode 在手机本地离线解析执行 .php 动态页面、JSON REST 接口、Session 会话、表单文件上传与多文件 include，并原生内置了 PDO('sqlite:...') 与 SQLite3 数据库引擎。
前端常用的 ES6 模块（type="module"）、fetch() 请求和 WebAssembly (.wasm) 能正常运行吗？+
完美支持。因为 SuperCode 启动了具备 65+ 种标准 MIME 类型（包含 application/wasm）的真实本地 HTTP 服务器承载您的工程，所以 fetch()、ES 模块导入、WebGL 3D 模型与 WebAssembly.instantiateStreaming() 均开箱即用，绝无 file:// 跨域报错。
在手机小屏幕上怎么调试 JavaScript 报错、查看接口请求和测试电脑端宽屏布局？+
进入网页预览后点击可拖拽的悬浮「灵动岛」胶囊，即可一键切换手机、平板（768dp）与桌面端宽屏视口；展开可自由拉高缩小的 Web DevTools 控制台抽屉，即可过滤错误/警告/网络请求日志，并直接在 REPL 中执行实时 JS 代码。
可以直接预览并修改托管在远程 FTP 或 SFTP 服务器上的网站代码吗？+
可以。在 SFTP/FTPS/FTP 工作区挂载您的服务器后，直接在标签页编辑远程 HTML/CSS/JS/PHP 文件并通过三阶段原子保存写回，点击「运行」还能按需缓存远程静态资源实现本地实时预览。
