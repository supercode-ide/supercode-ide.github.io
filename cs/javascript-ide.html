05 OTÁZKY A ODPOVĚDI

Často kladené otázky

Odpovědi ke spouštění souborů .js bez HTML, ES modulům, nekonečným smyčkám a modulům Node.js.

Mohu na Androidu spustit soubor .js přímo bez vytváření HTML stránky?+
Ano! Klepnutím na Spustit u libovolného souboru .js, .mjs nebo .cjs se okamžitě otevře samostatná JavaScript konzole SuperCode — zcela offline.
Mohu rozdělit JavaScript kód do více souborů pomocí import/export nebo require()?+
Ano. Jak ES Modules (import / export), tak CommonJS (require / module.exports) i importy .json fungují napříč lokálními soubory projektu a neuloženými kartami.
Zamrzne editor při nechtěné smyčce while(true) nebo přijdu o neuložený kód?+
Nikdy. Skripty běží v izolovaném workeru na pozadí pod dohledem 15sekundového watchdogu a pojistky proti zahlcení výstupu, takže zacyklený kód ukončí pod 1 milisekundu bez dopadu na vlákno UI.
Co když chci vytvořit vizuální DOM web s HTML, CSS a WebAssembly?+
SuperCode umí obojí! Použijte samostatné JavaScript IDE pro čisté moduly JS/Node a algoritmy, a Full-Stack Web & PHP Studio, kdykoli chcete živé HTTP DOM vykreslování, responzivní viewporty a Web DevTools.
