05 OTÁZKY A ODPOVĚDI

Často kladené otázky

Časté dotazy studentů SQL, datové vědy i uchazečů o backendové pohovory.

Mohu procvičovat úlohy typu LeetCode s Window funkcemi (`DENSE_RANK`, `LAG`, průběžné součty) offline?+
Ano! Každá standardní SQL window funkce (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) i specifikace rámců `ROWS`/`RANGE`/`GROUPS` funguje 100% offline.
Podporuje SuperCode funkce `MEDIAN()`, `PERCENTILE()` a `STDDEV()` přímo v SQL?+
Ano. Zatímco základní SQLite statistické agregace postrádá, SuperCode předregistrovává nativní funkce `MEDIAN(col)`, `PERCENTILE(col, 95)` a `STDDEV(col)`, takže datoví analytici spočítají rozdělení v jediném příkazu `SELECT`.
Jak uvnitř dotazu `.sql` funguje `READ_STDIN()`?+
Napište do souboru `.sql` například `WHERE department = READ_STDIN('Department name: ')` a klepněte na Spustit — SuperCode vás interaktivně vyzve v ukotvené konzoli, takže můžete parametrizované dotazy spouštět znovu bez úpravy kódu.
Jsou zapnuté moduly fulltextového vyhledávání FTS5 a prostorové R*Tree / Geopoly?+
Ano. Jak `USING fts5(...)` (včetně `bm25()`, `highlight()` a `snippet()`), tak prostorová rozšíření `USING rtree(...)` / Geopoly jsou zkompilovány přímo do offline jádra SQLite 3.54.1 v SuperCode.
