05 OTÁZKY A ODPOVĚDI

Často kladené otázky

Časté dotazy k úpravám HTML5/CSS3/JS, ES Modules a náhledům responzivních viewportů na Androidu.

Proč mi `<script type="module">` nebo `fetch('./data.json')` v jiných HTML editorech selhával?+
Prohlížeče blokují ES Modules a `fetch()` na URL `file://` kvůli přísným bezpečnostním pravidlům CORS. SuperCode automaticky servíruje váš projekt přes skutečný původ `localhost` HTTP/1.1 se správnými hlavičkami MIME, takže moderní JS moduly i načítání JSON fungují nativně offline.
Jak mohu na displeji smartphonu zobrazit náhled CSS media queries pro Tablet a Desktop?+
V živém webovém náhledu v SuperCode klepněte na ikonu viewportu na plovoucím Dynamic Islandu a okamžitě přepněte mezi viewportem Mobil, Tablet (`768dp`) a široký Desktop — vaše pravidla `@media` se spustí přesně.
Formátuje formátovač na 1 klepnutí také CSS uvnitř `<style>` a JS uvnitř `<script>`?+
Ano. Rekurzivní formátovač HTML v SuperCode parsuje vložené bloky `<style>` a `<script>` uvnitř souborů `.html` a přehledně odsadí všechny tři jazyky jediným klepnutím.
Mohu offline používat lokální videa `.mp4`, fonty `.woff2` a 3D modely `.glb`?+
Ano. Lokálně je předkonfigurováno přes 65 typů MIME včetně `font/woff2`, `model/gltf-binary`, `image/svg+xml` a streamování bajtových rozsahů HTTP `206 Partial Content` pro plynulé přetáčení `<video>` a `<audio>`.
