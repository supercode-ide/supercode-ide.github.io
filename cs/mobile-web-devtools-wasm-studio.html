05 OTÁZKY A ODPOVĚDI

Často kladené otázky

Dotazy ohledně kontroly chyb konzole, sledování HTTP požadavků, spouštění DOM JS příkazů a provádění `.wasm` offline.

Musím vkládat `<script src="eruda.js">` nebo být online, aby DevTools fungovaly?+
Ne! Web DevTools konzole, síťový monitor i interaktivní JavaScript REPL v SuperCode jsou vestavěné nativně přímo do offline náhledového enginu — bez externích CDN skriptů a 100% funkční i v režimu Letadlo.
Mohu spouštět binární soubory WebAssembly `.wasm` zkompilované z Rustu nebo C/C++?+
Ano. Umístěte binární soubor `.wasm` do složky projektu a načtěte jej pomocí `WebAssembly.instantiateStreaming(fetch('./module.wasm'))` — SuperCode servíruje `.wasm` s přesným typem MIME `application/wasm`.
Co se stane, když zaloguji element DOM nebo objekt s cyklickými odkazy?+
Elementy DOM se přehledně vykreslí jako souhrny `<tag#id.class>` a cyklické odkazy objektů se bezpečně detekují jako `[Circular]`, aniž by došlo k výjimce `JSON.stringify`.
Zachycuje karta Net kromě statických souborů a `fetch()` také volání PHP backendu?+
Ano. Každé statické aktivum, ES modul, binární `.wasm`, volání `fetch()` / `XMLHttpRequest` i lokální spuštění koncového bodu `.php` se zobrazí na kartě Net včetně stavového kódu HTTP, latence v milisekundách a velikosti přenosu v bajtech.
