05 QUESTIONS & ANSWERS

Frequently Asked Questions

Answers about learning Lua for Roblox/Luau, Love2D, metatables, and coroutines on Android.

Does practicing Lua 5.4 in SuperCode transfer directly to Roblox (Luau) and Love2D?+
Yes! Core Lua tables, closures, lexical scoping, metatables (`__index`, `__add`), coroutines, math, and modular `return M` scripts form the exact foundation shared by Roblox Luau, Love2D, Defold, Solar2D, and World of Warcraft/ Garry's Mod addons.
Can SuperCode render 3D Roblox worlds or Love2D OpenGL windows directly?+
SuperCode focuses on fast, decoupled gameplay logic, data-driven RPG systems, inventory SQLite/JSON persistence, and algorithm prototyping in a native console — letting you perfect core module scripts anywhere and sync them to your desktop renderer via Git.
How does SuperCode help prevent `.` vs `:` method errors in Lua OOP?+
When you type `entity:` versus `Entity.`, SuperCode's offline AST completion filters suggestions contextually so you immediately see colon-defined instance methods separately from static module functions.
Are starter game scripts included for offline study?+
Yes. Eight runnable Lua templates — including `adventure.lua`, `guess.lua`, `metatables.lua`, and `tables.lua` — are built right in and work 100% offline.
