05 SPØRGSMÅL OG SVAR

Ofte stillede spørgsmål

Ofte stillede spørgsmål fra begyndere, datalogistuderende og undervisere.

Er SuperCode god til helt nye begyndere, der vil lære Python på telefonen?+
Ja. Du behøver ikke konfigurere kompilere, stier eller konti — opret bare en `.py`-fil (eller vælg et af de 8 indbyggede Python-eksempler) og tryk på Kør. Error Radar og 1-tryks PEP 8-formatering hjælper begyndere med at rette tastefejl med det samme.
Kan jeg øve LeetCode-opgaver og datastruktur-algoritmer offline?+
Ja. Alle standard algoritmemoduler (`collections`, `heapq`, `bisect`, `itertools`, `functools`, `math`, `typing`) kører 100 % offline med måling af køretid på millisekundniveau og hukommelsesforbrug.
Kan undervisere bruge SuperCode i klasselokaler uden Wi-Fi til eleverne?+
Helt sikkert. Kernen i Python 3.11 kører offline fra start, offline `.whl`-arkiver kan deles lokalt uden internet, og studerende kan eksportere færdige opgaver direkte som syntaksfremhævede A4 PDF'er.
Understøtter SuperCode både lyst tema og mørkt tema til læsning i dagslys?+
Ja — SuperCode indeholder 8 optiske studietemaer (både skarpe lyse temaer og skånsomme mørke temaer) samt justerbar skriftstørrelse i editor og konsol.
