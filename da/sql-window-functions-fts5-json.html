05 SPØRGSMÅL OG SVAR

Ofte stillede spørgsmål

Ofte stillede spørgsmål fra SQL-studerende, data science-studerende og backend-jobkandidater.

Kan jeg øve LeetCode-lignende SQL Window Function-opgaver (`DENSE_RANK`, `LAG`, rullende summer) offline?+
Ja! Alle standard SQL window functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) samt `ROWS`/`RANGE`/`GROUPS`-rammespecifikationer virker 100 % offline.
Understøtter SuperCode `MEDIAN()`, `PERCENTILE()` og `STDDEV()` direkte i SQL?+
Ja. Mens standard SQLite mangler statistiske aggregater, forhåndsregistrerer SuperCode indbyggede `MEDIAN(col)`-, `PERCENTILE(col, 95)`- og `STDDEV(col)`-funktioner, så dataanalytikere kan beregne fordelinger i én enkelt `SELECT`.
Hvordan fungerer `READ_STDIN()` inde i en `.sql`-forespørgsel?+
Skriv `WHERE department = READ_STDIN('Afdelingsnavn: ')` i din `.sql`-fil og tryk på Kør — SuperCode beder dig interaktivt om input i den forankrede konsol, så du kan genkøre parametriserede forespørgsler uden at ændre koden.
Er FTS5-fuldtekstsøgning og R*Tree / Geopoly spatial-moduler aktiveret?+
Ja. Både `USING fts5(...)` (inklusive `bm25()`, `highlight()` og `snippet()`) og `USING rtree(...)` / Geopoly spatial-udvidelser er kompileret direkte ind i SuperCodes offline SQLite 3.54.1-motor.
