03 FLUSSO PASSO DOPO PASSO

Guida completa in 6 passi: come usare Git in SuperCode IDE

Segui questo flusso dentro SuperCode per clonare, creare branch, confrontare diff, fare merge e push da smartphone o tablet.

STEP 01 Menu -> Git Controls -> Clone

Clona un repo remoto o monta un progetto locale

Incolla l'URL HTTPS (es. https://github.com/user/repo.git) e il token PAT opzionale, poi tocca CLONA — oppure tocca Monta repo esistente se la cartella ha già una directory .git.

STEP 02 Time Machine -> Branch ▾

Cambia o crea un feature branch

Apri Git Time Machine e tocca il selettore branch in alto per cambiare branch o tocca + Crea nuovo branch… (es. feature/mobile-ui) con validazione automatica del nome.

STEP 03 Editor Tabs -> Save / Edit

Modifica codice multi-file con tutta l'intelligenza IDE

Modifica, formatta e testa il codice offline. Anche se dimentichi di salvare una scheda aperta, le operazioni Git salvano automaticamente su disco le schede modificate prima di procedere.

STEP 04 Git Dashboard -> Pull

Scarica in sicurezza gli aggiornamenti remoti del team

Tocca Pull prima del push. Le modifiche locali senza commit vengono messe in stash e ripristinate in automatico, e le schede aperte si aggiornano sul posto senza perdere la posizione del cursore.

STEP 05 Open Conflict Resolver

Risolvi visualmente qualsiasi collisione di merge

In caso di modifiche sovrapposte, tocca Apri risolutore conflitti, confronta affiancati i blocchi Locale vs Remoto, scegli Mantieni attuale / in ingresso / entrambi e tocca Applica risoluzioni.

STEP 06 Commit & Push

Rivedi i file in sospeso, scrivi il messaggio & fai Push

Verifica i badge [M]/[A]/[D] nell'elenco Modifiche in sospeso, conferma l'Identità autore e il messaggio di commit e tocca COMMIT per eseguire stage, commit e push su origin.

05 DOMANDE E RISPOSTE

Domande frequenti

Risposte pratiche su Personal Access Token di GitHub, repo privati, conflitti di merge e cronologia dei commit.

Come mi autentico con repository privati su GitHub, GitLab o Gitee?+
Genera un Personal Access Token (PAT) HTTPS con ambito repo su GitHub/GitLab/Gitee e incollalo nel campo Token durante Clone, Commit & Push o Pull. SuperCode lo salva in modo sicuro per non doverlo reinserire ogni volta.
Cosa succede se tocco Pull mentre ho schede non salvate o modifiche senza commit?+
SuperCode salva prima su disco le schede non salvate, mette automaticamente in stash le modifiche tracciate senza commit, scarica gli ultimi commit remoti, riapplica il lavoro locale e ricarica le schede aperte alla riga esatta del cursore.
Come visualizzo cosa è cambiato in un commit precedente o torno indietro?+
Apri Git Time Machine dalla Dashboard Git e tocca un commit nella timeline. Scegli Visualizza modifiche codice (Diff commit) per un unified diff a colori, Checkout (Solo visualizzazione) per ispezionare in sicurezza quello snapshot oppure Hard Reset per riavvolgere il branch.
Posso eseguire commit offline quando non ho connessione internet?+
Sì! Staging, commit locali, creazione di branch, ispezione della cronologia, unified diff e risoluzione dei conflitti funzionano tutti offline; esegui il push dei commit locali su origin appena torni online.
