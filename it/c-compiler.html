05 DOMANDE E RISPOSTE

Domande frequenti

Domande su compilazione C17 offline, header multi-file, <math.h> e input scanf su Android.

Il compilatore C di SuperCode è separato dal C++?+
Sì. Aprendo un file .c si attiva la console dedicata GNU C17 (-std=gnu17) e il linking con la libreria standard C pura, anziché compilare il codice C come C++.
Devo scrivere un Makefile per compilare più file .c e .h?+
No. SuperCode analizza automaticamente gli header #include "..." e i file .c collegati nel workspace e nelle schede aperte, compila in modo incrementale i file modificati e collega automaticamente <math.h> (-lm).
scanf() e fgets() funzionano in modo interattivo su Android?+
Sì. Il terminale a schermo diviso mette in pausa l'esecuzione quando il programma C legge da stdin, permette di inserire più righe di input in tempo reale e invia EOF premendo invio su un prompt vuoto.
E se il mio codice C usa header Linux POSIX come <pthread.h> o <sys/socket.h>?+
SuperCode rileva automaticamente gli header specifici di OS/POSIX e compila senza problemi il progetto multi-file sulla toolchain cloud POSIX, mantenendo la diagnostica esatta su nome file e numero di riga locali.
