05 DOMANDE E RISPOSTE

Domande frequenti

Domande frequenti su editing HTML5/CSS3/JS, ES Modules e anteprima viewport responsive su Android.

Perché `<script type="module">` o `fetch('./data.json')` falliscono in altre app editor HTML?+
I browser bloccano ES Modules e `fetch()` sugli URL `file://` per rigide norme di sicurezza CORS. SuperCode serve automaticamente il tuo progetto su una vera origine `localhost` HTTP/1.1 con header MIME corretti, così moduli JS moderni e fetch JSON funzionano nativamente offline.
Come posso vedere l'anteprima delle media query CSS per Tablet e Desktop sullo schermo di uno smartphone?+
Nell'anteprima Web live di SuperCode, tocca l'icona viewport sulla Dynamic Island flottante per passare istantaneamente tra viewport Mobile, Tablet (`768dp`) e Desktop ampio — attivando con precisione le tue regole `@media`.
Il formattatore 1-tap formatta anche il CSS dentro `<style>` e il JS dentro `<script>`?+
Sì. Il formattatore HTML ricorsivo di SuperCode analizza i blocchi `<style>` e `<script>` incorporati nei file `.html` e indenta tutti e tre i linguaggi con precisione in un solo tocco.
Posso usare offline video `.mp4`, font `.woff2` e modelli 3D `.glb` locali?+
Sì. Oltre 65 tipi MIME sono preconfigurati in locale, inclusi `font/woff2`, `model/gltf-binary`, `image/svg+xml` e streaming byte-range HTTP `206 Partial Content` per una ricerca fluida sulla timeline di `<video>` e `<audio>`.
