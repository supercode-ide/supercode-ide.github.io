05 DOMANDE E RISPOSTE

Domande frequenti

Domande frequenti su Java 17, OOP multi-file, file .jar personalizzati e input Scanner offline.

Quale versione di Java compila offline SuperCode su Android?+
SuperCode compila ed esegue Java 17 offline — inclusi record, classi sealed, espressioni switch, pattern matching per instanceof, text block e Stream — con instradamento automatico a Cloud Java per le funzionalità Java 21+.
Posso eseguire un progetto Java con più classi e package?+
Sì. SuperCode risolve tutti i file .java nelle cartelle del progetto e nelle schede aperte, individua automaticamente la classe con main() e sincronizza nel workspace i file generati.
Posso collegare Java a un database SQLite locale o aggiungere file .jar esterni?+
Sì! Un driver JDBC jdbc:sqlite:... offline è già integrato, e qualsiasi libreria .jar compatibile inserita nella cartella libs/ del progetto viene aggiunta automaticamente al classpath.
Scanner(System.in) funziona in modo interattivo?+
Sì. Il programma si mette in pausa in modo pulito ogni volta che Scanner o BufferedReader attende input, consentendoti di digitare più righe nel terminale a schermo diviso.
