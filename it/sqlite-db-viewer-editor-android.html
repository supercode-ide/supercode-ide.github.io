05 DOMANDE E RISPOSTE

Domande frequenti

Risposte su apertura di file `.db`/`.sqlite3`, importazione di dataset CSV/JSON ed export di risultati formattati offline.

Quali estensioni di file database SQLite può aprire direttamente SuperCode?+
SuperCode riconosce file `.db`, `.sqlite`, `.sqlite3`, `.db3` e `.s3db` in un tocco, eseguendo automaticamente un'ispezione offline di `.dbinfo`, `.tables` e `.schema`.
Perché SQLite 3.54.1 integrato fa la differenza rispetto ai comuni visualizzatori SQLite Android?+
La maggior parte dei viewer DB Android si affida alla vecchia build SQLite di sistema del telefono, priva di tabelle `STRICT`, `RETURNING`, `JSONB`, clausole Window frame moderne e query planner aggiornati. SuperCode include SQLite 3.54.1 in modo uniforme su tutti i dispositivi Android 8.0+.
Posso importare un file `.csv` o `.json` senza scrivere prima `CREATE TABLE`?+
Sì! Esegui `.import --csv filename.csv tablename` (o `--tsv` / `--json`) fino a 8 MB — se `tablename` non esiste ancora, SuperCode crea automaticamente lo schema della tabella dalle intestazioni CSV o dalle chiavi degli oggetti JSON.
Come esporto il risultato di una query SQL in una tabella Markdown o un file CSV?+
Aggiungi `.mode markdown` (o `.mode csv` / `.mode json` / `.mode insert`) seguito da `.once output.md` subito sopra la tua istruzione `SELECT` e tocca Esegui — il file appare immediatamente nel project explorer.
