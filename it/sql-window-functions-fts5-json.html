05 DOMANDE E RISPOSTE

Domande frequenti

Domande frequenti di studenti SQL, studenti di data science e candidati ai colloqui backend.

Posso esercitarmi offline su problemi SQL Window Function stile LeetCode (`DENSE_RANK`, `LAG`, somme mobili)?+
Sì! Ogni window function SQL standard (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) e le specifiche di frame `ROWS`/`RANGE`/`GROUPS` funzionano al 100% offline.
SuperCode supporta `MEDIAN()`, `PERCENTILE()` e `STDDEV()` direttamente in SQL?+
Sì. Mentre SQLite standard è privo di aggregati statistici, SuperCode pre-registra le funzioni native `MEDIAN(col)`, `PERCENTILE(col, 95)` e `STDDEV(col)` così i data analyst possono calcolare distribuzioni in un'unica `SELECT`.
Come funziona `READ_STDIN()` dentro una query `.sql`?+
Scrivi `WHERE department = READ_STDIN('Department name: ')` nel tuo file `.sql` e tocca Esegui — SuperCode ti chiede il valore interattivamente nella console ancorata così puoi rieseguire query parametrizzate senza modificare il codice.
La ricerca full-text FTS5 e i moduli spaziali R*Tree / Geopoly sono abilitati?+
Sì. Sia `USING fts5(...)` (inclusi `bm25()`, `highlight()` e `snippet()`) sia le estensioni spaziali `USING rtree(...)` / Geopoly sono compilate direttamente nel motore SQLite 3.54.1 offline di SuperCode.
