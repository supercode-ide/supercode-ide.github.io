05 DOMANDE E RISPOSTE

Domande frequenti

Domande comuni sull'uso dei moduli cjson, lsqlite3, LuaFileSystem e luarocks su Android.

Devo installare luarocks o un compilatore C per usare `cjson`, `lsqlite3` o `lfs`?+
No. Tutti gli 11+ alias delle estensioni principali (`cjson`, `dkjson`, `lsqlite3`, `sqlite3`, `lfs`, `crypto`, `sha2`, `md5`, `base64`, `regex`, `socket.http` e `inspect`) sono già pre-integrati in SuperCode e funzionano subito tramite `require()`.
`lsqlite3` può condividere lo stesso file `.db` con Python, PHP o l'IDE SQL di SuperCode?+
Sì! Un database `.db` creato da `lsqlite3` nella tua cartella di progetto è un file binario SQLite 3 standard che può essere interrogato direttamente in SQL Studio di SuperCode, Python `sqlite3`, PHP `PDO` o Java JDBC.
`cjson` supporta il pretty-printing formattato per i file di configurazione?+
Sì. Oltre ai classici `cjson.encode()` e `cjson.decode()`, SuperCode offre `cjson.encode_pretty()` per ispezionare o salvare JSON formattati in modo pulito offline.
Cosa succede se il mio script richiede `lpeg` o `luv`?+
Quando sei connesso a internet, SuperCode rileva gli import C-rock nativi specializzati come `lpeg` o `luv` e indirizza automaticamente il tuo progetto multi-file al suo ambiente Cloud Lua.
