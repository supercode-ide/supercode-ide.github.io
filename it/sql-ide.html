05 DOMANDE E RISPOSTE

Domande frequenti

Risposte su pratica SQL offline, apertura file .db/.sqlite, import CSV/JSON e sintassi MySQL.

Posso esercitarmi con query SQL offline senza configurare un server database?+
Sì! Crea un qualsiasi file .sql e tocca Run per eseguire query multi-statement CREATE, INSERT, JOIN, CTE e Window Function al 100% offline con tabelle Unicode Box Grid formattate.
SuperCode può aprire file .db e .sqlite già presenti sul mio telefono?+
Sì. Toccando o eseguendo un file .db, .sqlite, .sqlite3 o .db3 vengono ispezionati subito tabelle, viste, indici e schemi, e ogni script .sql nella stessa cartella di progetto può interrogare direttamente quel database.
Supporta sintassi MySQL come AUTO_INCREMENT, SHOW TABLES, DESCRIBE o Stored Procedure?+
DDL e comandi comuni MySQL/PostgreSQL (AUTO_INCREMENT, ENUM, SHOW TABLES, DESCRIBE, ILIKE) girano in locale offline, mentre Stored Procedure e Trigger specifici di MySQL 8.0 vengono instradati automaticamente a MySQL 8.0 Cloud.
Come esporto i risultati delle query SQL in CSV, Markdown o JSON?+
Aggiungi `.mode csv` (o `.mode markdown` / `.mode json`) e `.once output.csv` prima della query SELECT — SuperCode scrive il file esportato direttamente nella cartella del progetto.
