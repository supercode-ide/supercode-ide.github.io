05 DOMANDE E RISPOSTE

Domande frequenti

Risposte su esecuzione di file .js senza HTML, moduli ES, loop infiniti e moduli Node.js.

Posso eseguire un file .js direttamente su Android senza creare una pagina HTML?+
Sì! Toccando Esegui su qualsiasi file .js, .mjs o .cjs si avvia subito la console JavaScript standalone di SuperCode — completamente offline.
Posso dividere il codice JavaScript su più file con import/export o require()?+
Sì. Sia i moduli ES (import / export) sia CommonJS (require / module.exports), oltre agli import .json, funzionano tra file locali del progetto e schede non salvate.
Un ciclo while(true) accidentale bloccherà l'editor o farà perdere codice non salvato?+
Mai. Gli script vengono eseguiti in un worker isolato in background, protetto da un watchdog di 15 secondi e da un blocco anti-flood dell'output, terminando i loop fuori controllo in meno di 1 millisecondo senza toccare il thread UI.
E se volessi creare un sito DOM visivo con HTML, CSS e WebAssembly?+
SuperCode include entrambi! Usa l'IDE JavaScript standalone per moduli puri JS/Node e algoritmi, e lo Studio Web & PHP Full-Stack quando ti servono rendering DOM HTTP live, viewport responsive e Web DevTools.
