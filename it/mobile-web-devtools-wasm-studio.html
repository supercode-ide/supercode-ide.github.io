05 DOMANDE E RISPOSTE

Domande frequenti

Domande sull'ispezione degli errori console, monitoraggio richieste HTTP, esecuzione comandi JS DOM ed esecuzione `.wasm` offline.

Devo incollare `<script src="eruda.js">` o avere internet per far funzionare i DevTools?+
No! La Console Web DevTools, il monitor Network e il REPL JavaScript interattivo di SuperCode sono integrati nativamente nel motore di anteprima offline — zero tag script CDN esterni necessari e 100% operativi in modalità aereo.
Posso eseguire file binari WebAssembly `.wasm` compilati da Rust o C/C++?+
Sì. Inserisci il binario `.wasm` nella cartella del progetto e caricalo con `WebAssembly.instantiateStreaming(fetch('./module.wasm'))` — SuperCode serve `.wasm` con il tipo MIME esatto `application/wasm`.
Cosa succede se stampo nel log un elemento DOM o un oggetto con riferimenti circolari?+
Gli elementi DOM vengono visualizzati chiaramente come riepiloghi `<tag#id.class>` e i riferimenti circolari negli oggetti sono rilevati in sicurezza come `[Circular]` invece di generare eccezioni `JSON.stringify`.
La scheda Net cattura le chiamate backend PHP oltre ai file statici e a `fetch()`?+
Sì. Ogni asset statico, modulo ES, binario `.wasm`, chiamata `fetch()` / `XMLHttpRequest` ed esecuzione di endpoint `.php` locale appare nella scheda Net con codice di stato HTTP, latenza in millisecondi e dimensione payload in byte.
