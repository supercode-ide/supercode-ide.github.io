Ingegneria C multi-modulo reale senza attriti sugli script di build

Che tu metta due file `.c`/`.h` in una cartella o cloni un repository CMake strutturato da GitHub, SuperCode risolve automaticamente il grafo di compilazione.

Zero script di build · Supporto src/ e include/ annidati

Parser nativo del grafo target CMakeLists.txt

add_executable · add_library · target_include_directories

Estrazione sorgenti da Makefile e GNUmakefile

Lavori su un progetto universitario distribuito con Makefile o GNUmakefile? L'analizzatore estrae SRCS, OBJS, CFLAGS e dipendenze dei target per compilare offline in un tocco.

Potatura smart di #if 0 e rami #ifdef di piattaforma

I repository C multipiattaforma spesso proteggono <windows.h> o header macOS dentro blocchi #ifdef _WIN32 o #if 0. SuperCode rimuove i commenti ed esclude i rami del preprocessore inattivi prima di risolvere gli header.

Arbitraggio intelligente dell'entry point da header a main()

Tieni il cursore dentro include/parser.h o src/lexer.c e tocca direttamente Esegui. SuperCode ispeziona il grafo dei target, distingue le definizioni main() attive dai moduli di supporto e avvia il binario corretto.

05 DOMANDE E RISPOSTE

Domande frequenti

Domande comuni su errori `undefined reference`, percorsi `#include`, Makefile e CMake su Android.

Perché altre app C per Android danno `undefined reference` quando faccio `#include "helper.h"`?+
Le app mobile a file singolo passano al compilatore solo il file attivo e non collegano mai `helper.c`. SuperCode scansiona la cartella (e le sottocartelle `src/` o `include/`), compila `helper.c` insieme a `main.c` e collega automaticamente tutti i file oggetto.
Devo scrivere un `CMakeLists.txt` o un `Makefile` per piccoli progetti C?+
Assolutamente no. Se non è presente alcun `CMakeLists.txt` o `Makefile`, il crawler di dipendenze `#include "..."` a zero configurazione di SuperCode individua e collega automaticamente i file `.c` e `.h`. Se invece è presente un `CMakeLists.txt` o `Makefile`, SuperCode ne rispetta il grafo dei target.
Cosa succede se ho modifiche non salvate in una scheda `.h` aperta quando premo Esegui?+
SuperCode sovrappone automaticamente i buffer live non salvati dell'editor allo snapshot di build del workspace, così le modifiche tra schede `.h` e `.c` aperte si riflettono sempre all'istante.
Come gestisce SuperCode un workspace che contiene due programmi di test con `main()` separati?+
Se esegui un file che definisce il proprio `main()`, vince quel `main()`. Se esegui da un header `.h` condiviso, SuperCode controlla i target di `CMakeLists.txt`/`Makefile` e i collegamenti `#include` locali per scegliere l'eseguibile corrispondente senza conflitti di simboli duplicati.
