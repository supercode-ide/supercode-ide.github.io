05 DOMANDE E RISPOSTE

Domande frequenti

Risoluzione problemi per prompt `scanf`, newline di `fgets`, `EOF` e percorsi `fopen` su Android.

Perché `printf("Inserisci numero: ");` appare subito in SuperCode senza `fflush(stdout)`?+
Gli stream C standard usano spesso il block-buffering su pipe, nascondendo i prompt senza `\\n` finale. SuperCode imposta automaticamente gli stream standard senza buffering così i prompt interattivi compaiono prima che `scanf`, `fgets` o `getchar` attendano l'input.
Come invio `Ctrl+D` (`EOF`) da una tastiera touchscreen Android?+
Quando la barra di input della console è attiva e vuota, toccare Invia trasmette in modo pulito `EOF` (`[EOF]`) al processo C in esecuzione, chiudendo i cicli `while (scanf(...) != EOF)` e `getchar() != EOF`.
Come passo argomenti da riga di comando con spazi a `char *argv[]`?+
Scrivi `// @args "Mio Report.txt" -n 10` in cima al file `.c`. Il tokenizer degli argomenti di SuperCode conserva le stringhe tra virgolette come un singolo elemento `argv[i]` e supporta fino a 32 argomenti.
Dove vengono salvati i file creati con `fopen("output.txt", "w")`?+
Vengono sincronizzati direttamente nella stessa cartella di progetto Android del file sorgente `.c`, quindi restano salvati in modo permanente e si aprono subito nell'editor di SuperCode.
