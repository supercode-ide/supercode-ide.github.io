03 תהליך עבודה שלב אחר שלב

שלב אחר שלב: שימוש ב-PIP ובחבילות Wheel אופליין ב-SuperCode

התקינו חבילות PyPI אונליין או טענו קובצי .whl אופליין בפחות מ-30 שניות.

STEP 01 Python Console -> PIP Icon

פתחו את מנהל חבילות ה-PIP החזותי

פתחו כל קובץ .py ולחצו על סמל ה-PIP בכותרת קונסולת ה-Python — או פשוט הריצו סקריפט עם ייבוא שלא הותקן כדי להפעיל את Auto-PIP.

STEP 02 Quick Chips / Input Box

בחרו תגית פופולרית, הדביקו pip install או בחרו requirements.txt

לחצו על תגיות מהירות (requests, rich, beautifulsoup4, pyyaml, flask, telebot, colorama), הזינו מפרטי גרסה, או לחצו על באנר ה-requirements.txt שזוהה אוטומטית.

STEP 03 Import Local Archive (.whl)

או סרקו את ההורדות לחבילות .whl / .zip אופליין

בסביבות אופליין, לחצו על Local Archive בחלון ה-PIP כדי לסרוק את תיקיית ההורדות או הפרויקט אחר חבילות .whl, .tar.gz ו-.zip.

STEP 04 Manage Tab -> Verify

ייבאו מידית בכל הסקריפטים המרובים בפרויקט

הספריות המותקנות נשמרות בתיקיית site-packages המבודדת גם לאחר הפעלה מחדש של האפליקציה ועובדות מיד עם השלמה אוטומטית מבוססת AST.

site-packages קבוע במכשיר · הזרמת לוג התקנה לא-חוסמת ב-50ms מדריך האפליקציה

05 שאלות ותשובות

שאלות נפוצות

שאלות נפוצות על התקנת חבילות PyPI, קובצי .whl אופליין ו-requirements.txt ב-Android.

אפשר להדביק פקודה מלאה כמו `pip install requests beautifulsoup4` לתוך SuperCode?+
כן. מנתח הקלט של PIP מסיר אוטומטית תחיליות `pip install`, `pip3 install` או `python -m pip install`, מתעלם בבטחה מדגלי CLI לא נתמכים, ומכניס לתור את כל החבילות הרשומות עם אילוצי הגרסה לפי PEP 440.
איך מתקינים חבילות Python ב-Android כשאין לי אינטרנט?+
הורידו מראש את הארכיון ב-pure-Python בפורמט `.whl` (כגון `*-py3-none-any.whl`), `.tar.gz` או `.zip` לטלפון, פתחו את מנהל חבילות ה-PIP ב-SuperCode ולחצו על כפתור Local Archive כדי להתקין ישירות מתיקיית ההורדות.
למה לא צריך להריץ ידנית `pip install numpy` או `matplotlib`?+
ספריות עם הרחבות C/Fortran כבדות כמו NumPy, Pandas, SciPy, Matplotlib ו-Scikit-Learn מותאמות מראש בסביבת הריצה המדעית של SuperCode. פשוט כתבו `import numpy as np` בסקריפט ולחצו Run.
האם חבילות PIP שהותקנו נשארות בטלפון גם אחרי סגירת האפליקציה?+
כן. כל חבילה מותקנת נשמרת באופן קבוע באחסון ה-`python_site_packages` המקומי של SuperCode, כך שהסקריפטים שלך ירוצו אופליין בכל עת ללא התקנה חוזרת.
