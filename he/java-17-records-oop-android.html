05 שאלות ותשובות

שאלות נפוצות

תשובות על תמיכת Java 17 אופליין, מעבר מ-Jvdroid ותכונות Java 21+ ב-Android.

האם SuperCode באמת מהדר records ו-sealed classes של Java 17 ללא אינטרנט?+
כן. מרגע ש-Java 17 SDK האופליין הקל מאותחל בהפעלה הראשונה, `record`, `sealed` / `permits`, ביטויי `switch ->`, pattern matching של `instanceof`, בלוקי טקסט (`\"\"\"`) ו-`Stream.toList()` מתהדרים ורצים 100% אופליין במצב טיסה.
איך SuperCode מתפקד כחלופה מודרנית לאפליקציות Java 8 או Java 11 במובייל?+
אפליקציות Java ישנות ב-Android נכשלות לעיתים קרובות במטלות אקדמיות ובפתרונות LeetCode שמשתמשים ב-`record`, `Stream.toList()` או ביטויי switch. SuperCode תומך ב-Java 17 LTS מלא אופליין ובגיבוי אוטומטי ל-Cloud Java 21+, לצד Visual Git ו-SQLite JDBC מובנה.
האם אפשר להשתמש ב-`CompletableFuture`, `Optional` ו-`java.time` אופליין?+
כן. כל ספריית הליבה התקנית — כולל `java.util.stream`, `java.util.concurrent.CompletableFuture`, `java.time.*`, `java.math.BigDecimal` ו-`java.nio.file` — רצה מקומית אופליין.
איך מריצים Virtual Threads של Java 21 בטלפון Android?+
פשוט כתבו `Thread.ofVirtual()` או `Executors.newVirtualThreadPerTaskExecutor()` (או הוסיפו `// @cloud` בראש הקובץ) והקישו Run. SuperCode אורז אוטומטית את מחלקות הפרויקט ל-Cloud Java 21+ ומזרים את הפלט בחזרה לקונסול.
