05 שאלות ותשובות

שאלות נפוצות

תשובות על ייצוא HTML5 Canvas, תיקון משך WebM, polyfills של File Picker ו-IndexedDB ב-Android.

האם הורדות Blob ו-showSaveFilePicker() באמת עובדים בתצוגת הווב של SuperCode?+
כן. SuperCode מזריק בתחילת המסמך את WebMediaBridge ללא race conditions, המגשר הורדות Blob/DataURL, showSaveFilePicker, showOpenFilePicker ו-navigator.share ישירות לאחסון הטבעי של Android.
למה סרטוני WebM מ-Canvas MediaRecorder מתנגנים עם ציר זמן מדויק כשהם מיוצאים מ-SuperCode?+
SuperCode מריץ שלב תיקון EBML טהור ב-Kotlin ל-SeekHead, Duration ו-Cues לפני השמירה ל-MediaStore — ומתקן את המטא-דאטה החסרה של Chrome/WebView ללא קידוד מחדש.
האם אפשר לבנות משחקי HTML5 Canvas 2D ו-WebGL אופליין ב-SuperCode?+
כן. שרת ה-HTTP המקומי האמיתי תומך במודולי ES, טקסטורות, נכסי אודיו, גרירת HTTP 206, טבלאות שיאים ב-localStorage ובדיקת שגיאות ב-DevTools Console לחלוטין אופליין.
היכן נשמרים קובצי התמונה, הווידאו והאודיו שמייצאת אפליקציית הווב שלי?+
