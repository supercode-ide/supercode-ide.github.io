02 יכולות ליבה

שש שכבות מחוברות של הנדסת Web מודרנית ב-Android

מודולי ES בצד הלקוח, WebAssembly בינארי, סשנים ב-PHP בצד השרת, מסדי נתונים יחסיים ב-SQL, בדיקת DevTools ופריסת SFTP מרוחקת — במקום אחד.

02.1

מקור HTTP מקומי אמיתי ל-HTML5, CSS3, JS ו-WASM

מגיש פרויקטים דרך מקור HTTP/1.1 מקומי אמיתי במקום כתובות file:// שבורות — ומאפשר fetch(), <script type="module">, WebAssembly.instantiateStreaming() (.wasm), נכסי WebGL .glb/.gltf, IndexedDB וגלילה מדויקת בווידאו/אודיו עם HTTP 206.

65+ סוגי MIME · ES Modules · application/wasm · HTTP 206
02.2

מנוע Backend דינמי של PHP 100% אופליין

הרץ תבניות .php מרובות דפים, מחלקות OOP, closures, match ו-include/require לגמרי אופליין עם $_GET, $_POST, $_SESSION מתמשך, העלאות $_FILES, כותרות JSON REST ו-password_hash().

$_GET / $_POST / $_SESSION · ממשקי JSON API · PHP אופליין
02.3

מסדי נתונים SQL משולבים דרך PDO ו-SQLite3

בנה אפליקציות PHP מונחות-נתונים אופליין בעזרת new PDO('sqlite:app.db') או SQLite3 עם prepared statements (קישורי ? ו-:named), טרנזקציות ACID ובדיקת טבלאות מיידית ב-SQL IDE.

PDO('sqlite:...') · Prepared Statements · טרנזקציות ACID
02.4

קונסולת DevTools צפה, יומן רשת ו-JS REPL

בדוק בקשות HTTP חיות (GET /api.php -> 200 · 3ms · 1.2 KB), סנן לוגים לפי All / Error / Warn / Net, סקור עצי DOM ואובייקטים מובנים, והרץ ביטויים חיים בתוך > Run JavaScript... REPL.

תזמון רשת · תג שגיאות · JS REPL אינטראקטיבי
02.5

מחליף תצוגות ב-3 מצבים ולכידת דף ב-2560px

עבור מיד בין פריסות מובייל, טאבלט (768dp) ודסקטופ מתוך ה-Dynamic Island הנגרר, בדוק העלאות <input type="file"> מהמצלמה והגלריה, וייצא צילומי מסך חדים ברוחב 2560px PNG.

מובייל / טאבלט / דסקטופ · ייצוא PNG 2560px
02.6

תצוגה מקדימה ופריסה חיה ב-FTP / FTPS / SFTP מרוחק

03 תהליך עבודה שלב אחר שלב

איך בונים, מדבגים ופורסים אתר Full-Stack ב-Android

מאב-טיפוס מקומי של HTML/CSS/WASM ו-PHP+SQL ועד לפריסה בשרת חי.

STEP 01 index.html / index.php

כתוב קבצי HTML5, CSS3, JS, WASM ו-PHP

ערוך פרויקטי Web מרובי-קבצים עם השלמת AST ל-HTML/CSS/JS/PHP ועיצוב קוד רקורסיבי בלחיצה אחת המיישר יחד בלוקים מוטמעים של <script> ו-<style>.

STEP 02 PDO + app.db

חבר טפסי PHP וממשקי API אופליין ל-SQL

שלוף נתונים ממסדי .db מקומיים של SQLite מתוך PHP באמצעות PDO prepared statements, או אתחל טבלאות ישירות בתוך SQL Studio של SuperCode.

STEP 03 Run ▶ -> Dynamic Island

צפה במובייל, טאבלט ודסקטופ + DevTools

החלף רזולוציות תצוגה תוך כדי תנועה, בדוק סטטוס רשת ושגיאות JS במגירת DevTools, או נסה התאמות DOM חיות ב-JS REPL.

STEP 04 SFTP / Visual Git

פרסם עדכונים ישירות לשרת או ל-GitHub Pages

דחוף גרסאות סטטיות/WASM ל-GitHub Pages דרך Visual Git, או פרוס קבצי PHP ונכסי Web ישירות ל-VPS שלך דרך SFTP/FTPS.

החלקה מהקצה השמאלי מחזירה ישר לסייר הקבצים · איפוס מטמון וסשן בלחיצה אחת מדריך האפליקציה

05 שאלות ותשובות

שאלות נפוצות

תשובות על PHP + SQLite אופליין, ES Modules / fetch() / WASM, Web DevTools ופריסת FTP/SFTP.

אפשר להריץ אתרי PHP דינמיים ולהתחבר למסדי נתונים SQL אופליין ב-Android?+
כן! SuperCode מריצה דפי .php, נקודות קצה REST JSON, סשנים, העלאות טפסים והכללת קבצים מרובים לגמרי אופליין, עם תמיכה מובנית ב-PDO('sqlite:...') ובמסדי נתונים SQLite3.
האם מודולי ES6 (<script type="module">), fetch() ו-WebAssembly (.wasm) עובדים?+
כן. מכיוון ש-SuperCode מגישה את הפרויקט שלך דרך שרת HTTP מקומי אמיתי עם מעל 65 סוגי MIME (כולל application/wasm), fetch(), ES modules, מודלים תלת-ממדיים ב-WebGL ו-WebAssembly.instantiateStreaming() עובדים מיד מהקופסה.
איך מדבגים שגיאות JavaScript, בקשות רשת ופריסות דסקטופ בטלפון?+
הקש על גלולת ה-Dynamic Island הניתנת לגרירה במצב תצוגה מקדימה כדי לעבור בין תצוגות מובייל, טאבלט (768dp) ודסקטופ, או פתח את מגירת Web DevTools הניתנת לשינוי גודל כדי לסנן לוגים של Error/Warn/Net ולהריץ JavaScript חי ב-REPL.
אפשר לצפות בתצוגה מקדימה ולעדכן אתרים המתארחים בשרת FTP או SFTP מרוחק?+
כן. עגון את השרת בסביבת SFTP/FTPS/FTP, ערוך ישירות לשוניות HTML/CSS/JS/PHP מרוחקות עם שמירה אטומית ב-3 שלבים, והקש Run כדי לצפות בדפים מרוחקים עם שמירת משאבים במטמון לפי דרישה.
