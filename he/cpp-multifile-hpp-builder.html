05 שאלות ותשובות

שאלות נפוצות

שאלות על 21 תבניות הפרויקט ב-C++, קובצי `.hpp`/`.inl`, `#pragma once` ו-CMake ב-Android.

מה כלול ב-21 פרויקטי ההתחלה מרובי הקבצים של SuperCode ב-C++?+
כל אחת מ-21 תבניות הפרויקט מקימה תיקייה נקייה הכוללת כותרות `.h`/`.hpp` מודולריות, קובצי מימוש `.cpp`, קובץ ראשי `main.cpp` וקובץ `CMakeLists.txt` תקני—כך שתוכלו להריץ, ללמוד או להתאים ארכיטקטורה מרובת מחלקות עובדת באופן מיידי.
האם אפשר לקחת פרויקט CMake שנוצר ב-SuperCode ולפתוח אותו ב-CLion או VS Code במחשב הנייד?+
כן! מאחר שהפרויקטים הנוצרים משתמשים בקובצי `CMakeLists.txt` תקניים ובמבנה תיקיות נייד של ISO/GNU C++20, הם נפתחים בצורה נקייה בסביבות פיתוח שולחניות דרך Git ללא נעילה לפורמט קנייני.
האם SuperCode תומך בספריות header-only ובקובצי מימוש טמפלייט `.inl` / `.ipp`?+
כן. גם כותרות `#pragma once` וגם קובצי טמפלייט `.inl` / `.ipp` בתוך `include/` או תיקיות משנה מקוננות נמצאים במעקב של סורק התלויות ומטמון גיבוב התוכן.
מה קורה אם אני משנה שם או מפצל קובץ `.cpp` בזמן עבודה אופליין?+
גם מפענח ה-`CMakeLists.txt` וגם סורק ה-`#include` האוטומטי מאנדקסים מחדש את סביבת העבודה אוטומטית בהרצה הבאה, וקולטים מיד קובצי `.cpp` ו-`.hpp` חדשים או כאלה ששמם שונה.
