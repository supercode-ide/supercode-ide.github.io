05 שאלות ותשובות

שאלות נפוצות

תשובות על הרצת Scikit-Learn, OpenCV, PyTorch ותהליכי עבודה מול GPU מרוחק מ-Android.

האם אפשר להריץ Scikit-Learn, XGBoost ו-OpenCV (`cv2`) בלי אינטרנט?+
כן. לאחר שהחבילות נשמרו במטמון המכשיר על ידי סביבת הריצה המדעית של SuperCode, החבילות `scikit-learn`, `xgboost`, `lightgbm`, `opencv-python` (`cv2`), `Pillow` ו-`scikit-image` רצות אופליין לחלוטין.
איך מריצים קוד PyTorch או TensorFlow בלי למלא את אחסון הטלפון?+
פשוט כתבו `import torch` או `import tensorflow as tf` (או הוסיפו `# @cloud` בשורה 1). SuperCode אורזת את מודולי ה-.py המקומיים שלכם, מריצה אותם באשכול ה-Python בענן, וממפה כל traceback ישירות לשורות בעורך המקומי.
האם אפשר לערוך ולהריץ סקריפטים ישירות על תחנת ה-Linux GPU שלי?+
כן. התחברו לתחנת העבודה דרך סביבת ה-SFTP של SuperCode (עם תמיכה במפתחות SSH מסוג Ed25519/RSA מוצפנים ב-AES-256) כדי לערוך קובצי `.py` וקונפיגורציות `.yaml` מרוחקים עם השלמת AST מלאה ושמירה אטומית תלת-שלבית.
האם `cv2.imwrite()` שומר תמונות מעובדות בתיקייה שלי?+
כן — כל תמונה שנכתבת דרך `cv2.imwrite()` או `Image.save()` מסונכרנת ישירות לתיקיית הפרויקט ונפתחת בצורה נקייה במציג התמונות המובנה של SuperCode.
