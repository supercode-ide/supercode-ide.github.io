02.1

עקפו בבטחה חסימות noexec באחסון משותף (ללא Root)

Android מעגנת את /storage/emulated/0 ואת Downloads עם דגל noexec, החוסם את chmod +x ו-./script.sh. SuperCode מגשרת את ההרצה בתוך ארגז חול נקי ללא Root ומשקפת חלק את קובצי סביבת העבודה.

05 שאלות ותשובות

שאלות נפוצות

שאלות נפוצות על הרצת סקריפטי `.sh` ללא Root ופתרון שגיאות `Permission denied` ב-Android.

למה מתקבלת שגיאת `Permission denied` בהרצת קובץ `.sh` מתיקיית Downloads ב-Android?+
מטעמי אבטחה, Android מעגנת את האחסון המשותף של המשתמש (`/sdcard`, `Downloads`, `Documents`) עם דגל מערכת הקבצים `noexec`, כך שאפילו `chmod +x` לא יכול לסמן שם קבצים כבר-הרצה. SuperCode מבצעת את הרצת הסקריפט בצורה נקייה בסביבת הריצה הנייטיב שלה תוך סנכרון אוטומטי של תיקיית הפרויקט.
האם SuperCode דורשת מכשיר Android עם Root כדי להריץ סקריפטי Shell?+
לא. SuperCode עובדת מיד מהקופסה על טלפונים, מכשירים מתקפלים וטאבלטים רגילים עם Android 8.0+ ללא Root.
איך מעבירים ארגומנטים משורת הפקודה כמו `./deploy.sh --env staging`?+
הוסיפו `# @args --env staging` בראש הסקריפט (או הזינו קלט אינטראקטיבית דרך `read -p`), ו-SuperCode תעביר את פרמטרי המיקום הללו (`$1`, `$2`, `$@`) ישירות לסקריפט בהרצה.
האם סקריפט `.sh` יכול ליצור קבצים או תיקיות חדשים בתוך סביבת העבודה שלי?+
כן. כל הקבצים, הלוגים או הארכיונים שנוצרים באופן יחסי ל-`$PWD` בזמן ההרצה מסונכרנים אוטומטית חזרה לתיקיית הפרויקט הפעילה שלכם ב-Android.
