05 ÎNTREBĂRI ȘI RĂSPUNSURI

Întrebări frecvente

Răspunsuri despre PHP + SQLite offline, module ES / fetch() / WASM, Web DevTools și deploy FTP/SFTP.

Pot rula site-uri PHP dinamice și conecta baze de date SQL offline pe Android?+
Da! SuperCode rulează pagini .php, endpoint-uri REST JSON, sesiuni, încărcări de formulare și include-uri multi-fișier complet offline, cu suport integrat pentru baze de date PDO('sqlite:...') și SQLite3.
Funcționează modulele ES6 (<script type="module">), fetch() și WebAssembly (.wasm)?+
Da. Deoarece SuperCode servește proiectul printr-un server HTTP local real cu peste 65 de tipuri MIME (inclusiv application/wasm), fetch(), modulele ES, modelele 3D WebGL și WebAssembly.instantiateStreaming() funcționează imediat.
Cum depanez erorile JavaScript, cererile de rețea și layout-urile desktop pe telefon?+
Atinge pilula Dynamic Island glisabilă în modul de previzualizare pentru a comuta între viewport-urile Mobil, Tabletă (768dp) și Desktop, sau deschide sertarul redimensionabil Web DevTools pentru a filtra jurnalele Error/Warn/Net și a rula JavaScript live în REPL.
Pot previzualiza și actualiza site-uri găzduite pe un server FTP sau SFTP la distanță?+
Da. Montează serverul în spațiul de lucru SFTP/FTPS/FTP, editează direct filele HTML/CSS/JS/PHP de la distanță cu salvare atomică în 3 faze și apasă Rulează pentru a previzualiza paginile la distanță cu caching la cerere al resurselor.
