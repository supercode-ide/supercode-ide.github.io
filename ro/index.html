05 ÎNTREBĂRI ȘI RĂSPUNSURI

Întrebări frecvente

Răspunsuri directe despre compilatoarele offline, gestionarea fișierelor mari, limbajele suportate și fluxurile Git/SFTP.

Ce limbaje de programare rulează offline în SuperCode IDE pe Android?+
SuperCode rulează local pe Android Python (3.11 & 3.12 științific), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, PHP, HTML5/CSS3/WebAssembly, Lua 5.4 și scripturi Linux Shell, cu suport cloud opțional pentru Kotlin, MySQL 8.0 și framework-uri server complexe.
Poate SuperCode să deschidă fișiere jurnal de ordinul gigabyților și dump-uri SQL fără să înghețe?+
Da. Fișierele mai mari de 30 MB activează automat paginarea în streaming de ordinul GB, împărțind fișiere de sute de MB și GB în segmente pe disc de 10M caractere, cu salt instantaneu la pagină, detectare a 34 de seturi de caractere și înlocuire regex în flux global.
Sunt C și C++, sau SQL și Web/PHP, medii dedicate separate?+
Da. C17 și C++20 au fiecare standarde, headere și șabloane dedicate; SQL dispune de propria consolă cu 9 moduri și inspector binar .db; iar Web Studio rulează un server local real HTTP + PHP + PDO SQLite + WebAssembly cu DevTools integrate.
Include SuperCode un client Git integrat și un editor la distanță SFTP/FTPS?+
Da. Include un client Git vizual complet autonom (Clone cu PAT, ramificare, diff-uri unificate Commit Time Machine și rezolvare conflicte de merge) plus un spațiu de lucru SFTP, FTPS (TLS 1.3) și FTP criptat AES-256 cu salvări atomice la distanță în 3 faze.
Este SuperCode optimizat atât pentru telefoane Android, cât și pentru tablete?+
Da. Pe telefoane, barele de instrumente sunt plasate la îndemână, cu un meniu prin glisare din marginea dreaptă și consolă divizată cu pliere automată; pe pliabile și tablete, bara se andochează vertical, iar terminalul se deschide într-o stație de lucru alăturată 55% / 45%.

O singură aplicație nativă. Paisprezece spații de lucru inginerești în buzunar.
