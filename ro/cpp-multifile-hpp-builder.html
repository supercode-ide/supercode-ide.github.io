05 ÎNTREBĂRI ȘI RĂSPUNSURI

Întrebări frecvente

Întrebări despre cele 21 de șabloane de proiecte C++, fișierele `.hpp`/`.inl`, `#pragma once` și CMake pe Android.

Ce conțin cele 21 de proiecte de start C++ multi-fișier din SuperCode?+
Fiecare dintre cele 21 de șabloane creează un folder curat cu headere modulare `.h`/`.hpp`, fișiere de implementare `.cpp`, un fișier principal `main.cpp` și un `CMakeLists.txt` standard—astfel încât poți rula, studia sau personaliza imediat o arhitectură funcțională cu mai multe clase.
Pot lua un proiect CMake creat în SuperCode și să îl deschid în CLion sau VS Code pe laptop?+
Da! Deoarece proiectele generate folosesc fișiere `CMakeLists.txt` standard și structuri de directoare ISO/GNU C++20 portabile, se deschid curat în IDE-urile desktop prin Git, fără blocare într-un format proprietar.
Suportă SuperCode biblioteci header-only și fișiere de implementare template `.inl` / `.ipp`?+
Da. Atât headerele `#pragma once`, cât și fișierele template `.inl` / `.ipp` din `include/` sau subfoldere imbricate sunt urmărite de scannerul de dependențe și de cache-ul bazat pe hash de conținut.
Ce se întâmplă dacă redenumesc sau împart un fișier `.cpp` cât lucrez offline?+
Atât parserul `CMakeLists.txt`, cât și crawlerul `#include` zero-config reindexează automat workspace-ul la următoarea rulare, preluând imediat fișierele `.cpp` și `.hpp` nou adăugate sau redenumite.
