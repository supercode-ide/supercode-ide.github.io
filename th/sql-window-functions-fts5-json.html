02 ความสามารถหลัก

สร้างมาเพื่อการสัมภาษณ์ Data Engineering, แล็บ DBMS มหาวิทยาลัย และงานวิเคราะห์ข้อมูล

ครบทุกโครงสร้าง SQL ยุคใหม่ที่ออกสอบสัมภาษณ์สายข้อมูล FAANG/LeetCode — รันจบในระดับมิลลิวินาทีแม้เปิดโหมดเครื่องบิน

02.1

Window Functions, LAG/LEAD & Rolling Frames

แก้โจทย์ Top-N ต่อกลุ่ม, Sessionization, Retention Cohort และค่าเฉลี่ยเคลื่อนที่ 7 วันแบบออฟไลน์ด้วย ROW_NUMBER(), DENSE_RANK(), NTILE(), LAG(), LEAD() และ ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW

ROW_NUMBER · DENSE_RANK · LAG/LEAD · Frame Clauses
02.2

WITH RECURSIVE CTEs, STRICT & RETURNING

สร้างตารางปฏิทิน ท่องโครงสร้างองค์กรแบบลำดับชั้นและกราฟด้วย WITH RECURSIVE บังคับชนิดข้อมูลอย่างเคร่งครัดด้วยตาราง STRICT และรับค่าแถวที่เปลี่ยนแปลงในครั้งเดียวผ่าน UPSERT ... RETURNING *

WITH RECURSIVE · STRICT Types · UPSERT RETURNING
02.3

JSON / JSONB ดั้งเดิม (->, ->>) & json_each()

จัดเก็บเพย์โหลด JSONB แบบไบนารีและ Query แอตทริบิวต์ซ้อนด้วยตัวดำเนินการ -> และ ->> แตกอาเรย์ JSON เป็นแถวความสัมพันธ์ด้วย json_each() หรือ json_tree() และประกอบผลลัพธ์ JSON ซ้อนด้วย json_group_object()

ไบนารี JSONB · -> / ->> · แตกอาเรย์ json_each()
02.4

ค้นหาข้อความเต็ม FTS5 (bm25) & เชิงพื้นที่ Geopoly

สร้างเสิร์ชเอนจินความเร็วสูงแบบออฟไลน์ด้วย CREATE VIRTUAL TABLE ... USING fts5(...) พร้อมการจับคู่บูลีน/คำนำหน้า จัดอันดับความเกี่ยวข้อง bm25() และ highlight() — รวมถึงดัชนีหลายมิติ R*Tree และ Query รูปหลายเหลี่ยม Geopoly

FTS5 · จัดอันดับ bm25() · highlight() · R*Tree/Geopoly
02.5

MEDIAN(), PERCENTILE(), STDDEV() & READ_STDIN()

SQLite มาตรฐานไม่มีฟังก์ชันสถิติรวม — SuperCode เพิ่ม MEDIAN(), PERCENTILE(x, p) และ STDDEV() ในตัว พร้อมนิพจน์โต้ตอบ READ_STDIN('Prompt: ') เพื่อทดสอบ Query แบบรับพารามิเตอร์แบบไดนามิก

03 ขั้นตอนการทำงาน

วิธีฝึกทำโจทย์สัมภาษณ์ SQL และงานวิเคราะห์แบบออฟไลน์บนมือถือ

ฝึก SQL ให้คล่องระหว่างเดินทาง พร้อมผลลัพธ์ตาราง Unicode ทันทีโดยไม่ง้อ Wi-Fi

STEP 01 Templates -> 6 SQL Labs

เลือก 1 ใน 6 เทมเพลต Analytical SQL ในตัว

เปิดไฟล์ .sql ใหม่แล้วแตะ Templates เพื่อโหลด Schema ตัวอย่างที่มีข้อมูลยอดขาย พนักงาน JSON หรือ FTS5 เตรียมไว้พร้อมใช้

STEP 02 AST + Symbol Bar

เขียน CTEs, Joins & OVER() ที่ซับซ้อนได้รวดเร็ว

พิมพ์เครื่องหมายคำพูดเดี่ยว วงเล็บ -> และ * ได้สะดวกบนแถบ 21 ปุ่ม พร้อมระบบเติมคีย์เวิร์ดและชื่อคอลัมน์ SQL แบบออฟไลน์

STEP 03 Run ▶ (.mode box)

ตรวจตารางจัดอันดับและเวลาประมวลผลระดับต่ำกว่ามิลลิวินาที

แตะ Run ▶ เพื่อดูตาราง Unicode box คมชัด ทดสอบ Edge Case แบบโต้ตอบด้วย READ_STDIN() และปรับแต่ง Window Partition ของคุณ

STEP 04 Export PDF / .md

บันทึกโน้ตการเรียนเป็น Markdown หรือ PDF A4

ส่งออกผลลัพธ์ Query ผ่าน .mode markdown + .once notes.md หรือพิมพ์เฉลย .sql เป็นไฟล์ PDF A4 สำหรับส่งงานมหาวิทยาลัย

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามที่พบบ่อยจากผู้เรียน SQL นักศึกษาสาย Data Science และผู้เตรียมสัมภาษณ์ Backend

ฉันสามารถฝึกโจทย์ SQL Window Function สไตล์ LeetCode (`DENSE_RANK`, `LAG`, ผลรวมสะสม) แบบออฟไลน์ได้ไหม?+
ได้! Window Function มาตรฐานทุกตัว (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) รวมถึงการกำหนดขอบเขต `ROWS`/`RANGE`/`GROUPS` ทำงานแบบออฟไลน์ 100%
SuperCode รองรับ `MEDIAN()`, `PERCENTILE()` และ `STDDEV()` ใน SQL โดยตรงเลยไหม?+
ใช่ แม้ SQLite ปกติจะไม่มีฟังก์ชันสถิติรวม แต่ SuperCode ลงทะเบียนฟังก์ชัน `MEDIAN(col)`, `PERCENTILE(col, 95)` และ `STDDEV(col)` ไว้ในตัว ทำให้นักวิเคราะห์ข้อมูลคำนวณการกระจายตัวได้ใน `SELECT` เดียว
`READ_STDIN()` ทำงานอย่างไรภายใน Query `.sql`?+
พิมพ์ `WHERE department = READ_STDIN('Department name: ')` ในไฟล์ `.sql` แล้วแตะ Run — SuperCode จะขึ้นพรอมต์ถามค่าแบบโต้ตอบในคอนโซลด้านล่าง คุณจึงรัน Query แบบรับพารามิเตอร์ซ้ำได้โดยไม่ต้องแก้โค้ด
โมดูลค้นหาข้อความเต็ม FTS5 และเชิงพื้นที่ R*Tree / Geopoly เปิดใช้งานไว้ไหม?+
เปิดใช้งานครบ ทั้ง `USING fts5(...)` (รวม `bm25()`, `highlight()` และ `snippet()`) รวมถึงส่วนขยายเชิงพื้นที่ `USING rtree(...)` / Geopoly ถูกคอมไพล์ไว้ในเอนจิน SQLite 3.54.1 ออฟไลน์ของ SuperCode โดยตรง
