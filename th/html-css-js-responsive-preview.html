02 ความสามารถหลัก

ทำไมนักพัฒนา Frontend ถึงอัปเกรดจากแอปดู HTML ทั่วไปบนมือถือ

ระบบ Origin ของเบราว์เซอร์จริง การทดสอบเลย์เอาต์หลายจุดตัดหน้าจอ และการจัดรูปแบบโค้ดที่ลื่นไหลบนมือถือ จอพับ และแท็บเล็ต

02.1

เซิร์ฟเวอร์ HTTP/1.1 จริงในเครื่อง (65+ ประเภท MIME)

บอกลาปัญหา CORS 'origin null' ไปได้เลย การเสิร์ฟผ่าน localhost HTTP/1.1 จริงช่วยให้ใช้ <script type="module">, fetch('./data.json'), localStorage, IndexedDB, SVG สไปรต์ และเว็บฟอนต์ .woff2 ได้เต็มรูปแบบ

Localhost Origin จริง · 65+ MIME · ไร้บล็อก CORS
02.2

ตัวสลับหน้าจอ 3 ขนาดสไตล์ Dynamic Island

เช็กการทำงานของ CSS Grid, Flexbox และ @media queries ข้ามขนาดจอได้โดยไม่ต้องพก 3 เครื่อง แตะแคปซูล Dynamic Island ที่ลากย้ายได้เพื่อสลับระหว่างจอมือถือ แท็บเล็ต (768dp) และเดสก์ท็อปแบบสดๆ

จุดตัด มือถือ · แท็บเล็ต (768dp) · เดสก์ท็อป
02.3

จัดรูปแบบ HTML + <style> + <script> แบบเรียกซ้ำในคลิกเดียว

ไฟล์ต้นแบบเดี่ยวก็สะอาดตาได้: แตะ Format ครั้งเดียวเพื่อจัดเยื้ององค์ประกอบ HTML5 ที่ซ้อนกัน พร้อมจัดรูปแบบ CSS ภายใน <style> และโค้ด JavaScript ในบล็อก <script> ต่อเนื่องทันที

จัดสวยครบในที่เดียว: Markup + CSS + JS
02.4

สตรีมสื่อ HTTP 206 & เชดเดอร์ 3 มิติ WebGL

ทดสอบเครื่องเล่น <video> และ <audio> พร้อมการลากไทม์ไลน์ด้วย HTTP 206 Partial Content จริง หรือเรนเดอร์ Three.js, โมเดล 3D .glb/.gltf, HTML5 Canvas และเชดเดอร์ WebGL GLSL ด้วยเฟรมเรตลื่นไหล

HTTP 206 Range Seeking · WebGL GLSL · .glb / .gltf
02.5

3 เทมเพลตเว็บในตัว & เติมโค้ดอัตโนมัติจาก AST

เริ่มต้นทันใจจากเทมเพลตเว็บหลายส่วน 3 แบบ พิมพ์แท็กและพร็อพเพอร์ตี้ CSS ได้ไวด้วย AST ออฟไลน์และแถบสัญลักษณ์ 21 ปุ่ม พร้อมพรีวิวไฟล์ CSS ที่เชื่อมข้ามโฟลเดอร์ได้ไร้รอยต่อ

3 เทมเพลตเว็บ · AST HTML/CSS/JS · แถบ 21 ปุ่ม
02.6

ส่งออกภาพจำลอง PNG ความละเอียดสูงทั้งหน้าเว็บ

ต้องการส่งงานดีไซน์ให้ลูกค้า อาจารย์ หรือ GitHub PR ใช่ไหม? แคปภาพ PNG ทั้งหน้าเว็บคมชัด (สูงสุด 2560px) ได้ตรงจากมุมมองมือถือ แท็บเล็ต หรือเดสก์ท็อปที่เปิดอยู่

PNG สูงสุด 2560px · พร้อมส่งลูกค้าและการบ้าน
ออกแบบเพื่อมือถือ จอพับ และแท็บเล็ต · ขนาดเบา 40.2 MB Web, PHP 8.2 & WASM Hub
03 ขั้นตอนการทำงาน

วิธีสร้างและทดสอบเว็บ Responsive บนมือถือของคุณ

เปลี่ยนจากไฟล์สไตล์ชีตว่างเปล่าสู่เลย์เอาต์ Responsive 3 ขนาดที่ผ่านการทดสอบในไม่กี่นาที

STEP 01 Web Template / index.html

เลือกเทมเพลตเว็บในตัวหรือเปิดโฟลเดอร์ของคุณ

เปิดใช้งาน 1 ใน 3 เทมเพลตเริ่มต้น HTML5/CSS3/JS หรือเปิดโปรเจกต์ Frontend หลายโฟลเดอร์จากพื้นที่เครื่องหรือ Git

STEP 02 AST + 1-Tap Format

เขียน HTML5, CSS Grid & ES Modules ให้สะอาดตา

แก้ไขแท็บ .html, .css และ .js ที่เชื่อมโยงกันพร้อมคำแนะนำ AST ออฟไลน์ แล้วแตะ Format เพื่อจัดระเบียบ HTML, <style> และ <script> พร้อมกัน

STEP 03 Run ▶ -> Viewport Pill

สลับจอมือถือ แท็บเล็ต (768dp) & เดสก์ท็อปแบบสดๆ

แตะ Run ▶ แล้วสลับมุมมองบน Dynamic Island ที่ลากย้ายได้ เพื่อตรวจเช็กเมนูนำทาง ตัวอักษร และจุดตัดกริดทั้งหมด

STEP 04 PNG Capture / Git

ส่งออกสกรีนช็อตความละเอียดสูงหรือ Push ขึ้น GitHub

บันทึกภาพ PNG คมชัดของแต่ละขนาดจอไว้ใส่พอร์ตโฟลิโอ หรือ Push เว็บที่เสร็จสมบูรณ์ขึ้น GitHub Pages ได้โดยตรง

ทำงานออฟไลน์ 100% · รองรับ ES Modules, เว็บฟอนต์, Canvas, WebGL & Media Range Requests คู่มือแอป

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการเขียน HTML5/CSS3/JS, ES Modules และพรีวิว Responsive บน Android

ทำไม `<script type="module">` หรือ `fetch('./data.json')` ถึงล้มเหลวในแอปแก้ HTML อื่น?+
เบราว์เซอร์บล็อก ES Modules และ `fetch()` บน URL แบบ `file://` ตามกฎความปลอดภัย CORS ที่เข้มงวด SuperCode จึงเสิร์ฟโปรเจกต์ผ่าน `localhost` HTTP/1.1 จริงพร้อมหัว MIME ที่ถูกต้อง ทำให้โมดูล JS สมัยใหม่และการดึง JSON ทำงานออฟไลน์ได้ตามปกติ
จะพรีวิว CSS media queries ของแท็บเล็ตและเดสก์ท็อปบนจอมือถือได้อย่างไร?+
ในหน้า Web Preview ของ SuperCode เพียงแตะไอคอนขนาดจอที่ Dynamic Island เพื่อสลับระหว่างมุมมองมือถือ แท็บเล็ต (`768dp`) และเดสก์ท็อปกว้างได้ทันที — ซึ่งจะกระตุ้นกฎ `@media` ของคุณอย่างแม่นยำ
ตัวจัดรูปแบบคลิกเดียวช่วยจัด CSS ใน `<style>` และ JS ใน `<script>` ด้วยไหม?+
ใช่ ตัวจัดรูปแบบ HTML แบบเรียกซ้ำของ SuperCode จะวิเคราะห์บล็อก `<style>` และ `<script>` ที่ฝังอยู่ในไฟล์ `.html` และจัดเยื้องทั้งสามภาษาให้เป็นระเบียบในคลิกเดียว
สามารถใช้วิดีโอ `.mp4`, ฟอนต์ `.woff2` และโมเดล 3D `.glb` แบบออฟไลน์ได้หรือไม่?+
ได้ มี MIME กว่า 65 ประเภทตั้งค่าไว้ในเครื่องแล้ว รวมถึง `font/woff2`, `model/gltf-binary`, `image/svg+xml` และการสตรีม byte-range ด้วย HTTP `206 Partial Content` เพื่อให้ลากกรอไทม์ไลน์ `<video>` และ `<audio>` ได้อย่างลื่นไหล
