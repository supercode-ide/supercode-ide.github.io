02 ความสามารถหลัก

สร้างมาเพื่อ SRE, Sysadmin & นักดูแล Homelab แบบ Self-Hosted

ทุกรายละเอียดถูกออกแบบให้ทนทานต่อเน็ตมือถือที่ไม่เสถียร ไฟล์ล็อกขนาดมหึมา และความผิดพลาดของสิทธิ์ไฟล์บนโฮสต์ Linux ระยะไกล

02.1

บันทึก SFTP แบบอะตอมิก 3 ขั้นตอน คงสิทธิ์ POSIX 0755

การบันทึก /usr/local/bin/backup.sh ที่ใช้งานจริงผ่านเน็ตมือถือที่ไม่นิ่งจะไม่ทำให้สคริปต์ขาดวิ่นหรือเสียบิต +x โดย SuperCode จะเขียนลงไฟล์พัก ตรวจสอบความสมบูรณ์ เปลี่ยนชื่อแบบอะตอมิก และคงโหมด 0755/0644 ไว้แม่นยำ

ไร้ไฟล์คอนฟิกเขียนค้าง · คงสิทธิ์ POSIX 0755
02.2

ตู้นิรภัยคีย์ SSH & โฮสต์เข้ารหัส AES-256 ระดับฮาร์ดแวร์

เชื่อมต่อเซิร์ฟเวอร์ Ubuntu, Debian, Rocky หรือ Alpine ผ่าน SFTP, FTPS และ FTP ด้วยไพรเวตคีย์ SSH แบบ Ed25519/RSA ที่เข้ารหัสด้วย Android Keystore AES-256 พร้อมรับส่งไฟล์ขนานและทำต่อจากจุดเดิม

คีย์ Ed25519 / RSA · Keystore AES-256 · โหลดต่อได้
02.3

ทดลองรันตรรกะ .sh & awk/sed ก่อน Deploy จริง

อย่าลอง Regex ที่ยังไม่ทดสอบบนโปรดักชัน! ตรวจสอบตรรกะ .sh, awk, sed, grep และ set -euo pipefail ในเครื่องบน Android (หรือ Ubuntu GNU Bash 5.2) ก่อนบันทึกกลับขึ้นเซิร์ฟเวอร์

ทดลองรันในแซนด์บ็อกซ์เครื่อง · ยืนยันบน Bash 5.2
02.4

ตัวอ่านล็อกเซิร์ฟเวอร์หลาย GB & เซ็นเซอร์ข้อมูลด้วย Stream Regex

ดาวน์โหลดไฟล์ล็อก Nginx, Docker หรือ systemd journal ขนาด 2 GB แล้วเลื่อนอ่านแบบแบ่งหน้าบนดิสก์ที่ 120Hz โดยแรมไม่พุ่ง — หรือใช้ Global Stream Regex Replace เพื่อเซ็นเซอร์ข้อมูลลับทั้งไฟล์

แบ่งหน้าไฟล์ระดับ GB+ ทันที · Stream Regex $1 · 34 ชุดอักขระ

แก้ไข docker-compose.yml, ไฟล์ Kubernetes, Ansible playbooks, Dockerfile, Makefile, TOML และ .env พร้อมไฮไลต์ไวยากรณ์ Error Radar และจัดรูปแบบออฟไลน์ในแตะเดียว

03 ขั้นตอนการทำงาน

เวิร์กโฟลว์แก้เหตุฉุกเฉิน & อัปเดตคอนฟิกบน Android

วิเคราะห์ปัญหา ทดลองรัน Deploy แบบอะตอมิก และ Commit ลง Git โดยไม่ต้องเปิดแยก 4 แอป

STEP 01 SFTP -> Download Log

เชื่อมต่อด้วยคีย์ SSH & ตรวจสอบล็อกโปรดักชัน

เปิดเซิร์ฟเวอร์ Linux ใน SFTP Explorer แล้วตรวจไฟล์ `.log` ขนาดมหึมาในตัวอ่านระดับ GB แบบแบ่งหน้าบนดิสก์ หรือกรองข้อมูลด้วย `grep`/`awk`

STEP 02 Editor -> Format YAML/.sh

แก้ไข Shell Hooks, Docker Compose หรือคอนฟิก Nginx

แก้ไขไฟล์ `.sh`, `.yml` หรือ `.conf` พร้อมการจัดรูปแบบออฟไลน์ และทดสอบตรรกะ Shell ไปป์ไลน์ในเครื่องก่อนอัปโหลด

STEP 03 Save -> 3-Phase Atomic

เผยแพร่อย่างปลอดภัยผ่าน SFTP โดยคงสิทธิ์ 0755 ครบ

บันทึกกลับไปยังโฮสต์ระยะไกลโดยตรง — การเขียนพักแบบอะตอมิกป้องกันการเขียนไม่สมบูรณ์และรักษาสิทธิ์รันไฟล์ `0755` ไว้ครบถ้วน

STEP 04 Visual Git -> Push

Commit การเปลี่ยนแปลงโครงสร้างพื้นฐานลงรีโป Git

ตรวจทาน Unified Diff อย่างละเอียดใน Visual Git แล้ว Push คอมมิต Hotfix เพื่อให้โปรดักชันและเวอร์ชันคอนโทรลตรงกันเสมอ

APK ครบจบในตัวขนาด 40.2 MB · SFTP + FTPS + Visual Git + Shell + ตัวอ่านล็อก GB คู่มือแอป

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามจาก Linux Sysadmin, SRE และวิศวกร Homelab ที่ใช้ SuperCode บน Android

การแก้ไขสคริปต์ `.sh` ระยะไกลผ่าน SFTP จะทำให้สิทธิ์รันไฟล์ `chmod 0755` หายไหม?+
ไม่มีทาง SuperCode จะตรวจสอบโหมด POSIX เดิมของไฟล์ระยะไกลก่อนบันทึก และคงสิทธิ์ `0755` (หรือสิทธิ์ที่กำหนดเอง) ไว้ครบตลอดกระบวนการเปลี่ยนชื่อไฟล์พักแบบอะตอมิก 3 ขั้นตอน
SuperCode ปกป้องไพรเวตคีย์ SSH และรหัสผ่าน SFTP ของฉันอย่างไร?+
ข้อมูลรับรอง SFTP/FTPS โปรไฟล์โฮสต์ และไพรเวตคีย์ SSH ที่นำเข้า (`Ed25519`, `RSA`, `ECDSA`) ทั้งหมดจะถูกเข้ารหัสบนอุปกรณ์ด้วยการป้องกันระดับฮาร์ดแวร์ของ Android Keystore AES-256
จะเกิดอะไรขึ้นหากสัญญาณมือถือหลุดกลางคันระหว่างบันทึกไฟล์ `nginx.conf`?+
เนื่องจาก SuperCode อัปโหลดไปยังไฟล์พักชั่วคราวก่อน และจะเปลี่ยนชื่อแบบอะตอมิกฝั่งเซิร์ฟเวอร์ก็ต่อเมื่อตรวจสอบการถ่ายโอนสำเร็จแล้ว ไฟล์ `nginx.conf` ที่ใช้งานจริงของคุณจึงไม่มีวันถูกเขียนค้างหรือว่างเปล่า
สามารถตรวจสอบไฟล์ล็อกเซิร์ฟเวอร์ขนาด 1.5 GB ที่ดาวน์โหลดจาก SFTP โดยไม่ทำให้มือถือค้างหรือแอปแครชได้ไหม?+
ได้! Large File Editor ของ SuperCode จะโหลดไฟล์ขนาดหลายกิกะไบต์แบบแบ่งหน้าบนดิสก์แทนการโหลดทั้งไฟล์เข้า RAM พร้อม Global Stream Regex Replace ในตัว
