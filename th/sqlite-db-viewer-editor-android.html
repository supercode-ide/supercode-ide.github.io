02 ความสามารถหลัก

มากกว่าตารางดูข้อมูลแบบอ่านอย่างเดียว — เวิร์กสเตชัน SQLite ออฟไลน์เต็มรูปแบบ

ตรวจ Metadata ภายใน แก้ไขแบบกำหนดพารามิเตอร์ แปลงไฟล์แบนเป็นตาราง SQL และส่งออกรายงานสวยๆ ได้ในไม่กี่วินาที

02.1

ตัวตรวจไฟล์ .db, .sqlite, .sqlite3, .db3 & .s3db ในแตะเดียว

แตะไฟล์ฐานข้อมูล SQLite ใน Explorer ของ SuperCode หรือเปิดจากที่เก็บข้อมูล Android ระบบจะตรวจหัวไฟล์ไบนารีและแสดงสถิติหน้า .dbinfo จำนวน .tables และ .schema DDL ครบถ้วนอัตโนมัติ

.db · .sqlite · .sqlite3 · .db3 · .s3db
02.2

สลับได้ 9 รูปแบบ .mode (Box, Markdown, JSON, CSV+)

จัดรูปแบบผลลัพธ์ได้ตามต้องการ: ตาราง Unicode box คมชัดและ ASCII table สำหรับอ่านบนมือถือ ตาราง markdown สำหรับเอกสาร GitHub อาเรย์ json สำหรับ API csv/tabs สำหรับสเปรดชีต insert SQL dumps หรือ line card แนวตั้ง

box · table · markdown · json · csv · tabs · insert · line · list
02.3

.import --csv, --tsv & --json แบบไม่ต้องเขียนโครงสร้างเอง

ข้ามการพิมพ์ CREATE TABLE ที่น่าเบื่อ เพียงรัน .import --csv sales.csv sales หรือ .import --json users.json users (สูงสุด 8 MB) SuperCode จะอนุมานชื่อคอลัมน์ให้อัตโนมัติ พร้อม JOIN และสรุปผลได้ทันที

สร้างตารางอัตโนมัติ · CSV / TSV / JSON สูงสุด 8 MB
02.4

เมาท์ฐานข้อมูลใน Workspace อัตโนมัติสำหรับสคริปต์ .sql

เก็บ queries.sql ไว้ข้างไฟล์ app.db ของโปรเจกต์ SuperCode จะตรวจจับและเมาท์ฐานข้อมูลใน Workspace อัตโนมัติ (หรือทำตามคำสั่ง .open ที่ระบุ) เพื่อให้การ Migrate Schema และการแก้ไขถูกบันทึกลงดิสก์โดยตรง

บันทึกการแก้ไขลงดิสก์ถาวร · รองรับ .open หลาย DB
02.5

ส่งออกไฟล์ด้วย .once ลงโฟลเดอร์โปรเจกต์โดยตรง

ใช้โหมดแสดงผลใดก็ได้ร่วมกับ .once <filename> — เช่น .mode markdown + .once report.md หรือ .mode csv + .once clean_leads.csv — เพื่อเขียนผลลัพธ์ Query ลงไฟล์ใน Workspace พร้อมแชร์ทันที

ส่งออกด้วย .once · สร้างรายงานและ Dump ทันที
02.6

ความเป็นส่วนตัวบนเครื่อง 100% ด้วย SQLite 3.54.1

ข้อมูลลูกค้า ฐานข้อมูลแอปมือถือออฟไลน์ และไฟล์ CSV ทางการเงินจะไม่ถูกส่งไปยังเว็บเซิร์ฟเวอร์ภายนอก ทุกการตรวจสอบ การสร้าง Index, VACUUM และ Query ทำงานภายในเครื่องบน SQLite 3.54.1 แบบฝังตัว

ไม่อัปโหลดขึ้นคลาวด์ · เอนจิน SQLite 3.54.1 ออฟไลน์
ออกแบบเพื่อมือถือ จอพับ และแท็บเล็ต · ขนาดเบา 40.2 MB SQL & SQLite Studio Hub
03 ขั้นตอนการทำงาน

วิธีตรวจสอบไฟล์ `.db` หรือ Query ชุดข้อมูล CSV/JSON บน Android

เปิดฐานข้อมูลไบนารีที่มีอยู่หรือสร้างใหม่จากไฟล์ดิบได้ใน 4 ขั้นตอนง่ายๆ

STEP 01 Explorer -> Tap .db

เปิดไฟล์ .db, .sqlite หรือ .sqlite3 ได้ในแตะเดียว

เลือกไฟล์ฐานข้อมูลใน Workspace เพื่อดูสรุป .dbinfo รายการ .tables และ Schema ของ CREATE TABLE / INDEX ได้ทันที

STEP 02 .import --csv / --json

หรือนำเข้าไฟล์ CSV, TSV & JSON ดิบเข้าสู่ตาราง

รัน .import --csv data.csv my_table ในสคริปต์ .sql เพื่อสร้างและเติมข้อมูลคอลัมน์ความสัมพันธ์อัตโนมัติจากไฟล์ขนาดสูงสุด 8 MB

STEP 03 .mode box / markdown

รัน SQL Query และสลับได้ 9 รูปแบบผลลัพธ์

เขียนคำสั่ง SELECT, JOIN, UPDATE หรือ ALTER พร้อมระบบเติมคำ SQL จาก AST และดูตัวอย่างตาราง Unicode box หรือ Markdown ที่อ่านง่าย

STEP 04 .once export.csv

ส่งออกผลลัพธ์ที่สะอาดกลับเข้าสู่ Workspace

ใช้ .once ร่วมกับโหมด csv, json, markdown หรือ insert เพื่อบันทึกผลลัพธ์การวิเคราะห์ลงในโฟลเดอร์โปรเจกต์โดยตรง

ฝังตัว SQLite 3.54.1 · ไม่ต้องมีบัญชี · ธุรกรรม ACID อ่าน/เขียนเต็มรูปแบบ คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

SuperCode SQLite 3.54.1 Studio เทียบกับแอปดู `.db` ทั่วไปบน Android

ตัวดูและแก้ไขฐานข้อมูล SQLite ออฟไลน์ของ SuperCode เปิดไฟล์ไบนารี .db, .sqlite, .sqlite3, .db3 และ .s3db บน Android ได้ในแตะเดียวด้วย SQLite 3.54.1 ตรวจ Schema และ Metadata แบบออฟไลน์ นำเข้า CSV, TSV และ JSON สูงสุด 8 MB อัตโนมัติ และจัดรูปแบบผลลัพธ์ Query ได้ถึง 9 โหมด

ตารางเปรียบเทียบตัวดู .DB & ตัวแก้ไข QUERY ของ SQLITE บน ANDROID
ความสามารถ SQLite SuperCode SQL Studio แอปดู DB ทั่วไปบน Android แอปสเปรดชีตบนมือถือ ตัวดู SQLite ออนไลน์
เวอร์ชันเอนจิน SQLite 3.54.1 ออฟไลน์ (JSONB/FTS5 ยุคใหม่) SQLite 3.2x ของ Android OS ที่เก่าแล้ว ไม่ใช่เอนจิน SQL เชิงสัมพันธ์ อัปโหลด .db ส่วนตัวขึ้นเว็บ
ตรวจ Schema ในแตะเดียว แสดง .dbinfo + .tables + .schema DDL เต็มอัตโนมัติ เลือกจากเมนูตารางทีละอันเท่านั้น เปิดไฟล์ไบนารี .db/.db3 ไม่ได้ ติดขีดจำกัดหน่วยความจำเบราว์เซอร์
การจัดรูปแบบผลลัพธ์ 9 โหมด (box, markdown, json, csv, insert+) ตารางเซลล์แคบแบบตายตัว เซลล์สเปรดชีตเท่านั้น ตาราง HTML พื้นฐาน
นำเข้า CSV / TSV / JSON สร้างตาราง SQL อัตโนมัติสูงสุด 8 MB มีน้อยหรือเป็นส่วนเสริมเสียเงิน เปิดได้ทีละชีตแบนๆ เท่านั้น ต้องอัปโหลดผ่านอินเทอร์เน็ต
การเชื่อมโยงกับโค้ด Query ไฟล์ .db เดียวกันจาก Python, PHP, Java & Lua แอปดูไฟล์แบบแยกเดี่ยว ไม่มี ไม่มี

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำตอบเกี่ยวกับการเปิดไฟล์ `.db`/`.sqlite3` การนำเข้าชุดข้อมูล CSV/JSON และการส่งออกผลลัพธ์แบบออฟไลน์

SuperCode สามารถเปิดไฟล์ฐานข้อมูล SQLite นามสกุลใดได้โดยตรงบ้าง?+
SuperCode รองรับไฟล์ `.db`, `.sqlite`, `.sqlite3`, `.db3` และ `.s3db` ในแตะเดียว พร้อมตรวจสอบ `.dbinfo`, `.tables` และ `.schema` แบบออฟไลน์โดยอัตโนมัติ
ทำไม SQLite 3.54.1 แบบฝังตัวถึงสำคัญกว่าแอปดู SQLite ทั่วไปบน Android?+
แอปดู DB บน Android ส่วนใหญ่พึ่งพา SQLite เวอร์ชันเก่าของระบบในเครื่อง ซึ่งขาดตาราง `STRICT`, `RETURNING`, `JSONB`, Window frame สมัยใหม่ และ Query Planner ที่อัปเดตแล้ว SuperCode มาพร้อม SQLite 3.54.1 ที่ทำงานเหมือนกันทุกเครื่องบน Android 8.0+
ฉันสามารถนำเข้าไฟล์ `.csv` หรือ `.json` โดยไม่ต้องเขียน `CREATE TABLE` ก่อนได้ไหม?+
ได้! รัน `.import --csv filename.csv tablename` (หรือ `--tsv` / `--json`) ขนาดสูงสุด 8 MB — หากยังไม่มี `tablename` SuperCode จะสร้าง Schema ตารางจากหัวคอลัมน์ CSV หรือคีย์ของออบเจ็กต์ JSON ให้อัตโนมัติ
จะส่งออกผลลัพธ์ SQL Query เป็นตาราง Markdown หรือไฟล์ CSV ได้อย่างไร?+
เพิ่ม `.mode markdown` (หรือ `.mode csv` / `.mode json` / `.mode insert`) ตามด้วย `.once output.md` เหนือคำสั่ง `SELECT` ของคุณแล้วแตะ Run — ไฟล์จะปรากฏในตัวสำรวจโปรเจกต์ทันที
