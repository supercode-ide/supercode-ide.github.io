02 ความสามารถหลัก

สแต็ก Persistence, File I/O & Networking ครบวงจรสำหรับ Java 17

ฝึกทำแล็บฐานข้อมูลมหาวิทยาลัย, แพทเทิร์น DAO repository, ตัวแปลงไฟล์ CSV/JSON และไคลเอนต์ REST ภายในเวิร์กสเปซ Android เดียวที่กลมกลืน

02.1

ไดรเวอร์ SQLite JDBC ออฟไลน์ในตัว ไม่ต้องตั้งค่า

เขียน DriverManager.getConnection(\"jdbc:sqlite:campus.db\") หรือ \"jdbc:sqlite::memory:\" แล้วกด Run ได้เลย SuperCode ลงทะเบียน org.sqlite.JDBC ออฟไลน์ไว้ล่วงหน้า — ไม่ต้องหาไฟล์ .jar ไดรเวอร์, Class.forName() หรือเขียน pom.xml ให้ยุ่งยาก

jdbc:sqlite:app.db · :memory: · ไม่ต้องตั้งค่าไดรเวอร์
02.2

PreparedStatement, ACID Transactions & แล็บ Batch DAO

ฝึกป้องกัน SQL injection ด้วยการผูกพารามิเตอร์ใน PreparedStatement รันธุรกรรมข้ามหลายตารางแบบ atomic ด้วย setAutoCommit(false) และ rollback() เปิดใช้ PRAGMA foreign_keys และตรวจสอบคอลัมน์ผ่าน ResultSetMetaData

PreparedStatement · ACID Rollback · executeBatch()
02.3

เชื่อมต่อไปยัง Visual SQL Studio ของ SuperCode ใน 1 แตะ

ทุกไฟล์ .db หรือ .sqlite3 ที่โค้ด Java JDBC ของคุณสร้างขึ้นจะปรากฏในโครงสร้างโปรเจกต์ทันที แตะเพื่อดูสคีมา ดัชนี และตารางใน SQL Studio ของ SuperCode ทั้งในโหมด Box, Markdown, CSV และ JSON

เวิร์กสเปซ .db ร่วมกัน · มุมมองสคีมา & ตารางแบบภาพ
02.4

Java NIO.2 & Classic Stream File I/O เต็มรูปแบบ

อ่านชุดข้อมูล CSV อัปเดตคอนฟิก .properties และเขียนรายงานด้วย java.nio.file.Files (readString, writeString, readAllLines, createDirectories), FileChannel, BufferedReader และ ObjectOutputStream — ซิงก์ลงโฟลเดอร์ของคุณแบบเรียลไทม์

java.nio.file.Files · Path.of() · ซิงก์ลงดิสก์ถาวร
02.5

java.net.http.HttpClient มาตรฐาน & HttpServer บนเครื่อง

เรียกใช้ REST JSON API ด้วย HttpClient สมัยใหม่ของ Java (ทั้งแบบซิงโครนัส send() หรืออะซิงโครนัส sendAsync() ร่วมกับ CompletableFuture พร้อมกำหนด timeout และ headers) หรือเปิด route ด้วย com.sun.net.httpserver.HttpServer ขนาดเบา

java.net.http.HttpClient · sendAsync · HttpServer
02.6

วินิจฉัย SQLException & IOException แม่นยำตรงจุด

เมื่อพิมพ์ชื่อคอลัมน์ SQL ผิดหรือพาธไฟล์ CSV หายไป SuperCode จะกรองเฟรม reflection ภายในออก เพื่อให้ stack trace ชี้ไปยังหมายเลขบรรทัดใน DAO หรือตัวแปลงไฟล์ของคุณอย่างชัดเจน

กรอง Stack Trace · ระบุตำแหน่งบรรทัดแม่นยำ

03 ขั้นตอนการทำงาน

วิธีสร้างโปรเจกต์ Java + SQLite JDBC บน Android

เริ่มต้นจากโฟลเดอร์ว่างสู่ฐานข้อมูล JDBC ถาวรพร้อมลูปตรวจสอบ SQL แบบเห็นภาพในไม่กี่วินาที

STEP 01 import java.sql.*;

เชื่อมต่อผ่าน DriverManager.getConnection(\"jdbc:sqlite:...\")

เปิดไฟล์ .java ใดก็ได้แล้วเชื่อมต่อไปยังชื่อไฟล์ฐานข้อมูลแบบสัมพัทธ์ (เช่น jdbc:sqlite:store.db) — ไดรเวอร์จะโหลดให้อัตโนมัติแบบออฟไลน์

STEP 02 PreparedStatement

รันคำสั่ง DDL, Parameterized Inserts & Joins

รัน CREATE TABLE, batch INSERT และ SELECT join แบบออฟไลน์ หรืออ่านไฟล์ข้อมูลตั้งต้น .csv ข้างเคียงด้วย Files.readAllLines()

STEP 03 Explorer -> store.db

ตรวจสอบไฟล์ .db ที่สร้างขึ้นใน SQL Studio

แตะไฟล์ store.db ที่ซิงก์แล้วใน Explorer เพื่อเปิดดูตาราง รันคำสั่ง SQL เฉพาะกิจ หรือส่งออกผลลัพธ์เป็น Markdown/CSV

STEP 04 Visual Git / Export

ส่งออกรายงานหรือ Commit โปรเจกต์ DAO ของคุณ

ตรวจสอบไฟล์ CSV/JSON ที่ส่งออกในเอดิเตอร์ พิมพ์ซอร์สโค้ดเป็น PDF ขนาด A4 หรือ commit รีโป DAO หลายคลาสด้วย Visual Git

รวม org.sqlite.JDBC ออฟไลน์ในตัว · ซิงก์ไฟล์เวิร์กสเปซจริง · IDE SQL คู่ใจ คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

เปรียบเทียบการรองรับฐานข้อมูล Java & File I/O ข้ามแพลตฟอร์มมือถือ

SuperCode Java SQLite & File I/O Studio มาพร้อมไดรเวอร์ org.sqlite.JDBC ออฟไลน์ในตัวบน Android โดยไม่ต้องตั้งค่า Maven หรือ Gradle นักพัฒนาสามารถรันคิวรี SQLite แบบ parameterized, แชร์ไฟล์ .db กับ Visual SQL Studio ของ SuperCode โดยตรง, อ่านและเขียนไฟล์ในเวิร์กสเปซผ่าน Java NIO.2 Files และทดสอบ REST API ด้วย HttpClient

ความสามารถ JAVA JDBC, FILE I/O & HTTP บน ANDROID
ความสามารถ Backend SuperCode Java 17 IDE แอป Java มือถือทั่วไป คอมไพเลอร์ Java บนเว็บ การตั้งค่า Maven บนเดสก์ท็อป
ไดรเวอร์ SQLite JDBC jdbc:sqlite ออฟไลน์ในตัว (ตั้งค่า 0 ขั้นตอน) ไม่มีให้ (ClassNotFoundException) ไม่มีฐานข้อมูลถาวรในเครื่อง ต้องใช้ pom.xml + ดาวน์โหลดเพิ่ม
ดูข้อมูล DB แบบเห็นภาพ เปิดใน SQL Studio ในตัวได้ใน 1 แตะ ต้องใช้แอปดู DB ภายนอก ไม่มี ต้องใช้ปลั๊กอิน DB GUI แยกต่างหาก
Java NIO.2 File I/O ซิงก์โฟลเดอร์ Files.readString/writeString เต็มรูปแบบ จำกัดเฉพาะแซนด์บ็อกซ์ชั่วคราว คอนเทนเนอร์ชั่วคราวรีเซ็ตเมื่อปิด เต็มรูปแบบ
ไคลเอนต์ HTTP REST java.net.http.HttpClient & Server ในตัว ใช้ได้แค่ HttpURLConnection รุ่นเก่า บล็อกการเชื่อมต่อออกภายนอก เต็มรูปแบบ
ความเสถียรแบบออฟไลน์ รัน JDBC + NIO.2 ออฟไลน์ 100% ขึ้นอยู่กับปลั๊กอินแต่ละตัว ต้องใช้อินเทอร์เน็ต ออฟไลน์ได้หลังแคช Maven แล้ว

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามเกี่ยวกับสตริงเชื่อมต่อ JDBC, ไฟล์ `.db` แบบถาวร, พาธ NIO.2 และ `HttpClient` บน Android

ฉันต้องเรียก `Class.forName(\"org.sqlite.JDBC\")` หรือเพิ่ม dependency ใน Maven เพื่อใช้ SQLite ใน Java ไหม?+
ไม่ต้อง! SuperCode รวมและลงทะเบียน `org.sqlite.JDBC` ให้อัตโนมัติตั้งแต่แรก เพียง import `java.sql.*` แล้วเรียก `DriverManager.getConnection(\"jdbc:sqlite:mydb.db\")` — ใช้งานออฟไลน์ได้ทันที 100%
ไฟล์ `.db`, `.csv` และ `.txt` จะถูกบันทึกไว้ที่ไหนเมื่อโปรแกรม Java ของฉันเขียนไฟล์?+
พาธสัมพัทธ์เช่น `jdbc:sqlite:inventory.db` หรือ `Path.of(\"report.csv\")` จะอ้างอิงกับโฟลเดอร์โปรเจกต์ที่เปิดอยู่โดยตรง และซิงก์กลับเข้าสู่เวิร์กสเปซ Android ของคุณทันทีเมื่อโปรแกรมทำงานเสร็จ
ฉันสามารถสร้างข้อมูลตั้งต้นในฐานข้อมูล SQLite ด้วย SQL Studio ของ SuperCode แล้วค่อยคิวรีจาก Java ได้ไหม?+
ได้เลย! นั่นเป็นหนึ่งในเวิร์กโฟลว์ยอดนิยมของ SuperCode: ออกแบบตารางและเพิ่มข้อมูลเริ่มต้นใน SQL Studio (`schema.sql` -> `app.db`) จากนั้นเปิดคลาส `.java` DAO ในโฟลเดอร์เดียวกันแล้วคิวรี `jdbc:sqlite:app.db` ได้อย่างไร้รอยต่อ
`java.net.http.HttpClient` ใช้ทดสอบ REST API ได้ไหม?+
ได้ `HttpClient`, `HttpRequest` และ `HttpResponse` มาตรฐานของ Java 11/17 ใช้งานส่งคำขอ HTTPS REST ได้ทันทีเมื่ออุปกรณ์ออนไลน์ ส่วนการทำงานของ JDBC และไฟล์ NIO.2 นั้นใช้งานแบบออฟไลน์ได้สมบูรณ์
