02 ความสามารถหลัก

รูปแบบการเขียน Modern C++ ระดับโปรดักชัน—ไม่ใช่แค่ฟีเจอร์ย่อยยุค 2013

ฝึกใช้ RAII ownership ที่สะอาด, zero-copy views, constrained templates และตัวซิงโครไนซ์ C++20 บนฮาร์ดแวร์ Android ยุคใหม่

02.1

ไปป์ไลน์ <ranges> แบบ Lazy และข้อจำกัด <concepts>

ประกอบไปป์ไลน์ข้อมูลที่อ่านง่ายด้วย std::views::filter, transform, take, drop และ reverse พร้อมแทนที่ข้อผิดพลาด SFINAE ที่อ่านยากด้วย C++20 requires และ <concepts>

std::ranges · std::views · <concepts> · requires Clauses
02.2

Zero-Copy Views และชนิดข้อมูลเชิงพีชคณิต

เขียน API แบบไม่จองหน่วยความจำเพิ่มด้วย std::span และ std::string_view จัดการค่าที่อาจว่างหรือ sum types อย่างปลอดภัยด้วย std::optional, std::variant, std::any และจัดรูปแบบข้อความด้วย <format> และ <charconv>

<span> · <string_view> · <optional> · <variant> · <format>
02.3

RAII Smart Pointers และลำดับชั้น OOP ยุคใหม่

ขจัดปัญหา memory leak จาก new/delete ด้วย std::make_unique, std::make_shared, std::weak_ptr พร้อมตัวตรวจ virtual override/final, move constructors, ตัวเปรียบเทียบ <=> และ raw string literals R"(...)"

unique_ptr · shared_ptr · <=> Spaceship · R"(...)"
02.4

C++20 Concurrency ไร้รอยต่อ (<thread>, <latch>, <barrier>)

กำลังสร้างต้นแบบคิว producer-consumer แบบมัลติเธรดใช่ไหม? เพียง include <thread>, <future>, <semaphore>, <latch> หรือ <barrier> ระบบจะส่งโปรเจกต์ไปยัง Cloud C++20 (-pthread) อัตโนมัติพร้อมชี้บรรทัดผิดพลาดตรง 1:1

<thread> · <future> · <semaphore> · <latch> · <barrier>
02.5

เติมคำอัตโนมัติด้วย AST บนโอเปอเรเตอร์ ::, -> และ .

สำรวจลำดับชั้นคลาสที่ซับซ้อน, namespace std:: และการอ้างอิง smart-pointer (ptr->) แบบออฟไลน์—เอนจิน AST ของเราจะแยกแยะเมธอด ฟิลด์ และ STL container APIs ให้ทันทีขณะพิมพ์

std:: · ptr-> · obj. · AST อัจฉริยะออฟไลน์
02.6

จัดรูปแบบ C++20 ในแตะเดียวและเรดาร์ตรวจ Syntax

จัดโค้ด template header ที่ซับซ้อน, lambda captures และ namespace ซ้อนกันให้คมชัดบนจอมือถือ ด้วยการจัดรูปแบบออฟไลน์ทันทีและ Undo แบบขั้นตอนเดียว

03 ขั้นตอนการทำงาน

วิธีสร้างต้นแบบสถาปัตยกรรม C++20 ยุคใหม่บน Android

เขียน C++20 แบบออฟไลน์และประมวลผลงานมัลติเธรดบนคลาวด์ได้ทันทีเมื่อต้องการ

STEP 01 #include <ranges>

เขียน Constrained Templates และคลาส RAII

ใช้เฮดเดอร์ C++20 (<ranges>, <concepts>, <memory>, <span>, <optional>, <variant>) ได้เลยโดยไม่ต้องตั้งค่าแฟล็กคอมไพเลอร์

STEP 02 AST :: / -> + Format

เติมสมาชิก Smart-Pointer และจัดรูปแบบโค้ด

ตรวจดูสมาชิกคลาสและ STL ผ่านการเติมคำ -> และ :: แล้วแตะ "จัดรูปแบบ" เพื่อจัดเรียง views และ lambdas หลายบรรทัดให้เรียบร้อย

STEP 03 Run ▶ (Offline C++20)

คอมไพล์และทดสอบ OOP ไฟล์เดียวหรือหลายไฟล์แบบออฟไลน์

รันโมดูล C++20 แท้ในเครื่องได้ในระดับมิลลิวินาที พร้อมแคชอ็อบเจกต์แบบ Incremental แยกตาม Translation Unit

STEP 04 <thread> -> Auto -pthread

ทดสอบ Multi-Thread Primitives โดยไม่ต้องแก้สคริปต์ Build

เพียง include <thread>, <future> หรือ <latch> เมื่อต้องการรันแบบขนาน—SuperCode จะลิงก์ -pthread ให้อัตโนมัติ

สร้างมาเพื่อ Android 8.0–15+ · แทนที่แอป C++11 32-bit ที่ถูกทิ้งร้าง · มี Visual Git ในตัว คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

SuperCode Modern C++20 เทียบกับคอมไพเลอร์ C++ รุ่นเก่าบน Android

Modern C++20 IDE ของ SuperCode ยกระดับการพัฒนา C++ บน Android ให้เหนือกว่าคอมไพเลอร์มือถือยุค C++11 รุ่นเก่า วิศวกรสามารถเขียนโค้ด C++20 ออฟไลน์ด้วย std::ranges, concepts, std::format, std::span, std::optional, std::variant และ RAII smart pointers พร้อมการคอมไพล์ -pthread บนคลาวด์อัตโนมัติสำหรับ std::thread, futures, latches และ barriers

การรองรับภาษา MODERN C++20 บน ANDROID
ฟีเจอร์ Modern C++ SuperCode C++20 Studio แอปเก่า (เช่น CppDroid) เว็บคอมไพเลอร์ออนไลน์ CLI บนมือถือแบบตั้งค่าเอง
<ranges> และ <concepts> รองรับแบบออฟไลน์ (-std=gnu++2a) ไม่รองรับ (หยุดอยู่ที่ C++11) ต้องต่ออินเทอร์เน็ต ต้องติดตั้งแพ็กเกจเอง
optional / variant / span Vocabulary Types ของ C++17 & C++20 ครบชุด ไม่มีหรือยังเป็นรุ่นทดลอง รองรับแบบออนไลน์ รองรับ
ความเข้ากันได้กับ Android OS พร้อมใช้งาน 64-Bit Native บน Android 8.0–15+ ใช้งานไม่ได้หรือถูกถอดบน Android รุ่นใหม่ แท็บเบราว์เซอร์มือถือ ต้องตั้งค่าด้วยตนเอง
<thread>, <latch>, <barrier> สลับ `-pthread` อัตโนมัติ + ชี้บรรทัด 1:1 ลิงก์ไม่ผ่านหรือแอปเด้ง มักถูกจำกัด CPU ต้องใส่แฟล็ก `-pthread` เอง
เติมคำ AST `->` & `::` AST ออฟไลน์ในตัว + แถบ 21 ปุ่ม รายการคีย์เวิร์ดพื้นฐานรุ่นเก่า UI ออกแบบมาสำหรับเดสก์ท็อป ไม่มี UI แบบสัมผัส

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามเกี่ยวกับการรองรับไลบรารี C++17/C++20, การย้ายจาก CppDroid, raw string literals และ `<thread>`

ทำไมควรย้ายจากแอปเก่าอย่าง CppDroid มาใช้ SuperCode?+
แอปเก่าที่สร้างเมื่อสิบปีก่อนไม่มีเฮดเดอร์ C++17 และ C++20 (`<optional>`, `<variant>`, `<string_view>`, `<span>`, `<ranges>`, `<concepts>`) และมักติดตั้งไม่ได้บนอุปกรณ์ Android 14/15 แบบ 64-bit รุ่นใหม่ แต่ SuperCode มาพร้อมสภาพแวดล้อม C++20 64-bit ที่อัปเดตดูแลอย่างต่อเนื่อง
Raw string literals `R"(...)"` ของ C++ ใช้งานร่วมกับการสแกนเฮดเดอร์หลายไฟล์ได้หรือไม่?+
ได้ ตัวสแกน Dependency ของ SuperCode เข้าใจทั้ง raw string literals ของ C++11/20 (`R"delim(...)delim"`) และตัวคั่นตัวเลข (`1'000'000`) ดังนั้นข้อความ `#include` ที่อยู่ภายใน raw strings จะไม่ไปกระตุ้นการค้นหาเฮดเดอร์ผิดพลาด
`std::unique_ptr`, `std::shared_ptr`, `std::optional` และ `std::variant` ทำงานออฟไลน์ 100% หรือไม่?+
ใช่—เฮดเดอร์ `<memory>`, `<optional>`, `<variant>`, `<any>`, `<span>`, `<string_view>`, `<ranges>`, `<concepts>` และ `<charconv>` ทั้งหมดคอมไพล์แบบออฟไลน์บนอุปกรณ์ของคุณได้อย่างสมบูรณ์
`<thread>`, `std::async`, `<latch>` และ `<barrier>` รันบน Android ได้อย่างไร?+
เมื่อโปรเจกต์ C++ ของคุณ include เฮดเดอร์สำหรับทำงานพร้อมกันอย่าง `<thread>`, `<future>`, `<semaphore>`, `<latch>` หรือ `<barrier>` SuperCode จะแพ็กโปรเจกต์พร้อม `#line` markers ส่งไปคอมไพล์บน Cloud C++20 (`-pthread`) ให้อัตโนมัติ
