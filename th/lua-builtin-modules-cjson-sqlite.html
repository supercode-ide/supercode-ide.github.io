02 ความสามารถหลัก

เขียนสคริปต์ Lua ใช้งานจริงได้เหนือกว่าไลบรารีมาตรฐานขั้นพื้นฐาน

สร้างไคลเอนต์ REST, ตัวแก้ไขไฟล์เซฟเกม SQLite ในเครื่อง, เครื่องมือจัดการไฟล์ทั้งโฟลเดอร์ และสคริปต์ JSON สไตล์ OpenResty/Redis โดยไม่ต้องแตะคอมไพเลอร์ C

02.1

แปลงข้อมูล cjson & dkjson พร้อมใช้ทันที

พาร์สและสร้างเพย์โหลด JSON แบบออฟไลน์ได้ในพริบตาผ่าน require('cjson') หรือ require('dkjson') — พร้อม cjson.encode_pretty() สำหรับไฟล์คอนฟิกที่อ่านง่ายและการดีบัก API

cjson.encode · encode_pretty · cjson.decode
02.2

เอ็นจินฐานข้อมูล lsqlite3 / sqlite3 ฝังในตัว

เปิดฐานข้อมูล :memory: หรือไฟล์ .db ถาวรในเวิร์กสเปซผ่าน require('lsqlite3') หรือ require('sqlite3') รองรับ prepared statements, การผูกพารามิเตอร์แบบ :named, ตัววนซ้ำ db:nrows() และทรานแซกชัน ACID

lsqlite3 · ซิงก์ .db ถาวร · ใช้ร่วมกับ SQL IDE
02.3

LuaFileSystem (lfs) จัดการไดเรกทอรีและไฟล์อัตโนมัติ

ทำงานอัตโนมัติอย่างการเปลี่ยนชื่อไฟล์เป็นชุดและตรวจสอบแอสเซตทั่วโฟลเดอร์โปรเจกต์ด้วย require('lfs') — ทั้ง lfs.dir(), lfs.mkdir(), lfs.currentdir() และเช็กขนาด/เวลาของไฟล์ผ่าน lfs.attributes()

lfs.dir · lfs.mkdir · lfs.attributes
02.4

ชุดความปลอดภัย crypto, sha2, md5 & base64

ลงนามเพย์โหลด webhook, ตรวจสอบ checksum ไฟล์ และสร้างไอดีเฉพาะแบบออฟไลน์ด้วย SHA-256, SHA-512, MD5, HMAC แบบมีคีย์, crypto.uuid() และการเข้ารหัส/ถอดรหัส Base64 ตามมาตรฐาน RFC

SHA-256/512 · HMAC · crypto.uuid() · base64
02.5

socket.http, regex เต็มรูปแบบ & inspect ดูโครงสร้าง Table

ทดสอบ REST API จริงผ่าน require('socket.http'), รัน Regular Expression แบบ PCRE/POSIX เต็มรูปแบบเมื่อ Lua pattern ไม่พอด้วย require('regex') และแสดงผล table ซ้อนชั้นอย่างเป็นระเบียบด้วย require('inspect')

socket.http · regex เต็มรูปแบบ · inspect(table)
02.6

ส่งต่อ Cloud Lua อัตโนมัติสำหรับ C-Rocks อย่าง lpeg & luv

กำลังใช้ตัวพาร์ส PEG ใน lpeg หรือลูปอะซิงโครนัส libuv ใน luv อยู่ใช่ไหม? SuperCode จะรวมโมดูลโปรเจกต์ของคุณส่งไปยังรันไทม์ Lua บนคลาวด์โดยอัตโนมัติ และชี้บรรทัด traceback กลับมายังเอดิเตอร์แบบ 1:1

Cloud lpeg & luv · รวมหลายไฟล์อัตโนมัติ
ออกแบบเพื่อมือถือ จอพับ และแท็บเล็ต · ขนาดเบา 40.2 MB Lua 5.4 IDE Hub
03 ขั้นตอนการทำงาน

วิธีสร้างเครื่องมือ Lua ที่ขับเคลื่อนด้วยข้อมูลบน Android

ผสาน JSON, SQLite, การจัดการไฟล์อัตโนมัติ และการตรวจสอบ SQL ไว้ในเวิร์กสเปซเดียวที่เชื่อมโยงกันอย่างราบรื่น

STEP 01 require('cjson')

นำเข้าโมดูลในตัว 11+ ตัวได้ทันทีโดยตรง

พิมพ์ require('cjson'), require('lsqlite3'), require('lfs') หรือ require('crypto') บนหัวไฟล์ .lua ของคุณได้เลย — ไม่ต้องมีขั้นตอนติดตั้งให้วุ่นวาย

STEP 02 Toolbar -> Run ▶

อ่านและเขียนไฟล์ JSON และ SQLite จริงแบบออฟไลน์

รันสคริปต์เสร็จในระดับมิลลิวินาที ไฟล์ .db, .json หรือ .log ที่เขียนลงดิสก์จะซิงก์เข้าโครงสร้างโปรเจกต์ใน Explorer ทันที

STEP 03 SQL Studio -> Open .db

เปิดดูฐานข้อมูล lsqlite3 แบบภาพข้ามเครื่องมือได้ทันที

แตะไฟล์ .db ที่สร้างขึ้นใน Explorer เพื่อเรียกดูสคีมาและรันคิวรีวิเคราะห์ข้อมูลใน SQL Studio 9 โหมดของ SuperCode

STEP 04 require('lpeg')

ขยายสู่ C-Rocks เฉพาะทางได้อย่างราบรื่นเมื่อต้องการ

หากสคริปต์มีการอิมพอร์ต C rocks ภายนอกอย่าง lpeg หรือ luv ก็รันแบบออนไลน์พร้อมระบบรวมโมดูลหลายไฟล์อัตโนมัติได้ทันที

ส่วนขยายออฟไลน์ในตัว · ไร้ปัญหา gcc/luarocks ล้มเหลว · ซิงก์เวิร์กสเปซร่วมกัน คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

โมดูล Lua ในตัวของ SuperCode เทียบกับ Lua พื้นฐานและพอร์ตบนมือถือ

SuperCode IDE สำหรับ Android มาพร้อม native Lua 5.4.7 และโมดูลส่วนขยายที่ติดตั้งล่วงหน้ากว่า 11 ตัว พร้อมใช้งานแบบออฟไลน์ผ่าน require() — ทั้ง cjson, dkjson, lsqlite3, lfs (LuaFileSystem), crypto, sha2, md5, base64, regex, socket.http และ inspect — หมดปัญหาการคอมไพล์ luarocks บนมือถือ

ตารางความพร้อมใช้งานโมดูลเสริม LUA บน ANDROID
โมดูลส่วนขยาย ชื่อใน require() สถานะออฟไลน์บน SuperCode Lua CLI มาตรฐาน แอป Java LuaJ
JSON ความเร็วสูง + จัดย่อหน้าสวยงาม cjson / dkjson ติดตั้งในตัว ใช้ออฟไลน์ได้ทันที ต้องใช้ luarocks gcc ไม่มีให้ใช้
SQLite 3 แบบฝังในตัว lsqlite3 / sqlite3 ติดตั้งในตัว ใช้ออฟไลน์ได้ (:named + .db) ต้องใช้ C headers ไม่มีให้ใช้
ระบบไฟล์ & ไดเรกทอรี lfs ติดตั้งในตัว ใช้ออฟไลน์ได้ (dir/mkdir/attr) ต้องใช้ luarocks ไม่มีให้ใช้
แฮช, HMAC & UUID crypto / sha2 / md5 / base64 ติดตั้งในตัว ใช้ออฟไลน์ได้ทันที ต้องพึ่งไลบรารี C ภายนอก ไม่มีให้ใช้
HTTP, Regex & ดีบัก socket.http / regex / inspect ติดตั้งในตัว (+ Cloud lpeg/luv) ต้องบิลด์เอง ไม่มีให้ใช้

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการใช้ cjson, lsqlite3, LuaFileSystem และโมดูล luarocks บน Android

ต้องติดตั้ง luarocks หรือคอมไพเลอร์ C ก่อนถึงจะใช้ `cjson`, `lsqlite3` หรือ `lfs` ได้ไหม?+
ไม่ต้องเลย ชื่อเรียกส่วนขยายหลักทั้งหมดกว่า 11 รายการ (`cjson`, `dkjson`, `lsqlite3`, `sqlite3`, `lfs`, `crypto`, `sha2`, `md5`, `base64`, `regex`, `socket.http` และ `inspect`) ถูกรวมไว้ใน SuperCode แล้วและเรียกใช้ผ่าน `require()` ได้ทันที
`lsqlite3` ใช้ไฟล์ `.db` ร่วมกับ Python, PHP หรือ SQL IDE ของ SuperCode ได้ไหม?+
ได้แน่นอน! ฐานข้อมูล `.db` ที่สร้างด้วย `lsqlite3` ในโฟลเดอร์โปรเจกต์ของคุณคือไฟล์ไบนารี SQLite 3 มาตรฐาน ซึ่งสามารถนำไปคิวรีต่อได้ทันทีใน SQL Studio ของ SuperCode, Python `sqlite3`, PHP `PDO` หรือ Java JDBC
`cjson` รองรับการจัดย่อหน้าสวยงาม (pretty-printing) สำหรับไฟล์คอนฟิกไหม?+
รองรับครับ นอกจาก `cjson.encode()` และ `cjson.decode()` มาตรฐานแล้ว SuperCode ยังมี `cjson.encode_pretty()` ให้คุณตรวจสอบหรือบันทึกไฟล์ JSON แบบเว้นย่อหน้าอย่างเป็นระเบียบได้แบบออฟไลน์
จะเกิดอะไรขึ้นหากสคริปต์ของฉันต้องใช้ `lpeg` หรือ `luv`?+
เมื่อเชื่อมต่ออินเทอร์เน็ต SuperCode จะตรวจจับการอิมพอร์ต C-rock เฉพาะทางอย่าง `lpeg` หรือ `luv` และส่งต่อโปรเจกต์หลายไฟล์ของคุณไปยังสภาพแวดล้อม Cloud Lua ให้โดยอัตโนมัติ
