02 ความสามารถหลัก

สถาปัตยกรรมแพ็กเกจ Java ระดับเดสก์ท็อป โดยไม่ต้องรอ Gradle นาน

จัดโครงสร้างแพ็กเกจ domain, service และ repository อย่างเป็นระเบียบบน Android โดยไม่ต้องเสียเวลารอ Gradle sync 4 นาทีหรือตั้งค่า flag `javac -cp` เอง

02.1

สแกนได้สูงสุด 500 ไฟล์ .java ข้ามแพ็กเกจซ้อนกัน

จัดระเบียบโปรเจกต์ตามโครงสร้างมาตรฐาน Maven/Gradle (src/main/java/com/company/...) หรือโฟลเดอร์ย่อยแบบเรียบง่าย SuperCode สแกนได้ถึง 500 ไฟล์ .java (งบซอร์สโค้ด 12 MB) และคอมไพล์การ import ข้ามแพ็กเกจจบในครั้งเดียว

src/main/java · แพ็กเกจซ้อนกัน · 500 ไฟล์ / 12 MB
02.2

โหลด Classpath จาก libs/*.jar & lib/*.jar ไม่ต้องตั้งค่า

ต้องการใช้ Gson, Apache Commons, org.json หรือไลบรารีรายวิชาจากอาจารย์ใช่ไหม? เพียงวางไฟล์ .jar แบบ pure-Java (รวมไม่เกิน 30 MB) ลงในโฟลเดอร์ libs/ หรือ lib/ ของโปรเจกต์ แล้ว import แพ็กเกจใช้งานแบบออฟไลน์ได้ทันที

libs/*.jar · lib/*.jar · Classpath สูงสุด 30 MB
02.3

แคช SHA-256 Closure เพื่อรันซ้ำทันทีในระดับ ~0ms

SuperCode คำนวณค่าแฮช SHA-256 ครอบคลุมไฟล์ .java ที่เกี่ยวข้องทั้งหมด บัฟเฟอร์แท็บที่เปิดอยู่ และไฟล์ .jar เมื่อทดสอบซ้ำด้วยอินพุตคอนโซลใหม่ ระบบจะดึงจาก ⚡ Cache ใน ~0ms โดยไม่ต้องคอมไพล์ใหม่

แฮช SHA-256 Closure · ป้าย ⚡ Cache · เปิดรันทันที
02.4

ตรวจจับจุดเข้า main() อัจฉริยะจากแท็บใดก็ได้

กำลังแก้ไขอินเทอร์เฟซ InvoiceRepository หรือคลาสช่วย TaxCalculator อยู่ใช่ไหม? แตะ Run ▶ ได้จากตรงนั้นเลย — SuperCode จะวิเคราะห์กราฟแพ็กเกจ ค้นหาคลาสหลักที่มี main() ของโปรเจกต์ และผสานโค้ดที่ยังไม่เซฟในแท็บให้อัตโนมัติ

รันจากแท็บใดก็ได้ · ผสานบัฟเฟอร์ที่ยังไม่บันทึก
02.5

รวม Asset ใน resources/ เข้าสู่ Classpath อัตโนมัติ

วางไฟล์เทมเพลต .properties, .json, .csv, .xml หรือ .txt ไว้ในโฟลเดอร์ resources/ หรือ src/main/resources/ คลาสของคุณสามารถโหลดใช้งานผ่าน Class.getResourceAsStream() หรือ ClassLoader.getResource() ได้เหมือนบนเดสก์ท็อป

resources/ · src/main/resources/ · getResourceAsStream
02.6

ค้นหา Fuzzy 50k โหนด, AST Completion & Visual Git

กระโดดข้ามไปมาระหว่างคลาส Java นับสิบไฟล์ในระดับมิลลิวินาทีด้วยค้นหาแบบ CamelCase fuzzy (เช่น พิมพ์ 'ICR' เพื่อหา InvoiceController.java) รีแฟกเตอร์ด้วย AST completion และ commit งานผ่าน Visual Git ในตัว

03 ขั้นตอนการทำงาน

วิธีจัดโครงสร้างโปรเจกต์หลายแพ็กเกจ & .jar บน Android

สร้างพื้นที่ทำงาน OOP หลายแพ็กเกจพร้อมไลบรารี .jar ภายนอกใน 4 ขั้นตอนง่ายๆ

STEP 01 src/main/java/...

สร้างโฟลเดอร์แพ็กเกจหรือ Clone Git Repo

สร้างไดเรกทอรีแพ็กเกจซ้อนกันใน Explorer (หรือ clone รีโป Java จากมหาวิทยาลัย/GitHub ผ่านไคลเอนต์ Visual Git ของ SuperCode)

STEP 02 libs/gson.jar

วางไฟล์ .jar เสริมจากภายนอกลงใน libs/

คัดลอกไฟล์ .jar แบบ pure-Java ที่รองรับลงใน libs/ หรือ lib/ และวางไฟล์คอนฟิกแบบคงที่ไว้ใน resources/

STEP 03 Run ▶ From Any Class

กด Run โดยไม่ต้องสลับออกจากคลาสตัวช่วย

แตะ Run ▶ ได้แม้กำลังดูแท็บโมเดลหรืออินเทอร์เฟซ — SuperCode จะค้นหา main() และคอมไพล์ทั้งโครงสร้างแพ็กเกจแบบออฟไลน์ให้ทันที

STEP 04 ⚡ Cache Re-Run

ทดสอบ Edge Case ทันทีด้วยบิลด์แคช 0ms

รันซ้ำด้วยอินพุต Scanner หรืออาร์กิวเมนต์ CLI ใหม่ได้ทันที ด้วยระบบแคช SHA-256 bytecode closure

รองรับสูงสุด 500 ไฟล์ .java (12 MB) · โควตา .jar กำหนดเอง 30 MB · ซิงก์บัฟเฟอร์แท็บที่ยังไม่บันทึก คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

เปรียบเทียบการรองรับโปรเจกต์ Java หลายไฟล์ & .jar

SuperCode Multi-Class Java IDE สร้างโปรเจกต์ Java 17 หลายแพ็กเกจได้จริงแบบออฟไลน์บน Android โดยไม่มีภาระของ Gradle สแกนซอร์สไฟล์ได้ถึง 500 ไฟล์ข้ามแพ็กเกจซ้อนกัน โหลดไลบรารี .jar ภายนอกจาก libs/ อัตโนมัติ เลือกคลาสหลัก main() อย่างชาญฉลาด และแคชบิลด์ที่คอมไพล์แล้วด้วยแฮช SHA-256 เพื่อการรันซ้ำที่เร็วเกือบ 0ms

ความสามารถการบิลด์ JAVA หลายคลาส & JAR บน ANDROID
ความสามารถโปรเจกต์ SuperCode Java 17 IDE แอป Java มือถือพื้นฐาน คอมไพเลอร์วางโค้ดออนไลน์ พอร์ต Gradle มือถือขนาดใหญ่
ขนาดรองรับหลายแพ็กเกจ สูงสุด 500 ไฟล์ .java ใน src/main/java โฟลเดอร์เดียวหรือต้องเลือกรายไฟล์เอง 1 ไฟล์ (Main.java เท่านั้น) กิน RAM & พื้นที่จัดเก็บสูงมาก
ไลบรารี .jar กำหนดเอง โหลด libs/*.jar & lib/*.jar อัตโนมัติ (30 MB) ไม่รองรับหรือติดล็อกแบบเสียเงิน อัปโหลด .jar เองไม่ได้ ต้องซิงก์ Maven ออนไลน์
UX การรันจุดเริ่มต้นโปรแกรม เลือก main() อัตโนมัติจากแท็บใดก็ได้ พังหากเปิดแท็บคลาสตัวช่วยอยู่ บังคับชื่อคลาส Main ตายตัว ต้องตั้งค่า XML การรันเอง
ทรัพยากรใน Classpath เมานต์ resources/ อัตโนมัติผ่าน getResourceAsStream ไม่มี root ของ classpath ไม่รองรับ รองรับ
รันซ้ำเมื่อไม่แก้โค้ด แคช SHA-256 ⚡ เร็วเกือบ 0ms คอมไพล์ใหม่ทั้งหมดทุกครั้งที่แตะ รอคิวเครือข่ายทุกครั้งที่กดรัน daemon แบบ incremental ทำงานช้า

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับโครงสร้างหลายแพ็กเกจ การเพิ่มไลบรารี .jar ภายนอก และการค้นหา main()

ฉันจะเพิ่มไลบรารี `.jar` ภายนอกอย่าง Gson หรือ Commons Lang ใน SuperCode ได้อย่างไร?+
สร้างโฟลเดอร์ชื่อ `libs` (หรือ `lib`) ภายในรูทโปรเจกต์ Java ของคุณ แล้วคัดลอกไฟล์ `.jar` ลงไป SuperCode จะเพิ่มไฟล์ `.jar` ทั้งหมดใน `libs/` (รวมสูงสุด 30 MB) เข้าสู่ทั้ง classpath ตอนคอมไพล์และตอนรันให้อัตโนมัติ — ไม่ต้องเขียนสคริปต์บิลด์ใดๆ
จะเกิดอะไรขึ้นหากฉันกด Run ขณะแก้ไขคลาส Java ที่ไม่มี `main()`?+
ตัวตรวจจับจุดเข้าโปรแกรมของ SuperCode จะสแกนคลาสที่คอมไพล์แล้วในโปรเจกต์ เลือกคลาสหลักที่มี `main()` ให้อัตโนมัติ แล้วสั่งรันทันที — ช่วยให้คุณไม่ต้องสลับแท็บไปมาอยู่ตลอดเวลา
จำเป็นต้องใช้ `src/main/java` หรือไม่ หรือวางหลายไฟล์ในโฟลเดอร์ธรรมดาก็ใช้ได้?+
ใช้งานได้ทั้งสองแบบอย่างราบรื่น! คุณสามารถวางไฟล์ `.java` สองไฟล์เคียงกันในโฟลเดอร์ธรรมดาโดยไม่ต้องประกาศ `package` จัดโฟลเดอร์ย่อย `com.example.*` โดยตรง หรือใช้โครงสร้างเต็มรูปแบบ `src/main/java` + `resources/` + `libs/` ก็ได้เช่นกัน
ไฟล์ `.jar` แบบใดที่ใช้งานแบบออฟไลน์บน Android ได้?+
ไลบรารี pure-Java มาตรฐานใดๆ ที่คอมไพล์สำหรับ Java 8, 11 หรือ 17 (เช่น `gson`, `org.json`, `commons-lang3`, `commons-csv` หรือไลบรารีตรวจงานของมหาวิทยาลัย) ทำงานออฟไลน์ได้ 100% ส่วน jar สำหรับ GUI เดสก์ท็อปที่ต้องใช้หน้าต่าง AWT/Swing ไม่ได้ออกแบบมาสำหรับคอนโซลบนมือถือ
