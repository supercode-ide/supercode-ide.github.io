02 ความสามารถหลัก

สร้างสถาปัตยกรรมหลายเซอร์วิสครบวงจรภายในโฟลเดอร์โปรเจกต์เดียว

ไม่ต้องโหลดไดรเวอร์ ไม่ปวดหัวเรื่อง classpath และไม่ต้องก๊อปปี้ไฟล์ข้ามแอปมือถือให้ยุ่งยาก

02.1

ไฟล์ .db ร่วมกันในเวิร์กสเปซ พร้อมตรวจสอบสดใน SQL Studio

ทุกรันไทม์ทำงานบนโฟลเดอร์โปรเจกต์จริงของคุณโดยตรง เพิ่มแถวข้อมูลจาก Python scraper หรือ Java DAO แล้วสลับไปแท็บ .sql เพื่อรัน SELECT ในโหมดตารางตรวจสอบผลลัพธ์ได้ทันที

โฟลเดอร์โปรเจกต์เดียว · ตรวจสอบข้ามแท็บทันที
02.2

Python 3.11 sqlite3 & Pandas read_sql_query()

รันไปป์ไลน์ ETL, สคริปต์ดึงข้อมูล BeautifulSoup หรือโปรโตไทป์ Flask ที่บันทึกลง sqlite3.connect('app.db') — แล้วโหลดตารางเข้า pandas.read_sql_query() เพื่อส่งออกกราฟ Matplotlib ลงในเวิร์กสเปซโดยตรง

sqlite3 Stdlib · pandas.read_sql_query() · กราฟ
02.3

เว็บแดชบอร์ด PHP 8.2 new PDO('sqlite:app.db')

เปลี่ยนชุดข้อมูล SQLite ให้เป็นเว็บแอป HTML5 + PHP 8.2 แบบอินเทอร์แอกทีฟได้ออฟไลน์ ส่งฟอร์มจากเบราว์เซอร์ผ่าน $_POST ลง app.db ด้วย prepared statement และดูเวลาตอบสนอง HTTP สดใน Web DevTools

PHP 8.2 PDO · Full-Stack CRUD · Localhost HTTP
02.4

Java 17 JDBC ไม่ง้อ Gradle & Lua 5.4 lsqlite3 ระดับต่ำกว่ามิลลิวินาที

เขียน DriverManager.getConnection("jdbc:sqlite:app.db") ใน Java 17 ได้ทันทีเพราะมี org.sqlite.JDBC อยู่ใน classpath ออฟไลน์แล้ว หรือเขียนสคริปต์เก็บสถานะเกม/ระบบอัตโนมัติใน Lua 5.4 ผ่าน require('lsqlite3')

Java 17 jdbc:sqlite · Lua 5.4 lsqlite3 · ไม่ต้องตั้งค่า
02.5

ตรวจสอบ & แก้ไขด้วย Regex บนไฟล์ดัมพ์ .sql ขนาดหลาย GB

โหลดแบ็กอัป mysqldump หรือ pg_dump ไฟล์ .sql ขนาด 2 GB มาหรือ? ตัวแก้ไขไฟล์ใหญ่แบบแบ่งหน้าจากดิสก์ของ SuperCode เปิดไฟล์ .sql ระดับกิกะไบต์ได้ลื่นไหล รองรับกว่า 30 ชุดอักขระ ค้นหา/แทนที่ด้วย Regex และกระโดดไปยัง byte-offset ได้ทันที

ดัมพ์ .sql ระดับ GB+ แบบอ่านจากดิสก์ · ค้นหา/แทนที่ Regex

03 ขั้นตอนการทำงาน

วิธีสร้างแอปพลิเคชัน SQLite หลายภาษาบน Android

หนึ่งโฟลเดอร์โปรเจกต์ หนึ่งไฟล์ `app.db` และห้ารันไทม์ออฟไลน์ที่ทำงานประสานกันอย่างลงตัว

STEP 01 01_schema.sql -> Run ▶

ออกแบบตาราง ดัชนี และข้อมูลตั้งต้นใน SQL Studio

สร้าง app.db ในโฟลเดอร์โปรเจกต์ด้วย DDL ของ SQLite 3.54.1, ชนิดข้อมูล STRICT, ดัชนี FTS5 หรือนำเข้าจาก CSV/JSON

STEP 02 ingest.py / Dao.java

นำเข้าหรือประมวลผลข้อมูลผ่าน Python, Java หรือ Lua

เชื่อมต่อ 'app.db' ผ่าน Python sqlite3, Java jdbc:sqlite:app.db หรือ Lua lsqlite3 โดยไม่ต้องติดตั้งไดรเวอร์เพิ่ม

STEP 03 dashboard.php -> Run ▶

แสดงผล Web UI แบบไดนามิกผ่าน Localhost PHP PDO

เปิด dashboard.php แล้วคิวรี new PDO('sqlite:app.db') เพื่อเรนเดอร์กราฟและฟอร์ม CRUD บนเบราว์เซอร์ 3 มุมมองหน้าจอ

STEP 04 Tap app.db / Large .sql

ตรวจสอบตารางสด หรือคลีนไฟล์แบ็กอัป .sql ระดับ GB

แตะ app.db ได้ทุกเมื่อเพื่อเช็กข้อมูลใน 9 โหมดแสดงผล หรือเปิดไฟล์ดัมพ์ .sql ขนาดหลาย GB ในตัวแก้ไขไฟล์ใหญ่แบบแบ่งหน้าจากดิสก์

ไม่ต้องตั้งค่าไดรเวอร์ · Python 3.11 + PHP 8.2 + Java 17 + Lua 5.4 + SQLite 3.54.1 ออฟไลน์ คู่มือแอป

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับการใช้ไฟล์ `.db` ร่วมกันข้ามภาษา และการแก้ไขดัมพ์ `.sql` ขนาดใหญ่บน Android

ต้องดาวน์โหลดไฟล์ `.jar` เองไหมถ้าจะใช้ `jdbc:sqlite:app.db` ใน Java 17?+
ไม่ต้องเลย! SuperCode รวมไดรเวอร์ SQLite JDBC ไว้ใน classpath ออฟไลน์ของ Java 17 ให้เรียบร้อยแล้ว — แค่เขียน `DriverManager.getConnection("jdbc:sqlite:app.db")` แล้วกดรันได้ทันที
Python, PHP, Java และ Lua อ่านเขียนไฟล์ `app.db` เดียวกันได้จริงหรือ?+
ได้จริง ตราบใดที่ไฟล์ `.sql`, `.py`, `.php`, `.java` และ `.lua` อยู่ในโฟลเดอร์เวิร์กสเปซเดียวกัน (หรืออ้างอิงพาธสัมพัทธ์เดียวกัน) ทุกรันไทม์จะอ่านและคอมมิตทรานแซกชันแบบ ACID ลงบนไฟล์ `app.db` จริงบนดิสก์ไฟล์เดียวกันทั้งหมด
ใช้ SQLite ในสคริปต์ Lua 5.4 บน SuperCode ได้อย่างไร?+
เรียกใช้ `local sqlite3 = require('lsqlite3')` และ `local db = sqlite3.open('app.db')` ได้เลย โดย `lsqlite3` ถูกรวมไว้ในรันไทม์ Lua 5.4 แบบออฟไลน์ของ SuperCode พร้อมเปิดใช้งานได้ในระดับต่ำกว่ามิลลิวินาที
SuperCode เปิดไฟล์ดัมพ์ฐานข้อมูล `.sql` ขนาด 1 GB+ ได้โดยไม่ทำให้มือถือแครชจริงไหม?+
ได้จริง ตัวแก้ไขไฟล์ใหญ่ระดับ GB ของ SuperCode จะสตรีมไฟล์ `.sql`, `.csv` และ `.log` ขนาดมหึมาโดยตรงจากหน้าดิสก์แทนการโหลดทั้งไฟล์เข้า RAM — พร้อมรองรับการค้นหา/แทนที่ด้วย Regex และการตรวจจับชุดอักขระอัตโนมัติ
