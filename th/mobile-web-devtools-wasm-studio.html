02 ความสามารถหลัก

ระบบวิเคราะห์เบราว์เซอร์ระดับเดสก์ท็อปโดยไม่ต้องเสียบสาย USB Debugging

เห็นทุกคำเตือนในคอนโซล ตรวจสถานะ JS แบบอ้างอิงวนซ้ำ วัดค่า Latency ของ API และสตรีม WebAssembly ไบนารีได้บนมือถือของคุณ

02.1

ลิ้นชัก DevTools ปรับขนาดได้ & ป้ายแจ้งเตือน Error สด

ดึงแถบแบ่งหน้าจอ DevTools ขึ้นมาใต้หน้าเว็บที่เรนเดอร์อยู่ได้เลย กรองล็อกได้ทันทีในแท็บ All, Error, Warn และ Net พร้อมป้ายนับสดบน Dynamic Island ที่เตือนทันทีเมื่อเกิดข้อผิดพลาดที่ไม่ได้ดักจับ

All / Error / Warn / Net · ลากปรับความสูงได้
02.2

ตัวตรวจสอบเวลา HTTP, fetch() & เครือข่าย PHP

สลับไปแท็บ Net เพื่อตรวจทุกไฟล์ทรัพยากร, ES module, ไบนารี WASM และคำขอ PHP API แบบเรียลไทม์ — แสดงผลชัดเจนเป็น METHOD /path -> status · ms · bytes ให้เห็น 404 และเพย์โหลดที่ช้าได้ในพริบตา

สถิติ METHOD /path -> status · ms · bytes
02.3

DOM สดเชิงโต้ตอบ & JS REPL รองรับ Async Promise

พิมพ์คำสั่งในช่อง > Run JavaScript... เพื่อค้นหาหรือแก้ไของค์ประกอบ DOM สดๆ ทดสอบสลับคลาส CSS ตรวจ localStorage หรือรัน fetch() Promise แบบอะซิงโครนัสกับหน้าเว็บที่กำลังทำงานอยู่ได้ทันที

> Run JavaScript... · แกะผลลัพธ์ Promise อัตโนมัติ
02.4

แสดงโหนด DOM (<div#app.card>) & พิมพ์ออบเจกต์วนซ้ำอย่างปลอดภัย

ไม่ต้องจ้อง [object HTMLDivElement] หรือเจอแครชจาก JSON circular-reference อีกต่อไป SuperCode แสดงโหนด DOM เป็น <tag#id.class> ที่อ่านง่าย พร้อมจัดรูป Object ซ้อน, Map, Set และลิงก์ [Circular] อย่างปลอดภัย

รูปแบบ <div#id.class> · ปลอดภัยต่อ Circular Graph
02.5

รัน WebAssembly (.wasm) แบบสตรีมมิงความเร็วใกล้เคียงเนทีฟ

รันโมดูล .wasm ที่คอมไพล์จาก Rust, C, C++, Zig หรือ AssemblyScript ด้วยความเร็วสูง เซิร์ฟเวอร์ HTTP ในเครื่องส่งไฟล์ .wasm พร้อมหัว application/wasm ที่ถูกต้องให้ WebAssembly.instantiateStreaming(fetch(...)) ทำงานแบบ zero-copy

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามเกี่ยวกับการตรวจ Error คอนโซล, การจับเวลา HTTP, การรันคำสั่ง DOM JS และการใช้งาน `.wasm` แบบออฟไลน์

ต้องแปะ `<script src="eruda.js">` หรือต่อเน็ตเพื่อให้ DevTools ทำงานไหม?+
ไม่ต้อง! คอนโซล Web DevTools, ตัวตรวจเครือข่าย และ JavaScript REPL ของ SuperCode สร้างไว้ในเอนจินพรีวิวออฟไลน์โดยตรง — ไม่ต้องใส่แท็กสคริปต์ CDN ภายนอก และใช้งานได้ 100% แม้ในโหมดเครื่องบิน
รันไฟล์ไบนารี `.wasm` WebAssembly ที่คอมไพล์จาก Rust หรือ C/C++ ได้หรือไม่?+
ได้ เพียงวางไฟล์ `.wasm` ไว้ในโฟลเดอร์โปรเจกต์แล้วโหลดด้วย `WebAssembly.instantiateStreaming(fetch('./module.wasm'))` — SuperCode เสิร์ฟ `.wasm` ด้วยประเภท MIME `application/wasm` ที่ถูกต้องตรงเป๊ะ
จะเกิดอะไรขึ้นถ้าสั่ง log องค์ประกอบ DOM หรือออบเจกต์ที่มีการอ้างอิงวนซ้ำ?+
องค์ประกอบ DOM จะแสดงเป็นสรุป `<tag#id.class>` ที่อ่านง่าย ส่วนออบเจกต์ที่อ้างอิงวนซ้ำจะถูกตรวจจับอย่างปลอดภัยและแสดงเป็น `[Circular]` แทนที่จะพังด้วยข้อผิดพลาด `JSON.stringify`
แท็บ Net จับการเรียก PHP ฝั่ง Backend รวมถึงไฟล์นิ่งและ `fetch()` ด้วยไหม?+
ใช่ ทุกไฟล์นิ่ง, ES module, ไบนารี `.wasm`, คำสั่ง `fetch()` / `XMLHttpRequest` และการรันเอ็นด์พอยต์ `.php` ในเครื่องจะปรากฏในแท็บ Net พร้อมรหัสสถานะ HTTP, ความหน่วงระดับมิลลิวินาที และขนาดข้อมูลเป็นไบต์
