02 ความสามารถหลัก

ออกแบบให้ล้ำหน้ากว่าแอป Rhino ES5 รุ่นเก่าและ WebView บน Main-Thread

ทดสอบการประสานงานแบบอะซิงโครนัสสมัยใหม่ การโคลนสเตตแบบไม่กลายพันธุ์ และไปป์ไลน์ดึงข้อมูลเครือข่ายได้ผลลัพธ์ทันทีพร้อม UI ที่ลื่นไหลไม่มีสะดุด

02.1

รันสคริปต์ .js & .mjs ล้วนโดยไม่ต้องสร้างไฟล์ HTML

อยากทดสอบตัวช่วย async retry, ตัวแยก regex หรือ state reducer ใช่ไหม? สร้างไฟล์ `.js` หรือ `.mjs` เดี่ยวๆ แล้วกด รัน ▶ ได้เลย — ไม่ต้องใส่แท็ก `<script>`, หน้า HTML หลอก หรือเปิดลิ้นชัก DevTools บนมือถือที่เล็กจิ๋ว

รัน .js / .mjs โดยตรง · คอนโซลแบ่งหน้าจอติดขอบล่าง
02.2

ไวยากรณ์ ES2024 สมัยใหม่ที่เหนือกว่าแอป ES5 รุ่นเก่า

ตัวรัน JS บน Play Store หลายตัวใช้เอนจินเก่ากว่าสิบปีที่พังกับ `const`, arrow functions หรือ `async` แต่ SuperCode รัน top-level `await`, async generators (`async function*`), `#fields` ส่วนตัว, `BigInt`, `WeakRef`, `structuredClone`, `Object.groupBy` และ `Array.at()` แบบออฟไลน์ได้ครบ

Top-Level await · #Fields ส่วนตัว · BigInt · WeakRef
02.3

ระบายคิว Event-Loop & Microtask อัตโนมัติอย่างชาญฉลาด

โค้ด async จะไม่จบการทำงานก่อนที่ Promises ของคุณจะ resolve: เวิร์กเกอร์จะติดตาม `setTimeout`, `setInterval`, `queueMicrotask` และ `timers/promises` ที่ทำงานอยู่ เพื่อระบาย Event Loop จนเสร็จสิ้นสมบูรณ์

Promise.allSettled · timers/promises · ระบายคิวครบถ้วน
02.4

เธรด Worker แยกอิสระ & ตัดลูปไม่รู้จบใน <1ms

การรัน JavaScript บน UI เธรดหลักทำให้เอดิเตอร์ทั่วไปค้างสนิทเมื่อเจอ `while (true) {}` ที่มีบั๊ก แต่ SuperCode แยกรันบนแบ็กกราวด์เวิร์กเกอร์เฉพาะ แตะ หยุด ■ (หรือเมื่อครบเวลาเฝ้าระวัง 15 วินาที) เพื่อตัดลูปค้างได้ในเวลาต่ำกว่า 1ms

Worker นอก UI · ยกเลิกใน <1ms · เอดิเตอร์ไม่กระตุกเลย
02.5

Fetch API มาตรฐาน, AbortController & Web Streams

สร้างต้นแบบไคลเอนต์ API สดด้วย `fetch()`, `Headers`, `Request`, `Response`, `AbortController` / `AbortSignal.timeout()`, `URL`, `URLSearchParams`, `TextEncoder`/`TextDecoder` และ `ReadableStream` มาตรฐาน

fetch() · AbortController · URL · ReadableStream
02.6

console.table() แบบตาราง ASCII, ตัวจับเวลาละเอียด & บรรทัด 1:1

แสดงผลอาร์เรย์ของออบเจกต์เป็นตารางเส้นขอบชัดเจนด้วย `console.table()`, จับเวลาฟังก์ชันสำคัญด้วย `console.time()` และ `performance.now()` ระดับต่ำกว่ามิลลิวินาที พร้อมไล่ย้อนข้อผิดพลาดไปยังบรรทัดต้นฉบับตรงเป๊ะ

console.table() · performance.now() · สแต็กตรงบรรทัด 1:1

03 ขั้นตอนการทำงาน

วิธีสร้างต้นแบบสคริปต์ Async ES2024 ใน SuperCode

ตั้งแต่โค้ดสั้นบรรทัดเดียวไปจนถึงไปป์ไลน์ async generator ในมุมมองแบ่งหน้าจอที่ไร้สิ่งรบกวน

STEP 01 script.mjs / app.js

เปิดไฟล์ JavaScript แบบสแตนด์อโลนไฟล์ใดก็ได้

เขียนโค้ด ES2024 โดยตรงด้วยแถบสัญลักษณ์ JS/TS 21 ปุ่ม (`=>`, `?.`, `??`, `` ` ``, `${}`) พร้อมการเติมโค้ดอัตโนมัติ AST แบบออฟไลน์

STEP 02 await / console.table

ใช้ Top-Level await, ตัวจับเวลา หรือ Fetch

เชื่อม Promises, ตัววนซ้ำ `for await...of`, `structuredClone` หรือคำขอ `fetch()` พร้อมตั้งค่า timeout ด้วย `AbortController`

STEP 03 Run ▶ / Stop ■

รันในเวิร์กเกอร์แยกอิสระที่ไม่มีวันค้าง

ดูผลลัพธ์คอนโซลสตรีมแบบเรียลไทม์ในแถบด้านล่างหรือมุมมองแนวนอน 55:45 — และหยุดลูปที่รันไม่จบได้ใน `<1ms`

STEP 04 Format & Inspect

วัดประสิทธิภาพเวลา & จัดรูปแบบอัตโนมัติใน 1 แตะ

เปรียบเทียบข้อมูลเวลาประมวลผลระดับมิลลิวินาทีข้ามการรัน และจัดระเบียบ async callback ที่ซ้อนกันให้สะอาดตาในทันทีด้วยตัวจัดรูปแบบ JS ในตัว

แบ็กกราวด์เวิร์กเกอร์เฉพาะ · ตัวเฝ้าระวัง CPU 15 วินาที · รองรับ ES6–ES2024 เต็มรูปแบบ คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

เทียบ SuperCode ES2024 Worker กับแอป JS มือถือรุ่นเก่า

SuperCode ES2024 JavaScript Runner รัน JavaScript สมัยใหม่แบบสแตนด์อโลนบน Android ภายในแบ็กกราวด์เวิร์กเกอร์ที่แยกอิสระโดยไม่ต้องมีโครงสร้าง HTML ต่างจากแอปมือถือ ES5 รุ่นเก่าตรงที่รองรับ top-level await, async generators, Promise.allSettled, BigInt, structuredClone, Fetch พร้อม AbortController, console.table(), การระบายคิว Event-Loop อัตโนมัติ และการตัดลูปไม่รู้จบในระดับต่ำกว่ามิลลิวินาที

เปรียบเทียบรันไทม์ JAVASCRIPT แบบสแตนด์อโลนบน ANDROID
มิติของรันไทม์ SuperCode ES2024 Worker แอป JS มือถือ ES5 รุ่นเก่า กระดาษทด HTML WebView แซนด์บ็อกซ์ Repl ออนไลน์
มาตรฐาน ECMAScript ES2024 สมัยใหม่ + Top-Level await ออฟไลน์ ES5 ล้าสมัย / ES6 บางส่วน ผูกติดกับวงจรชีวิตหน้าเว็บ HTML ทันสมัย (ออนไลน์เท่านั้น)
ความปลอดภัยจากลูปไม่รู้จบ Worker แยกอิสระ (ตัดจบใน <1ms ไม่ค้าง) ทำแอปค้างหรือแครชทั้งแอป ล็อก UI เธรดของ WebView จนค้าง แท็บเบราว์เซอร์ค้าง
Async & Event Loop ระบาย Promises, Microtasks & Timers อัตโนมัติ ไม่มี async/await ในตัว ต้องเปิดดูใน DevTools เอง รองรับ
การวิเคราะห์ผลบนคอนโซล ASCII console.table(), ตัวจับเวลา & บรรทัด 1:1 พิมพ์ได้เฉพาะสตริงธรรมดา ซ่อนเป็น `[object Object]` หน่วงตามความเร็วเน็ต

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามที่พบบ่อยเกี่ยวกับไวยากรณ์ ES2024, top-level `await`, `fetch()` และการป้องกันลูปไม่รู้จบ

ฉันรันไฟล์ JavaScript ใน SuperCode โดยตรงแบบไม่ต้องสร้างไฟล์ HTML ได้ไหม?+
ได้! SuperCode มีเอนจินคอนโซล JavaScript แบบสแตนด์อโลนแยกจาก HTML5 Web IDE เพียงเปิดไฟล์ `.js`, `.mjs` หรือ `.cjs` ใดก็ได้แล้วแตะ รัน ▶
จะใช้ top-level `await` โดยไม่ต้องครอบโค้ดใน `async function main()` ได้อย่างไร?+
บันทึกไฟล์เป็น `.mjs` (หรือตั้งค่า `\"type\": \"module\"` ใน `package.json` หรือเขียน top-level `await` ในสคริปต์ ES Module ได้เลย) — SuperCode จะรัน top-level `await` แบบเนทีฟและรอให้ Promises ทั้งหมดทำงานจนเสร็จสิ้น
จะเกิดอะไรขึ้นถ้าเผลอเขียนลูปไม่รู้จบ `while (true)` บนมือถือ?+
เอดิเตอร์และไฟล์ที่ยังไม่ได้บันทึกของคุณจะยังคงตอบสนองได้ 100% เพราะสคริปต์รันบนเธรดแบ็กกราวด์เวิร์กเกอร์ที่แยกอิสระ แตะปุ่ม หยุด ■ (หรือปล่อยให้ตัวเฝ้าระวัง CPU 15 วินาทีทำงาน) เพื่อยุติเวิร์กเกอร์ในเวลาต่ำกว่า 1 มิลลิวินาที
`fetch()` ใช้งานในสคริปต์ JavaScript แบบสแตนด์อโลนได้หรือไม่?+
ได้ `fetch()`, `Headers`, `Request`, `Response` และ `AbortController` มาตรฐานถูกติดตั้งมาในรันไทม์เวิร์กเกอร์แล้ว เพื่อทดสอบ HTTPS API จริงได้ทุกเมื่อที่อุปกรณ์ของคุณเชื่อมต่ออินเทอร์เน็ต
