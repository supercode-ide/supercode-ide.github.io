02 ความสามารถหลัก

6 ชั้นการทำงานที่เชื่อมต่อกันสำหรับวิศวกรรมเว็บยุคใหม่บน Android

Frontend ES modules, ไบนารี WebAssembly, PHP sessions ฝั่ง Backend, ฐานข้อมูล SQL เชิงสัมพันธ์, การตรวจสอบผ่าน DevTools และการ Deploy ผ่าน SFTP — รวมไว้ในที่เดียว

02.1

Local HTTP Origin จริงสำหรับ HTML5, CSS3, JS & WASM

ให้บริการโปรเจกต์ผ่าน HTTP/1.1 Origin ท้องถิ่นจริงแทน URL แบบ file:// ที่มีข้อจำกัด — ปลดล็อก fetch(), <script type="module">, WebAssembly.instantiateStreaming() (.wasm), ไฟล์ WebGL .glb/.gltf, IndexedDB และการเลื่อนเล่นวิดีโอ/เสียงแบบ HTTP 206

65+ MIME Types · ES Modules · application/wasm · HTTP 206
02.2

เอนจิน Backend PHP ไดนามิกแบบออฟไลน์ 100%

รันเทมเพลต .php หลายหน้า, คลาส OOP, closures, match และ include/require แบบออฟไลน์สมบูรณ์ พร้อม $_GET, $_POST, $_SESSION แบบถาวร, การอัปโหลด $_FILES, เฮดเดอร์ JSON REST และ password_hash()

$_GET / $_POST / $_SESSION · JSON APIs · PHP ออฟไลน์
02.3

ฐานข้อมูล SQL ในตัวผ่าน PDO & SQLite3

สร้างแอป PHP ที่ขับเคลื่อนด้วยข้อมูลแบบออฟไลน์ด้วย new PDO('sqlite:app.db') หรือ SQLite3 พร้อม Prepared Statements (แบบ ? และ :named), ธุรกรรม ACID และการตรวจสอบตารางทันทีใน SQL IDE

PDO('sqlite:...') · Prepared Statements · ธุรกรรม ACID
02.4

คอนโซล DevTools แบบลอย, Network Log & JS REPL

ตรวจสอบ HTTP requests สด (GET /api.php -> 200 · 3ms · 1.2 KB), กรอง Log แบบ All / Error / Warn / Net, ตรวจโครงสร้าง DOM/Object tree และรันนิพจน์สดใน > Run JavaScript... REPL

Net Timing · ป้ายแจ้ง Error · JS REPL โต้ตอบได้
02.5

ตัวสลับมุมมอง 3 โหมด & จับภาพหน้าเว็บ 2560px

สลับระหว่างเลย์เอาต์ Mobile, Tablet (768dp) และ Desktop ได้ทันทีจาก Dynamic Island ที่ลากได้ ทดสอบอัปโหลด <input type="file"> จากกล้อง/คลังภาพ และส่งออกภาพหน้าจอ PNG คมชัด 2560px

Mobile / Tablet / Desktop · ส่งออก PNG 2560px
02.6

พรีวิวเว็บระยะไกล FTP / FTPS / SFTP สด & Deploy

กำลังแก้ไขเว็บจริงผ่าน SFTP หรือ FTPS อยู่ใช่ไหม? แตะ Run เพื่อพรีวิวหน้าระยะไกลบนเครื่อง (ดึงไฟล์ CSS, JS และรูปภาพแบบ Relative ตามต้องการ) แล้วบันทึกกลับไปยังเว็บโฮสต์แบบ Atomic

พรีวิวระยะไกลสด · อัปโหลด SFTP / FTPS แบบ Atomic
ออกแบบเพื่อมือถือ จอพับ และแท็บเล็ต · ขนาดเบา 40.2 MB ภาพรวม
03 ขั้นตอนการทำงาน

วิธีสร้าง ดีบัก และ Deploy เว็บไซต์ Full-Stack บน Android

ตั้งแต่การทำต้นแบบ HTML/CSS/WASM และ PHP+SQL ในเครื่อง ไปจนถึงการ Deploy ขึ้นเซิร์ฟเวอร์จริง

STEP 01 index.html / index.php

เขียนไฟล์ HTML5, CSS3, JS, WASM & PHP

แก้ไขโปรเจกต์เว็บหลายไฟล์ด้วยระบบเติมโค้ดอัตโนมัติ AST สำหรับ HTML/CSS/JS/PHP และจัดรูปแบบโค้ดแบบเรียกซ้ำในแตะเดียวที่จัดย่อหน้าบล็อก <script> และ <style> ในตัวพร้อมกัน

STEP 02 PDO + app.db

เชื่อมต่อฟอร์มและ API ของ PHP ออฟไลน์เข้ากับ SQL

คิวรีฐานข้อมูล SQLite .db ในเครื่องจาก PHP ผ่าน PDO Prepared Statements หรือสร้างข้อมูลตั้งต้นในตารางโดยตรงภายใน SQL Studio ของ SuperCode

STEP 03 Run ▶ -> Dynamic Island

พรีวิวทั้งบนมือถือ แท็บเล็ต และเดสก์ท็อป + DevTools

สลับมุมมองหน้าจอได้ทันที ตรวจสอบสถานะ Network และข้อผิดพลาด JS ในลิ้นชัก DevTools ที่ปรับขนาดได้ หรือทดสอบปรับ DOM สดใน JS REPL

STEP 04 SFTP / Visual Git

เผยแพร่อัปเดตตรงไปยังโฮสต์ของคุณหรือ GitHub Pages

Push งานบิลด์ Static/WASM ขึ้น GitHub Pages ผ่าน Visual Git หรือ Deploy ไฟล์ PHP และเว็บไปยัง VPS ของคุณโดยตรงผ่าน SFTP/FTPS

ปัดขอบซ้ายเพื่อกลับไปยัง Explorer ทันที · รีเซ็ตแคชและ Session ในแตะเดียว คู่มือแอป
