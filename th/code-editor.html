02 ความสามารถหลัก

สร้างขึ้นจากแถบเครื่องมือขึ้นมาเพื่อโปรเจกต์ซอฟต์แวร์จริง

ทุกปฏิสัมพันธ์ย่อย ตั้งแต่การกระโดดข้ามวงเล็บจนถึงการจัดรูปแบบโดยยึดตำแหน่งที่เลือก ล้วนผ่านการทดสอบเพื่อความเร็วนิ้วโป้งและความคมชัดของภาพ

02.1

การเติมโค้ดตามบริบทแบบ Hybrid AST

ทำงานอัตโนมัติเมื่อพิมพ์ ., ->, :: และ : ครอบคลุม C/C++, Python, Java, Kotlin, JS/TS, HTML, CSS, PHP, Lua, Shell และ SQL — วิเคราะห์ชนิดข้อมูลในเครื่อง สมาชิก Struct/Class, API ของ STL/DOM และ Snippet โค้ดแบบออฟไลน์

ตัวดำเนินการ: . · -> · :: · : | 10 ตระกูลภาษา
02.2

ไฮไลต์ 2 โหมด & ตรวจจับภาษาอัจฉริยะสำหรับไฟล์ไม่มีนามสกุล

ไฮไลต์บรรทัดในหน้าจอที่มองเห็นได้ทันทีที่ 120Hz พร้อมคงสีสันโทเค็นจัดรูปแบบภายใน (\n, %d, {0}) และแท็ก @param/TODO ตรวจจับภาษาอัตโนมัติในไฟล์ไร้นามสกุลผ่าน #! Shebang และการให้คะแนนคำศัพท์

40+ นามสกุล · ตรวจจับ Shebang · ไม่มีเฟรมดรอป
02.3

ตัวจัดรูปแบบออฟไลน์ 30+ ภาษา & คอมเมนต์อัจฉริยะ

จัดระเบียบโค้ด C/C++, Java, Kotlin, JS/TS, Python (PEP 8), JSON, CSS, PHP, SQL, Lua, Shell และ HTML/Vue (จัดรูปแบบซ้อน <script> และ <style> อัตโนมัติ!) พร้อมรักษาระยะย่อหน้าเดิมของส่วนที่เลือกไว้ในขั้นตอน Undo เดียว

Undo ครั้งเดียวแบบ Atomic · HTML/JS/CSS แบบซ้อน
02.4

Error Radar V2.0 & สถิติเอกสารแบบโฮโลแกรม

ดักจับวงเล็บไม่ครบ สตริง/แท็กที่ไม่ได้ปิด ข้อผิดพลาด TabError หรือลืมโคลอนใน Python และเครื่องหมายจุลภาคเกินใน JSON พร้อมแตะเดียวเพื่อกระโดดไปยังบรรทัด X คอลัมน์ Y ควบคู่กับสถิติจำนวนบรรทัด คำ อักขระ และไบต์ UTF-8 ที่แม่นยำทั้งไฟล์และส่วนที่เลือก

กระโดดบรรทัด/คอลัมน์ · ไบต์ UTF-8 ทั้งไฟล์และที่เลือก
02.5

แถบ 29 เครื่องมือ 5 โหมด & เมนูปัดขอบขวา

ปรับเปลี่ยนอัตโนมัติตามโหมด Code, Plain Text, Selection, Search และ Mega-File ยึดแนวตั้งในแนวนอน และจับคู่กับเมนูปัดขอบขวาด้วยนิ้วโป้ง 120Hz ที่มี 5 ช่องด่วนแบบเปิดค้างที่ปรับแต่งได้

5 โหมดอัตโนมัติ · 5 ช่องด่วน · คลิปบอร์ดเสมือน 15MB
02.6

แถบสัญลักษณ์ปัดขึ้น 21 ปุ่ม, 8 ธีม & ส่งออก PDF A4

สลับได้ 6 โปรไฟล์สัญลักษณ์ภาษา พร้อมการแตะและปัดขึ้นเพื่อเปิดแว่นขยาย รวมถึงโหมดล็อกเคอร์เซอร์ เขียนโค้ดใน 8 ธีมถนอมสายตา WCAG AAA (พร้อมโหมดกลางวัน/กลางคืนอัตโนมัติ) โหมด Zen หรือส่งออกเป็น PDF Monospace ขนาด A4 ที่คมชัด

03 ขั้นตอนการทำงาน

วิธีปรับแต่งและใช้งานเวิร์กสเปซ Editor ให้คล่องตัวสูงสุด

ตั้งค่าโฟลว์การเขียนโค้ดบนมือถือระดับเดสก์ท็อปในแบบของคุณได้ภายในไม่ถึง 2 นาที

STEP 01 Explorer / Smart Save

สร้างหรือเปิดไฟล์ซอร์สโค้ดใดก็ได้

เปิดหลายแท็บจากหน่วยความจำเครื่อง, SD/USB OTG, Git หรือ SFTP แม้แต่ไฟล์ร่างที่ยังไม่ตั้งชื่อก็ตรวจจับซินแทกซ์ภาษาและแนะนำนามสกุลที่ถูกต้องให้อัตโนมัติเมื่อใช้ Smart Save

STEP 02 21-Key Symbol Bar

พิมพ์เร็วขึ้นด้วยปุ่ม 2 ฟังก์ชันและ AST

แตะเพื่อแทรกเครื่องหมายคู่หรือครอบส่วนที่เลือก ปัดขึ้นบนปุ่มใดก็ได้เพื่อพิมพ์ตัวดำเนินการรอง (===, /**/, ลดย่อหน้า) และเรียกการเติมสมาชิก AST ใน 0ms

STEP 03 Format · Lint · Count

จัดรูปแบบโค้ด & ตรวจสอบ Error Radar

แตะ Format เพื่อจัดแนวการย่อหน้าให้สะอาดตา จากนั้นแตะ Count เพื่อตรวจพิกัด Error Radar แบบเรียลไทม์พร้อมสถิติ UTF-8 ของส่วนที่เลือกและทั้งเอกสาร

STEP 04 Right-Edge Swipe

ปัดจากขอบขวาเพื่อใช้ 5 ช่องคำสั่งด่วน

ลากจากขอบจอขวาเข้าด้านในด้วยมือเดียวเพื่อแตะ Undo/Redo/Theme/Wrap ซ้ำๆ ได้โดยไม่ต้องปิดเมนู สลับโหมด Zen หรือส่งออก PDF ขนาด A4

ลากแท็บ Editor แนวนอนเพื่อเรียงลำดับใหม่ · Hot Exit สำรองแท็บที่ยังไม่บันทึกอัตโนมัติ คู่มือแอป
