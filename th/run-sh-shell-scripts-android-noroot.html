02 ความสามารถหลัก

ทำไมแอปเทอร์มินัลทั่วไปถึงพังบน `/sdcard` — และ SuperCode แก้ปัญหานี้อย่างไร

เขียนสคริปต์ในโฟลเดอร์โปรเจกต์ที่เข้าถึงสะดวก ส่งแฟล็ก CLI ได้ง่าย และรันอย่างปลอดภัยโดยไม่ต้อง Root เครื่อง

02.1

ข้ามข้อจำกัด noexec ของ Shared Storage อย่างปลอดภัย (ไม่ต้อง Root)

Android เมานต์ /storage/emulated/0 และ Downloads ด้วย noexec ทำให้บล็อก chmod +x และ ./script.sh แต่ SuperCode เชื่อมการรันภายในแซนด์บ็อกซ์แบบไม่ใช้ Root พร้อมซิงก์ไฟล์ใน Workspace ของคุณอย่างไร้รอยต่อ

ไม่ต้อง Root · ใช้ได้ในโฟลเดอร์โปรเจกต์ทั่วไป
02.2

รองรับ set -euo pipefail, trap, getopts และ Arithmetic

เขียนสคริปต์อัตโนมัติระดับจริงจังด้วยแฟล็กคุม Error เข้มงวด (set -euo pipefail), ฮุกเคลียร์ค่า EXIT/ERR trap, ลูปแฟล็ก getopts, การคำนวณ (( count++ )), ฟังก์ชัน และเทมเพลต <<EOF heredoc

set -euo pipefail · trap · getopts · <<EOF
02.3

คำสั่งกำกับ CLI # @args และอินพุต read -p แบบโต้ตอบ

ทดสอบอาร์กิวเมนต์ตามตำแหน่ง ($1, $@) โดยไม่ต้องพิมพ์คำสั่งครอบซ้ำๆ เพียงเพิ่ม # @args --env prod ไว้บนหัวสคริปต์ และตอบพร้อมพ์ read -r -p สดได้ทันทีในคอนโซลแบ่งจอ

แฟล็ก # @args · read -p Stdin สด · 6 เทมเพลต
02.4

เชื่อมโยง source หลายไฟล์และจัดสรรจุดเริ่ม main.sh

แยกตัวแปร Log และ Config ที่ใช้ร่วมกันไว้ใน lib/common.sh ผ่านคำสั่ง source หรือ dot (.) เมื่อกดรันภายในไฟล์ตัวช่วย ระบบจะสลับไปรัน main.sh หรือ run.sh ให้อัตโนมัติ

source ./lib.sh · สลับรัน main.sh / run.sh อัตโนมัติ
02.5

วิเคราะห์ $LINENO แบบ 1:1 และปุ่มหยุดทั้ง Process Tree

Shell Syntax Error และบรรทัดที่ออกด้วยค่าไม่ใช่ศูนย์จะแมป 1:1 กลับไปยังไฟล์สคริปต์ที่เปิดอยู่ พร้อม Watchdog 120 วินาทีให้คุณสั่งหยุด Subshell ที่ค้างได้หมดจดในแตะเดียว

แมปบรรทัดแม่นยำ · หยุด Subshell ได้สะอาดหมดจด
02.6

ตัวจัดรูปแบบ Shell ออฟไลน์แตะเดียวและคำแนะนำ Expansion

จัดย่อหน้าบล็อก if/elif/fi, case/esac และ while/done ซ้อนกันอัตโนมัติแบบออฟไลน์ในแตะเดียว คู่กับคำแนะนำ AST ของ ${var:-default} Parameter Expansion และปุ่มสัญลักษณ์ | && >&2 ใช้งานไว

ตัวจัดรูปแบบ .sh ออฟไลน์ · ${var:-default} AST

03 ขั้นตอนการทำงาน

วิธีแก้ไขและรันสคริปต์ `.sh` บน Android โดยไม่ต้อง Root

เปลี่ยนจากไฟล์ `.sh` ที่เพิ่งดาวน์โหลดมาให้รันได้สะอาดหมดจดใน 4 แตะ

STEP 01 Open Folder / .sh

เปิดสคริปต์ `.sh` ใดก็ได้ใน Shared Storage หรือ Workspace

เปิดโฟลเดอร์ใน Downloads หรือ Documents — ไม่ต้องย้ายสคริปต์เข้าไปในไดเรกทอรีลับของแอปหรือรัน chmod

STEP 02 # @args + Format

จัดรูปแบบบล็อกและตั้งค่าอาร์กิวเมนต์ CLI เสริม

แตะ Format เพื่อจัดย่อหน้าให้เรียบร้อย และเพิ่มบรรทัดคอมเมนต์ `# @args` ได้ตามต้องการเพื่อส่งแฟล็ก `$1` / `getopts`

STEP 03 Toolbar -> Run ▶

รันออฟไลน์พร้อม read Stdin สดและการซิงก์ไฟล์

แตะรัน ▶ เพื่อประมวลผลทันที ตอบพร้อมพ์ `read` แบบโต้ตอบ และดูไฟล์ผลลัพธ์ซิงก์กลับเข้าตัวสำรวจไฟล์อัตโนมัติ

STEP 04 SFTP / Visual Git

Push สคริปต์ที่ทดสอบแล้วไปยังเซิร์ฟเวอร์ Linux หรือ Git

เมื่อทดสอบในเครื่องผ่านแล้ว ให้อัปโหลดผ่าน SFTP (คงสิทธิ์ 0755 Executable Bit ไว้) หรือ Commit ลงรีโพซิทอรีผ่าน Visual Git

รองรับ .sh · .bash · .zsh · .ksh · 6 เทมเพลต Shell เริ่มต้นในตัว คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

ตัวรัน `.sh` ไม่ต้อง Root ของ SuperCode เทียบกับวิธีเลี่ยงบนเทอร์มินัลทั่วไป

ตัวรันสคริปต์ Shell ของ SuperCode ช่วยรันสคริปต์ Linux .sh, .bash, .zsh และ .ksh บน Android โดยไม่ต้องใช้สิทธิ์ Root หรือเจอ Error Permission denied ใน Shared Storage พร้อมรองรับการซิงก์ $PWD ของโฟลเดอร์โปรเจกต์จริง, set -euo pipefail, getopts, read -p Stdin สด, การ source หลายสคริปต์ และการจัดรูปแบบออฟไลน์

เปรียบเทียบการรันสคริปต์ SHELL .SH บน ANDROID
ความต้องการใช้งาน Shell SuperCode .sh Studio CLI ดิบบน Shared Storage แอปรันสคริปต์ที่ต้อง Root Code Editor ทั่วไป
ต้อง Root หรือไม่? รันได้ 100% โดยไม่ต้อง Root ล้มเหลวด้วย Permission denied ต้องปลดล็อก/Root ระบบ OS รันไม่ได้
$PWD โฟลเดอร์แชร์ รันและซิงก์ตรงในโฟลเดอร์โปรเจกต์ ถูกบล็อกจากการเมานต์ noexec เสี่ยงต่อการเขียนทับทั้งระบบ แก้ไขได้อย่างเดียว
แฟล็ก CLI & Stdin คำสั่ง # @args + คอนโซล read -p สด ต้องพิมพ์คำสั่งเองทั้งหมด รันเบื้องหลังแบบสั่งแล้วปล่อย ไม่มี
โปรเจกต์หลายสคริปต์ source ./lib.sh + สลับรัน main.sh อัตโนมัติ ต้อง cd และระบุ Path เอง ได้แค่สคริปต์เดียว ไม่มี
การจัดรูปแบบสคริปต์ ตัวจัดรูปแบบ Shell ออฟไลน์แตะเดียว + AST แค่ข้อความดิบใน nano / vi ไม่มี แค่ไฮไลต์สี

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำถามพบบ่อยเกี่ยวกับการรันสคริปต์ `.sh` โดยไม่ต้อง Root และการแก้ `Permission denied` บน Android

ทำไมถึงขึ้น `Permission denied` เวลาพยายามรันไฟล์ `.sh` จากโฟลเดอร์ Downloads ของ Android?+
เพื่อความปลอดภัย Android จะเมานต์พื้นที่จัดเก็บข้อมูลร่วมของผู้ใช้ (`/sdcard`, `Downloads`, `Documents`) ด้วยแฟล็กไฟล์ระบบ `noexec` ดังนั้นแม้แต่ `chmod +x` ก็ไม่สามารถตั้งสิทธิ์ให้ไฟล์รันในนั้นได้ SuperCode จึงจัดการรันสคริปต์อย่างหมดจดในรันไทม์ Native พร้อมซิงก์โฟลเดอร์โปรเจกต์ของคุณอัตโนมัติ
SuperCode ต้องใช้เครื่อง Android ที่ Root แล้วในการรันสคริปต์ Shell ไหม?+
ไม่ต้องครับ SuperCode ใช้งานได้ทันทีบนมือถือ จอพับ และแท็บเล็ต Android 8.0+ ทั่วไปที่ไม่ได้ Root
จะส่งอาร์กิวเมนต์บรรทัดคำสั่งอย่าง `./deploy.sh --env staging` ได้อย่างไร?+
เพียงเพิ่ม `# @args --env staging` ไว้ด้านบนสคริปต์ (หรือป้อนค่าแบบโต้ตอบผ่าน `read -p`) แล้ว SuperCode จะส่งพารามิเตอร์ตามตำแหน่งเหล่านั้น (`$1`, `$2`, `$@`) เข้าสู่สคริปต์ของคุณโดยตรงเมื่อกดรัน
สคริปต์ `.sh` สามารถสร้างไฟล์หรือโฟลเดอร์ใหม่ภายใน Workspace ของฉันได้ไหม?+
ได้ครับ ไฟล์ บันทึก Log หรือไฟล์ Archive ใดๆ ที่ถูกสร้างขึ้นโดยอ้างอิงจาก `$PWD` ระหว่างการรันจะถูกซิงก์กลับเข้าสู่ไดเรกทอรีโปรเจกต์ Android ที่ใช้งานอยู่โดยอัตโนมัติ
