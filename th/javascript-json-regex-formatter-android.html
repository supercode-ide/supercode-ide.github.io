02 ความสามารถหลัก

เวิร์กเบนช์ JSON, Regex & JavaScript ที่เน้นความเป็นส่วนตัวเป็นอันดับแรก

เก็บ API Key ข้อมูล JSON จากระบบจริง และชุดทดสอบ Regex ไว้ในเครื่อง Android ของคุณ 100% ด้วยความเร็วระดับเดสก์ท็อปและไร้โฆษณาคั่นหน้าจอโค้ด

02.1

จัดรูปแบบ JSON, JSONC & JS อัตโนมัติด้วย Lexer

ขยายไฟล์ JSON หรือ JSONC ที่ถูกบีบอัดเป็นบรรทัดเดียว (โดยยังคงคอมเมนต์ // และ /* */ ไว้ครบ) ได้ในแตะเดียว พร้อมระบุคอมมาเกินหรือวงเล็บผิดรูปผ่าน Error Radar

JSON · JSONC · ตัวจัดรูปแบบ ES2024 · เลิกทำใน 1 ขั้นตอน
02.2

ทดสอบ ES2024 RegExp (ดัชนี /d, เซต /v, Lookbehind)

ทดสอบ Named Capture Group, ตัววนซ้ำ matchAll(), Unicode Property Escapes \\p{...} และดัชนีจับคู่ /d ในเครื่องได้ในเสี้ยววินาที โดยไม่เสี่ยงแอปค้างจาก Catastrophic Backtracking

Named Groups · แฟล็ก /d /v · ป้องกันด้วย Worker
02.3

Top-Level Await fetch() & URLSearchParams แบบเรียลไทม์

เขียนสคริปต์ทดสอบ REST API อย่างรวดเร็วด้วยมาตรฐาน Fetch, Headers, AbortController และ URL/URLSearchParams จากนั้นแปลงข้อมูลและจัดรูปแบบผลลัพธ์บันทึกลงดิสก์โดยตรงผ่าน node:fs

fetch() · AbortController · บันทึกด้วย node:fs
02.4

เวิร์กโฟลว์ console.table() & JSON Diff แบบมีโครงสร้าง

แสดงผลอาร์เรย์ของออบเจกต์ API ที่ซ้อนกันเป็นตาราง ASCII ที่อ่านง่าย กรองข้อมูลด้วย Array.prototype.groupBy / Object.groupBy และส่งออกเป็น CSV หรือ JSON Snapshot

console.table() · Object.groupBy · CSV/JSON
02.5

จัดการไฟล์ JSON ขนาดหลายร้อย MB ด้วย GB Stream Pager

เจอไฟล์ Log NDJSON หรือไฟล์ส่งออก API ขนาด 400 MB ใช่ไหม? GB Pager ที่อ่านตรงจากดิสก์ของ SuperCode เปิดได้ลื่นไหลระดับ 120Hz พร้อมรัน Global Stream Regex Replace ทั่วทั้งไฟล์โดยไม่เกิด OOM

GB Pager · แทนที่ด้วย Regex แบบสตรีมทั้งไฟล์
02.6

จัดรูปแบบที่ปลอดภัยต่อ Template Literal & แถบสัญลักษณ์ JS 21 ปุ่ม

ป้อน =>, ${}, ?., ?? และ Backtick ได้ในการปัดเดียว โดย CodeFormatEngine จะปกป้องนิพจน์ ${...} ที่ซ้อนกันภายในสตริง JavaScript ได้อย่างแม่นยำ

ตัวจัดรูปแบบปลอดภัยต่อ ${...} · แถบ JS 21 ปุ่ม
ออกแบบเพื่อมือถือ จอพับ และแท็บเล็ต · ขนาดเบา 40.2 MB ฮับ JavaScript & Node IDE
03 ขั้นตอนการทำงาน

ตรวจสอบ แปลงข้อมูล & ส่งออกสคริปต์ JSON/API ใน 4 ขั้นตอน

จัดรูปแบบ Payload ตรวจสอบแพตเทิร์น Regex และเขียนสคริปต์แปลงข้อมูล Node/JS ที่นำกลับมาใช้ใหม่ได้แบบออฟไลน์

STEP 01 Paste JSON/JSONC

เปิดหรือวางไฟล์ JSON / JSONC ที่ถูกบีบอัดไว้

โหลดไฟล์ส่งออก API จาก Downloads หรือพื้นที่จัดเก็บ SAF โดยไฟล์ขนาดเกิน 30 MB จะสตรีมอัตโนมัติแบบไร้การกระตุก

STEP 02 1-Tap Format

แตะ Format เพื่อจัดรูปแบบ & ตรวจสอบ Syntax ในเครื่อง

CodeFormatEngine จะจัดย่อหน้าออบเจกต์ที่ซ้อนกันอย่างเป็นระเบียบ ขณะที่ Error Radar ชี้ตำแหน่ง Syntax Error ตามบรรทัดและคอลัมน์อย่างแม่นยำ

STEP 03 matchAll() /d

รัน ES2024 Regex & สคริปต์แปลงข้อมูลใน Worker

เขียนสคริปต์ .mjs สั้นกระชับด้วย matchAll(), Object.groupBy() และ console.table() ที่ได้รับการปกป้องด้วยตัวตัด Loop ระดับ <1ms

STEP 04 fs.writeFile()

บันทึกผลลัพธ์ที่จัดระเบียบแล้วลง Workspace โดยตรง

บันทึกไฟล์ JSON, NDJSON หรือ CSV ที่จัดรูปแบบแล้วผ่าน node:fs/promises และแชร์หรือ Push ผ่าน Visual Git

ความเป็นส่วนตัวในเครื่อง 100% · ตัวจัดรูปแบบ Lexer JSON/JSONC · แซนด์บ็อกซ์ Worker ES2024 คู่มือแอป

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำตอบเกี่ยวกับการตรวจสอบ JSON/JSONC แบบออฟไลน์ การทดสอบ ES2024 Regex ไฟล์ Log JSON ขนาดใหญ่ และการเขียนสคริปต์ API

ปลอดภัยไหมหากใช้ SuperCode จัดรูปแบบ JSON ของระบบจริงหรือค่าคอนฟิก API ที่เป็นความลับ?+
ปลอดภัยแน่นอน ทั้งตัวจัดรูปแบบ JSON/JSONC และ Worker ของ JavaScript ES2024 ใน SuperCode ทำงานในเครื่อง Android ของคุณ 100% ข้อมูล JSON ของคุณจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ภายนอกเลย
ตัวจัดรูปแบบรองรับไฟล์ JSONC ที่มีคอมเมนต์ // เช่น tsconfig.json หรือ settings.json หรือไม่?+
รองรับ CodeFormatEngine รู้จักคอมเมนต์แบบ JSONC ควบคู่กับ JSON มาตรฐาน สามารถจัดย่อหน้าออบเจกต์และอาร์เรย์ซ้อนกันได้อย่างสวยงามโดยไม่ลบคอมเมนต์ของคุณทิ้ง
จะเกิดอะไรขึ้นหาก Regex ที่ซับซ้อนเกิด Catastrophic Backtracking ระหว่างทดสอบ?+
สคริปต์ JavaScript Regex ทั้งหมดทำงานภายใน Worker Thread ที่แยกออกจาก UI คุณจึงสั่งหยุด Regex ที่ช้าหรือทำงานวนไม่รู้จบได้ทันทีโดยไม่ทำให้หน้าจอแก้ไขโค้ดค้าง
SuperCode เปิดและค้นหาไฟล์ Log JSON หรือ NDJSON ขนาด 500 MB บนมือถือได้หรือไม่?+
ได้ ไฟล์ที่ใหญ่กว่า 30 MB จะสลับไปใช้ GB Streaming Pager ที่อ่านตรงจากดิสก์ของ SuperCode โดยอัตโนมัติ พร้อมการเลื่อนหน้าจอ 120Hz และ Global Stream Regex Replace
