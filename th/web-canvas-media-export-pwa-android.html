02 ความสามารถหลัก

API สื่อและพื้นที่จัดเก็บระดับเบราว์เซอร์จริงภายในหน้าตัวอย่างบนมือถือ

สร้างต้นแบบเครื่องมือครีเอทีฟโค้ดดิง เกม Canvas/WebGL เครื่องมือเสียง และเว็บแอปแบบ Offline-First ที่ทำงานได้เหมือน Chrome บนเดสก์ท็อปบนมือถือ Android ของคุณ

02.1

รองรับ showSaveFilePicker, showOpenFilePicker & Share API ในเครื่อง

การแทรก JS ตั้งแต่เริ่มโหลดเอกสารช่วยเชื่อม File System Access API สมัยใหม่ การสตรีม Blob/DataURL และ navigator.share เข้ากับระบบไฟล์และหน้าต่างแชร์ของ Android โดยตรงแบบไร้ Race Condition

showSaveFilePicker · สตรีม Blob · navigator.share
02.2

ตรวจสอบ Magic-Byte & ส่งออกสู่ Android MediaStore แบบ Atomic

ตรวจสอบ Header ไบนารีที่แท้จริงเพื่อให้ PNG, WebP, MP4 และ MP3 ไม่บันทึกผิดนามสกุล พร้อมจัดเส้นทางแบบ Atomic ผ่านการล็อก IS_PENDING ไปยัง Pictures/, Movies/, Music/ หรือ Download/SuperCode

ตัวตรวจ Magic-Byte · MediaStore แบบ Atomic
02.3

ซ่อมระยะเวลา WebM EBML & SeekHead แบบไม่สูญเสียคุณภาพ

ไฟล์ที่ส่งออกจาก HTML5 Canvas MediaRecorder มักขาด Header ระยะเวลาในแกลเลอรี Android ตัวซ่อม EBML ที่เขียนด้วย Kotlin ล้วนของ SuperCode จะแทรก SeekHead, Duration และ Cues โดยไม่ต้องเข้ารหัสใหม่

WebM SeekHead + Cues · เลื่อนไทม์ไลน์ลื่นไหล
02.4

ตัวแปลงวิดีโอเป็นเสียงในตัว (MP3 + 6 รูปแบบ)

สร้างเครื่องมือจัดการสื่อบนเบราว์เซอร์ที่ขับเคลื่อนด้วยสะพานเชื่อม Android MediaCodec + PureMp3Encoder ขนาดเบาของ SuperCode — แปลง MP4/MKV/WebM เป็น MP3 คุณภาพ SNR สูงพร้อมแท็ก ID3v2.4 แบบออฟไลน์

MediaCodec + PureMp3Encoder · ID3v2.4
02.5

Local HTTP Origin จริงสำหรับ IndexedDB, WebGL & HTTP 206

เพราะหน้าเว็บโหลดจากเซิร์ฟเวอร์ HTTP ในเครื่องจริง (ไม่ใช่ file://) จึงใช้งาน ES Modules, localStorage, IndexedDB, WebGL Shaders, เว็บฟอนต์ (.woff2) และการเลื่อนช่วงเวลาวิดีโอ/เสียงผ่าน HTTP 206 ได้อย่างสมบูรณ์

Local Origin จริง · เลื่อนช่วงเวลา HTTP 206
02.6

แปลง HEIC อัตโนมัติ, แก้ทิศทาง EXIF & จับภาพ PNG เต็มหน้าเว็บ

แทรกรูปภาพผ่าน Camera FileProvider แบบไม่ต้องขอสิทธิ์พิเศษ พร้อมแปลง HEIC และแก้ไขทิศทาง EXIF อัตโนมัติ หรือจับภาพม็อกอัป PNG เต็มหน้าเว็บคมชัดสูงสุด 2560px

แก้ EXIF อัตโนมัติ · ภาพหน้าจอ PNG 2560px
ออกแบบเพื่อมือถือ จอพับ และแท็บเล็ต · ขนาดเบา 40.2 MB ฮับ Web, PHP 8.2 & WASM
03 ขั้นตอนการทำงาน

สร้าง & ส่งออกเว็บแอปสื่อ HTML5 ที่สมบูรณ์ใน 4 ขั้นตอน

เขียนด้วย Web API มาตรฐานสมัยใหม่ — WebMediaBridge ของ SuperCode จะจัดการพื้นที่เก็บข้อมูลและ Codec ของ Android ให้อย่างราบรื่น

STEP 01 Real HTTP Origin

พัฒนา Canvas, WebGL หรือ WebApp บน Local HTTP

เสิร์ฟ HTML5, CSS3, ES Modules และไฟล์ Asset บน Local HTTP Origin จริงของ SuperCode พร้อม localStorage & IndexedDB เต็มรูปแบบ

STEP 02 WebMediaBridge

ใช้ Blob, MediaRecorder หรือ File Picker API มาตรฐาน

เรียกใช้ showSaveFilePicker(), a[download] หรือ navigator.share() ได้เหมือนกับที่เขียนบน Chrome เดสก์ท็อป

STEP 03 EBML SeekHead Fix

ตรวจสอบ Magic-Byte & ซ่อม EBML อัตโนมัติ

SuperCode ตรวจสอบลายเซ็นไบนารี ซ่อมข้อมูลระยะเวลาและ Seek Cues ของ WebM แบบไม่สูญเสียคุณภาพ และสตรีมบัฟเฟอร์ขนาดใหญ่อย่างปลอดภัย

STEP 04 MediaStore Save

บันทึกลงแกลเลอรี Android หรือ Downloads แบบ Atomic

ไฟล์ PNG, WebM, MP3 และ JSON ที่ส่งออกจะปรากฏในแอประบบทันทีโดยไม่มีไฟล์ค้างที่เขียนไม่สมบูรณ์

WebMediaBridge V10 · ซ่อม WebM แบบ Lossless · Local HTTP Origin จริง คู่มือแอป
04 ตารางเปรียบเทียบความสามารถ

SuperCode Web Studio เทียบกับตัวแสดงผล WebView ทั่วไปบน Android

HTML5 Canvas & WebMediaBridge Studio ของ SuperCode ยกระดับการพรีวิวเว็บบนมือถือ Android ด้วย Local HTTP Origin จริง, Polyfill สำหรับ showSaveFilePicker / navigator.share, การตรวจสอบไฟล์ด้วย Magic-Byte, การซ่อม WebM SeekHead/Cues แบบ Lossless และการส่งออกผ่าน MediaStore แบบ Atomic

ตารางความสามารถด้านเว็บมีเดีย พื้นที่เก็บข้อมูล & การส่งออกของ SUPERCODE
Web API / ความสามารถ SuperCode Web Studio ตัวพรีวิว file:// พื้นฐาน การเชื่อมต่อกับ Android เหมาะสำหรับงานใด
บันทึก & เปิดไฟล์ showSaveFilePicker + สตรีม Blob ใช้งานไม่ได้ / ถูกข้าม MediaStore แบบ Atomic + SAF แอป Canvas / PDF / เครื่องมือต่างๆ
ส่งออกวิดีโอ Canvas MediaRecorder + ซ่อม EBML Cues ขึ้น 0:00 เลื่อนเวลาไม่ได้ แกลเลอรี Movies/SuperCode Generative Art & เดโมต่างๆ
แปลงไฟล์เสียง MediaCodec ในตัว + สะพานเชื่อม MP3 ต้องใช้ WASM ขนาดหนัก Music/SuperCode + ID3v2.4 เครื่องมือจัดการสื่อแบบออฟไลน์
พื้นที่เก็บข้อมูล & โมดูล IndexedDB + localStorage + ESM ถูกบล็อกโดย CORS / null Local Origin แบบถาวร PWAs แบบ Offline-First
การเล่นวิดีโอ/เสียง HTTP 206 Partial Content เลื่อนช่วงเวลาเล่นสื่อไม่ได้ สตรีมไบต์แบบ Zero-Copy ตัวเล่นสื่อ & เกม HTML5

05 คำถามและคำตอบ

คำถามที่พบบ่อย

คำตอบเกี่ยวกับการส่งออก HTML5 Canvas การซ่อมระยะเวลา WebM Polyfill ตัวเลือกไฟล์ และ IndexedDB บน Android

การดาวน์โหลด Blob และ showSaveFilePicker() ใช้งานได้จริงในหน้าพรีวิวเว็บของ SuperCode หรือไม่?+
ใช้งานได้จริง SuperCode แทรก WebMediaBridge แบบไร้ Race Condition ตั้งแต่เริ่มโหลดเอกสาร เพื่อเชื่อมการดาวน์โหลด Blob/DataURL, showSaveFilePicker, showOpenFilePicker และ navigator.share เข้ากับระบบไฟล์ของ Android โดยตรง
ทำไมวิดีโอ WebM จาก Canvas MediaRecorder ที่ส่งออกจาก SuperCode จึงแสดงแถบเวลาและเลื่อนเล่นได้แม่นยำ?+
SuperCode จะรันขั้นตอนซ่อม EBML SeekHead, Duration และ Cues ที่เขียนด้วย Kotlin ล้วนแบบไม่สูญเสียคุณภาพก่อนบันทึกลง MediaStore เพื่อแก้ไข Metadata ระยะเวลาที่ขาดหายไปใน Chrome/WebView โดยไม่ต้องเข้ารหัสใหม่
สามารถสร้างเกม HTML5 Canvas 2D และ WebGL แบบออฟไลน์ใน SuperCode ได้ไหม?+
ได้ เซิร์ฟเวอร์ Local HTTP จริงรองรับ ES Modules, เทกซ์เจอร์, ไฟล์เสียง, การเลื่อนช่วงเวลาผ่าน HTTP 206, การบันทึกคะแนนใน localStorage และการตรวจจับ Error ผ่าน DevTools Console แบบออฟไลน์ทั้งหมด
ไฟล์รูปภาพ วิดีโอ และเสียงที่เว็บแอปส่งออกจะถูกเก็บไว้ที่ไหน?+
SuperCode ตรวจสอบประเภทไฟล์ที่แท้จริงด้วย Magic-Byte Sniffer แล้วบันทึกแบบ Atomic ผ่าน Android MediaStore ลงใน Pictures/SuperCode, Movies/SuperCode, Music/SuperCode หรือ Download/SuperCode
