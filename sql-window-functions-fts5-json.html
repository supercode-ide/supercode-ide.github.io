05 QUESTIONS & ANSWERS

Frequently Asked Questions

Common questions from SQL learners, data science students, and backend interview candidates.

Can I practice LeetCode-style SQL Window Function problems (`DENSE_RANK`, `LAG`, rolling sums) offline?+
Yes! Every standard SQL window function (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`) and `ROWS`/`RANGE`/`GROUPS` frame specification works 100% offline.
Does SuperCode support `MEDIAN()`, `PERCENTILE()`, and `STDDEV()` directly in SQL?+
Yes. While vanilla SQLite lacks statistical aggregates, SuperCode pre-registers native `MEDIAN(col)`, `PERCENTILE(col, 95)`, and `STDDEV(col)` functions so data analysts can compute distributions in a single `SELECT`.
How does `READ_STDIN()` work inside a `.sql` query?+
Write `WHERE department = READ_STDIN('Department name: ')` inside your `.sql` file and tap Run — SuperCode prompts you interactively in the docked console so you can re-run parameterized queries without editing code.
Are FTS5 full-text search and R*Tree / Geopoly spatial modules enabled?+
Yes. Both `USING fts5(...)` (including `bm25()`, `highlight()`, and `snippet()`) and `USING rtree(...)` / Geopoly spatial extensions are compiled directly into SuperCode's offline SQLite 3.54.1 engine.
