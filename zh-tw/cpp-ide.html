05 常見問答

常見問題

關於 C++20 支援、STL 競程刷題、多檔案標頭檔與離線使用的常見解答。

SuperCode 可以在沒有網路的情況下離線編譯 C++20 與 STL 容器嗎？+
可以。首次使用完成離線 C++ 工具鏈套件初始化後，GNU C++20 (-std=gnu++2a) 與完整 STL（vector、map、priority_queue、ranges、智慧指標、lambda）即可 100% 離線編譯與執行。
SuperCode 適合在手機或平板上用來打競程（Codeforces、LeetCode、資訊奧賽）嗎？+
非常適合。支援增量快取極速編譯、即時多行 std::cin 輸入、毫秒與 KB 級執行遙測，加上 55%/45% 橫向分割畫面，讓您隨時隨地高效練題。
多檔案 .cpp 與 .hpp 專案是如何運作的？+
只需將 .hpp 與 .cpp 檔案放在同一專案資料夾（或開啟的分頁）中。SuperCode 會自動探索本機 include、連結所有實作檔，甚至在您從標頭檔分頁點擊執行時自動找到 main()。
我可以使用 C++ <thread> 或網路通訊 API 嗎？+
可以。當偵測到作業系統層級的執行緒或 socket 標頭檔時，SuperCode 會自動透過支援 -pthread 的雲端 C++ 叢集編譯您的多檔案專案。
