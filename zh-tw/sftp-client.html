02 核心能力

企業級遠端連線安全與零損毀檔案工程

專為不穩定的行動網路設計——一般 FTP 編輯器在 5G 或 Wi-Fi 斷訊瞬間，極易將正式環境設定檔截斷成 0 位元組。

02.1

全面支援 4 種協定：SFTP、FTPS 顯式、FTPS 隱式與 FTP

支援 SSH SFTP（Port 22）、採用加密被動資料通道（PBSZ 0 + PROT P）的顯式 FTPS over TLS 1.2/1.3、隱式 FTPS（Port 990）以及 UTF-8 被動 FTP（Port 21）。

SFTP (22) · FTPS TLS 1.3 (21) · FTPS (990) · FTP
02.2

SSH 私鑰選擇器、AES-256 保險庫與 TOFU 防護

匯入 OpenSSH、PEM、RSA、Ed25519 或 ECDSA 金鑰（.pem、.key、id_rsa、id_ed25519）與密碼短語。所有機密資料皆透過 Android KeyStore AES-256-GCM 加密，並受 SHA256 主機金鑰異常警示保護。

Ed25519 / RSA / PEM · AES-256-GCM · MITM 主機防護
02.3

三階段原子遠端存檔（杜絕 0 位元組損毀）

開啟遠端檔案時會建立持久的本機鏡像分頁（☁️）。按下存檔即會上傳暫存檔、透過 STAT/SIZE 驗證遠端精確位元組大小，並以原子重新命名覆蓋目標檔案，同時保留 POSIX 權限！

暫存上傳 -> 大小驗證 -> 原子更名 + chmod
02.4

即時交握測試主控台與自我修復連線池

儲存伺服器前可先在內嵌診斷主控台驗證 TCP、TLS/SSH 交握與金鑰認證。三通道連線池會在 Wi-Fi/5G 切換後自動修復失效的 Socket。

⚡ 測試交握 · 三通道自我修復連線池
02.5

4 串流傳輸佇列與精確位元組續傳

透過 4 個平行串流上傳或下載整個目錄樹，並配備 20fps MB/s 即時進度面板。中斷的大型傳輸可透過 SFTP RESUME 或 FTP REST 從精確的位元組偏移量續傳！

4 平行串流 · 即時 MB/s · 位元組斷點續傳
02.6

遠端模糊搜尋與即時遠端網頁預覽

跨遠端伺服器資料夾搜尋檔名，支援 34 種字元編碼重新載入遠端分頁；對遠端 HTML/PHP 檔案按下「執行」，即可在編輯前後即時預覽伺服器頁面。

03 逐步操作流程

如何從 Android 連線並安全編輯線上伺服器

在硬體加密保險庫設定一次，即可隨時隨地於數秒內部署緊急修復。

STEP 01 Explorer -> Remote Servers -> +

選擇通訊協定並輸入密碼或匯入 SSH 金鑰

選擇 SFTP、FTPS（TLS）、FTPS（990）或 FTP，填入主機與使用者名稱，接著輸入密碼或挑選您的 .pem / id_ed25519 私鑰檔案。

STEP 02 ⚡ Test Handshake -> Save

驗證交握診斷並信任主機指紋

點擊「測試交握」即時確認 TCP/TLS/SSH 驗證流程，核對伺服器的 SHA256 主機指紋後，將連線資料存入 AES-256 保險庫。

STEP 03 Mount -> Tap Remote File

瀏覽遠端檔案樹並以完整 AST 與格式化進行編輯

直接在編輯器分頁開啟 Nginx 設定檔、Python/PHP 後端程式或 Shell 腳本，享有 AST 自動補全、錯誤雷達與一鍵格式化功能。

STEP 04 Save / Batch Upload

原子寫入存檔或具備衝突控制的資料夾同步

點擊「儲存」執行三階段原子部署，或多選資料夾進行上傳/下載，並可自由選擇覆蓋、位元組斷點續傳、兩者皆保留或略過等衝突處理策略。

保留遠端 Linux POSIX 檔案權限 · 離線重啟 App 仍完整保留設定 使用指南

05 常見問答

常見問題

關於 SSH 私鑰（.pem / Ed25519）、FTPS TLS 1.3、防止遠端存檔損毀與大型檔案續傳的常見解答。

AWS EC2、DigitalOcean 或 Linux VPS 伺服器支援哪些 SSH 私鑰格式？+
SuperCode 支援 OpenSSH、PEM（.pem）、RSA（id_rsa）、Ed25519（id_ed25519）與 ECDSA 私鑰（含或不含密碼短語皆可），並內建快速跳轉選擇器方便瀏覽「下載」與 .ssh 資料夾。
若存檔時行動網路斷訊，SuperCode 如何防止伺服器上的檔案變成 0 位元組毀損檔？+
每次遠端分頁存檔皆採用「三階段原子交易」：先上傳至暫存檔，透過 STAT/SIZE 向伺服器查詢並驗證接收的位元組數完全一致後，才以原子重新命名方式覆蓋目標檔案，同時完整保留 Linux 檔案權限。
除了 SSH SFTP 之外，SuperCode 是否也支援 FTPS（基於 SSL/TLS 的 FTP）？+
支援！原生支援顯式 FTPS（Port 21 上的 AUTH TLS 1.2/1.3 搭配加密 PROT P 被動資料通道）、隱式 FTPS（Port 990），以及標準 UTF-8 被動模式 FTP。
若大型備份檔下載或上傳中途斷線，可以接續傳輸嗎？+
可以。當偵測到遠端或本機已有部分傳輸完成的檔案時，SuperCode 會自動比對已完成大小並提供「一鍵從斷點續傳」，精確從該位元組偏移量接續傳輸，無需重傳已完成的資料。

從 Android 安全管理正式環境 VPS 與網頁主機。

在 Google Play 安裝 SuperCode IDE，享有 AES-256 SFTP/FTPS 編輯、SSH 金鑰驗證與三階段原子部署體驗。
