03 逐步操作流程

如何在 Android 上建立 Java + SQLite JDBC 專案

幾秒內從空白目錄完成持久化 JDBC 資料庫與視覺化 SQL 檢視循環。

STEP 01 import java.sql.*;

透過 DriverManager.getConnection("jdbc:sqlite:...") 連線

開啟任一 .java 檔並連線至相對路徑資料庫檔名（例如 jdbc:sqlite:store.db）— 驅動程式會自動離線載入。

STEP 02 PreparedStatement

執行 DDL、參數化新增與關聯查詢

離線執行 CREATE TABLE、批次 INSERT 與 SELECT JOIN，或透過 Files.readAllLines() 讀取同目錄的 .csv 種子資料檔。

STEP 03 Explorer -> store.db

在 SQL Studio 檢視產生的 .db 檔案

在檔案總管點擊同步好的 store.db 檔案即可瀏覽資料表、執行即時 SQL 查詢，或將結果匯出為 Markdown/CSV。

STEP 04 Visual Git / Export

在編輯器內核對匯出的 CSV/JSON 檔、將原始碼列印為 A4 PDF，或使用視覺化 Git 提交整個多類別 DAO 儲存庫。

05 常見問答

常見問題

關於 Android 上 JDBC 連線字串、持久化 `.db` 檔案、NIO.2 路徑與 `HttpClient` 的常見問題。

在 Java 中使用 SQLite 需要寫 `Class.forName("org.sqlite.JDBC")` 或加 Maven 相依性嗎？+
不需要！SuperCode 已開箱內建並自動註冊 `org.sqlite.JDBC`。只要匯入 `java.sql.*` 並呼叫 `DriverManager.getConnection("jdbc:sqlite:mydb.db")` — 立即就能 100% 離線運作。
Java 程式寫出的 `.db`、`.csv` 與 `.txt` 檔案會儲存在哪裡？+
像 `jdbc:sqlite:inventory.db` 或 `Path.of("report.csv")` 這類相對路徑會直接解析至目前開啟的專案資料夾，並在執行結束後立即同步回你的 Android 工作區。
我可以先在 SuperCode 的 SQL Studio 建好 SQLite 資料庫資料，再從 Java 查詢嗎？+
可以！這正是 SuperCode 最受歡迎的工作流程之一：先在 SQL Studio 建立資料表並寫入初始資料（`schema.sql` -> `app.db`），再於同一資料夾開啟你的 `.java` DAO 類別無縫查詢 `jdbc:sqlite:app.db`。
`java.net.http.HttpClient` 可以用來測試 REST API 嗎？+
可以。當裝置連網時，標準 Java 11/17 的 `HttpClient`、`HttpRequest` 與 `HttpResponse` 皆可開箱即用地發送 HTTPS REST 請求；而 JDBC 與 NIO.2 檔案操作則全程支援離線執行。
