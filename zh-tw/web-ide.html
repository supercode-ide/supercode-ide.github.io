02 核心能力

Android 上六層連貫的現代 Web 工程架構

整合前端 ES 模組、二進位 WebAssembly、後端 PHP Session、關聯式 SQL 資料庫、DevTools 檢測與遠端 SFTP 部署，一站搞定。

02.1

支援 HTML5、CSS3、JS & WASM 的真實本機 HTTP Origin

透過真實本機 HTTP/1.1 Origin 提供專案服務，取代受限的 file:// 網址 — 全面解鎖 fetch()、<script type="module">、WebAssembly.instantiateStreaming() (.wasm)、WebGL .glb/.gltf 資源、IndexedDB 及 HTTP 206 影音拖曳串流。

65+ 種 MIME 類型 · ES Modules · application/wasm · HTTP 206
02.2

100% 離線動態 PHP 後端引擎

完全離線執行多頁 .php 範本、OOP 類別、閉包、match 與 include/require，完整支援 $_GET、$_POST、持久化 $_SESSION、$_FILES 上傳、JSON REST 標頭及 password_hash()。

$_GET / $_POST / $_SESSION · JSON API · 離線 PHP
02.3

透過 PDO & SQLite3 整合 SQL 資料庫

使用 new PDO('sqlite:app.db') 或 SQLite3 離線打造資料驅動的 PHP 應用，支援預處理陳述式（? 與 :named 參數綁定）、ACID 交易，並可在 SQL IDE 即時檢視資料表。

PDO('sqlite:...') · 預處理陳述式 · ACID 交易
02.4

懸浮 DevTools 主控台、網路紀錄 & JS REPL

即時檢視 HTTP 請求（GET /api.php -> 200 · 3ms · 1.2 KB）、篩選 All / Error / Warn / Net 紀錄、瀏覽結構化 DOM/物件樹，並在 > Run JavaScript... REPL 即時運算表達式。

網路耗時 · 錯誤徽章 · 互動式 JS REPL
02.5

3 模式視口切換器 & 2560px 頁面擷取

透過可拖曳動態島即時切換手機、平板 (768dp) 與桌機版面，測試相機/相簿 <input type="file"> 上傳功能，並匯出高解析 2560px PNG 螢幕截圖。

03 逐步操作流程

如何在 Android 上建置、除錯與部署全端網站

從本機 HTML/CSS/WASM 與 PHP+SQL 原型開發，一路延伸至線上伺服器部署。

STEP 01 index.html / index.php

撰寫 HTML5、CSS3、JS、WASM & PHP 檔案

編輯多檔案網頁專案，享有 AST HTML/CSS/JS/PHP 自動補全，以及可連同內嵌 <script> 與 <style> 區塊一併縮排的一鍵遞迴格式化。

STEP 02 PDO + app.db

將離線 PHP 表單與 API 連接至 SQL

透過 PHP 的 PDO 預處理陳述式查詢本機 .db SQLite 資料庫，或直接在 SuperCode 的 SQL Studio 中建立資料表初始資料。

STEP 03 Run ▶ -> Dynamic Island

跨手機、平板與桌機預覽 + DevTools

隨時切換裝置視口，在可調大小的 DevTools 抽屜中查看網路狀態與 JS 錯誤，或在 JS REPL 即時測試 DOM 調整。

STEP 04 SFTP / Visual Git

直接發佈更新至主機或 GitHub Pages

透過視覺化 Git 將靜態/WASM 建置推送至 GitHub Pages，或經由 SFTP/FTPS 直接部署 PHP 與網頁資源至您的 VPS。

05 常見問答

常見問題

關於離線 PHP + SQLite、ES Modules / fetch() / WASM、網頁 DevTools 及 FTP/SFTP 部署的常見問題。

我可以在 Android 上離線執行動態 PHP 網站並連線至 SQL 資料庫嗎？+
可以！SuperCode 支援完全離線執行 .php 頁面、REST JSON 端點、Session、表單上傳及多檔案 include，並內建 PDO('sqlite:...') 與 SQLite3 資料庫支援。
是否支援 ES6 模組（<script type="module">）、fetch() 與 WebAssembly (.wasm)？+
支援。SuperCode 透過支援 65 種以上 MIME 類型（含 application/wasm）的真實本機 HTTP 伺服器提供專案服務，因此 fetch()、ES 模組、WebGL 3D 模型及 WebAssembly.instantiateStreaming() 皆可開箱即用。
如何在手機上除錯 JavaScript 錯誤、網路請求與桌機版面配置？+
在預覽模式點擊可拖曳的動態島膠囊，即可切換手機、平板 (768dp) 與桌機視口；或開啟可調整大小的網頁 DevTools 抽屜來篩選 Error/Warn/Net 紀錄，並在 REPL 即時執行 JavaScript。
我可以預覽並更新託管於遠端 FTP 或 SFTP 伺服器的網站嗎？+
可以。在 SFTP/FTPS/FTP 工作區掛載伺服器後，即可直接編輯遠端 HTML/CSS/JS/PHP 標籤頁並以三階段原子儲存寫回，點擊「執行」即可搭配隨需資源快取預覽遠端頁面。
