05 常見問答

常見問題

關於離線編譯器、大檔處理、支援語言與 Git/SFTP 工作流程的常見解答。

SuperCode IDE 可在 Android 上離線執行哪些程式語言？+
SuperCode 可在 Android 本機離線執行 Python（3.11 與科學運算 3.12）、C（GNU C17）、C++（GNU C++20）、Java 17、JavaScript（ES2024）、SQL、PHP、HTML5/CSS3/WebAssembly、Lua 5.4 與 Linux Shell 腳本，並可選用雲端支援執行 Kotlin、MySQL 8.0 及大型伺服器框架。
SuperCode 開啟 GB 級 Log 檔與 SQL 傾印檔時不會卡頓嗎？+
沒錯。超過 30 MB 的檔案會自動啟用 GB 級串流分頁器，將數百 MB 乃至 GB 級大檔切分為 1000 萬字元磁碟分頁，支援瞬間跳頁、34 種字元集偵測與全域串流正規表達式取代。
C 與 C++、或 SQL 與 Web/PHP 是各自獨立的專用環境嗎？+
是的。C17 與 C++20 各有專屬標準庫、標頭檔與範本；SQL 擁有獨立的 9 模式主控台與 .db 二進位檢視器；Web 工作室則運行真實本機 HTTP + PHP + PDO SQLite + WebAssembly 預覽伺服器並內建 DevTools。
SuperCode 是否內建 Git 用戶端與 SFTP/FTPS 遠端編輯器？+
是的。內建獨立視覺化 Git 用戶端（支援 PAT 複製儲存庫、分支管理、提交時光機統一差異檢視與合併衝突解決器），以及採用 AES-256 加密與 3 階段原子遠端存檔的 SFTP、FTPS（TLS 1.3）及 FTP 工作區。
SuperCode 是否針對 Android 手機與平板雙重最佳化？+
是的。在手機上，工具列置於單手拇指可及之處，並搭配右側滑動選單與自動收合分割主控台；在摺疊機與平板上，工具列改為垂直停靠，終端機則以 55% / 45% 左右雙欄工作站開啟。
