03 逐步操作流程

逐步指南：如何在 SuperCode 使用 PIP 與離線 Wheel

不到 30 秒即可線上安裝 PyPI 套件或離線側載 .whl 檔案。

STEP 01 Python Console -> PIP Icon

開啟視覺化 PIP 套件管理員

開啟任一 .py 檔案並點選 Python 主控台頂端列的 PIP 圖示 — 或直接執行含有未安裝匯入項目的腳本以觸發 Auto-PIP。

STEP 02 Quick Chips / Input Box

點選熱門標籤、貼上 pip install 或選擇 requirements.txt

點選一鍵常用標籤（requests、rich、beautifulsoup4、pyyaml、flask、telebot、colorama）、輸入版本規格，或點擊自動偵測的 requirements.txt 橫幅。

STEP 03 Import Local Archive (.whl)

或瀏覽下載資料夾匯入離線 .whl / .zip 套件

在無網路環境下，點擊 PIP 對話框中的「本機封存檔」，掃描下載項目或專案資料夾中的 .whl、.tar.gz 與 .zip 套件。

STEP 04 Manage Tab -> Verify

立即在多檔案腳本中匯入使用

已安裝的函式庫會持久保存在獨立的 site-packages 目錄中，重啟應用程式依然存在，並立即支援 AST 自動補全。

裝置端持久保存 site-packages · 50ms 非阻塞安裝日誌串流 使用指南

05 常見問答

常見問題

關於在 Android 上安裝 PyPI 套件、離線 .whl 封裝與 requirements.txt 的常見問題。

我可以直接將完整的 `pip install requests beautifulsoup4` 指令貼到 SuperCode 嗎？+
可以。PIP 輸入解析器會自動剝除開頭的 `pip install`、`pip3 install` 或 `python -m pip install` 前綴，安全忽略不支援的 CLI 參數，並將所有列出的套件連同其 PEP 440 版本限制加入佇列。
在沒有網路的情況下，如何在 Android 上安裝 Python 套件？+
請事先將純 Python 的 `.whl`（例如 `*-py3-none-any.whl`）、`.tar.gz` 或 `.zip` 封存檔下載到手機上，開啟 SuperCode 的 PIP 套件管理員並點選「本機封存檔」按鈕，即可直接從下載資料夾進行安裝。
為什麼我不需要手動執行 `pip install numpy` 或 `matplotlib`？+
像 NumPy、Pandas、SciPy、Matplotlib 與 Scikit-Learn 這類包含大量原生 C/Fortran 擴充的函式庫，已預先適配於 SuperCode 的科學運算執行環境。只需在腳本中撰寫 `import numpy as np` 並按下執行即可。
關閉應用程式後，已安裝的 PIP 套件還會保留在手機上嗎？+
是的。每個已安裝的套件都會持久儲存在 SuperCode 本機的 `python_site_packages` 儲存空間中，讓您的腳本隨時都能離線執行而無需重新安裝。
