05 常見問答

常見問題

關於 Android 離線 Java 17 語法支援、Jvdroid 遷移及 Java 21+ 功能的常見問答。

SuperCode 真的不用連網就能編譯 Java 17 的 records 和 sealed 類別嗎？+
是的。首次啟動完成輕量離線 Java 17 SDK 初始化後，`record`、`sealed` / `permits`、`switch ->` 運算式、`instanceof` 模式比對、文字區塊（`"""`）以及 `Stream.toList()` 都能在飛航模式下 100% 離線編譯執行。
作為 Java 8 或 Java 11 手機 App 的現代替代方案，SuperCode 表現如何？+
舊款 Android Java App 遇到使用 `record` 元組、`Stream.toList()` 或 switch 運算式的大學作業與 LeetCode 解法經常編譯失敗。SuperCode 除了完整離線支援 LTS Java 17，還提供自動雲端 Java 21+ 支援、視覺化 Git 與內建 SQLite JDBC。
`CompletableFuture`、`Optional` 和 `java.time` 也能離線使用嗎？+
可以。完整核心標準函式庫 — 包含 `java.util.stream`、`java.util.concurrent.CompletableFuture`、`java.time.*`、`java.math.BigDecimal` 與 `java.nio.file` — 皆可原生離線執行。
如何在 Android 手機上執行 Java 21 虛擬執行緒？+
只要寫入 `Thread.ofVirtual()` 或 `Executors.newVirtualThreadPerTaskExecutor()`（或在檔案頂端加上 `// @cloud`）並點擊執行，SuperCode 就會自動打包專案類別至雲端 Java 21+ 並將輸出即時串流回終端機。
