05 常見問答

常見問題

關於離線 JSON/JSONC 驗證、ES2024 Regex 測試、大型 JSON 日誌與 API 腳本的常見解答。

在 SuperCode 中格式化機密的正式環境 JSON 或 API 設定檔安全嗎？+
安全。SuperCode 的 JSON/JSONC 格式化工具與 ES2024 JavaScript Worker 皆 100% 在您的 Android 裝置本機執行——您的 JSON 資料絕不會傳送至任何外部伺服器。
格式化工具是否支援像 tsconfig.json 或 settings.json 這樣含有 // 註解的 JSONC 檔案？+
支援。CodeFormatEngine 能同時辨識標準 JSON 與 JSONC 註解，在整齊排版巢狀物件與陣列時完整保留您的註解。
如果複雜的 Regex 在測試時發生災難性回溯怎麼辦？+
所有 JavaScript Regex 腳本都在隔離的非 UI Worker 執行緒中運行，因此您可以立即中斷過慢或失控的 Regex，編輯器完全不會卡死。
SuperCode 可以在手機上開啟並搜尋 500 MB 的 JSON 或 NDJSON 日誌檔嗎？+
可以。超過 30 MB 的檔案會無縫啟用 SuperCode 以磁碟為後盾的 GB 串流分頁器，支援 120Hz 流暢捲動與全域串流 Regex 取代。
