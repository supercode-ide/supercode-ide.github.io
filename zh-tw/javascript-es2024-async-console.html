02.1

免 HTML 樣板，直接執行純 .js 與 .mjs 腳本

想測試非同步重試輔助函式、正規表達式解析器或狀態 Reducer 嗎？建立單一 `.js` 或 `.mjs` 檔案並點擊執行 ▶ 即可 — 不需要 `<script>` 標籤、假 HTML 頁面或狹窄的手機 DevTools 抽屜。

直跑 .js / .mjs · 停駐式分割主控台
02.2

全面碾壓舊版 ES5 App 的現代 ES2024 語法

許多 Play 商店的 JS 執行器仍內嵌十年前的引擎，連 `const`、箭頭函式或 `async` 都會報錯。SuperCode 離線原生執行頂層 `await`、非同步生成器（`async function*`）、私有 `#fields`、`BigInt`、`WeakRef`、`structuredClone`、`Object.groupBy` 與 `Array.at()`。

頂層 await · 私有 #Fields · BigInt · WeakRef
02.3

智慧事件迴圈與微任務自動排空 (Auto-Drain)

非同步程式碼絕不會在 Promise 解析前提前退出：Worker 會追蹤作用中的 `setTimeout`、`setInterval`、`queueMicrotask` 與 `timers/promises` 控制代碼，乾淨地排空事件迴圈直到所有工作完成。

Promise.allSettled · timers/promises · 完整排空
02.4

隔離 Worker 執行緒與 <1ms 無窮迴圈秒殺防護

在主 UI 執行緒執行 JavaScript 一旦遇到有 Bug 的 `while (true) {}` 就會讓整個編輯器徹底卡死。SuperCode 將執行隔離至專屬背景 Worker，點擊停止 ■（或觸發 15 秒監看計時器）即可在 1 毫秒內強制終止失控迴圈。

非 UI 背景 Worker · <1ms 中止 · 編輯器零卡頓
02.5

標準 Fetch API、AbortController 與 Web Streams

使用標準 `fetch()`、`Headers`、`Request`、`Response`、`AbortController` / `AbortSignal.timeout()`、`URL`、`URLSearchParams`、`TextEncoder`/`TextDecoder` 與 `ReadableStream` 快速開發即時 API 用戶端原型。

fetch() · AbortController · URL · ReadableStream

05 常見問答

常見問題

關於 ES2024 語法、頂層 `await`、`fetch()` 與無窮迴圈保護的常見問題。

在 SuperCode 中可以不建立 HTML 檔案就直接執行 JavaScript 嗎？+
可以！SuperCode 擁有獨立於 HTML5 Web IDE 之外的專屬 JavaScript 主控台引擎。只要開啟任何 `.js`、`.mjs` 或 `.cjs` 檔案並點擊執行 ▶ 即可。
如何在不用 `async function main()` 包裝的情況下使用頂層 `await`？+
將檔案儲存為 `.mjs`（或在 `package.json` 設定 `\"type\": \"module\"`，或直接在 ES Module 腳本中撰寫頂層 `await`）— SuperCode 會原生執行頂層 `await` 並等待所有 Promise 完成。
在手機上不小心寫出 `while (true)` 無窮迴圈怎麼辦？+
由於腳本是在隔離的背景 Worker 執行緒中運行，你的編輯器與未儲存檔案會保持 100% 流暢回應。點擊停止 ■ 按鈕（或等待 15 秒 CPU 監看保護自動觸發），即可在 1 毫秒內終止該 Worker。
獨立的 JavaScript 腳本中支援 `fetch()` 嗎？+
支援。標準 `fetch()`、`Headers`、`Request`、`Response` 與 `AbortController` 皆已直接內建於 Worker 執行環境中，只要裝置連網即可隨時測試即時 HTTPS API。
