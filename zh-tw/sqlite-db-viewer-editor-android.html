03 逐步操作流程

如何在 Android 上檢視 `.db` 檔案或查詢 CSV/JSON 資料集

四個快速步驟即可開啟現有二進位資料庫，或從原始檔案建立全新資料庫。

STEP 01 Explorer -> Tap .db

一鍵開啟任一 .db、.sqlite 或 .sqlite3 檔案

在工作區中選取資料庫檔案，即可立即檢視其 .dbinfo 摘要、.tables 清單與 CREATE TABLE / INDEX Schema。

STEP 02 .import --csv / --json

或將原始 CSV、TSV 與 JSON 檔案匯入資料表

在 .sql 指令碼中執行 .import --csv data.csv my_table，即可自動從最高 8 MB 的平面檔案建立並填入關聯式欄位。

STEP 03 .mode box / markdown

執行 SQL 查詢並切換 9 種輸出格式

搭配 AST SQL 自動補全撰寫 SELECT、JOIN、UPDATE 或 ALTER 陳述式，並預覽清晰的 Unicode 方框或 Markdown 表格。

STEP 04 .once export.csv

將乾淨結果匯出回工作區

搭配 csv、json、markdown 或 insert 模式使用 .once，將乾淨的分析輸出直接儲存至專案資料夾。

05 常見問答

常見問題

關於離線開啟 `.db`/`.sqlite3` 檔案、匯入 CSV/JSON 資料集與匯出格式化結果的常見問題。

SuperCode 可直接開啟哪些 SQLite 資料庫副檔名？+
SuperCode 可一鍵辨識 `.db`、`.sqlite`、`.sqlite3`、`.db3` 與 `.s3db` 檔案，並自動離線檢視 `.dbinfo`、`.tables` 與 `.schema`。
相較於一般 Android SQLite 檢視器，內建 SQLite 3.54.1 為何重要？+
多數 Android DB 檢視器仰賴手機較舊的系統 SQLite 版本，缺乏 `STRICT` 資料表、`RETURNING`、`JSONB`、現代視窗框架子句與新版查詢最佳化器。SuperCode 在 Android 8.0+ 裝置上提供一致的 SQLite 3.54.1 體驗。
我可以不先寫 `CREATE TABLE` 就匯入 `.csv` 或 `.json` 檔案嗎？+
可以！執行 `.import --csv filename.csv tablename`（或 `--tsv` / `--json`），支援最高 8 MB — 若 `tablename` 尚未存在，SuperCode 會自動依據您的 CSV 標頭或 JSON 物件鍵名建立資料表 Schema。
如何將 SQL 查詢結果匯出成 Markdown 表格或 CSV 檔案？+
在 `SELECT` 陳述式上方加上 `.mode markdown`（或 `.mode csv` / `.mode json` / `.mode insert`）接著 `.once output.md`，然後點擊「執行」— 檔案會立即出現在您的專案檔案總管中。
