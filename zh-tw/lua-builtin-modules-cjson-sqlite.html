02 核心能力

超越陽春標準函式庫的實戰級 Lua 腳本開發

無須碰觸 C 編譯器，就能打造 REST 用戶端、本機 SQLite 存檔編輯器、目錄批次工具及 OpenResty/Redis 風格的 JSON 腳本。

02.1

開箱即用的 cjson 與 dkjson 序列化

使用 require('cjson') 或 require('dkjson') 離線即時解析與輸出 JSON 資料 — 並內建 cjson.encode_pretty() 方便產出易讀的設定檔與進行 API 除錯。

cjson.encode · encode_pretty · cjson.decode
02.2

嵌入式 lsqlite3 / sqlite3 資料庫引擎

透過 require('lsqlite3') 或 require('sqlite3') 開啟 :memory: 或工作區持久化 .db 檔。支援預處理陳述式、:named 參數綁定、db:nrows() 疊代器與 ACID 交易。

lsqlite3 · 持久化 .db 同步 · 與 SQL IDE 共用
02.3

LuaFileSystem (lfs) 目錄與檔案自動化

透過 require('lfs') 在專案資料夾自動執行批次重新命名與資源稽核 — 支援 lfs.dir()、lfs.mkdir()、lfs.currentdir() 與 lfs.attributes() 檔案大小/時間戳記檢查。

lfs.dir · lfs.mkdir · lfs.attributes
02.4

crypto、sha2、md5 與 base64 安全加解密套件

使用 SHA-256、SHA-512、MD5、金鑰雜湊 HMAC 摘要、crypto.uuid() 與符合 RFC 標準的 Base64 編碼/解碼，離線簽章 Webhook 負載、驗證檔案校驗碼並產生唯一 ID。

SHA-256/512 · HMAC · crypto.uuid() · base64
02.5

socket.http、完整 regex 與 Table inspect

透過 require('socket.http') 測試即時 REST API；當 Lua 模式比對不敷使用時以 require('regex') 執行完整 PCRE/POSIX 正規表示式；並用 require('inspect') 清晰傾印巢狀 Table。

socket.http · 完整 regex · inspect(table)
02.6

05 常見問答

常見問題

關於在 Android 上使用 cjson、lsqlite3、LuaFileSystem 與 luarocks 模組的常見問題。

使用 `cjson`、`lsqlite3` 或 `lfs` 需要先安裝 luarocks 或 C 編譯器嗎？+
不需要。超過 11 個核心擴充模組別名（`cjson`、`dkjson`、`lsqlite3`、`sqlite3`、`lfs`、`crypto`、`sha2`、`md5`、`base64`、`regex`、`socket.http` 與 `inspect`）已直接預載於 SuperCode，透過 `require()` 即可立即使用。
`lsqlite3` 可以與 Python、PHP 或 SuperCode 的 SQL IDE 共用同一個 `.db` 檔案嗎？+
可以！`lsqlite3` 在專案資料夾建立的 `.db` 資料庫就是標準 SQLite 3 二進位檔案，可直接在 SuperCode 的 SQL Studio、Python `sqlite3`、PHP `PDO` 或 Java JDBC 中進行查詢。
`cjson` 是否支援設定檔用的縮排美化輸出？+
支援。除了標準的 `cjson.encode()` 與 `cjson.decode()` 外，SuperCode 還提供 `cjson.encode_pretty()`，讓你在離線狀態也能檢視或儲存縮排整齊的 JSON。
如果我的腳本需要用到 `lpeg` 或 `luv` 怎麼辦？+
在連網狀態下，SuperCode 會自動偵測 `lpeg` 或 `luv` 等進階原生 C-Rock 匯入項目，並將你的多檔案專案自動路由至雲端 Lua 環境執行。
