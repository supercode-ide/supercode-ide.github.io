05 常見問答

常見問題

關於在 Android 上跨語言共用 `.db` 檔案與編輯超大型 `.sql` 傾印檔的常見問題。

在 Java 17 使用 `jdbc:sqlite:app.db` 需要另外下載 `.jar` 檔嗎？+
不用！SuperCode 已將 SQLite JDBC 驅動程式直接預先內建於離線 Java 17 Classpath 中 — 只要撰寫 `DriverManager.getConnection("jdbc:sqlite:app.db")` 並點擊執行即可。
Python、PHP、Java 與 Lua 真的能讀寫同一個 `app.db` 檔案嗎？+
是的。只要你的 `.sql`、`.py`、`.php`、`.java` 與 `.lua` 檔案位於同一個工作區資料夾（或指向相同的相對路徑），它們全都會對磁碟上同一個 `app.db` 檔案進行讀取與 ACID 交易提交。
如何在 SuperCode 的 Lua 5.4 腳本中使用 SQLite？+
呼叫 `local sqlite3 = require('lsqlite3')` 與 `local db = sqlite3.open('app.db')` 即可。SuperCode 離線 Lua 5.4 執行期已內建嵌入式 `lsqlite3`，啟動時間低於 1 毫秒。
SuperCode 能開啟超過 1 GB 的 `.sql` 資料庫傾印檔而不讓手機閃退嗎？+
可以。SuperCode 的 GB 級大型檔案編輯器直接以磁碟分頁串流讀取大型 `.sql`、`.csv` 與 `.log` 檔案，而非將整份檔案載入記憶體 — 並完整支援正規表示式搜尋/取代與編碼偵測。
