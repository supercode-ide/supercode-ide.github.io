03 逐步操作流程

如何在 Android 上建置與除錯多檔案 C 程式

免去任何建置腳本設定，輕鬆撰寫單檔練習或跨模組 C 專案。

STEP 01 main.c + utils.h

建立 .c 原始碼與 .h 標頭檔

善用 C/C++ 21 鍵符號列（->、*、&、{}、;、#include）與 AST 結構體成員自動補全，快速編寫模組化 C17 程式碼。

STEP 02 Format & Error Radar

離線檢查前置處理指令與排版縮排

錯誤雷達能即時捕捉異常的 #include 指令與未配對的大括號；輕點格式化即可對齊 K&R/Allman 區塊與第 0 欄巨集。

STEP 03 Toolbar -> Run ▶

從專案任一分頁直接離線編譯與連結

即使游標停留在 utils.h 內，點擊執行仍會自動定位 main.c、編譯異動單元、連結 -lm 並啟動執行檔。

STEP 04 Stdin / Workspace

輸入即時 scanf 資料並檢視輸出檔案

在底部或並排終端機中互動輸入測試數值，隨即檢視結束代碼、毫秒級執行時間、記憶體用量及產生的檔案。

05 常見問答

常見問題

關於 Android 離線 C17 編譯、多檔案標頭檔、<math.h> 與 scanf 輸入的常見問題。

SuperCode 的 C 編譯器是與 C++ 分開的嗎？+
是的。開啟 .c 檔案時會啟用專屬的 GNU C17 (-std=gnu17) 主控台與純 C 標準函式庫連結，而非將您的 C 程式碼當作 C++ 編譯。
編譯多個 .c 和 .h 檔案需要自己寫 Makefile 嗎？+
不需要。SuperCode 會自動掃描工作區與已開啟編輯器分頁中的 #include "..." 標頭檔與關聯 .c 檔案，對異動檔案進行增量編譯，並自動連結 <math.h> (-lm)。
scanf() 和 fgets() 在 Android 上能進行互動式輸入嗎？+
可以。每當您的 C 程式從 stdin 讀取資料時，分割畫面終端機便會暫停執行，讓您即時輸入多行內容，並在送出空白提示時發送 EOF 訊號。
如果我的 C 程式碼使用了 <pthread.h> 或 <sys/socket.h> 等 Linux POSIX 標頭檔怎麼辦？+
SuperCode 會自動偵測作業系統/POSIX 專屬標頭檔，並無縫切換至 POSIX 雲端工具鏈編譯您的多檔案專案，同時完整保留精確的本機檔名與行號錯誤診斷。
