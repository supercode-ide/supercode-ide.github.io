05 常見問答

常見問題

關於多套件目錄結構、匯入外部 .jar 函式庫與 main() 解析機制的常見問題。

如何在 SuperCode 中加入 Gson 或 Commons Lang 等外部 `.jar` 函式庫？+
只要在 Java 專案根目錄建立名為 `libs`（或 `lib`）的資料夾並將 `.jar` 檔複製進去即可。SuperCode 會自動把 `libs/` 中所有 `.jar`（總計最高 30 MB）加入編譯期與執行期類別路徑 — 完全免寫建置腳本。
如果我在編輯沒有 `main()` 的 Java 類別時按下執行會怎樣？+
SuperCode 的進入點仲裁器會掃描專案已編譯的類別，自動選出包含 `main()` 的主要進入點類別並執行 — 省去來回切換分頁的麻煩。
一定要用 `src/main/java` 目錄嗎？一般的多檔案資料夾也能跑嗎？+
兩種都能順暢運作！你可以把兩個不帶 `package` 宣告的 `.java` 檔並排放在同一個資料夾、直接建立 `com.example.*` 子目錄，或是採用完整的 `src/main/java` + `resources/` + `libs/` 目錄結構。
哪些 `.jar` 檔可以在 Android 上離線正常運作？+
任何以 Java 8、11 或 17 為目標的標準純 Java `.jar` 函式庫（如 `gson`、`org.json`、`commons-lang3`、`commons-csv` 或大學評測函式庫）皆可 100% 離線使用。需要 AWT/Swing 視窗的桌機 GUI jar 則不適用於手機終端機環境。
