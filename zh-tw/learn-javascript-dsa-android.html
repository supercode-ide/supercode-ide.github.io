JavaScript 初學者、程式訓練營學員與面試學習者的常見問題。

使用 SuperCode 離線開始學習 JavaScript 完全免費嗎？+
是的！你可以免費建立無限數量的 `.js`、`.mjs`、`.json` 與 `.html` 檔案，執行全部 6 個內建 JavaScript 範本、使用 21 鍵符號列、格式化程式碼，並離線執行 ES2024 與 Node 核心腳本，完全免登入。

可以。開啟或貼上任何 `.json` 檔案（甚至是數 MB 的 Payload），透過錯誤雷達檢查精確的行／欄語法錯誤，再點擊格式化即可一步完成縮排與整理。
當我想建置網站時，SuperCode 也能執行 HTML、CSS 與 DOM JavaScript 嗎？+
當然可以。每當你想從獨立主控台 JS 跨入視覺化網頁開發，SuperCode 內建的 Web IDE 即可透過真實的本機 HTTP 伺服器預覽多檔案 HTML5、CSS3、DOM JavaScript，甚至離線 PHP + SQLite。
我也可以練習 TypeScript 語法嗎？+
SuperCode 提供完整的 TypeScript（`.ts` / `.tsx`）語法突顯、AST 符號辨識、21 鍵 JS/TS 符號列與一鍵格式化，並支援獨立的 ES2024 `.js`/`.mjs` 離線執行。
