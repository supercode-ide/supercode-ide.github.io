05 常見問答

常見問題

解答 Codeforces、LeetCode、AtCoder、ICPC 與 USACO 選手在 Android 刷題的常見疑問。

結構化綁定 `auto [u, w]`、`std::popcount` 與 `std::ranges::sort` 等 C++20 語法都能離線編譯嗎？+
可以。SuperCode 的本機 C++ 編譯器以 GNU C++20（`-std=gnu++2a`）模式運作，因此結構化綁定、`constexpr if`、泛型 lambda、`<bit>`、`<ranges>` 以及 `std::gcd` / `std::lcm` 皆可 100% 離線編譯。
可以在 SuperCode 裡使用 `ios::sync_with_stdio(false); cin.tie(nullptr);` 嗎？+
沒問題！標準演算法競賽的高速 I/O 慣用寫法，無論搭配多行貼上的測資或 `freopen()` 檔案重導向都能穩定順暢運作。
要如何測試讀取到檔案結尾的題目（`while (cin >> x)`）？+
先將測試資料行貼進即時主控台輸入列並送出，接著在空白輸入列再點擊一次「傳送」即可送出 `[EOF]` 並印出最終答案。
SuperCode 會顯示我的 C++ 解法跑了多久、用了多少記憶體嗎？+
會的。每次執行都會顯示執行摘要徽章，清楚標示行程結束代碼、執行耗時（`µs` 或 `ms`）以及峰值記憶體用量（`KB` 或 `MB`）。
