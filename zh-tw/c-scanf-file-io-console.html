02 核心能力

每個 C 輸入與輸出通道都如原生終端機般順暢運作

選單式主控台應用、指令列解析器與二進位紀錄作業，表現皆與桌面端終端機完全一致。

02.1

scanf 與 fgets 前自動停用 stdout 緩衝

在許多手機或線上執行器中，沒有換行結尾的 printf("Enter age: "); 會一直隱形到 scanf() 結束才顯示！SuperCode 會自動停用 stdout 緩衝，確保提示訊息永遠在你輸入前出現。

免寫 fflush(stdout) · 自然選單迴圈
02.2

多步驟即時 Stdin 與一鍵 [EOF] 訊號

隨著程式執行逐步輸入互動資料。正在測試 while (scanf("%d", &x) != EOF) 或 while (fgets(buf, sizeof buf, stdin))？只要送出空白輸入行，即可傳送乾淨的 EOF 訊號。

scanf · fgets · getchar · 乾淨 [EOF] 終止
02.3

支援 argc / argv CLI 程式的 // @args 指令

在 .c 檔案頂部加上 // @args -i "input data.csv" --verbose，即可將最多 32 個解析後的指令列權杖直接傳入 main(int argc, char *argv[])，並完整保留引號內的空白。

// @args · 引號字串 · 最多 32 個 argv 參數
02.4

自動掛載 .txt / .csv / .dat / .in 資料集

將 input.in、students.csv 或 records.dat 放入專案目錄，即可直接透過 fopen("students.csv", "r") 等標準相對路徑開啟—完全不需寫死 Android 的 /storage/emulated/0 路徑。

相對路徑 fopen() · .txt / .csv / .dat / .in
02.5

雙向 fopen、fprintf 與 fwrite 工作區同步

透過 fopen(..., "w" / "wb")、fprintf() 與 fwrite() 寫入的文字報表與二進位 struct，會自動同步至 Android 工作區檔案樹並立即重新整理檔案總管。

文字與二進位檔同步 · 檔案總管即時刷新
02.6

20 秒閒置暫停的 CPU 迴圈看門狗

從容思考並輸入主控台資料也完全沒問題—等待 stdin 時 20 秒看門狗會自動暫停；但若輸入後遇到有臭蟲的無窮迴圈空轉 CPU，看門狗會立刻介入中止。

05 常見問答

常見問題

排解 Android 上 `scanf` 提示、`fgets` 換行特性、`EOF` 與 `fopen` 路徑常見問題。

為什麼在 SuperCode 中不用寫 `fflush(stdout)`，`printf("Enter number: ");` 就能立刻顯示？+
標準 C 串流在經由管線導向時通常會採用區塊緩衝，導致沒有 `\n` 結尾的提示文字被隱藏。SuperCode 會自動將標準串流設為無緩衝，讓互動提示在 `scanf`、`fgets` 或 `getchar` 等待輸入前即時出現。
在 Android 觸控螢幕鍵盤上要怎麼送出 `Ctrl+D` (`EOF`)？+
當主控台輸入列處於啟用且空白狀態時，點擊「傳送」按鈕就會乾淨地將 `EOF`（`[EOF]`）傳遞給執行中的 C 處理程序—順利結束 `while (scanf(...) != EOF)` 與 `getchar() != EOF` 迴圈。
要如何將含空白的指令列參數傳給 `char *argv[]`？+
只要在 `.c` 檔案頂部附近寫上 `// @args "My Report.txt" -n 10`。SuperCode 的參數詞法解析器會將雙引號字串保留為單一 `argv[i]` 項目，最多支援 32 個參數。
用 `fopen("output.txt", "w")` 建立的檔案會儲存在哪裡？+
它們會直接同步至與你 `.c` 原始碼相同的 Android 專案資料夾中，因此會永久保留並可直接於 SuperCode 編輯器內開啟。
