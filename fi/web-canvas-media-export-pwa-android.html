05 KYSYMYKSET JA VASTAUKSET

Usein kysytyt kysymykset

Vastauksia HTML5 Canvas -vienteihin, WebM-keston korjaukseen, File Picker -polyfilleihin ja IndexedDB:hen Androidilla.

Toimivatko Blob-lataukset ja showSaveFilePicker() oikeasti SuperCoden Web-esikatselussa?+
Kyllä. SuperCode injektoi kilpatilanteettoman WebMediaBridgen dokumentin alussa, yhdistäen Blob/DataURL-lataukset, showSaveFilePickerin, showOpenFilePickerin ja navigator.sharen suoraan Androidin natiiviin tallennustilaan.
Miksi Canvas MediaRecorder WebM -videot toistuvat tarkoilla aikajanoilla SuperCodesta vietäessä?+
SuperCode ajaa häviöttömän puhtaan Kotlin-pohjaisen EBML SeekHead-, Duration- ja Cues-korjauksen ennen MediaStore-kirjoitusta – korjaten Chromen/WebViewn puuttuvat kestometatiedot ilman uudelleenkoodausta.
Voinko rakentaa HTML5 Canvas 2D- ja WebGL-pelejä offline-tilassa SuperCodessa?+
Kyllä. Aito paikallinen HTTP-palvelu tukee ES-moduuleja, tekstuureja, ääniresursseja, HTTP 206 -kelausta, localStorage-huipputuloksia ja DevTools Console -virheiden tarkastelua täysin offline-tilassa.
Minne verkkosovellukseni viemät kuvat, videot ja äänitiedostot tallentuvat?+
SuperCode varmistaa aidot tiedostotyypit Magic-Byte-tunnistimellaan ja tallentaa atomisesti Android MediaStoren kautta kansioihin Pictures/SuperCode, Movies/SuperCode, Music/SuperCode tai Download/SuperCode.
