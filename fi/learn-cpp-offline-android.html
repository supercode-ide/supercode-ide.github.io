Voinko ajaa myös C:tä, Pythonia, Javaa ja SQL:ää samassa sovelluksessa muita kurssejani varten?+
Kyllä. SuperCode sisältää omat offline-ympäristöt C17-, C++20-, Python 3.11/3.12-, Java 17-, JavaScript-, Lua 5.4-, PHP/Web- ja SQLite-kielille yhdessä kevyessä 40,2 Mt:n Android-studiossa.
