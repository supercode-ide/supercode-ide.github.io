05 KYSYMYKSET JA VASTAUKSET

Usein kysytyt kysymykset

Usein kysyttyä PyPI-pakettien, offline-.whl-tiedostojen ja requirements.txt:n asentamisesta Androidilla.

Voinko liittää kokonaisen `pip install requests beautifulsoup4` -komennon SuperCodeen?+
Kyllä. PIP-syötteen jäsennin poistaa automaattisesti alusta `pip install`, `pip3 install` tai `python -m pip install` -etuliitteet, ohittaa tukemattomat CLI-valitsimet turvallisesti ja lisää kaikki listatut paketit jonoon PEP 440 -versiorajoitteineen.
Miten asennan Python-paketteja Androidilla ilman verkkoyhteyttä?+
Lataa puhdas Python-`.whl` (esim. `*-py3-none-any.whl`), `.tar.gz`- tai `.zip`-paketti puhelimeesi etukäteen, avaa SuperCoden PIP-pakettienhallinta ja napauta Paikallinen arkisto -painiketta asentaaksesi suoraan Lataukset-kansiosta.
Miksi minun ei tarvitse ajaa `pip install numpy` tai `matplotlib` käsin?+
Raskaita natiiveja C/Fortran-laajennuksia sisältävät kirjastot, kuten NumPy, Pandas, SciPy, Matplotlib ja Scikit-Learn, on esisovitettu SuperCoden tieteisajoympäristöön. Kirjoita vain `import numpy as np` skriptiisi ja paina Suorita.
Säilyvätkö asennetut PIP-paketit puhelimessa sovelluksen sulkemisen jälkeen?+
Kyllä. Jokainen asennettu paketti tallennetaan pysyvästi SuperCoden paikalliseen `python_site_packages`-hakemistoon, joten skriptisi toimivat offline-tilassa milloin tahansa ilman uudelleenasennusta.
