02.1

Jäsennä ja muodosta JSON-tietueita välittömästi offline-tilassa require('cjson')- tai require('dkjson')-kutsuilla — mukana cjson.encode_pretty() helppolukuisia asetustiedostoja ja API-debuggausta varten.

cjson.encode · encode_pretty · cjson.decode
02.2

Upotettu lsqlite3 / sqlite3 -tietokantamoottori

lsqlite3 · Pysyvä .db-synkronointi · Jaettu SQL IDE:n kanssa
02.3

LuaFileSystem (lfs) -hakemisto- ja tiedostoautomaatio

Automatisoi eränimeämiset ja resurssitarkistukset projektikansiossasi require('lfs')-moduulilla — mukaan lukien lfs.dir(), lfs.mkdir(), lfs.currentdir() sekä lfs.attributes()-koko- ja aikaleimatarkistukset.

lfs.dir · lfs.mkdir · lfs.attributes

05 KYSYMYKSET JA VASTAUKSET

Usein kysytyt kysymykset

Yleisiä kysymyksiä cjson-, lsqlite3-, LuaFileSystem- ja luarocks-moduulien käytöstä Androidilla.

Pitääkö minun asentaa luarocks tai C-kääntäjä käyttääkseni `cjson`-, `lsqlite3`- tai `lfs`-moduulia?+
Ei. Kaikki 11+ ydinlaajennuksen aliasta (`cjson`, `dkjson`, `lsqlite3`, `sqlite3`, `lfs`, `crypto`, `sha2`, `md5`, `base64`, `regex`, `socket.http` ja `inspect`) on esiintegroitu suoraan SuperCodeen ja toimivat välittömästi `require()`-kutsulla.
Voiko `lsqlite3` jakaa saman `.db`-tiedoston Pythonin, PHP:n tai SuperCoden SQL IDE:n kanssa?+
Kyllä! Projektikansioosi `lsqlite3`:lla luotu `.db`-tietokanta on tavallinen SQLite 3 -binääritiedosto, johon voidaan tehdä kyselyitä suoraan SuperCoden SQL Studiossa, Python `sqlite3`:ssa, PHP `PDO`:ssa tai Java JDBC:ssä.
Tukeeko `cjson` muotoiltua sisennettyä tulostusta asetustiedostoille?+
Kyllä. Tavallisten `cjson.encode()`- ja `cjson.decode()`-funktioiden lisäksi SuperCode tarjoaa `cjson.encode_pretty()`-funktion, jotta voit tarkastella tai tallentaa siististi sisennettyä JSON-dataa offline-tilassa.
Mitä tapahtuu, jos skriptini vaatii `lpeg`- tai `luv`-moduulia?+
Kun laite on yhteydessä internetiin, SuperCode tunnistaa erikoistuneet natiivit C-rock-tuonnit kuten `lpeg` tai `luv` ja reitittää monitiedostoisen projektisi automaattisesti pilven Lua-ympäristöön.
