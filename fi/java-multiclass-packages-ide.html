05 KYSYMYKSET JA VASTAUKSET

Usein kysytyt kysymykset

Usein kysytyt kysymykset monipakettirakenteista, ulkoisten .jar-kirjastojen lisäämisestä ja main()-ratkaisusta.

Miten lisään ulkoisen `.jar`-kirjaston kuten Gsonin tai Commons Langin SuperCodessa?+
Luo Java-projektisi juureen kansio nimeltä `libs` (tai `lib`) ja kopioi `.jar`-tiedostosi sinne. SuperCode lisää automaattisesti kaikki `libs/`-kansion `.jar`-arkistot (jopa 30 Mt) sekä käännös- että ajonaikaiseen luokkapolkuun — käännösskriptejä ei tarvita.
Mitä tapahtuu, jos painan Suorita muokatessani Java-luokkaa, jossa ei ole `main()`-metodia?+
SuperCoden aloituspisteen ratkaisija skannaa projektisi käännetyt luokat, valitsee automaattisesti ensisijaisen `main()`-sisältävän aloitusluokan ja suorittaa sen — säästäen sinut jatkuvalta välilehtien välillä hyppimiseltä.
Onko minun pakko käyttää `src/main/java`-rakennetta, vai toimivatko yksinkertaiset monitiedostokansiotkin?+
Molemmat toimivat saumattomasti! Voit asettaa kaksi `.java`-tiedostoa rinnakkain yksinkertaiseen kansioon ilman `package`-lausetta, järjestää `com.example.*`-alikansioita suoraan tai käyttää täyttä `src/main/java` + `resources/` + `libs/` -hakemistorakennetta.
Mitkä `.jar`-tiedostot toimivat offline-tilassa Androidilla?+
Mikä tahansa standardi puhdas Java `.jar` -kirjasto, joka on kohdistettu Java 8-, 11- tai 17-versiolle (kuten `gson`, `org.json`, `commons-lang3`, `commons-csv` tai yliopistojen testikirjastot), toimii 100 % offline-tilassa. AWT/Swing-ikkunoita vaativat työpöytä-GUI-jarit eivät sovellu mobiilikonsoleille.
