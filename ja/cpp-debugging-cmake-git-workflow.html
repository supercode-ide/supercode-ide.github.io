05 よくある質問

よくある質問 (FAQ)

C++20の複数ファイルエラー、AST補完、C++整形、Git連携に関するよくある質問。

複数ファイルのC++コンパイルエラーで正確な .hpp や .cpp のファイル名と行番号が表示されますか？+
はい。オフラインC++20コンパイラと Unity Cloud C++ の両方がファイルごとに標準の #line 1 ディレクティブを出力するため、警告やエラーはローカルの正確なヘッダまたはソース行へ1対1で対応付けられます。
SuperCodeのC++自動補完はインターネット接続なしでも動作しますか？+
はい。SuperCodeは端末上で100%オフラインの Tree-sitter WASM AST エンジンを実行しており、::、->、. トリガーでの文脈補完をサーバ通信なしで提供します。
C++フォーマッタでC++生文字列リテラルやプリプロセッサ指令が壊れることはありませんか？+
ありません。SuperCodeの字句認識型C++フォーマッタはコメント、文字列/文字リテラル、プリプロセッサ行を正確に追跡し、部分選択整形や即座の1タップUndoにも対応しています。
Termuxを入れずにC++プロジェクトを直接GitHubへコミット・プッシュできますか？+
はい。SuperCodeはネイティブの Visual Git クライアントを内蔵しており、HTTPS Personal Access Tokenによるclone/pull/push、ブランチ切り替え、色分けコミット差分、視覚的マージコンフリクト解消に対応しています。
