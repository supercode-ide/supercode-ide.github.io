02 主要エンジニアリング機能

フロントエンド開発者が簡易HTMLビューアから乗り換える理由

ブラウザ本来のオリジン仕様、マルチブレークポイントの実機検証、スマホ・折りたたみ端末・タブレットでの快適な整形をこれ1つで。

02.1

本物のローカルHTTP/1.1サーバー（65種以上のMIMEタイプ）

CORSの「origin null」エラーとはお別れ。正規のlocalhost HTTP/1.1オリジンで配信するため、ネイティブの<script type="module">インポート、fetch('./data.json')、localStorage、IndexedDB、SVGスプライト、.woff2 Webフォントがそのまま動きます。

正規Localhostオリジン · 65種超のMIMEタイプ · CORSブロックなし
02.2

Dynamic Island 3ビューポート・レスポンシブ切替

3台の端末を持ち歩かなくても、CSS GridやFlexbox、@mediaクエリの挙動を正確に確認可能。ドラッグ可能なDynamic Islandピルをタップするだけで、モバイル・タブレット(768dp)・ワイドデスクトップをリアルタイムで切り替えられます。

モバイル · タブレット(768dp) · デスクトップ ブレークポイント
02.3

HTML + <style> + <script> ワンタップ再帰フォーマッタ

単一ファイルのプロトタイプも常に美しく整形。フォーマットを1回タップするだけで、ネストしたHTML5要素はもちろん、<style>内のCSSルールや<script>内のJavaScriptコードまで再帰的にインデント整形します。

マークアップ + CSS + JS 一括コード整形

05 よくある質問

よくある質問 (FAQ)

AndroidでのHTML5/CSS3/JS編集、ES Modules、レスポンシブプレビューに関するよくある質問。

他のHTMLエディタアプリで `<script type="module">` や `fetch('./data.json')` が失敗するのはなぜですか？+
ブラウザの厳格なCORSセキュリティ規則により、`file://` URLではES Modulesや`fetch()`がブロックされます。SuperCodeは適切なMIMEヘッダー付きの本物の`localhost` HTTP/1.1オリジンでプロジェクトを自動配信するため、モダンなJSモジュールやJSON取得がオフラインでもネイティブに動作します。
スマホの画面上でタブレットやデスクトップのCSSメディアクエリをプレビューするには？+
SuperCodeのライブWebプレビュー内にあるフローティングDynamic Islandのビューポートアイコンをタップするだけで、モバイル・タブレット(`768dp`)・ワイドデスクトップを瞬時に切り替えられ、`@media`ルールが正確に適用されます。
ワンタップフォーマッタは`<style>`内のCSSや`<script>`内のJSも整形しますか？+
はい。SuperCodeの再帰HTMLフォーマッタは`.html`ファイル内の埋め込み`<style>`および`<script>`ブロックも解析し、ワンタップで3言語すべてのインデントを美しく整えます。
ローカルの`.mp4`動画、`.woff2`フォント、`.glb` 3Dモデルはオフラインで使えますか？+
はい。`font/woff2`、`model/gltf-binary`、`image/svg+xml`を含む65種以上のMIMEタイプがローカル設定済みで、`<video>`・`<audio>`の滑らかなタイムラインシークを実現するHTTP `206 Partial Content`バイト範囲ストリーミングにも対応しています。
