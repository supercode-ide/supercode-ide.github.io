05 よくある質問

よくある質問 (FAQ)

C17データ構造、ポインタ循環対策、組み込み stdint.h ヘッダ、課題出力に関するよくある質問。

再帰構造体、連結リスト、二分木を完全オフラインでCコンパイルできますか？+
はい。SuperCodeのオフライン GNU C17 ツールチェーンは完全な再帰構造体、malloc/calloc/realloc/free によるヒープ管理、関数ポインタ、複数ファイルの .c/.h ヘッダをインターネット接続なしでサポートします。
スマホ上で連結リストや while ループが無限ループに入ったらどうなりますか？+
オフラインCプログラムはUIスレッドから分離された専用 Web Worker 内で実行されます。エディタは120Hzの滑らかさを維持し、停止をタップするとANRやアプリクラッシュなしで即座にWorkerを終了します。
1つのフォルダ内で #if 0 の下に複数のテスト用 main() ブロックを保持できますか？+
はい。SuperCodeの O(N) C/C++ プリプロセッサ字句解析器がリンク前に #if 0 や #if false の無効分岐を評価するため、退避したテストブロックが main() 重複エラーを起こすことはありません。
乱れたC課題を整形してAndroid上で直接PDFに出力できますか？+
はい。「整形」をタップすると字句認識型Cフォーマッタが実行され（1タップUndo対応）、そのまま提出用の行番号・シンタックスハイライト付きA4 PDFを出力できます。
