05 よくある質問

よくある質問 (FAQ)

オフラインコンパイラ、GB級ファイルの仕組み、対応言語の独立構成、Git/SFTP 連携に関するよくある質問。

SuperCode IDE ではどのプログラミング言語をオフラインで実行できますか？+
Android 端末単体で Python（3.11 および科学計算用 3.12）、C言語（GNU C17）、C++（GNU C++20）、Java 17、JavaScript（ES2024）、SQL、動的 PHP、HTML5/CSS3/WebAssembly、Lua 5.4、Linux シェルスクリプトをオフライン実行できます。さらに Kotlin や MySQL 8.0 などのクラウド実行にも対応しています。
ギガバイト単位の巨大なログファイルや SQL ダンプを開いてもフリーズしませんか？+
はい、フリーズしません。30 MB を超えるファイルは自動的に GB級ストリームページャへ切り替わり、ディスク上で1000万文字単位のページに分割して読み込みます。ページ番号指定ジャンプ、Shift_JIS を含む34文字コード判別、ディスク横断の正規表現一括置換も高速に行えます。
C言語とC++、あるいは SQL と Web/PHP はそれぞれ独立した専用環境ですか？+
はい。C17 と C++20 はそれぞれ専用の言語規格・ヘッダ・テンプレートを持ち、SQL には9モード出力コンソールと .db バイナリインスペクタ、Web スタジオにはローカル HTTP + PHP + PDO SQLite + WebAssembly サーバーと内蔵 DevTools が用意されています。
アプリ内に Git クライアントや SFTP/FTPS リモートエディタは内蔵されていますか？+
はい。外部ツール不要のビジュアル Git クライアント（PAT クローン、ブランチ管理、コミットタイムマシンの Unified Diff、競合解決 UI）と、AES-256 暗号化保管庫・3段階アトミック保存を備えた SFTP/FTPS (TLS 1.3)/FTP ワークスペースを標準搭載しています。
スマートフォンだけでなく折りたたみ端末やタブレットの横画面にも最適化されていますか？+
はい。スマホ縦画面では親指が届く下部ツールバーと右端スワイプメニュー、入力時に自動折りたたみされるコンソールを採用し、タブレットや折りたたみ横画面では縦ドックツールバーと 55% / 45% の2ペイン並列ワークステーションへ自動変形します。
