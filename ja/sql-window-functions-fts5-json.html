05 よくある質問

よくある質問 (FAQ)

SQL学習者、データサイエンス学生、バックエンド面接受験者から寄せられるよくある質問。

LeetCode形式のSQLウィンドウ関数問題（`DENSE_RANK`、`LAG`、累積和）をオフラインで練習できますか？+
はい！すべての標準SQLウィンドウ関数（`ROW_NUMBER`、`RANK`、`DENSE_RANK`、`NTILE`、`LAG`、`LEAD`、`FIRST_VALUE`、`LAST_VALUE`、`NTH_VALUE`）および `ROWS`/`RANGE`/`GROUPS` フレーム指定が100%オフラインで動作します。
SuperCodeはSQL内で `MEDIAN()`、`PERCENTILE()`、`STDDEV()` を直接サポートしていますか？+
はい。標準のSQLiteには統計集約関数がありませんが、SuperCodeはネイティブの `MEDIAN(col)`、`PERCENTILE(col, 95)`、`STDDEV(col)` 関数を事前登録しているため、1つの `SELECT` 文で分布を計算できます。
`.sql` クエリ内で `READ_STDIN()` はどのように機能しますか？+
`.sql` ファイル内に `WHERE department = READ_STDIN('Department name: ')` と記述して実行をタップすると、ドックコンソール上で対話的な入力プロンプトが表示され、コードを書き換えずにパラメータ付きクエリを繰り返しテストできます。
FTS5全文検索や R*Tree / Geopoly 空間モジュールは有効になっていますか？+
はい。`USING fts5(...)`（`bm25()`、`highlight()`、`snippet()` を含む）および `USING rtree(...)` / Geopoly 空間拡張の両方が、SuperCodeのオフラインSQLite 3.54.1エンジンに直接コンパイルされています。
