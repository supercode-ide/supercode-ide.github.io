02 主要エンジニアリング機能

スマホでPythonライブラリを追加する4つの手軽な方法

高速Wi-Fi環境でも、ネットのない教室でも、SuperCodeならPythonの依存関係を整理して永続化できます。

02.1

Auto-PIP 未導入import検出 & 35+ エイリアスマップ

import bs4、import yaml、import dotenv、import jwt、import telebot を記述して実行を押すだけ。SuperCodeが自動で正規のPyPIパッケージ（beautifulsoup4、pyyaml、python-dotenv、PyJWT、pyTelegramBotAPI）へ紐付け、導入後にスクリプトを再実行します。

bs4 -> beautifulsoup4 · yaml -> pyyaml · 35+ エイリアス
02.2

設定不要の requirements.txt ワークスペース検出

Gitリポジトリのクローンや requirements.txt を含むフォルダを開くだけで、ビジュアルPIPマネージャーが最大6階層上まで自動スキャン。行継続（\）や環境マーカーを解析し、ワンタップ一括インストールバナーを表示します。

上位ルートスキャン · 環境マーカー · 一括キュー
02.3

100% オフライン .whl / .tar.gz / .zip ローカル導入

通勤中や機内、制限付き学内Wi-Fiでも安心。pure-Pythonの .whl、.tar.gz、.zip をAndroidのダウンロードフォルダに事前保存しておけば、PEP 440のバージョン検証付きで完全オフライン導入が可能です。

機内モード対応 · .whl / .tar.gz / .zip
02.4

PEP 440 バージョン制約 & コマンドパーサー

「pip install requests>=2.31.0 flask~=3.0」などのコマンドをそのまま入力欄へ貼り付け可能。SuperCodeがCLI定型句を取り除き、==、>=、<=、!=、~= を Python 3.11 向けに評価して互換リリースを解決します。

PEP 440 準拠 · pipコマンド丸ごと貼付対応
02.5

導入済みパッケージ容量確認 & ワンタップ削除

「管理」タブで導入済みライブラリをリアルタイム検索し、正確なバージョンやKB/MB単位のストレージ使用量を確認。不要なパッケージもワンタップでクリーンに削除できます。

リアルタイム検索 · 正確な容量表示 · クリーン削除

03 実践ステップガイド

ステップ解説：SuperCodeでのPIP & オフラインWheelの使い方

オンラインでのPyPI導入も、オフラインでの .whl サイドロードも30秒以内で完了。

STEP 01 Python Console -> PIP Icon

ビジュアルPIPパッケージマネージャーを開く

任意の .py ファイルを開いてPythonコンソール上部のPIPアイコンをタップするか、未導入のimportを含むスクリプトを実行してAuto-PIPを起動します。

STEP 02 Quick Chips / Input Box

人気チップをタップ、pip install貼付、または requirements.txt 選択

ワンクリックチップ（requests、rich、beautifulsoup4、pyyaml、flask、telebot、colorama）を選ぶか、バージョン指定を入力、または自動検出された requirements.txt バナーをタップします。

STEP 03 Import Local Archive (.whl)

オフラインならダウンロードから .whl / .zip を参照

オフライン環境ではPIPダイアログの「ローカルアーカイブ」をタップし、ダウンロードまたはプロジェクトフォルダ内の .whl、.tar.gz、.zip をスキャンして導入します。

STEP 04 Manage Tab -> Verify

複数ファイルのスクリプトから即座にimport可能

導入したライブラリは独立した site-packages に永続保存され、アプリ再起動後もそのまま維持され、AST自動補完と即座に連携します。

デバイス内永続 site-packages · 50ms ノンブロッキング導入ログストリーム 入門ガイド

05 よくある質問

よくある質問 (FAQ)

AndroidでのPyPIパッケージ、オフライン .whl、requirements.txt の導入に関するよくある質問。

`pip install requests beautifulsoup4` のようなコマンドをそのまま貼り付けられますか？+
はい。PIP入力パーサーが先頭の `pip install`、`pip3 install`、`python -m pip install` を自動除去し、非対応のCLIフラグを安全に無視して、PEP 440のバージョン制約付きで全パッケージをキュー登録します。
ネット接続がない環境でAndroidにPythonパッケージを入れるには？+
pure-Pythonの `.whl`（`*-py3-none-any.whl` など）、`.tar.gz`、または `.zip` アーカイブを事前にスマホへ保存し、SuperCodeのPIPパッケージマネージャーで「ローカルアーカイブ」ボタンをタップすればダウンロードフォルダから直接導入できます。
なぜ `numpy` や `matplotlib` を手動で `pip install` する必要がないのですか？+
NumPy、Pandas、SciPy、Matplotlib、Scikit-Learnなどの重いC/Fortranネイティブ拡張を含むライブラリはSuperCodeの科学計算ランタイムに事前対応済みです。スクリプトに `import numpy as np` と書いて実行するだけで動作します。
導入したPIPパッケージはアプリを閉じてもスマホに残りますか？+
はい。導入されたパッケージはSuperCodeのローカル `python_site_packages` ストレージに永続保存されるため、再インストールなしでいつでもオフライン実行できます。
