重厚な PC 環境なしで、モダン Java 17 の表現力をフル活用

02.1

モダンなオフライン Java 17 構文＆簡潔な void main() 対応

record クラス、sealed インターフェース、switch -> 式、instanceof パターンマッチング、テキストブロック（"""）、Stream API、java.time、さらに学習者に優しい簡潔な void main() を 100% オフラインでサポートします。

05 よくある質問

よくある質問 (FAQ)

Java 17 の対応構文、複数ファイル OOP、外部 .jar 読み込み、オフライン Scanner 入力に関する質問。

Android 端末のオフライン環境でどのバージョンの Java をコンパイルできますか？+
Java 17 を完全オフラインでコンパイル・実行できます（record、sealed クラス、switch 式、instanceof パターンマッチング、テキストブロック、Stream API 等に対応）。さらに Java 21+ の機能を使う場合はクラウド Java へ自動連携します。
複数のクラスや複数パッケージに分かれた Java プロジェクトも動かせますか？+
はい。プロジェクトフォルダおよび開いているタブ内の全 .java ファイルを自動解決し、main() を含むエントリクラスを自動判別して実行します。書き出されたファイルもワークスペースへ自動同期されます。
Java からローカルの SQLite データベースに接続したり、外部の .jar を追加できますか？+
はい！オフライン動作する jdbc:sqlite:... ドライバが最初から内蔵されているほか、プロジェクト内の libs/ ディレクトリに配置した互換 .jar ライブラリも自動的にクラスパスへ読み込まれます。
Scanner(System.in) を使ったキーボードからの対話入力は動作しますか？+
はい。Scanner や BufferedReader が入力を待つタイミングでプログラムが適切に一時停止し、分割ターミナルから複数行のデータをリアルタイムに入力できます。
