02 主要エンジニアリング機能

快適なスクリプト編集、ローカルのテキスト処理パイプライン、そして Kotlin 実行

外部ターミナルアプリを行き来することなく、タッチ操作に最適化された編集・自動整形と本物のパイプライン実行を両立します。

02.1

ネイティブ OS シェル実行＆ Toybox パイプライン処理

通常の共有ストレージ上では chmod +x が制限される Android 環境でも、grep、awk、sed、sort、uniq、wc、cut、tr、find、cat やリダイレクトを使った .sh スクリプトをローカルでクリーンに実行できます。

grep · awk · sed · sort · uniq · find · パイプ処理
02.2

複数スクリプトの source 読込＆生成ファイルの自動ツリー同期

フォルダ内の補助 .sh スクリプトを source で読み込み、対話型 read 入力を受け付け、スクリプトが生成・変換したレポートファイルを自動的にエクスプローラへ反映します。

複数ファイル source · ライブ read 入力 · 生成物自動同期
02.3

GNU Bash 5.2 ＆ 1タップ Kotlin (.kt) クラウドスタジオ

GNU Bash 5 の連想配列や、Kotlin のデータクラス・コルーチン・関数型コードを動かしたい時は、専用のクラウドランタイムへシームレスにルーティングしてビルド・実行します。

Ubuntu Bash 5.2 · Kotlin .kt / .kts ビルド＆実行
02.4

Shell ＆ Kotlin 対応 AST コード補完＋オフラインフォーマッタ

${var:-default} などのシェル変数展開ヒント、Kotlin の AST 補完、Shell と Kotlin/Gradle 両対応のオフラインコード整形、6種の内蔵シェルテンプレートを完備しています。

Shell + Kotlin 自動整形 · Dockerfile/Makefile ハイライト

05 よくある質問

よくある質問 (FAQ)

Android ストレージ上での .sh 実行の仕組み、awk/sed パイプライン、Kotlin コンパイルに関する質問。

Android の共有フォルダは chmod +x が効かないのに、なぜ SuperCode では普通に .sh を実行できるのですか？+
SuperCode がバックグラウンドで $PWD（作業ディレクトリ）をネイティブシェル環境と透過的に整合させて実行し、生成・更新された出力ファイルを即座に元のプロジェクトフォルダへ同期するためです。
SuperCode で Kotlin (.kt) のコードを書いて実行することもできますか？+
はい！Kotlin および Gradle（.kt、.kts、.gradle.kts）の構文ハイライト、オフライン AST コード補完、オフライン自動コード整形、そして1タップでのクラウド Kotlin コンパイル＆実行に対応しています。
Android 標準の sh にはない GNU Bash 5 の連想配列などを使うスクリプトはどうなりますか？+
Bash 固有の構文や # @cloud 指定を自動検知し、ワークスペースのスクリプトを Ubuntu GNU Bash 5.2 環境へ自動でルーティングして実行します。

スマートフォンひとつで、シェルスクリプトも Kotlin も自在に実行。
