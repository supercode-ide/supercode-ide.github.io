02 主要エンジニアリング機能

純粋なスクリプトから科学計算プロットまで支える3層 Python 基盤

大学のプログラミング課題からデータ可視化、Web スクレイピングまで、面倒な黒い画面の環境構築なしで即座に動かせます。

02.1

完全オフラインの複数ファイル Python 3.11 ＆ エントリ自動解決

.py、.json、.csv、.yaml、.toml にまたがるマルチモジュール構成を 100% オフライン実行。サブモジュールのタブを開いたまま実行を押しても、プロジェクトのメインスクリプトを自動特定して起動します。

複数ファイル import · 未保存タブ即時反映 · ファイル自動同期
02.2

端末内キャッシュ対応の NumPy・Pandas・Matplotlib

numpy、scipy、pandas、matplotlib、scikit-learn の import を検知すると端末内の科学計算ランタイムを起動。ローカルにホイールをキャッシュするため、データ集計や plt.savefig() による画像生成がオフラインで完結します。

NumPy · Pandas · Matplotlib · PNG/SVG/PDF 自動出力
02.3

ビジュアル PIP マネージャ・Auto-PIP ＆ オフライン .whl 導入

bs4 や yaml が未導入でも、Auto-PIP が別名（bs4 -> beautifulsoup4）を自動解決して PyPI から導入・再実行します。requirements.txt の一括導入やローカル .whl/.zip のオフラインインストールにも対応。

Auto-PIP 自動解決 · requirements.txt · ローカル .whl 読込
02.4

リアルタイム対話 input() ＆ 可変分割コンソール

複数回連続する input() プロンプトへのリアルタイム入力に対応。コンソールはタイピング中に自動でコンパクトに畳まれ、タブレット横画面では 55%/45% の左右2ペインで快適に対話できます。

対話 Stdin · ANSI フルカラー · 7sp–26sp ピンチズーム

PEP 8 自動整形・AST コード補完＆エラーレーダー

Python 専用21キー記号バー、オフライン AST メンバ補完、1タップ PEP 8 インデント整形に加え、実行前に TabError（インデント混在）やコロン抜けを警告するエラーレーダーを備えています。

03 実践ステップガイド

SuperCode で Python 開発＆パッケージ管理を行う4ステップ

空のフォルダからわずか4タップで、複数ファイル Python ＆ Matplotlib プロジェクトが動き出します。

STEP 01 新規作成 -> main.py

スクリプト作成または内蔵 Python サンプルを読込

オフライン実行＆リアルタイム input() 対話

05 よくある質問

よくある質問 (FAQ)

オフラインでの Python 実行、pip/.whl ライブラリの導入、NumPy/Matplotlib 画像出力、複数ファイル分割に関する質問。

インターネットに繋がっていない場所でも Android で Python を書いて実行できますか？+
はい、完全にオフラインで動作します。複数ファイルの Python 3.11 スクリプト、標準ライブラリ、導入済みの PIP/.whl パッケージ、および端末内にキャッシュされた Python 3.12 科学計算ライブラリ（NumPy、Pandas、Matplotlib、SciPy、scikit-learn）がネットなしで高速に実行できます。
requests や bs4 などの外部ライブラリや、オフライン用の .whl ファイルはどうやって入れますか？+
ビジュアル PIP パッケージマネージャを開くか、そのままスクリプトを実行して Auto-PIP に不足パッケージを自動検知させます。PyPI からの取得、requirements.txt の一括導入、端末のダウンロードフォルダにある .whl / .tar.gz / .zip の直接インポートに対応しています。
Matplotlib で描画したグラフや open('data.csv', 'w') で保存したファイルはどこに出力されますか？+
スクリプトが書き出した画像・PDF・CSV・JSON ファイルはすべて作業中のプロジェクトフォルダへ自動的に同期され、SuperCode 内蔵の画像ビューアやエディタでその場ですぐに開けます。
ループ内で何度も入力を受け付けるような対話型 input() にも対応していますか？+
はい。スクリプトが input() を呼び出すたびに分割コンソールの入力欄がハイライトされ、リアルタイムに値を送信して対話的に実行を進められます。
