02 主要エンジニアリング機能

必須となるすべての Git ワークフローを、タッチ操作のために専用設計

リポジトリ排他ロック、未保存タブの自動フラッシュ保存、Detached HEAD 救出バナーにより、モバイルでも安心してバージョン管理が行えます。

02.1

タクティカル Git ダッシュボード＆マルチリポジトリ切替

マウント中のリポジトリ、現在のブランチ、短縮コミットハッシュ、リモートとの ↑Ahead / ↓Behind 差分、変更・追加・削除・競合ファイル数をひと目で把握し、複数リポジトリも1タップで切り替えられます。

複数リポジトリ切替 · ↑Ahead ↓Behind 表示 · 既存 .git マウント
02.2

HTTPS + PAT クローン＆暗号化トークン永続保管

パーソナルアクセストークン（PAT）を使って GitHub、GitLab、Gitee、Bitbucket、自社ホスト Git サーバーから公開・非公開リポジトリをクローン。保存先名も自動補完され、トークンは次回以降の Push のため安全に暗号化保管されます。

GitHub / GitLab / Bitbucket PAT · リアルタイム転送進捗
02.3

未保存タブの自動書き出し・変更プレビュー＆ Author 設定

コミット前に編集中の未保存タブを自動でディスクへ保存するため、書き忘れによるコミット漏れが起きません。最大80件の変更ファイルを [M]/[A]/[U]/[D] バッジ付きで事前確認でき、Author 名とメールアドレスも自在に設定可能です。

保存忘れゼロ · カスタム Author 設定 · 自動 Upstream 紐付け
02.4

自動退避（Auto-Stash）＆カーソル行・列維持リロード付きスマート Pull

未コミットのローカル変更がある状態で Pull しても、余計な仮コミットを作らず自動で Stash 退避 -> リモート取得 -> 変更の再適用を行い、開いているエディタタブを現在のカーソル行・列を保ったままその場でホットリロードします！

ノイズゼロ Auto-Stash · カーソル位置維持タブ自動更新
02.5

Git タイムマシン・ブランチ作成＆2D カラー Unified Diff ビューア

最大120件のコミット履歴を遡り、任意のコミットの +緑 / -赤 カラー Unified Diff を縦横スクロールで閲覧。ローカル/リモートブランチの作成・切替、安全なスナップショット確認、確認付き Hard Reset に対応しています。

カラー Unified Diff · + 新規ブランチ · Detached HEAD 救出バナー
02.6

複数ファイル対応ビジュアル・マージコンフリクト解決 UI

もう小さな画面で競合マーカー記号を手作業で削る必要はありません。競合ファイル（1 / N）を順に表示し、見やすい「ローカル vs リモート」比較カード上で「現在を維持」「受信を採用」「両方を維持」をタップするだけで自動ステージングされます。

現在 / 受信 / 両方を維持 · 自動ステージング＆即 Push

03 実践ステップガイド

完全6ステップガイド：SuperCode IDE での Git 実践手順

スマホやタブレットから、クローン・ブランチ作成・差分確認・競合解決・プッシュまで迷わず行える手順です。

STEP 01 Menu -> Git Controls -> Clone

リモートをクローンまたは既存ローカル .git をマウント

HTTPS URL（例：https://github.com/user/repo.git）と任意の PAT トークンを貼り付けて CLONE を押すか、既存の .git フォルダをマウントします。

STEP 02 Time Machine -> Branch ▾

作業用フィーチャーブランチの切替・新規作成

Git タイムマシン上部のブランチ選択からブランチを切り替えるか、命名規則チェック付きの「+ 新規ブランチ作成…」（例：feature/mobile-ui）を実行します。

STEP 03 Editor Tabs -> Save / Edit

フル機能のオフライン IDE で複数ファイルを開発

オフラインでコードを編集・整形・実行テストします。万が一タブの保存を忘れていても、Git 操作の直前に自動でディスクへ保存されます。

STEP 04 Git Dashboard -> Pull

プッシュ前にチームのリモート変更を安全に取り込む

Push 前に Pull をタップします。未コミットの変更は自動で退避・復元され、開いているタブもカーソル位置を保ったまま最新状態へ更新されます。

STEP 05 Open Conflict Resolver

重複箇所のマージコンフリクトをカード UI で視覚解決

編集箇所が重なった場合は「競合解決を開く」をタップし、ローカルとリモートを並べて比較しながら採用方法を選んで一括反映します。

STEP 06 Commit & Push

変更ファイル一覧を確認し、メッセージを書いて Push

変更リストの [M]/[A]/[D] バッジと Author 情報・コミットメッセージを確認し、COMMIT をタップしてステージングから origin への Push まで完了します。

残留 index.lock の自動復旧機構を搭載 · オフライン環境でのローカルコミット・履歴閲覧に対応 入門ガイド

05 よくある質問

よくある質問 (FAQ)

GitHub パーソナルアクセストークン（PAT）、非公開リポジトリ、マージ競合、オフラインコミットに関する質問。

GitHub や GitLab のプライベート（非公開）リポジトリにはどうやって認証しますか？+
GitHub / GitLab 等で repo スコープ付きの HTTPS パーソナルアクセストークン（PAT）を発行し、初回クローンや Pull / Push 時のトークン欄に貼り付けるだけです。安全に暗号化保存されるため毎回入力し直す必要はありません。
未保存のタブや未コミットの変更がある状態で Pull を押すとどうなりますか？+
まず未保存タブを自動でディスクへ書き出し、未コミットの変更を自動で Stash 退避したうえで最新のリモートコミットを取り込み、ローカル変更を再適用して現在のカーソル行のままタブを再読み込みします。
過去のコミットでの変更差分を見たり、以前のバージョンへ戻すにはどうすればいいですか？+
Git ダッシュボードから「Git タイムマシン」を開き、任意のコミットをタップします。「コード変更を表示（Commit Diff）」で色分けされた Unified Diff の閲覧、「チェックアウト（閲覧専用）」で過去状態の安全な確認、「Hard Reset」でブランチの巻き戻しが行えます。
移動中などインターネット接続がないオフライン状態でもコミットできますか？+
はい！ステージング、ローカルコミット、ブランチ作成、履歴と Unified Diff の閲覧、競合解決はすべてオフラインで動作し、オンラインに戻ったタイミングでまとめて origin へ Push できます。
