02 主要エンジニアリング機能

実戦のソフトウェア開発を見据え、ツールバーからゼロベースで設計

閉じ括弧の自動スキップから選択範囲の基準インデントを保つコード整形まで、すべてのマイクロ操作を親指のスピードと視認性のために磨き上げました。

02.1

ハイブリッド AST 文脈認識コード補完

C/C++、Python、Java、Kotlin、JS/TS、HTML、CSS、PHP、Lua、Shell、SQL で . / -> / :: / : の入力時に自動起動。ローカル変数の型、構造体・クラスメンバ、STL/DOM API、スニペットを完全オフラインで解決します。

演算子：. · -> · :: · : | 10言語ファミリー対応
02.2

デュアルモード構文ハイライト＆拡張子なし自動判別

表示中のビューポートを 120Hz コマ落ちゼロで即座に色分けし、文字列内の書式トークン（\n、%d、{0}）や @param/TODO タグも精密に強調。拡張子のない新規タブも #! Shebang と語彙スコアから言語を自動推定します。

40+ 拡張子対応 · Shebang 自動判別 · 120Hz ゼロ遅延
02.3

30種以上のオフライン自動コード整形＆スマートコメント

C/C++、Java、Kotlin、JS/TS、Python (PEP 8)、JSON、CSS、PHP、SQL、Lua、Shell、さらに HTML/Vue（内包する script と style ブロックも再帰的に一括整形！）をベースインデントを維持したまま1回の Undo 単位で美しく整形します。

1ステップ Undo 対応 · HTML/JS/CSS 再帰フォーマット
02.4

エラーレーダー V2.0 ＆ ホログラフィック文書統計

括弧の不一致、閉じ忘れた文字列・タグ、Python の TabError やコロン漏れ、JSON の末尾カンマを実行前に検出し、1タップで該当の行・列へジャンプ。全体および選択範囲の行数・単語数・文字数・正確な UTF-8 バイト数も同時表示します。

行/列 1タップ移動 · 全体＆選択範囲 UTF-8 バイト計測
02.5

29機能・5モード可変ツールバー＆右端スワイプメニュー

コード・プレーンテキスト・選択・検索・超大容量ファイルの5モードへ自動変形し、横画面ではサイドに縦ドック化。さらに5つの常駐クイックスロットを備えた 120Hz 右画面端スワイプメニューで片手操作を極められます。

5つの自動モード · 5つの常駐スロット · 15MB 仮想クリップボード
02.6

21キー上フリック記号バー・8つの光学テーマ＆A4 PDF 出力

6種の言語別プロファイルを自動切替し、拡大ルーペ付き上フリック入力とソフトキーボードを抑止するカーソルロックを搭載。WCAG AAA 準拠の8つの光学テーマ（自動昼夜切替）、禅モード、A4 等幅フォント PDF 書き出しに対応。

03 実践ステップガイド

エディタ環境を自分好みにカスタマイズして使いこなす手順

わずか2分で、デスクトップ級に快適なモバイルコーディング環境が整います。

STEP 01 エクスプローラ / スマート保存

あらゆるソースファイルを作成・マルチタブで開く

内部ストレージ、SD/USB OTG、Git、SFTP から複数タブでファイルを開きます。無題のメモでも構文を自動認識し、保存時に最適な拡張子を提案します。

STEP 02 21キー記号バー

2層アクションキーと AST 補完で高速タイピング

タップで括弧ペア挿入や選択範囲の囲み処理を行い、キーを上へ払えば第2記号（===、/**/、逆インデント等）を入力しつつ 0ms で AST メンバ補完を呼び出せます。

STEP 03 整形 · 診断 · 文字数カウント

インデントを整え、エラーレーダーで事前チェック

「整形」タップで瞬時に美しいインデントへ揃え、「カウント」からエラーレーダーの座標リストと正確な UTF-8 バイト統計を確認します。

STEP 04 画面右端から内スワイプ

片手で5スロット常駐クイックメニューを起動

画面の右端から親指で内側へ引くだけで、メニューを閉じずに Undo/Redo/テーマ/折り返しを連続タップしたり、禅モードや A4 PDF 出力を実行できます。

タブの横ドラッグ並び替え対応 · 未保存タブを自動保護するホットイグジット搭載 入門ガイド

05 よくある質問

よくある質問 (FAQ)

オフライン整形・補完の対象言語、ツールバーの並び替え、PDF・画像表示機能に関するよくある質問。

コードの自動補完やフォーマット（整形）は 100% オフラインで動作しますか？+
はい。AST 文脈コード補完、デュアルモード構文ハイライト、エラーレーダーによるリアルタイム構文チェック、そして30言語以上のコードフォーマッタはすべてネット接続なしで端末内完結で動作します。
21キー記号キーボードを使うと、なぜスマホでのコーディングが速くなるのですか？+
開いているファイルに応じて6種類の言語プロファイル（C/C++、Python、Java/Kotlin、JS/TS、Web、Shell/SQL）を自動切替し、選択テキストの括弧囲み、拡大ルーペ付きの上フリック第2記号入力、さらに閲覧中にシステムキーボードを出さない「カーソルロック」を備えているためです。
下部ツールバーやクイックメニューのボタン配置は自由に変更できますか？+
はい。「設定 -> ツールバーとメニューのカスタマイズ」から、ドラッグ＆ドロップでメインツールバーおよび5つの常駐クイックスロットの順序を自由に入れ替えられ、1タップで初期配置にも戻せます。
ソースコードを PDF に書き出したり、アプリ内で画像や PDF を確認できますか？+
はい。「印刷」または「.pdf として保存」で美しい A4 等幅コード PDF を生成できるほか、プロジェクト内の PDF（1〜5倍ズーム・ページ移動）や WEBP・HEIC・AVIF・ICO を含む10形式の画像を IDE 内で直接プレビューできます。

デスクトップ品質のコード編集体験を、あなたの Android に。
