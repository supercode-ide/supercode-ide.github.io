05 よくある質問

よくある質問 (FAQ)

SuperCodeのJava 17プロジェクトテンプレート25選、オフライン ECJ + D8 ビルド、カスタマイズに関するよくある質問。

25種類の複数ファイルJavaプロジェクトテンプレートはすべてAndroidオフラインで動きますか？+
はい。25テンプレートすべてがAWT非依存の純粋な Java 17 プロジェクトであり、SuperCodeのオフライン ECJ + D8 + DexClassLoader ランタイム向けに検証済みのため、機内モードでもコンパイル・実行できます。
テンプレートに独自の .java パッケージや外部 .jar ライブラリを追加できますか？+
はい。プロジェクトツリー内のどこにでも新しいフォルダや .java ファイルを追加でき（最大500ファイル）、libs/*.jar にカスタムJARを配置すればSuperCodeが自動でコンパイル・リンクします。
対話型テンプレートが NoSuchElementException でクラッシュしないのはなぜですか？+
Scanner(System.in) を使用するすべてのテンプレートに適切なEOFガードと実用的なデモフォールバックが組み込まれているため、対話コンソール入力でも自動実行でも安全に動作します。
1クラスを編集した後、複数ファイルJavaテンプレートの再ビルドはどれくらい高速ですか？+
SuperCodeはソースツリーを SHA-256 でハッシュ化します。未変更の再実行はDEXキャッシュから約0msで起動し、差分編集も1秒未満でクリーンに再コンパイルされます。
