02 主要エンジニアリング機能

競技プログラマ・情報系専攻生・C++ エンジニアのために設計

モバイルキーボードでの記号入力ストレス、クラウド実行の待ち時間、煩雑な CMake 設定から解放され、モダン C++20 の実装に集中できます。

02.1

完全オフライン対応の C++20 標準テンプレートライブラリ (STL)

std::vector、map、unordered_map、set、priority_queue、string_view、optional、unique_ptr/shared_ptr、std::ranges::sort、ラムダ式、テンプレートをネットなしでフル活用できます。

-std=gnu++2a · STL コンテナ完備 · Ranges ＆ テンプレート
02.2

std:: / -> / :: を即座に解決する高精度 AST コード補完

v. や ptr->、std:: と入力した瞬間に、STL コンテナ、イテレータ、ストリーム、スマートポインタ、自作クラスのメンバ候補をオフラインで高速提示します。

AST 型推論エンジン · C++ 専用21キー記号プロファイル
02.3

複数ファイル .cpp / .hpp 自動ビルダ＆差分ハッシュキャッシュ

サブフォルダを含む .cpp、.cc、.cxx、.hpp、.hh、.hxx、.inl ファイルに対応。未変更の翻訳単位はハッシュキャッシュによりスキップされ、反復ビルドを劇的に高速化します。

マルチファイル OOP · ヘッダからでも main.cpp を自動実行
02.4

競プロ仕様の分割コンソール＆ライブ std::cin 入力

複数行のテストケースをそのまま std::cin へ貼り付け、正確な実行時間（ms）とピークメモリ（KB）を計測。タブレット横画面では 55%/45% の2ペイン並列画面で問題考察と実装が捗ります。

高速 I/O · キーボード連動折りたたみ · 12x12 カラーパレット
02.5

ofstream ファイル出力同期＆暴走ループ・再帰保護

std::ofstream で書き出したファイルはプロジェクトツリーへ直ちに同期。さらに15秒 CPU ウォッチドッグと25万文字出力上限が、無限再帰や無限ループから作業中のコードを安全に守ります。

ofstream 自動同期 · 15秒ウォッチドッグ · 8つの C++ テンプレート
02.6

マルチスレッド＆ネットワーク対応クラウド C++ シームレス拡張

thread や std::async、POSIX ソケット通信を使用するコードは、自動的に複数ファイルをバンドルして -pthread 有効のクラウド C++ クラスターでビルドし、1:1 の行番号診断を返します。

std::thread 対応 · 正確なエディタ行番号エラー表示
スマホ・折りたたみ・タブレット対応 · 軽量 40.2 MB 概要

05 よくある質問

よくある質問 (FAQ)

オフライン C++20 対応、AtCoder 等の競技プログラミング適性、複数ヘッダ結合、スレッド利用に関する質問。

圏外や機内モードなど、ネットなしでも C++20 と STL コンテナをコンパイルできますか？+
はい。初回利用時にオフライン C++ ツールチェーンが初期化された後は、GNU C++20 (-std=gnu++2a) と完全な STL（vector、map、priority_queue、ranges、スマートポインタ、ラムダ等）が 100% オフラインでコンパイル・実行できます。
スマホやタブレットでの競技プログラミング（AtCoder、Codeforces、LeetCode 等）に向いていますか？+
最適です。差分キャッシュによる高速ビルド、複数行ペースト対応のライブ std::cin、ミリ秒・KB 単位の実行テレメトリ、そして 55%/45% 横画面分割コンソールにより、移動中でも快適にアルゴリズム精進が行えます。
複数の .cpp と .hpp に分かれたプロジェクトはどうやってビルドしますか？+
同じプロジェクトフォルダ（または開いているタブ）に .hpp と .cpp を置くだけです。SuperCode がローカル include を自動探索して全実装ファイルをリンクし、ヘッダタブから実行を押した場合でも main() を自動特定して起動します。
C++ の std::thread やソケット通信 API を使うコードも動かせますか？+
はい。OS レベルのスレッドやネットワーク系ヘッダを検知すると、自動的に複数ファイルプロジェクトを -pthread 対応のクラウド C++ クラスターへルーティングして実行します。

スマホでもタブレットでも、モダン C++20 をオフラインで高速ビルド。
