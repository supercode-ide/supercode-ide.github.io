05 よくある質問

よくある質問 (FAQ)

`.kt` / `.kts` のコンパイル、オフライン編集、APK ビルドに関するよくある質問。

SuperCode で Kotlin をコンパイルするにはインターネット接続が必要ですか？+
コード編集、シンタックスハイライト、AST 自動補完、`.kt`/`.gradle.kts` の整形、Visual Git、A4 PDF 書き出しはすべて 100% オフラインで動作します。`.kt` / `.kts` のコンパイルと実行には SuperCode の高速クラウド Kotlin コンパイラを使用します（なお Java 17 は端末上で 100% オフラインコンパイル可能です）。
Kotlin の `readln()` や `Scanner` に複数行のテスト入力を渡せますか？+
はい！実行をタップする前にコンソールの常駐 `stdin` 入力バーへ複数行のテストケースを入力または貼り付けるだけで、競技プログラミングや面接対策をスムーズに行えます。
SuperCode はマルチモジュールの Gradle Android `.apk` パッケージもビルドできますか？+
SuperCode はスタンドアロンの Kotlin（`.kt`/`.kts`）プログラミング、OOP モデリング、関数型パイプライン、DSA 演習、および Git 経由での `.gradle.kts` 編集に特化しており、数 GB 規模の Android SDK `.apk` ビルドには対応していません。
`build.gradle.kts` ファイルもオフラインで整形できますか？+
はい。`.kt` / `.kts` ソースファイルと `.gradle.kts`（Gradle Kotlin DSL スクリプト）の両方が、SuperCode のオフラインシンタックスハイライトとワンタップコードフォーマッタに対応しています。
