05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Válaszok a C++20 többfájlos fordítási hibákkal, AST kiegészítéssel, C++ formázással és Git integrációval kapcsolatban.

A többfájlos C++ fordítási hibák megmutatják a pontos .hpp vagy .cpp fájlnevet és sorszámot?+
Igen. Mind az offline C++20 fordító, mind a Unity Cloud C++ fájlonként szabványos #line 1 direktívákat bocsát ki, így a figyelmeztetések és hibák 1:1 arányban visszavezethetők a pontos helyi fejléc- vagy forrássorra.
Működik a SuperCode C++ kódkiegészítése internetkapcsolat nélkül?+
Igen. A SuperCode egy 100% offline Tree-sitter WASM AST motort futtat az eszközön, amely kontextusfüggő kiegészítést nyújt ::, -> és . operátoroknál szerverhívások nélkül.
Elrontja a C++ formázó a C++ nyers string literálokat vagy előfeldolgozó direktívákat?+
Nem. A SuperCode lexer-alapú C++ formázója tisztán követi a kommenteket, string/karakter literálokat és előfeldolgozó sorokat, támogatja a részleges kijelölés formázását, és azonnali 1 érintéses visszavonást kínál.
Commitolhatok és pusholhatok C++ projekteket közvetlenül GitHubra Termux telepítése nélkül?+
Igen. A SuperCode natív Visual Git klienst tartalmaz, amely támogatja a HTTPS Personal Access Token alapú klónozást/pullt/pusht, ágváltást, színkódolt commit diffeket és a vizuális összevonási ütközésfeloldót.
