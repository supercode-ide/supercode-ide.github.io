05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Válaszok az SQLite REGEXP_REPLACE, SHA-256 hashelő UDF-ek, többfájlos .read szkriptek és az ATTACH DATABASE használatáról.

Működik offline a REGEXP és a REGEXP_REPLACE a SuperCode-ban bővítmények betöltése nélkül?+
Igen. A SuperCode az Android natív ICU Unicode regex motorját (64 elemű LRU gyorsítótárral) közvetlenül az SQLite 3.54.1-hez köti, így a REGEXP, REGEXP_LIKE, REGEXP_REPLACE és REGEXP_EXTRACT alapból elérhető.
Milyen kriptográfiai hash függvényeket hívhatok meg közvetlenül az SQL lekérdezésekben?+
A SuperCode a BoringSSL alapú MD5, SHA1, SHA224, SHA256, SHA384, SHA512 és HMAC_SHA256 UDF-eket teszi natívan elérhetővé offline hasheléshez, ellenőrző összegekhez és anonimizáláshoz.
Futtathat egy SQL szkript alárendelt .sql fájlokat és összekapcsolhat több .db adatbázist?+
Igen. Használd a .read relative/file.sql parancsot a moduláris séma/adat szkriptek beolvasásához, és az ATTACH DATABASE 'other.db' AS alias utasítást több projektmappabeli SQLite fájl összekapcsolásához vagy mentéséhez.
Mi történik, ha egy véletlen cross-join túl sokáig fut egy nagy .db fájlon?+
Koppints bármikor a Leállítás gombra — a SuperCode azonnali SQLite megszakítást / CancellationSignal leállítást indít, így a hosszú lekérdezések tisztán leállnak az adatbázis zárolása vagy a felület lefagyása nélkül.
