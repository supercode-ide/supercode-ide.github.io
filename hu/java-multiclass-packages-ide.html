05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Gyakori kérdések a többcsomagos elrendezésekről, külső .jar könyvtárak hozzáadásáról és a main() feloldásáról.

Hogyan adhatok hozzá külső `.jar` könyvtárat (például Gson vagy Commons Lang) a SuperCode-ban?+
Hozz létre egy `libs` (vagy `lib`) nevű mappát a Java projekted gyökerében, és másold bele a `.jar` fájlt. A SuperCode automatikusan hozzáadja a `libs/` mappában lévő összes `.jar` archívumot (30 MB-ig) a fordítási és futásidejű classpath-hoz is — nincs szükség build szkriptekre.
Mi történik, ha olyan Java osztály szerkesztése közben nyomok a Futtatásra, amelyben nincs `main()`?+
A SuperCode belépésipont-választója átvizsgálja a projekt lefordított osztályait, automatikusan kiválasztja a `main()` metódust tartalmazó elsődleges belépő osztályt, és elindítja azt — így nem kell állandóan ide-oda váltogatnod a fülek között.
Muszáj a `src/main/java` struktúrát használnom, vagy az egyszerű többfájlos mappák is működnek?+
Mindkettő zökkenőmentesen működik! Elhelyezhetsz két `.java` fájlt egymás mellett egy egyszerű mappában `package` utasítás nélkül, rendezheted őket közvetlenül `com.example.*` almappákba, vagy használhatsz teljes `src/main/java` + `resources/` + `libs/` könyvtárszerkezetet is.
Milyen `.jar` fájlok működnek offline Androidon?+
Bármely szabványos, tisztán Java `.jar` könyvtár, amely Java 8-at, 11-et vagy 17-et céloz (mint például a `gson`, `org.json`, `commons-lang3`, `commons-csv` vagy egyetemi értékelő könyvtárak), 100%-ban offline működik. Az AWT/Swing ablakokat igénylő asztali GUI jar-ok nem mobil konzolokra valók.
