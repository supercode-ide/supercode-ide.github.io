05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Gyakori kérdések a Java 17 funkciókról, többfájlos OOP-ról, egyéni .jar fájlokról és az offline Scanner bemenetről.

Milyen Java verziót fordít a SuperCode offline Androidon?+
A SuperCode offline fordítja és futtatja a Java 17-et — beleértve a recordokat, sealed osztályokat, switch kifejezéseket, az instanceof mintaillesztést, a szövegblokkokat és a Streameket —, automatikus Cloud Java átirányítással a Java 21+ funkciókhoz.
Futtathatok több osztályt és csomagot tartalmazó Java projektet?+
Igen. A SuperCode feloldja az összes .java fájlt a projektmappákban és a nyitott szerkesztőfüleken, automatikusan kiválasztja a main() metódust tartalmazó osztályt, és minden írt fájlt visszaszinkronizál a munkaterületre.
Csatlakoztathatom a Javát helyi SQLite adatbázishoz, vagy adhatok hozzá külső .jar fájlokat?+
Igen! Egy offline jdbc:sqlite:... JDBC illesztőprogram közvetlenül be van építve, és a projekt libs/ könyvtárába helyezett kompatibilis .jar könyvtárak automatikusan bekerülnek a classpath-ba.
Interaktívan működik a Scanner(System.in)?+
Igen. A program tisztán megáll, valahányszor a Scanner vagy BufferedReader bemenetre vár, így több sort is begépelhetsz az osztott képernyős terminálban.
