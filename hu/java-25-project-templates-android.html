05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Válaszok a SuperCode 25 Java 17 projektsablonjával, az offline ECJ + D8 buildekkel és a testreszabással kapcsolatban.

Mind a 25 többfájlos Java projektsablon teljesen offline fut Androidon?+
Igen. Mind a 25 sablon tiszta, AWT-mentes Java 17 projekt, kifejezetten a SuperCode offline ECJ + D8 + DexClassLoader futtatókörnyezetére hitelesítve, így repülőgépes módban is lefordulnak és futnak.
Hozzáadhatom a saját .java csomagjaimat vagy külső .jar könyvtáraimat ezekhez a sablonokhoz?+
Igen. Adj hozzá új mappákat és .java fájlokat bárhol a projektfában (akár 500 fájl), vagy helyezz el egyéni JAR-okat a libs/*.jar mappába – a SuperCode automatikusan lefordítja és linkeli őket.
Miért nem omlanak össze sosem az interaktív sablonok NoSuchElementException hibával?+
Minden Scanner(System.in)-t használó sablon tiszta EOF-védelmet és észszerű demó-tartalékot tartalmaz, így akár élő konzolbemenetet gépelhetsz be, akár azonnali automatizált futtatást indíthatsz.
Milyen gyorsan fordulnak újra a többfájlos Java sablonok egy osztály szerkesztése után?+
A SuperCode SHA-256-tal hasheli a forrásfát – a változatlan futtatások ~0 ms alatt indulnak a DEX gyorsítótárból, az inkrementális módosítások pedig a másodperc töredéke alatt újrafordulnak.
