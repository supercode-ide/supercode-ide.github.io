02 FŐ KÉPESSÉGEK

Minden, ami valódi dinamikus PHP backendek építéséhez kell egy telefonon

Az egyetemi webes beadandóktól és REST API prototípusoktól a teljes CRUD admin felületekig — repülőgépes módban is működőképesen.

02.1

Modern PHP 8.2 szintaxis és 32 szintű többfájlos include-ok

Építs tiszta backend architektúrákat a PHP 8.2 match kifejezéseivel, nyílfüggvényeivel (fn() =>), konstruktor-tulajdonság előléptetéssel, névterekkel, valamint akár 32 szint mély include, require és require_once hierarchiákkal.

PHP 8.2 · match · fn() => · 32 mélységű require_once
02.2

Beépített PDO('sqlite:app.db') és ACID tranzakciók

Csatlakoztasd a PHP szkripteket közvetlenül helyi SQLite adatbázisokhoz a new PDO('sqlite:app.db') hívással — ? és :named előkészített utasításokkal az SQL-injekció ellen, PDO::FETCH_ASSOC móddal és beginTransaction() / commit() / rollBack() támogatással.

php.ini szerkesztés nélkül · Előkészített utasítások · ACID
02.3

Tartós $_SESSION, $_COOKIE és Bcrypt hitelesítés

Építs valódi bejelentkezési, bevásárlókosár- és CSRF-védett folyamatokat offline. A SuperCode megőrzi a $_SESSION és $_COOKIE állapotot az oldalátirányításokon (header('Location: ...')) át, és tartalmazza a natív password_hash() és password_verify() függvényeket.

session_start() · password_hash() · HTTP átirányítások
02.4

$_GET, $_POST, JSON REST API-k és egyedi fejlécek

Kezeld az URL lekérdezési paramétereket, az urlencoded HTML űrlapokat és a nyers php://input JSON adatokat, miközben egyedi HTTP állapotkódokat és header('Content-Type: application/json') válaszokat küldesz a frontend fetch() klienseknek.

$_GET / $_POST · php://input · JSON REST végpontok
02.5

Multipart $_FILES feltöltések akár 24 MB-ig

Tesztelj <input type="file"> űrlapokat az Android kameráddal vagy fájlválasztóddal. Ellenőrizd a MIME metaadatokat a $_FILES tömbben, és mentsd a feltöltött képeket vagy dokumentumokat közvetlenül a munkaterületedre a move_uploaded_file() segítségével akár 24 MB-ig.

multipart/form-data · Kamera/Tárhely · 24 MB limit
02.6

Gazdag alapkiterjesztések: mbstring, PCRE és JSON

Dolgozz fel nemzetközi UTF-8 karakterláncokat az mb_strlen() és mb_substr() függvényekkel, ellenőrizz bemeneteket a preg_match() és preg_replace() segítségével, formázz időbélyegeket, és futtass többfájlos appokat háttérdémonok akkumulátor-merítése nélkül.

mbstring · preg_* · json_encode · Azonnali indulás

03 LÉPÉSRŐL LÉPÉSRE

PHP 8.2 + SQLite projekt futtatása offline Androidon

Nincs szükség root jogosultságra, porttovábbítási menükre vagy külön elindítandó adatbázis-démonra.

STEP 01 New Folder -> index.php

Hozz létre vagy klónozz többfájlos PHP munkaterületet

Hozz létre egy projektmappát index.php, includes/db.php és assets/ elemekkel — a SuperCode automatikusan a projekt gyökerét tekinti helyi webszerver-gyökérnek.

STEP 02 new PDO('sqlite:app.db')

Csatlakozz egy helyi SQLite adatbázishoz

Inicializálj táblákat közvetlenül PHP PDO-ból, vagy készítsd elő és vizsgáld meg az app.db fájlt vizuálisan a SuperCode beépített SQL Studio-jában.

STEP 03 Toolbar -> Run ▶

Tesztelj űrlapokat, munkameneteket és Fetch API-kat Localhoston

Koppints a Futtatás ▶ gombra az élő böngésző-előnézet megnyitásához valódi helyi HTTP eredeten, küldj be POST/fájl űrlapokat, és figyeld a PHP kérések időzítését a Net fülön.

STEP 04 Session Reset / SFTP

Sütik törlése 1 koppintással vagy publikálás SFTP-n keresztül

Töröld az aktív $_SESSION sütiket bármikor az előnézeti sávról a bejelentkezési folyamatok újbóli teszteléséhez, majd telepítsd az ellenőrzött PHP fájlokat közvetlenül a Linux tárhelyedre SFTP/FTPS-en.

05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Válaszok a PHP 8.2, a PDO SQLite, a munkamenetek és a fájlfeltöltések offline androidos futtatásával kapcsolatos gyakori kérdésekre.

Teljesen offline, internet nélkül futtatja a SuperCode a PHP 8.2-t?+
Igen. A SuperCode PHP 8.2 motorja és PDO SQLite adatbázis-illesztőprogramja 100%-ban helyben fut az Android eszközödön — többoldalas PHP webhelyeket, bejelentkezési űrlapokat és JSON API-kat építhetsz és tesztelhetsz repülőgépes módban.
Miért válasszam a SuperCode-ot a KSWEB vagy a terminálban futtatott `php -S` helyett?+
A különálló szerverdémonok manuális virtuális gépútvonalakat igényelnek, folyamatosan futtatják a háttérszolgáltatásokat, és három alkalmazás (szerkesztő, szerver, böngésző) közötti váltásra kényszerítenek. A SuperCode egyesíti az AST PHP szerkesztést, az automatikus projektgyökér-alapú HTTP útválasztást, a Web DevTools-t, az SQL Studio-t és az SFTP publikálást egyetlen pehelysúlyú IDE-ben.
Hívhatja a frontend JavaScript a helyi `.php` fájljaimat a `fetch()` segítségével?+
Igen! Mivel a munkaterületed valódi `localhost` HTTP/1.1 eredeten fut, az `await fetch('/api/tasks.php', { method: 'POST', ... })` zökkenőmentesen működik JSON fejlécekkel, sütikkel és a DevTools Hálózat időzítésével.
Megnézhetem a PHP `new PDO('sqlite:app.db')` által létrehozott SQLite `.db` fájlt?+
Azonnal. Koppints az `app.db` fájlra a SuperCode fájlkezelőjében, és tekintsd meg a tábláit, sémáját és sorait Unicode táblázat vagy Markdown formátumban az SQL Studio-ban.
