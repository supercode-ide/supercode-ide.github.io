05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Kérdések a MySQL és PostgreSQL szintaxis offline futtatásáról, illetve a Cloud MySQL 8.0 tárolt eljárásokról.

Futtathatok MySQL `CREATE TABLE ... AUTO_INCREMENT ENGINE=InnoDB` szkripteket internet nélkül?+
Igen! A SuperCode offline SQL kompatibilitási rétege transzparensen lefordítja a gyakori MySQL és PostgreSQL DDL klózokat (`AUTO_INCREMENT`, `SERIAL`, `BIGSERIAL`, `UNSIGNED`, `ENUM`, `ENGINE=InnoDB`, `CHARSET`), így a sémád és lekérdezéseid offline futnak.
Működik a `SHOW TABLES`, a `DESCRIBE table_name` és a `TRUNCATE TABLE` offline?+
Igen. Nem kell megjegyezned a `.schema` vagy `PRAGMA table_info(...)` parancsokat MySQL tanfolyam közben — a `SHOW TABLES`, `DESCRIBE` / `DESC`, `SHOW CREATE TABLE` és `TRUNCATE TABLE` közvetlenül működik offline.
Hogyan futnak a MySQL tárolt eljárások (`CREATE PROCEDURE` és `DELIMITER //`) Androidon?+
Mivel a procedurális `BEGIN ... END` rutinok és a `DELIMITER` szerverszintű eljárási motort igényelnek, a SuperCode zökkenőmentesen a Cloud MySQL 8.0 motorra irányítja ezeket a szkripteket, és a `CALL` eredményhalmazokat közvetlenül visszafolyatja a konzolba.
Melyik extra MySQL és PostgreSQL függvények érhetők el offline?+
Több mint 50 skalár függvény van beépítve offline, köztük a `DATE_FORMAT`, `DATEDIFF`, `NOW`, `CURDATE`, `CONCAT_WS`, `LPAD`, `RPAD`, `SUBSTRING_INDEX`, `ILIKE`, `REGEXP_REPLACE`, `UUID`, `MD5`, `SHA256`, `MEDIAN` és `STDDEV`.
