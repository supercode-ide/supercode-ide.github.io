05 KÉRDÉSEK ÉS VÁLASZOK

Gyakran ismételt kérdések

Közvetlen válaszok az offline fordítókról, a nagyfájl-kezelésről, a támogatott nyelvekről és a Git/SFTP munkafolyamatokról.

Milyen programozási nyelvek futnak offline a SuperCode IDE-ben Androidon?+
A SuperCode helyben, Androidon futtatja a Python (3.11 & tudományos 3.12), C (GNU C17), C++ (GNU C++20), Java 17, JavaScript (ES2024), SQL, PHP, HTML5/CSS3/WebAssembly, Lua 5.4 és Linux Shell szkripteket, opcionális felhős támogatással a Kotlin, a MySQL 8.0 és a nagyobb szerver-keretrendszerek számára.
Meg tudja nyitni a SuperCode a gigabájtos naplófájlokat és SQL dumpokat lefagyás nélkül?+
Igen. A 30 MB-nál nagyobb fájloknál automatikusan bekapcsol a GB-os streamelő lapozó, amely a több száz MB-os és GB-os fájlokat 10 millió karakteres lemezblokkokra osztja azonnali lapugrással, 34 karakterkészlet-felismeréssel és globális stream regex cserével.
A C és a C++, illetve az SQL és a Web/PHP külön dedikált környezetet kapott?+
Igen. A C17 és a C++20 külön szabványokkal, fejlécekkel és sablonokkal rendelkezik; az SQL saját 9 módú konzolt és .db bináris vizsgálót kapott; a Web Studio pedig valódi helyi HTTP + PHP + PDO SQLite + WebAssembly előnézeti szervert futtat beépített DevTools eszközökkel.
Tartalmaz a SuperCode beépített Git klienst és SFTP/FTPS távoli szerkesztőt?+
Igen. Tartalmaz egy önálló vizuális Git klienst (klónozás PAT-tal, ágkezelés, Commit Time Machine egységes diffek és merge-ütközésfeloldó), valamint egy AES-256 titkosítású SFTP, FTPS (TLS 1.3) és FTP munkaterületet 3 fázisú atomi távoli mentéssel.
Optimalizálva van a SuperCode mind Android telefonokra, mind tabletekre?+
Igen. Telefonokon az eszköztárak hüvelykujj-közelben vannak jobb széli húzható menüvel és automatikusan összecsukódó osztott konzollal; összecsukható készülékeken és tableteken az eszköztár függőlegesen dokkol, a terminál pedig 55% / 45% arányú egymás melletti munkaállomásként nyílik meg.
