02 핵심 엔지니어링 기능

안드로이드 위에 하나로 연결된 모던 웹 엔지니어링 6계층

프론트엔드 ES 모듈, 바이너리 WebAssembly, 백엔드 PHP 세션, 관계형 SQL 데이터베이스, DevTools 디버깅과 SFTP 원격 배포가 유기적으로 작동합니다.

02.1

HTML5, CSS3, JS & WASM을 위한 실제 로컬 HTTP 오리진

CORS 오류가 발생하는 file:// 경로 대신 진짜 로컬 HTTP/1.1 서버로 프로젝트를 서빙하여 fetch(), <script type="module">, WebAssembly.instantiateStreaming()(.wasm), WebGL .glb/.gltf 에셋, IndexedDB, HTTP 206 미디어 탐색을 완벽히 지원합니다.

65+ MIME 타입 · ES 모듈 · application/wasm · HTTP 206
02.2

100% 오프라인 동적 PHP 백엔드 엔진

$_GET, $_POST, 영구 $_SESSION, $_FILES 파일 업로드, JSON REST 응답 헤더, password_hash()는 물론 다중 페이지 .php 템플릿, OOP 클래스, 클로저, match, include/require를 완전 오프라인으로 실행합니다.

$_GET / $_POST / $_SESSION · JSON API · 오프라인 PHP
02.3

PDO & SQLite3 기반 오프라인 SQL 데이터베이스 통합

new PDO('sqlite:app.db') 또는 SQLite3의 프리페어드 스테이트먼트(? 및 :named 바인딩)와 ACID 트랜잭션으로 데이터 기반 PHP 웹앱을 구축하고, 내장 SQL IDE에서 테이블을 즉시 조회할 수 있습니다.

PDO('sqlite:...') · Prepared Statements · ACID 트랜잭션
02.4

플로팅 DevTools 콘솔, 네트워크 로그 & 실시간 JS REPL

실시간 HTTP 요청(GET /api.php -> 200 · 3ms · 1.2 KB)을 추적하고 All / Error / Warn / Net 필터링, 구조화된 DOM/객체 트리 탐색 및 > Run JavaScript... 대화형 REPL 평가를 수행합니다.

네트워크 타이밍 · 에러 배지 · 대화형 JS REPL
02.5

3모드 반응형 뷰포트 전환기 & 2560px 고해상도 캡처

드래그 가능한 다이내믹 아일랜드에서 모바일, 태블릿(768dp), 데스크톱 레이아웃을 즉시 전환하고 카메라/갤러리 <input type="file"> 업로드를 테스트한 뒤 선명한 2560px PNG 스크린샷으로 내보냅니다.

모바일 / 태블릿 / 데스크톱 · 2560px PNG 내보내기
02.6

원격 FTP / FTPS / SFTP 실시간 웹 프리뷰 & 배포

SFTP나 FTPS로 연결된 실서버 사이트를 수정 중인가요? 실행을 누르면 상대 경로의 CSS, JS, 이미지를 온디맨드로 캐싱해 원격 페이지를 즉시 미리 보여주고 3단계 원자적 저장으로 호스팅 서버에 안전하게 반영합니다.

실시간 원격 프리뷰 · 원자적 SFTP / FTPS 퍼블리싱
스마트폰 · 폴더블 · 태블릿 최적화 · 경량 40.2 MB 전체 개요
03 단계별 실전 사용법

안드로이드에서 풀스택 웹사이트 제작, 디버깅 & 배포하기

로컬 HTML/CSS/WASM 및 PHP+SQL 프로토타이핑부터 실서버 배포까지 끊김 없이 진행하세요.

STEP 01 index.html / index.php

HTML5, CSS3, JS, WASM & PHP 파일 작성

AST HTML/CSS/JS/PHP 자동완성과 문서 내부의 <script>·<style> 블록까지 한 번에 들여쓰기하는 재귀 포매터로 다중 파일 웹 프로젝트를 편집합니다.

STEP 02 PDO + app.db

오프라인 PHP 폼 & REST API를 SQL DB에 연결

PDO 프리페어드 스테이트먼트로 로컬 .db SQLite 데이터베이스를 질의하거나 SuperCode의 SQL 스튜디오에서 초기 테이블 데이터를 구성합니다.

STEP 03 실행 ▶ -> 다이내믹 아일랜드

모바일·태블릿·데스크톱 반응형 프리뷰 & DevTools 점검

뷰포트 크기를 즉시 전환하며 크기 조절형 DevTools 서랍에서 네트워크 상태와 JS 에러를 점검하고 JS REPL에서 실시간 DOM 수정을 테스트합니다.

STEP 04 SFTP / 비주얼 Git

웹 호스팅 서버 또는 GitHub Pages로 즉시 퍼블리싱

정적/WASM 빌드를 비주얼 Git으로 GitHub Pages에 푸시하거나 PHP 및 웹 에셋을 SFTP/FTPS를 통해 운영 VPS에 안전하게 배포합니다.

좌측 엣지 스와이프로 탐색기 즉시 복귀 · 원탭 브라우저 캐시 및 PHP 세션 초기화 앱 가이드

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인 PHP + SQLite 구동, ES 모듈 / fetch() / WASM 지원, 웹 DevTools 및 SFTP 배포에 대한 답변입니다.

인터넷 없이 안드로이드에서 동적 PHP 웹사이트와 SQL 데이터베이스를 실행할 수 있나요?+
네! .php 페이지, REST JSON 엔드포인트, 세션 유지, 파일 업로드 폼, 다중 파일 include가 모두 100% 오프라인으로 구동되며 PDO('sqlite:...') 및 SQLite3 데이터베이스 연동이 기본 내장되어 있습니다.
ES6 모듈(<script type="module">), fetch(), WebAssembly(.wasm)도 정상 작동하나요?+
네. SuperCode가 application/wasm을 포함한 65종 이상의 MIME 타입을 지원하는 실제 로컬 HTTP 서버 위에서 프로젝트를 구동하므로 fetch(), ES 모듈, WebGL 3D 모델, WebAssembly.instantiateStreaming()이 별도 설정 없이 즉시 작동합니다.
스마트폰 화면에서 자바스크립트 에러나 데스크톱 레이아웃은 어떻게 디버깅하나요?+
프리뷰 화면의 드래그형 다이내믹 아일랜드 알약 버튼을 눌러 모바일·태블릿(768dp)·데스크톱 뷰포트를 즉시 전환하거나, 크기 조절형 웹 DevTools 서랍을 열어 Error/Warn/Net 로그 필터링과 실시간 JS REPL 명령 실행을 수행할 수 있습니다.
원격 FTP 또는 SFTP 서버에 호스팅된 실제 웹사이트도 미리 보고 수정할 수 있나요?+
네. SFTP/FTPS/FTP 워크스페이스에 서버를 마운트하면 원격 HTML/CSS/JS/PHP 탭을 3단계 원자적 저장으로 안전하게 직접 편집할 수 있으며, 실행을 누르면 연관 에셋을 자동 캐싱해 원격 페이지를 실시간으로 미리 보여줍니다.

HTML, WASM, PHP, SQL 풀스택 로컬 서버를 주머니 속에 휴대하세요.
