05 자주 묻는 질문

자주 묻는 질문 (FAQ)

콘솔 오류 검사, HTTP 요청 모니터링, DOM JS 명령 실행 및 오프라인 `.wasm` 실행에 관한 질문입니다.

DevTools를 사용하려면 `<script src="eruda.js">`를 붙여넣거나 인터넷에 연결해야 하나요?+
아니요! SuperCode의 웹 DevTools 콘솔, 네트워크 모니터, 대화형 JavaScript REPL은 오프라인 미리보기 엔진에 기본 내장되어 있어 외부 CDN 스크립트 태그 없이 비행기 모드에서도 100% 작동합니다.
Rust나 C/C++에서 컴파일한 바이너리 `.wasm` WebAssembly 파일도 실행할 수 있나요?+
네. 프로젝트 폴더에 `.wasm` 바이너리를 넣고 `WebAssembly.instantiateStreaming(fetch('./module.wasm'))`로 로드하세요 — SuperCode가 정확한 `application/wasm` MIME 타입으로 `.wasm` 파일을 서빙합니다.
DOM 요소나 순환 참조가 있는 객체를 로깅하면 어떻게 되나요?+
DOM 요소는 `<tag#id.class>` 요약 형태로 깔끔하게 출력되며, 순환 참조 객체는 `JSON.stringify` 예외를 발생시키는 대신 `[Circular]`로 안전하게 감지되어 표시됩니다.
Net 탭은 정적 파일과 `fetch()`뿐만 아니라 PHP 백엔드 호출도 캡처하나요?+
네. 모든 정적 에셋, ES 모듈, `.wasm` 바이너리, `fetch()` / `XMLHttpRequest` 호출 및 로컬 `.php` 엔드포인트 실행 내역이 HTTP 상태 코드, 밀리초 지연 시간, 바이트 크기와 함께 Net 탭에 표시됩니다.
