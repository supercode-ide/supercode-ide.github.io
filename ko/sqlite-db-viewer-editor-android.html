02 핵심 엔지니어링 기능

단순 읽기 전용 테이블 뷰어를 넘어 — 진정한 오프라인 SQLite 워크스테이션

내부 메타데이터를 검사하고, 파라미터화된 편집을 실행하며, 플랫 파일을 SQL 테이블로 변환하고 깔끔한 리포트를 몇 초 만에 내보내세요.

02.1

.db, .sqlite, .sqlite3, .db3 & .s3db 원탭 인스펙터

SuperCode 탐색기에서 바이너리 SQLite 데이터베이스를 탭하거나 Android 저장소에서 바로 여세요. 바이너리 헤더를 검증하고 .dbinfo 페이지 통계, .tables 개수, 전체 .schema DDL을 자동 출력합니다.

.db · .sqlite · .sqlite3 · .db3 · .s3db
02.2

전환 가능한 9가지 .mode 포맷 (Box, Markdown, JSON, CSV+)

용도에 맞게 결과를 포맷하세요: 모바일 가독성이 뛰어난 유니코드 box 그리드 및 ASCII table 뷰, GitHub 문서용 markdown 테이블, API용 json 배열, 시트용 csv/tabs, insert SQL 덤프, 세로 line 카드까지 지원합니다.

box · table · markdown · json · csv · tabs · insert · line · list
02.3

보일러플레이트 없는 .import --csv, --tsv & --json

번거로운 CREATE TABLE 입력을 생략하세요. .import --csv sales.csv sales 또는 .import --json users.json users(최대 8 MB)를 실행하면 SuperCode가 컬럼명을 자동 추론해 즉시 JOIN과 집계를 수행할 수 있습니다.

자동 테이블 생성 · 최대 8 MB CSV / TSV / JSON
02.4

.sql 스크립트용 워크스페이스 DB 자동 마운트

프로젝트의 app.db 파일 옆에 queries.sql을 두세요. SuperCode가 워크스페이스 데이터베이스를 자동 감지·마운트(또는 명시적 .open 명령 추적)하므로 스키마 마이그레이션과 편집 내용이 디스크에 그대로 영구 저장됩니다.

디스크 영구 편집 · .open 다중 DB 지원
02.5

프로젝트 폴더로 직접 .once 파일 내보내기

모든 출력 모드에 .once <filename>을 결합해 — 예: .mode markdown + .once report.md 또는 .mode csv + .once clean_leads.csv — 쿼리 결과를 공유 가능한 워크스페이스 파일로 바로 저장하세요.

03 단계별 실전 사용법

Android에서 `.db` 파일 검사 및 CSV/JSON 데이터셋 쿼리 방법

빠른 4단계로 기존 바이너리 데이터베이스를 열거나 원시 파일에서 새 DB를 구축하세요.

STEP 01 Explorer -> Tap .db

원탭으로 모든 .db, .sqlite, .sqlite3 파일 열기

워크스페이스에서 데이터베이스 파일을 선택하면 .dbinfo 요약, .tables 목록, CREATE TABLE / INDEX 스키마를 즉시 확인할 수 있습니다.

STEP 02 .import --csv / --json

또는 원시 CSV, TSV & JSON 파일을 테이블로 가져오기

.sql 스크립트에서 .import --csv data.csv my_table을 실행해 최대 8 MB 플랫 파일로부터 관계형 컬럼을 자동 생성하고 채우세요.

STEP 03 .mode box / markdown

SQL 쿼리 실행 & 9가지 출력 포맷 전환

AST SQL 자동 완성으로 SELECT, JOIN, UPDATE, ALTER 구문을 작성하고 깔끔한 유니코드 box 또는 Markdown 그리드로 미리 보세요.

STEP 04 .once export.csv

정제된 결과를 워크스페이스로 다시 내보내기

csv, json, markdown 또는 insert 모드와 .once를 함께 사용해 깔끔한 분석 결과를 프로젝트 폴더에 직접 저장하세요.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인에서 `.db`/`.sqlite3` 파일 열기, CSV/JSON 데이터셋 가져오기, 포맷된 결과 내보내기에 관한 자주 묻는 질문입니다.

SuperCode에서 직접 열 수 있는 SQLite 데이터베이스 파일 확장자는 무엇인가요?+
SuperCode는 `.db`, `.sqlite`, `.sqlite3`, `.db3`, `.s3db` 파일을 원탭으로 인식하며, `.dbinfo`, `.tables`, `.schema` 오프라인 검사를 자동으로 실행합니다.
일반 Android SQLite 뷰어와 비교해 내장 SQLite 3.54.1이 왜 중요한가요?+
대부분의 Android DB 뷰어는 기기의 구형 시스템 SQLite 빌드에 의존하므로 `STRICT` 테이블, `RETURNING`, `JSONB`, 최신 윈도우 프레임 절 및 업데이트된 쿼리 플래너를 지원하지 못합니다. SuperCode는 Android 8.0+ 기기 전반에서 일관된 SQLite 3.54.1을 제공합니다.
`CREATE TABLE`을 먼저 작성하지 않고 `.csv` 또는 `.json` 파일을 가져올 수 있나요?+
네! 최대 8 MB까지 `.import --csv filename.csv tablename`(또는 `--tsv` / `--json`)을 실행하세요 — `tablename`이 아직 없으면 SuperCode가 CSV 헤더나 JSON 객체 키로부터 테이블 스키마를 자동 생성합니다.
SQL 쿼리 결과를 Markdown 테이블이나 CSV 파일로 어떻게 내보내나요?+
`SELECT` 문 바로 위에 `.mode markdown`(또는 `.mode csv` / `.mode json` / `.mode insert`)과 `.once output.md`를 차례로 추가하고 실행을 탭하세요 — 프로젝트 탐색기에 파일이 즉시 생성됩니다.
