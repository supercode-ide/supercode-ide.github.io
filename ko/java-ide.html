02 핵심 엔지니어링 기능

무거운 데스크톱 설정 없이 누리는 모던 Java 17의 모든 강력함

첫날 배우는 간결한 main() 메서드부터 다중 패키지 JDBC 데이터베이스 연동 프로젝트까지 안드로이드 기기 하나로 충분합니다.

02.1

모던 오프라인 Java 17 문법 & 간결한 void main()

record 클래스, sealed 인터페이스, switch -> 화살표 표현식, instanceof 패턴 매칭, 텍스트 블록(""""), Stream API, java.time 및 학습자 친화적인 간결한 void main() 메서드를 100% 오프라인으로 지원합니다.

Records · Sealed · Switch -> · 텍스트 블록 · Streams
02.2

다중 패키지 OOP 컴파일 & 0ms 바이트코드 캐시

열린 탭과 프로젝트 폴더 전반의 다중 패키지 클래스를 한 번에 컴파일하고 main() 진입 클래스를 자동으로 판별하며, 해시 기반 바이트코드 캐시로 즉시(⚡ Cache) 재실행을 구현합니다.

다중 클래스 패키지 · main() 자동 판별 · ⚡ 0ms 캐시
02.3

내장 오프라인 SQLite JDBC & 커스텀 libs/*.jar 로드

드라이버 설치 없이 DriverManager.getConnection("jdbc:sqlite:app.db") 한 줄로 로컬 데이터베이스에 즉시 연결하거나, 프로젝트 내 libs/ 폴더에 외부 .jar 라이브러리를 넣어 클래스패스에 자동 추가할 수 있습니다.

jdbc:sqlite 기본 내장 · 커스텀 .jar 자동 로드
02.4

실시간 Scanner(System.in) & 깔끔한 예외 스택 트레이스

[EOF] 제어가 포함된 대화형 Scanner 및 BufferedReader 입력 루프를 지원하며, System.exit() 호출 시 앱이 닫히지 않도록 안전하게 처리하고 내부 런타임 노이즈를 제거한 명확한 예외 위치만 출력합니다.

실시간 System.in · 안전한 System.exit() · 정제된 진단
02.5

AST Java 자동완성, 코드 포매터 & 8종 예제 템플릿

Java/Kotlin 전용 21키 심볼 키보드, 오프라인 AST 멤버 자동완성, 원탭 Java 코드 정렬기 및 8가지 객체지향·자료구조 내장 템플릿으로 생산성을 높여줍니다.

AST 자동완성 · Java 포매터 · 8종 Java 실전 예제

클라우드 Java 21+ & 표준 SE 자동 라우팅

Java 21+ 최신 문법이나 모바일 런타임 외 데스크톱 전용 표준 패키지를 테스트할 때는 다중 클래스 소스를 자동 번들링하여 클라우드 Java 환경에서 매끄럽게 실행합니다.

03 단계별 실전 사용법

SuperCode에서 다중 클래스 Java 프로젝트 빌드하는 방법

객체지향 프로그래밍 과제, 자료구조 구현, DB 연동 Java 애플리케이션 제작에 최적화된 과정입니다.

STEP 01 src/ + libs/

Java 클래스 생성 및 선택적 .jar 라이브러리 추가

오프라인 AST 자동완성과 괄호·임포트 보조 기능을 활용해 패키지별 .java 클래스(및 libs/ 폴더 내 외부 .jar)를 구성합니다.

STEP 02 포맷 & 린트

Java 코드 블록 정렬 및 구문 검사

포맷 버튼으로 클래스, 메서드, Javadoc 주석 들여쓰기를 깔끔하게 맞추고 에러 레이더로 괄호나 문자열 누락을 점검합니다.

STEP 03 툴바 -> 실행 ▶

온디바이스 오프라인 컴파일 및 바이트코드 캐싱

STEP 04 Scanner / JDBC

분할 터미널에서 콘솔 입력을 실시간으로 전달하고 JDBC로 로컬 SQLite DB를 조회하며 생성된 파일을 탐색기에서 바로 확인합니다.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인 Java 17 문법 지원, 다중 파일 OOP, 외부 .jar 라이브러리 및 Scanner 입력에 대한 자주 묻는 질문입니다.

안드로이드 오프라인 상태에서 컴파일 가능한 Java 버전은 무엇인가요?+
레코드(record), 봉인 클래스(sealed), switch 화살표 표현식, instanceof 패턴 매칭, 텍스트 블록, Stream API를 포함한 Java 17을 오프라인으로 컴파일 및 실행하며, Java 21+ 기능은 자동으로 클라우드 Java로 연결됩니다.
여러 개의 클래스와 패키지로 나뉜 Java 프로젝트도 실행할 수 있나요?+
네. 프로젝트 폴더와 열린 에디터 탭에 있는 모든 .java 파일을 자동으로 해석하고 main() 메서드가 포함된 진입 클래스를 스스로 찾아 실행하며, 생성된 파일도 워크스페이스에 자동 반영합니다.
Java 코드에서 로컬 SQLite 데이터베이스에 연결하거나 외부 .jar 파일을 추가할 수 있나요?+
네! 오프라인 jdbc:sqlite:... JDBC 드라이버가 기본 내장되어 있어 바로 SQL 쿼리를 수행할 수 있으며, 프로젝트의 libs/ 폴더에 호환 가능한 .jar 파일을 넣으면 클래스패스에 자동 등록됩니다.
Scanner(System.in) 대화형 콘솔 입력이 정상적으로 작동하나요?+
네. Scanner나 BufferedReader가 입력을 대기할 때마다 프로그램이 안전하게 일시 정지하며 분할 화면 터미널에서 여러 줄의 입력값을 실시간으로 전달할 수 있습니다.
