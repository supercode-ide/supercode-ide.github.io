02 핵심 엔지니어링 기능

터미널 번거로움 없는 백엔드 JavaScript 스크립팅 및 파일 툴링

JSON/CSV 변환 자동화, 빌드 아티팩트 압축, 모듈 라이브러리 테스트, CLI 유틸리티 실행을 오프라인에서 밀리초 단위로 처리하세요.

02.1

오프라인에 바로 준비된 29+ 내장 Node.js 코어 모듈

별도 설정 없이 표준 `node:` 접두사 또는 일반 코어 모듈을 바로 임포트하세요: fs, fs/promises, path, path/posix, buffer, events, stream, stream/promises, stream/web, zlib, crypto, util, assert, url, querystring, readline, string_decoder, timers, timers/promises, perf_hooks, os, process, diagnostics_channel을 지원합니다.

node:fs · path · buffer · events · stream · zlib · util
02.2

실제 node:fs & fs/promises 워크스페이스 동기화

실제 프로젝트 파일을 대상으로 readFileSync, writeFile, appendFile, mkdir({ recursive: true }), readdir, stat, copyFile을 실행하세요. 생성된 JSON 번들, Markdown 문서, CSV, `.gz` 아카이브가 Android 폴더에 바로 반영됩니다.

fs.readFileSync · fs/promises · 영구 폴더 I/O
02.3

매끄러운 ES Modules (.mjs) & CommonJS (.cjs) 상호 운용

`import` / `export` 및 최상위 `await`로 최신 ES Modules를 작성하고, `require()`와 `module.exports`로 CommonJS 유틸리티를 유지하며, 중첩 디렉터리 간 `.json` 설정 파일도 네이티브로 임포트하세요.

import / export · require() · .mjs / .cjs / .json
02.4

package.json Exports, 하위 경로 & #imports 지원

`package.json`으로 깔끔한 다중 파일 패키지를 구성하세요. SuperCode는 저장되지 않은 열린 에디터 탭에서도 `\"type\": \"module\"`, `\"main\"`, 조건부 `\"exports\"` 맵 및 비공개 `#internal/*` 하위 경로 임포트를 정확히 해석합니다.

package.json · 조건부 exports · #subpath 임포트
02.5

바이너리 Buffer, EventEmitter, Stream & Zlib 처리

`Buffer.alloc`/`concat`(UTF-8, hex, base64, base64url), `EventEmitter`, `Readable`/`Writable`/`Transform` `pipeline()`, `zlib.gzipSync`/`gunzipSync`를 사용해 모바일에서도 바이너리 프로토콜과 대용량 텍스트 스트림을 효율적으로 처리하세요.

Buffer · EventEmitter · stream.pipeline · gzipSync

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Android에서 지원되는 `node:*` 모듈, `fs` 파일 경로, `package.json`, npm 패키지에 대한 질문과 답변입니다.

SuperCode에서 100% 오프라인으로 동작하는 Node.js 코어 모듈은 무엇인가요?+
`fs`, `fs/promises`, `path`, `path/posix`, `buffer`, `events`, `stream`, `stream/promises`, `stream/web`, `zlib`, `crypto`, `readline`, `util`, `assert`, `url`, `querystring`, `string_decoder`, `timers`, `timers/promises`, `perf_hooks`, `os`, `process`, `console` 등 29개 이상의 표준 모듈이 완전 오프라인으로 실행됩니다.
`fs.writeFileSync('out.json', data)`를 실행하면 실제 Android 폴더에 파일이 저장되나요?+
네! 파일 시스템 작업은 열려 있는 프로젝트 폴더(저장되지 않은 에디터 탭 포함)에서 직접 읽고, 생성되거나 수정된 모든 파일을 Android 디렉터리에 즉시 동기화합니다.
`node:fs` 접두사와 일반 `require('fs')` 임포트를 모두 사용할 수 있나요?+
네. 최신 `import fs from 'node:fs/promises'` ES Module 문법과 기존 `const fs = require('fs')` CommonJS 호출 모두 동일한 내장 오프라인 구현체로 연결됩니다.
스크립트에서 `node:http`, `net` 또는 `worker_threads`를 임포트하면 어떻게 되나요?+
OS 서버 소켓이나 하위 프로세스가 필요한 모듈(`http`, `https`, `net`, `tls`, `dns`, `child_process`, `worker_threads`)은 자동으로 감지되어 SuperCode의 다중 파일 클라우드 Node.js 번들러로 실행됩니다. 풀스택 로컬 HTTP 미리보기는 SuperCode Web IDE에서도 이용할 수 있습니다.
