SuperCode에서 Kotlin 컴파일 시 인터넷 연결이 필요한가요?+
편집, 구문 강조, AST 자동 완성, `.kt`/`.gradle.kts` 포맷팅, 비주얼 Git, A4 PDF 내보내기는 모두 100% 오프라인에서 작동합니다. `.kt` 및 `.kts` 코드의 컴파일과 실행에는 SuperCode의 빠른 클라우드 Kotlin 컴파일러가 사용됩니다(Java 17은 기기에서 100% 오프라인 컴파일 지원).
Kotlin에서 `readln()` 또는 `Scanner`에 다중 행 테스트 입력을 전달할 수 있나요?+
네! 실행을 탭하기 전에 콘솔의 고정 `stdin` 입력 바에 다중 행 테스트 케이스를 입력하거나 붙여넣으면 알고리즘 대회 및 면접 연습을 손쉽게 할 수 있습니다.
SuperCode로 전체 멀티 모듈 Gradle Android `.apk` 번들을 빌드할 수 있나요?+
SuperCode는 수 기가바이트 규모의 Android SDK `.apk` 패키징이 아닌, 독립 실행형 Kotlin(`.kt`/`.kts`) 프로그래밍, OOP 모델링, 함수형 파이프라인, DSA 연습 및 Git 기반 `.gradle.kts` 파일 편집에 최적화되어 있습니다.
`build.gradle.kts` 파일을 오프라인에서 포맷팅할 수 있나요?+
네. `.kt`/`.kts` 소스 파일과 `.gradle.kts` Gradle Kotlin DSL 스크립트 모두 SuperCode의 오프라인 구문 강조 및 원탭 코드 포매터를 지원합니다.
