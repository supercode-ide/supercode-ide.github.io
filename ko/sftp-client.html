02 핵심 엔지니어링 기능

엔터프라이즈급 원격 보안과 파일 손상 제로 엔지니어링

5G나 Wi-Fi 신호가 끊기는 순간 운영 서버 설정 파일을 0바이트 빈 파일로 날려버리는 일반 FTP 편집기의 치명적 약점을 근본적으로 해결했습니다.

02.1

4대 프로토콜 통합: SFTP, FTPS Explicit, FTPS Implicit & FTP

SSH 기반 SFTP(22번 포트), 암호화된 패시브 데이터 채널(PBSZ 0 + PROT P)을 사용하는 TLS 1.2/1.3 기반 Explicit FTPS, Implicit FTPS(990번 포트), 표준 UTF-8 패시브 FTP(21번 포트)를 모두 네이티브로 지원합니다.

SFTP(22) · FTPS TLS 1.3(21) · FTPS(990) · FTP
02.2

SSH 개인키 선택기, AES-256 하드웨어 금고 & TOFU 방어

OpenSSH, PEM, RSA, Ed25519, ECDSA 개인키(.pem, .key, id_rsa, id_ed25519)와 패스프레이즈를 손쉽게 불러오세요. 모든 인증 비밀은 Android KeyStore AES-256-GCM으로 암호화되며 SHA256 호스트 지문 불일치 경고로 MITM 공격을 차단합니다.

Ed25519 / RSA / PEM · AES-256-GCM · MITM 호스트 가드
02.3

3단계 원자적 원격 저장 (0바이트 파일 손상 원천 차단)

원격 파일을 열면 영구 로컬 미러 탭(☁️)이 생성됩니다. 저장 시 임시 파일로 먼저 업로드한 뒤 STAT/SIZE로 원격 바이트 크기를 정확히 검증하고, 통과 시에만 원본 위로 원자적 이름 변경(Rename)을 수행하며 리눅스 POSIX 권한까지 그대로 보존합니다!

임시 업로드 -> 바이트 크기 검증 -> 원자적 이름 변경 + chmod 보존
02.4

실시간 핸드셰이크 진단 콘솔 & 자가 치유 연결 풀

서버를 저장하기 전 내장 진단 콘솔에서 TCP 연결, TLS/SSH 협상, 키 인증 과정을 실시간으로 검증하세요. 3채널 멀티플렉싱 연결 풀이 Wi-Fi와 5G 네트워크 전환 후 끊어진 소켓을 자동으로 복구합니다.

⚡ 핸드셰이크 진단 · 3채널 자가 치유 연결 풀
02.5

4스트림 병렬 전송 큐 & 정확한 바이트 오프셋 이어받기

전체 디렉터리 트리를 20fps 실시간 MB/s 속도 패널과 함께 4개 병렬 스트림으로 고속 업로드·다운로드합니다. 대용량 전송 중 연결이 끊겨도 SFTP RESUME 또는 FTP REST를 통해 중단된 정확한 바이트 지점부터 이어받습니다!

4개 병렬 스트림 · 실시간 MB/s · 바이트 오프셋 이어받기
02.6

원격 퍼지 파일 검색 & 원격 웹사이트 실시간 프리뷰

원격 서버 디렉터리 전반에서 파일명을 빠르게 퍼지 검색하고 34종 인코딩으로 원격 탭을 다시 읽을 수 있으며, 원격 HTML/PHP 파일에서 실행을 눌러 수정 전후 실서버 웹페이지를 즉시 미리 확인할 수 있습니다.

03 단계별 실전 사용법

안드로이드에서 운영 서버에 안전하게 접속하고 핫픽스 배포하기

하드웨어 암호화 금고에 한 번만 등록해 두면 언제 어디서나 몇 초 만에 안전하게 원격 코드를 수정할 수 있습니다.

STEP 01 Explorer -> Remote Servers -> +

프로토콜 선택 및 비밀번호 또는 SSH 개인키 등록

SFTP, FTPS(TLS), FTPS(990), FTP 중 하나를 고르고 호스트·계정을 입력한 뒤 비밀번호나 .pem / id_ed25519 개인키 파일을 선택합니다.

STEP 02 ⚡ Test Handshake -> Save

연결 진단 로그 확인 & 호스트 지문 신뢰 등록

핸드셰이크 테스트를 탭해 TCP/TLS/SSH 인증 성공 여부를 실시간 확인하고 서버의 SHA256 호스트 지문을 검증한 뒤 AES-256 금고에 저장합니다.

STEP 03 Mount -> Tap Remote File

원격 폴더 트리 탐색 & AST 자동완성·포매팅 편집

Nginx 설정, Python/PHP 백엔드 코드, 쉘 스크립트를 에디터 탭으로 바로 열어 AST 자동완성, 에러 레이더, 원탭 코드 정렬로 편집합니다.

STEP 04 Save / Batch Upload

3단계 원자적 저장 배포 또는 충돌 정책 기반 폴더 동기화

저장을 탭해 3단계 원자적 배포를 수행하거나, 여러 폴더를 다중 선택해 덮어쓰기·바이트 이어받기·둘 다 유지·건너뛰기 정책으로 전송합니다.

원격 리눅스 POSIX 파일 권한 완벽 보존 · 앱 재시작 및 오프라인 전환 시에도 로컬 미러 탭 유지 앱 가이드

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

AWS/VPS용 SSH 개인키(.pem / Ed25519), FTPS TLS 1.3 지원, 원격 저장 시 0바이트 파일 손상 방지 및 대용량 이어받기 FAQ입니다.

AWS EC2, DigitalOcean, 카페24나 일반 리눅스 VPS 접속 시 어떤 SSH 개인키 형식을 사용할 수 있나요?+
패스프레이즈 유무와 관계없이 OpenSSH, PEM(.pem), RSA(id_rsa), Ed25519(id_ed25519), ECDSA 개인키를 모두 지원하며, 다운로드 폴더와 .ssh 폴더로 바로 이동하는 전용 키 선택기가 내장되어 있습니다.
원격 파일을 저장하는 도중 모바일 신호가 끊기면 서버 파일이 0바이트로 깨지지 않나요?+
절대 깨지지 않습니다. 모든 원격 탭 저장은 3단계 원자적 트랜잭션으로 동작하여 임시 파일에 먼저 업로드한 뒤 STAT/SIZE 명령으로 전체 바이트 도착 여부를 검증하고, 완전히 일치할 때만 리눅스 권한을 유지한 채 원본 파일 위로 원자적 이름 변경을 수행합니다.
SSH 기반 SFTP 외에 SSL/TLS 암호화 방식인 FTPS도 지원하나요?+
네! 패시브 데이터 채널까지 암호화(PROT P)하는 21번 포트 Explicit FTPS(AUTH TLS 1.2/1.3)와 990번 포트 Implicit FTPS, 그리고 표준 UTF-8 패시브 FTP까지 모두 네이티브로 지원합니다.
대용량 백업 파일을 다운로드하거나 업로드하다가 연결이 끊기면 이어받기가 가능한가요?+
네. 전송 대상 경로에 이미 일부 전송된 부분 파일이 감지되면 전송된 바이트 크기를 계산하여 완료된 구간을 다시 보낼 필요 없이 정확한 바이트 오프셋부터 원탭으로 부분 전송 이어받기를 수행합니다.

안드로이드에서 운영 VPS와 웹 호스팅 서버를 안심하고 관리하세요.
