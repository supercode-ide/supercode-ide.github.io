오프라인 컴파일러, 대용량 파일 처리, 지원 언어 및 Git/SFTP 워크플로에 대해 자주 묻는 질문과 답변입니다.

SuperCode IDE에서 인터넷 없이 오프라인으로 실행 가능한 프로그래밍 언어는 무엇인가요?+
안드로이드 기기 로컬에서 Python(3.11 및 과학 연산용 3.12), C(GNU C17), C++(GNU C++20), Java 17, JavaScript(ES2024), SQL, 동적 PHP, HTML5/CSS3/WebAssembly, Lua 5.4, Linux Shell 스크립트를 100% 오프라인으로 실행할 수 있으며, Kotlin·MySQL 8.0·대규모 서버 프레임워크는 선택형 클라우드 실행도 지원합니다.
수 기가바이트(GB) 크기의 대용량 로그 파일이나 SQL 덤프도 멈춤 없이 열 수 있나요?+
네. 30MB를 초과하는 파일은 자동으로 GB급 디스크 스트리밍 페이저가 작동하여 수백 MB~수 GB 파일을 1,000만 글자 단위의 디스크 청크로 분할 로드하며, 즉시 페이지 점프, EUC-KR 포함 34종 인코딩 자동 감지, 전역 스트림 정규식 치환을 지원합니다.
C와 C++, 또는 SQL과 웹/PHP 환경이 각각 전용 워크스페이스로 분리되어 있나요?+
네. C17과 C++20은 각각의 전용 표준 플래그·헤더·템플릿으로 분리되어 있으며, SQL은 9가지 출력 모드와 원탭 .db 바이너리 탐색기를 갖추고 있고, 웹 스튜디오는 내장 DevTools가 결합된 실제 로컬 HTTP + PHP + PDO SQLite + WebAssembly 서버를 구동합니다.
외부 터미널 설치 없이 Git 클라이언트와 SFTP/FTPS 원격 서버 편집을 바로 쓸 수 있나요?+
