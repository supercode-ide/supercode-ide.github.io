02 핵심 엔지니어링 기능

스마트폰에서 Python 라이브러리를 추가하는 4가지 손쉬운 방법

고속 Wi-Fi 환경이든 인터넷이 없는 강의실이든, SuperCode는 Python 종속성을 깔끔하고 영구적으로 유지합니다.

02.1

Auto-PIP 누락 임포트 감지기 & 35+ 별칭 맵

import bs4, import yaml, import dotenv, import jwt 또는 import telebot을 작성하고 실행을 누르세요. SuperCode가 임포트 이름을 표준 PyPI 패키지(beautifulsoup4, pyyaml, python-dotenv, PyJWT, pyTelegramBotAPI)로 자동 매핑해 설치하고 스크립트를 다시 실행합니다.

bs4 -> beautifulsoup4 · yaml -> pyyaml · 35+ 별칭
02.2

무설정 requirements.txt 워크스페이스 감지

Git 저장소를 클론하거나 requirements.txt가 포함된 프로젝트 폴더를 여세요. 비주얼 PIP 매니저가 상위 디렉터리 최대 6단계까지 스캔하고 줄 바꿈(\)과 플랫폼 마커를 파싱해 원탭 일괄 설치 배너를 표시합니다.

상위 루트 스캔 · 플랫폼 마커 · 일괄 설치 큐
02.3

100% 오프라인 .whl, .tar.gz & .zip 로컬 가져오기

출퇴근길, 비행기 또는 제한된 캠퍼스 Wi-Fi에서 학습 중이신가요? 순수 Python .whl, .tar.gz, .zip 배포 파일을 Android 다운로드 폴더에 미리 받아두면 완전 오프라인 상태에서 PEP 440 버전 검증과 함께 설치할 수 있습니다.

비행기 모드 설치 · .whl / .tar.gz / .zip
02.4

PEP 440 버전 제약 & 명령어 파서

전체 pip install 명령어(예: pip install requests>=2.31.0 flask~=3.0)를 입력창에 그대로 붙여넣으세요. SuperCode가 CLI 상용구를 제거하고 Python 3.11 기준으로 ==, >=, <=, !=, ~= 조건을 평가해 호환 릴리스를 찾습니다.

PEP 440 호환 · 전체 pip 명령어 붙여넣기
02.5

설치된 패키지 디스크 검사기 & 원탭 정리

관리 탭으로 전환해 설치된 라이브러리를 실시간 필터링하고, 정확한 버전 번호와 KB/MB 단위 디스크 용량을 확인한 뒤, 쓰지 않는 패키지를 탭 한 번으로 깔끔하게 삭제하세요.

실시간 검색 필터 · 정확한 디스크 용량 · 깔끔한 제거

03 단계별 실전 사용법

단계별 가이드: SuperCode에서 PIP & 오프라인 휠 사용하기

온라인 PyPI 패키지 설치부터 오프라인 .whl 사이드로드까지 30초 만에 완료하세요.

STEP 01 Python Console -> PIP Icon

비주얼 PIP 패키지 매니저 열기

아무 .py 파일을 열고 Python 콘솔 헤더의 PIP 아이콘을 탭하세요 — 또는 미설치 임포트가 있는 스크립트를 실행해 Auto-PIP를 바로 호출할 수 있습니다.

STEP 02 Quick Chips / Input Box

인기 칩 탭, pip install 붙여넣기 또는 requirements.txt 선택

원클릭 칩(requests, rich, beautifulsoup4, pyyaml, flask, telebot, colorama)을 탭하거나, 버전 스펙을 입력하거나, 자동 감지된 requirements.txt 배너를 누르세요.

STEP 03 Import Local Archive (.whl)

또는 다운로드 폴더에서 오프라인 .whl / .zip 패키지 탐색

오프라인 환경에서는 PIP 대화상자의 로컬 아카이브 버튼을 눌러 다운로드 또는 프로젝트 폴더의 .whl, .tar.gz, .zip 패키지를 스캔하세요.

STEP 04 Manage Tab -> Verify

멀티 파일 스크립트에서 즉시 임포트

설치된 라이브러리는 앱을 재시작해도 격리된 site-packages 디렉터리에 유지되며 AST 자동 완성과 함께 바로 동작합니다.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Android에서 PyPI 패키지, 오프라인 .whl 휠, requirements.txt 설치에 관한 자주 묻는 질문입니다.

`pip install requests beautifulsoup4` 전체 명령어를 SuperCode에 붙여넣을 수 있나요?+
네. PIP 입력 파서가 앞의 `pip install`, `pip3 install`, `python -m pip install` 접두사를 자동으로 제거하고 미지원 CLI 플래그는 안전하게 무시한 뒤, PEP 440 버전 제약과 함께 나열된 모든 패키지를 대기열에 추가합니다.
인터넷이 없을 때 Android에서 Python 패키지를 어떻게 설치하나요?+
순수 Python `.whl`(예: `*-py3-none-any.whl`), `.tar.gz` 또는 `.zip` 아카이브를 미리 스마트폰에 다운로드한 다음, SuperCode의 PIP 패키지 매니저를 열고 로컬 아카이브 버튼을 탭해 다운로드 폴더에서 바로 설치하세요.
왜 `numpy`나 `matplotlib`는 수동으로 `pip install` 할 필요가 없나요?+
NumPy, Pandas, SciPy, Matplotlib, Scikit-Learn처럼 무거운 네이티브 C/Fortran 확장이 포함된 라이브러리는 SuperCode의 과학 런타임에 사전 최적화되어 있습니다. 스크립트에 `import numpy as np`만 작성하고 실행을 누르세요.
앱을 종료한 후에도 설치한 PIP 패키지가 스마트폰에 남아 있나요?+
네. 설치된 모든 패키지는 SuperCode의 로컬 `python_site_packages` 저장소에 영구 보관되므로, 재설치 없이 언제든 오프라인으로 스크립트를 실행할 수 있습니다.
