05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Turbo C에서 전환하거나 malloc/free를 실습하고 대학 C 과제를 제출하는 학생들을 위한 답변입니다.

C를 배울 때 왜 `<conio.h>`, `clrscr()`, `getch()`를 쓰면 안 되나요?+
`<conio.h>`는 1980년대 비표준 MS-DOS 헤더로, 최신 Linux, macOS 및 모든 대학 채점 서버에서 거부됩니다. SuperCode는 표준 ISO/GNU C17(`<stdio.h>`, `<stdlib.h>`, `getchar()`, `fgets()`)을 컴파일하므로 배운 내용이 대학 시험과 시스템 개발 실무로 그대로 이어집니다.
SuperCode는 `.c` 파일을 C++ 대신 진짜 C 컴파일러로 컴파일하나요?+
네. C에서는 `malloc()`이 반환하는 `void *`가 캐스팅 없이 포인터 타입으로 암시적 변환되지만 C++에서는 거부됩니다. SuperCode는 `.c` 파일을 전용 GNU C17(`-std=gnu17`) 환경에서 컴파일하므로 표준 C17 문법이 깔끔하게 동작합니다.
`sqrt()`, `pow()`, `sin()`을 쓸 때 `-lm`을 직접 추가해야 하나요?+
아니요. SuperCode는 모든 C17 빌드에서 표준 수학 라이브러리(`-lm`)를 자동으로 링크하므로 `<math.h>` 함수가 즉시 동작합니다.
실수로 잘못된 포인터를 역참조하거나 `while(1)` 무한 루프를 작성하면 어떻게 되나요?+
에디터 세션은 완전히 안전하게 유지됩니다. 격리된 서브프로세스 실행이 충돌 종료 코드를 깔끔하게 보고하며, 20초 CPU 워치독이 스마트폰을 멈추게 하지 않고 폭주하는 무한 루프를 중단시킵니다.
