05 자주 묻는 질문

자주 묻는 질문 (FAQ)

SQL 학습자, 데이터 사이언스 전공자, 백엔드 면접 준비생들이 자주 묻는 질문입니다.

오프라인에서 LeetCode 스타일 SQL 윈도우 함수 문제(`DENSE_RANK`, `LAG`, 누적 합계)를 연습할 수 있나요?+
네! 모든 표준 SQL 윈도우 함수(`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LAG`, `LEAD`, `FIRST_VALUE`, `LAST_VALUE`, `NTH_VALUE`)와 `ROWS`/`RANGE`/`GROUPS` 프레임 지정이 100% 오프라인에서 동작합니다.
SuperCode는 SQL에서 `MEDIAN()`, `PERCENTILE()`, `STDDEV()`를 직접 지원하나요?+
네. 기본 SQLite에는 통계 집계 함수가 없지만, SuperCode는 네이티브 `MEDIAN(col)`, `PERCENTILE(col, 95)`, `STDDEV(col)` 함수를 사전 등록해 데이터 분석가가 단일 `SELECT` 문으로 분포를 계산할 수 있습니다.
`.sql` 쿼리 안에서 `READ_STDIN()`은 어떻게 작동하나요?+
`.sql` 파일 안에 `WHERE department = READ_STDIN('Department name: ')`처럼 작성하고 실행을 탭하면 — 도킹된 콘솔에서 대화형 입력 프롬프트가 나타나 코드를 수정하지 않고도 파라미터화된 쿼리를 반복 실행할 수 있습니다.
FTS5 전문 검색과 R*Tree / Geopoly 공간 모듈이 활성화되어 있나요?+
네. `USING fts5(...)`(`bm25()`, `highlight()`, `snippet()` 포함)와 `USING rtree(...)` / Geopoly 공간 확장 모듈 모두 SuperCode의 오프라인 SQLite 3.54.1 엔진에 직접 컴파일되어 있습니다.
