브라우저 탭에 종속되지 않는 진정한 독립형 JavaScript 런타임

자료구조, 비동기 파이프라인, JSON 데이터 가공, 모듈형 유틸리티를 즉각적인 피드백과 정확한 줄 번호 진단으로 테스트하세요.

02.1

ES6–ES2024 전체 문법 오프라인 완벽 지원

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

HTML 없이 .js 파일 단독 실행하기, ES 모듈 분리, 무한 루프 보호 및 Node.js 연동에 대한 FAQ입니다.

HTML 페이지를 만들지 않고 안드로이드에서 .js 파일만 단독으로 바로 실행할 수 있나요?+
네! 어떤 .js, .mjs, .cjs 파일에서든 실행 버튼만 누르면 SuperCode의 독립형 JavaScript 워커 콘솔이 즉시 가동되어 100% 오프라인으로 결과를 출력합니다.
import/export나 require()로 여러 파일에 자바스크립트 코드를 나누어 작성할 수 있나요?+
네. ES 모듈(import / export)과 CommonJS(require / module.exports), 그리고 .json 데이터 임포트까지 로컬 프로젝트 폴더와 미저장 탭 전반에서 매끄럽게 동작합니다.
실수로 while(true) 무한 루프를 실행하면 에디터가 멈추거나 작성 중인 코드가 날아가나요?+
절대 그렇지 않습니다. 스크립트가 UI와 분리된 격리 백그라운드 워커에서 15초 워치독 및 출력 폭주 차단기의 보호 아래 실행되므로 무한 루프도 1밀리초 이내에 안전하게 종료됩니다.
HTML, CSS, WebAssembly가 포함된 시각적 DOM 웹사이트도 함께 만들고 싶다면 어떻게 하나요?+
SuperCode에는 두 환경이 모두 들어 있습니다! 순수 JS 모듈과 알고리즘 테스트에는 독립형 JavaScript IDE를, 실제 로컬 HTTP DOM 렌더링·반응형 뷰포트·웹 DevTools가 필요할 때는 풀스택 웹 & PHP 스튜디오를 바로 사용하세요.
