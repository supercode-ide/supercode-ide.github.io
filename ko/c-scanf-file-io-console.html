02 핵심 엔지니어링 기능

네이티브 터미널처럼 동작하는 모든 C 입출력 채널

02.1

scanf & fgets 전 자동 비버퍼링 stdout

대부분의 모바일·웹 실행기에서는 줄바꿈 없는 printf("Enter age: ");가 scanf() 종료 전까지 보이지 않습니다! SuperCode는 stdout 버퍼링을 자동 해제해 입력 전에 항상 프롬프트를 표시합니다.

fflush(stdout) 불필요 · 자연스러운 메뉴 루프
02.2

다단계 실시간 Stdin 및 원탭 [EOF] 신호

프로그램 실행 중 단계별로 대화형 입력을 전달하세요. while (scanf("%d", &x) != EOF) 또는 while (fgets(buf, sizeof buf, stdin)) 테스트 시 빈 입력줄을 전송해 깔끔하게 EOF 신호를 보낼 수 있습니다.

scanf · fgets · getchar · 깔끔한 [EOF] 종료
02.3

argc / argv CLI 프로그램용 // @args 지시어

.c 파일 상단에 // @args -i "input data.csv" --verbose를 추가하면 따옴표 내 공백을 유지한 채 최대 32개의 파싱된 커맨드라인 토큰이 main(int argc, char *argv[])로 직접 전달됩니다.

// @args · 따옴표 문자열 · 최대 32개 argv 토큰
02.4

.txt / .csv / .dat / .in 데이터셋 자동 마운트

프로젝트 디렉터리에 input.in, students.csv 또는 records.dat를 넣고 fopen("students.csv", "r") 같은 표준 상대 경로로 여세요—Android /storage/emulated/0 경로를 하드코딩할 필요가 없습니다.

상대 경로 fopen() · .txt / .csv / .dat / .in
02.5

양방향 fopen, fprintf & fwrite 워크스페이스 동기화

fopen(..., "w" / "wb"), fprintf(), fwrite()로 기록한 텍스트 리포트와 바이너리 구조체가 Android 워크스페이스 트리에 자동 동기화되며 파일 탐색기가 즉시 새로고침됩니다.

텍스트 및 바이너리 파일 동기화 · 즉시 탐색기 새로고침

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Android에서 `scanf` 프롬프트, `fgets` 줄바꿈 동작, `EOF` 및 `fopen` 경로 문제 해결 가이드입니다.

SuperCode에서는 왜 `fflush(stdout)` 없이도 `printf("Enter number: ");`가 즉시 보이나요?+
표준 C 스트림은 파이프로 연결될 때 블록 버퍼링되는 경우가 많아 `\\n`으로 끝나지 않는 프롬프트가 가려집니다. SuperCode는 표준 스트림을 자동으로 비버퍼링 설정해 `scanf`, `fgets`, `getchar` 대기 전에 대화형 프롬프트가 항상 표시됩니다.
Android 터치 키보드에서 `Ctrl+D` (`EOF`)는 어떻게 보내나요?+
콘솔 입력창이 활성화되고 비어 있는 상태에서 전송 버튼을 탭하면 실행 중인 C 프로세스에 `EOF` (`[EOF]`)가 깔끔하게 전달되어 `while (scanf(...) != EOF)` 및 `getchar() != EOF` 루프를 종료합니다.
`char *argv[]`에 공백이 포함된 커맨드라인 인자는 어떻게 전달하나요?+
`.c` 파일 상단에 `// @args "My Report.txt" -n 10`처럼 작성하세요. SuperCode의 인자 토크나이저는 따옴표로 묶인 문자열을 하나의 `argv[i]` 항목으로 유지하며 최대 32개의 인자를 지원합니다.
`fopen("output.txt", "w")`로 생성한 파일은 어디에 저장되나요?+
`.c` 소스 파일이 있는 동일한 Android 프로젝트 폴더에 직접 동기화되어 영구 보존되며, SuperCode 코드 에디터 내부에서 바로 열 수 있습니다.
