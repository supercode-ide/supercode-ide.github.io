02 핵심 엔지니어링 기능

실제 소프트웨어 프로젝트를 위해 툴바부터 새로 설계한 에디터

괄호 자동 건너뛰기부터 선택 영역 들여쓰기 보존 정렬까지, 모든 마이크로 인터랙션을 엄지 속도와 가독성에 맞춰 검증했습니다.

02.1

하이브리드 AST 문맥 인식 코드 자동완성

C/C++, Python, Java, Kotlin, JS/TS, HTML, CSS, PHP, Lua, Shell, SQL에서 ., ->, ::, : 입력 시 즉시 작동하여 로컬 변수 타입, 구조체·클래스 멤버, STL/DOM API 및 스니펫을 오프라인으로 추천합니다.

연산자: . · -> · :: · : | 10개 언어 패밀리
02.2

듀얼 모드 구문 강조 & 무확장자 파일 자동 판별

현재 화면 영역을 120Hz로 즉시 렌더링하면서 문자열 내부 포맷 토큰(\n, %d, {0})과 @param/TODO 태그까지 정밀하게 구분합니다. 확장자가 없는 파일도 #! 셔뱅(Shebang)과 어휘 분석으로 언어를 자동 인식합니다.

40+ 확장자 · Shebang 스니퍼 · 0 프레임 드랍
02.3

30종+ 오프라인 코드 포매터 & 스마트 주석기

C/C++, Java, Kotlin, JS/TS, Python(PEP 8), JSON, CSS, PHP, SQL, Lua, Shell 및 HTML/Vue(내부 <script>·<style> 재귀 정렬 포함!)를 선택 영역 기준 들여쓰기를 유지한 채 단 한 번의 실행 취소(1-Undo) 단위로 깔끔하게 정렬합니다.

단일 Undo 원자적 정렬 · HTML/JS/CSS 재귀 포맷
02.4

에러 레이더 V2.0 & 홀로그램 UTF-8 문서 통계

짝이 안 맞는 괄호, 닫히지 않은 문자열/태그, Python TabError 및 콜론 누락, 잘못된 JSON 쉼표를 즉시 포착해 원탭으로 해당 줄·열(Ln/Col)로 이동시키며, 전체 및 선택 영역의 줄·단어·글자·정확한 UTF-8 바이트 수를 함께 보여줍니다.

원탭 Ln/Col 이동 · 전체 & 선택 영역 UTF-8 바이트
02.5

29종 도구 5모드 적응형 툴바 & 우측 엣지 스와이프 메뉴

코드·일반 텍스트·선택·검색·초대용량 파일 5가지 모드로 자동 전환되며 가로 모드에서는 측면에 세로 도킹됩니다. 한 손으로 우측 화면 끝을 쓸어 열 수 있는 120Hz 스와이프 메뉴에는 창이 닫히지 않는 5개의 커스텀 퀵 슬롯이 제공됩니다.

5종 자동 모드 · 5개 퀵 슬롯 · 15MB 가상 클립보드
02.6

21키 스와이프 업 심볼 바, 8종 광학 테마 & A4 PDF 출력

6가지 언어별 심볼 프로필을 자동 로드하며 탭 입력, 스와이프 업 확대 돋보기, 키보드 숨김 커서 잠금 모드를 지원합니다. 8종 WCAG AAA 광학 테마(주야간 자동 전환), 젠 모드 및 A4 고정폭 PDF 내보내기로 완성도를 높였습니다.

6종 심볼 프로필 · AMOLED #000000 · 내장 PDF/이미지 뷰어

03 단계별 실전 사용법

나만의 모바일 코딩 워크스페이스 2분 완성 가이드

스마트폰과 태블릿 어디서나 데스크톱급 편집 흐름을 손쉽게 세팅하세요.

STEP 01 탐색기 / 스마트 저장

모든 소스 파일 열기 또는 새 스크래치패드 생성

내부 저장소, SD/USB OTG, Git, SFTP에서 다중 탭으로 파일을 여세요. 이름 없는 임시 탭도 문법을 자동 감지하여 스마트 저장 시 알맞은 확장자를 추천합니다.

STEP 02 21키 심볼 바

듀얼 액션 키캡과 AST 자동완성으로 고속 타이핑

탭하여 쌍괄호 삽입이나 선택 영역 감싸기를 수행하고, 키캡을 위로 밀어 보조 연산자(===, /**/, 내어쓰기) 입력과 0ms AST 멤버 자동완성을 활용하세요.

STEP 03 정렬 · 진단 · 통계

원탭 코드 정렬 및 에러 레이더 좌표 점검

포맷 버튼으로 들여쓰기를 가지런히 정렬한 뒤 통계 버튼을 눌러 실시간 에러 레이더 위치와 선택 영역·전체 UTF-8 바이트 통계를 확인합니다.

STEP 04 우측 엣지 스와이프

우측 화면 끝 스와이프로 5슬롯 연속 퀵 액션 실행

오른쪽 화면 가장자리를 안쪽으로 당겨 메뉴를 닫지 않고 실행 취소/다시 실행/테마/자동 줄바꿈을 연속 클릭하거나 젠 모드 전환 및 A4 PDF 내보내기를 실행하세요.

상단 탭 드래그 순서 변경 지원 · 비정상 종료에도 미저장 탭을 보호하는 Hot Exit 자동 백업 앱 가이드

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인 코드 정렬, 자동완성 지원 언어, 툴바 커스터마이징 및 PDF/이미지 뷰어에 대한 안내입니다.

스마트 코드 자동완성과 코드 포매터는 100% 오프라인으로 작동하나요?+
네. AST 문맥 인식 자동완성, 듀얼 모드 구문 강조, 실시간 에러 레이더 문법 검사, 30종 이상의 언어 포매터 모두 네트워크 연결 없이 안드로이드 기기 자체에서 100% 오프라인으로 즉시 실행됩니다.
21키 심볼 키보드는 스마트폰 코딩 속도를 어떻게 높여주나요?+
현재 파일에 맞춰 6가지 언어 프로필(C/C++, Python, Java/Kotlin, JS/TS, Web, Shell/SQL)을 자동 로드하며, 선택 텍스트 괄호/따옴표 감싸기, 확대 돋보기가 표시되는 스와이프 업 보조 기호 입력, 코드 탐색 중 가상 키보드 팝업을 막아주는 커서 잠금 모드를 제공합니다.
하단 툴바와 우측 퀵 메뉴 버튼 순서를 내 손에 맞게 바꿀 수 있나요?+
물론입니다. 설정 -> 툴바 및 메뉴 사용자 지정에서 하단/측면 메인 툴바 아이콘 순서와 5개의 골든 퀵 액션 슬롯을 드래그하여 자유롭게 배치하거나 원탭으로 초기화할 수 있습니다.
작성한 소스 코드를 PDF로 내보내거나 앱 안에서 PDF·이미지를 바로 볼 수 있나요?+
네. 인쇄 또는 .pdf로 다른 이름 저장을 통해 깔끔한 A4 고정폭 폰트 PDF를 생성할 수 있으며, 프로젝트 내 PDF(1x~5x 줌, 페이지 이동)와 10가지 이미지 포맷(WEBP, HEIC, AVIF, ICO 포함)을 외부 앱 없이 바로 확인할 수 있습니다.
