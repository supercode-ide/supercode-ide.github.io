05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Android에서의 오프라인 Java 17 언어 지원, Jvdroid 마이그레이션 및 Java 21+ 기능에 대한 답변입니다.

SuperCode는 정말 인터넷 없이 Java 17 records와 sealed 클래스를 컴파일하나요?+
네. 첫 실행 시 가벼운 오프라인 Java 17 SDK가 초기화되면 `record`, `sealed` / `permits`, `switch ->` 표현식, `instanceof` 패턴 매칭, 텍스트 블록(`\"\"\"`), `Stream.toList()` 모두 비행기 모드에서도 100% 오프라인으로 컴파일 및 실행됩니다.
Java 8이나 Java 11 모바일 앱과 비교하면 최신 대안으로서 어떤 장점이 있나요?+
구식 Android Java 앱은 `record` 튜플, `Stream.toList()`, switch 표현식을 사용하는 최신 대학 과제나 LeetCode 풀이를 실행하지 못합니다. SuperCode는 완전한 오프라인 LTS Java 17과 자동 Cloud Java 21+ 폴백, Visual Git, 내장 SQLite JDBC를 모두 제공합니다.
`CompletableFuture`, `Optional`, `java.time`도 오프라인에서 사용할 수 있나요?+
네. `java.util.stream`, `java.util.concurrent.CompletableFuture`, `java.time.*`, `java.math.BigDecimal`, `java.nio.file`을 포함한 전체 핵심 표준 라이브러리가 오프라인에서 네이티브로 실행됩니다.
Android 스마트폰에서 Java 21 가상 스레드는 어떻게 실행하나요?+
코드에 `Thread.ofVirtual()` 또는 `Executors.newVirtualThreadPerTaskExecutor()`를 작성하거나(또는 파일 상단에 `// @cloud` 추가) 실행을 누르면 됩니다. SuperCode가 프로젝트 클래스를 Cloud Java 21+로 자동 번들링해 실행하고 결과를 터미널 콘솔로 스트리밍합니다.
