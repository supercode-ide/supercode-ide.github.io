03 단계별 실전 사용법

안드로이드에서 다중 모듈 Lua 스크립트 프로토타이핑하기

단일 스크립트 실험부터 모듈화된 게임 로직 설계까지 초고속 반복 개발을 지원합니다.

STEP 01 main.lua + lib/

Lua 스크립트 생성 또는 내장 예제 불러오기

8가지 내장 Lua 스타터 예제를 선택하거나 탐색기에서 다중 파일 모듈 구조를 생성합니다.

STEP 02 AST . 및 : 자동완성

테이블 문맥 인식 자동완성 & 원탭 정렬

표준 라이브러리와 커스텀 테이블 뒤에서 : 또는 .을 입력해 오프라인 추천을 받고 포맷 버튼으로 블록을 정렬합니다.

STEP 03 툴바 -> 실행 ▶

마이크로초 단위의 초고속 오프라인 실행

실시간 io.read() 입력과 함께 즉시 코드를 구동하고 마이크로초(µs) 및 킬로바이트(KB) 실행 지표를 확인합니다.

STEP 04 Git / SFTP 동기화

게임 엔진 또는 원격 서버로 즉시 배포

완성된 Lua 모듈을 비주얼 Git 저장소에 푸시하거나 SFTP를 통해 원격 서버에 원탭으로 동기화합니다.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인 Lua 5.4 문법 지원, 다중 파일 require() 모듈 분리 및 코드 정렬 관련 자주 묻는 질문입니다.

SuperCode에서 오프라인으로 실행되는 Lua 버전은 무엇인가요?+
네이티브 Lua 5.4.7 엔진이 내장되어 있어 인터넷 없이 100% 오프라인으로 실행되며, 정수 나눗셈(//), 비트 연산자, <const> 및 <close> 변수 속성, 코루틴, 메타테이블, utf8 라이브러리를 모두 지원합니다.
Lua 스크립트를 여러 파일로 나누고 require()로 불러올 수 있나요?+
네. require() 호출 시 프로젝트 폴더와 현재 열려 있는 에디터 탭을 자동으로 탐색해 모듈을 연결하며, io.open()으로 생성한 파일도 탐색기 트리에 즉시 동기화됩니다.
오프라인 상태에서 Lua 코드 자동 정렬(포매팅)도 지원하나요?+
네. 포맷 버튼을 한 번 탭하면 function, if/then/else, for/do, repeat/until 블록과 중첩 테이블 생성자 들여쓰기를 오프라인에서 깔끔하게 정렬해 줍니다.
