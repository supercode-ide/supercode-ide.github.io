02 핵심 엔지니어링 기능

터치 친화적 스크립트 편집, 로컬 텍스트 파이프라인, 그리고 Kotlin

번거로운 외부 터미널 앱 전환 없이 정교한 스크립트 포매팅과 실제 파이프라인 실행을 한 화면에서 해결하세요.

02.1

네이티브 OS 쉘 실행 & Toybox 텍스트 파이프라인

일반적으로 chmod +x 실행 권한이 차단되는 안드로이드 공유 저장소에서도 grep, awk, sed, sort, uniq, wc, cut, tr, find, cat 및 파일 리다이렉션을 포함한 .sh 스크립트를 로컬에서 깔끔하게 구동합니다.

grep · awk · sed · sort · uniq · find · 파이프
02.2

다중 스크립트 source 연동 & 결과 파일 자동 동기화

폴더 내 보조 .sh 스크립트를 source로 불러오고 실시간 대화형 read 입력을 받을 수 있으며, 스크립트가 생성한 리포트나 변환된 파일이 탐색기에 자동으로 나타납니다.

다중 파일 source · 실시간 read 입력 · 파일 자동 동기화
02.3

GNU Bash 5.2 & 원탭 Kotlin(.kt) 클라우드 스튜디오

GNU Bash 5 전용 연관 배열 문법이 필요하거나 Kotlin 데이터 클래스, 코루틴, 함수형 코드를 컴파일하고 싶을 때 전용 클라우드 런타임으로 깔끔하게 자동 연결됩니다.

Ubuntu Bash 5.2 · Kotlin .kt / .kts 원탭 실행
02.4

Shell & Kotlin AST 자동완성 + 오프라인 코드 포매터

${var:-default} 쉘 변수 확장 힌트, Kotlin AST 멤버 자동완성, Shell 및 Kotlin/Gradle 오프라인 포매터와 6가지 실전 Shell 템플릿을 기본 내장했습니다.

Shell + Kotlin 포매터 · Dockerfile/Makefile 구문 강조

03 단계별 실전 사용법

쉘 자동화 스크립트 & Kotlin 스니펫 실행 가이드

DevOps 서버 스크립트 점검, 로그 텍스트 가공, Kotlin 문법 실습을 위한 간결한 워크플로입니다.

STEP 01 task.sh / Main.kt

쉘 스크립트 또는 Kotlin 소스 파일 생성

전용 심볼 키보드와 정밀 구문 강조를 활용해 .sh, .bash, Makefile, Dockerfile 또는 .kt 파일을 작성합니다.

STEP 02 툴바 -> 포맷

반복문, 분기문 & Kotlin 블록 원탭 자동 정렬

쉘 스크립트의 if/fi, case/esac 구조와 Kotlin 클래스를 오프라인에서 탭 한 번으로 가지런히 정렬합니다.

STEP 03 툴바 -> 실행 ▶

기기 로컬 쉘 또는 클라우드 Bash / Kotlin 실행

POSIX 쉘 파이프라인은 기기 로컬에서 즉시 실행하고, GNU Bash 5.2 및 Kotlin 코드는 클라우드로 매끄럽게 컴파일합니다.

STEP 04 SFTP / 비주얼 Git

검증된 스크립트를 실서버로 즉시 배포

작동이 확인된 쉘 스크립트를 POSIX 실행 권한을 보존한 채 SFTP로 업로드하거나 비주얼 Git으로 커밋합니다.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

안드로이드 공유 저장소에서의 .sh 실행 원리, awk/sed 파이프라인 및 Kotlin 컴파일 관련 FAQ입니다.

안드로이드 공유 저장소는 chmod +x 권한을 막는데 SuperCode는 어떻게 일반 폴더의 .sh 스크립트를 실행하나요?+
SuperCode가 프로젝트 작업 경로($PWD)를 안드로이드 네이티브 쉘 실행 환경에 투명하게 매핑하여 구동한 뒤, 새로 생성되거나 변경된 출력 파일을 원래 프로젝트 폴더로 자동 동기화해 주기 때문입니다.
SuperCode에서 Kotlin(.kt) 코드를 작성하고 실행할 수 있나요?+
네! Kotlin 및 Gradle(.kt, .kts, .gradle.kts) 구문 강조, 오프라인 AST 자동완성, 오프라인 코드 포매터는 물론 원탭 클라우드 Kotlin 컴파일 및 실행을 완벽히 지원합니다.
안드로이드 기본 sh에 없는 GNU Bash 5 연관 배열 문법을 쓰면 어떻게 되나요?+
Bash 전용 고급 문법이나 # @cloud 지시어를 자동으로 감지하여 워크스페이스 스크립트를 Ubuntu GNU Bash 5.2 클라우드 환경으로 매끄럽게 라우팅해 실행합니다.
