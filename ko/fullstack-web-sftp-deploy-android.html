Android에서 라이브 사이트를 미리 보고 안전하게 편집 & 게시하는 방법

두 가지 깔끔한 배포 파이프라인 — PHP/VPS 호스트용 직접 SFTP/FTPS, 또는 Pages용 비주얼 Git.

STEP 01 SFTP / Git -> Connect

웹 호스트 마운트 또는 Git 저장소 복제

SFTP/FTPS 관리자에서 암호화된 SSH 키 또는 비밀번호로 VPS/cPanel 호스트를 추가하거나 GitHub Pages 저장소를 복제하세요.

STEP 02 Edit + Run ▶ Preview

3종 뷰포트에서 원격 또는 스테이징 페이지 미리보기

AST 자동 완성으로 HTML, CSS, JS 또는 PHP를 편집하고 실행 ▶을 탭해 게시 전 모바일/태블릿/데스크톱 렌더링과 DevTools 로그를 검사하세요.

STEP 03 Save (Atomic) / Diff

STEP 04 Verify Live / Push

프로덕션에 푸시 및 네트워크 상태 확인

커밋을 푸시해 GitHub/Cloudflare Pages 빌드를 트리거하거나 에셋 폴더를 프로덕션 서버에 동시 동기화하세요.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

SFTP/FTPS를 통한 원격 웹 사이트 편집, 업로드 손상 방지 및 GitHub Pages 푸시에 관한 자주 묻는 질문입니다.

서버 전체를 다운로드하지 않고 어떻게 원격 SFTP 또는 FTP 웹페이지를 미리 볼 수 있나요?+
열려 있는 원격 `.html` 또는 `.php` 탭에서 실행을 탭하면 SuperCode가 로컬 미리보기 서버에서 페이지를 렌더링하고 참조된 상대 경로 CSS, JS, 폰트 및 이미지 파일만 원격 호스트에서 온디맨드로 자동 가져옵니다.
원격 `index.php` 파일을 저장하는 도중 스마트폰 모바일 신호가 끊기면 어떻게 되나요?+
라이브 프로덕션 파일은 전혀 손상되지 않습니다! SuperCode의 3단계 원자적 저장은 먼저 임시 파일에 기록한 뒤 업로드된 바이트 수가 100% 일치하는지 확인하고, 그다음에야 서버 측 원자적 이름 변경을 실행합니다.
SuperCode는 Linux SSH VPS 서버뿐만 아니라 공유 cPanel/Plesk 웹 호스팅도 지원하나요?+
네. DigitalOcean, AWS Lightsail, Hetzner, Linode 같은 클라우드 VPS 인스턴스에는 비밀번호 또는 Ed25519/RSA 개인 키를 사용하는 SFTP를 이용하고, cPanel 및 공유 호스팅에는 FTPS(TLS 1.3) 또는 FTP를 이용하세요.
정적 HTML/CSS/JS 또는 WASM 사이트를 빌드해 GitHub Pages에 무료로 게시할 수 있나요?+
네. SuperCode의 로컬 HTTP 서버에서 오프라인으로 사이트를 작성하고 테스트한 다음, 내장 비주얼 Git 클라이언트를 사용해 GitHub Pages 저장소에 바로 커밋하고 푸시하세요.
