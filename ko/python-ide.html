02 핵심 엔지니어링 기능

순수 스크립트부터 데이터 분석까지 아우르는 3계층 Python 아키텍처

02.1

오프라인 다중 파일 Python 3.11 & 스마트 진입점 라우팅

.py, .json, .csv, .yaml, .toml이 결합된 다중 모듈 프로젝트를 100% 오프라인으로 실행합니다. 보조 모듈 탭에서 실행 버튼을 눌러도 프로젝트의 메인 진입 스크립트를 자동으로 찾아 구동합니다.

다중 파일 import · 미저장 탭 오버레이 · 파일 자동 동기화
02.2

온디바이스 캐시 기반 NumPy, Pandas & Matplotlib

NumPy · Pandas · Matplotlib · PNG/SVG/PDF 자동 저장
02.3

bs4나 yaml 같은 외부 모듈이 없나요? Auto-PIP가 별칭(bs4 -> beautifulsoup4)을 자동 매핑해 PyPI에서 설치 후 스크립트를 재실행하며, requirements.txt 일괄 설치와 로컬 .whl/.zip 오프라인 반입도 지원합니다.

Auto-PIP · requirements.txt · 오프라인 .whl 설치기

스크립트 생성 또는 내장 Python 예제 불러오기

Python 전용 21키 심볼 바로 처음부터 작성하거나 코드 예제 라이브러리의 8가지 내장 Python 템플릿으로 빠르게 시작합니다.

STEP 02 PIP Package Manager

PyPI 라이브러리 또는 오프라인 .whl 아카이브 설치

감지된 requirements.txt 칩을 원탭으로 일괄 설치하고, 추천 패키지(requests, rich, bs4, flask)를 선택하거나 다운로드 폴더의 .whl 파일을 오프라인으로 불러옵니다.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인 파이썬 실행, pip/.whl 라이브러리 설치, NumPy/Matplotlib 차트 저장 및 다중 파일 임포트 관련 FAQ입니다.

인터넷이 전혀 없는 비행기 모드에서도 안드로이드에서 파이썬 코드를 실행할 수 있나요?+
네. 다중 파일 Python 3.11 스크립트, 표준 라이브러리, 로컬에 설치된 PIP/.whl 패키지 및 캐시된 과학 연산용 Python 3.12 라이브러리(NumPy, Pandas, Matplotlib, SciPy, scikit-learn) 모두 100% 오프라인으로 실행됩니다.
requests, bs4 같은 서드파티 라이브러리나 오프라인 .whl 파일은 어떻게 설치하나요?+
비주얼 PIP 패키지 매니저를 열거나 스크립트를 바로 실행해 Auto-PIP가 누락된 모듈을 자동 감지하도록 맡기세요. PyPI 온라인 설치, 감지된 requirements.txt 원탭 설치, 로컬 저장소의 .whl·.tar.gz·.zip 파일 반입을 모두 지원합니다.
Matplotlib 그래프나 open('data.csv', 'w')로 생성한 파일은 어디에 저장되나요?+
스크립트가 생성하거나 수정한 모든 이미지, PDF, CSV, JSON 파일은 현재 열려 있는 프로젝트 폴더에 자동으로 동기화되며 SuperCode 내장 이미지 갤러리나 에디터 탭에서 즉시 열람할 수 있습니다.
반복문 안의 대화형 input() 입력도 실시간으로 동작하나요?+
네. 스크립트가 input()을 호출할 때마다 분할 콘솔의 입력 바가 활성화되어 실행 흐름을 멈추고 사용자의 실시간 키보드 입력을 받아 이어서 동작합니다.
