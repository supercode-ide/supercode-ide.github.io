05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Java 입문자, AP Computer Science A 학생, 교사 및 코딩 테스트 준비생을 위한 자주 묻는 질문입니다.

Wi-Fi 없이 SuperCode로 AP Computer Science A 시험을 공부할 수 있나요?+
네! AP Computer Science A 시험에 출제되는 모든 Java 클래스, 배열, `ArrayList`, 문자열 메서드, 상속 구조, 재귀 패턴이 스마트폰이나 태블릿에서 100% 오프라인으로 컴파일되고 실행됩니다.
웹 컴파일러에서는 `Scanner(System.in)` 여러 줄 입력이 자주 실패하는데 SuperCode는 어떻게 처리하나요?+
대부분의 온라인 컴파일러는 실행을 누르기 전에 모든 입력값을 미리 입력해야 합니다. SuperCode는 `System.in`을 실시간으로 스트리밍하여 프롬프트를 먼저 출력하고 각 줄 입력을 기다리며, `while (sc.hasNext())` 반복문을 위한 `[EOF]` 버튼도 제공합니다.
Java 코드를 작성하기 전에 계정을 만들거나 로그인해야 하나요?+
전혀 필요 없습니다. SuperCode는 회원가입 장벽 없이 곧바로 코드 에디터 워크스페이스가 열리므로 학생과 수업 현장에서 즉시 코딩을 시작할 수 있습니다.
나중에 간결한 `void main()`에서 표준 다중 클래스 Java 패키지로 전환할 수 있나요?+
네. 간결한 `void main()`은 빠른 실습을 위한 선택적 편의 기능입니다. 표준 `public class Main` 파일, 여러 `.java` 클래스, 인터페이스 또는 `jdbc:sqlite` 데이터베이스 프로젝트를 작성하면 별도 모드 전환 없이 그대로 컴파일됩니다.
