02 핵심 엔지니어링 기능

데스크톱급 SQL 데이터 분석, 바이너리 DB 검사 & 폭넓은 방언 호환성

모던 오프라인 SQL: 윈도우 함수, 재귀 CTE & JSONB

ROW_NUMBER/RANK/DENSE_RANK/LAG/LEAD OVER(...), WITH RECURSIVE 재귀 쿼리, RETURNING, UPSERT, -> 및 ->> JSON 경로 추출, json_each(), BM25 전문 검색을 100% 오프라인으로 지원합니다.

윈도우 함수 · 재귀 CTE · JSONB & 전문 검색

9가지 결과 렌더링 모드 & 파일 내보내기 파이프라인

box · markdown · csv · json · table · insert

03 단계별 실전 사용법

SuperCode에서 데이터베이스 조회 및 데이터셋 임포트하기

안드로이드 워크스페이스에 그대로 보존되는 깔끔한 스크립트 중심 DB 작업 흐름입니다.

STEP 01 query.sql 또는 app.db

.db 데이터베이스 열기 또는 .sql 스크립트 생성

로컬 .db/.sqlite 파일을 탭해 스키마를 한눈에 확인하거나 오프라인 AST SQL 자동완성·포매터로 .sql 스크립트를 작성합니다.

STEP 02 .import --csv / --json

초기 테이블 시딩 또는 CSV & JSON 파일 적재

프로젝트 폴더에 있는 CSV, TSV, JSON 데이터셋을 단일 명령어로 관계형 테이블에 즉시 불러옵니다.

STEP 03 실행 ▶ (.mode box)

오프라인 다중 구문 SQL 쿼리 실행

분할 화면 콘솔에서 유니코드 박스 표, 마크다운 테이블, JSON 출력을 확인하고 필요 시 READ_STDIN() 파라미터를 입력합니다.

STEP 04 .save / .once report.csv

깔끔한 리포트 내보내기 & PHP/Java 연동

업데이트된 .db 파일이나 .csv/.json 리포트를 프로젝트 폴더에 저장하면 SuperCode의 PHP PDO 및 Java JDBC에서 즉시 함께 사용할 수 있습니다!

6종 내장 SQL 실전 예제 · 로컬 PHP PDO 및 Java 17 JDBC와 직접 DB 파일 공유 앱 가이드

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인 SQL 코딩 테스트 연습, 휴대폰 .db/.sqlite 파일 열기, CSV/JSON 임포트 및 MySQL 문법에 대한 FAQ입니다.

별도 데이터베이스 서버 구축 없이 오프라인으로 SQL 쿼리 연습을 할 수 있나요?+
네! 아무 .sql 파일이나 만들고 실행 버튼만 누르면 CREATE, INSERT, JOIN, 재귀 CTE, 윈도우 함수가 포함된 다중 쿼리가 100% 오프라인으로 실행되며 깔끔한 유니코드 박스 표로 출력됩니다.
스마트폰에 저장된 기존 .db 또는 .sqlite 파일도 열어서 조회할 수 있나요?+
네. .db, .sqlite, .sqlite3, .db3 파일을 탭하거나 실행하면 모든 테이블, 뷰, 인덱스, 스키마 구조를 즉시 보여주며, 같은 프로젝트 폴더 안의 .sql 스크립트에서 해당 DB를 바로 질의하고 수정할 수 있습니다.
AUTO_INCREMENT, SHOW TABLES, DESCRIBE나 저장 프로시저 같은 MySQL 문법도 지원하나요?+
자주 쓰는 MySQL/PostgreSQL DDL 및 조회 명령어(AUTO_INCREMENT, ENUM, SHOW TABLES, DESCRIBE, ILIKE)는 기기 로컬에서 오프라인으로 즉시 호환 실행되며, 서버 전용 MySQL 8.0 저장 프로시저와 트리거는 클라우드 MySQL 8.0으로 자동 연결됩니다.
SQL 쿼리 실행 결과를 CSV, Markdown 또는 JSON 파일로 어떻게 내보내나요?+
SELECT 쿼리 앞에 `.mode csv`(또는 `.mode markdown` / `.mode json`)와 `.once output.csv`를 추가해 실행하면 결과 파일이 현재 프로젝트 폴더에 즉시 생성됩니다.
