02 핵심 엔지니어링 기능

실서버 운영 로그, 대규모 DB 덤프, 레거시 한글 인코딩을 위한 설계

다계층 메모리 보호 설계를 통해 한 줄짜리 거대 압축 JSON이나 수 기가바이트 서버 로그에서도 스크롤, 검색, 저장이 쾌적하게 유지됩니다.

02.1

자동 GB급 10MB 디스크 페이징 스트리밍

30MB가 넘는 파일은 백그라운드 I/O에서 자동으로 스트리밍 페이저가 가동되어 거대 로그, CSV, SQL 백업을 10,000,000자 페이지 단위로 분할하며, 4,000자 이상의 압축된 단일 행도 버벅임 없이 렌더링합니다.

페이지당 1,000만 자 · 120Hz 스크롤 · 초장문 압축 행 안전 모드
02.2

메가 파일 커맨드 센터 & 원자적 병합 저장

이전 페이지, 다음 페이지 또는 1..N 페이지 직접 점프(이동 시 수정된 청크 자동 플러시)로 빠르게 탐색한 뒤 전체 병합 및 저장을 눌러 GB급 원본 파일을 디스크에서 원자적으로 안전하게 재결합합니다.

페이지 [1/N] 즉시 점프 · 수정 청크 자동 보존 · 원자적 저장
02.3

전역 스트림 일괄 치환 & 정규식 캡처 그룹

파일 전체를 RAM에 올리지 않고도 디스크의 모든 페이지에 걸쳐 전역 스트림 모두 바꾸기를 실행합니다. $1..$99 및 ${name} 캡처 그룹, \n/\t 이스케이프, 선택 영역 한정 검색과 1,200ms 정규식 타임아웃 안전장치를 지원합니다.

스트림 전체 치환 · 정규식 $1..$99 · 50,000+ 매치 버퍼
02.4

15MB 가상 메가 클립보드 (10만 줄 이상)

안드로이드 기본 클립보드는 약 800KB 부근에서 오류를 일으킵니다. SuperCode의 인프로세스 가상 클립보드는 최대 15MB 분량의 로그나 SQL 구문을 탭 간에 손쉽게 복사, 잘라내기, 스트리밍 붙여넣기할 수 있습니다.

800KB OS 한계 돌파 · 최대 15MB 대용량 붙여넣기
02.5

EUC-KR 포함 34종 문자 인코딩 & 무손실 저장 가드

UTF-8/16/32, EUC-KR, GB18030/GBK/Big5, Shift_JIS/EUC-JP, KOI8-R, ISO-8859 11종, Windows 코드 페이지 9종을 5단계로 자동 판별합니다. 저장 전 매핑 불가능한 유니코드 문자를 사전 경고하여 한글이 ?로 깨지는 사고를 원천 방지합니다.

34종 인코딩 · BOM 안전 처리 · LF / CRLF / CR 보존
02.6

5만 파일 워크스페이스 퍼지 검색 & 바이너리 방화벽

로컬, Git, SD/USB OTG, SFTP 전반에서 7단계 CamelCase/경로 랭킹(node_modules·.git 자동 제외)으로 원하는 파일을 즉시 찾으며, 4KB 매직 바이트 검사로 비텍스트 바이너리 오열람을 안전하게 차단합니다.

50,000 노드 스캔 · USB OTG 지원 · 4KB 매직 바이트 가드
스마트폰 · 폴더블 · 태블릿 최적화 · 경량 40.2 MB 전체 개요
03 단계별 실전 사용법

수백 MB ~ 수 GB 대용량 파일 탐색 및 일괄 편집 방법

안드로이드 스마트폰과 태블릿에서 거대 서버 로그, CSV 추출본, 레거시 인코딩 파일을 안전하게 다루세요.

STEP 01 Internal / SD / USB OTG

대용량 로그, CSV 또는 SQL 덤프 파일 열기

내부 저장소나 마운트된 SD 카드·USB OTG 드라이브에서 파일을 선택하면 인코딩을 자동 감지하고 1,000만 자 페이지를 즉시 마운트합니다.

STEP 02 Page [1/N] Cockpit

원하는 페이지 청크로 즉시 점프

간결한 7종 메가 파일 전용 바에서 페이지 버튼을 눌러 원하는 페이지 번호로 바로 이동하거나 텍스트 모드 및 젠 모드를 전환합니다.

STEP 03 Search / Stream Replace

매치 탐색 또는 전역 스트림 모두 바꾸기 실행

검색창을 플로팅 미니 알약 바 형태로 접어둔 채 매치 지점을 순회하거나, 전역 스트림 모두 바꾸기로 디스크 전 구간 패턴을 일괄 변환합니다.

STEP 04 Merge All & Save

변경 사항을 디스크에 원자적으로 확정 저장

전체 병합 및 저장을 탭하면 수정된 모든 청크가 문자 인코딩 무결성을 100% 유지한 채 원본 파일로 안전하게 병합 기록됩니다.

내부 저장소, 외장 SD 카드 및 핫플러그 USB OTG 외장 메모리 완벽 지원 앱 가이드

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

GB급 파일 열기 원리, 정규식 일괄 치환, USB 메모리 연결 및 EUC-KR 한글 깨짐 복구에 대한 자주 묻는 질문입니다.

스마트폰 RAM 용량을 초과하는 1GB 이상의 파일을 어떻게 멈춤 없이 편집하나요?+
기가바이트 전체를 메모리에 한꺼번에 올리는 대신 파일을 약 1,000만 글자(~10MB) 단위의 디스크 기반 페이지 청크로 스트리밍 분할합니다. 화면에는 현재 활성 페이지만 상주하며, 전역 스트림 치환 역시 디스크 청크를 순차 처리하므로 메모리 부담 없이 안전합니다.
EUC-KR 한글 깨짐이나 일본어·중국어·러시아어 레거시 인코딩 텍스트 파일도 복구할 수 있나요?+
네. 5단계 인코딩 자동 분석기가 EUC-KR, GB18030, GBK, Big5, Shift_JIS, EUC-JP, KOI8-R, Windows-1251/1252, BOM 없는 UTF-16 등 34종 문자셋을 정확히 식별하며, 원하는 인코딩으로 다시 읽거나 무손실로 UTF-8 변환 저장할 수 있습니다.
한 줄 길이가 500KB에 달하는 압축(minified) JSON이나 JS 파일을 열면 어떻게 되나요?+
4,000자를 초과하는 초장문 행이 감지되면 자동으로 줄바꿈 연산을 생략하는 O(1) 고속 기본 표시 모드가 적용되어 압축 번들이나 긴 로그 라인도 끊김 없이 부드럽게 스크롤됩니다.
USB 메모리(OTG)나 외장 SD 카드에 담긴 대용량 파일도 바로 열 수 있나요?+
네. 워크스페이스 탐색기에서 내부 저장소뿐만 아니라 외장 SD 카드와 핫플러그로 연결한 USB OTG 플래시 드라이브의 대용량 파일을 직접 열고 편집할 수 있습니다.

거대 서버 로그, DB 덤프, EUC-KR 문서까지 멈춤 없이 여세요.
