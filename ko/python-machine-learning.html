02 핵심 엔지니어링 기능

AI 엔지니어와 학생을 위한 온디바이스 + 클라우드 하이브리드 아키텍처

기존 ML과 이미지 파이프라인은 100% 오프라인으로 학습하고, 코드에서 임포트할 때만 수 GB 규모의 딥러닝 프레임워크로 확장하세요.

02.1

오프라인 Scikit-Learn, XGBoost & LightGBM

scikit-learn, xgboost, lightgbm, statsmodels, patsy로 분류, 회귀, 클러스터링, PCA, 교차 검증 및 그래디언트 부스팅을 완전 오프라인으로 실행하세요.

RandomForest · XGBoost · LightGBM · 교차 검증
02.2

OpenCV(cv2), Pillow & Scikit-Image 비전 스튜디오

워크스페이스 폴더에서 PNG/JPEG 이미지를 불러와 이진화(Thresholding), Canny 엣지 검출, 윤곽선, 모폴로지 필터 또는 Pillow 합성을 적용하고 결과 이미지를 즉시 확인하세요.

opencv-python (cv2) · Pillow (PIL) · scikit-image
02.3

NLP 토크나이저, 그래프 ML & 생물정보학

tiktoken을 활용한 LLM 토큰 계산, nltk 및 regex 텍스트 처리, networkx 그래프 중심성 분석, biopython 서열 분석을 간편하게 실험하세요.

tiktoken · nltk · networkx · biopython
02.4

Joblib & Pickle 모델 폴더 직렬화 저장

학습된 추정기와 전처리 배열을 joblib.dump('model.pkl') 또는 np.save('features.npy')로 로컬 Android 디렉터리에 바로 저장해 다른 스크립트에서 재사용하세요.

joblib.dump · .pkl / .npy / .npz 영구 저장

03 단계별 실전 사용법

Android에서 ML & 비전 모델 프로토타이핑 워크플로

로컬 데이터셋 탐색부터 모델 영구 저장 및 원격 GPU 서버 연동까지 막힘없이 이어집니다.

STEP 01 dataset.csv / sample.jpg

워크스페이스에서 피처 및 이미지 준비

프로젝트 폴더에서 바로 Pandas로 표 형식 CSV를 불러오거나 `cv2.imread()` 및 `PIL.Image.open()`으로 로컬 이미지를 읽으세요.

STEP 02 import sklearn, xgboost

기존 ML 모델 오프라인 학습 및 교차 검증

Scikit-Learn 파이프라인이나 XGBoost 모델을 오프라인으로 학습하고, 분류 리포트를 출력하며 Matplotlib로 ROC/혼동 행렬 플롯을 내보내세요.

STEP 03 import torch / # @cloud

클라우드 버스트로 신경망 아키텍처 테스트

로컬 파일 및 라인 번호와 1:1 매핑되는 트레이스백으로 텐서 차원, 커스텀 `nn.Module` 순전파, 손실 함수를 검증하세요.

STEP 04 SFTP / Visual Git

GitHub 또는 GPU 서버로 깔끔한 코드 푸시

검증된 실험 코드를 Visual Git으로 GitHub에 푸시하거나 SFTP를 통해 원격 Linux 학습 서버와 직접 동기화하세요.

오프라인 기존 ML & 비전 · 원격 GPU 서버용 SFTP SSH 키 보관함 앱 가이드

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Android에서 Scikit-Learn, OpenCV, PyTorch 및 원격 GPU 워크플로를 실행하는 방법에 대한 FAQ입니다.

인터넷 없이 Scikit-Learn, XGBoost, OpenCV(`cv2`)를 실행할 수 있나요?+
네. SuperCode의 과학 연산 런타임이 기기에 한 번 캐싱되면 `scikit-learn`, `xgboost`, `lightgbm`, `opencv-python`(`cv2`), `Pillow`, `scikit-image`가 완전 오프라인으로 동작합니다.
스마트폰 저장 공간을 채우지 않고 PyTorch나 TensorFlow 코드를 실행하려면 어떻게 하나요?+
코드에 `import torch` 또는 `import tensorflow as tf`를 작성하거나 첫 줄에 `# @cloud`를 추가하면 됩니다. SuperCode가 로컬 `.py` 모듈을 번들링해 클라우드 Python 클러스터에서 실행하고, 모든 트레이스백을 로컬 에디터의 해당 라인에 정확히 매핑해 줍니다.
제 Linux GPU 워크스테이션의 스크립트를 편집하고 실행할 수 있나요?+
네. SuperCode의 SFTP 워크스페이스(AES-256 암호화된 Ed25519/RSA SSH 키 지원)로 워크스테이션에 연결하면, 전체 AST 자동 완성과 3단계 원자적 저장 기능으로 원격 `.py` 및 `.yaml` 설정 파일을 편집할 수 있습니다.
`cv2.imwrite()`로 처리한 이미지가 내 폴더에 저장되나요?+
네 — `cv2.imwrite()` 또는 `Image.save()`로 저장한 모든 이미지는 프로젝트 디렉터리에 즉시 동기화되며 SuperCode 내장 이미지 뷰어로 깔끔하게 열어볼 수 있습니다.
