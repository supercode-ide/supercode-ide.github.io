02 핵심 엔지니어링 기능

무거운 Gradle 대기 시간 없는 데스크톱급 Java 패키지 아키텍처

4분씩 걸리는 Gradle 동기화나 수동 `javac -cp` 플래그 없이 Android에서 domain, service, repository 패키지를 깔끔하게 구성하세요.

02.1

중첩 패키지 내 최대 500개 .java 파일 스캔

표준 Maven/Gradle 폴더 구조(src/main/java/com/company/...)나 가벼운 하위 폴더 형태로 프로젝트를 구성하세요. SuperCode가 최대 500개 .java 파일(12MB 소스 예산)을 스캔해 패키지 간 import를 한 번에 컴파일합니다.

src/main/java · 중첩 패키지 · 500개 파일 / 12MB
02.2

설정 없는 libs/*.jar & lib/*.jar 클래스패스 로더

Gson, Apache Commons, org.json 또는 강의용 커스텀 라이브러리가 필요하신가요? 프로젝트의 libs/ 또는 lib/ 폴더에 순수 Java .jar 파일(총 30MB 이하)을 넣기만 하면 오프라인에서 즉시 패키지를 import할 수 있습니다.

libs/*.jar · lib/*.jar · 최대 30MB 클래스패스
02.3

거의 0ms 즉시 재실행을 위한 SHA-256 클로저 캐시

SuperCode는 참여하는 모든 .java 소스, 열린 탭 버퍼, .jar 파일의 암호화 SHA-256 다이제스트를 계산합니다. 다른 콘솔 입력으로 재테스트할 때 재컴파일 없이 ~0ms 만에 ⚡ 캐시에 히트합니다.

SHA-256 클로저 해시 · ⚡ 캐시 배지 · 즉시 실행
02.4

열린 탭 어디서나 동작하는 스마트 main() 진입점 판별

InvoiceRepository 인터페이스나 TaxCalculator 헬퍼 클래스를 편집 중이신가요? 그 자리에서 실행 ▶ 을 누르세요. SuperCode가 패키지 그래프를 분석해 프로젝트의 main() 진입 클래스를 찾고 저장되지 않은 탭 편집 내용까지 자동 병합합니다.

모든 탭에서 실행 · 미저장 버퍼 오버레이
02.5

자동 resources/ 클래스패스 에셋 번들링

.properties, .json, .csv, .xml 또는 .txt 템플릿을 resources/ 또는 src/main/resources/ 폴더에 두세요. 데스크톱과 동일하게 Class.getResourceAsStream()이나 ClassLoader.getResource()로 깔끔하게 불러올 수 있습니다.

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

다중 패키지 레이아웃, 외부 .jar 라이브러리 추가 및 main() 자동 판별에 대한 자주 묻는 질문입니다.

SuperCode에서 Gson이나 Commons Lang 같은 외부 `.jar` 라이브러리는 어떻게 추가하나요?+
Java 프로젝트 루트 안에 `libs`(또는 `lib`) 폴더를 만들고 `.jar` 파일을 복사해 넣으세요. SuperCode가 빌드 스크립트 없이도 `libs/`의 모든 `.jar` 아카이브(최대 30MB)를 컴파일 및 런타임 클래스패스에 자동으로 추가합니다.
`main()`이 없는 Java 클래스를 편집하다가 실행 버튼을 누르면 어떻게 되나요?+
SuperCode의 진입점 판별기가 프로젝트의 컴파일된 클래스를 스캔해 `main()`을 포함한 기본 진입 클래스를 자동으로 선택해 실행합니다. 더 이상 탭을 계속 오갈 필요가 없습니다.
반드시 `src/main/java`를 써야 하나요, 아니면 단순한 다중 파일 폴더도 되나요?+
둘 다 문제없이 작동합니다! `package` 문 없이 단순한 폴더에 `.java` 파일 두 개를 나란히 두거나, `com.example.*` 하위 폴더를 직접 구성하거나, `src/main/java` + `resources/` + `libs/` 전체 구조를 사용할 수 있습니다.
Android 오프라인 환경에서 어떤 `.jar` 파일이 동작하나요?+
Java 8, 11 또는 17을 타겟으로 하는 표준 순수 Java `.jar` 라이브러리(`gson`, `org.json`, `commons-lang3`, `commons-csv`, 대학 채점용 라이브러리 등)는 100% 오프라인으로 동작합니다. AWT/Swing 창이 필요한 데스크톱 GUI jar는 모바일 터미널 콘솔용으로 적합하지 않습니다.
