02 핵심 엔지니어링 기능

스마트폰에서 바로 쓰는 프로덕션급 암호화 프리미티브

인터넷 노출 없이 브라우저/엣지 표준(`crypto.subtle`)과 Node.js 백엔드 규격(`node:crypto`)을 아우르는 이식 가능한 보안 유틸리티를 구축하세요.

02.1

W3C crypto.subtle & Node.js node:crypto 기본 내장

폴리필 번들이나 외부 npm 설치 없이 `globalThis.crypto.subtle`(`crypto.webcrypto`)과 Node 백엔드 호출(`import crypto from 'node:crypto'`)을 함께 사용해 크로스 런타임 보안 모듈을 작성하세요.

crypto.subtle · crypto.webcrypto · node:crypto
02.2

AES-128/192/256 인증 암호화 (GCM, CBC, CTR)

`createCipheriv` / `createDecipheriv` 또는 `crypto.subtle.encrypt` / `decrypt`로 페이로드를 오프라인 암복호화하세요. `getAuthTag()` 및 `setAuthTag()`를 완벽 지원해 AEAD 암호문 무결성을 정확히 검증합니다.

aes-256-gcm · aes-256-cbc · aes-256-ctr · AuthTag
02.3

SHA-256/512 다이제스트, HMAC 웹훅 & timingSafeEqual

GitHub/Stripe 스타일의 HMAC-SHA256 웹훅 헤더를 검증하고, `base64url` Buffer로 무의존성 HS256/HS512 JWT 검증기를 구현하며, `crypto.timingSafeEqual(a, b)`로 타이밍 부채널 공격을 방어하세요.

createHash · createHmac · base64url · timingSafeEqual
02.4

PBKDF2 키 스트레칭 & CSPRNG 난수 생성

`pbkdf2`, `pbkdf2Sync`, `subtle.deriveBits`로 암호문구에서 강력한 256비트 키를 파생하고, `randomBytes()`, `getRandomValues()`, `randomUUID()`로 암호학적으로 안전한 솔트, IV 논스, v4 UUID를 생성하세요.

pbkdf2Sync · randomBytes · getRandomValues · randomUUID
02.5

민감한 토큰 & 페이로드를 위한 100% 에어갭 감사

장애 대응 중 Bearer 토큰, OAuth PKCE `S256` 코드 챌린지, 암호화된 설정 블롭을 점검해야 하나요? 비행기 모드를 켜고 원격 전송 유출 없이 Android 기기에서 로컬로 감사하세요.

네트워크 유출 제로 · PKCE S256 · JWT 감사
02.6

node:fs 연동 파일 체크섬 & 암호화 백업 스크립팅

`node:crypto`를 `node:fs` 및 `node:zlib`와 직접 연동해 워크스페이스 폴더의 SHA-256 무결성 매니페스트를 생성하거나 SFTP 업로드 전 로컬 JSON/SQLite 스냅샷을 암호화하세요.

03 단계별 실전 사용법

SuperCode에서 오프라인으로 암호화를 프로토타이핑 및 검증하는 방법

네 단계만으로 해시, HMAC 서명, AES-GCM 페이로드를 로컬에서 깔끔하게 검증하세요.

STEP 01 import crypto from 'node:crypto'

node:crypto 또는 표준 globalThis.crypto.subtle 선택

`.mjs` 또는 `.js` 파일을 여세요 — Node의 동기/스트리밍 암호화 API와 Promise 기반 Web Crypto를 모두 즉시 사용할 수 있습니다.

STEP 02 pbkdf2Sync + randomBytes(12)

CSPRNG 논스 생성 및 키 파생

암호학적 IV, 솔트 또는 UUID를 생성하고 암호문구를 32바이트 AES-256 키로 오프라인 스트레칭하세요.

STEP 03 createCipheriv / createHmac

암호화, 서명 또는 상수 시간 검증 실행

실행 ▶ 버튼을 눌러 hex/base64url 출력, 인증 태그, `timingSafeEqual` 검증 결과를 밀리초 단위로 확인하세요.

STEP 04 fs.writeFileSync

체크섬 또는 암호화된 아티팩트를 폴더에 저장

`.sha256` 매니페스트 파일이나 암호화된 페이로드를 Git 버전 관리나 SFTP 전송을 위해 워크스페이스에 바로 저장하세요.

100% 기기 내 암호화 실행 · 외부 npm 의존성 불필요 앱 가이드

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

오프라인 Web Crypto, `node:crypto` 암호화, JWT 검증 및 비밀키 보안에 관한 FAQ.

기본 Android WebView 앱에서는 종종 실패하는 `crypto.subtle`이 SuperCode에서는 왜 오프라인으로 작동하나요?+
브라우저는 안전하지 않은 `file://` 페이지에서 `window.crypto.subtle`을 제한합니다. SuperCode의 독립 실행형 JavaScript 워커는 보안 컨텍스트 제약 없이 `globalThis.crypto.subtle`(`crypto.webcrypto`)과 `node:crypto`를 모두 오프라인에서 네이티브로 제공합니다.
오프라인에서 어떤 AES 암호 모드와 다이제스트 알고리즘이 지원되나요?+
`aes-128`, `aes-192`, `aes-256`을 `GCM`(16바이트 인증 태그 포함), `CBC`, `CTR` 모드로 실행할 수 있으며, `SHA-1`, `SHA-256`, `SHA-384`, `SHA-512`, `MD5` 해싱 및 HMAC도 함께 지원합니다.
JWT 생성 및 검증에 `Buffer.toString('base64url')`이 작동하나요?+
네! SuperCode의 `Buffer` 구현은 `utf8`, `hex`, `base64` 및 RFC 4648 `base64url` 인코딩/디코딩을 기본 지원하므로 — 무의존성 JWT 및 OAuth PKCE `S256` 스크립트를 손쉽게 작성할 수 있습니다.
`node:crypto` 실행 시 키나 페이로드가 네트워크로 전송되나요?+
절대 전송되지 않습니다. 모든 `node:crypto` 및 `crypto.subtle` 연산은 Android 기기 내에서 100% 로컬로 실행되며, Wi-Fi와 모바일 데이터를 완전히 꺼도 정상 작동합니다.
