02 핵심 엔지니어링 기능

05 자주 묻는 질문

자주 묻는 질문 (FAQ)

Android에서의 HTML5/CSS3/JS 편집, ES Modules, 반응형 뷰포트 미리보기에 관한 자주 묻는 질문입니다.

다른 HTML 에디터 앱에서 `<script type="module">`이나 `fetch('./data.json')`이 실패하는 이유는 무엇인가요?+
브라우저는 엄격한 CORS 보안 규칙 때문에 `file://` URL에서 ES Modules와 `fetch()` 실행을 차단합니다. SuperCode는 올바른 MIME 헤더가 포함된 실제 `localhost` HTTP/1.1 오리진으로 프로젝트를 자동 서빙하므로 최신 JS 모듈과 JSON 요청이 오프라인에서도 정상 작동합니다.
스마트폰 화면에서 태블릿 및 데스크톱 CSS 미디어 쿼리를 어떻게 미리 볼 수 있나요?+
SuperCode의 실시간 웹 미리보기 화면에서 플로팅 다이내믹 아일랜드의 뷰포트 아이콘을 탭하면 모바일, 태블릿(`768dp`), 와이드 데스크톱 뷰포트 간에 즉시 전환되어 `@media` 규칙이 정확하게 적용됩니다.
원탭 포매터가 `<style>` 내부 CSS와 `<script>` 내부 JS도 함께 정렬하나요?+
네. SuperCode의 재귀 HTML 포매터는 `.html` 파일 내부에 포함된 `<style>` 및 `<script>` 블록까지 파싱하여 한 번의 탭으로 세 언어를 모두 깔끔하게 들여쓰기합니다.
로컬 `.mp4` 동영상, `.woff2` 폰트, `.glb` 3D 모델도 오프라인에서 사용할 수 있나요?+
네. `font/woff2`, `model/gltf-binary`, `image/svg+xml` 등 65개 이상의 MIME 타입이 로컬에 사전 설정되어 있으며, 원활한 `<video>` 및 `<audio>` 타임라인 탐색을 위한 HTTP `206 Partial Content` 바이트 범위 스트리밍도 지원합니다.
