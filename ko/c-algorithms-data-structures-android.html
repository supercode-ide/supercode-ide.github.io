05 자주 묻는 질문

자주 묻는 질문 (FAQ)

C17 자료구조, 포인터 순환 안전성, 임베디드 stdint.h 헤더 및 과제 내보내기에 관한 자주 묻는 질문입니다.

재귀 구조체, 연결 리스트, 이진 트리를 완전 오프라인 C 환경에서 컴파일할 수 있나요?+
네. SuperCode의 오프라인 GNU C17 툴체인은 인터넷 연결 없이도 재귀 구조체, malloc/calloc/realloc/free 힙 메모리 관리, 함수 포인터, 다중 .c/.h 헤더 파일을 완벽히 지원합니다.
연결 리스트나 while 루프가 스마트폰에서 무한 루프에 빠지면 어떻게 되나요?+
오프라인 C 프로그램은 UI와 분리된 격리된 Web Worker 내에서 실행됩니다. 에디터는 120Hz 반응성을 유지하며, 정지를 누르면 ANR이나 앱 충돌 없이 Worker가 즉시 종료됩니다.
한 폴더 안에서 여러 개의 테스트용 main() 블록을 #if 0으로 묶어 보관할 수 있나요?+
네. SuperCode의 O(N) C/C++ 전처리기 렉서가 링크 전 #if 0 및 #if false 비활성 분기를 먼저 평가하므로, 보관 중인 테스트 블록이 중복 main() 오류를 일으키지 않습니다.
Android에서 지저분한 C 과제를 포맷팅하고 바로 PDF로 내보낼 수 있나요?+
네. 포맷을 눌러 렉서 기반 C 포맷터를 실행한 뒤(원탭 실행 취소 지원), 제출용 줄 번호와 구문 강조가 적용된 깔끔한 A4 PDF로 바로 내보낼 수 있습니다.
